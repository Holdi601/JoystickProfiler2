Pour commencer

Votre premier profil en 10 minutes

Afficher :

Il y a deux chemins vers des boutons qui marchent. Le chemin rapide prend quelques clics : JoyPro fait le travail. Le chemin à la main prend plus de temps : vous décidez de chaque bouton. Vous pouvez commencer par le chemin rapide et changer des choses à la main plus tard.

Pour les débutants

#Le chemin rapide

  1. Tout configurer pour moi
    sur la page Accueil
  2. Utiliser ces boutons
    regardez la liste
  3. Écrire dans mon jeu
    JoyPro garde une sauvegarde
  4. Volez
    vos boutons sont là
  1. Sur la page Accueil, appuyez sur Tout configurer pour moi. Au premier lancement, Terminé, et tout configurer pour moi fait la même chose.
  2. Regardez la liste de ce qui va où. Appuyez sur Utiliser ces boutons.
  3. Fermez votre jeu. Appuyez sur Écrire dans mon jeu.
  4. Lancez votre jeu et volez.

Pour ACE COMBAT 8 et les autres jeux uniquement Xbox, la fin est différente : Configurer la fausse manette. Tout, étape par étape : Démarrage rapide : faire marcher mon manche.

Un problème ? Voir Annuler la configuration rapide.

#Le faire à la main

Vous avez déjà des assignations dans vos jeux ? Ou vous voulez décider de chaque bouton ? Alors prenez ce chemin.

  1. Importer
    les assignations de vos jeux
  2. Relations
    une fonction, tous les jeux
  3. Assignations
    un bouton ou un axe chacune
  4. Exporter
    dans chaque jeu
  1. Importer. Sur la page Accueil, appuyez sur Importer sur la carte de votre jeu, puis sur Importer maintenant. JoyPro lit vos assignations et crée un profil. Le jeu ne change pas. (Importer un jeu)
  2. Relations. Ouvrez Relations. Une relation est une fonction ("Gear Up/Down") avec son action dans chaque jeu. Pour couvrir un second jeu, ouvrez une relation et appuyez sur Ajouter sur une suggestion. (Créer des relations)
  3. Assignations. Ouvrez Assignations. Choisissez une relation, appuyez sur Enregistrer l'entrée, puis sur le bouton de votre manche. Pour un axe, bougez-le jusqu'au bout. (Page Assignations)
  4. Vérifier. Appuyez sur Vérifier dans la barre du bas. Corrigez les cartes rouges. (La vérification)
  5. Exporter. Fermez le jeu. Ouvrez Exporter, gardez Remplacer sur mes périphériques et Effacer aussi mes autres périphériques (cela retire les anciennes assignations de vos manches dans le jeu ; JoyPro les sauvegarde d'abord). Cochez les jeux, appuyez sur Exporter les jeux cochés. (Exporter)

Lancez ensuite le jeu : vos assignations sont dans son menu des commandes.

Vous changez quelque chose dans le jeu ?

Après la fermeture du jeu, JoyPro demande s'il faut reprendre votre modification dans le profil.

Annuler la dernière exportation sur la carte du jeu remet les fichiers du jeu exactement comme ils étaient.

#Vous avez déjà des assignations ? Mélangez les deux chemins

La page Accueil liste les jeux où vous avez fait vous-même des assignations. Importer, puis combler les vides reprend d'abord vos assignations. Ensuite, la configuration n'utilise que les boutons libres. Vos propres assignations restent.

Avancé

#Des voies plus rapides à la main

  • Configurer étape par étape... (page Accueil) ouvre l'assistant de configuration avec toutes ses étapes : vos jeux, vos périphériques et leurs rôles, vos priorités d'appareils, le plan, la relecture.
  • Combler les vides... (page Accueil) fait la même chose pour les jeux déjà dans votre profil. Vos assignations restent où elles sont.
  • Créer automatiquement des relations à partir de toutes mes actions... (page Relations) regroupe la même fonction de chaque appareil et jeu (Groupement auto). Vous voyez d'abord un aperçu.
  • L'Assignation auto place les relations non assignées sur les meilleures commandes d'un périphérique. Disposer avec l'IA accepte des souhaits en mots simples ("trim on the hat") et montre chaque changement avant de l'appliquer.
  • Suivre l'entrée (pages Relations et Assignations) : appuyez sur un bouton et sa relation s'ouvre.
Détails techniques

#En coulisses

La voie rapide lance d'elle-même les étapes moteur de l'assistant de configuration (engine setup plan, engine setup apply) puis l'exportation du jeu. La voie à la main utilise l'import (engine dcs import et l'import des autres jeux), les commandes de relation (engine relations add), les assignations (engine binds set), la vérification (engine profile validate) et l'exportation (engine dcs export et les autres). Chaque changement est une version du profil, Annuler fonctionne donc d'un redémarrage à l'autre.
