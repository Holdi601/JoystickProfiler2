Démarrage rapide : faire marcher mon manche

Afficher :

Vous voulez que votre manche marche dans votre jeu. Vous ne voulez pas d'abord apprendre JoyPro. Cette page est pour vous.

JoyPro regarde votre manche, votre manette des gaz et votre palonnier. Il y place tout seul les commandes importantes du jeu. Vous regardez le résultat et cliquez sur deux boutons bleus. C'est tout.

  1. Tout configurer pour moi
    sur la page Accueil
  2. Utiliser ces boutons
    dans la nouvelle fenêtre
  3. Écrire dans mon jeu
    le bouton bleu suivant
  4. Volez
    lancez votre jeu
Pour les débutants

#Avant de commencer

  • Téléchargez JoyPro et décompressez-le : Télécharger et installer.
  • Branchez votre manche, votre manette des gaz et votre palonnier.
  • Lancez votre jeu une fois, puis fermez-le. Certains jeux ne créent leurs fichiers de commandes qu'à ce moment-là.
  • Gardez le jeu fermé pendant que JoyPro écrit dedans.

#Le chemin rapide, étape par étape

  1. Lancez JoyPro. La première fois, une fenêtre montre vos jeux. Appuyez sur Terminé, et tout configurer pour moi. Vous pouvez alors sauter l'étape 2.
  2. Appuyez sur Tout configurer pour moi. Vous le trouvez sur la page Accueil, dans la carte « Configurer vos périphériques ». La réponse Faire simplement marcher mon manche à l'écran de bienvenue (la première question de JoyPro après le premier démarrage) fait la même chose.
  3. Regardez la liste. Elle dit ce que fait chaque bouton, par exemple « Bouton 4 : Recharger les armes ». Afficher l'image en grand montre votre manche avec chaque bouton.
  4. Appuyez sur Utiliser ces boutons. Maintenant, JoyPro a vos boutons. Votre jeu ne change pas encore.
  5. Appuyez sur Écrire dans mon jeu. Maintenant, votre jeu a vos boutons. JoyPro garde une copie des anciens.
  6. Volez. La page Accueil indique « Ça a marché ! ». Lancez votre jeu et volez.

Un seul bouton est bleu à la fois. Cliquez sur le bleu, et le suivant devient bleu.

#La question du suivi de la tête

Pour un simulateur de vol, la liste demande : Utilisez-vous le suivi de la tête ou la VR ? Répondez Oui si vous regardez autour de vous en bougeant la tête (TrackIR, une webcam de suivi du visage, Tobii ou la VR), ou si vous comptez le faire. Alors aucun bouton de vue ne va sur votre manche, seulement « recentrer la vue ». Répondez Non si vous regardez autour de vous avec votre manche : un chapeau reçoit la vue. Voir Suivi de la tête et regarder autour.

La ligne du bas

« Tous les boutons importants sont réglés. Quelques extras rares n'avaient pas de place (18). Ce n'est pas grave. » C'est une bonne nouvelle. Votre manche a moins de boutons que le jeu n'a de commandes. Les importantes sont toutes sur votre manche.

#Le jeu a déjà des boutons

Vous avez déjà configuré des boutons dans le jeu ? Alors Écrire dans mon jeu pose une question :

Réponse Ce qui se passe
Utiliser les nouveaux Les boutons de JoyPro remplacent les anciens. JoyPro garde une copie des anciens.
Garder aussi les anciens Vos nouveaux boutons s'ajoutent à côté des anciens. Rien n'est retiré.
Annuler Rien n'est écrit. Appuyez à nouveau sur Écrire dans mon jeu quand vous êtes prêt.

#ACE COMBAT et les autres jeux uniquement Xbox

ACE COMBAT 8 et Hell Let Loose: Vietnam ne connaissent qu'une manette Xbox. Ils ne voient pas votre manche. JoyPro change votre manche en fausse manette (une manette Xbox virtuelle). Rien n'est écrit dans ces jeux.

  1. Tout configurer pour moi
    puis Utiliser ces boutons
  2. Configurer la fausse manette
    le deuxième bouton bleu
  3. Tester
    bougez votre manche
  4. Lancez le jeu
    attendez son écran titre
  5. Alt+Tab, Démarrer
    puis Alt+Tab pour revenir
  1. Appuyez sur Tout configurer pour moi, puis sur Utiliser ces boutons.
  2. Le bouton bleu suivant est Configurer la fausse manette. La page Joystick virtuel s'ouvre.
  3. La première fois, il faut un programme d'aide gratuit appelé ViGEmBus. Cochez la case sous la licence. Puis appuyez sur Installer ViGEmBus. Windows demande l'autorisation : cliquez sur Oui.
  4. Appuyez sur Tester. Bougez votre manche. L'image de la manette bouge aussi.
  5. Lancez le jeu. Attendez son écran titre.
  6. Maintenez Alt et appuyez sur Tab. Vous êtes de retour dans JoyPro. Appuyez sur Démarrer.
  7. Appuyez à nouveau sur Alt+Tab. Vous êtes de retour dans le jeu. Bon vol !
Démarrer vient après le jeu

N'appuyez sur Démarrer que lorsque le jeu affiche son écran titre. Trop tôt ? JoyPro affiche « Trop tôt ». Appuyez sur Arrêter, puis sur Démarrer. Faites-le à chaque partie.

#Un problème ?

  • Aucun jeu ou aucun manche trouvé. Branchez votre manche, ou lancez votre jeu une fois. Puis appuyez sur Réessayer.
  • Vous voulez choisir davantage vous-même. Appuyez sur Configurer étape par étape. Cela ouvre l'assistant de configuration avec toutes ses étapes.
  • Vous voulez retrouver les anciens boutons. Voir Annuler la configuration rapide.
  • Vous voulez un autre bouton pour une chose. Voir Changer un bouton plus tard.

#Mots simples

Vous voulez un grand texte et des phrases très courtes ? Cochez Mots simples : grand texte, phrases courtes dans l'écran de bienvenue ou dans la première fenêtre. Chaque carte de visite a aussi Mots plus simples. Voir Mots simples, visites et F1.

Avancé

#Ce que fait la configuration rapide

  • C'est l'assistant de configuration qui tourne tout seul. Il utilise ses valeurs par défaut : vos périphériques et leurs rôles habituels, tous les appareils à égalité, pas de modificateur.
  • Il ne configure que les jeux où rien n'est encore sur vos manches. La carte de la page Accueil les nomme : « Configurez vos périphériques pour War Thunder et Star Citizen ».
  • Où placer les fonctions ? vient de votre dernier choix dans l'assistant (le milieu au départ). Voir Où placer les fonctions ?.
  • Un périphérique que JoyPro ne connaît pas est configuré comme un périphérique habituel de son type. Bouger le manche dirige, le bouton 1 tire, le premier chapeau sert au trim, le premier levier est la manette des gaz. L'encadré en haut le dit.
  • Modifier quelque chose montre les outils : déplacer, échanger ou laisser de côté une fonction, et la remettre. Il montre aussi ce qui n'a pas trouvé de place.
  • Les jeux où vous avez fait des assignations vous-même sont listés sous la carte. Importer, puis combler les vides reprend d'abord vos assignations ; ensuite la configuration n'utilise que les commandes libres. Les jeux déjà dans votre profil ont Combler les vides....
  • Utiliser ces boutons est une seule étape dans l'historique du profil. Un seul Annuler (Ctrl+Z) annule tout.
  • Écrire dans mon jeu est une exportation de ces jeux. Elle sauvegarde d'abord les fichiers du jeu, comme la page Exporter.
  • Ensuite, une courte visite montre où changer un bouton plus tard. Elle se termine par « C'est fait ! Lancez votre jeu ».
Détails techniques

#En coulisses de la configuration rapide

La voie rapide lance les étapes moteur de l'assistant sans les montrer : engine setup devices, engine setup aircraft et engine setup plan jusqu'à la relecture. Utiliser ces boutons lance engine setup apply (une version du profil). Écrire dans mon jeu lance l'exportation du jeu avec les réglages et la sauvegarde de la page Exporter. Pour les jeux uniquement à manette, il ouvre à la place la page Joystick virtuel ; leur tableau vient de engine vjoy map. Interface : QuickSetupCommand sur la page Accueil, StartQuickSetupAsync (MainWindowViewModel.AutoSetupStart.cs), la fenêtre Views/SetupWizardWindow.axaml.
