JoyPro 2

#Un seul profil pour tous vos périphériques, dans chaque jeu de vol et d'espace.

JoyPro met la même fonction sur le même bouton dans chaque appareil et chaque jeu : train, volets, contre-mesures, trim, gaz. Il peut configurer votre manche, votre manette des gaz et votre palonnier tout seul. Gratuit et open source (GPL-3.0), sans compte, sans télémétrie.

#Comment JoyPro fonctionne

La voie rapide. JoyPro le fait pour vous.

  1. Tout configurer pour moi
    sur la page Accueil
  2. Utiliser ces boutons
    regardez la liste
  3. Écrire dans mon jeu
    JoyPro garde une sauvegarde
  4. Volez
    vos boutons sont là

À votre façon. Vous décidez de chaque bouton.

  1. Importer
    les assignations de vos jeux
  2. Relations
    une fonction, tous les jeux
  3. Assignations
    un bouton ou un axe chacune
  4. Exporter
    dans chaque jeu
  • Une relation est une fonction (« Gear Up/Down ») avec son action dans chaque jeu et chaque appareil.
  • Une assignation est le bouton ou l'axe sur lequel se trouve la relation. Une relation peut en avoir plusieurs.
  • Exporter l'écrit dans les propres fichiers de commandes de chaque jeu. Une sauvegarde est faite d'abord, et vous pouvez l'annuler.
  • Vous changez quelque chose plus tard dans un jeu ? Après la fermeture du jeu, JoyPro vous demande s'il doit le reprendre.
