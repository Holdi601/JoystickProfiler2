Arma Reforger

Afficher :

Arma Reforger prend les joysticks par un fichier de preset joystick que vous choisissez dans les paramètres du jeu. JoyPro écrit son propre preset, JoyPro.conf, avec vos assignations d'hélicoptère sur vos joysticks, et vous le sélectionnez une fois. Le propre fichier de réassignation du jeu n'est jamais touché. Reforger utilise au plus quatre joysticks, donc JoyPro écrit aussi les règles d'ordre des périphériques du jeu, qui disent quel périphérique est le joystick 0, 1, 2 ou 3.

Pour les débutants

#Le faire marcher en 3 étapes

  1. Tout configurer pour moi
    sur la page Accueil
  2. Utiliser ces boutons
    regardez d'abord la liste
  3. Écrire dans mon jeu
    gardez Arma Reforger fermé

Avant : lancez Arma Reforger une fois et ouvrez Settings > Controllers. Puis fermez le jeu.

Ensuite, une fois : dans le jeu, ouvrez Settings > Controllers. Sous Joystick preset, choisissez JoyPro. Redémarrez le jeu. Après les exportations suivantes, un redémarrage suffit.

Vous avez déjà assigné des boutons dans Arma Reforger ? Alors la page Accueil propose Importer, puis combler les vides. Vos assignations restent, et seuls les boutons libres reçoivent de nouveaux rôles. Voir Démarrage rapide : faire marcher mon manche.

#Ce que JoyPro fait pour Arma Reforger

  • Importer : les assignations d'hélicoptère du preset joystick arrivent dans votre profil, avec leur multiplicateur et leur inversion.
  • Relations : une relation est une fonction dans tous les jeux. "Collective" peut être le même levier dans Reforger, Arma 3 et DCS.
  • Exporter : JoyPro écrit JoyPro.conf avec seulement les actions de vol d'hélicoptère et vos joysticks, et range vos périphériques dans les quatre emplacements joystick du jeu. Les commandes d'infanterie et de véhicule, le clavier, la souris et la manette restent comme le jeu les a.

#Importer vos assignations Reforger

  1. Ouvrez Démarrer. Si la carte Arma Reforger demande une liste de commandes, appuyez sur Créer la liste : JoyPro lit les actions d'hélicoptère et leurs noms dans les fichiers du jeu (en lecture seule).
  2. Appuyez sur Importer sur la carte Arma Reforger et gardez Ajouter à mon profil.
  3. Appuyez sur Importer maintenant. Voir mes relations ouvre ce qui est arrivé.

Les assignations clavier et les modificateurs ne sont ni importés ni exportés dans Reforger : JoyPro gère seulement vos joysticks.

#Créer et vérifier les relations

Reliez la même fonction de vos jeux avec le parcours des relations, puis appuyez sur Vérifier sur la page Exporter. Le jeu de base n'a que des hélicoptères (UH-1H, Mi-8) ; les actions d'avion n'arrivent qu'avec des mods.

#Exporter vers Arma Reforger

  1. Fermez Arma Reforger. Le jeu écrit ses paramètres quand vous les changez, donc JoyPro refuse d'écrire pendant qu'il tourne.
  2. Ouvrez Exporter et cochez la carte Arma Reforger.
  3. Gardez Remplacer sur mes périphériques avec Effacer aussi mes autres périphériques si c'est dans JoyPro que vous configurez vos manches. Appuyez sur Exporter maintenant sur la carte.
Dans le jeu: Ce que vous voyez dans Arma Reforger

Lancez le jeu et ouvrez Settings > Controllers. Sous Joystick preset, choisissez JoyPro (une fois), puis redémarrez le jeu. La liste Devices montre vos joysticks dans les emplacements choisis par JoyPro. Les assignations du preset ne s'affichent pas dans Settings > Controls : cette page ne liste que les colonnes clavier et manette.

#Ce que vous faites vous-même dans Arma Reforger

  • Sélectionnez le preset une fois : Settings > Controllers > Joystick preset > JoyPro, puis redémarrez. Après les exportations suivantes, un redémarrage suffit. Choisir là un Controller preset de manette remplace le preset joystick : un seul des deux peut être actif.
  • Lancez le jeu une fois et ouvrez Settings > Controllers avant la première exportation. JoyPro n'écrit l'ordre des périphériques que dans le fichier de paramètres que le jeu a déjà enregistré ; sans lui, il numérote vos périphériques comme le ferait le jeu et vous avertit.
  • Quatre joysticks au maximum. Le jeu prend les quatre premiers qui envoient une entrée après son lancement ; tout périphérique en plus remplace le quatrième. Avec plus de périphériques, débranchez ou masquez les autres (par exemple avec HidHide) pendant que vous jouez à Reforger. Le mode Joystick virtuel peut fusionner vos périphériques en un seul, mais un périphérique vJoy n'est pas apparu dans le jeu en quatre lancements.

#Pièges courants

  • Rien ne se passe en vol : le preset JoyPro n'est pas sélectionné, ou le jeu n'a pas été redémarré après l'exportation.
  • Un manche manque : plus de quatre joysticks envoient des entrées, ou le périphérique n'a jamais envoyé d'entrée pendant que la fenêtre du jeu avait le focus. Bougez un de ses axes ou appuyez sur un bouton avec la fenêtre du jeu au premier plan.
  • Deux périphériques identiques : le jeu distingue les périphériques par leur nom, donc deux du même modèle reçoivent une seule règle d'emplacement ; le second n'a pas d'emplacement.
  • Stable et expérimental : les deux versions gardent des dossiers de paramètres séparés. JoyPro écrit l'ordre des périphériques dans chaque dossier de paramètres qu'il trouve.

#Fichiers que JoyPro lit et écrit

Fichier De quoi il s'agit
%USERPROFILE%\Documents\My Games\ArmaReforger\profile\.save\settings\customInputConfigs\JoyPro.conf Le preset de joystick propre à JoyPro (texte Enfusion) : un bloc Action par action d'hélicoptère avec ses sources joystick et ses filtres
...\profile\.save\app<id>_user<steam id>\settings\ReforgerEngineSettings.conf les réglages du moteur du jeu ; JoyPro ne modifie que les entrées JoystickOrderRule sous DeviceOrderRules
...\app<id>_user<steam id>\settings\ReforgerGameSettings.conf les réglages du jeu ; JoyPro ne modifie que le mode collectif HOTAS et l'intensité du retour de force quand vous les réglez
JoyPro.conf.joypro-meta.json Les noms, groupes et réglages de JoyPro pour les assignations écrites, relus par la prochaine importation
*.jpbak des copies d'avant la première écriture, plus le stockage de sauvegardes versionnées de JoyPro

Le fichier de réassignation propre au jeu InputUserSettings.conf n'est jamais touché, pas plus que vos autres presets dans customInputConfigs. Les anciennes versions nomment les deux fichiers de réglages EngineUserSettings.conf et GameUserSettings.conf (même contenu).

#Les règles d'ordre des périphériques

Le jeu liste au plus quatre joysticks (joystick0 à joystick3) et donne un emplacement à un périphérique quand le nom d'une règle fait partie du nom du périphérique. À l'exportation, JoyPro :

  1. donne aux périphériques pour lesquels vous avez choisi un emplacement cet emplacement (le réglage joystickSlot, 0 à 3 ; -1 = automatique) ;
  2. garde l'emplacement qu'une règle existante donne à un périphérique (y compris les règles propres au jeu avec le nom long) ;
  3. donne aux autres périphériques le plus petit emplacement qu'aucune règle ne réclame.

Chaque règle utilise le nom de produit HID du périphérique (le nom du jeu le contient). JoyPro change un emplacement sur place ou ajoute une règle, et n'écrit que les emplacements 0 à 3. Il prévient quand plus de quatre périphériques sont utilisés, quand il ne reste aucun emplacement ou quand deux emplacements choisis sont identiques. L'importation retrouve joystickN par les mêmes règles.

#Les modes d'exportation dans Arma Reforger

Seuls les blocs Action de vol du preset changent. Les sources clavier, souris et manette, et les joysticks non branchés restent toujours.

Mode Ce qui se passe dans JoyPro.conf
Ajouter seulement Chaque source reste. Une assignation dont l'entrée joystick est utilisée par une autre action de vol n'est pas écrite et reçoit une marque « Non écrit dans le jeu ».
Mettre à jour, garder les assignations du jeu Vos sources entrent ; la source d'une autre action de vol sur la même entrée est retirée. Les anciennes sources de l'action restent.
Mettre à jour, mon profil l'emporte Comme ci-dessus, et une action que vous assignez perd ses autres sources joystick des périphériques branchés.
Remplacer sur mes périphériques Les sources de vol des périphériques que vous écrivez sont retirées et remplacées par les vôtres.
+ Effacer aussi mes autres périphériques Pareil pour les périphériques branchés sans assignations dans votre profil.

Un bloc qui reste sans sources est retiré.

#Ce qui n'est jamais touché

  • InputUserSettings.conf, vos autres presets et toutes les actions d'infanterie, de véhicule et de menu.
  • Les sources clavier, souris et manette ; les joysticks non branchés ; les périphériques ignorés de l'importation et le périphérique vJoy alimenté par JoyPro.
  • Chaque ligne des deux fichiers de réglages sauf les règles d'ordre et les deux réglages que JoyPro gère. Un bloc de réglages manquant n'est pas créé (JoyPro prévient : changez le réglage une fois dans le jeu).
  • Les mods du Workshop ne sont pas lus.

#Hélicoptères, courbes, réglages

  • Granularité : un seul jeu d'assignations pour tous les hélicoptères (le contexte Helicopter du jeu).
  • Réglages des axes : par assignation, un multiplicateur et une inversion, écrits comme filtre de valeur du jeu sur les deux moitiés de l'axe. Les zones mortes et courbes de Reforger par axe de périphérique ne sont pas écrites (leur format n'est pas encore connu).
  • Les boutons agissent comme les touches du jeu : un bouton reçoit le même preset et le même filtre que la source par défaut du jeu pour cette action (clic, maintien, répétition), donc "Engine start" est maintenu et "Sight range down" se répète.
  • Réglages du jeu : mode collectif HOTAS (Default, Manual, Sticky, Direct ; le défaut du jeu pour un HOTAS est Direct) et intensité du retour de force (0 à 3) ; par périphérique le joystickSlot. Réglez-les dans Paramètres > Paramètres de retour de force des jeux (choisissez Arma Reforger) ou avec engine ffb set. Une exportation sans assignations Reforger les écrit quand même.
  • Surveillance : un changement dans le preset ou dans les réglages du jeu est remarqué après la fermeture du jeu ; JoyPro demande s'il doit le reprendre.
  • HUD : le HUD trouve le jeu par son processus et affiche vos assignations Reforger.
Détails techniques

#Dans l'intégration Reforger

Code : engine\Games\ArmaReforgerIntegration.cs, engine\Games\ReforgerCatalogSource.cs, engine\Games\EnfusionPak.cs, le modèle d'axes engine\AxisModels\ArmaReforger.cs et le modèle de réglages engine\FfbModels\ArmaReforger.cs.

  • Format : texte Enfusion, indentation d'un espace, Key Value, objets Class "{16 hex digits}" { ; chaque nouvel objet reçoit un identifiant aléatoire unique. Entrées : joystick0:button4 (à partir de 0), joystick0:axis6, demi-axes joystickN:axisA+ / axisA-, chapeaux joystickN:pov_up|pov_down|pov_left|pov_right ; axes 0 à 7 = X, Y, Z, Rx, Ry, Rz, Slider 0, Slider 1. Une action sur l'axe entier est écrite comme joystickN:axisA (inversée par un Multiplier négatif).
  • Périphériques : le jeu détecte un joystick par l'entrée brute (usage page 1, usage 4) quand il envoie son premier rapport pendant que la fenêtre du jeu a le focus ; les manettes et les contrôleurs multi-axes ne sont jamais des joysticks ici. Sa table contient quatre entrées ; un cinquième nouveau périphérique écrase le quatrième.
  • Liste de commandes : engine reforger refresh-db lit Configs/System/chimeraInputCommon.conf, les titres de menu de keyBindingMenu.conf et localization.en_us.conf dans les archives .pak du jeu (lecture seule), plus les actions de vos presets ; seuls les contextes Helicopter / Airplane comptent. engine reforger catalog les liste, engine reforger paths montre les fichiers trouvés.
  • Importation / exportation : engine reforger import, engine reforger scan ; engine reforger export --mode clean|add|merge|merge-overwrite --nuke-untouched-devices --ignore-device <d> --dry-run.
  • Paramètres : engine ffb set --device * --game ArmaReforger --param hotasCollective=<0..3> (aussi forceFeedbackIntensity) ; --device "<device>" --param joystickSlot=<0..3> ; un emplacement au-dessus de 3 est refusé.

#Limites connues

  • L'exportation n'est pas encore vérifiée dans le jeu lancé ; les menus de réglages l'ont été.
  • Multiplicateur et inversion seulement ; pas de zone morte ni de courbe.
  • Quatre joysticks au plus ; un périphérique vJoy n'est pas apparu dans le jeu en quatre lancements, le joystick virtuel n'est donc suggéré que pour plus de quatre périphériques.
  • On ne sait pas encore si un preset remplace les sources clavier par défaut du jeu ou s'y ajoute.
  • Tests : engine\tests\smoke\arma.ps1 (filtre, règles d'ordre, réglages du jeu, refus).
