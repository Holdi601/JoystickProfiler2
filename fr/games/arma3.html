Arma 3

Afficher :

Arma 3 garde vos assignations dans votre profil de joueur, <name>.Arma3Profile : une ligne par action avec des codes numériques, et une liste des joysticks que le jeu a vus. JoyPro lit les assignations d'avion et d'hélicoptère dans votre profil et ne les réécrit que dans ces lignes. Les assignations d'infanterie, de véhicule et de menu restent telles quelles. Dans Arma, les courbes de réponse sont par périphérique et par axe physique, donc une courbe vaut pour tous les véhicules.

Pour les débutants

#Le faire marcher en 3 étapes

  1. Tout configurer pour moi
    sur la page Accueil
  2. Utiliser ces boutons
    regardez d'abord la liste
  3. Écrire dans mon jeu
    gardez Arma 3 fermé

Avant : lancez Arma 3 une fois avec tous les périphériques branchés, puis quittez.

Ensuite : vos assignations sont dans Options > Controls.

Vous avez déjà assigné des boutons dans Arma 3 ? Alors la page Accueil propose Importer, puis combler les vides. Vos assignations restent, et seuls les boutons libres reçoivent de nouveaux rôles. Voir Démarrage rapide : faire marcher mon manche.

#Ce que JoyPro fait pour Arma 3

  • Importer : les assignations d'avion et d'hélicoptère sur vos manches, manettes des gaz et palonniers arrivent dans votre profil, avec la sensibilité, la zone morte et la pente de chaque axe.
  • Relations : une relation est une fonction dans tous les jeux. "Gear" peut être le même interrupteur dans Arma 3, DCS et les autres jeux.
  • Exporter : JoyPro ne réécrit que les lignes de touches des actions de vol. Vos assignations clavier et souris restent, y compris sur ces actions.

#Importer vos assignations Arma 3

  1. Ouvrez Démarrer. Si la carte Arma 3 demande une liste de commandes, appuyez sur Créer la liste : JoyPro lit les actions et leurs noms anglais dans la config du jeu (en lecture seule, pas besoin d'un premier lancement).
  2. Appuyez sur Importer sur la carte Arma 3 et gardez Ajouter à mon profil.
  3. Appuyez sur Importer maintenant. Voir mes relations ouvre ce qui est arrivé.

Les assignations clavier ne sont ni importées ni exportées dans Arma 3 : JoyPro gère seulement vos joysticks.

#Créer et vérifier les relations

Reliez la même fonction de vos jeux avec le parcours des relations, puis appuyez sur Vérifier sur la page Exporter. L'exportation compte les hélicoptères et les avions comme des véhicules différents : le même bouton sur une action d'avion et sur une action d'hélicoptère n'est pas un conflit ; deux actions d'avion sur un bouton en sont un.

#Exporter vers Arma 3

  1. Fermez Arma 3. Le jeu enregistre le profil quand il quitte et quand vous changez des paramètres, donc JoyPro refuse d'écrire pendant qu'il tourne.
  2. Ouvrez Exporter et cochez la carte Arma 3.
  3. Gardez Remplacer sur mes périphériques avec Effacer aussi mes autres périphériques si c'est dans JoyPro que vous configurez vos manches. Appuyez sur Exporter maintenant sur la carte.
Dans le jeu: Ce que vous voyez dans Arma 3

Lancez le jeu et ouvrez Options > Controls dans le menu principal. Vos assignations sont sur les actions d'avion et d'hélicoptère, à côté des touches clavier que vous aviez. Sous Controllers, vos périphériques sont listés et activés ; Customize d'un périphérique montre la sensibilité, la zone morte et la pente écrites par JoyPro.

#Ce que vous faites vous-même dans Arma 3

  • Lancez Arma une fois avec tous les périphériques branchés. Le jeu ajoute un périphérique à sa liste (et lui donne sa plage de numéros) la première fois qu'il le voit. JoyPro ne peut pas écrire un périphérique absent de la liste : il l'ignore et vous dit de lancer le jeu une fois avec lui branché.
  • Un périphérique que vous avez désactivé dans la liste Controllers du jeu est activé par l'exportation quand il reçoit des assignations (l'exportation le signale), sauf si vous l'avez désactivé pour Arma 3 dans JoyPro (enabled=0, voir Technique).

#Pièges courants

  • "Arma 3 est en cours d'exécution" : quittez le jeu et exportez à nouveau.
  • Un périphérique a été ignoré : Arma ne l'a pas encore vu, ou il a reçu un nouvel ID (un autre port USB donne une nouvelle entrée avec une nouvelle plage de numéros). Lancez le jeu une fois avec lui branché.
  • Deux relations sur un axe avec des courbes différentes : Arma a une courbe par axe physique. La première relation par ordre de nom l'emporte ; l'exportation nomme les deux.
  • La manette des gaz ne marche que sur la moitié du levier : la poussée analogique a besoin des deux moitiés du levier. JoyPro écrit les gaz et l'aérofrein de l'avion comme un axe complet ; vérifiez que la relation est sur un axe, pas sur un bouton.

#Fichiers que JoyPro lit et écrit

Fichier De quoi il s'agit
%USERPROFILE%\Documents\Arma 3\<name>.Arma3Profile le profil par défaut : lignes key<Action>[]={...};, class JoysticksList (les périphériques avec leurs tableaux) et les options du jeu
%USERPROFILE%\Documents\Arma 3 - Other Profiles\<name>\<name>.Arma3Profile vos autres profils (les noms de dossier et de fichier sont encodés comme une URL, Mission%20Builder)
<profile>.joypro-meta.json Les noms, groupes et réglages de JoyPro pour les assignations écrites, relus par la prochaine importation
<profile>.jpbak la copie d'avant la première écriture, plus le stockage de sauvegardes versionnées de JoyPro

JoyPro ne touche jamais à <name>.vars.Arma3Profile ni à .3den.Arma3Profile, et s'arrête quand le profil est un fichier binaire (rapifié) au lieu de texte. Un dossier -profiles= ou un autre dossier Documents peut être réglé sur la page Exporter sous Options et chemins (pour experts).

#Les modes d'exportation dans Arma 3

Seules les lignes des actions d'avion et d'hélicoptère cataloguées changent. Les codes clavier, souris, TrackIR et manette Xbox restent toujours.

Mode Ce qui se passe dans le profil
Ajouter seulement Rien n'est retiré. Une assignation dont le code est déjà utilisé par une autre action du même véhicule n'est pas écrite et reçoit une marque « Non écrit dans le jeu ».
Mettre à jour, garder les assignations du jeu Vos codes entrent ; un code d'une autre action du même véhicule que vous avez mis ailleurs est retiré. Les autres codes de l'action restent.
Mettre à jour, mon profil l'emporte Comme ci-dessus, et une action que vous assignez perd ses autres codes joystick des joysticks branchés.
Remplacer sur mes périphériques Les lignes de vol perdent aussi tous les autres codes des périphériques écrits.
+ Effacer aussi mes autres périphériques Pareil pour les codes des autres joysticks branchés. Un joystick non branché garde ses codes.

#Ce qui n'est jamais touché

  • Les actions d'infanterie, de véhicule, de vue et de menu ; toute ligne qui n'est pas une action de vol cataloguée.
  • Les codes clavier, souris, TrackIR et manette Xbox.
  • Les joysticks non branchés, les codes dont la plage de numéros n'a pas de périphérique dans la liste, les périphériques ignorés de l'importation et le périphérique vJoy alimenté par JoyPro.
  • La liste des périphériques elle-même : JoyPro n'ajoute aucune entrée et ne change que les tableaux, le mode et les seuils de clic analogique des entrées existantes.

#Véhicules, courbes, réglages du jeu

  • Granularité : un seul jeu d'assignations pour tous les avions et hélicoptères. Certaines actions sont partagées (palonnier, train).
  • Courbes d'axe, par périphérique et par axe physique, comme la fenêtre Customize les garde : sensibilité pour chaque moitié (-1 = cubique, 0 = linéaire, +1 = racine cubique), zone morte (0 à 0.1) et pente (1.0, 1.2, 1.5, 1.9, 2.4 ou 3.0 ; les autres valeurs sont arrondies avec un avertissement). La pente multiplie et sature, ce n'est pas un exposant. JoyPro n'écrit que les valeurs que vous avez réglées pour Arma 3 ou qui viennent de l'importation ; votre courbe JoyPro générale n'est pas reprise.
  • Inverser : Arma n'a pas d'option d'inversion. JoyPro inverse en assignant la moitié opposée de l'axe.
  • Manette des gaz sur l'axe complet : "Thrust (Analog)" et "Speedbrake (Analog)" reçoivent les deux moitiés du levier, la moitié négative d'abord (levier vers l'avant), et, inversées, la moitié positive d'abord.
  • Réglages du jeu : le modèle de vol avancé de l'hélicoptère et son auto-trim, les jauges, les options d'atterrissage brutal, de vent et de dégâts de contrainte, et la vibration de la manette ; par périphérique activé/désactivé et les seuils de clic analogique. Réglez-les dans Paramètres > Paramètres de retour de force des jeux (choisissez Arma 3) ou avec engine ffb set. Une exportation sans assignations Arma 3 les écrit quand même et ne touche à aucune ligne de touche.
  • Retour de force : Arma 3 n'a pas d'option de retour de force pour le joystick.
  • Surveillance : une assignation ou une courbe que vous changez dans le jeu est remarquée après sa fermeture ; JoyPro demande s'il doit la reprendre.
  • HUD : le HUD trouve le jeu par son processus et affiche vos assignations Arma 3.
Détails techniques

#Dans l'intégration Arma 3

Code : engine\Games\Arma3Integration.cs sur le code de profil Arma partagé avec Arma 2 (ArmaProfileIntegration.cs, ArmaGameData.cs), le modèle d'axes engine\AxisModels\Arma3.cs et le modèle de réglages engine\FfbModels\Arma3.cs.

  • Périphériques : class JoysticksList { class Joystick1 { guid="..."; name="..."; offset=256; isXInput=0; sensitivity[]={...}; deadZone[]={...}; steepness[]={...}; mode="Custom"; ... }; }. guid est le GUID d'instance DirectInput, en majuscules, sans accolades. offset vaut 256 fois N, attribué quand le jeu voit le périphérique pour la première fois ; les entrées restent après débranchement. mode="Disabled" désactive un périphérique.
  • Codes (32 bits signés, off = l'offset du périphérique) : bouton 0x20000 + off + button ; axe 0x30000 + off + a, a de 0 à 7 pour la moitié positive, a + 8 pour la moitié négative (X, Y, Z, RotX, RotY, RotZ, Slider 1, Slider 2) ; chapeau 0x40000 + off + direction (huit directions, un seul chapeau). Les codes clavier sont des numéros DIK.
  • Tableaux : sensitivity[] (16 valeurs, moitiés positives puis moitiés négatives), deadZone[] (8) et steepness[] (8). Un tableau manquant est créé après son prédécesseur dans l'ordre d'enregistrement du jeu, avec les valeurs par défaut du jeu pour les autres axes, seulement quand une valeur diffère de la valeur par défaut. Importation + exportation sont identiques octet par octet.
  • Liste de commandes : engine arma3 refresh-db lit CfgDefaultKeysPresets dans bin.pbo > config.bin et les noms de menu anglais dans le stringtable.xml de languagecore_f.pbo ; un profil ajoute les actions des mods. 51 actions. engine arma3 catalog les liste, engine arma3 paths montre les profils trouvés.
  • Importation / exportation : engine arma3 import, engine arma3 scan ; engine arma3 export --mode clean|add|merge|merge-overwrite --nuke-untouched-devices --ignore-device <d> --dry-run.
  • Paramètres : engine ffb set --device "<name> {GUID}" --game Arma3 --param enabled=0|1 (aussi analogClickHigh, analogClickLow) ; pour tout le jeu --device * avec RTDEnabled, RTDAutoTrim, RTDFullHUD, RTDRoughLanding, RTDWindDynamic, RTDStressDamage, vibrations.

#Limites connues

  • Les boutons de joystick avec modificateurs ne sont pas encore confirmés ; JoyPro n'écrit ni modificateurs ni assignations clavier pour Arma 3.
  • Jusqu'à 256 boutons, 8 axes et un chapeau par périphérique peuvent être encodés (d'après le format du fichier).
  • On ne sait pas encore si le curseur Customize écrit la même valeur dans les deux moitiés, ni comment agissent les courbes par action que certaines actions ajoutent par-dessus (l'aperçu ne montre que la courbe du périphérique).
  • Tests : engine\tests\smoke\arma.ps1 (tableaux, réglages, manette des gaz sur l'axe complet, avertissement de conflit, aller-retour d'importation, exportation des réglages seuls) ; dans le jeu tools\e2e\games\Arma3Settings.ps1 (profil de test JoyProE2E, menu principal > Options > Controls seulement).
