Afficher :

JoyPro gère 36 titres et a des notes sur 21 autres. Chaque page ci-dessous explique un jeu (ou une famille de jeux qui partagent leurs fichiers). Elle commence par Le faire marcher en 3 étapes. Le sélecteur Afficher : en haut d'une page de jeu choisit le niveau : Débutant (les étapes, l'importation, les relations, l'exportation et ce que vous voyez ensuite dans le jeu), Avancé (les fichiers, ce que fait chaque mode d'exportation dans ce jeu, ce qui n'est jamais touché, les courbes, le retour de force, la surveillance) et Technique (formats de fichier, identification des périphériques, commandes du moteur).

Pour les débutants

#La méthode rapide pour la plupart des jeux

  1. Tout configurer pour moi
    sur la page Accueil
  2. Utiliser ces boutons
    regardez d'abord la liste
  3. Écrire dans mon jeu
    gardez le jeu fermé

ACE COMBAT 8 et Hell Let Loose: Vietnam ne connaissent qu'une manette Xbox. Pour eux, JoyPro crée plutôt une fausse manette. Voir Jouer à un jeu Xbox seulement avec un HOTAS.

#Comment vos assignations arrivent dans un jeu

Tous les jeux suivent les mêmes règles : JoyPro n'écrit que les actions de la liste de commandes du jeu, refuse d'écrire pendant que le jeu tourne, sauvegarde d'abord les fichiers (Annuler la dernière exportation sur la page Exporter les remet octet pour octet) et ignore un périphérique ou une action qu'il ne peut pas associer au lieu de deviner. Les périphériques non branchés, votre souris, les périphériques ignorés à l'importation et le périphérique vJoy vers lequel JoyPro transmet ne sont jamais effacés.
