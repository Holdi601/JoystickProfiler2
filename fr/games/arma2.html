Arma 2 et Operation Arrowhead

Afficher :

Arma 2 et Arma 2: Operation Arrowhead gardent vos assignations dans votre profil de joueur : une ligne par action avec des codes numériques, et une liste des joysticks que le jeu a vus. Les deux jeux partagent un dossier mais ont des fichiers séparés, donc JoyPro les traite comme deux jeux. Il ne lit et n'écrit que les assignations d'avion et d'hélicoptère ; les assignations d'infanterie, de véhicule et de menu restent. Operation Arrowhead couvre aussi Combined Operations, BAF, PMC, ACR et le mod DayZ.

Pour les débutants

#Le faire marcher en 3 étapes

  1. Tout configurer pour moi
    sur la page Accueil
  2. Utiliser ces boutons
    regardez d'abord la liste
  3. Écrire dans mon jeu
    gardez le jeu fermé

Avant : lancez le jeu une fois avec tous les périphériques branchés. Ouvrez Options > Controls > Controllers. Puis quittez. Faites-le pour chacun des deux jeux auxquels vous jouez.

Ensuite : vos assignations sont dans Options > Controls.

Vous avez déjà assigné des boutons dans Arma 2 ? Alors la page Accueil propose Importer, puis combler les vides. Vos assignations restent, et seuls les boutons libres reçoivent de nouveaux rôles. Voir Démarrage rapide : faire marcher mon manche.

#Ce que JoyPro fait pour Arma 2

  • Importer : les assignations d'avion et d'hélicoptère sur vos manches, manettes des gaz et palonniers arrivent dans votre profil, avec le curseur de sensibilité de chaque axe.
  • Relations : une relation est une fonction dans tous les jeux. Arma 2 et Operation Arrowhead y sont deux jeux, donc une relation peut contenir les deux.
  • Exporter : JoyPro ne réécrit que les lignes de touches des actions de vol. Les assignations clavier et souris restent, y compris sur ces actions.

#Importer vos assignations Arma 2

  1. Ouvrez Démarrer. Si la carte Arma 2 ou Operation Arrowhead demande une liste de commandes, appuyez sur Créer la liste : JoyPro lit les actions et leurs noms anglais dans les fichiers du jeu (en lecture seule, pas besoin d'un premier lancement).
  2. Appuyez sur Importer sur la carte du jeu auquel vous jouez et gardez Ajouter à mon profil.
  3. Appuyez sur Importer maintenant. Voir mes relations ouvre ce qui est arrivé.

JoyPro gère seulement vos joysticks : les assignations clavier ne sont ni importées ni exportées, et Arma 2 ne connaît pas de boutons de joystick avec modificateurs.

#Créer et vérifier les relations

Reliez la même fonction de vos jeux avec le parcours des relations, puis appuyez sur Vérifier sur la page Exporter. L'exportation compte les hélicoptères et les avions comme des véhicules différents : le même bouton sur les deux n'est pas un conflit. Les actions d'armes et de vue comptent pour les deux.

#Exporter vers Arma 2

  1. Fermez le jeu. Arma 2 enregistre lui-même le profil, donc JoyPro refuse d'écrire pendant qu'il tourne.
  2. Ouvrez Exporter et cochez la carte Arma 2 ou Operation Arrowhead.
  3. Gardez Remplacer sur mes périphériques avec Effacer aussi mes autres périphériques si c'est dans JoyPro que vous configurez vos manches. Appuyez sur Exporter maintenant sur la carte.
Dans le jeu: Ce que vous voyez dans Arma 2

Lancez le jeu et ouvrez Options > Controls dans le menu principal. Vos assignations sont sur les actions d'avion et d'hélicoptère, à côté de vos touches clavier. Sous Controllers, vos périphériques sont listés et activés, et Customize d'un périphérique montre le curseur de sensibilité de chaque axe là où JoyPro l'a réglé.

#Ce que vous faites vous-même dans Arma 2

  • Lancez le jeu une fois avec tous les périphériques branchés et ouvrez Options > Controls > Controllers. Le jeu ajoute un périphérique à sa liste la première fois qu'il le voit ; JoyPro ne peut pas écrire un périphérique absent de la liste et vous dit de lancer le jeu une fois avec lui.
  • Un périphérique que le jeu a laissé désactivé est activé par l'exportation quand il reçoit des assignations (l'exportation le signale).
  • Lancez chacun des deux jeux une fois si vous jouez aux deux : chacun a son propre fichier de profil et sa propre liste de périphériques.

#Pièges courants

  • "Le jeu est en cours d'exécution" : quittez Arma 2 ou Operation Arrowhead et exportez à nouveau.
  • Le palonnier ou une manette des gaz tire des armes ou fait regarder autour : quand le jeu voit un périphérique pour la première fois, il lui ajoute toutes les valeurs par défaut des joysticks (inclinaison sur X, nez sur Y, regard sur le chapeau, quelques boutons), palonniers et manettes des gaz compris. Remplacer sur mes périphériques les retire.
  • Les boutons au-delà de 32 ou un deuxième chapeau ne font rien : Arma 2 lit 32 boutons, 8 axes et le premier chapeau. JoyPro ignore les assignations au-delà.
  • Un périphérique a été ignoré après un changement de port USB : le jeu voit un nouvel ID comme un nouveau périphérique. Lancez le jeu une fois avec lui branché.
  • Arma 2 seul : la manette des gaz ne marche que sur la moitié du levier : Arma 2 sans Operation Arrowhead ne peut pas réunir les deux moitiés d'un levier sur une action.
Avancé

#Fichiers que JoyPro lit et écrit

Fichier De quoi il s'agit
%USERPROFILE%\Documents\ArmA 2\<name>.ArmA2OAProfile Operation Arrowhead (et Combined Operations, mod DayZ) : lignes key<Action>[]={...};, class JoysticksList et les autres options
%USERPROFILE%\Documents\ArmA 2\<name>.ArmA2Profile Arma 2 seul, le même format
%USERPROFILE%\Documents\ArmA 2 Other Profiles\<name>\<name>.<ext> vos autres profils (sans tiret, contrairement à Arma 3)
<profile>.joypro-meta.json Les noms, groupes et réglages de JoyPro pour les assignations écrites, relus par la prochaine importation
<profile>.jpbak la copie d'avant la première écriture, plus le stockage de sauvegardes versionnées de JoyPro

JoyPro ne touche jamais à <name>.vars.<ext> ni aux réglages vidéo ArmA2.cfg / ArmA2OA.cfg, et s'arrête quand un profil est un fichier binaire (rapifié). Chaque autre octet reste : fins de ligne, tabulation en début de ligne, ordre des lignes. Une ligne de touche cataloguée manquante est ajoutée après la dernière ligne de touche (une ligne manquante signifie « le réglage par défaut du jeu »).

#Les modes d'exportation dans Arma 2

Seules les lignes des actions d'avion et d'hélicoptère cataloguées changent. Les codes clavier, souris, TrackIR et manette Xbox et les combinaisons clavier restent toujours.

Mode Ce qui se passe dans le profil
Ajouter seulement Rien n'est retiré. Une assignation dont le code est déjà utilisé par une autre action du même véhicule n'est pas écrite et reçoit une marque « Non écrit dans le jeu ».
Mettre à jour, garder les assignations du jeu Vos codes entrent ; un code d'une autre action du même véhicule que vous avez mis ailleurs est retiré. Les autres codes de l'action restent.
Mettre à jour, mon profil l'emporte Comme ci-dessus, et une action que vous assignez perd ses autres codes joystick des joysticks branchés.
Remplacer sur mes périphériques Les lignes de vol perdent aussi tous les autres codes des périphériques écrits, y compris les réglages automatiques par défaut du jeu.
+ Effacer aussi mes autres périphériques Pareil pour les codes des autres joysticks branchés. Un joystick non branché garde ses codes.

#Ce qui n'est jamais touché

  • Infanterie, véhicule, menu et toute autre ligne qui n'est pas une action de vol cataloguée.
  • Les codes clavier, souris, TrackIR et manette Xbox.
  • Les joysticks non branchés, les codes dont la plage de numéros n'a pas de périphérique dans la liste, les périphériques ignorés de l'importation et le périphérique vJoy alimenté par JoyPro.
  • La liste des périphériques : JoyPro n'ajoute aucune entrée et ne change que sensitivity[] et le mode des entrées existantes ; joystickSensitivity[], les schémas de manette, les réglages souris et TrackIR restent.

#Véhicules, courbes, réglages

  • Granularité : un seul jeu d'assignations pour tous les avions et hélicoptères ; par jeu (Arma 2, Operation Arrowhead).
  • Les axes en moitiés : Arma 2 assigne chaque moitié d'un axe à une action. Les relations d'axe de JoyPro écrivent les deux : tangage (piquer / cabrer), roulis (incliner à gauche / à droite), palonnier (pédale gauche / droite), le virage arcade, le taux de poussée (augmenter / diminuer la poussée) ainsi que la vue et le zoom.
  • Manette des gaz : "Thrust (Analogue)" est la manette des gaz de l'avion et le collectif absolu de l'hélicoptère ; "Brake (Analogue)" est l'aérofrein. Dans Operation Arrowhead, JoyPro met les deux moitiés du levier sur l'action, la moitié négative d'abord (inversé : la moitié positive d'abord), et le jeu les réunit en un axe complet. Arma 2 seul reçoit une moitié.
  • Sensibilité : un curseur par périphérique et par axe physique (la fenêtre Customize, -1 à 1), enregistré comme 10 puissance la valeur du curseur. Il compte pour tous les véhicules. JoyPro n'écrit que les valeurs que vous avez réglées pour Arma 2 / Operation Arrowhead (ou pour les deux, family:arma2) ou qui viennent de l'importation ; quand deux relations sur un même axe ne sont pas d'accord, la première par ordre de nom l'emporte, avec un avertissement.
  • Zone morte : fixée à 7 % sur les axes principaux (aucune sur les curseurs) ; non réglable dans le jeu, non écrite.
  • Inverser : par l'ordre des moitiés (voir Manette des gaz) ou par la moitié opposée ; il n'y a pas d'option d'inversion.
  • Paramètres : par périphérique activé/désactivé (mode Custom ou Disable). Arma 2 n'a pas d'options globales que JoyPro écrit, pas de retour de force et pas de télémétrie.
  • Surveillance : une assignation ou un curseur que vous changez dans le jeu est remarqué après sa fermeture ; JoyPro demande s'il doit le reprendre.
  • HUD : le HUD trouve le jeu par son processus et affiche vos assignations.
Détails techniques

#Dans l'intégration Arma 2

Code : engine\Games\Arma2Integration.cs sur le code de profil Arma partagé avec Arma 3 (ArmaProfileIntegration.cs, ArmaGameData.cs) et le modèle d'axes engine\AxisModels\Arma2.cs (jeux Arma2 et Arma2OA).

  • Périphériques : class JoysticksList { class Joystick1 { guid="..."; name="..."; offset=256; isXInput=0; mode="Custom"; }; }. guid est le GUID d'instance DirectInput, en majuscules, sans accolades ; name le nom du produit. Un nouveau périphérique reçoit le plus grand offset + 256 ; les entrées restent, un périphérique garde donc son offset. Les noms de classe Joystick1..N sont renumérotés à chaque sauvegarde, JoyPro compare donc seulement par guid. mode vaut "Custom", "Scheme" (schéma de manette Xbox) ou "Disable". sensitivity[] (16 valeurs) n'apparaît qu'après validation de la fenêtre Customize du jeu ; JoyPro le crée après isXInput quand une valeur diffère de la valeur par défaut.
  • Codes : bouton 0x20000 + offset + b (b de 0 à 31) ; demi-axe 0x30000 + offset + a positif, + a + 8 négatif (X, Y, Z, RotX, RotY, RotZ, Slider 1, Slider 2) ; premier chapeau 0x40000 + offset + direction (huit directions). L'importation lit aussi les codes d'axe complet enregistrés ; l'exportation ne les écrit jamais.
  • Liste de commandes : engine arma2oa refresh-db lit CfgDefaultKeysMapping dans Expansion\dta\bin.pbo, et engine arma2 refresh-db dans Dta\bin.pbo, avec les noms de menu anglais de languagecore.pbo ; un profil ajoute ce que les mods définissent. Operation Arrowhead 68 actions, Arma 2 66 actions. engine arma2oa catalog, engine arma2oa paths, engine arma2 catalog, engine arma2 paths.
  • Importation / exportation : engine arma2oa import, engine arma2oa scan, engine arma2oa export ; engine arma2 import, engine arma2 scan, engine arma2 export (--mode clean|add|merge|merge-overwrite --nuke-untouched-devices --ignore-device <d> --dry-run).
  • Interrupteur de périphérique : engine ffb set --device "<name> {GUID}" --game Arma2|Arma2OA --param enabled=0|1 (engine ffb set).

#Limites connues

  • On ne sait pas encore quel sens du curseur le jeu appelle « plus sensible ».
  • Les combinaisons de joystick (un bouton avec un modificateur) n'existent pas dans Arma 2 ; JoyPro n'en écrit aucune.
  • Arma 2 seul n'a pas d'axe complet sur une action ; on ne sait pas encore comment se comporte son collectif d'hélicoptère sur une moitié du levier. Le sens de l'axe complet dans Operation Arrowhead reste aussi à confirmer après un vrai premier lancement.
  • Tests : engine\tests\smoke\arma.ps1 (sensibilité, portée de famille, interrupteur de périphérique) ; dans le jeu tools\e2e\games\Arma2Settings.ps1 -Game arma2oa|arma2 (profils de test JoyProE2E_OA / JoyProE2E_A2, menu principal > Options > Controls seulement).
