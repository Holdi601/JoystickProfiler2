X-Plane 12 / 11

Afficher :

X-Plane garde les attributions de tous vos périphériques dans un seul fichier de préférences dans son installation : un « usage » d'axe (tangage, gaz, volets ...) par axe matériel, une commande par bouton, et des courbes de réponse facultatives. JoyPro lit ce fichier dans votre profil, le relie à vos autres jeux dans des relations et le réécrit, en ne changeant que les lignes de vol qu'il gère. X-Plane 12 et X-Plane 11 sont deux jeux dans JoyPro, chacun avec sa propre installation, sa liste de commandes et ses réglages ; les deux peuvent être installés côte à côte.

Pour les débutants

#Le faire marcher en 3 étapes

  1. Tout configurer pour moi
    sur la page Accueil
  2. Utiliser ces boutons
    regardez d'abord la liste
  3. Écrire dans mon jeu
    gardez X-Plane fermé

Avant : lancez X-Plane une fois avec vos périphériques branchés, puis quittez.

Ensuite : calibrez vos périphériques dans X-Plane (Settings > Joystick). Vos attributions s'y affichent aussi.

Vous avez déjà assigné des boutons dans X-Plane ? Alors la page Accueil propose Importer, puis combler les vides. Vos assignations restent, et seuls les boutons libres reçoivent de nouvelles tâches. Voir Démarrage rapide : faire marcher mon manche.

#Ce que JoyPro fait pour X-Plane

  • Importer : les usages d'axe, les commandes de bouton, les indicateurs d'inversion et les courbes de réponse de vos périphériques arrivent dans votre profil.
  • Relations : une relation est une fonction dans tous vos jeux ("Gear" dans X-Plane, MSFS et DCS sur le même bouton). Les commandes de vol de X-Plane viennent de son propre Commands.txt.
  • Exporter : JoyPro écrit les préférences joystick de la version que vous exportez. X-Plane montre vos attributions dans Settings > Joystick.

#Importer vos attributions X-Plane

  1. Ouvrez Démarrer. La carte X-Plane 12 (ou X-Plane 11) montre l'image du jeu. Si elle demande une liste de commandes, appuyez sur Créer la liste : JoyPro lit Resources\plugins\Commands.txt du X-Plane installé.
  2. Appuyez sur Importer sur la carte et choisissez Ajouter à mon profil (X-Plane n'a pas d'assignations clavier dans ce fichier).
  3. Appuyez sur Importer maintenant. Voir mes relations ouvre ce qui est arrivé.

#Créer et vérifier les relations

Sur la page Relations, la commande ou l'axe X-Plane d'une relation se trouve à côté de la même fonction dans vos autres jeux. Utilisez le flux des relations pour les relier, puis appuyez sur Vérifier maintenant sur la page Exporter (la vérification).

#Exporter vers X-Plane

  1. Fermez X-Plane. Il réécrit ses préférences quand la fenêtre des réglages se ferme et quand il quitte. Les deux versions tournent sous le nom X-Plane.exe, JoyPro refuse donc tant que l'une d'elles tourne.
  2. Ouvrez Exporter. Chaque version installée a sa propre carte.
  3. Gardez Remplacer sur mes périphériques avec Effacer aussi mes autres périphériques si c'est dans JoyPro que vous configurez vos périphériques. Appuyez sur Exporter maintenant sur la carte.
Dans le jeu: Ce que vous voyez dans X-Plane

Lancez X-Plane et ouvrez Settings > Joystick, puis choisissez votre périphérique. Chaque axe montre l'usage écrit par JoyPro, les boutons montrent leurs commandes, et Edit Response Curve sur un axe montre les points et l'interpolation écrits par JoyPro.

#Ce que vous faites vous-même dans X-Plane

  • Lancez X-Plane une fois avec vos périphériques branchés, puis quittez-le. Une version jamais lancée n'a pas encore de fichier de préférences. Le tout premier lancement fait voler le tutoriel, et X-Plane écrit ses préférences joystick en quittant.
  • Calibrez dans X-Plane. La calibration et la zone neutre restent à X-Plane (Settings > Joystick) ; JoyPro ne les écrit jamais.
  • Les commandes des plugins et des appareils ne sont pas dans la liste de JoyPro : assignez-les dans X-Plane, JoyPro n'y touche pas.

#Pièges courants

  • Un axe ne fait rien ("Multiple axes assigned to yaw") : X-Plane ignore un usage partagé par deux axes branchés. L'exportation prévient ; Effacer aussi mes autres périphériques ou Remplacer efface l'autre axe.
  • La manette des gaz fonctionne à l'envers : X-Plane inverse lui-même les axes de manette des gaz. JoyPro écrit votre inversion sans la changer, laissez donc l'inversion désactivée sauf si votre levier va vraiment dans l'autre sens.
  • Une courbe que vous avez faite dans X-Plane a changé : dans les modes Mettre à jour et Ajouter seulement, elle reste si le réglage de JoyPro est linéaire (avec un avertissement) ; « Mon profil l'emporte » et Remplacer écrivent la courbe de JoyPro.

#Fichiers que JoyPro lit et écrit

Fichier De quoi il s'agit
<install>\Output\preferences\X-Plane Joystick Settings.prf les assignations actuelles de tous les périphériques (par ligne)
<install>\Output\preferences\control profiles\<Name> - Joysticks.prf profils de commandes enregistrés, même format
<file>.joypro.json, <file>.joypro-meta.json les entrées et courbes que JoyPro a écrites ; noms, groupes et réglages pour le prochain import
%LOCALAPPDATA%\x-plane_install_12.txt / _11.txt là où l'installateur de X-Plane liste ses installations (en lecture seule)

X-Plane Keys.prf (clavier) n'est jamais touché. Une version installée par Steam et jamais lancée est trouvée dans son dossier Steam. Un autre dossier se règle dans Paramètres > Jeux.

#Les modes d'exportation dans X-Plane

Mode Ce qui se passe dans X-Plane
Ajouter seulement Entrées libres uniquement. Une assignation sur une entrée qui a un autre usage ou une autre commande n'est pas écrite et est listée ; un usage d'axe que X-Plane a sur un autre axe y reste (avertissement).
Mettre à jour, garder les assignations du jeu Remplace l'autre usage ou l'autre commande sur votre entrée et garde tout le reste ; un usage d'axe se déplace (X-Plane ignore un usage partagé par deux axes).
Mettre à jour, mon profil l'emporte Libère aussi les autres axes et boutons des périphériques branchés qui portent un usage ou une commande que vous assignez, avec leurs courbes.
Remplacer sur mes périphériques Libère aussi tous les autres axes et commandes de vol sur les périphériques que vous écrivez.
+ Effacer aussi mes autres périphériques Les périphériques branchés que vous n'écrivez pas perdent leurs usages et commandes de vol.

#Ce qui n'est jamais touché

  • Les emplacements des périphériques non branchés, les périphériques ignorés de l'import et le périphérique vJoy vers lequel JoyPro redirige.
  • Les axes de vue, de caméra, de VR et de commandes personnalisées, les commandes de plugins et d'appareils, le clavier.
  • Les clés de calibrage (_joy_center, _joy_null, données de calibrage brutes), _eq_pfc_* et toutes les autres lignes.

#Courbes et réglages

  • Granularité : un seul fichier pour tous les appareils (X-Plane peut lier des appareils à des profils de commandes ; JoyPro écrit les fichiers qu'il trouve).
  • Courbes de réponse (modèle d'axe xplane) : un nombre quelconque de points avec LINEAR, CATMULL_ROM ou CUBIC_AVG, et les plages fixes des axes de gaz, d'hélice et de mélange (beta, feather, cutoff, FADEC ...). La Courbe par défaut devient des points ; une courbe inchangée garde ses octets. Le réglage peut se faire pour une version ou pour les deux (family:xplane).
  • Inversion : _joy_rev_axis, votre inversion inchangée (X-Plane inverse les manettes des gaz de lui-même).
  • Paramètres du jeu (Paramètres > Paramètres de retour de force des jeux) : réponse des commandes en tangage, roulis et lacet ; pour X-Plane 12 aussi les axes du copilote et les « control-loaded axes » pour les manches à retour de force ; pour X-Plane 11 l'augmentation de stabilité ; pour les deux les crans des volets. Seules les lignes que le fichier a déjà sont changées.
  • Retour de force : X-Plane n'en a pas en propre ; seulement l'interrupteur control-loaded.
  • Enregistrement de la télémétrie : à partir de la sortie de données UDP de X-Plane (port 49000), avec la position, une trace Tacview est donc possible.
  • Surveillance : les changements dans les préférences sont remarqués après la fermeture de X-Plane (la surveillance).
Détails techniques

#Dans l'intégration de X-Plane

Code : engine\Games\XPlaneIntegration.cs (une instance par version), engine\Games\XPlanePrf.cs, engine\AxisModels\XPlane.cs, engine\FfbModels\XPlane.cs, engine\Games\LegacyGameIds.cs (les profils d'avant la séparation en deux versions sont migrés au chargement).

  • Lignes : _joy_AXIS_use<i> (code d'usage), _joy_rev_axis<i>, _joy_BUTN_use<i> (chemin de commande, sim/none/none = libre), axis_response_curve<i>. Indices globaux : axe = emplacement × 25 + axe, bouton = emplacement × 160 + bouton.
  • Périphériques : emplacements _joy_unique_id<slot> VID:<dec>PID:<dec> ; avec des périphériques identiques, le chemin d'interface HID DirectInput doit être égal à _joy_location<slot>. Les boutons sont ceux du périphérique, puis le premier chapeau sous forme de 8 boutons dans le sens horaire à partir du haut ; les autres chapeaux ne sont pas pris en compte. Lit 160 boutons et 25 axes par périphérique.
  • Codes d'usage : 0 à 66 dans les deux versions ; X-Plane 12 ajoute la manette des gaz 9, le tangage/roulis/lacet/freins/roulette du copilote et les deux freins de roue. Les codes 74 à 77 et les axes de vue ne sont pas catalogués.
  • Liste de commandes : engine xplane12 refresh-db / engine xplane11 refresh-db : la table des axes de la version plus les groupes de commandes de vol de Commands.txt (sim/flight_controls, engines, autopilot, lights ... ; pas sim/view, operation, replay ...).
  • Import / exportation : engine xplane12 import, engine xplane12 scan, engine xplane12 export (--mode, --nuke-untouched-devices, --dry-run), de même pour engine xplane11 export. Sauvegarde en .jpbak d'abord.
  • Paramètres et courbes : engine ffb set --game XPlane12, engine binds tuning set --scope game:XPlane12 --curve-points 0:0,0.4:0.3,1:1, engine binds tuning preview (mesuré dans X-Plane 12.4.3 à 0.0001 près).

#Limites connues

  • La signification des codes d'usage 74 à 77 ; l'ordre des axes HID par rapport à DirectInput est déduit.
  • La Control Sensitivity de X-Plane sans courbe n'est pas dans l'aperçu.
  • X-Plane 11 n'est vérifié que par rapport à ses fichiers installés ; la vérification dans le menu du jeu reste à faire.
  • Tests : engine\tests\smoke\xplane.ps1 ; dans le jeu (X-Plane 12), les assignations et les courbes de réponse ont réussi 33 étapes sur 33 ; tools\e2e\games\XPlaneCurves.ps1 parcourt chaque axe et le compare à l'aperçu de JoyPro.
