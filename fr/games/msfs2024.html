Microsoft Flight Simulator 2024

Afficher :

MSFS 2024 garde vos commandes dans des profils, un par périphérique et par catégorie (Airplanes et General), et retient pour chaque périphérique et chaque appareil quel profil il utilise. JoyPro lit ces profils dans un seul profil à lui et réécrit vos assignations exactement dans les profils que la simulation utilise, dans la version Steam et la version Microsoft Store. Pour les appareils que la simulation n'a pas encore configurés pour un périphérique, JoyPro ajoute ses propres presets sous forme d'un petit paquet dans le dossier Community2024 de la simulation, et là où il ne peut pas écrire un profil, il vous laisse un fichier à importer dans le menu Controls de la simulation.

Pour les débutants

#Le faire marcher en 3 étapes

  1. Tout configurer pour moi
    sur la page Accueil
  2. Utiliser ces boutons
    regardez d'abord la liste
  3. Écrire dans mon jeu
    gardez la simulation fermée

Avant : branchez chaque périphérique une fois.

Ensuite : lisez l'encadré Vos profils MSFS 2024. Nomme-t-il un fichier d'importation ? Alors importez ce fichier dans la simulation (voir Ce que vous faites vous-même plus bas).

Vous avez déjà assigné des boutons dans MSFS 2024 ? Alors la page Accueil propose Importer, puis combler les vides. Vos assignations restent, et seuls les boutons libres reçoivent de nouveaux rôles. Voir Démarrage rapide : faire marcher mon manche.

#Ce que JoyPro fait pour MSFS 2024

  • Importer : les profils que vous avez créés dans le menu Controls de la simulation (Steam ou Microsoft Store) arrivent dans votre profil, assignations de vol et assignations General (caméras, vues, pause active, etc.), avec les réglages d'axe de la page Sensitivity. Un périphérique que vous n'avez jamais modifié dans la simulation apporte le preset que la simulation fournit pour lui, quand les propres données de la simulation montrent qu'il utilise ce preset.
  • Relations : une relation est une fonction. Dans MSFS 2024, une relation peut valoir pour tous les appareils (par défaut) ou seulement pour les appareils que vous cochez, comme dans DCS.
  • Exporter : JoyPro écrit vos assignations dans le profil que la simulation utilise pour chaque périphérique et chaque catégorie, écrit son paquet de presets pour les appareils que la simulation n'a pas encore configurés, et écrit un fichier d'importation là où il n'a pas pu mettre à jour votre profil.

#Importer vos assignations MSFS 2024

  1. Ouvrez Démarrer et appuyez sur Importer sur la carte Microsoft Flight Simulator 2024.
  2. Deux options comptent pour MSFS, toutes deux désactivées sauf si vous les cochez :
    • Importer aussi les périphériques non connectés : MSFS garde les assignations de tous les périphériques qu'il a jamais vus. Désactivé : seulement les périphériques branchés maintenant.
    • Importer aussi les préréglages par défaut que le simulateur n'utilise peut-être pas : pour les périphériques dont les données de la simulation ne montrent pas l'utilisation d'un preset fourni. Cela peut ajouter des assignations que la simulation n'a pas.
  3. Appuyez sur Importer maintenant (ou sur Voir d'abord pour voir ce que la simulation contient sans changer votre profil).

Les relations importées s'appliquent à tous les appareils. Quand une assignation n'existe que dans les profils de certains appareils, la page Relations affiche une note après l'importation avec Limiter à ces appareils pour chaque relation, Tout limiter et Garder pour tous les appareils.

#Créer et vérifier les relations

Sur la page Relations, une action MSFS 2024 montre les appareils de la simulation avec des coches : tous les appareils cochés signifie tous les appareils. Une action qui n'existe que dans certains appareils add-on indique « only for: » avec ces appareils, et l'ajouter ne coche qu'eux. Voir le parcours des relations, puis lancez la vérification sur la page Exporter : elle trouve un bouton avec deux fonctions avant que la simulation ne le fasse.

#Exporter vers MSFS 2024

  1. Fermez MSFS 2024. JoyPro refuse d'écrire pendant que la simulation tourne (dans la version Microsoft Store, aussi pendant que son programme d'aide au lancement tourne).
  2. Ouvrez Exporter. Sous Exporter vers les jeux, deux cases concernent MSFS 2024 :
    • MSFS 2024 : écrire dans mes profils MSFS (activé) : l'exportation met à jour le profil que la simulation utilise pour chaque périphérique et chaque catégorie, après une sauvegarde.
    • MSFS 2024 : fichiers d'importation pour chaque périphérique (désactivé) : un fichier d'importation pour chaque périphérique et chaque catégorie, pas seulement là où JoyPro n'a pas pu écrire votre profil.
  3. Gardez Remplacer sur mes périphériques avec Effacer aussi mes autres périphériques si c'est dans JoyPro que vous configurez vos périphériques, et appuyez sur Exporter maintenant sur la carte MSFS 2024.

Après l'exportation, l'encadré Vos profils MSFS 2024 liste chaque profil écrit par JoyPro, avec ses appareils et le nombre d'assignations. Quand des fichiers d'importation ont été écrits, un second encadré les nomme avec Ouvrir le dossier.

Dans le jeu: Ce que vous voyez dans MSFS 2024

Lancez la simulation et ouvrez Settings > Controls, puis choisissez votre périphérique et la catégorie (Airplanes ou General). Vos assignations sont dans votre propre profil, sous les noms d'actions de la simulation ; la page du périphérique (Hardware Settings sur la roue dentée du périphérique) montre les courbes d'axe écrites par JoyPro. Dans un appareil que la simulation n'a pas encore configuré pour ce périphérique, le périphérique démarre avec le preset de JoyPro.

#Ce que vous faites vous-même dans MSFS 2024

  • Rien, pour chaque profil listé comme mis à jour dans Vos profils MSFS 2024.
  • Fichiers d'importation : quand l'exportation en liste un, ouvrez Settings > Controls, choisissez le périphérique et la catégorie (Airplanes ou General), cliquez sur la roue dentée du profil (pas celle du preset), choisissez Import et sélectionnez le fichier que JoyPro a écrit pour ce périphérique et cette catégorie. La simulation n'accepte un fichier que pour le même périphérique et la même catégorie. Quand le fichier porte le nom de votre profil, la simulation demande s'il faut l'écraser : confirmez, et votre profil a les assignations de JoyPro. N'importez à nouveau un fichier que si l'exportation dit qu'il est nouveau ou modifié.
  • Branchez chaque périphérique une fois avant la première exportation : JoyPro a besoin de l'ID produit du périphérique pour son preset.
  • Un appareil a besoin d'autres assignations que les autres : donnez-lui son propre profil dans la simulation (Controls, avec cet appareil chargé : dupliquez le profil), puis exportez à nouveau. L'exportation nomme chaque relation qu'elle n'a pas pu placer.
  • Question du cloud Xbox : si la simulation ou l'application Xbox demande quelle sauvegarde garder, gardez celle de ce PC ; l'autre supprime les assignations de JoyPro (exportez alors à nouveau).

#Pièges courants

  • "MSFS 2024 est en cours d'exécution" : fermez la simulation ; dans la version Microsoft Store, le programme d'aide au lancement de la simulation (gamelaunchhelper.exe) doit aussi avoir disparu.
  • Des assignations manquent dans un appareil : cet appareil utilise un autre de vos profils. Vérifiez la liste Vos profils MSFS 2024 ; une ligne avec « fichier d'importation » signifie que vous devez importer ce fichier dans la simulation.
  • Une relation n'a pas été écrite : elle est limitée à certains appareils, mais le profil que la simulation utilise là est partagé avec d'autres appareils. L'avertissement nomme le profil et les appareils.
  • Un périphérique a plusieurs profils : l'importation prend celui que nomment les données de la simulation, sinon le plus récent, et nomme les autres. Choisissez-en un autre avec Profil du jeu dans le formulaire Autres jeux de la page Accueil.
  • "WRONG DEVICE" pendant une assignation dans la simulation : un périphérique qui envoie des valeurs en permanence (certains manches à retour de force) prend le balayage de la simulation. Cela arrive dans l'assignation propre à la simulation, pas dans JoyPro.
  • Reset to Defaults dans la simulation réinitialise les presets de tous les périphériques et appareils ; JoyPro ne le fait jamais à votre place.

#Fichiers que JoyPro lit et écrit

Avant chaque écriture, tout le dossier de sauvegarde Store ou le fichier Steam va dans le jeu de sauvegardes, donc Annuler la dernière exportation remet la sauvegarde en place.

#Les modes d'exportation dans MSFS 2024

Les modes travaillent par profil (donc par groupe d'appareils) et seulement dans les contextes gérés.

Mode Ce qui se passe dans vos profils MSFS 2024
Ajouter seulement Une assignation n'est écrite que là où aucune autre action de ce profil n'utilise la combinaison d'entrées ; sinon elle est listée comme non écrite. Rien n'est retiré.
Mettre à jour, garder les assignations du jeu L'autre action sur votre combinaison d'entrées la perd ; tout le reste reste, aussi l'ancienne combinaison d'une action (une action en a deux : Primary et Secondary).
Mettre à jour, mon profil l'emporte Comme ci-dessus, et chaque action que vous assignez perd ses autres combinaisons, aussi dans les profils des autres périphériques branchés (ces profils sont écrits aussi).
Remplacer sur mes périphériques Les profils des périphériques branchés que JoyPro écrit ne gardent que vos assignations.
+ Effacer aussi mes autres périphériques Ne vide jamais un de vos propres profils MSFS 2024.

Une relation pour tous les appareils va dans chaque profil que nomment les données de la simulation ; une relation limitée à des appareils ne va que dans les profils dont tous les appareils sont cochés. Les relations limitées ne vont jamais dans le paquet de presets ni dans les fichiers d'importation, car ceux-ci s'appliquent à tous les appareils.

#Ce qui n'est jamais touché

  • Les contextes de menu, de carte du monde et de développeur (MENU, MENU_*, WORLDMAP_*, DEBUG, DEVMODE*, EDITOR_*, MISSION_FLOW_TOOLS), dans tous les modes.
  • Les profils clavier, souris et manette (GUID="{0}") : les assignations clavier ne sont pas écrites dans MSFS.
  • profile_00, les presets qu'Asobo fournit, les emplacements de preset propres à un appareil, et chaque autre container de la sauvegarde Store (carnets de vol, autres titres).
  • Les périphériques non branchés, les périphériques ignorés de l'importation et le périphérique vJoy alimenté par JoyPro.

#Appareils, courbes, le reste

  • Granularité : par périphérique et par catégorie (Airplanes, General) et par profil ; la simulation choisit le profil par périphérique et par appareil, JoyPro suit ce choix.
  • Courbes d'axe : la page Sensitivity du périphérique, un jeu de valeurs par axe physique : Sensitivity + et -, Neutral, Dead zone, Extremity dead zone, Reactivity, l'indicateur sans courbe et l'inversion. Une relation peut donner à une action ses propres valeurs (le réglage propre par action de MSFS 2024). Les relations sur le même axe de périphérique partagent sa page : l'exportation écrit les valeurs de la première relation et prévient. Voir axis-curves.
  • Retour de force : MSFS n'en a pas lui-même.
  • Enregistrement de la télémétrie : par SimConnect, en lecture seule, avec votre propre SimConnect.dll (JoyPro n'en fournit pas) : la version Steam de MSFS 2024 n'en a pas, installez donc le SDK de MSFS 2024 ou gardez MSFS 2020 installé (sa copie marche aussi).
  • HUD : le HUD trouve la simulation par son processus et affiche ses assignations.
  • Surveillance : JoyPro surveille son paquet, les profils Steam et le containers.index de la sauvegarde Store ; après la fermeture de la simulation (la sauvegarde Store attend 10 s après sa dernière écriture), il demande s'il doit reprendre vos changements faits dans le jeu (la surveillance des jeux).
  • Réimportation : les noms, groupes et réglages des relations reviennent grâce aux métadonnées de JoyPro à côté des fichiers (réimportation).
  • Options pour experts (Autres jeux sur la page Accueil) : Profil du jeu (choisir un profil quand un périphérique en a plusieurs), Appareil à exporter (exporter aussi les relations limitées à un appareil, pour tous les appareils), Écrire dans mes profils MSFS, Écrire aussi des fichiers d'importation MSFS pour chaque périphérique, une simulation à blanc.
Détails techniques

#Dans l'intégration MSFS 2024

Code : engine\Games\MsfsIntegration.cs (une classe pour les deux simulations), MsfsIntegration.UserProfiles.cs (l'écriture directe), MsfsIntegration.ImportFiles.cs, MsfsCommunityPackage.cs, MsfsUserProfiles.cs (lecture Steam et Store), WgsContainers.cs (la sauvegarde Store), MsfsSimProfile.cs (les données dans profile_00), MsfsSimDefaults.cs, MsfsProfileFile.cs (l'éditeur ligne par ligne), MsfsGameData.cs, MsfsAircraft.cs, engine\AxisModels\Msfs.cs.

  • Format : un fragment XML (plusieurs éléments de premier niveau) : <Version>, <FriendlyName>, <Device DeviceName GUID ProductID CompositeID HWVer> avec <Axes> et <Context ContextName> / <Action ActionName Flag> / <Primary> / <Secondary> / <KEY Information>code</KEY>. Un profil 2024 liste chaque action de ses contextes, celles non assignées sous forme de <Action/> vide. Codes : bouton N = N-1, chapeau 256-259, axe L X/Y/Z 1026/1042/1058, axe R 770/786/802, curseurs 514/530. Indicateurs : 2 numérique, 4 axe, 128 inversion, 1024 sans courbe de sensibilité, 4096 réglage d'axe propre à l'action. Seuls les éléments <Action> modifiés sont générés de nouveau.
  • Périphériques : un profil nomme son périphérique par le GUID d'instance DirectInput (GUID), il n'est donc pas nécessaire qu'un périphérique soit branché pour le lire. Le simulateur associe un preset par l'ID produit USB (hex) : JoyPro utilise celui que le simulateur a noté dans profile_00, sinon le PID USB (vJoy apparaît avec l'ID produit 0).
  • Quel profil est actif : pour chaque périphérique et appareil, les enregistrements de profile_00 contiennent un emplacement General et un emplacement de catégorie ; un profil personnel y est inputprofile_<n>, qui est le nom de fichier Steam et le nom du conteneur Store.
  • Sauvegarde Store : écrite seulement quand l'index a la structure connue (version 14, pas d'indicateur de conflit, le conteneur listé une seule fois dans un état connu) ; alors un nouveau blob, container.<n+1>, l'index en dernier (fichier temporaire puis remplacement), relu, et l'ancienne génération supprimée. Tout échec remet tout en place ; tout élément inconnu n'écrit rien et le fichier d'importation porte les assignations.
  • Liste de commandes : engine msfs2024 refresh-db lit les presets d'Asobo, chaque événement de vol nommé par en-US.locPak, vos profils General et les paquets d'add-ons non compressés (Community, Marketplace) avec leurs appareils ; la liste des appareils vient de la liste de contenu du simulateur. Une installation neuve construit la liste au premier import.
  • Commandes : engine msfs2024 paths, engine msfs2024 catalog, engine msfs2024 scan, engine msfs2024 import (--game-profile, --include-disconnected, --include-sim-defaults, --limit-to-profile-aircraft, --replace), engine msfs2024 export (--mode, --nuke-untouched-devices, --dry-run, --aircraft <key> ; --user-profiles false et --import-files pour les deux cases de la page Exporter) ; relations par appareil avec engine relations aircraft set ; Annuler avec engine backups restore ; la surveillance avec engine sync status et engine sync diff. L'ancien nom CLI engine msfs ... désigne toujours MSFS 2024.

#Limites connues

  • Les emplacements de preset propres à un appareil ne sont pas écrits (ils ne viennent qu'avec le paquet de l'appareil) ; JoyPro n'écrit jamais profile_00 (le fichier se termine par une somme de contrôle).
  • Le preset de JoyPro n'atteint que les appareils que le simulateur n'a pas encore configurés pour un périphérique ; ailleurs, votre propre profil ou un fichier d'importation porte les assignations.
  • Au plus deux combinaisons d'entrées par action ; une troisième est signalée. Les demi-axes, les diagonales de chapeau et un deuxième chapeau ne sont ni lus ni écrits. Modificateurs : uniquement des boutons du même périphérique.
  • Les paquets d'add-ons compressés (.fsarchive) sont ignorés ; les chemins de sauvegarde Store de plus de 260 caractères ne sont pas lus.
  • Une copie cloud (Steam Cloud, cloud Xbox) peut l'emporter sur l'écriture de JoyPro quand un autre PC a enregistré plus tard.
  • Tests : engine\tests\smoke\msfs.ps1, smoke\msfsuserprofiles.ps1, gui\JoyPro.Gui.Tests\MsfsProfileImportTests.cs (sauvegardes Steam et Store, profils par appareil, retour arrière), MsfsStoreWatcherEndToEndTests ; dans le simulateur tools\e2e\games\Msfs2024Settings.ps1 (presets, axes, boutons et la courbe par action dans Controls).
