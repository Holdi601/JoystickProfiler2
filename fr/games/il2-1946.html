IL-2 Sturmovik: 1946

Afficher :

IL-2 Sturmovik: 1946 garde les commandes par pilote, dans un simple fichier ini dans le dossier du jeu, et la réponse des axes dans conf.ini. Il ne connaît les périphériques que par leur position dans l'ordre des périphériques de Windows. JoyPro lit les commandes du pilote actuel dans votre profil, vous laisse les relier à vos autres jeux dans des relations et les réécrit ligne par ligne, en laissant chaque autre octet des fichiers tel qu'il était.

Pour les débutants

#Le faire marcher en 3 étapes

  1. Tout configurer pour moi
    sur la page Accueil
  2. Utiliser ces boutons
    regardez d'abord la liste
  3. Écrire dans mon jeu
    gardez le jeu fermé

Avant : branchez vos périphériques dans leur ordre habituel. Fermez le jeu.

Ensuite : vos assignations sont dans Main Menu > Controls, pour le pilote actuel.

Vous avez déjà assigné des boutons dans IL-2 1946 ? Alors la page Accueil propose Importer, puis combler les vides. Vos assignations restent, et seuls les boutons libres reçoivent de nouveaux rôles. Voir Démarrage rapide : faire marcher mon manche.

#Regarder autour sans suivi de la tête

Pas de TrackIR, pas de VR ? La configuration met les vues rapides sur un chapeau de votre manche : avant, arrière, gauche et droite. Voir Suivi de la tête et regarder autour.

#Ce que JoyPro fait pour IL-2 1946

  • Importer : les assignations du pilote actuel sur vos manches, manettes des gaz et palonniers arrivent dans votre profil, avec la zone morte et la courbe de chaque axe. Les touches clavier arrivent quand vous les demandez.
  • Relations : une relation est une fonction dans tous vos jeux ("Gear" dans 1946, Great Battles et DCS).
  • Exporter : JoyPro écrit le settings.ini du pilote et les lignes d'axe de conf.ini. Le jeu affiche vos assignations sur sa page Controls.

#Importer vos assignations IL-2 1946

  1. Ouvrez Démarrer. La carte IL-2 Sturmovik: 1946 affiche l'image du jeu. Si elle demande une liste de commandes, appuyez sur Créer la liste : JoyPro combine sa propre liste de commandes avec les commandes que nomment vos fichiers.
  2. Appuyez sur Importer sur la carte. Choisissez Ajouter à mon profil et cochez Prendre aussi les touches du clavier si vous voulez aussi vos touches de vol.
  3. Appuyez sur Importer maintenant. Voir mes relations ouvre ce qui est arrivé.

#Créer et vérifier les relations

Sur la page Relations, la commande 1946 d'une relation se trouve à côté de la même fonction dans vos autres jeux. Utilisez le parcours des relations pour les réunir, puis appuyez sur Vérifier maintenant sur la page Exporter (la vérification).

#Exporter vers IL-2 1946

  1. Fermez le jeu. JoyPro refuse d'écrire tant que il2fb.exe tourne ; le jeu réécrit settings.ini à chaque Apply et conf.ini en quittant.
  2. Ouvrez Exporter. La carte IL-2 Sturmovik: 1946 montre combien de ses relations sont assignées.
  3. Gardez Remplacer sur mes périphériques avec Effacer aussi mes autres périphériques si c'est dans JoyPro que vous configurez vos manches. Appuyez sur Exporter maintenant sur la carte.
Dans le jeu: Ce que vous voyez dans IL-2 1946

Lancez le jeu et ouvrez Main Menu > Controls. Vos assignations s'affichent dans les lignes de commandes, par exemple JoyButton 7 ID4 (bouton 7 du quatrième périphérique), Hat Switch -135 ID14 ou U Slider axis ID4 en fin de liste. Controls > Input montre la zone morte et les curseurs de courbe écrits par JoyPro pour chaque axe assigné.

#Ce que vous faites vous-même dans IL-2 1946

  • Gardez vos périphériques dans le même ordre. Le jeu enregistre « périphérique 0, 1, 2, 3 » dans l'ordre de Windows, pas des noms. Si vous branchez les périphériques dans un autre ordre, exportez à nouveau.
  • Steam Cloud synchronise le dossier Users quand le jeu se ferme. Un fichier modifié par JoyPro pendant que le jeu est fermé est envoyé au lancement suivant.
  • Volez avec le pilote vers lequel vous avez exporté. JoyPro prend d'abord le fichier du pilote actuel (Users\all.ini indique lequel) ; pour un autre pilote, indiquez le settings.ini de ce pilote sous Options et chemins (pour experts) sur la page Exporter.

#Pièges courants

  • Un périphérique est refusé : le jeu ne lit que les quatre premiers contrôleurs de jeu. Un périphérique en cinquième position ou au-delà ne peut pas être écrit.
  • Une assignation avec modificateur manque : le jeu ignore une touche maintenue pendant qu'on appuie sur un bouton de joystick, donc JoyPro ignore les assignations joystick avec modificateurs (avec un avertissement). Les touches peuvent avoir un modificateur.
  • Des assignations sur le mauvais manche : l'ordre des périphériques a changé. Exportez à nouveau.
Avancé

#Fichiers que JoyPro lit et écrit

Fichier De quoi il s'agit
<install>\Users\<pilot>\settings.ini les assignations d'un pilote, sections [HotKey move] (axes), pilot, gunner, misc, aircraftView, orders ...
<install>\Users\all.ini la liste des pilotes et le pilote actuel (lecture seule)
<install>\Users\default.ini le modèle pour les nouveaux pilotes (lu seulement pour la liste de commandes)
<install>\conf.ini la réponse des axes, sections [rts_joystick] / [rts_joystick<k>]
settings.ini.joypro.json les entrées que JoyPro a écrites

<install> est steamapps\common\IL 2 Sturmovik 1946 pour Steam. JoyPro modifie les lignes sur place.

#Les modes d'exportation dans IL-2 1946

Mode Ce qui se passe dans le jeu
Ajouter seulement Rien n'est retiré. Une assignation sur une entrée que le jeu utilise pour une autre commande n'est pas écrite et est listée.
Mettre à jour, garder les assignations du jeu Vos assignations entrent ; une assignation du jeu sur une entrée que vous donnez à une autre commande est retirée, le reste reste (le jeu garde deux entrées par commande).
Mettre à jour, mon profil l'emporte Comme ci-dessus, et chaque commande que vous assignez perd ses autres entrées (le clavier seulement avec l'option clavier).
Remplacer sur mes périphériques Les périphériques que vous écrivez perdent toutes leurs autres lignes dans les sections gérées.
+ Effacer aussi mes autres périphériques Les autres périphériques branchés perdent leurs lignes.

#Ce qui n'est jamais touché

  • Les lignes d'un périphérique non branché, les lignes que l'importation ne sait pas lire, les lignes souris (MouseAXE_X, MouseLeft) et les lignes clavier (le clavier seulement avec l'option clavier).
  • Les fichiers des autres pilotes, sauf si vous y exportez, et chaque autre ligne de conf.ini.

#Courbes et réglages

  • Granularité : par pilote. Tous les appareils d'un pilote partagent les assignations ; la réponse des axes est par axe de périphérique.
  • Réponse de l'axe (modèle d'axes il21946) : bande morte (0 à 50), dix points de courbe de 10 % à 100 % du manche (pourcentage de la sortie linéaire), le filtre et l'indicateur d'axe à un seul côté. La Courbe par défaut est adaptée : zone morte vers bande morte, la forme vers les dix points (plafonnée au linéaire, donc une courbe au-dessus du linéaire ne peut pas être exprimée), un curseur vers un seul côté. En mode Mettre à jour, une courbe réglée dans le jeu reste quand celle de JoyPro est la simple valeur par défaut.
  • Inverser : un - devant la commande. Une seule commande par axe de périphérique reçoit une ligne de réponse (une deuxième reçoit un avertissement).
  • Pas de retour de force ni de réglages du jeu. La surveillance remarque les changements après la fermeture du jeu.
Détails techniques

#Dans l'intégration 1946

Code : engine\Games\Il21946Integration.cs, engine\Games\Il2LegacyIntegration.cs, engine\Games\Il2LegacyInput.cs, engine\Games\LegacyIniFile.cs.

  • Lignes : <trigger>[ <trigger>]=<command>. Axe AXE_<X|Y|Z|RX|RY|RZ|U|V> JoystickDevice<d>, bouton Joystick<b> JoystickDevice<d> (b à partir de 0), chapeau Pov<angle> JoystickPov<d*4+h>, touche [<modifier> ]<key>. Les nouvelles lignes sont écrites entrée d'abord, comme le fait le jeu.
  • Périphériques : par index seulement. JoystickDevice<d> est le d-ième contrôleur de jeu dans l'ordre DirectInput ; JoyPro le fait correspondre au périphérique branché qui a cet index. Jusqu'à 4 périphériques (JoystickDevice0..3), 8 axes et 4 chapeaux chacun.
  • Lignes d'axe : 1<axis>[<device>]= 13 entiers : bande morte, dix points de courbe, filtre, un seul côté (0 centré, 1 un seul côté, 2 un seul côté inversé). [rts] JoyProfile=k choisit la section.
  • Liste de commandes : engine il21946 refresh-db : la liste de commandes propre à JoyPro plus chaque commande que nomment Users\default.ini, conf.ini et les settings.ini des pilotes. Les identifiants sont <section>.<command> (pilot.Gear, move.power4).
  • Importation / exportation : engine il21946 paths (pilote actuel d'abord), engine il21946 import, engine il21946 scan, engine il21946 export. Sauvegarde des deux fichiers avant la première écriture.

#Limites connues

  • Les noms de touches avec une langue de jeu autre que l'anglais ne sont pas encore confirmés.
  • La limite de boutons par périphérique : les fichiers en permettent 128, les joueurs en signalent 32.
  • Tests : engine\tests\smoke\il21946.ps1 ; dans le jeu tools\e2e\games\IL21946.ps1 (assignations sur la page Controls, réponses sur la page Input, la réécriture du jeu et son importation ; 29 étapes sur 33, un passage entièrement vert reste à faire).
