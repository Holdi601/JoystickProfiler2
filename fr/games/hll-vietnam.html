Hell Let Loose: Vietnam

Afficher :

Hell Let Loose: Vietnam est un jeu de tir d'infanterie sous Unreal Engine 5 avec des hélicoptères pilotables, mais il ne lit aucun joystick : seulement le clavier, la souris et les manettes Xbox. Ses dispositions de manette sont fixes (vous choisissez A, B ou C dans le jeu). JoyPro le pilote donc par une fausse manette (une manette Xbox virtuelle) : votre manche, votre manette des gaz et votre palonnier pilotent les commandes de manette que votre disposition utilise pour chaque action d'hélicoptère. JoyPro n'écrit rien pour la manette. Il n'écrit que les touches clavier du pilote, quand vous les demandez.

Pour les débutants

#Le faire marcher en 3 étapes

  1. Assignez l'hélicoptère
    sur la page Relations
  2. Installer ViGEmBus
    puis Tester
  3. Lancez le jeu
    à son écran titre : Alt+Tab, Démarrer

#À configurer une seule fois

  1. Ouvrez Démarrer. Si la carte Hell Let Loose: Vietnam demande une liste de commandes, appuyez sur Créer la liste. JoyPro écrit son propre tableau des trois dispositions de manette et des touches du pilote.
  2. Ouvrez Relations. Mettez votre manche, votre manette des gaz et votre palonnier sur les actions de manette de l'hélicoptère : collectif, cyclique, lacet. Pour le collectif, mettez un axe de la manette des gaz à la fois sur Collective up et Collective down. JoyPro le partage au centre sur les deux gâchettes.
  3. Ouvrez la page Joystick virtuel. La fausse manette a besoin d'un programme d'aide gratuit appelé ViGEmBus. Cochez la case sous sa licence. Puis appuyez sur Installer ViGEmBus. Windows demande l'autorisation : cliquez sur Oui. Vous ne le faites qu'une fois.
  4. Appuyez sur Tester. Bougez votre manche. L'image de la manette bouge avec lui.

Vous n'avez rien à changer. Le jeu utilise la fausse manette tout seul. La page indique « Sur la manette Xbox d'office : le jeu ne lit que les manettes Xbox ». Ce jeu n'a pas besoin de HidHide : il ne voit de toute façon jamais vos vrais manches.

La configuration rapide ne connaît que les touches du pilote

Tout configurer pour moi ne connaît pour l'instant que les touches clavier du pilote du jeu, pas ses actions de manette. Assignez donc vous-même les actions de manette, comme à l'étape 2. La réponse de l'écran de bienvenue Jouer à ACE COMBAT avec mon manche montre les mêmes étapes de fausse manette sous forme de visite.

#À chaque partie

  1. Lancez Hell Let Loose: Vietnam. Attendez qu'il affiche son écran titre.
  2. Maintenez Alt et appuyez sur Tab. Vous êtes de retour dans JoyPro.
  3. Appuyez sur Démarrer.
  4. Appuyez à nouveau sur Alt+Tab. Vous êtes de retour dans le jeu. Bon vol !
  5. Quand vous avez fini, appuyez sur Arrêter.
Démarrer vient après le jeu

N'appuyez sur Démarrer que lorsque le jeu affiche son écran titre. Trop tôt ? JoyPro affiche « Trop tôt ». Appuyez sur Arrêter, puis sur Démarrer. Faites-le à chaque partie.

#Ce que JoyPro fait pour Hell Let Loose: Vietnam

  • L'hélicoptère sur la fausse manette : JoyPro connaît les actions d'hélicoptère des trois dispositions de manette (collectif, cyclique, lacet, maintien de stabilité, mise à niveau auto, largage de ravitaillement, fusée de reconnaissance, regard, siège, médecin). Assignez-y votre HOTAS, et la fausse manette bouge le stick, la gâchette ou le bouton que le jeu attend.
  • Touches clavier du pilote : sur demande, JoyPro lit et écrit les touches clavier des actions du pilote du jeu.
  • Hell Let Loose (l'original) n'a rien à piloter, et Squad lit un seul périphérique fusionné : les deux sont seulement documentés (voir Avancé).

#Importer vos touches du pilote

Il n'y a pas d'assignations joystick à importer dans le jeu. Seules les touches clavier du pilote arrivent :

  1. Appuyez sur Importer sur la carte Hell Let Loose: Vietnam.
  2. Cochez Prendre aussi les touches du clavier.
  3. Appuyez sur Importer maintenant.

#Créer et vérifier les relations

Le parcours des relations marche comme pour tous les jeux. Une relation peut contenir l'action d'hélicoptère de ce jeu et la même fonction de vos simulateurs de vol. "Collective" est alors partout un seul levier des gaz.

#Exporter

La fausse manette n'a pas besoin d'exportation : Démarrer sur la page Joystick virtuel crée son tableau à partir de vos relations. Une exportation n'écrit que les touches clavier du pilote, et seulement si vous avez coché le clavier à l'importation (le choix est gardé par jeu) : fermez le jeu, ouvrez Exporter, appuyez sur Exporter maintenant sur sa carte.

Dans le jeu: Ce que vous voyez dans Hell Let Loose: Vietnam

Le jeu voit une manette Xbox : ses menus affichent les boutons de la manette (par exemple "B EXIT" dans le menu principal). Votre manche, votre manette des gaz et votre palonnier pilotent l'hélicoptère comme le ferait la manette avec la disposition que vous avez choisie. Les touches clavier du pilote écrites par JoyPro apparaissent dans les réglages de touches du jeu.

#Ce que vous faites vous-même dans Hell Let Loose: Vietnam

  • Appuyez sur Démarrer à l'écran titre, à chaque partie (voir plus haut).
  • Choisissez la disposition de manette (A, B ou C) dans Options > Controls. Après un changement, appuyez sur Mettre à jour le mappage sur la page Joystick virtuel (ou sur Arrêter et Démarrer). JoyPro suit alors la nouvelle disposition.
  • Les boutons de manette du jeu ne peuvent pas être réassignés, donc la disposition décide quelle commande de manette a chaque action. JoyPro la suit. Il n'y a rien à régler dans le jeu pour la manette.

#Pièges courants

  • Le jeu ne réagit pas : avez-vous appuyé trop tôt sur Démarrer ? Appuyez sur Arrêter, puis sur Démarrer à l'écran titre.
  • Pas de ViGEmBus : sans lui, le jeu ne peut pas voir votre manche. Installez-le sur la page Joystick virtuel.
  • Le lacet et le regard bougent ensemble dans les dispositions A et B : le jeu met le lacet et le regard gauche / droite sur le même axe de stick et décide selon le contexte. JoyPro y fixe un axe physique et avertit pour le second.
  • Le collectif va dans le mauvais sens : cochez Invert sur la relation du collectif. Cela échange les deux gâchettes.
  • Une touche du pilote n'a pas été écrite : les touches clavier ne sont écrites qu'avec le choix clavier de l'importation.

Avancé

#Comment fonctionne la fausse manette

  • Pas de HidHide. Le jeu ne lit que les manettes Xbox, il ne voit donc jamais vos vrais manches. Rien ne doit être masqué, et Windows ne demande aucun droit d'administrateur. HidHide ne sert qu'aux jeux réglés sur vJoy.
  • Le mode se règle tout seul. Tant que vous n'avez pas choisi de mode, le jeu utilise la manette Xbox. Choisissez un autre mode sur la page Joystick virtuel, et JoyPro garde votre choix.
  • Votre courbe arrive jusqu'à la manette. Le jeu ne reçoit pas d'exportation, JoyPro applique donc lui-même la zone morte, la saturation, la courbe et l'inversion de Réponse de l'axe (page Assignations) au stick ou à la gâchette de la manette. Cochez seulement ce jeu sous S'applique à pour une courbe à lui. Sinon c'est la Courbe par défaut qui compte.
  • Le démarrage automatique crée la manette dans les 3 secondes environ après le lancement du jeu, avant son écran titre. Dans les tests de JoyPro, une manette créée avant l'écran titre n'a jamais atteint ce jeu. Appuyez alors sur Arrêter et Démarrer à l'écran titre.
  • Plusieurs jeux sur la manette : chaque jeu garde sa propre table. Avec le démarrage automatique, la table du jeu lancé devient active. Sinon, choisissez-la sous Table de la manette Xbox pour « Démarrer » et « Tester ».
  • Experts : vJoy, HidHide, la fréquence de transfert et les modes sont sous Afficher les détails pour experts (vJoy, HidHide, modes).

#Les modes d'exportation (touches de pilote au clavier)

Une touche par action de pilote. Un bouton de souris sur une action de pilote reste toujours ; les touches d'infanterie et communes ne changent jamais.

Mode Ce qui se passe
Ajouter seulement La touche du jeu reste ; une touche qu'a une autre action de pilote est ignorée et marquée « Non écrit dans le jeu ».
Mettre à jour, garder les assignations du jeu / Mettre à jour, mon profil l'emporte La touche du profil est posée ; une autre action de pilote sur cette touche la perd (le jeu y utilise alors son réglage par défaut).
Remplacer sur mes périphériques Les autres touches de pilote que vous avez changées dans le jeu reviennent aux réglages par défaut du jeu.
+ Effacer aussi mes autres périphériques Rien à vider : le jeu n'enregistre pas d'assignations joystick.

#Ce qui n'est jamais touché

  • Les dispositions de manette du jeu : elles sont fixes et JoyPro n'écrit aucune assignation de manette.
  • Les touches d'infanterie et de véhicule, les boutons de souris, chaque autre octet du fichier de sauvegarde.
  • HidHide : la fausse manette n'en a pas besoin pour ce jeu.

#Manette, courbes, autres réglages

  • Inverser sur une relation d'axe inverse cet axe de la manette dans le transfert de JoyPro. JoyPro applique aussi votre courbe d'axe à la manette (voir plus haut) ; les réglages de manette propres au jeu s'appliquent après.
  • Une action sans touche de manette dans la disposition reçoit la prochaine commande de manette libre ; ce qui ne tient pas est listé sur la page Joystick virtuel. Les fonctions virtuelles marchent aussi sur la manette.
  • Paramètres > Jeux : Hell Let Loose: Vietnam : utiliser la bibliothèque Oodle d'un autre jeu installé : les fichiers du jeu sont compressés et il ne fournit pas de bibliothèque pour les lire. Avec votre accord, JoyPro en utilise une qu'un autre jeu de ce PC possède, là où elle se trouve (jamais copiée), pour construire la liste à partir des fichiers propres au jeu. Désactivé : la table propre à JoyPro, qui suffit pour le mode manette. Redemander oublie votre réponse.
  • Surveillance : le fichier de sauvegarde du clavier est surveillé après la fermeture du jeu (la surveillance des jeux).
  • HUD : pendant que le jeu tourne, le HUD nomme l'action de chaque bouton appuyé.

Détails techniques

#Dans l'intégration Hell Let Loose: Vietnam

Code : engine\Games\HllVietnamIntegration.cs, engine\Games\GvasKeyMappings.cs ; le planificateur et le transfert de manette de virtual-joystick.

  • Entrée : l'exécutable du jeu n'a pas de code DirectInput, raw input ni GameInput, seulement clavier, souris et XInput. Il se déclare jeu à un seul périphérique (0 joystick, mode suggéré xbox).
  • Liste de commandes : DB\HLLVietnam\actions.tsv, deux sortes de lignes : les actions d'hélicoptère Pad_* avec la touche par défaut de chaque disposition dans la 5e colonne (A:Gamepad_LeftY|B:Gamepad_RightY|C:Gamepad_LeftY), et les touches de pilote au clavier Driver_*. engine hllv refresh-db écrit la table propre à JoyPro, ou lit les ressources d'entrée du jeu quand une bibliothèque Oodle peut être utilisée (celle du jeu d'abord, celle d'un autre jeu seulement après votre accord : --oodle-dll <path>, chargée là où elle se trouve, seulement dans le processus d'actualisation). engine hllv oodle nomme la bibliothèque qu'il utiliserait.
  • Plan de la manette : le planificateur lit la disposition dans GameUserSettings.ini, fixe chaque action à sa touche dans cette disposition (Gamepad_LeftY vers XB_LY, Gamepad_FaceButton_Right vers XB_B ...) ; une relation sur les deux actions du collectif devient XB_TRIGGERS ; Inverser ajoute ~ (avec une courbe, c'est la courbe qui le porte). Le jeu déclare MaxJoysticks 0 et le mode suggéré xbox, donc sans choix enregistré son mode est xbox ; engine vjoy mode HLLVietnam xbox en enregistre un. engine vjoy map. Pas d'étape HidHide : engine vjoy apply-hidhide dit "HidHide is not needed" pour de tels jeux.
  • Tables de configuration : DB\Functions\HLLVietnam.tsv ne liste pour l'instant que les actions de pilote au clavier Driver_*, donc l'assistant de configuration et la configuration rapide ne placent pas les actions Pad_*.
  • Fichier du clavier : GVAS Unreal avec la fin Enhanced Input (profils, correspondances avec nom, touche, classe de matériel et emplacement). JoyPro ne réécrit que les correspondances <Action>_Keyboard des actions de pilote ; les noms de touches sont convertis en noms de touches Unreal (Space vers SpaceBar, D1 vers One).
  • Commandes : engine hllv paths, engine hllv catalog, engine hllv scan, engine hllv import, engine hllv export --include-keyboard --mode clean|add|merge|merge-overwrite --dry-run.

#Limites connues

  • Un vol avec la manette virtuelle n'est pas encore confirmé (collectif sur les gâchettes, cyclique, lacet, Stability hold, Supply drop) ; les menus ont été vérifiés.
  • Le lacet et la vue partagent un axe de stick dans les dispositions A et B.
  • Tests : engine\tests\smoke\hllv.ps1 (aucune bibliothèque chargée sans votre accord, la table de secours, la bibliothèque propre au jeu d'abord) ; dans le jeu tools\e2e\games\HllVietnamXbox.ps1 (menus avec la manette virtuelle ; vJoy et HidHide inchangés ensuite).
