G-Rebels

Afficher :

G-Rebels est un jeu de combat aérien cyberpunk sous Unreal Engine 5 : vous pilotez un VTOL au-dessus de mégapoles. Le jeu met chaque joystick que vous activez sur un canal (0 à 5) et garde le rôle de chaque axe (tangage, roulis, lacet, poussée, déplacement latéral, haut / bas) et les assignations de boutons par canal dans deux fichiers de sauvegarde. JoyPro lit ces rôles et assignations dans votre profil et les réécrit ; le clavier, la manette et la souris restent comme le jeu les a.

Pour les débutants

#Le faire marcher en 3 étapes

  1. Tout configurer pour moi
    sur la page Accueil
  2. Utiliser ces boutons
    regardez d'abord la liste
  3. Écrire dans mon jeu
    gardez G-Rebels fermé

Avant, une fois par périphérique dans le jeu : donnez-lui un canal sous OPTIONS > INPUT > DEVICES. Changez un rôle d'axe sur son onglet JST. Assignez un bouton. (Détails ci-dessous.)

Ensuite : vos assignations s'affichent sur l'onglet JST du périphérique.

Vous avez déjà assigné des boutons dans G-Rebels ? Alors la page Accueil propose Importer, puis combler les vides. Vos assignations restent, et seuls les boutons libres reçoivent de nouveaux rôles. Voir Démarrage rapide : faire marcher mon manche.

#Ce que JoyPro fait pour G-Rebels

  • Importer : les rôles des axes de chaque canal (quel axe du manche est le tangage, le roulis, le lacet, la poussée, le déplacement latéral, haut / bas), avec l'inversion, et les assignations de boutons que JoyPro connaît, arrivent dans votre profil sur vos vrais périphériques.
  • Relations : "Pitch" dans G-Rebels peut être la même relation que le tangage dans vos autres jeux.
  • Exporter : JoyPro règle les rôles des axes et les assignations de boutons sur les canaux de vos périphériques. Il n'ajoute jamais de canal ni de périphérique : cette partie, vous la faites une fois dans le jeu.

#Importer vos assignations G-Rebels

  1. Ouvrez Démarrer. Si la carte G-Rebels demande une liste de commandes, appuyez sur Créer la liste : JoyPro écrit son propre tableau des rôles d'axe et des boutons du jeu.
  2. Appuyez sur Importer sur la carte G-Rebels, gardez Ajouter à mon profil (recommandé) et appuyez sur Importer maintenant.
  3. Voir mes relations ouvre ce qui est arrivé.

#Créer et vérifier les relations

Assignez vos relations aux actions de G-Rebels sur la page Relations (voir le parcours des relations), puis lancez Vérifier sur la page Exporter. G-Rebels permet un rôle par axe et un bouton par action et par canal ; la vérification montre où deux relations veulent la même entrée.

#Exporter vers G-Rebels

  1. Fermez G-Rebels. JoyPro refuse d'écrire pendant que le jeu tourne.
  2. Ouvrez Exporter et cochez la carte G-Rebels.
  3. Gardez Remplacer sur mes périphériques avec Effacer aussi mes autres périphériques si c'est dans JoyPro que vous configurez vos manches. Appuyez sur Exporter maintenant sur la carte.
Dans le jeu: Ce que vous voyez dans G-Rebels

Ouvrez OPTIONS > INPUT > CONTROLS et l'onglet JST<channel> de votre périphérique (JST0 pour le canal 0). Sous AXIS, chaque axe du joystick (X, Y, Z, RX, RY, RZ, Slider, Dial) affiche le rôle réglé par JoyPro (YAW, THRUST, ROLL, PITCH, SIDE STRAFE, UP / DOWN ou NONE). Sous BUTTONS, l'action assignée affiche votre bouton, par exemple "Enhanced Raw Input Controller 0 Button 5".

#Ce que vous faites vous-même dans G-Rebels

Faites ceci une fois par périphérique, avant la première exportation :

  1. Activez le périphérique : OPTIONS > INPUT > DEVICES liste chaque joystick avec DEACTIVATED. Donnez un canal à chaque périphérique que vous voulez (0 - CHANNEL ... 5 - CHANNEL). Un périphérique sans canal est ignoré par l'exportation avec « activez-le dans OPTIONS > INPUT > DEVICES ».
  2. Changez un rôle d'axe sur l'onglet JST du périphérique. Ce n'est qu'alors que le jeu enregistre les lignes d'axe de ce canal ; JoyPro les modifie sur place et ne les ajoute jamais. Ouvrir l'onglet seul n'enregistre rien.
  3. Assignez un bouton une fois dans le jeu. Le fichier des boutons apparaît avec la première assignation.

#Pièges courants

  • Un rôle d'axe n'est pas écrit : le canal n'a pas encore de lignes d'axe enregistrées. Changez un rôle d'axe sur son onglet JST dans le jeu, fermez le jeu, exportez à nouveau.
  • Une assignation de bouton manque : seul Primary Fire parmi les boutons du jeu est confirmé pour l'instant ; les autres actions suivront quand leurs noms seront connus.
  • Plusieurs périphériques raw input partagent des touches : mettez tout le HOTAS sur un seul périphérique avec le Joystick virtuel ; il n'a alors besoin que d'un canal.
Avancé

#Fichiers que JoyPro lit et écrit

Fichier De quoi il s'agit
%LOCALAPPDATA%\G_Rebels\Saved\SaveGames\SaveOptions.sav les périphériques avec leurs canaux (par chemin HID) et une ligne d'axe par axe de chaque canal : rôle, inversion, zone morte, multiplicateur
%LOCALAPPDATA%\G_Rebels\Saved\SaveGames\EnhancedInputUserSettings.sav les assignations de boutons, une correspondance par action et par canal
...\SaveOptions.sav.joypro-meta.json Les données de JoyPro sur les assignations exportées (noms, groupes), relues par la prochaine importation

Les deux fichiers de sauvegarde du jeu sont sauvegardés avant la première écriture (.jpbak à côté et le stockage de sauvegardes de JoyPro).

#Les modes d'exportation dans G-Rebels

Un rôle par axe et une touche par action et par canal. Les mêmes règles valent pour les rôles d'axe et les boutons.

Mode Ce qui se passe
Ajouter seulement Un rôle ne va que sur un axe qui n'en a pas ; un axe avec un autre rôle est ignoré et marqué « Non écrit dans le jeu ».
Mettre à jour, garder les assignations du jeu Le rôle du profil va sur son axe (le rôle qui s'y trouvait part) ; le rôle reste sur ses autres axes. Un bouton : la correspondance d'une autre action sur la touche part.
Mettre à jour, mon profil l'emporte Comme ci-dessus, et les autres axes du rôle sur les canaux branchés reçoivent NONE.
Remplacer sur mes périphériques Chaque autre rôle d'un canal écrit devient NONE.
+ Effacer aussi mes autres périphériques Pareil sur les canaux activés et branchés que JoyPro n'écrit pas.

#Ce qui n'est jamais touché

  • Le clavier, la manette, la souris et les autres options du jeu.
  • Un canal dont le périphérique n'est pas branché garde ses rôles.
  • Les périphériques ignorés de l'importation et le périphérique vJoy alimenté par JoyPro.
  • La liste des périphériques du jeu : JoyPro n'active ni ne désactive jamais un périphérique et n'ajoute jamais de canal.

#Axes et autres réglages

  • Global : un seul jeu d'assignations par canal, pas de profils par appareil.
  • Inverser est écrit avec le rôle. Les chapeaux (les lignes POV), la zone morte et la sensibilité ne sont pas encore écrits.
  • Pas de réglages globaux du jeu, pas de retour de force.
  • Surveillance : un rôle ou une assignation que vous changez dans le jeu est remarqué après sa fermeture (la surveillance des jeux).
  • HUD : pendant que G-Rebels tourne, le HUD nomme l'action de chaque bouton appuyé.
  • Le jeu lit jusqu'à 96 boutons et 24 axes par périphérique, pas de chapeaux.
Détails techniques

#Dans l'intégration G-Rebels

Code : engine\Games\GRebelsIntegration.cs, engine\Games\GRebelsSaveOptions.cs, engine\Games\GvasKeyMappings.cs.

  • SaveOptions.sav : GVAS Unreal (UE 5.8, balises de propriété avec arbres de types). Joysticks contient S_Controller_Save { DeviceID (HID path), Enabled, MultiID (channel) } ; AxisOptions contient S_Input_Axis_Save { Key, Offset, Multiplier, Role, Inverted, DeadZone } avec des clés comme RawInput_Controller0_AxisY et le rôle sous forme d'enum (0 Yaw, 1 Thrust, 2 Roll, 3 Pitch, 4 Side strafe, 5 Up/down, 6 None). Pas de somme de contrôle : JoyPro modifie sur place des valeurs de taille fixe.
  • EnhancedInputUserSettings.sav : touches attribuées par le joueur de l'Enhanced Input d'Unreal. Les noms de correspondance sont <ACTION>JST<channel> (PRIMARYFIREJST0), les touches RawInput_Controller<channel>_Button<n> avec n le numéro de bouton DirectInput. La liste des correspondances est réécrite ; chaque autre octet reste.
  • Périphériques : reconnus par chemin HID au canal que le jeu leur a donné.
  • Liste de commandes : la table propre à JoyPro (DB\GRebels\actions.tsv, rôles d'axe et boutons ; les fichiers du jeu ne sont pas lus). engine grebels refresh-db l'écrit dans le dossier des données de jeu ; les lignes déjà présentes gardent leur entrée.
  • Commandes : engine grebels paths, engine grebels catalog, engine grebels scan, engine grebels import, engine grebels export --mode clean|add|merge|merge-overwrite --nuke-untouched-devices --dry-run.

#Limites connues

  • Les chapeaux, la zone morte et la sensibilité ne sont pas écrits.
  • Parmi les boutons, seul Primary Fire est confirmé dans le jeu.
  • Des entrées ne sont jamais ajoutées : les canaux, les lignes d'axe et le fichier des boutons doivent exister grâce au jeu.
  • Tests : engine\tests\smoke\grebels.ps1 ; dans le jeu tools\e2e\games\GRebelsSettings.ps1 (deux lancements : le premier donne un canal à vJoy et enregistre les lignes d'axe, le second vérifie des rôles aléatoires et Primary Fire sur JST0 ; le dossier de sauvegarde est restauré ensuite).
