IL-2 Series: Korea

Afficher :

IL-2 Series: Korea vient de la même famille qu'IL-2 Great Battles mais garde son key mapping dans un nouveau format JSON : un profil ("General") pour tous les appareils, dans l'installation du jeu. JoyPro le lit dans votre profil, relie ses actions à vos autres jeux dans des relations et les réécrit, y compris les courbes de réponse de l'éditeur de courbes du jeu et ses réglages de retour de force.

Pour les débutants

#Le faire marcher en 3 étapes

  1. Tout configurer pour moi
    sur la page Accueil
  2. Utiliser ces boutons
    regardez d'abord la liste
  3. Écrire dans mon jeu
    gardez le jeu fermé

Avant : enregistrez une fois un key mapping. Ouvrez Settings > Key mapping et appuyez sur ACCEPT. Fermez le jeu.

Ensuite : vos assignations sont dans Settings > Key mapping, dans chaque appareil.

Vous avez déjà assigné des boutons dans IL-2 Korea ? Alors la page Accueil propose Importer, puis combler les vides. Vos assignations restent, et seuls les boutons libres reçoivent de nouveaux rôles. Voir Démarrage rapide : faire marcher mon manche.

#Regarder autour sans suivi de la tête

Pas de TrackIR, pas de VR ? La configuration met les vues rapides sur un chapeau de votre manche : avant, arrière, gauche et droite. Les axes de regard vont sur le mini-stick de votre manette des gaz, si elle en a un. Voir Suivi de la tête et regarder autour.

#Ce que JoyPro fait pour IL-2 Korea

  • Importer : chaque action du key mapping placée sur un manche, une manette des gaz, un palonnier ou un panneau arrive dans votre profil, avec les modificateurs, l'inversion de chaque axe et les valeurs de l'éditeur de courbes. Les touches clavier arrivent quand vous les demandez.
  • Relations : une relation est une fonction dans tous vos jeux, par exemple "Gear" dans Korea, IL-2 Great Battles et DCS sur le même bouton. Korea a un seul key mapping pour tous les appareils.
  • Exporter : JoyPro écrit le key mapping et donne un numéro de périphérique à chacun de vos périphériques, comme le fait la propre boîte de dialogue "assign device number" du jeu.

#Importer vos assignations Korea

  1. Ouvrez Démarrer. La carte IL-2 Series: Korea affiche l'image du jeu. Si elle demande une liste de commandes, appuyez sur Créer la liste : JoyPro lit le general.actions du jeu (chaque action reçoit le propre nom et l'explication de JoyPro).
  2. Appuyez sur Importer sur la carte. Choisissez Ajouter à mon profil et cochez Prendre aussi les touches du clavier si vous voulez aussi vos touches de vol.
  3. Appuyez sur Importer maintenant. Voir mes relations ouvre ce qui est arrivé.

#Créer et vérifier les relations

Sur la page Relations, l'action Korea d'une relation se trouve à côté de la même fonction dans vos autres jeux. Utilisez le parcours des relations pour les réunir, puis appuyez sur Vérifier maintenant sur la page Exporter : cela trouve un bouton qui fait deux choses dans Korea (la vérification).

#Exporter vers IL-2 Korea

  1. Fermez le jeu. JoyPro refuse d'écrire tant que IL2Series.exe tourne.
  2. Ouvrez Exporter. La carte IL-2 Series: Korea montre combien de ses relations sont assignées.
  3. Gardez Remplacer sur mes périphériques avec Effacer aussi mes autres périphériques si c'est dans JoyPro que vous configurez vos manches. Appuyez sur Exporter maintenant sur la carte.
Dans le jeu: Ce que vous voyez dans IL-2 Korea

Lancez le jeu et ouvrez Settings > Key mapping. Vos assignations sont dans les lignes d'action (par exemple sur l'onglet Basic), avec votre périphérique par son nom et son numéro ("joy 2") ; le jeu ne demande pas de numéro de périphérique. L'icône de courbe d'une ligne d'axe ouvre l'éditeur de réponse avec les valeurs écrites par JoyPro. Le retour de force et le filtre de bruit des axes s'affichent dans Settings > Input devices.

#Ce que vous faites vous-même dans IL-2 Korea

  • Enregistrez une fois un key mapping. Le jeu écrit general.actions quand vous appuyez sur ACCEPT dans Key mapping. Un premier lancement affiche aussi le contrat d'utilisation du jeu. Sans general.actions, il n'y a rien vers quoi exporter.
  • La version autonome s'installe par défaut sous Program Files, et Windows peut protéger ce dossier. L'exportation le dit alors au lieu d'écrire la moitié des fichiers.
  • Pour le propre retour de force de JoyPro à partir de la télémétrie du jeu, la page Retour de force ajoute l'adresse de JoyPro au startup.cfg du jeu (fermez d'abord le jeu). Désactivez le propre retour de force du jeu pour ce manche.

#Pièges courants

  • "IL-2 Korea est en cours d'exécution" : fermez le jeu et exportez à nouveau.
  • Un périphérique a été ignoré : un périphérique sans numéro de périphérique qui n'est pas branché ne peut pas en recevoir. Branchez-le et exportez à nouveau.
  • Une assignation manque après « Ajouter seulement » : l'entrée était utilisée pour une autre action dans le jeu. La vérification la liste sous « Non écrit dans le jeu ».
Avancé

#Fichiers que JoyPro lit et écrit

Fichier De quoi il s'agit
<install>\data\input\general.actions le profil de key mapping "General" (JSON) : périphériques utilisés, modificateurs, chaque action avec ses entrées, valeurs Relative Control
<install>\data\input\known.devices.json chaque périphérique que le jeu a vu, avec son numéro de périphérique
<install>\data\input\general.pitch la courbe de tangage ("General (Common pitch curve)")
<install>\data\input\shared.responses les courbes des autres axes
<install>\data\NSData\UserData\UserSettings.json Settings > Input devices : le retour de force et le filtre de bruit des axes (section input)
<install>\data\startup.cfg l'adresse de télémétrie de JoyPro (seulement quand vous configurez le retour de force par télémétrie)
general.actions.joypro-meta.json les noms, groupes, modificateurs et réglages de JoyPro à côté du fichier, relus par la prochaine importation

<install> est steamapps\common\IL2Series pour Steam, ou le dossier game sous le lanceur autonome. current.map est compilé par le jeu ; JoyPro ne l'écrit jamais.

#Les modes d'exportation dans IL-2 Korea

Mode Ce qui se passe dans le jeu
Ajouter seulement Rien n'est retiré. Une assignation dont l'entrée est utilisée par le jeu pour une autre action n'est pas écrite et est listée.
Mettre à jour, garder les assignations du jeu Vos assignations entrent ; les autres entrées du jeu restent, sauf une assignation du jeu sur une entrée que vous donnez à une autre action.
Mettre à jour, mon profil l'emporte Comme ci-dessus, et chaque action que vous assignez perd ses autres entrées (joysticks ; le clavier seulement avec l'option clavier).
Remplacer sur mes périphériques Chaque entrée joystick des périphériques que vous écrivez est libérée ; puis vos assignations entrent.
+ Effacer aussi mes autres périphériques Les périphériques branchés sans assignation dans votre profil perdent leurs entrées joystick.

#Ce qui n'est jamais touché

  • Les touches du clavier, les entrées souris et les paires de touches sur les axes en mode Remplacer (le clavier ne change qu'avec l'option clavier).
  • Les périphériques non branchés, les lignes que l'importation ne sait pas lire, les périphériques ignorés de l'importation et le périphérique vJoy alimenté par JoyPro.
  • current.map, les fichiers de retour de force par périphérique et les autres réglages du jeu.

#Courbes, Relative Control, retour de force

  • Granularité : globale. Un seul key mapping pour tous les appareils ; le profil de courbe de tangage est attribué par défaut à chaque appareil.
  • Courbes d'axe (modèle d'axes il2korea) : exposant (-100 à 100), zones mortes au centre et au bord, le décalage du centre pour le tangage ; pour le tangage, le roulis et le lacet aussi la courbe de réponse intégrée et la charge des gouvernes. Les axes à un seul côté (gaz, freins) reçoivent un exposant et des zones mortes basse/haute sur toute la course. Les axes de caméra n'ont pas d'éditeur et ne reçoivent pas de courbe. Les valeurs sont dans les unités du fichier ; le jeu affiche les zones mortes quatre fois plus grandes.
  • Relative Control (le bouton ◆ d'une entrée d'axe) : activé/désactivé, zone morte (0 à 80 %) et sensibilité (1 à 20), comme la fenêtre les affiche.
  • Réglages du jeu (Paramètres > Paramètres de retour de force des jeux) : retour de force activé, puissance des secousses, puissance du retour, force du manche à basse et à haute vitesse, rééquilibrage force-neutre, contact avec le terrain et le filtre de bruit des axes, en % comme le jeu les affiche.
  • Retour de force par télémétrie et enregistrement : à partir de la sortie de télémétrie du jeu, comme dans Great Battles (CSV seulement, pas de piste Tacview).
  • Surveillance : les changements dans general.actions sont remarqués après la fermeture du jeu (la surveillance des jeux).
Détails techniques

#Dans l'intégration Korea

Code : engine\Games\Il2KoreaIntegration.cs, modèle d'axes il2korea dans engine\AxisModels.

  • Entrées : dev<N>_b<button, 0-based>, dev<N>_axis_<x|y|z|w|s|t|p|q> (X, Y, Z, RX, RY, RZ, curseur 1, curseur 2), - devant le jeton = inversé, * = Relative Control, chapeaux dev<N>_pov<hat>_<angle>, touches key_<name>, combinaisons avec +.
  • Périphériques : known.devices.json indexe chaque périphérique par son GUID d'instance DirectInput (dans l'ordre des octets d'IL-2) et contient son deviceId (le numéro, -1 = aucun) et son ident (vid_pid). Un périphérique que JoyPro écrit garde son numéro ; un périphérique branché sans numéro reçoit le plus petit numéro libre à partir de 1.
  • Liste de commandes : engine il2korea refresh-db ajoute les actions d'un fichier de key mapping. Les actions sans entrée ne sont pas dans general.actions, donc une liste neuve contient environ 318 actions. JoyPro ne lit pas les archives compressées du jeu.
  • Importation / exportation : engine il2korea import, engine il2korea scan, engine il2korea export (--mode, --nuke-untouched-devices, --include-keyboard, --dry-run) ; engine il2korea paths montre les fichiers.
  • Réglages et courbes : engine ffb set --device * --game IL2Korea --param ffForce=80, engine binds tuning set --scope game:IL2Korea (ou family:il2), engine binds tuning preview (correspond à la table compilée du jeu à 1e-6 près, sauf le côté plat d'un décalage du centre).
  • Télémétrie : engine ffb telemetry setup il2korea.

#Limites connues

  • Les textes d'action propres au jeu sont dans ses archives compressées, que JoyPro ne lit pas ; JoyPro utilise ses propres noms.
  • Environ 60 actions de la page Key mapping n'ont pas d'entrée dans un general.actions neuf et ne sont pas dans une liste fraîchement construite.
  • Tests : engine\tests\smoke\il2korea.ps1, il2koreainstall.ps1 ; dans le jeu tools\e2e\games\IL2Korea.ps1 (49 étapes sur 49), IL2KoreaCurves.ps1, IL2KoreaSettings.ps1.
