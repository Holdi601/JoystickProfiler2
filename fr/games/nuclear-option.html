Nuclear Option

Afficher :

Nuclear Option est un jeu de combat aérien avec des jets, des VTOL et des hélicoptères, et un seul jeu d'assignations pour tous les appareils. Il ne garde pas ses commandes dans un fichier mais dans le registre Windows : une map joystick Rewired par périphérique, écrite par le Control Mapper du jeu. JoyPro lit ces maps dans votre profil et y réécrit vos assignations Flight Controls ; les assignations de caméra, de gameplay et de chat restent telles quelles.

Pour les débutants

#Le faire marcher en 3 étapes

  1. Tout configurer pour moi
    sur la page Accueil
  2. Utiliser ces boutons
    regardez d'abord la liste
  3. Écrire dans mon jeu
    gardez Nuclear Option fermé

Avant : lancez Nuclear Option une fois, puis fermez-le.

Ensuite : vos assignations sont dans Settings > Controls > Open Control Bindings Menu, sur l'onglet de votre périphérique.

Vous avez déjà assigné des boutons dans Nuclear Option ? Alors la page Accueil propose Importer, puis combler les vides. Vos assignations restent, et seuls les boutons libres reçoivent de nouveaux rôles. Voir Démarrage rapide : faire marcher mon manche.

#Ce que JoyPro fait pour Nuclear Option

  • Importer : les maps joystick de vos périphériques branchés arrivent dans votre profil : les axes avec leur inversion, les boutons, et les boutons sur un axe (par exemple "Increase Throttle").
  • Relations : une relation est une fonction ; Nuclear Option n'a pas de listes d'appareils, donc une relation vaut pour tous les appareils.
  • Exporter : JoyPro modifie la map de chaque périphérique sur place, seulement les actions Flight Controls qu'il écrit. Un périphérique pour lequel le jeu n'a pas de map enregistrée reçoit une nouvelle map avec vos assignations.

#Importer vos assignations

  1. Lancez Nuclear Option une fois (pour que sa clé de registre existe) et fermez-le.
  2. Ouvrez Démarrer, appuyez sur Importer sur la carte Nuclear Option, puis sur Importer maintenant.

#Créer et vérifier les relations

Créez des relations comme pour tous les jeux (parcours des relations) ; l'Assistant de configuration et l'Assignation auto connaissent les fonctions du jeu. Puis lancez la vérification sur la page Exporter.

#Exporter vers Nuclear Option

  1. Fermez Nuclear Option. JoyPro refuse d'écrire pendant qu'il tourne : le jeu écrit ses maps quand le menu des assignations se ferme et quand un périphérique est débranché.
  2. Ouvrez Exporter, gardez Remplacer sur mes périphériques avec Effacer aussi mes autres périphériques, et appuyez sur Exporter maintenant sur la carte Nuclear Option.
Dans le jeu: Ce que vous voyez dans Nuclear Option

Ouvrez Settings > Controls > Open Control Bindings Menu. Le Control Mapper a un onglet par périphérique : cliquez sur votre périphérique en haut pour y voir vos assignations Flight Controls (sous les noms du jeu, par exemple Pitch, Roll, Yaw, Throttle). Les assignations de caméra, de gameplay et de chat ne changent pas.

#Ce que vous faites vous-même dans Nuclear Option

  • Lancez le jeu une fois avant la première importation ou exportation, pour qu'il crée sa clé de registre.
  • Use Throttle Axis Negative Region dans les commandes du jeu : laissez-le activé pour un axe de gaz complet. JoyPro vous avertit quand il est désactivé et que votre profil assigne un axe de gaz.
  • Chapeaux : pour l'instant, assignez les directions de chapeau dans le jeu ; JoyPro ne les écrit pas encore.

#Pièges courants

  • "Nuclear Option est en cours d'exécution" : fermez le jeu et exportez à nouveau.
  • Un périphérique est ignoré : deux périphériques branchés du même modèle (ou un clavier qui apparaît aussi comme contrôleur de jeu) ne peuvent pas être distingués dans les maps du jeu ; JoyPro les laisse de côté avec un avertissement.
  • Un périphérique garde les assignations par défaut du jeu : un périphérique branché pour lequel le jeu n'a pas de map enregistrée utilise la map par défaut du jeu, que JoyPro ne peut pas lire ; Effacer aussi mes autres périphériques n'y touche pas. Assignez-lui quelque chose dans JoyPro, ou videz une fois son onglet dans le Control Mapper.
  • Gaz bloqués au milieu : vérifiez Use Throttle Axis Negative Region (voir plus haut).
Avancé

#Ce que JoyPro lit et écrit

Où De quoi il s'agit
HKCU\Software\Shockfront\NuclearOption Les paramètres Unity du jeu dans le registre ; les valeurs Rewired sont binaires (texte UTF-8 plus un octet zéro), les noms se terminent par _h<hash>
une valeur par périphérique avec dataType=ControllerMap et le hardwareIdentifier du périphérique dans son nom la carte joystick d'un périphérique (XML Rewired), pour le joueur Player0
le même nom avec dataType=ControllerMap_KnownActionIds les ids d'action que la carte connaît ; JoyPro l'écrit avec une nouvelle carte
<install>\NuclearOption_Data\resources.assets la liste d'actions Rewired du jeu : en lecture seule, pour la liste de commandes
%LOCALAPPDATA%\JoyPro2\GameMetadata\HKCU_Software_Shockfront_NuclearOption.joypro-meta.json Les noms, groupes et réglages de JoyPro pour les assignations exportées, pour le prochain import

Avant la première écriture, JoyPro prend un instantané des valeurs de carte de contrôleur de Player0 dans le stockage des sauvegardes ; Annuler la dernière exportation les réécrit et supprime les valeurs de carte que JoyPro a ajoutées. Certains noms de valeurs dépassent 255 caractères, JoyPro utilise donc l'API du registre (Regedit et reg export ne les montrent pas tous).

#Les modes d'exportation dans Nuclear Option

Mode Ce qui se passe dans les cartes de vos périphériques
Ajouter seulement Rien du jeu ne change ; une assignation dont le bouton ou l'axe pilote déjà une autre action (ou l'autre pôle d'un axe) est laissée de côté et listée.
Mettre à jour, garder les assignations du jeu Une action Flight Controls sur une entrée que vous donnez à une autre action la perd ; l'action garde ses autres entrées.
Mettre à jour, mon profil l'emporte Comme ci-dessus, et chaque action (ou pôle) que vous assignez quitte ses autres entrées, sur chaque périphérique branché que JoyPro peut lire.
Remplacer sur mes périphériques Toutes les autres actions Flight Controls des périphériques écrits sont libérées.
+ Effacer aussi mes autres périphériques Les actions Flight Controls des autres cartes enregistrées des périphériques branchés sont libérées. Les périphériques sans carte enregistrée gardent la carte par défaut du jeu.

#Ce qui n'est jamais touché

  • Toutes les actions hors Flight Controls : caméra, gameplay, chat, débogage et assignations de l'éditeur de missions.
  • Les cartes clavier et souris, les cartes de calibrage, les comportements d'entrée, l'attribution des contrôleurs et tous les paramètres du jeu (graphismes, ThrottleUseNegative et les autres options de commandes).
  • Les périphériques non branchés, deux périphériques ou plus du même modèle, les périphériques ignorés de l'import et le périphérique vJoy vers lequel JoyPro redirige.
  • Tout ce qui, dans une carte modifiée, se trouve hors des cartes d'éléments que JoyPro change, y compris les assignations d'actions de mods.

#Granularité, courbes, le reste

  • Granularité : globale, un seul jeu d'assignations pour tous les appareils (l'action Throttle est aussi le collectif de l'hélicoptère).
  • Courbes d'axe : non écrites. La zone morte de calibrage du jeu reste telle quelle.
  • Clavier et modificateurs : non écrits ; les assignations joystick du jeu n'ont pas de modificateurs.
  • Chapeaux : pas encore lus ni écrits. Les curseurs sont écrits avec un avertissement.
  • Retour de force, télémétrie : aucun.
  • Surveillance : une notification de changement du registre sur la clé du jeu ; l'empreinte couvre uniquement les cartes de contrôleur de Player0 (la surveillance).
  • HUD : le HUD trouve le jeu par son processus (NuclearOption).
Détails techniques

#Dans l'intégration de Nuclear Option

Code : engine\Games\NuclearOptionIntegration.cs (le stockage dans le registre, les particularités du jeu, la structure du catalogue) au-dessus de engine\Games\RewiredMapIntegration.cs (lecture et écriture des cartes joystick Rewired, partagé avec Tiny Combat Arena).

  • Noms des valeurs : Unity ajoute _h<hash> à chaque clé (djb2 avec XOR sur la clé UTF-8, en décimal).
  • Périphériques : aucun des périphériques HOTAS habituels n'est connu du Rewired du jeu, leurs cartes portent donc un hardwareGuid à zéro et hardwareIdentifier = WindowsRawInput + chaîne produit HID sans espaces + PID + VID (quatre chiffres hex chacun, en majuscules). duplicate compte les périphériques d'un même modèle ; JoyPro n'en gère qu'un par modèle.
  • Éléments : axes X, Y, Z, Rx, Ry, Rz = 0 à 5, curseurs 6 et 7, bouton n = 31 + n. Un bouton sur une action d'axe est <Action>.Positive / .Negative (axisContribution 0 / 1). La carte par défaut du jeu assigne Pitch, Roll, Yaw, Throttle et Brake aux axes 0 à 4 et onze boutons.
  • Écriture : seuls les blocs ActionElementMap touchés changent (boutons dans <buttonMaps>, axes dans <axisMaps>) ; une nouvelle carte a sourceMapId -1 et la liste des ids d'action connus, pour que le jeu n'y ajoute pas d'assignations par défaut.
  • Liste de commandes : engine nuclearoption refresh-db trouve l'InputManager Rewired dans resources.assets par sa première action ("Pitch") et écrit DB\NuclearOption\actions.tsv (nom de l'action, titre, catégorie, id Rewired ; les actions d'axe ont aussi des lignes de pôle).
  • Commandes : engine nuclearoption paths, engine nuclearoption catalog, engine nuclearoption scan, engine nuclearoption import, engine nuclearoption export ; Annuler avec engine backups restore.

#Limites connues

  • Les périphériques que le Rewired du jeu reconnaît (un hardwareGuid non nul, par exemple un T.16000M) ne sont pas gérés.
  • Les ids d'élément des chapeaux n'ont pas été vus dans une carte enregistrée, les chapeaux sont donc ignorés ; les ids des curseurs suivent la définition générique de Rewired.
  • Les assignations ont été vérifiées dans le menu du jeu, pas encore en vol ; le signe d'axe que le jeu attend pour Pitch n'est pas encore confirmé.
  • Tests : engine\tests\smoke\nuclearoption.ps1 (une vraie carte vJoy plus des assignations caméra et gameplay) ; dans le jeu tools\e2e\games\NuclearOptionSettings.ps1 (Pitch, Roll et Yaw sur des axes vJoy aléatoires apparaissent dans l'onglet vJoy du Control Mapper, et un import après que le jeu a de nouveau enregistré les relit).
