War Thunder

Afficher :

War Thunder garde vos commandes dans machine.blk, un fichier texte qui ne contient que ce qui diffère du préréglage de départ. JoyPro lit les commandes d'avion et d'hélicoptère dans votre profil et les réécrit sur place : les commandes de char, de navire et de menu restent telles quelles. Le jeu garde aussi une copie du fichier sur le serveur de Gaijin ; JoyPro écrit de façon à ce que votre fichier exporté l'emporte à la prochaine connexion.

Pour les débutants

#Le faire marcher en 3 étapes

  1. Tout configurer pour moi
    sur la page Accueil
  2. Utiliser ces boutons
    regardez d'abord la liste
  3. Écrire dans mon jeu
    gardez War Thunder fermé

Avant : connectez-vous une fois. Branchez vos périphériques, lancez le jeu et ouvrez Commandes une fois. Puis quittez.

Ensuite : connectez-vous. Vos assignations sont dans Commandes.

Vous avez déjà assigné des boutons dans War Thunder ? Alors la page Accueil propose Importer, puis combler les vides. Vos assignations restent, et seuls les boutons libres reçoivent de nouvelles tâches. Voir Démarrage rapide : faire marcher mon manche.

#Ce que JoyPro fait pour War Thunder

  • Importer : les raccourcis et axes d'avion et d'hélicoptère sur vos périphériques arrivent dans votre profil, avec toutes les valeurs de la fenêtre Axis setup du jeu, ainsi que les options de commandes globales du jeu (sensibilité, inversion, WEP, autotrim, retour de force).
  • Relations : une relation est une fonction dans chaque jeu. "Gear" peut être le même interrupteur dans War Thunder, DCS et IL-2.
  • Exporter : JoyPro modifie machine.blk sur place. Chars, navires, sous-marins, infanterie et menus ne sont jamais touchés.

#Importer vos assignations War Thunder

  1. Ouvrez Démarrer. Si la carte War Thunder demande une liste de commandes, appuyez sur Créer la liste : JoyPro lit les actions d'avion et d'hélicoptère dans les archives du jeu (en lecture seule ; 290 actions). Paramètres > Jeux permet de désactiver cela ; JoyPro utilise alors sa propre liste plus courte.
  2. Appuyez sur Importer sur la carte War Thunder. Gardez Ajouter à mon profil. Cochez Prendre aussi les touches du clavier si vous voulez aussi vos touches de vol dans JoyPro.
  3. Appuyez sur Importer maintenant. Voir mes relations ouvre ce qui est arrivé.

#Créer et vérifier les relations

Reliez la même fonction de vos jeux avec le flux des relations, puis appuyez sur Vérifier sur la page Exporter. La manette des gaz de l'avion et le collectif de l'hélicoptère sur un même axe, c'est correct dans War Thunder ; deux actions d'avion sur un même bouton, non.

#Exporter vers War Thunder

  1. Fermez War Thunder. Le jeu enregistre le fichier de temps en temps pendant qu'il tourne et quand il quitte, JoyPro refuse donc d'écrire tant qu'il tourne.
  2. Ouvrez Exporter et cochez la carte War Thunder.
  3. Gardez Remplacer sur mes périphériques avec Effacer aussi mes autres périphériques si c'est dans JoyPro que vous configurez vos manches. Appuyez sur Exporter maintenant sur la carte.
Dans le jeu: Ce que vous voyez dans War Thunder

Lancez le jeu et connectez-vous. Dans le hangar, appuyez sur Esc et ouvrez Commandes. Vos assignations sont dans les sections avion et hélicoptère ; la fenêtre Axis setup d'un axe montre sa zone morte, sa non-linéarité, son multiplicateur, sa correction et son inversion. Les lignes de sensibilité, le multiplicateur de retour de force et l'autotrim ne sont listés que dans les modes de commande Realistic et Full-real. Cliquer sur les onglets Mouse aim / Simplified / Realistic / Full-real change votre mode de commande, cela ne filtre pas la liste.

#Ce que vous faites vous-même dans War Thunder

  • Laissez le jeu lister chaque périphérique une fois. War Thunder numérote les boutons et les axes par périphérique dans sa propre table. Branchez le périphérique, lancez le jeu et ouvrez Commandes : le jeu ajoute alors le périphérique à machine.blk. JoyPro ignore un périphérique que le jeu n'a pas encore listé.
  • Connectez-vous une fois avant la première exportation, pour que le fichier de votre compte existe.

#Pièges courants

  • "War Thunder est en cours d'exécution" : quittez le jeu et exportez à nouveau.
  • Un périphérique a été ignoré : le jeu ne l'a pas listé, deux périphériques branchés partagent son VID:PID, ou son nombre de boutons ou d'axes diffère de ce que le jeu a enregistré (tous les numéros seraient faux). Ouvrez Controls dans le jeu avec le périphérique branché.
  • Les anciennes assignations sont revenues après la connexion : vous avez restauré une copie à la main. Utilisez plutôt Annuler la dernière exportation : JoyPro augmente alors la version du fichier, pour que le serveur ne le remplace pas.
  • Les diagonales de chapeau, les boutons de souris et les modificateurs d'axe ne peuvent pas être écrits.
Avancé

#Fichiers que JoyPro lit et écrit

Fichier De quoi il s'agit
%USERPROFILE%\Documents\My Games\WarThunder\Saves\<uid>\production\machine.blk vos commandes (hotkeys{}, axes{}, params{}, deviceMapping{}) et les blocs de paramètres du jeu ; <uid> est votre compte (Saves\lastlogin.blk le nomme ; Saves\last avant une connexion)
...\production\machine.blk.joypro-meta.json Les noms, groupes et réglages de JoyPro pour les assignations écrites, relus par la prochaine importation
machine.blk.jpbak la copie d'avant la première écriture, plus le stockage de sauvegardes versionnées de JoyPro
un preset de commandes exporté (controls{} en haut) peut aussi être importé et exporté ; les options globales du jeu sont écrites uniquement dans machine.blk

machine.blk est un diff par rapport au preset de base nommé dans basePresetPaths : le premier bloc d'un raccourci remplace toute la liste du preset pour lui, un ID_X{} vide signifie non assigné, et un attribut d'axe manquant signifie « la valeur du preset ». JoyPro écrit les blocs de raccourci catalogués, axisId et les valeurs d'axe des axes catalogués, et les clés d'option isolées que vous réglez. Toutes les autres lignes gardent leur texte ; deviceMapping{} est seulement lu.

#Les modes d'exportation dans War Thunder

Seules les commandes cataloguées d'avion et d'hélicoptère comptent. Un conflit, c'est une autre de ces commandes sur la même entrée.

Mode Ce qui se passe dans machine.blk
Ajouter seulement Un raccourci n'est écrit que si aucune autre commande d'avion ou d'hélicoptère n'utilise cette entrée ; il ne supprime jamais un bloc et ne remplace jamais un axe assigné. Les assignations ignorées reçoivent la marque « Non écrit dans le jeu ».
Mettre à jour, garder les assignations du jeu Vos raccourcis s'ajoutent à côté des autres raccourcis de la commande ; seuls les conflits sont retirés (un axe d'une autre commande sur votre axe reçoit axisId -1).
Mettre à jour, mon profil l'emporte Comme ci-dessus, et une commande que vous assignez perd ses autres raccourcis sur les périphériques branchés que le jeu liste (le clavier seulement avec l'option clavier).
Remplacer sur mes périphériques Comme ci-dessus, et les autres raccourcis et axes d'avion et d'hélicoptère des périphériques écrits sont libérés.
+ Effacer aussi mes autres périphériques Pareil pour les périphériques branchés sans assignations dans votre profil.

Un ID_X{} vide est remplacé quand JoyPro assigne la commande. Une commande absente du fichier reçoit un avertissement : votre raccourci remplace alors la valeur par défaut du preset de base pour elle.

#Ce qui n'est jamais touché

  • Les raccourcis et axes de char, de navire, de sous-marin, d'infanterie et de menu.
  • deviceMapping{}, config{} et toutes les lignes de paramètres que JoyPro ne règle pas.
  • Les assignations souris, les périphériques non branchés, les périphériques ignorés de l'import et le périphérique vJoy vers lequel JoyPro redirige.
  • Le clavier, sauf si vous exportez des assignations clavier.
  • Le contrôle relatif, le maintien de la valeur et la plage de l'axe restent tels que le fichier les a, sauf si vous les réglez.

#Appareils, courbes, options du jeu

  • Granularité : un seul jeu de commandes pour tous les avions et un pour tous les hélicoptères (le jeu n'a pas d'assignations par appareil).
  • Modificateurs : le dernier bouton d'un raccourci est l'entrée principale, les autres boutons et touches du bloc sont ses modificateurs. Jusqu'à trois alternatives par raccourci.
  • Courbes d'axe dans les unités propres au jeu, telles que la boîte de dialogue Axis setup les montre : zone morte (0 à 0.5), non-linéarité (0 à 3, affichée de 1 à 4), multiplicateur, correction, inversion, contrôle relatif avec sa sensibilité et son pas, maintien de la valeur pour un axe désactivé. Une relation sans valeurs War Thunder reçoit sa courbe JoyPro ajustée : multiplicateur = 1 / saturation X, zone morte mise à l'échelle avec lui, la non-linéarité la plus proche ; pour un curseur, la course entre zone morte et saturation est étalée sur toute la plage. Une valeur égale à celle du preset de base supprime la ligne, comme le jeu lui-même l'enregistre.
  • Options du jeu : sensibilité en roulis, tangage et lacet pour les avions et pour les hélicoptères, inversion de Y (avion, hélicoptère), inversion de la manette des gaz, maintien des gaz pour le WEP, autotrim, retour de force activé (le jeu doit redémarrer) et son multiplicateur. Réglez-les dans Paramètres > Paramètres de retour de force des jeux (choisissez War Thunder) ou avec engine ffb set. Elles sont écrites même par une exportation sans assignations War Thunder ; l'import reprend les valeurs du fichier.
  • Copie cloud : à la connexion, le jeu compare la première ligne version:i=N du fichier avec celle du serveur. JoyPro garde la version, votre nouveau contenu est donc envoyé. Annuler la dernière exportation donne au fichier restauré une version supérieure à celle qu'il remplace, pour que la copie du serveur ne revienne pas.
  • Retour de force par télémétrie : la page Retour de force pilote votre manche à retour de force depuis le serveur web local du jeu (127.0.0.1:8111, servi par le jeu en cours ; rien à configurer). Désactivez le retour de force propre au jeu pour ce manche.
  • Enregistrement de la télémétrie : JoyPro peut enregistrer une sortie à partir du même serveur et l'exporter en CSV ou pour Tacview (une carte plate autour de 0/0, car le jeu n'a pas de vraie position géographique).
  • Surveillance : une assignation, une valeur d'axe ou une option que vous changez dans le jeu est remarquée après sa fermeture ; des clés réordonnées ou le style de diff du jeu ne comptent pas comme un changement.
  • HUD : le HUD trouve le jeu par son processus et affiche vos assignations War Thunder.
Détails techniques

#Dans l'intégration de War Thunder

Code : engine\Games\WarThunderIntegration.cs, engine\Games\WarThunderVromfs.cs, le modèle d'axe engine\AxisModels\WarThunder.cs et le modèle de réglages engine\FfbModels\WarThunder.cs.

  • Périphériques : deviceMapping{ joystick{ devId:t="0738:2215" name:t="..." buttonsOffset:i= buttonsCount:i= axesOffset:i= axesCount:i= } }. devId est le VID:PID du produit DirectInput ; le jeu associe les périphériques uniquement par devId, deux périphériques identiques n'en font donc qu'un. joyButton = buttonsOffset + index local (boutons, puis quatre par chapeau : haut, droite, bas, gauche) ; axisId = axesOffset + index local dans l'ordre DirectInput (X, Y, Z, Rx, Ry, Rz, deux curseurs), puis deux par chapeau. engine games devices montre ce que JoyPro voit pour chaque périphérique.
  • Format : texte BLK, name:type=value, les noms de bloc se répètent (lus comme une liste ordonnée), CRLF. Les fichiers avec controls.version inférieur à 5 sont anciens et ne sont pas lus.
  • Liste de commandes : engine warthunder refresh-db lit shortcutsgroupaircraft.nut et shortcutsgrouphelicopter.nut dans gui.vromfs.bin et les titres dans lang.vromfs.bin (lang/controls.csv), décompressés dans un dossier temporaire supprimé ensuite ; seuls les ids et les titres restent. --no-game-archives (Paramètres > Jeux : décochez « War Thunder: read the full command list from the game's archives ») utilise la propre liste de JoyPro de 116 actions ; les ids sans ID_ sont des axes. --path prend un dossier contenant les scripts de commandes sous forme de fichiers simples.
  • Import / exportation : engine warthunder import, engine warthunder scan ; engine warthunder export --mode clean|add|merge|merge-overwrite --nuke-untouched-devices --include-keyboard --ignore-device <d> --dry-run.
  • Presets de base : sans table des valeurs des presets officiels, l'exportation écrit explicitement chaque attribut d'axe réglé (elle ne supprime jamais une ligne comme « égale à la base »), le fichier est donc juste quel que soit le preset de base ; l'import utilise les valeurs par défaut du code pour les attributs que le fichier ne règle pas.
  • Options du jeu : engine ffb set --device * --game WarThunder --param <key>=<value> (joyFX, forceGain 0..100, aileronsMultiplier ... en %, invertY, invertYHelicopter, invertT, holdThrottleForWEP, autotrim).
  • Télémétrie : engine ffb telemetry setup et engine telemetry record ; JoyPro interroge /state 20 fois par seconde et /indicators une requête sur deux, uniquement pendant que le jeu tourne.

#Limites connues

  • Aucune table des valeurs des presets de base n'est fournie (voir ci-dessus).
  • Une fois, un passage de la surveillance a manqué un changement de « hold throttle for WEP », et une sensibilité a été relue avec un écart d'une unité.
  • 128 boutons et 4 chapeaux par périphérique sont lus ; les diagonales de chapeau, les boutons de souris et les modificateurs d'axe ne sont pas écrits.
  • Tests : dans le jeu tools\e2e\games\WarThunderSettings.ps1 (assignations sur des axes vJoy, les boîtes de dialogue Axis setup du tangage et de la manette des gaz, les valeurs de la page Controls, et l'import du fichier que le jeu a réécrit).
