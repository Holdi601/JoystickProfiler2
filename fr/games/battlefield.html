Battlefield

Afficher :

Battlefield 6 et Battlefield 2042 lisent un seul joystick, et leurs assignations ne nomment aucun périphérique. Un HOTAS de plusieurs périphériques ne marche donc qu'avec le joystick virtuel de JoyPro : JoyPro met chaque entrée utilisée par vos relations Battlefield sur un périphérique vJoy et cache les vrais périphériques au jeu avec HidHide. Le profil texte du jeu contient les assignations des jets et des hélicoptères ; JoyPro écrit déjà leurs touches clavier et lit les assignations joystick. L'écriture des assignations joystick attend un relevé confirmé de la numérotation joystick du jeu. Les anciens Battlefield sont seulement documentés.

Pour les débutants

#Le faire marcher en 3 étapes

  1. Tout configurer pour moi
    puis Utiliser ces boutons
  2. L'utiliser
    puis Démarrer avant le jeu
  3. Assigner vJoy dans le jeu
    sur sa page joystick
  1. Sur la page Accueil, appuyez sur Tout configurer pour moi. Regardez la liste. Appuyez sur Utiliser ces boutons. JoyPro choisit les boutons pour les jets et les hélicoptères.
  2. Ouvrez la page Joystick virtuel. Installez-y vJoy et HidHide s'ils manquent. Appuyez sur L'utiliser à côté de Battlefield. Appuyez sur Démarrer avant de lancer le jeu.
  3. Dans le jeu, ouvrez la page joystick. Cliquez sur la case d'une ligne, puis appuyez sur votre bouton. Le jeu voit un seul joystick, "vJoy Device".

JoyPro n'écrit pas encore les assignations joystick de Battlefield. L'étape 3 est donc pour vous. Détails ci-dessous.

#Ce que JoyPro fait pour Battlefield

  • Un seul périphérique pour le jeu : en mode virtuel, votre manche, votre manette des gaz et votre palonnier apparaissent à Battlefield comme un seul joystick vJoy dont les entrées ne bougent jamais. Tous les autres programmes continuent de voir vos vrais périphériques.
  • Touches clavier : JoyPro lit et écrit les touches clavier des actions de bouton des jets et des hélicoptères, quand vous demandez le clavier.
  • Assignations joystick : JoyPro les lit (avec un avertissement) mais ne les écrit pas encore. La numérotation des entrées joystick du jeu n'est pas confirmée ; d'ici là, vous assignez vous-même le périphérique vJoy sur la page joystick du jeu.

#Importer

  1. Lancez le jeu une fois pour qu'il écrive son profil de paramètres. Avant cela, JoyPro liste son propre tableau des actions de jet et d'hélicoptère ; la première importation le remplace par les actions de votre profil.
  2. Ouvrez Démarrer, appuyez sur Importer sur la carte Battlefield 6 (ou 2042), cochez Prendre aussi les touches du clavier si vous les voulez, appuyez sur Importer maintenant.

#Configurer le joystick virtuel

  1. Ouvrez la page Joystick virtuel. Sous Ce dont cette page a besoin, installez vJoy et HidHide s'ils manquent.
  2. Sous Jeux, passez Battlefield 6 sur vJoy (JoyPro le suggère là avec L'utiliser).
  3. Si la page propose Configurer vJoy pour le tableau, appuyez dessus : JoyPro configure le périphérique vJoy sans les axes Rx et Ry, car Battlefield prend un joystick avec Rx / Ry pour une manette Xbox. Windows doit redémarrer avant que vJoy prenne le changement en compte.
  4. Appuyez sur Démarrer avant de lancer le jeu, et sur Arrêter quand vous avez fini.

#Créer et vérifier les relations

Assignez votre HOTAS aux actions de jet et d'hélicoptère de Battlefield sur la page Relations (parcours des relations) : seules les entrées des relations qui ont une action Battlefield reçoivent une place sur le périphérique vJoy. Le jet et l'hélicoptère sont des véhicules différents, donc le même bouton peut faire autre chose dans chacun.

#Exporter

  1. Fermez le jeu.
  2. Ouvrez Exporter, gardez Remplacer sur mes périphériques, appuyez sur Exporter maintenant sur la carte Battlefield. Les touches clavier sont écrites si vous avez coché le clavier à l'importation (le choix est gardé par jeu). Les assignations joystick sont listées comme non écrites.
  3. Lancez le jeu une fois ensuite et regardez les assignations : Steam Cloud et EA synchronisent le dossier de paramètres, et une copie dans le cloud peut l'emporter.
Dans le jeu: Ce que vous voyez dans Battlefield

Quand le joystick virtuel tourne, l'unique joystick du jeu est "vJoy Device". Dans Battlefield 6, les lignes des aéronefs sont sous l'icône d'engrenage > CONTROLLER > EDIT SETTINGS > JOYSTICK > Aircraft EDIT ("AIRCRAFT PILOT CONTROL MAPPING") : chaque ligne affiche UNBOUND ou l'assignation, par exemple "AXIS 1 X -". Les touches clavier écrites par JoyPro apparaissent dans les assignations clavier du jeu.

#Ce que vous faites vous-même dans Battlefield

  • Assignez le périphérique vJoy dans le jeu sur la page joystick ci-dessus : cliquez sur la case d'une ligne, puis bougez l'entrée. Le jeu assigne la première entrée qu'il voit, donc seul vJoy doit lui être visible (joystick virtuel en marche).
  • Désactivez Steam Input pour ce jeu.
  • Si le jeu voit encore vos vrais périphériques (certains joueurs signalent que Battlefield 6 voit des périphériques cachés par HidHide), débranchez-les pendant que vous jouez ; le périphérique vJoy transporte tout.

#Pièges courants

  • La page joystick manque dans le jeu : le joystick a des axes Rx ou Ry, et le jeu le prend pour une manette Xbox. Configurez vJoy sans eux (étape 3 ci-dessus) et redémarrez Windows.
  • Une ligne assigne un axe qui tremble : un autre périphérique est encore visible pour le jeu. Lancez le joystick virtuel avant le jeu, ou débranchez les vrais périphériques.
  • Un seul périphérique a été exporté : le jeu lit un seul joystick ; JoyPro écrit le périphérique qui a le plus d'assignations et liste les autres (« utilisez le joystick virtuel »).

#Fichiers que JoyPro lit et écrit

Jeu Fichier De quoi il s'agit
Battlefield 6 %USERPROFILE%\Documents\Battlefield 6\settings\steam\PROFSAVEbf6mp_profile et PROFSAVE_profile profil multijoueur et campagne, lignes de texte GstKeyBinding.<category>.<Concept>.<slot>.axis <n> (aussi .button, .negate, .type) ; la version de l'application EA n'a pas de dossier steam
Battlefield 2042 %USERPROFILE%\Documents\Battlefield 2042\settings\PROFSAVE_profile le même format

Une exportation écrit chaque *_profile du dossier qui contient des assignations, pour que campagne et multijoueur correspondent. Les fichiers binaires PROFSAVE sans _profile ne contiennent pas d'assignations et ne sont jamais touchés. Sauvegardes comme pour toute exportation (.jpbak et le stockage de sauvegardes de JoyPro), noms et groupes de JoyPro dans <profile>.joypro-meta.json.

#Les modes d'exportation dans Battlefield

Seuls les emplacements avion à réaction et hélicoptère changent. Les emplacements soldat et véhicule terrestre, les emplacements souris et manette, les touches sur les actions d'axe et les codes joystick que la table de JoyPro ne lit pas ne changent jamais.

Mode Ce qui se passe
Ajouter seulement Une assignation dont l'entrée est utilisée par une autre action du même véhicule est ignorée (marquée « Non écrit dans le jeu ») ; aucun emplacement n'est libéré.
Mettre à jour, garder les assignations du jeu L'emplacement de l'autre action sur l'entrée du profil est libéré ; les emplacements assignés de l'action restent. Une assignation qui ne trouve pas d'emplacement libre reste dehors.
Mettre à jour, mon profil l'emporte Comme ci-dessus, et les autres emplacements de l'action (les touches avec l'option clavier) sont libérés ; un emplacement assigné reçoit l'entrée du profil.
Remplacer sur mes périphériques Les emplacements de vol de ce que l'exportation écrit sont libérés : les touches du clavier quand des touches sont exportées (le joystick une fois que des assignations joystick sont écrites).
+ Effacer aussi mes autres périphériques Pas d'autre périphérique à vider : le jeu lit un seul joystick.

#Ce qui n'est jamais touché

  • Les assignations d'infanterie, de véhicule terrestre, de transport et de mitrailleur ; les emplacements souris et manette.
  • Les touches du clavier sur les actions d'axe (le jeu gère ces paires) et les touches du clavier sans l'option clavier.
  • Les emplacements joystick, tant que la numérotation n'est pas confirmée.
  • HidHide masque vos vrais périphériques seulement à l'exécutable du jeu, seulement pendant que le joystick virtuel tourne ; Arrêter rend à HidHide exactement ses réglages d'avant.

#Axes et autres réglages

  • Par classe de véhicule : avion à réaction et hélicoptère sont des catégories séparées dans le profil du jeu ; JoyPro écrit les deux.
  • Inverser seulement : un axe est écrit en deux moitiés, et Inverser les échange. Pas de courbes ni de zones mortes, pas de modificateurs.
  • Chapeaux : quatre directions seulement, les diagonales sont ignorées. Les joueurs voient environ 18 boutons ; au-delà, ce n'est pas confirmé.
  • Surveillance : les fichiers de profil sont surveillés après la fermeture du jeu (la surveillance des jeux).
  • HUD : pendant que le jeu tourne, le HUD nomme l'action de chaque bouton appuyé.
  • Les fonctions virtuelles (bascules, plages d'axe, appui court / long ...) marchent sur le périphérique vJoy pour Battlefield.

Détails techniques

#Dans l'intégration Battlefield

Code : engine\Games\BattlefieldIntegration.cs (une seule classe pour Battlefield 6 et 2042) ; le planificateur vJoy, le transfert et la session HidHide de virtual-joystick.

  • Lignes d'assignation : type 0 souris, 1 manette, 2 clavier (button = scan code DIK, 255 = aucun), 3 joystick ; « rien d'assigné » est l'axe 56 (Battlefield 6) ou 27 (2042) et le bouton 60. negate 1 = l'emplacement pilote l'action dans le sens négatif. Le profil par défaut a deux emplacements joystick vides par action d'axe (negate 0 et 1) ; une action de bouton reçoit l'emplacement n+1 avec ses quatre lignes à leur place triée.
  • Périphériques : les assignations ne nomment aucun périphérique ; JoyPro écrit un seul joystick. Le jeu se déclare jeu à un seul périphérique (1 joystick, mode suggéré virtual, axes vJoy Rx et Ry évités), le planificateur ne donne donc aucune entrée Rx / Ry et engine vjoy configure-vjoy configure le périphérique sans eux.
  • Numérotation du joystick : une table provisoire tirée du schéma décodé de Battlefield 4 (X / Y comme Axis1X / Axis1Y, Z / Rx / Ry / Rz comme codes de bouton de demi-axe 36-43, le bouton n comme code n-1, le chapeau n comme 44 + 4(n-1) + direction). Le réglage par défaut du jeu ne correspond pas, donc sans table confirmée JoyPro lit les assignations joystick avec un avertissement et n'en écrit aucune. Le relevé en direct tools\e2e\games\BattlefieldJoystickSurvey.ps1 produit la table confirmée <engine>\TOOLS\Conversions\Battlefield6JoystickMap.tsv (Battlefield2042JoystickMap.tsv).
  • Commandes : engine bf6 paths, engine bf6 catalog, engine bf6 scan, engine bf6 import, engine bf6 export --include-keyboard --mode clean|add|merge|merge-overwrite --dry-run, engine bf6 refresh-db ; les mêmes sous engine bf2042 export et ses voisines. Mode virtuel : engine vjoy mode Battlefield6 virtual, engine vjoy map, engine vjoy apply-hidhide.

#Limites connues

  • Les assignations joystick ne sont pas écrites tant que le relevé n'a pas confirmé la numérotation.
  • Battlefield 2042 est implémenté d'après le même format, sans jeu installé.
  • Les boutons au-delà d'environ 18, et la question de savoir si un demi-axe est enregistré comme axe entier, ne sont pas encore confirmés.
  • Tests : engine\tests\smoke\battlefield.ps1 ; les scripts de relevé tools\e2e\games\BattlefieldJoystickSurvey.ps1, BattlefieldSurveyAuto.ps1, BattlefieldAdminSession.ps1 (ils ont besoin d'une fenêtre de redémarrage de Windows pour la configuration de vJoy).
