Étapes principales

Exporter vers vos jeux

Afficher :

L'exportation est l'étape qui fait marcher vos manches dans le jeu. JoyPro écrit vos relations et assignations dans les fichiers de réglages des commandes de chaque jeu, les mêmes fichiers que le menu Controls du jeu enregistre. Rien ne tourne en arrière-plan pendant que vous volez : une fois l'exportation faite, le jeu lit ses propres fichiers comme toujours.

Pour les débutants

#Exporter en trois étapes

Ouvrez Exporter dans la barre du bas. La page se compose de trois cartes numérotées, de haut en bas :

  1. Vérifiez votre profil. Appuyez sur Vérifier maintenant. JoyPro cherche ce qui irait mal dans le jeu, par exemple un bouton qui fait deux choses dans le même appareil. Corrigez ce qu'il trouve (un clic par problème) ou laissez tel quel ; la vérification ne bloque jamais l'exportation. Voir la vérification.
  2. Comment JoyPro écrit dans les jeux. Choisissez l'un des quatre choix. En cas de doute, gardez le premier : Remplacer sur mes périphériques avec Effacer aussi mes autres périphériques coché. Vos manches font alors exactement ce que dit votre profil, et rien d'autre.
  3. Exporter vers les jeux. Chaque jeu pour lequel votre profil a des assignations reçoit une carte avec son image. Cochez les jeux et appuyez sur Exporter les jeux cochés, ou appuyez sur Exporter maintenant sur une carte.

Fermez d'abord le jeu. Les jeux écrivent leurs fichiers de commandes en quittant, JoyPro refuse donc d'exporter vers un jeu qui tourne et vous le dit.

#Quel choix me convient ?

Choix Choisissez-le quand Ce qui arrive aux propres assignations du jeu
Remplacer sur mes périphériques JoyPro est l'endroit où vous configurez vos manches Sur les périphériques de votre profil, seules vos assignations restent (pour les appareils que vous exportez).
Mettre à jour, garder les assignations du jeu Vous assignez aussi des choses dans le jeu et voulez les garder Vos assignations sont ajoutées ; une assignation du jeu n'est retirée que là où elle est sur un bouton que vous utilisez pour autre chose.
Mettre à jour, mon profil l'emporte Comme ci-dessus, mais vous avez déplacé des actions vers d'autres boutons dans JoyPro Comme ci-dessus, et chaque action que vous assignez perd ses autres boutons dans le jeu, pour qu'un déplacement déplace vraiment.
Ajouter seulement Vous essayez JoyPro pour la première fois Rien n'est retiré. Si le jeu utilise déjà un bouton pour autre chose, votre assignation est laissée de côté et la vérification vous le dit.

Effacer aussi mes autres périphériques (une case sous les choix) : les périphériques branchés qui n'ont pas d'assignation dans votre profil perdent leurs assignations dans les appareils exportés. Laissez-la cochée si vous voulez repartir de zéro, décochez-la si vous utilisez un second périphérique uniquement dans le jeu.

#Sûr par conception

  • Avant que JoyPro ne modifie un fichier du jeu, il le copie dans une sauvegarde. Chaque carte a Annuler la dernière exportation : cela remet les fichiers exactement comme ils étaient, octet par octet.
  • La première exportation vers un jeu qui a déjà ses propres assignations demande une fois : « Importer d'abord ? ». Choisissez Importer d'abord si vous voulez garder ce que vous avez fait dans le jeu, Exporter quand même pour le remplacer.
  • Les périphériques non branchés gardent leurs assignations. Vos assignations de souris et de manette ne sont jamais touchées.

#Ce que vous remarquez dans le jeu

Lancez le jeu et ouvrez son menu des commandes : vos assignations y sont, dans la colonne de chaque périphérique, sous les noms qu'utilise le jeu. Dans DCS, elles s'affichent par appareil ; dans Star Citizen, par action de vaisseau ; dans IL-2, dans Key mapping. La section Dans le jeu ci-dessous liste chaque type de jeu.

#Les autres façons dont vos assignations arrivent dans le jeu

Moyen Ce qu'il fait
Écrire dans mon jeu (la configuration rapide) L'exportation de la configuration rapide. Elle écrit les jeux qu'elle a configurés, avec la même sauvegarde. Voir Démarrage rapide.
La fausse manette (manette Xbox virtuelle) Pour ACE COMBAT 8 et Hell Let Loose: Vietnam, rien n'est écrit. Leur exportation le dit. Votre manche pilote une fausse manette tant que Démarrer est actif. Voir Jeux uniquement Xbox.
La planchette de genou DCS Pas une exportation d'assignations : une page par appareil qui liste ce que font vos boutons, dans le cockpit. Voir la planchette de genou.

#Options par jeu

Sous Options et chemins (pour experts) :

  • DCS : la liste Appareils... sur la carte DCS (seuls les appareils cochés sont écrits) ; DCS : garder les défauts du clavier (activé) ; mes périphériques perdent aussi les assignations par défaut de DCS dans tous les autres appareils (désactivé).
  • Star Citizen : SC : garder les défauts du clavier, préférer l'ordre local.
  • Les autres jeux : une case Essai à blanc qui montre ce qui changerait sans rien écrire.
  • Chemins : un autre dossier Saved Games ou de configuration par jeu ; Chemins et périphériques ignorés propres à ce profil donne au profil ouvert les siens au lieu de ceux du PC.

#Marques : « Non écrit dans le jeu »

Ajouter seulement (et tout mode où un jeu n'a pas de place libre pour une autre entrée, par exemple Elite Dangerous avec deux entrées par action) laisse certaines assignations de côté. Le profil retient chacune avec l'action du jeu qui occupe l'entrée et la date ; la vérification montre une carte par marque avec Exporter avec 'Mettre à jour' pour le remplacer, Déplacer vers un autre bouton et Laisser tel quel. Chaque exportation remplace les marques de son jeu et de ses appareils, une marque disparaît donc quand une exportation ultérieure écrit l'assignation.

#Réglages retenus

Le mode, la case Effacer aussi, les options par jeu et les chemins sont gardés dans les paramètres de JoyPro ; les jeux et appareils DCS que vous avez cochés vous-même sont gardés par profil. Remplacer et Effacer aussi demandent confirmation avant chaque exportation (Paramètres > Confirmations peut désactiver la question).

#Après l'exportation

  • Annuler la dernière exportation sur la carte restaure la sauvegarde la plus récente de ce jeu. La liste complète se trouve sous Sauvegardes de la config du jeu en bas de la page Exporter.
  • L'exportation enregistre les fichiers du jeu pour la surveillance des jeux : l'exportation de JoyPro elle-même ne demande jamais plus tard « reprendre les changements ? » ; un changement que vous faites ensuite dans le jeu, si (la surveillance).
  • JoyPro garde ses propres données à côté du fichier du jeu, un import ultérieur ramène donc les noms des relations, les groupes, les modificateurs et les courbes (réimportation).

#Dans le jeu

Ce que le joueur voit après une exportation dépend du type de jeu. Chaque jeu ci-dessous suit les mêmes règles : JoyPro n'écrit que les actions de sa liste de commandes, refuse d'écrire tant que le jeu tourne, sauvegarde d'abord les fichiers et ne devine jamais un périphérique ou une action qu'il ne peut pas faire correspondre (il l'ignore avec un avertissement).

Dans le jeu: Simulateurs de vol : DCS, IL-2 (Great Battles, Korea, 1946, Cliffs of Dover), Falcon BMS, X-Plane, MSFS, FSX, Prepar3D

JoyPro prend en main les périphériques qu'il écrit. Avec Remplacer, toutes les autres assignations de ces périphériques disparaissent dans les appareils exportés ; avec Effacer aussi, les autres périphériques branchés sont effacés aussi (DCS : leurs réglages par défaut DCS également).

  • DCS World : dans Options > Controls, choisissez l'appareil : vos assignations sont dans la colonne du périphérique, les réglages par défaut retirés apparaissent comme cases vides, vos modificateurs sont dans la liste des modificateurs. Seuls les appareils cochés changent. JoyPro n'écrit que les différences avec les réglages par défaut de DCS, comme DCS lui-même.
  • IL-2 Great Battles : Settings > Key mapping montre vos assignations et les réponses des axes. Les lignes de souris et les lignes que JoyPro ne connaît pas restent.
  • IL-2 Korea : le profil de key mapping "General".
  • Falcon BMS : le launcher crée le fichier de touches et l'attribution des axes à son prochain Launch, lancez donc BMS par le launcher.
  • MSFS 2024 / 2020 : dans Controls, le périphérique montre le préréglage de JoyPro.
  • X-Plane 11 / 12 : Settings > Joystick montre les attributions.
Dans le jeu: Jeux avec infanterie, véhicules ou menus : Star Citizen, War Thunder, Arma 3 / 2, Arma Reforger, WARDOGS, Nuclear Option, Hell Let Loose, Battlefield

JoyPro ne touche que les actions de vol (avion, hélicoptère, vaisseau spatial). Vos assignations à pied, de véhicule et de menu restent octet par octet. Remplacer et Effacer aussi ne libèrent que les actions de vol que JoyPro connaît.

  • Star Citizen : Options > Keybindings montre les actions de vaisseau sur vos joysticks (js1, js2, ...). Avec Remplacer ou Effacer aussi, les assignations joystick par défaut du jeu sur js1 sont désactivées quand js1 est écrit ou inutilisé.
  • War Thunder : Controls montre les assignations d'avion ; les commandes de char et de navire ne changent pas.
  • Arma 3 / Arma 2 : les réglages de touches du profil ; seules les actions d'avion et d'hélicoptère changent.
Dans le jeu: Jeux spatiaux : Elite Dangerous, X4: Foundations
  • Elite Dangerous garde deux entrées par action (Primary et Secondary). Une assignation sans place libre reçoit une marque « Non écrit » avec « Déplacer vers un autre bouton » ou « Laisser tel quel ». Les assignations à pied et SRV restent.
  • X4 : les réglages d'entrée du jeu ; seules les actions de vaisseau cataloguées changent.
Dans le jeu: Jeux qui lisent un seul périphérique ou seulement une manette Xbox
  • Jeux réglés sur vJoy (jeux qui ne lisent que quelques périphériques) : l'exportation écrit les assignations sur le périphérique vJoy. JoyPro y copie vos manches pendant que vous jouez, et HidHide cache vos vrais périphériques pour ce jeu uniquement. Le jeu voit un seul périphérique avec tout dessus. Voir Joystick virtuel.
  • Jeux uniquement Xbox (ACE COMBAT 8, Hell Let Loose: Vietnam) : rien n'est écrit, et l'exportation le dit. Votre manche pilote une fausse manette (manette Xbox virtuelle) tant que Démarrer est actif. HidHide n'est pas nécessaire. Voir Jouer à un jeu uniquement Xbox avec un HOTAS.
Détails techniques

#Comment ça marche à l'intérieur

Une exportation, du clic jusqu'aux fichiers écrits :

# Qui Ce qui se passe
1 Vous Appuyez sur Exporter les jeux cochés sur la page Exporter.
2 JoyPro Interroge le moteur sur le jeu (profile game-state --game <id>) : importé, exporté, a des assignations.
3 JoyPro Vous demande si nécessaire : une première exportation (« Importer d'abord ? ») ou un mode qui retire des assignations (Paramètres > Confirmations).
4 Moteur Lance <game> export --mode <m> --nuke-untouched-devices <b> ... : il refuse tant que le jeu tourne, sauvegarde chaque fichier (GameBackups et .jpbak) et n'écrit que des actions cataloguées.
5 Moteur Enregistre l'enregistrement de synchronisation (empreinte et référence) et les marques d'exportation, puis répond : écrit, ignoré, SkippedTakenInputs.
6 JoyPro La carte du jeu affiche « Exporté 14:02 », et Annuler la dernière exportation est prêt.
  1. Interface. ExportSelectedGamesAsync / ExportGameNowAsync (MainWindowViewModel.ExportGames.cs) appellent AskAboutFirstExportAsync (engine profile game-state) et ConfirmRiskyExportAsync, puis ExportGameAsync choisit l'exportateur de la carte : dcs, il2, starcitizen ou un jeu du registre. La commande est construite à partir des réglages de la page, p. ex. RunDcsExportAsync : engine dcs export --mode clean --keep-keyboard-defaults true --nuke-untouched-devices true --clean-all-aircraft false --ignore-device <d> --planes F-16C_50|FA-18C_hornet. Chaque appel au moteur passe par un seul endroit, RunEngineAsync, avec --profile et --status true (la progression et Annuler de la zone d'activité), sérialisé pour que deux commandes n'écrivent jamais en même temps.
  2. Moteur. engine\Program.cs dirige dcs / il2 / starcitizen vers leurs exportateurs et tous les autres jeux vers Games.GameRegistry (une GameIntegration par jeu). DCS : EngineDcsExport.Modes.cs calcule, par fichier de périphérique, les assignations que DCS a actives (profil propre moins removed, plus added et changed), décide lesquelles doivent être actives et n'écrit que les vraies différences par rapport aux valeurs par défaut.
  3. Sécurité. GameExportSafety.BackupBeforeOverwrite copie chaque fichier en <file>.jpbak et dans le stockage de sauvegardes versionné (%LOCALAPPDATA%\JoyPro2\GameBackups\<date-time>_<game>\ avec manifest.json ; les 30 jeux de sauvegardes les plus récents par jeu sont gardés). Les jeux à registre (Nuclear Option) reçoivent un instantané des valeurs qu'ils peuvent changer. Un fichier que l'exportation crée est noté « n'existait pas », une restauration le supprime donc à nouveau.
  4. Ensuite. L'enregistrement de synchronisation (<data>\Sync\<game>.json : taille, heure et SHA-256 par fichier et un hachage de chaque assignation) fait taire la surveillance pour le propre changement de JoyPro. ExportSkippedBinds.cs remplit SkippedTakenInputs ; la commande d'exportation les transforme en marques du profil. L'historique du profil garde un point de restauration avant chaque exportation.

Choix dans l'interface Options du moteur
Remplacer sur mes périphériques + Effacer aussi mes autres périphériques (par défaut) --mode clean --nuke-untouched-devices true
Remplacer sur mes périphériques --mode clean --nuke-untouched-devices false
Mettre à jour, mon profil l'emporte (+ Effacer aussi) --mode merge-overwrite --nuke-untouched-devices true|false
Mettre à jour, garder les assignations du jeu (+ Effacer aussi) --mode merge --nuke-untouched-devices true|false
Ajouter seulement --mode add (nuke n'est pas utilisé)
