Étapes principales

Importer un jeu

Afficher :

L'importation lit les réglages de commandes qu'un jeu a enregistrés et les transforme en profil JoyPro : une relation par fonction avec son bouton ou son axe. C'est le départ le plus rapide : tout ce que vous avez déjà configuré dans vos jeux arrive, et à partir de là JoyPro le garde en un seul endroit.

Pour les débutants

#Importer en trois clics

  1. Ouvrez Démarrer (le premier bouton de la barre du bas). Sous Vos jeux, chaque jeu que JoyPro a trouvé sur votre PC a une carte avec son image. Appuyez sur Importer sur le jeu auquel vous jouez le plus.
  2. JoyPro demande comment :
    • Ajouter à mon profil (recommandé) garde ce que vous avez et ajoute les assignations du jeu.
    • Recommencer à partir de ce jeu remplace vos relations par ce que contient le jeu (JoyPro garde d'abord une copie de votre profil).
    • Prendre aussi les touches du clavier importe aussi les commandes de vol au clavier. Les assignations de périphériques sont toujours prises.
    • Pour DCS : Tous mes appareils DCS, ou décochez-le et choisissez des appareils.
  3. Appuyez sur Importer maintenant. Un instant plus tard, la carte indique « Terminé : votre profil a maintenant 214 relations (180 assignées) » et Voir mes relations les ouvre. Voir d'abord montre plutôt ce que contient le jeu, sans rien changer.

Aucun profil ouvert ? JoyPro en crée un pour vous et l'enregistre automatiquement à partir de là (il n'y a pas de bouton Enregistrer : chaque modification est enregistrée et peut être annulée, même après un redémarrage).

#Qu'est-ce qui change dans le jeu ?

Rien. L'importation ne fait que lire les fichiers du jeu. Le jeu garde ses assignations exactement telles quelles, que vous exportiez plus tard ou non.

#Importer, puis laisser JoyPro combler les vides

Sur la page Accueil, la carte « Configurer vos périphériques » liste les jeux où vous avez fait vous-même des assignations. Importer, puis combler les vides importe d'abord un tel jeu. Puis Combler les vides maintenant... place les fonctions importantes sur les boutons encore libres. Vos propres assignations restent. Pour les jeux déjà dans votre profil, la carte propose Combler les vides....

#Avant votre première importation : la liste de commandes

JoyPro doit connaître les commandes de chaque jeu (leurs noms et identifiants). Il crée cette liste une fois à partir de votre propre installation. Quand une liste manque, la page Accueil affiche Créer la liste (ou Créer toutes les listes manquantes) ; une carte de jeu propose Mettre à jour après une mise à jour du jeu. Cela prend de quelques secondes à quelques minutes (DCS lit chaque module).

Avancé

#Options et leur effet

Option Par défaut Effet
Ajouter à mon profil / Recommencer Ajouter Ajouter fusionne dans le profil ouvert ; Recommencer remplace ses relations après une confirmation et une copie du profil.
Prendre aussi les touches du clavier votre dernier choix Les commandes de vol assignées à des touches sont prises aussi.
Importer aussi les périphériques non connectés activé Les périphériques qui ne sont pas branchés maintenant sont importés aussi (utile pour un manche que vous branchez plus tard). Désactivé : ils sont ignorés et comptés.
Traiter les périphériques de même nom comme un seul périphérique activé Windows donne de temps en temps un nouvel ID à un périphérique ; ses anciens et nouveaux fichiers sont lus comme un seul périphérique sur l'ID branché. Deux périphériques identiques branchés en même temps restent séparés.
Inclure les défauts (DCS, forme experte) activé Chaque assignation par défaut que DCS a active pour un périphérique importé est prise, pour qu'un import suivi d'une exportation Remplacer + Effacer aussi laisse DCS comme il était. Vos propres assignations l'emportent sur une valeur par défaut sur la même entrée.
Importer inversion / curseur / courbure / zone morte / saturation (forme experte) désactivé Reprend les valeurs réglées dans le jeu pour les assignations que JoyPro n'a pas exportées lui-même. Une assignation exportée par JoyPro retrouve ses réglages sans ces options.
DCS : ignorer les appareils *_easy désactivé Les copies en mode facile des appareils sont laissées de côté.

L'importation experte (page Accueil, sous les cartes, et la page Avancé) propose chaque option du moteur par jeu avec Analyser (aperçu), Importer et Exporter. Chaque choix est retenu pour le prochain import.

#Les noms, groupes et modificateurs reviennent

Un fichier de jeu ne contient que le périphérique, l'entrée et parfois une courbe. L'exportation de JoyPro garde ses propres données à côté, et un import les relit :

Jeu Données de JoyPro Restauré
DCS <aircraft>\joystick\<device>.jp, modifiers.lua nom de la relation, groupes (dans l'ordre), modificateurs avec leurs noms, inversion, curseur, zone morte, saturation, courbe
IL-2 Great Battles data\input\jp.actions nom, groupes, alias, modificateurs, les réglages exacts
Jeux du registre (X-Plane, Elite, X4, Arma, MSFS, War Thunder, BMS ...) <config>.joypro-meta.json nom, groupes, alias, modificateurs, réglages
Star Citizen actionmaps.jp noms

L'état actuel du jeu l'emporte : une courbe que vous avez changée dans DCS après l'exportation est gardée. Les assignations que JoyPro n'a jamais exportées reçoivent un nom construit à partir de l'action du jeu et les groupes DCS, IL2 ou GENERATED + jeu.

#Deux garde-fous

  • Changements pas encore exportés. Si vous avez changé des assignations dans JoyPro sans les exporter vers ce jeu, un import ramènerait les anciennes assignations. JoyPro demande d'abord.
  • Déjà importé ? Quand le profil contient le jeu, les changements que vous faites ensuite dans le jeu arrivent par la surveillance des jeux (elle demande après la fermeture du jeu) ; importer à nouveau reste à un clic.
Dans le jeu: Ce que l'importation lit, par type de jeu

L'importation n'écrit jamais dans un dossier de jeu. Ce qu'elle lit :

  • DCS : les assignations de chaque appareil et périphérique, vos modificateurs, et avec « Inclure les défauts » les assignations par défaut que DCS a pour chaque périphérique.
  • IL-2 Great Battles / Korea : le key mapping et les réponses des axes.
  • Star Citizen : les keybindings de la branche (LIVE, PTU ...), avec les assignations joystick par défaut du jeu sur js1.
  • Jeux avec infanterie ou véhicules (War Thunder, Arma, Reforger, WARDOGS ...) : seulement les actions de vol ; tout le reste est ignoré, pas supprimé.
  • MSFS : les profils d'entrée du simulateur (version Steam ou Microsoft Store) et, sur demande, les préréglages par défaut du simulateur.

Les périphériques que le jeu ne peut pas distinguer (deux périphériques du même modèle dans certains jeux) et les assignations de demi-axe (Elite) sont ignorés et nommés dans le résultat.

Détails techniques

#Comment ça marche à l'intérieur

  1. Interface. StartImportWizard → RunImportWizardAsync (MainWindowViewModel.GameHub.cs). Elle appelle AskAboutUnexportedChangesAsync (moteur sync pending), confirme Recommencer et garde une copie du profil (BackupProfileBeforeChange("before-import")), puis appelle l'import du jeu : ImportDcsAsync, ImportIl2Async, ImportStarCitizenAsync ou ImportRegistryGameAsync. Voir d'abord fait la même chose avec scan (PreviewImportWizardAsync) et ouvre le panneau Sortie.
  2. Moteur. Pour DCS : engine dcs import [--path <Saved Games\DCS>] --merge --include-defaults [--plane <a> --plane <b>] --include-keyboard true|false --ignore-easy-planes false --only-connected false --merge-same-name true. L'importateur lit chaque fichier de périphérique, identifie le périphérique par son GUID d'instance DirectInput et son nom, fait correspondre chaque id de commande à la liste de commandes du jeu (DB\<game> dans %LOCALAPPDATA%\JoyPro2\GameData), et construit une relation par fonction et par entrée. Les corrections au chargement (--load-corrections, --correction-mode) remappent les ids de commande renommés avec un score de certitude.
  3. Profil. Les relations sont fusionnées par nom et par entrée identique ; les modificateurs sont créés à partir de modifiers.lua (DCS) ou des réglages de shift du jeu. Le profil est enregistré de façon atomique et chaque enregistrement est une version dans <data>\ProfileHistory (Annuler fonctionne d'un redémarrage à l'autre).
  4. Surveillance. L'import d'un jeu sans enregistrement de synchronisation enregistre les fichiers du jeu, pour que les changements que vous faites plus tard dans le jeu soient remarqués (<data>\Sync\<game>.json).

#Les fichiers qu'il lit

Jeu Fichiers
DCS Saved Games\DCS\Config\Input\<aircraft>\{joystick,keyboard}\*.diff.lua et modifiers.lua, plus les profils propres que JoyPro a construits à partir de votre installation DCS
IL-2 Great Battles / Korea data\input\*.actions et les réponses d'axe
Star Citizen actionmaps.xml de la branche
MSFS le dossier distant Steam ou la sauvegarde Microsoft Store

Les options de l'interface sous forme d'options du moteur : Ajouter --merge, clavier --include-keyboard true, périphériques non branchés --only-connected false, même nom --merge-same-name true, appareils faciles --ignore-easy-planes true. Le garde-fou des changements pas encore exportés est engine sync pending.

Commandes du moteur : engine dcs import, engine dcs scan, engine il2 import, engine starcitizen import et engine <game> import pour chaque jeu du registre (par exemple engine warthunder import, engine msfs2024 import). Règles de réimportation : réimportation. Tests : engine\tests\smoke\dcsincludedefaults.ps1, engine\tests\smoke\roundtrip.ps1, gui\JoyPro.Gui.Tests\ImportSettingsPersistTests.cs.
