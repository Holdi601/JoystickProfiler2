Pages de l'interface

Joystick virtuel

Afficher :

Certains jeux ne prennent que quelques joysticks, choisissent les mauvais ou mélangent leur ordre quand vous branchez un autre périphérique. En mode virtuel, JoyPro place chaque axe, bouton et chapeau qu'utilisent les assignations d'un jeu sur un seul joystick virtuel (vJoy), ou sur une manette Xbox 360 virtuelle pour les jeux qui ne lisent que les manettes de jeu. Le jeu voit un seul périphérique dont les entrées ne bougent jamais ; votre profil garde vos vrais périphériques. En plus, les fonctions virtuelles font ce que fait Joystick Gremlin : plages d'axe comme boutons, bascules, appui court/long, couches de décalage, macros, modes.

Pour les débutants

#L'utiliser en quatre étapes

  1. Sous Jeux, passez le jeu sur vJoy (ou Manette Xbox pour les jeux qui ne prennent qu'une manette de jeu). Les jeux connus pour ne lire qu'un seul périphérique affichent une suggestion avec L'utiliser. Les jeux qui ne lisent que les manettes Xbox (ACE COMBAT 8, Hell Let Loose: Vietnam) sont sur la manette Xbox tout seuls tant que vous ne choisissez pas un autre mode ; la page dit pourquoi. La liste est triée par nom.
  2. Exportez de nouveau le jeu sur la page Exporter. JoyPro écrit les assignations sur le joystick virtuel ; votre profil garde vos vrais périphériques.
  3. Appuyez sur Démarrer. Une règle par type de jeu, dite de la même façon dans la visite de la manette, l'aide et la page :
    • Manette Xbox (ACE COMBAT, Hell Let Loose: Vietnam) : lancez d'abord le jeu et attendez son écran titre, puis appuyez sur Démarrer. Trop tôt ? Appuyez sur Arrêter, puis sur Démarrer. Ces jeux n'ont pas d'exportation et rien à changer, les étapes 1 et 2 sont donc sautées pour eux.
    • vJoy : appuyez sur Démarrer avant de lancer le jeu. JoyPro cache vos vrais périphériques à ce jeu avec HidHide (Windows demande une fois les droits d'administrateur) et copie chaque entrée en direct sur le joystick virtuel.
  4. Appuyez sur Arrêter quand vous avez fini. HidHide retrouve exactement les réglages qu'il avait avant ; rien ne reste caché.

Ce dont cette page a besoin montre les pilotes gratuits : vJoy (pour les jeux réglés sur vJoy), ViGEmBus (manette Xbox) et HidHide (pour les jeux vJoy). Ils ne font pas partie de JoyPro ; installez ceux dont vous avez besoin en un clic à cet endroit. Un jeu qui ne lit que les manettes Xbox (ACE COMBAT 8, Hell Let Loose: Vietnam) n'a besoin que de ViGEmBus : il ne voit jamais vos vrais périphériques, HidHide n'est donc pas nécessaire et Windows ne demande pas de droits d'administrateur.

Seulement des jeux uniquement Xbox ?

Alors la page s'appelle Fausse manette et ne montre que ce dont ces jeux ont besoin : la carte ViGEmBus, Tester et Démarrer. vJoy, HidHide et les listes de modes sont derrière Afficher les détails pour experts (vJoy, HidHide, modes). Voir Jouer à un jeu uniquement Xbox avec un HOTAS.

Testez d'abord

Tester lit vos périphériques et montre dans l'onglet Test en direct ce que le jeu recevrait, sans toucher à vJoy ni à HidHide. Bougez votre manche et regardez les barres.

Dans le jeu: Ce qui change dans le jeu

Le menu des commandes du jeu montre un seul périphérique, « vJoy Device », avec vos assignations sur ses boutons et ses axes. Vos vrais périphériques sont invisibles pour ce jeu seulement pendant que le joystick virtuel tourne ; tous les autres programmes continuent de les voir. Les courbes, les zones mortes et les inversions viennent toujours des réglages du jeu lui-même que JoyPro exporte. Sur la Manette Xbox, c'est différent : ces jeux n'ont pas d'exportation, JoyPro applique donc lui-même chaque courbe d'axe (page Assignations, Réponse de l'axe).

Avancé

#Les quatre onglets

Vue d'ensemble : ce que c'est et comment s'en servir ; État de vJoy (version, périphériques), de HidHide et de la session JoyPro (Actualiser, Configurer vJoy pour le tableau quand un périphérique vJoy manque d'axes, de boutons ou de chapeaux, Restaurer HidHide après un plantage, Configurer vJoy au maximum : 8 axes, 128 boutons, 4 chapeaux, demande un redémarrage de Windows) ; Ce dont cette page a besoin ; Jeux (Natif / vJoy / manette Xbox par jeu, ce que le jeu lit d'un joystick avec des avertissements au-dessus) ; Options : masquer les vrais périphériques (HidHide, recommandé), démarrer et s'arrêter tout seul quand un jeu virtuel démarre et se termine (JoyPro le cherche toutes les 3 secondes ; appuyer sur Démarrer avant le jeu reste le plus sûr pour vJoy ; les jeux à manette Xbox ci-dessus le veulent après leur écran titre).

Mappage : le tableau. Chaque entrée physique qu'utilisent les jeux virtuels a une place fixe sur le joystick virtuel : un axe garde son propre axe là où il est libre (X reste X), les boutons et les chapeaux prennent le prochain numéro libre. Les places existantes ne bougent jamais, donc les assignations du jeu restent les mêmes d'une session à l'autre. Mettre à jour le mappage donne une place aux nouvelles entrées et enregistre le tableau dans le profil.

Fonctions : les fonctions virtuelles, leurs modes, l'importation Gremlin et le graphe (plus bas).

Test en direct : des barres pour les axes, les boutons pressés et les chapeaux de chaque périphérique vJoy tels que le transmetteur les écrit, avec le journal du transmetteur. Afficher le joystick virtuel en direct (pour les joueurs dont tous les jeux sont sur la fausse manette : Afficher la fausse manette en direct) active ou désactive les barres. Pour la manette Xbox, chaque commande mappée dit ce qu'elle fait et d'où elle vient (« A: Fire machine gun (VKB Gunfighter BTN1) », « LX: Roll (Rhino X) »), et un bouton pressé s'allume.

#La manette Xbox

  • Tout seul : un jeu qui ne lit aucun joystick, seulement des manettes Xbox, utilise la manette Xbox tant que vous n'avez pas choisi de mode pour lui (« Sur la manette Xbox tout seul »). Votre choix l'emporte et est gardé. Sans le pilote ViGEmBus, la carte Jeux le dit et propose son installation en un clic.
  • Courbes d'axe : ces jeux n'ont pas d'exportation, donc JoyPro applique lui-même la courbe d'axe de la relation (zone morte, saturation, courbure ou courbe utilisateur, inversion ; la courbe propre au jeu, sinon la Courbe par défaut) au stick ou à la gâchette de la manette. La Réponse de l'axe de la page Assignations le dit pour eux. Les jeux vJoy gardent les valeurs brutes, car leur courbe est dans l'exportation.
  • Plusieurs jeux sur la manette : chacun garde sa propre table de manette ; une seule est active à la fois. Avec le démarrage automatique, c'est la table du jeu qui tourne ; Démarrer et Tester prennent la table du jeu en cours, sinon celle choisie sous Table de la manette Xbox pour Démarrer et Tester (gardée dans le profil).
  • Configuration auto (issue du test en direct d'ACE COMBAT 8, pour chaque profil) : la manette des gaz pilote les deux gâchettes (avant RT, arrière LT) et un axe de frein ne prend pas LT ; le lacet sur LB/RB vient de la rotation de votre manche, sinon du palonnier, à environ 30 % de débattement ; les leurres d'ACE COMBAT 8 (L3 + R3 ensemble, pas encore confirmé dans le jeu) viennent de votre bouton de leurres / CMS avant ; la croix directionnelle de l'ailier de votre interrupteur de communication ou de votre chapeau de menu IA ; une direction de chapeau sur Change target pilote Y ; votre bouton Cobra (ASC Direct Control de DCS) ou une relation de bouton nommée « High-G » maintient les deux gâchettes pour le virage à fort G. Une entrée ne pilote jamais deux commandes de la manette, et un emplacement de la manette qu'aucune relation n'alimente plus disparaît tout seul.
  • Inverser sur la manette : l'inversion de DCS n'arrive jamais jusqu'à la manette. Le tangage d'ACE COMBAT 8 est inversé par défaut (avec les Pitch Controls par défaut du jeu, vers l'avant fait piquer le nez). Retournez l'axe d'un jeu dans Réponse de l'axe avec seulement ce jeu coché sous S'applique à ; DCS garde le sien. engine vjoy pad-check montre ce qu'un profil atteint sur la manette.

#Fonctions virtuelles

Les fonctions tournent dans le joystick virtuel, entre vos périphériques et ce que reçoit le jeu. Choisissez le jeu, le type, Ajouter la fonction, puis définissez ses entrées et ses sorties dans l'éditeur.

Fonction Ce qu'il fait
Bandes d'axe un axe découpé en jusqu'à 16 bandes, chaque bande étant un bouton (crans de gaz)
Cycle de boutons chaque appui passe à la sortie suivante
Bascule (verrouillage) un bouton-poussoir qui reste actif jusqu'au prochain appui
Interrupteur en impulsions marche/arrêt un interrupteur maintenu envoie une impulsion par position
Appui court / long / double trois rôles sur un seul bouton
Couche shift tant que le bouton shift est maintenu, les entrées vont vers d'autres sorties
Fusionner / séparer des axes deux pédales en un seul palonnier ; un axe en deux
Courbe d'axe zone morte, saturation, courbure, inversion, curseur
Extrémités d'axe vers boutons, axes vers chapeau, boutons vers axe, axe vers impulsions d'encodeur conversions
Turbo, macro répéter tant que c'est maintenu ; une suite d'appuis et de touches
Chapeau vers boutons, boutons vers chapeau, remappage chapeaux et remappages
Commutateur de mode change le mode (passer à, maintenir, basculer, faire défiler, revenir)

L'éditeur : nom, Activé, Sortie clavier (permet aux sorties et aux étapes de macro d'appuyer sur des touches ; seulement quand il tourne pour de vrai), une vue des nœuds (entrées → fonction → sorties, allumée quand une sortie se déclenche), la barre des bandes d'axe avec des bords à faire glisser, la courbe, Actif dans les modes, Mode cible, les entrées (périphérique et entrée, Effacer), les sorties (bouton ou axe vJoy, commande Xbox ou touche ; Assigner la relation assigne une relation à cette sortie), les réglages et les étapes de macro. Essayer lance la fonction dans l'éditeur avec des curseurs et des boutons à presser ; rien ne va à vJoy ni au jeu. Enregistrer la stocke ; un joystick virtuel en marche la prend après Arrêter et Démarrer.

Chaînage : une entrée peut lire la sortie d'une autre fonction au lieu d'un périphérique : choisissez ⚙ f1 ... dans la liste des périphériques de l'entrée, ou faites glisser dans le Graphe de toutes les fonctions d'un point de sortie (bord droit) vers un point d'entrée (bord gauche). Les boucles sont refusées. Cliquez sur un fil, puis sur son × pour le déconnecter.

Modes (couches) : donnez à vos entrées un autre rôle selon la situation (Combat, Landing ...). Un mode peut hériter d'un autre ; une fonction est active dans les modes cochés (aucun = tous les modes). Ajouter un mode, Renommer, × (supprimer), Au démarrage (le mode dans lequel démarre le transmetteur). Le mode en cours est marqué en direct.

#Si vous venez de Joystick Gremlin

Choisissez le jeu, cochez si vous le voulez Remplacer les fonctions et modes du jeu, appuyez sur Importer un profil Gremlin... et choisissez le .xml (R13 ou R14). JoyPro montre d'abord un rapport : ce qu'il en fait, ce qu'il ne sait pas faire (conditions d'activation, actions de souris, plugins Python, sons ...) et ce qui est importé, mais différent. Rien n'est enregistré avant Importer. Les modes, remappages, courbes, macros, axes fusionnés, conteneurs tempo, chain et toggle deviennent des fonctions et des modes. Réglez ensuite le jeu sur vJoy, gardez ou assignez les relations sur les sorties vJoy, exportez et Démarrer : HidHide et le transmetteur remplacent le masquage de périphériques de Gremlin et son programme d'arrière-plan.

Détails techniques

#Derrière la page

Modèles de vue : MainWindowViewModel.VirtualJoystick.cs (état, tableau, Démarrer/Tester/Arrêter, démarrage auto, vue en direct), MainWindowViewModel.VirtualFunctions.cs, MainWindowViewModel.VirtualModes.cs (modes, importation Gremlin), VirtualFunctionEditorViewModel.cs ; vues VirtualJoystickView.axaml, VirtualFunctionEditorView.axaml, Views/Controls/VirtualFunctionGraphView.cs, VirtualFunctionFlowView.cs, AxisBandEditor.cs.

Démarrer le joystick virtuel :

# Qui Ce qui se passe
1 Vous Appuyez sur Démarrer.
2 Moteur vjoy map : les nouvelles entrées reçoivent un emplacement ; le tableau est enregistré dans le profil.
3 Moteur vjoy forwarder-config : le tableau et les fonctions, résolus.
4 Moteur vjoy apply-hidhide écrit d'abord son journal, puis cache les périphériques physiques aux jeux vJoy (HidHide demande une fois les droits d'administrateur). Jeux qui ne lisent que les manettes Xbox : « HidHide n'est pas nécessaire », aucune demande.
5 JoyPro.VJoy run --sink vjoy --parent-pid N : à chaque passage (par exemple 144 fois par seconde), il lit les périphériques, exécute les fonctions et écrit vJoy ou la manette Xbox.

Arrêter :

# Qui Ce qui se passe
1 Vous Appuyez sur Arrêter.
2 JoyPro.VJoy S'arrête : sorties au neutre, touches relâchées.
3 Moteur vjoy restore-hidhide remet exactement la configuration d'avant.
  • Tableau de mappage : dans le profil (Pr0file.VirtualJoystick) ; engine vjoy map (--prune, --reset), engine vjoy mode (native | virtual | xbox par jeu), engine vjoy status, engine vjoy settings (quels périphériques vJoy JoyPro utilise), engine vjoy configure-vjoy (vJoyConfig, n'enlève jamais rien sauf les axes évités), engine vjoy limits.
  • Exportation, importation, synchronisation : pendant qu'un jeu virtuel est exporté, importé ou synchronisé, ses assignations pointent vers les emplacements vJoy ; ensuite, le profil retrouve ses périphériques physiques. Un périphérique vJoy manquant arrête l'exportation avec un message.
  • Session HidHide : engine vjoy apply-hidhide, engine vjoy restore-hidhide, engine vjoy recover : un journal est écrit avant tout changement, donc un plantage peut être réparé (Restaurer HidHide).
  • Fonctions et modes : engine vjoy functions types, engine vjoy functions list, engine vjoy functions add --game, engine vjoy functions set --game, engine vjoy functions remove --game, engine vjoy functions test (simulation, rien ne va à vJoy), engine vjoy modes list. Stockés par jeu dans le profil (VJoySettings.Functions[game], VJoySettings.Modes[game]) ; leurs sorties sont réservées dans le tableau. Le même code d'évaluation tourne dans le test du moteur, l'aperçu de l'éditeur et le transmetteur ; les fonctions sont évaluées dans l'ordre des dépendances à chaque passage, rien n'est alloué par passage (environ 10 µs par passage pour 50 fonctions).
  • Gremlin : engine vjoy import-gremlin (--dry-run pour le rapport, --replace, --vjoy-device).
  • Transmetteur : gui/JoyPro.VJoy (JoyPro.VJoy.exe run --config ... --sink vjoy|dry), DirectInput non exclusif en entrée, vJoyInterface.dll / ViGEmBus en sortie. Tester utilise la sortie à blanc et pas de HidHide.

Référence : virtual-joystick, pilotes : components.

#Démarrer et s'arrêter tout seul quand un jeu réglé sur Virtuel démarre et se termine

Case à cocherrédigé2 ×

Désactivé par défaut. Activé : JoyPro cherche toutes les 3 secondes un jeu réglé sur Virtuel, démarre le joystick virtuel quand le jeu démarre et l'arrête quand le jeu se termine.

Appuyer sur Démarrer avant le jeu reste le plus sûr, car certains jeux ne cherchent les périphériques qu'à leur démarrage.
