Pages de l'interface

HUD

Afficher :

Le HUD montre vos périphériques à l'écran pendant que vous jouez, comme l'overlay de manette d'un streamer : l'image du manche s'incline avec votre manche, les leviers et les axes bougent sous forme de barres, les boutons maintenus s'allument avec leur nom, et une ligne dit ce que fait le bouton pressé dans le jeu en cours (« Gear Toggle »). Il peut s'afficher par-dessus le jeu, dans OBS, ou les deux, chacun avec ses propres widgets. Cette page est son éditeur.

Pour les débutants

#Démarrer le HUD en trois clics

  1. Ouvrez HUD dans la barre du bas. L'aperçu bouge déjà quand vous bougez votre manche.
  2. Laissez Sur mon écran (par-dessus le jeu) coché.
  3. Appuyez sur Démarrer le HUD (aussi sur la page Accueil). Lancez votre jeu : le HUD se place par-dessus et ne prend jamais la souris ni le clavier au jeu.

Arrêter le HUD (le même bouton) le ferme. Tout ce que vous réglez ici est gardé et est de nouveau là après un redémarrage.

#Ce qu'il y a à l'écran

  • Un widget par périphérique : les manches, les manettes des gaz et les palonniers sont affichés au départ, les panneaux et les claviers sont masqués (cochez-les dans la liste Widgets). Chaque widget peut montrer la photo du périphérique, la position du manche, les axes en barres, les boutons et les chapeaux.
  • Le widget de l'appareil : le manche et la manette des gaz de l'appareil que vous pilotez, tels que le jeu les dessine, qui bougent avec les vôtres.
  • L'en-tête du jeu : le jeu ou l'appareil DCS avec son image.
  • Ce que fait le bouton : les derniers boutons pressés avec leur action dans le jeu en cours.

Faites glisser un widget dans l'aperçu pour le déplacer ; cliquez dessus pour le modifier à droite. Disposer automatiquement les place le long du bas : la manette des gaz et les périphériques de la main gauche à gauche, le palonnier au milieu, le manche de la main droite à droite.

Dans le jeu: Ce que vous voyez dans le jeu

La fenêtre du HUD est transparente et reste par-dessus les jeux en mode fenêtré et sans bordure. Les clics la traversent jusqu'au jeu. Elle n'est ni dans la barre des tâches ni dans Alt+Tab. Le plein écran exclusif la masque (une limite de Windows) : passez le jeu en mode sans bordure. La ligne du bouton pressé nomme l'action de ce jeu et de cet appareil, par exemple « Weapon Release » dans le F-16C et « Fire guns » dans IL-2.

Avancé

#Où le HUD s'affiche

Les trois sorties sont indépendantes les unes des autres :

Sortie Pour Comment
Sur mon écran (par-dessus le jeu) vous une fenêtre transparente par-dessus le jeu
Page pour OBS (source Navigateur, transparente) votre stream (recommandé) JoyPro sert une page sur ce PC uniquement ; Copier met son adresse dans le presse-papiers
Fenêtre de stream (Capture de fenêtre) les streams par Capture de fenêtre une fenêtre normale (peut se trouver derrière le jeu) avec un fond transparent ou chroma key

Décochez Sur mon écran pour jouer avec un écran propre pendant que le stream montre toujours le HUD, ou montrez des widgets différents sur chacun : chaque widget a deux coches, un écran (votre écran) et OBS (le stream). Aperçu : Mon écran / Le stream change ce que montre le concepteur. Mises à jour par seconde (max.) (15, 30 ou 60 ; 30 est fluide et léger).

#Configurer OBS (source Navigateur)

  1. Cochez Page pour OBS (source Navigateur, transparente) et appuyez sur Démarrer le HUD.
  2. Appuyez sur Copier à côté de l'adresse (http://127.0.0.1:8765/hud).
  3. Dans OBS : Sources > + > Browser. Collez l'adresse comme URL, Width 1920, Height 1080. Rien d'autre n'est nécessaire : le fond est transparent, pas de CSS personnalisé.
  4. Optionnel : cochez Shutdown source when not visible pour qu'OBS arrête la page dans les scènes où elle n'est pas.

La page dessine les widgets cochés pour le stream, aux mêmes endroits et dans les mêmes styles que dans l'application, sur une scène de 1920 x 1080 mise à l'échelle de la source. Port pris par un autre programme ? Choisissez-en un autre sous Port et copiez à nouveau l'adresse.

Capture de fenêtre à la place : cochez Fenêtre de stream, choisissez le fond (transparent, vert, magenta, bleu ou votre couleur). Dans OBS, ajoutez Window Capture avec Capture Method: Windows 10 (1903 and up) ; avec une couleur, ajoutez un filtre Chroma Key de cette couleur. Si un fond transparent s'affiche en noir dans votre OBS, utilisez la source Navigateur ou une couleur.

Comment la source Navigateur d'OBS reçoit le HUD : une page, puis seulement les changements.

# Qui Ce qui se passe
1 OBS La source Navigateur ouvre http://127.0.0.1:8765/hud.
2 JoyPro Envoie la page : disposition, styles et images.
3 OBS Ouvre /hud/events. Elle reste ouverte.
4 JoyPro Envoie l'état (axes, boutons, ce que fait le bouton), au plus 30 fois par seconde et seulement quand quelque chose a changé.
5 JoyPro Renvoie la disposition quand les widgets, les emplacements ou les styles changent.

#Widgets

Widgets liste chaque périphérique plus l'en-tête, le défilant des assignations et le widget d'appareil. Recharger les périphériques relit les périphériques branchés ; Tout afficher coche chaque widget pour votre écran ; Disposer automatiquement et Réinitialiser les emplacements les mettent en place.

Par widget (cliquez dessus dans l'aperçu ou la liste) :

  • Afficher sur mon écran, Afficher dans le stream, Taille, Style de ce widget (le style du HUD ou n'importe quel autre).
  • Afficher : nom, type (manche, manette des gaz), image, image qui s'incline avec le manche, boutons qui s'allument, boutons maintenus par leur nom, axes et leviers, noms des axes, valeurs des axes, position du manche (cardan), chapeaux. Le widget d'en-tête : son image.
  • Image : Photo (l'image du fabricant, fond découpé), Disposition (votre image de disposition JoyPro de la page Disposition, avec les boutons pressés allumés à leur place), Auto (la photo quand il y en a une).
  • Poignée sur cette base : pour les bases qui acceptent plusieurs poignées (VPforce Rhino, Virpil WarBRD) ; la poignée décide de l'image et des noms des boutons.
  • Axes du manche : d'où viennent X, Y et Twist de l'élément manche. Automatique prend les axes propres au périphérique ; une poignée qui est un périphérique à part sans axes les prend de la base sur laquelle elle est montée.

Le widget d'appareil : manche, manette des gaz, barre de course des gaz, position du manche, commandes qui s'allument, commandes maintenues par leur nom ; Appareils (Automatique : l'appareil que vous pilotez, ou n'importe quelle image définie sur ce PC) et Bouge avec (le manche et la manette des gaz qui le font bouger). Ses images viennent des images de cockpit propres au jeu (Cockpits > Créer les images à partir de mes jeux, ou un pack d'images), sinon du dessin au trait de JoyPro de la vraie poignée.

#Les 40 styles

Style a 40 préréglages : Verre, Néon, Minimal, des styles sobres (Verre dépoli clair, Streamer sobre, Streamer marqué, Compact, Grand texte, Pastel, Contours seuls), des affichages de cockpit (HUD militaire vert, MFD ambre, PFD de ligne, Cockpit tout écran, Vision nocturne, Éclairage cockpit rouge, Fil de fer vectoriel, Terminal rétro, Warbird, Hologramme), des jeux et des genres (Espace orange, Holo cyan, Cyberpunk, Synthwave, Néon rose, Course, Tactique sable, Marine et or, Furtif, Fantôme), des thèmes de couleur (Arctique, Désert, Océan, Coucher de soleil, Royal, Carbone) et la lisibilité (Contraste élevé, Contraste élevé clair, Monochrome, Monochrome clair). › passe au suivant.

En dessous : des couleurs d'accent en un clic, Accentuation, Appuyé et Opacité, puis les options de design par élément : Cartes (fond, bordure, coins, ombre), Texte (police, taille, espacement des lettres, couleurs, Noms en gras), Indicateur du manche (anneau, carré, réticule, radar, point ; taille, halo), Barres et leviers (formes, hauteurs, la partie vide) et Boutons et pastilles (formes). Une option changée fait passer le style en « design personnel (modifié) » : Enregistrer le style le garde sous votre nom, Annuler les modifications revient au préréglage, Exporter le style... / Importer un style... le partagent sous forme de fichier, Supprimer retire votre propre style.

#Ce que fait le bouton et l'appareil DCS

Ce que fait le bouton : combien de lignes, combien de temps elles restent (secondes), la taille de police, Afficher le périphérique et le bouton et Seulement pendant qu'un jeu tourne. Clic traversant laisse passer les clics de souris à travers la fenêtre du HUD (s'applique au démarrage du HUD).

JoyPro trouve le jeu en cours par son processus (DCS, IL-2, Star Citizen et tous les autres jeux qu'il gère) et ne montre que les assignations de ce jeu. DCS a aussi besoin de l'appareil : choisissez-le sous Appareil DCS, ou Installer le hook DCS pour que DCS donne l'appareil à JoyPro à chaque début de mission (un petit fichier Lua plus une ligne protégée dans Export.lua, sauvegardé d'abord ; Supprimer remet le fichier octet pour octet ; fermez DCS d'abord). Vérifier dit si le hook est installé.

Détails techniques

#Derrière la page

Modèle de vue : MainWindowViewModel.Hud.cs (périphériques, widgets, disposition), MainWindowViewModel.HudStyles.cs (préréglages, styles personnels, importation/exportation), MainWindowViewModel.HudStream.cs (sorties, page de stream, widget d'appareil), MainWindowViewModel.HudAxes.cs (axes du manche), MainWindowViewModel.Overlay.cs (démarrer/arrêter, jeu en cours, lignes des boutons, hook DCS). Vues : Views/HudWindow.axaml, Views/Controls/HudSurface.axaml, HudElements.cs, HudPanel.cs. Préréglages : Models/HudStylePresets.cs.

  • Périphériques : engine hud devices donne pour chaque périphérique branché son modèle, son type, sa main, l'image du produit, les axes avec leur rôle, les boutons avec leurs noms et leurs ids de commande (Controls, pour le widget d'appareil) et l'image de disposition avec les positions des boutons.
  • Assignations du jeu en cours : engine overlay map (--game, --plane, --unit) : les boutons assignés avec modificateurs et titres. Une assignation avec modificateurs s'affiche tant que ses modificateurs sont maintenus ; l'assignation qui a le plus de modificateurs correspondants l'emporte.
  • Hook DCS : engine overlay dcs-hook status / install / remove (--path, --dry-run) : Scripts\JoyProOverlay.lua plus une ligne entourée de pcall dans Export.lua ; DCS envoie le type d'unité à 127.0.0.1:1992 (UDP). Le hook appelle les fonctions d'exportation des autres scripts (SRS, Tacview) qu'il remplace.
  • Serveur de stream : Services/HudStreamServer.cs, HudStreamHub.cs, Resources/hud-stream.html ; lié uniquement à 127.0.0.1, les requêtes avec un autre nom d'hôte sont refusées. GET /hud (page), /hud/events (Server-Sent Events : layout, state), /hud/img/<id> (images en PNG), /hud/state (JSON). Sans page connectée, il ne fait qu'écouter.
  • Coût pendant que vous jouez : Services/HudInputPump.cs ne garde que le rapport le plus récent par périphérique et les applique à la fréquence choisie ; les éléments ne se redessinent que lors d'un changement ; rien n'est alloué par rapport ; les images sont découpées une seule fois (poignées d'appareil de 480 px de haut). Mesuré par le test d'endurance du HUD par rapport à des budgets de CPU, d'allocation et de mémoire.
  • Paramètres : %APPDATA%\JoyPro2\hud.json (emplacements, tailles, coches par widget pour l'écran et le stream, le style avec chaque option, styles personnels, sorties, port, fond, fréquence de mise à jour). Fichiers de style : *.joypro-hudstyle.json ("format": "joypro-hud-style").
