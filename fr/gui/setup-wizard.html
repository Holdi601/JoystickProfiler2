Pages de l'interface

Assistant de configuration

Afficher :

L'assistant de configuration configure d'un coup vos commandes pour vos jeux. Il regarde vos périphériques connectés, donne un rôle à chacun (manche principal, manette des gaz, palonnier, panneau ...), crée des relations pour les fonctions importantes des appareils de vos jeux, les assigne à vos périphériques et vous montre le résultat sous forme d'aide-mémoires. Vous vérifiez tout avant que votre profil change, et un seul Annuler retire tout. Il fonctionne sans IA : les mêmes choix donnent toujours le même plan.

Ouvrez-le depuis la page Accueil. Sa carte « Configurez vos périphériques » a deux boutons :

  • Tout configurer pour moi (le bleu) : la configuration rapide. Elle lance cet assistant toute seule, sans montrer les étapes, et s'arrête sur une simple liste de ce qui va où. Voir Démarrage rapide.
  • Configurer étape par étape... : cet assistant avec les cinq étapes, pour que vous choisissiez chacune vous-même.

Sans cette carte (tous les jeux sont déjà configurés), appuyez sur Configurer mes périphériques automatiquement... sous Vos jeux sur la page Accueil, ou sur la page Assignations.

  1. Jeux
    quels jeux configurer
  2. Périphériques
    à quoi sert chaque périphérique
  3. Priorités
    vos appareils, modificateurs, où placer les fonctions
  4. Plan
    ce que JoyPro a placé
  5. Vérification
    vérifiez, puis Appliquer à mon profil

La configuration rapide (Tout configurer pour moi) exécute le même planificateur sans ces étapes. Elle utilise les rôles habituels de vos périphériques, tous les appareils à égalité, aucun modificateur et votre dernier choix pour Où placer les fonctions ?. Pour un simulateur de vol, elle pose une question : Utilisez-vous le suivi de la tête ou la VR ?

Pour les débutants

#Les cinq étapes

Les étapes sont affichées en haut ; Retour et Suivant en bas passent de l'une à l'autre. Fermez la fenêtre quand vous voulez : un assistant fermé avant Appliquer revient tel que vous l'avez laissé.

#1. Jeux

Les jeux que vous surveillez sur la page Accueil sont cochés. Cochez les jeux que cette configuration doit couvrir. Cela ne change pas les jeux que JoyPro surveille.

#2. Périphériques

JoyPro reconnaît vos manches, manettes des gaz, palonniers et panneaux et propose un rôle pour chacun : « À quoi sert ce périphérique ». Changez un rôle dans sa liste. Un périphérique par main : un deuxième manche pour la même main reçoit « inutilisé », sauf si vous choisissez autrement. Une base qui accepte plusieurs poignées demande la poignée. Le cadre à droite dit en mots comment JoyPro va les utiliser. Détecter à nouveau relit les périphériques (branchez d'abord un périphérique).

#3. Priorités

  • Vos appareils : cherchez un appareil (« F-16 », « helicopter », « Star Citizen ») et appuyez sur Ajouter en priorité suivante (une nouvelle ligne) ou Ajouter à égalité (dans la ligne sélectionnée). Plus un appareil est haut, meilleures sont les places de ses fonctions. Les appareils d'une même ligne comptent autant ; les appareils que vous ne listez pas comptent le moins.
  • Modificateurs : un modificateur est un bouton que vous maintenez (comme Shift) pour que chaque autre bouton fasse une deuxième chose. Choisissez combien ; Le moins possible n'en utilise un que quand vous manquez de boutons.
  • Commutateur de mode (couches de phase) : un interrupteur à position fixe peut changer ce que font vos boutons selon la phase de combat.
  • Où placer les fonctions ? : un curseur. Extrémité gauche : Même bouton pour la même tâche dans chaque appareil. Extrémité droite : Là où l'appareil réel l'a. Le milieu est la position de départ. Le canon et la manette des gaz ne bougent jamais. Voir Où placer les fonctions ?.
  • Utilisez-vous le suivi de la tête ou la VR ? Seulement pour les simulateurs de vol. Oui si vous regardez autour de vous en bougeant la tête (TrackIR, une webcam de suivi du visage, Tobii ou la VR), ou si vous comptez le faire : aucun bouton de vue sur vos périphériques, seulement « recentrer la vue ». Non : la vue va sur un chapeau de votre manche ou de votre manette des gaz, juste après les boutons les plus importants. Voir Suivi de la tête et regarder autour.

#4. Plan

JoyPro établit le plan : combien de fonctions il a placées, ce qu'il n'a pas pu placer, les modificateurs qu'il a créés, les règles qu'il a suivies et une note de qualité par appareil (100 % = chaque fonction à sa meilleure place).

#5. Vérification

Choisissez un Périphérique et un appareil dans Appareils pour voir le dessin du périphérique par JoyPro avec ce qui est assigné où. Sélectionnez une fonction dans la liste pour la déplacer vers une entrée libre, l'échanger avec une autre ou la retirer du plan. Non placées liste ce qui n'a pas trouvé de place, le plus important en premier.

Quand ça vous plaît : Appliquer à mon profil, puis Exporter vers mes jeux (la page Exporter s'ouvre). Vos jeux ne changent qu'avec l'exportation.

Avancé

#Détails

  • Rôles : manche principal (main droite dans chaque appareil), manche d'hélico (main droite dans les hélicoptères, pour un second manche comme une base à retour de force), manche gauche (main gauche dans les jeux spatiaux ; le côté gaz sans manette des gaz), manette des gaz, collectif (main gauche dans les hélicoptères), palonnier (gouvernail et freins aux pieds), panneau (interrupteurs système dont l'étiquette imprimée correspond : « LDG GEAR UP » reçoit le train), joystick clavier et virtuel (gardés, rien de nouveau n'est assigné), inutilisé.
  • Votre profil d'abord : une commande déjà dans l'une de vos relations y reste, et une relation déjà assignée sur un périphérique de cette configuration garde son entrée. Une commande que vous avez désactivée reste désactivée.
  • Où placer les fonctions ? Le curseur va de Même bouton pour la même tâche dans chaque appareil à Là où l'appareil réel l'a. Sous le milieu, il y a une relation par fonction pour tous les appareils ; à partir du milieu, les appareils dont le vrai HOTAS a la fonction ailleurs reçoivent leur propre relation, et plus vous allez à droite, plus la vraie position compte. La configuration rapide et la page Accueil utilisent votre dernier choix (le milieu au départ).
  • Les choix de l'étape 3 sont mémorisés ; le prochain assistant commence avec eux.
  • Appliquer écrit tout en un seul changement : une version dans l'Historique du profil nommée « Setup wizard: N relations, M binds ». Annuler (Ctrl+Z) reprend tout.
  • Ouvrir la fiche montre l'aide-mémoire en taille réelle dans votre visionneuse d'images, pour l'imprimer.
  • La nouvelle disposition suit votre appareil le plus utilisé de sa classe quand Paramètres > Statistiques d'utilisation > Disposer les nouveaux appareils comme mon plus utilisé est activé.
Dans le jeu: Après Appliquer et une exportation

Rien jusqu'à ce que vous exportiez. Après Appliquer et une exportation, les fichiers de commandes de chaque jeu contiennent les assignations de l'assistant : dans DCS, chaque appareil choisi a la même fonction sur le même bouton quand le curseur est près de Même bouton pour la même tâche dans chaque appareil, Star Citizen reçoit les commandes du vaisseau sur le manche et les axes de translation sur un manche gauche, les panneaux reçoivent les systèmes que nomment leurs étiquettes. Exportez avec Remplacer sur mes périphériques si les périphériques doivent perdre les assignations que le jeu avait avant.

Détails techniques

#Derrière l'assistant

Fenêtre Views/SetupWizardWindow.axaml, modèle de vue ViewModels/SetupWizardViewModel.cs (son propre modèle de vue, créé par MainWindowViewModel.SetupWizard.cs avec les jeux surveillés), planificateur engine/SetupWizard/*.cs. Chaque étape est une commande du moteur, donc la ligne de commande fait le même plan : engine setup devices (reconnaissance et rôles, --role, --grip), engine setup aircraft (la liste des priorités), engine setup plan (--games, --priorities "A>B|C", --modifiers, --prefer-fewer ou --use-all-modifiers, --placement (ancien nom --realism), --phase-layers, entrées de cockpit de engine cockpits comme --cockpit-file ; écrit le plan en JSON), engine setup render (une feuille de légendes par périphérique), engine setup apply (--plan, une seule version du profil). Déplacer, permuter, retirer et remettre modifient le plan dans l'interface (SetupPlanEdit) et sont vérifiés de nouveau avant Appliquer. Référence : Assistant de configuration.

#Appliquer

Boutonrédigé

Place ces boutons dans JoyPro. Le jeu ne change pas encore.

Étape 5 : écrit les relations, assignations et modificateurs du plan dans votre profil en une seule étape : une seule version dans l'Historique du profil, et un seul Annuler revient sur le tout.

Le plan est d'abord vérifié ; un problème l'arrête avec une indication.
