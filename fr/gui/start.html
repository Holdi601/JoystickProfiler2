Pages de l'interface

Démarrer

Afficher :

La page Accueil est celle où JoyPro s'ouvre. Elle montre ce qui est configuré, ce qu'il faut faire ensuite, et vos jeux : Importer reprend dans JoyPro les assignations faites dans un jeu ; Exporter les réécrit dans le jeu. L'importation étape par étape : Importer un jeu.

Pour les débutants

#De haut en bas

  • Avis : prérequis manquants, listes de commandes à créer ou mettre à jour, un rapport de plantage à envoyer, une mise à jour.
  • Configurez vos périphériques : la carte de configuration automatique. JoyPro regarde (en lecture seule) lesquels de vos jeux n'ont encore rien d'assigné et les nomme : « Configurez vos périphériques pour War Thunder et Star Citizen ». Tout configurer pour moi (le bouton bleu) fait tout tout seul ; Configurer étape par étape... ouvre l'assistant de configuration avec ces jeux cochés. Les jeux où vous avez fait des assignations vous-même sont listés en dessous : Importer, puis combler les vides reprend d'abord vos assignations, puis la configuration n'utilise que les commandes libres. Jeux déjà dans votre profil : Combler les vides.... Où est quoi ? montre vos périphériques avec ce que fait chaque commande.
  • Le profil en un coup d'œil : les relations (et combien sont des axes), combien sont assignées, les modificateurs, les périphériques connectés, les jeux installés.
  • Prochaines étapes : ce que JoyPro suggère maintenant (« 3 relations n'ont pas encore de bouton : les assigner », « VPforce Rhino FFB Base n'est pas encore utilisé : Assignation auto », « Écrire vos assignations dans vos jeux : Exporter »).
  • Vos jeux : une carte par jeu avec Importer, Exporter, Mettre à jour (sa liste de commandes), Annuler l'exportation, Surveiller les modifications et un bouton pour masquer. Configurer mes périphériques automatiquement... lance l'assistant de configuration.
  • Vos périphériques : les périphériques connectés avec leurs images ; un clic ouvre la page Disposition. Un Quelle poignée ? ou Quel modèle ? orange sur un périphérique signifie que JoyPro ne sait pas lequel c'est : un clic dessus ouvre la page Disposition avec le choix ouvert, et votre réponse est gardée.
  • Activité récente par jeu et l'interrupteur de surveillance des jeux ; la carte HUD.
Avancé

#L'assistant d'importation

  1. Choisissez un jeu (Importer sur sa carte).
  2. Choisissez comment : Ajouter à mon profil (recommandé) ou Recommencer à partir de ce jeu, le clavier, les périphériques non branchés, les appareils DCS. Voir d'abord montre ce que le jeu contient dans le panneau Sortie sans rien changer.
  3. Importer maintenant : le résultat reste au-dessus des cartes (« Terminé : votre profil a maintenant 214 relations ») avec Voir mes relations.

Sous les cartes, l'importation experte propose toutes les options par jeu (DCS, IL-2, Star Citizen et tous les autres jeux de Charger les jeux) avec Scan / Import / Export.

Détails techniques

#Derrière la page

MainWindowViewModel.GameHub.cs (cartes, assistant), MainWindowViewModel.Design.cs (tableau de bord), MainWindowViewModel.DbUpdates.cs (listes de commandes), MainWindowViewModel.DeviceCenter.cs (périphériques), MainWindowViewModel.GameSync.cs (surveillance). Moteur : engine games installs, engine db check-updates, engine hud devices, engine sync status, engine dcs import / engine dcs scan et l'importation et le scan des autres jeux.

#Arrête la commande avant qu'elle n'écrive quoi que ce soit (JoyPro ne le propose que pendant la lecture)

Boutonrédigé

JoyPro ne le propose que tant que la commande lit encore, rien n'a donc été écrit quand elle s'arrête.
