Pages de l'interface

Vérifier

Afficher :

Vérifier dans la barre du bas lance la vérification du profil et montre les résultats sur la page Exporter sous Problèmes trouvés par la vérification. Ce que signifie chaque type de carte et comment marchent les corrections : La vérification.

Pour les débutants

#Utiliser la liste

  • La ligne du haut compte les cartes : « À regarder : 0 erreurs, 1 avertissement, 0 remarques ».
  • Recherche trouve des cartes par relation, appareil, bouton et commande.
  • La première liste montre un type (Tous les problèmes, erreurs, avertissements, remarques) ; la deuxième les trie (Par relation, Par appareil, Par jeu, Par certitude).
  • Tout développer / Tout réduire ouvre ou ferme chaque section.
  • Le bouton bleu avec une coche sur une carte est la suggestion de JoyPro ; Plus contient les autres corrections ; Ouvrir '' saute à la relation avec les commandes de la carte marquées.
  • Ignorer sur une carte garde les assignations telles quelles et masque l'avertissement. Il revient tout seul, marqué Nouveau et « Affiché à nouveau : maintenant aussi sur ... », quand la commande arrive sur un bouton de plus. Ainsi, vous parcourez la liste une fois et ensuite vous ne voyez que ce qui est nouveau.
  • Avertissements ignorés (n) (seulement si vous en avez ignoré) liste ceux qui sont masqués avec Afficher à nouveau pour chacun et Tout afficher à nouveau. Taper « ignore list », « hidden » ou « muted » dans la recherche l'ouvre aussi.
Avancé

#En corriger beaucoup d'un coup

Tout corriger avec une règle applique une règle à toutes les cartes d'une section, Corriger avec l'IA prend une consigne en mots simples ; les deux montrent un Aperçu avec une coche par changement, Appliquer la sélection les applique en une seule étape d'annulation. Aussi juste après les importations et les reprises lance automatiquement les corrections sûres après une importation.

#Aussi juste après les importations et les reprises

Case à cocherrédigé

Info-bulle Quand une importation ou une reprise place une action dans une deuxième relation, JoyPro la corrige aussitôt s'il en est au moins aussi sûr ; le reste vous attend ici.

Désactivé par défaut : quand une importation ou une reprise des modifications du jeu met une action dans une seconde relation, JoyPro applique aussitôt sa correction proposée s'il est au moins aussi sûr que l'indique le curseur ; le reste demeure dans la vérification pour vous.

L'avis de l'importation indique combien ont été corrigées.

#Corriger avec l'IA

Bouton basculerédigé

Ouvre la zone Corriger avec l'IA : décrivez en une phrase où vont les actions de « actions activées dans plusieurs relations », par exemple « garder les fonctions de trim dans les relations Trim, tout le reste dans les relations Mode Button ».

JoyPro lit lui-même les phrases simples ; l'IA locale facultative n'aide que pour le reste.
