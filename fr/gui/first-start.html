Configuration du premier démarrage

Afficher :

La fenêtre « Bienvenue dans JoyPro2 : vos jeux » s'ouvre une fois au premier démarrage, après que JoyPro a cherché vos jeux. Elle liste chaque jeu que JoyPro prend en charge, ceux trouvés en premier. Ici, vous indiquez les jeux que vous avez, vous liez un jeu installé là où JoyPro n'a pas cherché, et vous indiquez à JoyPro un autre dossier pour les commandes d'un jeu. La même fenêtre se rouvre depuis Paramètres > Jeux > Relancer la configuration. Le guide pas à pas pour un nouvel utilisateur se trouve sur Premier démarrage.

Dans chaque ligne Ce qui se passe
Décochez J'ai ce jeu JoyPro masque le jeu partout. Vos assignations pour lui restent.
Parcourir... ou .exe... à côté de Installation Ce dossier est le jeu. Pratique pour une copie sur un autre disque.
Parcourir... à côté de Commandes enregistrées dans JoyPro lit et écrit les commandes du jeu à cet endroit.

Puis appuyez sur l'un des trois boutons en bas :

Vous appuyez sur
Et ensuite
Terminé
JoyPro enregistre vos jeux. Au premier démarrage, l'écran de bienvenue demande ce que vous voulez faire.
Terminé, et tout configurer pour moi
JoyPro enregistre vos jeux. Puis la configuration rapide met les fonctions importantes sur votre manche.
Plus tard
Rien ne change. Au premier démarrage, l'écran de bienvenue vient ensuite.
Pour les débutants

#Une ligne par jeu

Chaque ligne a la jaquette du jeu, son nom et un état :

  • Coché, avec un dossier : JoyPro a trouvé le jeu (la ligne dit comment : Steam, un emplacement connu, la liste des applications Windows).
  • Décoché : JoyPro ne l'a pas trouvé. C'est normal si vous ne l'avez pas ; il n'est pas masqué et JoyPro le trouve dès que vous l'installez.

Ce que vous pouvez faire :

  1. Décochez un jeu trouvé que vous n'avez pas ou qui ne vous intéresse pas : il est masqué partout dans JoyPro (cartes de jeux, cartes d'exportation, surveillance, listes de jeux). Vos assignations pour lui restent dans le profil.
  2. Un jeu installé ailleurs (une copie portable, un autre disque) : cochez-le et appuyez sur Parcourir... à côté de Installation pour choisir son dossier, ou sur .exe... pour choisir le programme ou le lanceur du jeu.
  3. Commandes enregistrées dans : certains jeux rangent leurs commandes dans vos dossiers d'utilisateur. Si les vôtres sont ailleurs, par exemple Saved Games\DCS.openbeta au lieu de Saved Games\DCS, appuyez sur Parcourir... à cet endroit.
  4. Appuyez sur Terminé. Plus tard ferme la fenêtre et ne change rien.
  5. Ou appuyez sur Terminé, et tout configurer pour moi : JoyPro enregistre vos jeux et configure votre manche tout seul. Voir Démarrage rapide.
Astuce

Après Terminé, JoyPro crée la liste de commandes de chaque jeu que vous avez à partir de votre propre installation. La page Accueil montre la progression et un avis pour chaque liste encore manquante.

Avancé

#Détails

  • Un dossier lié est vérifié à l'aide des fichiers marqueurs du jeu (bin\DCS.exe, bin\game\Il-2.exe, X4.exe ...) : la ligne dit « Marqueur trouvé », ou « Marqueur introuvable, mais le dossier est conservé tel que vous l'avez choisi ». Un dossier lié compte comme l'installation pour tout (importation, exportation, liste de commandes) et la détection ne le remplace jamais.
  • Utiliser la détection (installation ou configuration) oublie votre lien ; JoyPro détecte de nouveau le jeu.
  • Je ne l'ai pas (le masquer partout) est proposé pour un jeu que JoyPro n'a pas trouvé : sans cela, le jeu reste « non installé » et apparaît tout seul une fois installé ; avec cela, le jeu est masqué comme un jeu trouvé décoché.
  • Les jeux qui gardent leurs commandes dans l'installation (IL-2, Falcon BMS, X-Plane ...) montrent l'emplacement de leur configuration en lecture seule.
  • Les jeux masqués sont listés à la fin de Paramètres > Jeux avec Afficher à nouveau.
Détails techniques

#Derrière la fenêtre

Fenêtre Views/GameSetupWindow.axaml (+ .axaml.cs pour les sélecteurs de dossier, Terminé et Plus tard), modèle de vue MainWindowViewModel.GameSetup.cs, lignes Models/GameSetupItem.cs. La fenêtre s'ouvre une fois quand gameSetupDone n'est pas défini dans ui-settings.json et que la détection au démarrage (engine games installs) a répondu. Terminé lance, pour chaque ligne changée, engine games install set (ou clear), engine games config set (ou clear), puis un seul engine games install disable / enable pour les jeux masqués et affichés, détecte de nouveau, marque la configuration comme faite et lance engine db check-updates pour créer les listes de commandes manquantes. Référence : Installations des jeux.

#Terminé

Boutonrédigé
