Pages de l'interface

Exporter

Afficher :

La page Exporter écrit votre profil dans les jeux. Elle comporte trois étapes numérotées, puis les options pour experts et les sauvegardes de la config des jeux. Tout sur les modes et ce qu'ils font dans chaque jeu se trouve sur Exporter vers vos jeux.

Pour les débutants

#La page de haut en bas

  1. Vérifier votre profil : Vérifier maintenant lance la vérification ; ses cartes apparaissent plus bas.
  2. Comment JoyPro écrit dans les jeux : quatre choix (Remplacer sur mes périphériques, Mettre à jour en gardant les assignations du jeu, Mettre à jour avec mon profil qui l'emporte, Ajouter seulement) et la case Effacer aussi mes autres périphériques.
  3. Exporter vers les jeux : une carte par jeu avec des assignations dans votre profil. Cochez des cartes et appuyez sur Exporter les jeux cochés, ou sur Exporter maintenant sur une carte. Annuler la dernière exportation sur une carte restaure les fichiers de ce jeu.

En dessous : Options et chemins (pour experts), puis Problèmes trouvés par la vérification, Même bouton utilisé deux fois et Sauvegardes de la config du jeu.

Avancé

#Cartes et choix mémorisés

  • Une carte n'est cochée au départ que quand le jeu a des relations assignées et a été lancé une fois (ses fichiers de commandes existent). Une coche que vous changez reste, par profil.
  • La carte DCS a Appareils... : chaque appareil (et couche d'entrée) du profil avec son image et combien de ses relations sont assignées ; seuls les appareils cochés sont écrits (Tous / Aucun).
  • Chaque carte montre son dernier résultat (« Exporté 14:02 » ou l'erreur du moteur).
  • Les jeux non installés n'ont pas de carte ; la page les nomme avec un lien vers Paramètres > Jeux.
  • Aperçu sur une carte (là où il est proposé) lance l'exportation à blanc et montre ce qui changerait.
Détails techniques

#Derrière la page

Modèle de vue : MainWindowViewModel.ExportGames.cs (cartes, exportation, annulation), MainWindowViewModel.ExportDefaults.cs (modes par défaut, marques), MainWindowViewModel.Backups.cs. Moteur : engine profile games remplit les cartes ; engine dcs export, engine il2 export, engine starcitizen export et engine <game> export écrivent ; engine backups list / engine backups restore pour l'annulation et la liste des sauvegardes ; engine profile game-state pour la question « Importer d'abord ? ».

#Effacer aussi mes autres périphériques (dans les appareils exportés, les périphériques sans assignation dans mon profil perdent toutes leurs assignations)

Case à cocherrédigé2 ×

Info-bulle Supprime chaque assignation des périphériques que votre profil n'utilise pas (demande d'abord ; une sauvegarde est faite)

Les périphériques branchés qui n'ont aucune assignation dans votre profil perdent toutes leurs assignations dans les appareils exportés.

Les périphériques non branchés, les périphériques ignorés de l'importation et le périphérique vJoy dans lequel JoyPro transfère les entrées ne sont jamais vidés.

Plus de détails (en anglais)

#MSFS 2024 : écrire dans mes profils MSFS

Case à cocherrédigé

Info-bulle L'exportation place les assignations dans le profil que MSFS 2024 utilise pour chaque périphérique et chaque catégorie (Steam ou Microsoft Store), après une sauvegarde. Désactivé : uniquement des fichiers d'importation.

Microsoft Flight Simulator 2024 uniquement, activé par défaut : l'exportation écrit vos assignations directement dans le profil que MSFS 2024 utilise pour chaque périphérique et chaque catégorie, après une sauvegarde.

La zone sous les cartes indique alors, par périphérique, quel profil les a reçues.

Plus de détails (en anglais)

#MSFS 2024 : fichiers d'importation pour chaque périphérique

Case à cocherrédigé

Info-bulle Désactivé : fichiers d'importation uniquement là où JoyPro n'a pas pu écrire votre profil.

Microsoft Flight Simulator 2024 uniquement, désactivé par défaut : l'exportation écrit aussi un fichier d'importation pour chaque périphérique et chaque catégorie, pas seulement là où JoyPro n'a pas pu écrire votre profil.

Ouvrir le dossier dans la zone MSFS montre les fichiers.

Plus de détails (en anglais)

#Ouvrir le dossier

Boutonrédigé2 ×

Microsoft Flight Simulator 2024 uniquement. Là où JoyPro n'a pas pu écrire votre propre profil MSFS 2024, l'exportation écrit vos assignations dans un fichier par périphérique et par catégorie ; ceci ouvre ce dossier dans l'Explorateur.

Dans le simulateur : Settings > Controls, choisissez le périphérique et la catégorie, la roue dentée de votre profil, Import, puis choisissez le fichier de ce périphérique et de cette catégorie.

#Annuler la dernière exportation

Boutonrédigé

Info-bulle Remet les fichiers de commandes du jeu d'avant la dernière exportation de JoyPro (demande d'abord ; seulement après une exportation de ce jeu)

Remet le jeu dans son état d'avant.

Remet le jeu comme il était avant la dernière exportation : JoyPro restaure la sauvegarde la plus récente de ce jeu ; chaque fichier modifié par la dernière exportation revient octet pour octet, les fichiers qu'elle a créés sont supprimés.

La restauration elle-même est d'abord sauvegardée, elle peut donc aussi être annulée.

#Chemins et périphériques ignorés propres à ce profil

Case à cocherrédigé

Info-bulle Désactivé (par défaut) : les chemins des jeux et les périphériques ignorés appartiennent à ce PC et chaque profil les utilise. Activé : ce profil garde les siens ; un chemin saisi l'emporte toujours sur ce que JoyPro détecte.

Donne au profil ouvert ses propres chemins de jeu et périphériques ignorés au lieu de ceux du PC.

Ouvrir un autre profil rétablit les chemins du PC.

Plus de détails (en anglais)

#DCS : nettoyer aussi mes périphériques dans tous les autres appareils

Case à cocherrédigé

Info-bulle Désactivé (par défaut) : une exportation ne touche que les appareils exportés. Activé : avec Remplacer sur mes périphériques, les périphériques écrits par JoyPro perdent aussi leurs assignations et celles par défaut de DCS dans tous les autres appareils installés.

DCS uniquement, désactivé par défaut : avec Remplacer sur mes périphériques, les périphériques écrits perdent aussi leurs assignations et les valeurs par défaut de DCS dans tous les autres appareils installés, pas seulement dans ceux exportés.

Plus de détails (en anglais)

#SC : garder les défauts du clavier

Case à cocherrédigé

Star Citizen uniquement, activé par défaut : le clavier garde les touches par défaut du jeu.

Désactivé : les assignations clavier du profil sont écrites et les touches par défaut qu'elles occupent sont libérées.

Plus de détails (en anglais)

#SC : préférer l'ordre local

Case à cocherrédigé

Star Citizen uniquement, activé par défaut : un périphérique garde l'emplacement de joystick que le jeu lui a déjà donné dans son propre fichier ; les autres périphériques remplissent les emplacements libres.

Désactivé : les emplacements suivent l'ordre dans lequel Windows signale les périphériques, ce qui peut déplacer toutes les assignations d'un périphérique vers un autre emplacement.
