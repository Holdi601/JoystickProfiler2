Aide et dépannage

Afficher :

D'abord les réponses courtes. Chacune renvoie vers une page avec les étapes.

#Réponses rapides

Mon manche ne fait rien dans ACE COMBAT 8. ACE COMBAT 8 ne connaît qu'une manette Xbox. JoyPro change votre manche en fausse manette (une manette Xbox virtuelle). Lancez d'abord le jeu. À son écran titre, faites Alt+Tab vers JoyPro et appuyez sur Démarrer. Voir Jouer à un jeu uniquement Xbox avec un HOTAS.

Démarrer indique « Trop tôt ». Vous avez appuyé sur Démarrer avant que le jeu ne tourne. Lancez le jeu et attendez son écran titre. Puis maintenez Alt et appuyez sur Tab, cliquez sur Arrêter, puis sur Démarrer. Faites Alt+Tab pour revenir au jeu.

Comment installer ViGEmBus ? Qu'est-ce que la case sous la licence ? ViGEmBus est un programme d'aide gratuit. La fausse manette en a besoin. Sur la page Joystick virtuel, cochez d'abord la case sous la licence : c'est votre accord pour le téléchargement. Puis appuyez sur Installer ViGEmBus. Windows demande l'autorisation : cliquez sur Oui. Vous ne le faites qu'une fois.

La configuration indique « Quelques extras rares n'avaient pas de place ». Est-ce grave ? Non. Votre manche a moins de boutons que le jeu n'a de commandes. Toutes les commandes importantes sont sur votre manche. Modifier quelque chose dans la fenêtre de configuration montre ce qui n'a pas trouvé de place.

Comment changer un bouton plus tard ? Ouvrez Assignations, cliquez sur une commande du jeu dans la liste, cliquez sur Enregistrer l'entrée et appuyez sur le nouveau bouton. Puis renvoyez-la au jeu : Exporter, Exporter les jeux cochés. Voir Changer un bouton plus tard.

Comment annuler la configuration rapide ? Annuler la dernière exportation sur la carte du jeu (page Exporter) remet les anciens boutons du jeu. Ctrl+Z l'annule dans JoyPro. Voir Annuler la configuration rapide.

Mon périphérique n'est pas dans la liste de JoyPro. Il fonctionne quand même. JoyPro le configure comme un modèle habituel de son type : bouger le manche dirige, le bouton 1 tire, le premier chapeau règle le trim, le premier levier est la manette des gaz. Parlez-nous-en sur le Discord, avec le fichier de support. Voir Périphériques pris en charge.

Où voir mes assignations dans le cockpit ? Dans DCS, sur la planchette de genou. Page Disposition, Aide-mémoires, Poser sur la planchette de genou. Voir Voir mes assignations sur la planchette de genou DCS. Sur un second écran, utilisez Où est quoi ? (plus).

Comment retrouver la visite ou l'écran de bienvenue ? Aide en haut à droite > Visites..., ou Paramètres > Visites > Afficher l'écran de bienvenue. Ou double-cliquez sur JoyPro 2 - Tour dans le dossier de JoyPro.

Que sont les Mots simples ? Un grand texte et des phrases très courtes, dans les visites et l'aide. Cochez Mots simples : grand texte, phrases courtes dans l'écran de bienvenue, ou activez-le dans Paramètres > Visites. Voir Mots simples, visites et F1.

Que fait un bouton ? Appuyez sur F1, puis cliquez sur le bouton. Il ne s'exécute pas ; une petite fenêtre l'explique. Appuyez à nouveau sur F1 pour arrêter.

#Un problème est survenu : le fichier de support

Le moyen le plus rapide d'obtenir de l'aide est le fichier de support. Il contient tout ce qu'il faut pour comprendre un problème, pour que personne n'ait à vous demander un second fichier.

Pour les débutants
  1. Ouvrez Paramètres > Signaler un problème.
  2. Décrivez dans Que s'est-il passé ? ce que vous avez fait et ce que vous attendiez.
  3. Laissez Joindre mon profil ouvert et son historique coché (cela aide beaucoup ; décochez-le si vous ne voulez pas partager vos assignations et les noms de vos périphériques).
  4. Appuyez sur Créer le rapport. JoyPro liste ce qui va dans le fichier ; confirmez. Le zip est enregistré dans Documents\JoyPro2\Problem Reports et affiché dans l'Explorateur.
  5. Appuyez sur Ouvrir la page des tickets GitHub et glissez le zip dans le ticket, ou publiez-le sur le Discord.

JoyPro lui-même n'envoie rien en ligne. Votre nom d'utilisateur Windows est remplacé dans chaque texte du fichier.

Avancé

Ce que contient le fichier : summary.txt (versions, système, dossiers, l'environnement des jeux, périphériques branchés, et ce qui a été laissé de côté), les journaux de JoyPro d'au moins les 14 derniers jours (au plus 100 Mo), les rapports de plantage et les dernières erreurs, les fichiers de paramètres et d'état de JoyPro, les périphériques avec l'état de vJoy et de HidHide, pour chaque jeu l'enregistrement de la surveillance, la liste des sauvegardes et le jeu de sauvegardes le plus récent, et avec votre accord le profil ouvert, son historique, les fichiers d'assignations actuels des jeux et les profils de JoyPro 1.

Détails techniques

Le fichier d'assistance est créé par engine support bundle (--list montre le contenu sans rien écrire).

#La surveillance des jeux demande « Reprendre les modifications dans votre profil ? »

Quand vous modifiez des commandes dans un jeu que JoyPro gère, JoyPro demande, après la fermeture du jeu, s'il faut reprendre les modifications dans votre profil. Quand plusieurs relations utilisent ce bouton, il demande à quelle relation appartient la modification, ou s'il faut en créer une nouvelle.

  • Les propres exportations de JoyPro ne déclenchent jamais la question : chaque exportation enregistre les fichiers du jeu.
  • Désactivez-la pour un jeu avec Surveiller les modifications sur la carte du jeu de la page Accueil, ou pour tous les jeux dans Paramètres > Jeux

    Surveiller les configurations des jeux.

  • Pour continuer à surveiller quand JoyPro est fermé : Paramètres > Exécuter en arrière-plan > Démarrer avec Windows (dans la zone de notification).
Détails techniques

Moteur : engine sync status, engine sync diff, engine sync apply, engine sync accept. Détails : surveillance des configurations des jeux.

#Questions courantes

JoyPro 2.7 est-il plus rapide ? Oui, là où vous attendez le plus. Un profil s'ouvre plus tôt. La vérification montre ses premières cartes tout de suite pendant que vous tapez dans sa recherche. La page Accueil examine vos jeux en arrière-plan et ne ralentit jamais la fenêtre. Les clics après une exportation restent rapides, et JoyPro rend de la mémoire quand vous faites une pause. Les commandes de War Thunder se chargent environ cinq fois plus vite, et les jeux dans des chemins de dossier très longs fonctionnent.

Le jeu ne montre pas mes assignations après une exportation. Le jeu était-il fermé pendant l'exportation ? JoyPro refuse d'écrire tant qu'il tourne ; la carte en indique la raison. Certains jeux demandent une étape à part : Falcon BMS crée son fichier de touches quand vous appuyez sur Launch dans son launcher ; dans MSFS, un périphérique peut avoir besoin du préréglage ou du fichier d'importation de JoyPro (voir la page du jeu). Vérifiez le résultat de la carte et le panneau Sortie. La page du jeu sous Jeux liste ses particularités. ACE COMBAT 8 et Hell Let Loose: Vietnam n'ont pas d'exportation : ils utilisent la fausse manette.

Les assignations par défaut du jeu sont encore sur mon périphérique (DCS). Utilisez Remplacer sur mes périphériques avec Effacer aussi mes autres périphériques : les périphériques écrits perdent les réglages par défaut de DCS dans les appareils exportés. Paramètres > DCS : assignations par défaut peut désactiver les réglages par défaut dans l'installation de DCS elle-même.

Je veux retrouver mes anciennes commandes. Page Exporter, la carte du jeu : Annuler la dernière exportation. Cela restaure les fichiers d'avant l'exportation, octet par octet. Sauvegardes plus anciennes : Sauvegardes de la config du jeu en bas de la page Exporter.

Une exportation indique « Non écrit dans le jeu ». Vous avez exporté avec Ajouter seulement, et le jeu utilise déjà ce bouton pour une autre fonction. La vérification a une carte avec Exporter avec 'Mettre à jour' pour le remplacer, Déplacer vers un autre bouton et Laisser tel quel.

Mon manche a un nouvel ID / j'ai remplacé un périphérique. Les importations traitent les périphériques du même nom comme un seul périphérique. Pour déplacer des assignations vers un nouveau périphérique, utilisez Remplacer le périphérique... (Paramètres, les cartes de périphérique de la page Disposition, ou le menu de la page Assignations pour le périphérique de l'assignation sélectionnée).

Un jeu manque. Paramètres > Jeux : Détecter à nouveau, ou Choisir un dossier... pour lier une installation portable. Les jeux que JoyPro ne gère pas encore sont listés sous Jeux pris en charge.

Puis-je annuler une modification dans JoyPro ? Oui : Annuler / Rétablir dans la barre du haut (Ctrl+Z / Ctrl+Y), même après un redémarrage. Historique liste chaque version du profil.

JoyPro est-il sûr avec les anti-triche ? JoyPro ne lit aucune mémoire de jeu et n'injecte rien ; il écrit des fichiers de configuration pendant que le jeu est fermé. Les périphériques virtuels facultatifs (vJoy, ViGEmBus, HidHide) sont des pilotes signés ; un jeu peut quand même refuser les périphériques virtuels. Voir les remarques de chaque jeu sous Jeux pris en charge.
