概要、ライセンス、コミュニティ

表示：

JoyPro は趣味のプロジェクトです。1 人のパイロットが自分のスティックのために始め、ほかのパイロットにも役立つので公開しました。JoyPro 2 は JoyPro 1 の後継で、同じ考え方に新しいプログラムを組み合わせたものです（改善点）。

#ライセンス

JoyPro は GNU General Public License バージョン 3 以降 のもとで提供されるフリー ソフトウェアです（LICENSE）。使用、研究、共有、変更が自由にできます。保証は一切ありません：JoyPro はゲームのファイルに書き込む前に必ずバックアップを作りますが、念のためご自身でもバックアップを取ってください。サードパーティのコンポーネントとそのライセンスは THIRD_PARTY_NOTICES.md に記載されています。

#1 段落でわかるプライバシー

JoyPro にはアカウントもテレメトリーもありません。オンラインに接続するのは、更新の確認（GitHub）、デバイスのメーカーの製品写真（デバイスごとに許可した後のみ）、PC にないゲームのカバー画像（オフにできます）、オプションの AI モデル、設定 > コンポーネント のオプションのドライバー、不足している .NET Framework のインストーラーの場合だけです。問題レポートは PC 上のファイルです。自分でどこかに添付しない限り、何もアップロードされません。詳細：プライバシー。

#ヘルプとコミュニティ

  • Discord：質問、アイデア、テストは discord.gg/yK4gQA9xgk へ。
  • GitHub の Issue：JoystickProfiler2/issues。サポート ファイルを添付してください（方法）。
  • これは余暇のプロジェクトです。できる範囲でサポートしますが、修正や日程の約束はできません。

#貢献する

ソースは GitHub にあります。アイデアや問題は Discord か GitHub の Issue へどうぞ。このウェブサイトはソースから作られているため、現在のバージョンについて説明しています。

技術的な内部情報

ビルドは dotnet build gui/JoyPro.Gui/JoyPro.Gui.csproj、テストは dotnet test gui/JoyPro.Gui.Tests と engine/tests/engine_smoke_test.ps1 です。アーキテクチャの全体図は ARCHITECTURE.md です。このウェブサイトは website/build.py でソースから生成されます。新しいボタンやエンジンコマンドには説明が必要で、ないとサイトの網羅性チェックが失敗します。
