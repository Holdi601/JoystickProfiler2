主な流れ

ゲームをインポート

表示：

インポートは、ゲームが保存した操作設定を読み取り、JoyPro のプロファイルに変換します。機能ごとに 1 つのリレーションと、そのボタンまたは軸です。いちばん早い始め方です。ゲームですでに設定したものがすべて入り、それ以降は JoyPro が 1 か所で管理します。

初心者向け

#3 クリックでインポート

  1. 開始（下部バーの最初のボタン）を開きます。所有ゲーム には、JoyPro が PC で見つけたゲームごとに画像付きのカードがあります。いちばんよく遊ぶゲームで インポート を押します。
  2. JoyPro が 方法 を聞いてきます：
    • プロファイルに追加（推奨） は、今あるものを残してゲームの割り当てを追加します。
    • このゲームから最初からやり直す は、リレーションをゲームの内容で置き換えます（JoyPro は先にプロファイルのコピーを保存します）。
    • キーボードのキーも取り込む で、キーボードの飛行コマンドも取り込みます。デバイスの割り当ては常に取り込みます。
    • DCS の場合：すべての DCS 機体、またはチェックを外して機体を選びます。
  3. 今すぐインポート を押します。少しするとカードに「完了: プロファイルに 214 件のリレーションができました（180 件が割り当て済み）」と表示され、リレーションを表示 で開けます。代わりに 先に確認 を押すと、何も変えずにゲームの内容を表示します。

プロファイルを開いていませんか？ JoyPro が自動で作成し、以後は自動で保存します（保存ボタンはありません。すべての変更は保存され、再起動後も元に戻せます）。

#ゲーム内で何が変わる？

何も変わりません。 インポートはゲームのファイルを読み取るだけです。後でエクスポートするかどうかにかかわらず、ゲームの割り当てはそのまま残ります。

#インポートしてから、JoyPro に空きを埋めてもらう

スタートページの「デバイスをセットアップ」カードには、自分で割り当てをしたゲームが一覧表示されます。インポートしてから空きを埋める は、まずそのゲームをインポートします。次に 今すぐ空きを埋める... で、重要な機能をまだ空いているボタンに割り当てます。自分の割り当てはそのまま残ります。すでにプロファイルにあるゲームには、カードに 空きを埋める... が表示されます。

#最初のインポートの前に：コマンドリスト

JoyPro は各ゲームのコマンド（名前と ID）を知る必要があります。このリストは、あなたのインストールから一度だけ作成します。リストがない場合、スタートページに リスト作成（または 不足リストをすべて作成）が表示されます。ゲームのアップデート後は、ゲームのカードに 更新 が表示されます。数秒から数分かかります（DCS はすべてのモジュールを読みます）。

詳細

#オプションとその働き

オプション 既定 エフェクト
プロファイルに追加 / 最初からやり直す 追加 追加は開いているプロファイルに結合します。最初からやり直す は、確認してプロファイルのコピーを取ったあと、そのリレーションを置き換えます。
キーボードのキーも取り込む 前回の選択 キーに割り当てた飛行コマンドも取り込みます。
接続されていないデバイスもインポート オン 今つながっていないデバイスもインポートします（あとで接続するスティックに便利です）。オフ：読み飛ばして件数を数えます。
同じ名前のデバイスを 1 つのデバイスとして扱う オン Windows はときどきデバイスに新しい ID を付けます。その古いファイルと新しいファイルを、接続中の ID の 1 つのデバイスとして読み込みます。同じデバイスを 2 台同時に接続している場合は、別々のままです。
既定を含める（DCS、上級者向けフォーム） オン インポートしたデバイスで DCS が有効にしているすべての既定の割り当てを取り込みます。こうすると、インポートのあとに「置き換え」+「ほかのデバイスもクリア」でエクスポートしても、DCS は元のままです。同じ入力では、自分の割り当てが既定値より優先されます。
反転 / スライダー / 曲率 / デッドゾーン / 飽和をインポート（上級者向けフォーム） オフ JoyPro 自身がエクスポートしていない割り当てについて、ゲーム内で 設定した値を取り込みます。JoyPro がエクスポートした割り当ては、これらがなくても調整が戻ってきます。
DCS: *_easy 機体を無視 オフ 機体のイージー モード用コピーは除外します。

上級者向けインポート（スタート ページのカードの下と、詳細ページ）では、ゲームごとにエンジンのすべてのオプションを使えて、スキャン（プレビュー）、インポート、エクスポート があります。選択はすべて次回のインポートのために記憶されます。

#名前、グループ、モディファイアが戻ってくる

ゲームのファイルが持っているのは、デバイス、入力、場合によってはカーブだけです。JoyPro のエクスポートはその隣に独自のデータを置き、インポートでそれを読み戻します：

ゲーム JoyPro のデータ 復元されるもの
DCS <aircraft>\joystick\<device>.jp、modifiers.lua リレーション名、グループ（順序どおり）、名前付きのモディファイア、反転、スライダー、デッドゾーン、飽和、カーブ
IL-2 Great Battles data\input\jp.actions 名前、グループ、別名、モディファイア、正確な調整
レジストリのゲーム（X-Plane、Elite、X4、Arma、MSFS、War Thunder、BMS など） <config>.joypro-meta.json 名前、グループ、別名、モディファイア、調整
Star Citizen actionmaps.jp 名前

ゲームの現在の状態が優先されます。エクスポート後に DCS で変えたカーブは保たれます。JoyPro が一度もエクスポートしていない割り当てには、ゲームのアクションから作った名前と、グループ DCS、IL2、または GENERATED + ゲームが付きます。

#2 つの安全装置

  • まだエクスポートしていない変更。 JoyPro で割り当てを変えて、まだこのゲームにエクスポートしていない場合、インポートすると古い割り当てが戻ってきてしまいます。JoyPro は先に確認します。
  • インポート済み？ プロファイルにそのゲームがある場合、あとでゲーム内で行った変更は ゲーム監視 を通じて取り込まれます（ゲームを閉じたあとに確認します）。もう一度インポートするのも 1 クリックのままです。
ゲーム内: ゲームの種類ごとにインポートが読み取るもの

インポートがゲームのフォルダーに書き込むことはありません。読み取るものは次のとおりです：

  • DCS：すべての機体とデバイスの割り当て、モディファイア、そして「既定を含める」では DCS が各デバイスに持つ既定の割り当て。
  • IL-2 Great Battles / Korea：キーマッピングと軸の応答。
  • Star Citizen：ブランチ（LIVE、PTU ...）のキー割り当てと、js1 にあるゲームのジョイスティックの既定。
  • 歩兵や車両があるゲーム（War Thunder、Arma、Reforger、WARDOGS ...）：飛行アクションだけ。それ以外は無視され、削除はされません。
  • MSFS：シム（Steam 版または Microsoft Store 版）の入力プロファイルと、必要に応じてシムの既定のプリセット。

ゲームが区別できないデバイス（一部のゲームでは同じモデルの 2 台）と半軸の割り当て（Elite）は飛ばされ、結果に名前が表示されます。

技術的な内部情報

#内部の仕組み

  1. GUI。 StartImportWizard → RunImportWizardAsync（MainWindowViewModel.GameHub.cs）。AskAboutUnexportedChangesAsync（エンジンの sync pending）で確認し、最初からやり直す を確認してプロファイルのコピーを取り（BackupProfileBeforeChange("before-import")）、そのあとゲームのインポートを呼び出します：ImportDcsAsync、ImportIl2Async、ImportStarCitizenAsync、または ImportRegistryGameAsync。先に確認 は同じ処理を scan で実行し（PreviewImportWizardAsync）、出力パネルを開きます。
  2. エンジン。 DCS の場合：engine dcs import [--path <Saved Games\DCS>] --merge --include-defaults [--plane <a> --plane <b>] --include-keyboard true|false --ignore-easy-planes false --only-connected false --merge-same-name true。インポーターは各デバイスのファイルを読み込み、DirectInput のインスタンス GUID と名前でデバイスを対応付け、すべてのコマンド ID をゲームのコマンド一覧（%LOCALAPPDATA%\JoyPro2\GameData の DB\<game>）に対応付けて、機能と入力ごとに 1 つのリレーションを作ります。読み込み時の補正（--load-corrections、--correction-mode）は、名前の変わったコマンド ID を確信度のスコア付きで割り当て直します。
  3. プロファイル。 リレーションは名前と同じ入力で結合されます。モディファイアは modifiers.lua（DCS）またはゲームのシフト設定から作られます。プロファイルはアトミックに保存され、保存のたびに <data>\ProfileHistory にバージョンが残ります（再起動後も元に戻せます）。
  4. 監視機能。 同期の記録がないゲームをインポートすると、そのゲームのファイルが記録されるため、あとでゲーム内で行った変更が検出されます（<data>\Sync\<game>.json）。

#読み込むファイル

ゲーム ファイル
DCS Saved Games\DCS\Config\Input\<aircraft>\{joystick,keyboard}\*.diff.lua と modifiers.lua、そして JoyPro が DCS のインストールから作ったクリーンなプロファイル
IL-2 Great Battles / Korea data\input\*.actions と軸の応答
Star Citizen そのブランチの actionmaps.xml
MSFS Steam のリモート フォルダー、または Microsoft Store 版のセーブ

GUI のオプションに対応するエンジンのオプション：追加は --merge、キーボードは --include-keyboard true、接続されていないデバイスは --only-connected false、同じ名前は --merge-same-name true、イージー モードの機体は --ignore-easy-planes true。まだエクスポートしていない変更の安全装置は engine sync pending です。

エンジン コマンド：engine dcs import、engine dcs scan、engine il2 import、engine starcitizen import、そしてすべてのレジストリのゲームには engine <game> import（たとえば engine warthunder import、engine msfs2024 import）。再インポートのルール：再インポート。テスト：engine\tests\smoke\dcsincludedefaults.ps1、engine\tests\smoke\roundtrip.ps1、gui\JoyPro.Gui.Tests\ImportSettingsPersistTests.cs。
