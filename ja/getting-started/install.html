はじめに

ダウンロードとインストール

表示：

JoyPro 2 は無料のオープンソース（GPL-3.0）です。アカウントも登録もテレメトリーもありません。

初心者向け

#3 つのステップ

  1. GitHub のリリースページ を開き、JoyPro2-<version>-win-x64.zip をダウンロードします（Assets の下）。
  2. zip を右クリックして すべて展開... を選び、書き込みできるフォルダーを選びます。たとえば C:\JoyPro2 やドキュメント内のフォルダーです。（C:\Program Files は避けてください。JoyPro は自分のフォルダー内で自身を更新します。）
  3. フォルダーを開き、JoyPro.Gui（ジョイスティックのアイコンのプログラム。ファイルの拡張子を表示している場合は JoyPro.Gui.exe）をダブルクリックします。

Windows に Windows によって PC が保護されました と表示されたら？ 詳細情報 をクリックし、次に 実行 をクリックします。Windows は、インターネットからダウンロードしたまだ知らないプログラムについて、一度だけこれを尋ねます。

初回起動時、JoyPro はゲームを探してウィンドウに表示します：初回起動 を参照してください。JoyPro は初めてですか？ そこで 完了してすべて自動で設定 を押し、クイックスタート：スティックを使えるようにする に従ってください。

その後、ようこそ画面で何をしたいかを聞かれ、あなたに合ったツアーが始まります。同じフォルダーにある JoyPro 2 - Tour で、いつでもようこそ画面を開き直せます。大きな文字と短い文がいいですか？ ようこそ画面で やさしいことば: 大きな文字、短い文 にチェックを入れてください（やさしいことば、ツアー、F1）。

#必要なもの

  • Windows 10 または 11（64 ビット）。
  • JoyPro のエンジン用の .NET Framework 4.8。Windows 10 と 11 には最初から入っています。ない場合は、JoyPro が Microsoft のインストーラーを案内します。
  • ほかには何もいりません。zip にすべて入っています（.NET 9 を別途インストールする必要はありません）。

#アップデート

JoyPro は起動時に GitHub で新しいバージョンを確認します（設定：起動時にアップデートを確認）。新しいバージョンがあると、変更内容と 今すぐアップデート / 後で / このバージョンをスキップ のウィンドウが開きます。プロファイルと設定はそのまま残ります。

詳細

#JoyPro がデータを置く場所

プロファイルはドキュメント フォルダーの JoyPro2 にあります。問題レポートもそこに入ります。アップデートで置き換わるのはプログラムのフォルダーだけで、プロファイル、設定、コマンド一覧、バックアップ、履歴はそのまま残ります。フォルダーの完全な一覧は「技術情報」にあります。

#オプションのコンポーネント

設定 > コンポーネント では、仮想ジョイスティック モード用に、vJoy（仮想ジョイスティック）、HidHide（実際のデバイスをゲームから隠す）、ViGEmBus（仮想 Xbox パッド）を、同意のうえでそれぞれワンクリックでインストールできます。設定 > ローカル AI では、アシスタント用のオプションの AI モデルをダウンロードできます。なくてもすべての機能が使えます。

#インターネットへの接続

JoyPro がインターネットに接続するのは次の場合だけです：アップデートの確認（GitHub）、デバイスのメーカーの製品写真（デバイスごとに同意したあとのみ）、PC にないゲームのカバー画像（オフにできます）、オプションの AI モデル、オプションのコンポーネント、不足している .NET Framework のインストーラー。これらのサイトには IP アドレスが見えます。詳細：プライバシー。

技術的な内部情報

#JoyPro のすべてのフォルダー

内容 場所
プログラム 展開したフォルダー（engine\engine.exe、vjoy\、tray\、JoyPro に同梱のデータ DB\ を含む）
プロファイル Documents\JoyPro2（または保存した場所）
設定 %APPDATA%\JoyPro2（ui-settings.json、export-settings.json、hud.json など）
PC で作ったゲームのコマンド一覧 %LOCALAPPDATA%\JoyPro2\GameData
ゲームのファイルのバックアップ %LOCALAPPDATA%\JoyPro2\GameBackups（ゲームごとに最新の 30 個）
プロファイルの履歴（再起動後も元に戻せる） %LOCALAPPDATA%\JoyPro2\ProfileHistory
ログ %LOCALAPPDATA%\JoyPro2\Logs（数日後に自動で削除）
問題レポート Documents\JoyPro2\Problem Reports

#パッケージの中身

  • JoyPro.Gui.exe：Avalonia のアプリ（.NET 9、自己完結型）。
  • JoyPro 2 - Tour.cmd：JoyPro.Gui.exe --welcome を起動し、ツアー付きのようこそ画面を表示します（JoyPro が実行中ならそちらに渡します）。
  • engine\engine.exe：エンジン（.NET Framework 4.8）。GUI は操作のたびにこれを実行します。コンソールで実行することもできます（エンジンのコマンドライン）。
  • vjoy\JoyPro.VJoy.exe（仮想ジョイスティックへの転送）、JoyPro.Ffb.exe（テレメトリによるフォースフィードバック）、tray\JoyPro.Tray.exe（GUI を閉じている間の監視機能）。
  • アップデートはリリースの zip をダウンロードし、公開されている .sha256 ファイルと照合してからインストールします。
  • ソースからのビルド：dotnet build gui/JoyPro.Gui/JoyPro.Gui.csproj（エンジンもビルドします。.NET Framework 4.8 のビルド ツールが必要）。リポジトリの README を参照してください。
