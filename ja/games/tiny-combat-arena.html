Tiny Combat Arena

表示：

Tiny Combat Arena は、すべての機体で 1 組の割り当てを使う空戦フライトゲームです。操作設定は Windows レジストリ（Unity の設定保存先）にあり、デバイスごと、Control Mapper のタブ（Flight、Weapons、Camera、View Select、Map UI、System）ごとに Rewired のジョイスティックマップが 1 つあります。JoyPro はこれらのマップをプロファイルに読み込み、各デバイスの正しいタブに割り当てを書き戻します。

初心者向け

#3 ステップで使えるようにする

  1. すべて自動で設定
    スタート ページで
  2. このボタンを使う
    先に一覧を確認
  3. ゲームに書き込む
    ゲームは閉じたまま

事前に：Tiny Combat Arena を一度起動して Control Mapper を開いてください。その後ゲームを閉じます。

その後：割り当てはゲームの Control Mapper の各タブに入っています。

以前に Tiny Combat Arena でボタンを割り当てていましたか？ それならスタートページに インポートしてから空きを埋める が表示されます。今の割り当てはそのまま残り、空いているボタンだけに新しい役割が付きます。クイックスタート：スティックを使えるようにする を参照してください。

#JoyPro が Tiny Combat Arena に対して行うこと

  • インポート：接続されたデバイスのジョイスティックマップが、すべてのタブからプロファイルに入ります。反転付きの軸、ボタン、ハットの方向、軸上のボタン（たとえば Throttle Up / Down）です。
  • リレーション：1 つのリレーションは、すべての機体で 1 つの機能です。
  • エクスポート：JoyPro は各割り当てをそのタブのマップに書き込み（ピッチは Flight、機銃は Weapons、視点は View Select）、各マップのそれ以外の部分はそのまま残します。

#割り当てをインポート

  1. Tiny Combat Arena を一度起動して Control Mapper を開き（ゲームが接続中の全デバイスのマップを保存します）、ゲームを閉じてください。
  2. 開始 を開き、Tiny Combat Arena のカードの インポート を押してから 今すぐインポート を押します。

#リレーションの作成と確認

ほかのゲームと同じようにリレーションを作ります（リレーションの流れ）。このゲームにはまだ手作りの機能表がないため、セットアップウィザードと自動割り当ては、ゲーム自身の名前とカテゴリから作った表を使います。その後、エクスポートページで 確認 を実行してください。

#Tiny Combat Arena へエクスポート

  1. Tiny Combat Arena を閉じてください。 実行中（プロセス Arena）は JoyPro が書き込みを拒否します。ゲームは Control Mapper で Done を押したときにすべてのマップを保存します。
  2. エクスポート を開き、自分のデバイスで置き換え と ほかのデバイスもクリア のままにして、Tiny Combat Arena のカードの 今すぐエクスポート を押します。
ゲーム内: Tiny Combat Arena での表示

ゲームの Control Mapper を開いてデバイスを選ぶと、割り当てが Flight、Weapons、Camera、View Select、Map UI の各タブに表示されます。マッパーは Rewired の番号で入力に名前を付けます。「Axis 0」は X 軸、ボタン 1 は「Button 0」、最初のハットの上は「Hat 0 Up」と表示されます。マッパーまでのメニューの道順はまだ確認されていません。

#Tiny Combat Arena で自分で行うこと

  • 最初のインポートやエクスポートの前に ゲームを一度起動してください。ゲームがレジストリキーを作成します。最初の起動時に簡単なゲーム設定とヘッドトラッキングについて聞かれます。好きなように答えてください。
  • カーブ：ゲーム自身のジョイスティックとラダーのカーブ、スロットル速度は設定ファイルにあります。ゲーム内で設定してください。JoyPro はこれらを書き込みません。

#よくある落とし穴

  • 「Tiny Combat Arena が実行中です」：ゲームを閉じて、もう一度エクスポートしてください。
  • デバイスが飛ばされる：同じモデルのデバイスを 2 台接続すると、ゲームのマップでは区別できません。JoyPro は警告を出して除外します。
  • Logitech Extreme 3D や T.16000M のツイストやスロットル：ゲームの Rewired がこれらのデバイスを認識し、マップを別のキーに保存します。JoyPro はまだ対応していません。
  • ハットの斜め方向がない：JoyPro が書き込むのはハットの上下左右の 4 方向だけです。
詳細

#JoyPro が読み書きするもの

場所 これは何か
HKCU\Software\TinyCombat\Arena レジストリにあるゲームの Unity 設定。Rewired の値はバイナリー（UTF-8 テキストと 1 バイトのゼロ）で、名前は _h<hash> で終わります
デバイスとタブごとの値で、名前に dataType=ControllerMap とデバイスの hardwareIdentifier を含みます 1 つのデバイスの 1 つのタブのジョイスティック マップ（Rewired XML）。プレイヤー Player 用
<install>\Arena_Data\sharedassets*.assets ゲームの Rewired アクション一覧。読み取り専用で、コマンド一覧に使います
%USERPROFILE%\AppData\LocalLow\TinyCombat\Arena\Settings\Controls.cfg ゲームのカーブとスロットルの速さ：書き込みません

書き込むたびに、その前に JoyPro はプレイヤーのコントローラー マップの値をバックアップ保管場所に保存します。前回のエクスポートを元に戻す はそれを書き戻します。

タブは Rewired のマップ カテゴリーです：0 System、3 Flight、8 Weapons、11 Camera、4 View Select、9 Map UI。各アクションは、そのアクション カテゴリーのタブに入ります（Flight Control は Flight、Weapon Control は Weapons、Camera Control は Camera、View Control は View Select、Map Control は Map UI、Default は System）。

#Tiny Combat Arena でのエクスポート モード

Tiny Combat Arena は飛行だけのゲームなので、割り当て可能なアクションはすべて JoyPro の管理対象になります。

モード デバイスのマップで起きること
追加のみ ゲームの内容は何も変わりません。入力がすでに別のアクション（または軸の反対側）を動かしている割り当ては除外され、一覧に表示されます。
更新（ゲームの割り当てを優先） 別のアクションに割り当てた入力にあるアクションは、その入力を失います。そのアクションのほかの入力は残ります。
更新（プロファイルを優先） 上記に加え、割り当てたすべてのアクションは、JoyPro が読み込める接続中のデバイスで、ほかの入力を外されます。
自分のデバイスで置き換え 書き込んだデバイスのほかの割り当て可能なアクションは、すべてのタブで解除されます。
+ ほかのデバイスもクリア 接続中のほかのデバイス（モデルごとに 1 台）は、それらのアクションを失います。保存済みマップのないデバイスには空のマップが作られますが、ゲームは未知のデバイスに既定の割り当てを付けないため、ゲーム内では何も変わりません。

#一切変更しないもの

  • プレイヤーが割り当てられないアクション（メニュー操作といくつかの固定アクション）。
  • キーボードとマウスのマップ、キャリブレーションのマップ、入力の動作、コントローラーの割り当て先、ゲームの設定ファイル。
  • 接続されていないデバイス、同じモデルが 2 台以上あるデバイス、インポートで無視したデバイス、JoyPro が入力を送り込む vJoy デバイス。

#適用範囲、カーブ、その他

  • 適用範囲：全体共通で、すべての機体に 1 セットの割り当てです。
  • 軸カーブ：書き込みません（ゲームのカーブは Controls.cfg にあります）。
  • キーボードとモディファイア：書き込みません。
  • フォースフィードバック、テレメトリ：なし。
  • 監視機能：ゲームのキーに対するレジストリの変更通知を使います（監視機能）。
  • HUD：HUD はプロセス（Arena）からゲームを見つけます。
技術的な内部情報

#Tiny Combat Arena 連携の内部

コード：engine\Games\TinyCombatArenaIntegration.cs（レジストリ キー、プレイヤー名、タブ、カタログの構成）が、engine\Games\RewiredMapIntegration.cs（Rewired のジョイスティック マップの読み書き。Nuclear Option と共通）の上に乗っています。

  • デバイス：未知のデバイスは hardwareGuid がゼロで、hardwareIdentifier = WindowsRawInput + 空白を除いた HID の製品文字列 + PID + VID になります。キーは HID の製品名と VID/PID から作られるため、エクスポートにはデバイスの接続が必要です。
  • 要素：軸 X、Y、Z、Rx、Ry、Rz が 0 ～ 5、ボタン n が 31 + n、ハット h（1 から数える）の Up / Right / Down / Left が 160 + 4(h-1) + 0 ～ 3 です。マッパーはボタン要素に axisRange 1 を書き込みます。JoyPro も 1 を書き込み、ボタンの比較ではこれを無視します。
  • コマンド一覧：engine tinycombatarena refresh-db は、最初に解析できた Arena_Data\sharedassets*.assets から Rewired の InputManager を読み込みます。プレイヤーが割り当てられないアクションは除外し、軸アクションにはゲームの名前を付けた片側ごとの行を加えます（DB\TinyCombatArena\actions.tsv）。
  • コマンド：engine tinycombatarena paths、engine tinycombatarena catalog、engine tinycombatarena scan、engine tinycombatarena import、engine tinycombatarena export（短い名前は engine tca）。元に戻すのは engine backups restore です。

#既知の制限

  • ゲームの Rewired が認識するデバイス（hardwareGuid がゼロでないもの）は扱いません。
  • ハットの斜め方向とキーボードの割り当ては書き込みません。
  • テスト：engine\tests\smoke\tinycombatarena.ps1。ゲーム内では tools\e2e\games\TinyCombatArenaSettings.ps1（ランダムな vJoy 軸に割り当てた Pitch、Roll、Yaw、2 つのボタン、ハットの 1 方向が Flight、Weapons、View Select のタブに表示され、ゲーム終了後のインポートですべて読み戻せること）。
