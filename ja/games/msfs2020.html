初心者向け

#3 ステップで使えるようにする

  1. すべて自動で設定
    スタート ページで
  2. このボタンを使う
    先に一覧を確認
  3. ゲームに書き込む
    シムは閉じたまま

事前準備：シム内（Settings > Controls）で、デバイスごとにプロファイルを一度作成します。JoyPro が書き込むのは Steam 版だけです。Microsoft Store 版はインポートのみできます。

その後：シムを起動します。割り当ては、すべての機体で Settings > Controls にあります。

以前に MSFS 2020 でボタンを割り当てたことがありますか？ その場合、スタート ページに インポートしてから空きを埋める が表示されます。今の割り当てはそのまま残り、空いているボタンにだけ新しい役割が付きます。クイック スタート：スティックを使えるようにする を参照してください。

#JoyPro が MSFS 2020 で行うこと

  • インポート：接続中の各デバイスのプロファイル（Steam 版または Microsoft Store 版）を取り込みます。飛行の割り当て、General の割り当て（カメラ、視点、一時停止）、Sensitivity ページの軸設定が対象です。
  • リレーション：1 つのリレーションは 1 つの機能です。MSFS 2020 のプロファイルはデバイスごとに 1 つなので、リレーションはすべての機体に適用されます。
  • エクスポート：JoyPro は Steam 版の remote フォルダーにあるデバイス プロファイルを編集します。シムは次の起動時にそれを読み込みます。

#MSFS 2020 の割り当てをインポート

  1. スタート を開き、Microsoft Flight Simulator 2020 のカードの インポート を押します。
  2. 接続されていないデバイスもインポート（オフ）：MSFS はこれまでに認識したすべてのデバイスのプロファイルを保存しています。オフなら、今接続しているデバイスだけが対象です。シミュレーターが使っていない可能性のある既定のプリセットもインポート（オフ）は、独自のプロファイルがないデバイスについて、シムに付属するプリセットを追加します。シムがそれを使っているか分からない場合も追加します。
  3. 今すぐインポート を押します。プロファイルを変えずにシムの内容を見たい場合は 先に確認 を押します。

#リレーションの作成と確認

ほかのゲームと同じように リレーション ページでリレーションを作り（リレーションの流れ を参照）、エクスポート ページで 確認 を実行します。ここでは、飛行機のスロットルとヘリコプターのコレクティブが同じ軸にあってもエラーとは報告されません。MSFS 2020 には機体別の一覧がないためです。

#MSFS 2020 へのエクスポート

  1. MSFS 2020 を閉じます。 シムの実行中は JoyPro が書き込みを拒否します。
  2. エクスポート を開き、JoyPro でデバイスを設定しているなら 自分のデバイスで置き換え と ほかのデバイスもクリア のまま、MSFS 2020 のカードの 今すぐエクスポート を押します。
  3. シムを起動します。remote フォルダーは Steam Cloud のフォルダーなので、変更したファイルは Steam が同期します。
ゲーム内: MSFS 2020 での表示

Settings > Controls を開いてデバイスを選びます。割り当ては、デバイスのプロファイルにシムのアクション名で表示されます。デバイスの Sensitivity ページには、JoyPro が書き込んだ軸のカーブが表示されます。同じプロファイルがすべての機体で使われます。

#MSFS 2020 で自分で行うこと

  • シム内でデバイスごとにプロファイルを一度作成します（Settings > Controls）。JoyPro は既存のプロファイルを編集するだけです。プロファイルのないデバイスについては、エクスポートで「create one in the sim first」と表示されます。
  • Microsoft Store 版：JoyPro はプロファイルをインポートできますが、書き込めません。エクスポートには Steam 版を使うか、シム内で割り当ててください。
  • 機体を限定したリレーション：MSFS 2020 では機体ごとに分けられません。スタート ページの その他のゲーム フォームで エクスポートする機体 を使うと、1 機体に限定したリレーションもすべての機体向けにエクスポートされます。

#よくある落とし穴

  • 「MSFS 2020 が実行中です」：シムを閉じて、もう一度エクスポートします。
  • シムに古い割り当てが表示される：Steam Cloud が古いコピーを戻しました。シムを閉じて、もう一度エクスポートしてください。
  • 1 台のデバイスに複数のプロファイルがある：JoyPro は その他のゲーム フォームの ゲームのプロファイル で選んだもの、またはプロファイルが 1 つだけならそれを使います。それ以外の場合、そのデバイスはスキップされ、プロファイル名を挙げた警告が表示されます。
  • 割り当てがない：1 つのアクションが持てる入力の組み合わせは最大 2 つ（Primary と Secondary）です。3 つ目は報告されて除外されます。
詳細

#JoyPro が読み書きするファイル

ファイル これは何か
<Steam>\userdata\<id>\1250410\remote\inputprofile_<n> 1 つのデバイスプロファイル。拡張子なしの XML で、その場で書き換えます（先に .jpbak にバックアップ）
<Steam>\userdata\<id>\1250410\remote\profile_00 デバイスプロファイルについてのシムのバイナリの索引：読み取り専用、書き込みません
%LOCALAPPDATA%\Packages\Microsoft.FlightSimulator_8wekyb3d8bbwe\SystemAppData\wgs\<user>\ Microsoft Store 版のセーブ：読み取り専用（インポートとスキャン）
<install>\Input\*.xml、fs-base\en-US.locPak シムに同梱のプリセットとメニュー名：読み取り専用
%LOCALAPPDATA%\JoyPro2\Ownership\MSFS、...\Backups\MSFS JoyPro の所有データとバックアップ。Steam のフォルダーには置きません

Steam の remote フォルダーは Steam Cloud のフォルダーです。編集するのは既存の inputprofile_* ファイルだけです：シムの profile_00 が特定のファイルを指定しているため、新しいファイルは読み込まれません。

#MSFS 2020 のエクスポートモード

モード デバイスプロファイルで起きること
追加のみ 割り当ては、その入力の組み合わせに別のアクションがないプロファイルにだけ書き込まれます。そうでなければ「Binds Not Written, Button Taken In The Game」に一覧表示されます。何も削除されません。
更新（ゲームの割り当てを優先） あなたの組み合わせにある別のアクションはそれを失います。それ以外はすべて残り、アクションの古い組み合わせも残ります。
更新（プロファイルを優先） 上と同じで、さらに割り当てるすべてのアクションが、接続済みデバイスのプロファイルにある他の組み合わせを失います。
自分のデバイスで置き換え JoyPro が割り当てる接続済みデバイスのプロファイルには、あなたの割り当てだけが残ります。
+ ほかのデバイスもクリア プロファイルに割り当てのない接続済みデバイスのプロファイルを空にします。

#一切変更しないもの

  • メニュー、ワールドマップ、開発者用のコンテキスト（MENU、MENU_*、WORLDMAP_*、DEBUG、DEVMODE*、EDITOR_*、MISSION_FLOW_TOOLS）。どのモードでも変更しません。
  • キーボード、マウス、ゲームパッドのプロファイル（GUID="{0}"）：MSFS ではキーボードの割り当てを書き込みません。
  • 接続されていないデバイスのプロファイル、profile_00、Store 版のセーブ、インポートで無視したデバイス、JoyPro が転送先にしている vJoy デバイス。

#カーブとその他

  • 単位：デバイスごとに 1 つのプロファイルで、すべての機体に共通です。
  • 軸カーブ：デバイスの Sensitivity ページ。物理軸ごとに 1 セット：Sensitivity + と -、Neutral、Dead zone、Extremity dead zone、Reactivity、カーブなしのフラグ、反転。MSFS 2020 にはアクションごとの上書きがないため、それを求めるリレーションにはデバイスのページの値が使われ、警告が出ます。カーブのプレビューはシムと一致します（MSFS 2020 で測定）。チューニングの範囲 family:msfs は両方のシムをカバーします。axis-curves を参照してください。
  • フォースフィードバック：MSFS には独自のものがありません。
  • テレメトリ記録：SimConnect 経由で読み取り専用。シムのインストールフォルダーにある SimConnect.dll（または MSFS SDK のもの）を使います。JoyPro には同梱していません。
  • HUD：HUD はプロセス（FlightSimulator）からシムを見つけ、その割り当てを表示します。
  • 監視：JoyPro は inputprofile_* ファイルと Store 版のセーブの containers.index を監視し、シムの終了後に尋ねます（監視）。

#MSFS 2024 との違い

MSFS 2020 MSFS 2024
エクスポート先 Steam のプロファイルをその場で 自分のプロファイル（Steam と Store）、JoyPro のプリセットパッケージ、インポート用ファイル
Microsoft Store 版 インポートのみ インポートと書き込み
プロファイル デバイスごとに 1 つ デバイスとカテゴリーごと。機体ごとに選択
機体を限定したリレーション エクスポートする機体 使用時のみ（その場合はすべての機体向け） その機体のプロファイルに書き込み
プロファイル内のアクション一覧 割り当て済みのアクションのみ そのコンテキストのすべてのアクション
アクションごとの軸の上書き なし あり
技術的な内部情報

#MSFS 2020 連携の内部

コード：engine\Games\MsfsIntegration.cs（両方のシムで 1 つのクラス、sim == 2020）、MsfsProfileFile.cs（行単位のエディター）、MsfsUserProfiles.cs（Steam と Store の読み取り）、MsfsSimDefaults.cs、MsfsGameData.cs、MsfsAircraft.cs、engine\AxisModels\Msfs.cs。

  • 形式：XML フラグメント（フラグメントとして読み取り）：<Version>、<FriendlyName>、<Device DeviceName GUID ProductID>、<Axis AxisName AxisSensitivy AxisDeadZone ...> を含む <Axes>（属性名のつづり間違いはシムのものです）、<Context ContextName> / <Action ActionName Flag> / <Primary> / <Secondary> / <KEY Information>code</KEY>。解除したアクションは削除されます。新しいアクションは、フォルダー内の他のプロファイルで使われているコンテキストに入り、なければコマンド一覧のコンテキスト、それもなければ PLANE に入ります（警告あり）。
  • デバイス：GUID は DirectInput のインスタンス GUID なので、読み取りにデバイスの接続は不要です。ProductID は 10 進の USB プロダクト ID です。コード：ボタン N = N-1、ハット 256-259、軸 1026/1042/1058、770/786/802、スライダー 514/530。組み合わせの最後の KEY がメインの入力で、同じデバイスの他のボタンはモディファイアです。
  • コマンド一覧：engine msfs2020 refresh-db は、シムのプリセット（<install>\Input、公式パッケージ）と、en-US.locPak に名前のあるすべての飛行イベントを読み取ります。一覧の元は MSFS 2024 のものと共通です。
  • コマンド：engine msfs2020 paths、engine msfs2020 catalog、engine msfs2020 scan、engine msfs2020 import（--game-profile、--include-disconnected、--include-sim-defaults）、engine msfs2020 export（--mode、--nuke-untouched-devices、--dry-run、--aircraft <key>）。元に戻すには engine backups restore。
  • 古いプロファイル：JoyPro に MSFS のゲームが 1 つしかなかった頃に保存したプロファイル（MSFS:<action>）は、読み込むと各シムにノードが作られます。

#既知の制限

  • Microsoft Store 版は読み取り専用です。そのセーブフォルダーをパスにしたエクスポートは拒否されます。
  • 新しい inputprofile_* ファイルは作成しません。デバイスには、シムで作ったプロファイルが必要です。
  • Steam Cloud が古いプロファイルを戻してしまうことがあります。
  • 半分の軸、ハットの斜め、2 つ目のハットは読み書きしません。組み合わせはアクションごとに最大 2 つです。
  • MSFS 2020 に同梱のプリセットは実際のインストールで確認していないため、2020 のプリセットを既定値とみなすには、デバイス名も含まれている必要があります。
  • テスト：engine\tests\smoke\msfs.ps1（Sensitivity ページ、上書き、フラグ、競合、マージ）。シム内では tools\e2e\games\MsfsCurves.ps1（割り当て、Sensitivity ページ、飛行中のボタンと軸カーブを SimConnect で読み戻して確認）。
