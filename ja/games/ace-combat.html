初心者向け

#3 ステップで使えるようにする

#ACE COMBAT 8

  1. すべて自動で設定
    次に このボタンを使う
  2. 仮のコントローラーを設定
    次に テスト
  3. ゲームを起動
    タイトル画面で Alt+Tab、開始

#ACE COMBAT 7

  1. ゲームを一度起動
    そのあと終了
  2. すべて自動で設定
    次に このボタンを使う
  3. ゲームに書き込む
    ゲームは閉じたまま

#ACE COMBAT 8：最初に一度だけ設定

  1. スタート ページで すべて自動で設定 を押します。または、ようこそ画面で フライトスティックで ACE COMBAT を遊ぶ を選ぶと、短いツアーですべての手順を案内します。
  2. どのボタンに何が入るかの一覧を確認し、このボタンを使う を押します。
  3. 仮のコントローラーを設定 を押します。セットアップ画面が閉じ、仮想ジョイスティック ページが開きます。
  4. 仮のコントローラーには、ViGEmBus という無料の補助プログラムが必要です。ライセンスの下にあるチェックボックスをオンにし、ViGEmBus をインストール を押します。Windows が許可を求めたら はい をクリックします。これは一度だけで済みます。
  5. テスト を押します。スティックを動かすと、コントローラーの画像も一緒に動きます。ボタンを押すと、そのボタンが光ります。

切り替えは必要ありません。ACE COMBAT 8 は自動で仮のコントローラーを使います。ページには「On the Xbox pad by itself: the game reads only Xbox controllers」と表示されます。このゲームでは HidHide も不要です。どのみち本物のスティックはゲームから見えないからです。

#ACE COMBAT 8：プレイするたびに

  1. ACE COMBAT 8 を起動し、タイトル画面が表示されるまで待ちます。
  2. Alt を押したまま Tab を押します。JoyPro に戻ります。
  3. 開始 を押します。
  4. もう一度 Alt+Tab を押すと、ゲームに戻ります。さあ、飛びましょう！
  5. 遊び終わったら 停止 を押します。
開始はゲームの起動後に

開始 は、ゲームがタイトル画面を表示してから押してください。早すぎると JoyPro に「早すぎます」と表示されます。その場合は 停止 を押してから 開始 を押します。これはプレイするたびに行います。

#ACE COMBAT 8 の割り当て一覧

HOTAS 側 仮のコントローラー側 ゲーム内
スティックの前後左右 左スティック ピッチとロール
スロットル レバー 前：RT。後ろ：LT。 加速と減速
スティックのひねり（またはペダル） LB と RB（約 30 % から） 左右のヨー
スティックの空いているハット 右スティック 周囲を見回す
フレア ボタン L3 と R3 の同時押し フレア（ゲーム内で未確認）
通信スイッチまたは AI メニュー用ハット 十字キー 僚機への指示
「High-G」という名前のボタン用リレーション 両トリガーを最後まで High-G ターン

仮想ジョイスティック ページの ライブ テスト タブに、各ボタンの役割が「A: Fire machine gun」のように表示されます。

フレアはゲーム内で未確認

JoyPro はフレアのために L3 と R3 を同時に押します。これがゲーム内で動くことはまだ誰も確認していません。JoyPro でもそのように表示されます。

#ハットで周囲を見回す

ゲームは仮のコントローラーの右スティックで周囲を見回します。JoyPro はこれをスティックの空いているハットに割り当てます。ハットをある方向に押し続けると、視点がその方向に回ります。多くの場合、スティック上部のハットが使われます。そのハットは、ほかのゲームでは元の役割（たとえば DCS のトリム）のままです。ヘッド トラッキングと見回し を参照してください。

#ACE COMBAT 7：手早く設定

  1. すべてのデバイスを接続した状態で ACE COMBAT 7 を一度起動 し、終了します。ゲームは終了時に Input.ini を書き出します。
  2. スタート ページで すべて自動で設定 を押します。一覧を確認し、このボタンを使う を押します。
  3. ゲームを閉じます。 ゲームに書き込む を押します。JoyPro は古いファイルのコピーを保存します。

以前に ACE COMBAT 7 でボタンを割り当てたことがありますか？ その場合、スタート ページに インポートしてから空きを埋める が表示されます。今の割り当てはそのまま残り、空いているボタンにだけ新しい役割が付きます。

#ACE COMBAT 7：自分の割り当てをインポート

  1. すべてのデバイスを接続した状態で ACE COMBAT 7 を一度起動 し、終了します。
  2. スタート を開きます。このファイルができるまでは、JoyPro は独自に用意した 20 個の飛行アクションの一覧を使います。カードの 更新 を押すと、ファイルから一覧を作成します。
  3. ACE COMBAT 7 カードの インポート を押し、プロファイルに追加（推奨） のまま 今すぐインポート を押します。

#リレーションの作成と確認

1 つのリレーションに、同じ機能の ACE COMBAT 7 のアクションと ACE COMBAT 8 のアクションをまとめられます。そうすると、両方のゲームが 1 つのボタンでその機能を使えます（リレーションの流れ）。確認では、ACE COMBAT 7 で 1 つのボタンが 2 つの役割を持っている箇所を見つけます。下部バーの 確認 か、エクスポート ページの 今すぐ確認 を押します（確認）。

#エクスポート

  • ACE COMBAT 7：ゲームを閉じて エクスポート を開き、自分のデバイスで置き換え と ほかのデバイスもクリア をオンのまま、カードの 今すぐエクスポート を押します。
  • ACE COMBAT 8：エクスポートしても何も書き込まず、その旨が表示されます。割り当ては、開始 がオンの間、仮のコントローラーを通じてゲームに届きます。
ゲーム内: ACE COMBAT での表示

ACE COMBAT 8 には Xbox コントローラーが 1 台見えます。メニューにはパッドのボタンが表示され、SYSTEM > CONTROLS > CONTROLLER > BUTTON MAPPING には変更できる 9 つのアクション（左右のヨー、加速、減速、機銃発射、ミサイル発射、武装切り替え、ターゲット切り替え、レーダー マップ）とそのパッド ボタンが表示されます。スティックは、パッドの左スティックと同じようにメニューのフォーカスを動かします。

ACE COMBAT 7 には、フライトスティックの割り当てを変更するメニューがありません。割り当ては Input.ini から読み込まれます。操作設定メニューにそれが表示されるかどうかは、まだ確認されていません。JoyPro のゲーム内テストでは、ゲームが終了時にファイルを書き直しても、JoyPro が書き込んだ値がすべて残ることを確認しました。

#自分で行うこと

  • ACE COMBAT 8：プレイするたびに、タイトル画面で 開始 を押します（上記参照）。
  • ACE COMBAT 8：BUTTON MAPPING でパッドのボタンを変更したら、ゲームのカードの 更新 を押します。次に、仮想ジョイスティック ページで マッピングを更新 を押します。これで JoyPro が新しいボタンに合わせます。
  • ACE COMBAT 7：各デバイスを接続した状態で、ゲームを一度起動します。ファイルにセクションがないデバイスは「start the game once with this device connected」と表示されてスキップされます。このゲームでは Steam Input をオフにしてください。

#よくある落とし穴

  • ACE COMBAT 8 が反応しない：開始 を早く押しすぎていませんか？ タイトル画面で 停止、次に 開始 を押します。
  • ACE COMBAT 8：機首が逆方向に動く：ゲームで「Pitch Controls: Inverted」に設定していませんか？ 「詳細」レベルを参照してください。
  • ACE COMBAT 8：ViGEmBus がない：ViGEmBus がないと、ゲームからスティックが見えません。仮想ジョイスティック ページでインストールしてください。
  • ACE COMBAT 7：軸が半分の位置で止まる：このゲームは、1 つのアクションをすべてのデバイスで平均します。スロットルが 100 %、同じアクションを割り当てたスライダーが -100 % なら、結果は 50 % になります。各軸のアクションは 1 台のデバイスだけに割り当ててください（更新（プロファイルを優先） でほかのデバイスの割り当てを消せます）。
  • ACE COMBAT 7：同じモデルのスティックが 2 本 あると、1 つのセクションを共有します。ゲームは両者を区別できません。

詳しくは：Xbox 専用ゲームを HOTAS で遊ぶ。

詳細

#仮のコントローラーの仕組み

  • HidHide は不要。 ACE COMBAT 8 は Xbox コントローラーしか読み取らないため、実際のスティックはゲームから見えません。何も隠す必要がなく、Windows が管理者権限を求めることもありません。HidHide は vJoy に設定したゲームでのみ使います。
  • モードは自動で切り替わります。 モードを選んでいない間、このゲームは Xbox パッドを使います。仮想ジョイスティック ページで別のモードを選ぶと、JoyPro はその選択を保持します。
  • ゲームのレイアウトが優先：ACE COMBAT 8 のアクションに付いたリレーションは、ゲームがそのアクションに使うパッドの操作に固定されます（ゲームのセーブから読み取ります）。ピッチとロールは左スティック、周囲を見る操作は右スティックに入ります。
  • スロットル：スロットルレバーで両方のトリガーを操作します。前に倒すと RT、後ろに引くと LT、中央はニュートラルです。「減速」が別のリレーション（トーブレーキなど）にある場合でも機能します。
  • ヨー：スティックのひねり（なければラダーペダル）を約 30 % 倒すと、LB または RB が押されます。
  • 周囲を見る：視点アクションに軸がない場合、空いているハットで右スティックを操作します（「Hat to axes」）。各方向を押している間はスティックを端まで倒した状態になり、斜めでは両方が動きます。JoyPro は、別のゲームの視点（look/view）リレーションが使うハットを使い、なければスティックの一番上のハットを使います。視点アクションに空いているミニスティックがあれば、常にそちらが優先されます。
  • フレア：フレアまたはカウンターメジャーのリレーションから、L3 と R3 を同時に 120 ms 押します。ゲーム内ではまだ確認されていません。
  • 僚機への指示 は、通信スイッチまたは AI メニューのハットから D パッドに送られます。
  • 高 G ターン：「High-G」という名前のボタンのリレーションで、両方のトリガーを押し続けます。DCS の ASC Direct Control（Su-27、Su-33、J-11A の「コブラボタン」）を持つリレーションも同様です。トリガーに割り当てたスロットルはそのまま機能します。
  • 1 つの入力に 1 つの役割：これらの機能のどれかを動かす入力はテーブルから外されるため、2 つの操作を同時に押すことはありません。
  • カーブはパッドにも届きます。 軸の応答（割り当て ページ）のデッドゾーン、飽和、カーブ、反転は、パッドのスティックやトリガーにも適用されます。専用のカーブを使うには、適用先 で ACE COMBAT 8 だけにチェックを入れます。そうでなければ 既定のカーブ が使われます。
  • ピッチ：DCS の反転設定はパッドには届きません。既定では、スティックを前に倒すと機首下げになります。ゲームで「Pitch Controls: Inverted」にしている場合は、ACE COMBAT 8 だけ反転のチェックを外してください（軸の応答、適用先：ACE COMBAT 8）。
  • ロールが逆になる：JoyPro はロールをそのまま渡します。ロールのリレーションで、ACE COMBAT 8 だけ反転にチェックを入れてください。
  • パッド（スティック 2 本、トリガー 2 つ、ボタン 14 個、D パッド）に 収まらないもの は、仮想ジョイスティック ページに一覧表示されます。
  • 複数のゲームでパッドを使う：ACE COMBAT 7 と 8 はどちらもパッドを使え、それぞれ専用のテーブルを持ちます。自動開始では、実行中のゲームのテーブルが有効になります。そうでなければ 「開始」と「テスト」のXbox パッドテーブル で選びます。
  • 自動開始 は、ゲームの起動から約 3 秒以内、タイトル画面より前にパッドを作ります。このゲームではそれが早すぎることがあります。その場合はタイトル画面で 停止、次に 開始 を押してください。
  • 上級者向け：vJoy、HidHide、転送レート、各モードは 上級者向けの詳細を表示（vJoy、HidHide、モード） にあります。
  • ACE COMBAT Zero は ACE COMBAT 8 のフォルダー内に同梱されています（ACZero\acz.exe）。調査はしていません。試すには、ACE COMBAT 8 の 開始 を手動で押してから Zero を起動します。未テストです。

#JoyPro が読み書きするファイル

ファイル これは何か
%LOCALAPPDATA%\BANDAI NAMCO Entertainment\ACE COMBAT 7\Config\Input.ini ACE COMBAT 7：[JoystickSetting] と、デバイスのモデルごとに 1 つの [Joystick-<product GUID>] セクション（ProductName= とすべての Flight_* および UI_* キーを含む）
...\ACE COMBAT 7\Config\Input.ini.joypro-meta.json エクスポートした割り当てについての JoyPro のデータ（名前、グループ）。次回のインポートで使います
%LOCALAPPDATA%\BANDAI NAMCO Entertainment\ACE COMBAT 8\Saved\SaveGames\System.sav ACE COMBAT 8：ゲームで設定したパッドのキー。読み取り専用

#ACE COMBAT 7 のエクスポートモード

アクションとデバイスごとに 1 つの入力。メニューキー（UI_*）と、JoyPro が読み取らない組み合わせは変更しません。

モード どうなるか
追加のみ そのデバイスで既に値があるアクションはその値を保ちます。ゲームが別のアクションに使っている入力への割り当ては書き込まれず、「ゲームに書き込まれていません」の印が付きます。
更新（ゲームの割り当てを優先） プロファイルの値を書き込みます。同じ入力にある別のアクションは解除されます。そのアクションの他のデバイスでの値は残ります（ゲームが平均化する軸は報告されます）。
更新（プロファイルを優先） 上と同じで、さらにプロファイルが割り当てるすべてのアクションを、接続されている他のデバイスから消去します。
自分のデバイスで置き換え JoyPro が書き込むセクションには、読み取れる値のうちあなたの値だけが残ります。書き込んだ軸は、これまでどおり接続されている他のデバイスから消去されます。
+ ほかのデバイスもクリア 接続されている他のデバイスの、読み取れる値を消去します。

Input.ini のコメント、順序、エンコード、改行コードはそのまま残ります。ACE COMBAT 8 にはエクスポートモードがなく、何も書き込みません。

#一切変更しないもの

  • ACE COMBAT 7：キーボード、メニューキー、組み合わせ、接続されていないデバイスのセクション、インポートで無視したデバイス、JoyPro が転送先にしている vJoy デバイス。
  • ACE COMBAT 8：ゲームのすべてのファイル、および HidHide。

#軸、監視、HUD

  • ACE COMBAT 7：グローバルな割り当て（機体ごとのプロファイルなし）。反転のみ（:R）で、カーブやデッドゾーンはありません。ゲームはデバイスごとに最大 32 個のボタン、8 本の軸、4 方向のハット 4 つを読み取ります。モディファイアはありません。
  • 監視：ACE COMBAT 7 の Input.ini はゲーム終了後に監視されます（監視）。ACE COMBAT 8 には JoyPro が書き込むものがないため、監視するものもありません。
  • HUD：ゲームの実行中、HUD が押したボタンごとにそのアクション名を表示します。
  • どちらのゲームにもフォースフィードバックとテレメトリーはありません。
技術的な内部情報

#ACE COMBAT 連携の内部

コード：engine\Games\AceCombat7Integration.cs、engine\Games\AceCombat8Integration.cs。virtual-joystick のパッドプランナーとフォワーダー、パッド独自の機能は engine\VJoy\XboxPadAutoSetup.cs にあります。

  • ACE COMBAT 7 のセクション：Joystick- + DirectInput のプロダクト GUID（PID の上位ワード + VID、続いて 504944564944、つまり「PIDVID」）。オブジェクトは X Y Z Rx Ry Rz Slider1 Slider2、Button1-Button32、POV_U/D/L/R1-4。オプションは :P / :N（半分）、:R（反転）、:C（-1..1 を 0..1 として扱う）。組み合わせは &、!、+、>、<。空の値は未割り当てです。JoyPro は軸を X や Y:R、ボタンを ButtonN、ハットの方向を POV_<U|D|L|R><n> として書き込みます。組み合わせと半分の軸はインポート時に報告されますが、読み込まれません。
  • ACE COMBAT 7 のアクション：軸は Flight_Pitch/Roll/Yaw/Throttle/CameraPitch/CameraYaw、ボタンは Flight_Gun/Missile/Target/Weapon/Radar/Flare/View/AccelerationDeceleration/AutoPilot/Pause と Flight_HatSwitchUp/Down/Left/Right。engine ac7 refresh-db は Flight_* キーをあなたのファイルから取得します。
  • ACE COMBAT 8：System.sav は Checksum 付きの Unreal GVAS です。9 つのゲームパッドキーを Unreal のキー名で保持しています（YawLeftKey_Controller = Gamepad_LeftShoulder ...）。engine ac8 refresh-db はそれらを読み取り、操作ごとに 1 つの Pad_* アクションにして、キーを一覧の 5 列目に入れます。スティックは JoyPro 独自のテーブルから取ります。
  • パッドモード：このゲームは MaxJoysticks 0 と推奨モード xbox を宣言しているため、保存された選択がなければモードは xbox になります（VJoySettings.ModeOf）。engine vjoy mode AceCombat8 xbox で選択を保存します。engine vjoy map、engine vjoy forwarder-config --xbox-game AceCombat8。HidHide の手順はありません。仮想モードにこうしたゲームしかない場合、engine vjoy apply-hidhide は「HidHide is not needed」と表示し、管理者権限では何も起動しません。
  • パッドの機能：スロットルの分割（XB_TRIGGERS）、ヨー（「Axis ends to buttons」、端のゾーン 0.35）、フレアの同時押し（IGamePadChords.PadChords、Confirmed = false）、D パッド、High-G の押し続け（PadHolds）、視点ハット（hat-axes、IGamePadConventions.PadLookActions = Pad_CameraYaw / Pad_CameraPitch）は、プランのたびに作り直されます。Pad_Pitch は既定で反転です（PadInvertDefault）。
  • 確認：engine vjoy pad-check は、プロファイルがパッドで何に届くか（ピッチ、ロール、機銃、ミサイル、ターゲット、スロットル分割、ヨー、同時押し、押し続け、D パッド、視点）をスコア付きで報告します。
  • コマンド：engine ac7 paths、engine ac7 scan、engine ac7 import、engine ac7 export。engine ac8 scan、engine ac8 import、engine ac8 export（何も書き込みません）。

#既知の制限

  • ACE COMBAT 7：操作メニューにスティックの割り当てが表示されるかどうか、およびピッチに :R、スロットルに :C を付けた状態での飛行は、まだ確認されていません。
  • ACE COMBAT 8：フレアの同時押し（L3 + R3）と視点ボタンは、ゲーム内でまだ確認されていません。
  • ACE COMBAT 8：パッドなしで動くのは、ゲーム自体が対応している少数のスティック（Thrustmaster と HORI の各 1 モデル）だけです。JoyPro はそれらの設定を書き込みません。
  • テスト：engine\tests\smoke\acecombat7.ps1、acecombat8.ps1。ゲーム内では tools\e2e\games\AceCombat7Settings.ps1（エクスポート、起動、書き換えたファイルにすべての値が残っていること、インポート）と AceCombat8Xbox.ps1（仮想パッドでのメニュー。パッドはタイトル画面が表示されてから作成）。
