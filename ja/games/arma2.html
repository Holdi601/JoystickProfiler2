Arma 2 と Operation Arrowhead

表示：

初心者向け

#3 ステップで使えるようにする

  1. すべて自動で設定
    スタート ページで
  2. このボタンを使う
    先に一覧を確認
  3. ゲームに書き込む
    ゲームは閉じたまま

事前準備：すべてのデバイスを接続した状態でゲームを一度起動します。Options > Controls > Controllers を開き、終了します。遊ぶゲームが 2 つなら、両方でこれを行います。

その後：割り当ては Options > Controls にあります。

以前に Arma 2 でボタンを割り当てたことがありますか？ その場合、スタート ページに インポートしてから空きを埋める が表示されます。今の割り当てはそのまま残り、空いているボタンにだけ新しい役割が付きます。クイック スタート：スティックを使えるようにする を参照してください。

#JoyPro が Arma 2 で行うこと

  • インポート：スティック、スロットル、ペダルにある航空機とヘリコプターの割り当てを、各軸の感度スライダーごとプロファイルに取り込みます。
  • リレーション：1 つのリレーションは、すべてのゲームで 1 つの機能です。Arma 2 と Operation Arrowhead は別々のゲームとして入るので、1 つのリレーションに両方を含められます。
  • エクスポート：JoyPro は飛行アクションのキー行だけを書き換えます。キーボードとマウスの割り当ては、それらのアクションのものも含めてそのまま残ります。

#Arma 2 の割り当てをインポート

  1. スタート を開きます。Arma 2 または Operation Arrowhead のカードがコマンド リストを求めたら、リスト作成 を押します。JoyPro はゲームのファイルからアクションとその英語名を読み取ります（読み取りのみ、事前の起動は不要）。
  2. 遊んでいるゲームのカードで インポート を押し、プロファイルに追加 のままにします。
  3. 今すぐインポート を押します。リレーションを表示 で取り込んだ内容を開けます。

JoyPro が管理するのはジョイスティックだけです。キーボードの割り当てはインポートもエクスポートもされません。また、Arma 2 にはモディファイア付きのジョイスティック ボタンという仕組みがありません。

#リレーションの作成と確認

リレーションの流れ で各ゲームの同じ機能をまとめ、エクスポート ページで 確認 を押します。エクスポートではヘリコプターと飛行機を別の乗り物として扱うため、両方で同じボタンを使っても競合にはなりません。武器と視点のアクションは両方に共通として扱われます。

#Arma 2 へのエクスポート

  1. ゲームを閉じます。 Arma 2 はプロファイルを自分で保存するため、起動中は JoyPro が書き込みを拒否します。
  2. エクスポート を開き、Arma 2 または Operation Arrowhead のカードにチェックを入れます。
  3. JoyPro でスティックを設定しているなら、自分のデバイスで置き換え と ほかのデバイスもクリア をオンのままにします。カードの 今すぐエクスポート を押します。
ゲーム内: Arma 2 での表示

ゲームを起動し、メイン メニューで Options > Controls を開きます。割り当ては航空機とヘリコプターのアクションに、キーボードのキーと並んで表示されます。Controllers にはデバイスが一覧表示され、有効になっています。デバイスの Customize では、JoyPro が設定した各軸の感度スライダーを確認できます。

#Arma 2 で自分で行うこと

  • すべてのデバイスを接続した状態でゲームを一度起動 し、Options > Controls > Controllers を開きます。ゲームはデバイスを初めて認識したときに一覧へ追加します。一覧にないデバイスには JoyPro は書き込めず、そのデバイスを接続してゲームを一度起動するよう案内します。
  • ゲームで無効のままになっているデバイスは、割り当てがあればエクスポート時に有効になります（エクスポートでその旨が表示されます）。
  • 両方のゲームを遊ぶなら、それぞれを一度ずつ起動してください。どちらにも独自のプロファイル ファイルとデバイス一覧があります。

#よくある落とし穴

  • 「ゲームが実行中です」：Arma 2 または Operation Arrowhead を終了し、もう一度エクスポートします。
  • ペダルやスロットルで武器が発射されたり視点が動いたりする：ゲームはデバイスを初めて認識したとき、ペダルやスロットルも含め、ジョイスティックの既定の割り当て（X 軸でバンク、Y 軸で機首、ハットで視点、いくつかのボタン）をすべて追加します。自分のデバイスで置き換え でこれらを削除できます。
  • 33 番以降のボタンや 2 つ目のハットが効かない：Arma 2 が読み取るのはボタン 32 個、軸 8 本、最初のハットだけです。それを超える割り当ては JoyPro がスキップします。
  • USB ポートを変えたらデバイスがスキップされた：ゲームは新しい ID を新しいデバイスとして扱います。そのデバイスを接続した状態でゲームを一度起動してください。
  • Arma 2 単体：スロットルがレバーの半分でしか効かない：Operation Arrowhead のない Arma 2 では、レバーの両半分を 1 つのアクションにまとめられません。
詳細

#JoyPro が読み書きするファイル

ファイル これは何か
%USERPROFILE%\Documents\ArmA 2\<name>.ArmA2OAProfile Operation Arrowhead（および Combined Operations、DayZ mod）：key<Action>[]={...}; の行、class JoysticksList とその他のオプション
%USERPROFILE%\Documents\ArmA 2\<name>.ArmA2Profile Arma 2 単体。形式は同じです
%USERPROFILE%\Documents\ArmA 2 Other Profiles\<name>\<name>.<ext> あなたの他のプロファイル（Arma 3 と違ってダッシュなし）
<profile>.joypro-meta.json 書き込んだ割り当ての JoyPro の名前、グループ、チューニング。次回のインポートで読み戻されます
<profile>.jpbak 最初の書き込み前のコピーと、JoyPro のバージョン管理されたバックアップ保存領域

JoyPro は <name>.vars.<ext> やビデオ設定の ArmA2.cfg / ArmA2OA.cfg には一切触れず、プロファイルがバイナリ（rapified）ファイルの場合は処理を中止します。それ以外のバイトはすべてそのまま残ります：改行コード、先頭のタブ、行の順序。コマンド一覧にあるキーの行が見つからない場合は、最後のキーの行の後に追加します（行がないのは「ゲームの既定値」という意味です）。

#Arma 2 のエクスポートモード

変わるのは、コマンド一覧にある航空機とヘリコプターのアクションの行だけです。キーボード、マウス、TrackIR、Xbox パッドのコードと、キーボードの組み合わせは常にそのまま残ります。

モード プロファイルで起きること
追加のみ 何も削除されません。同じ乗り物の別のアクションが既に持っているコードへの割り当ては書き込まれず、「ゲームに書き込まれていません」の印が付きます。
更新（ゲームの割り当てを優先） あなたのコードが入ります。あなたが別の場所に割り当てた、同じ乗り物の別のアクションのコードは削除されます。そのアクションの他のコードは残ります。
更新（プロファイルを優先） 上と同じで、さらに割り当てたアクションから、接続されたジョイスティックの他のジョイスティックコードが削除されます。
自分のデバイスで置き換え 飛行用の行からは、書き込むデバイスの他のコードもすべて削除されます。ゲームが自動で設定した既定値も含みます。
+ ほかのデバイスもクリア 接続されている他のジョイスティックのコードにも同じことを行います。接続されていないジョイスティックはコードを保ちます。

#一切変更しないもの

  • 歩兵、乗り物、メニューの行と、コマンド一覧にある飛行アクション以外のすべての行。
  • キーボード、マウス、TrackIR、Xbox パッドのコード。
  • 接続されていないジョイスティック、番号の範囲に一覧のデバイスがないコード、インポートで無視したデバイス、JoyPro が転送先にしている vJoy デバイス。
  • デバイスの一覧：JoyPro はエントリを追加せず、既存のエントリの sensitivity[] とモードだけを変更します。joystickSensitivity[]、コントローラーのスキーム、マウスと TrackIR の設定は残ります。

#乗り物、カーブ、設定

  • 単位：すべての航空機とヘリコプターで 1 セットの割り当て。ゲームごと（Arma 2、Operation Arrowhead）です。
  • 軸は半分ずつ：Arma 2 では、軸の半分ずつをそれぞれアクションに割り当てます。JoyPro の軸のリレーションは両方を書き込みます：ピッチ（機首下げ / 機首上げ）、ロール（左 / 右バンク）、ラダー（左 / 右ペダル）、アーケード旋回、推力の増減（推力を上げる / 下げる）、視点とズーム。
  • スロットル：「Thrust (Analogue)」は飛行機のスロットルとヘリコプターの絶対コレクティブ、「Brake (Analogue)」はエアブレーキです。Operation Arrowhead では、JoyPro はレバーの両半分をそのアクションに入れ（先に負の半分、反転時は先に正の半分）、ゲームがそれを 1 本の完全な軸にまとめます。Arma 2 単体では半分だけです。
  • 感度：デバイスと物理軸ごとに 1 つのスライダー（Customize ダイアログ、-1 ～ 1）で、10 のスライダー値乗として保存されます。すべての乗り物に共通です。JoyPro が書き込むのは、Arma 2 / Operation Arrowhead（または両方、family:arma2）用にあなたが設定した値か、インポートで取り込んだ値だけです。1 本の軸にある 2 つのリレーションの値が食い違う場合は、名前順で最初のものが使われ、警告が出ます。
  • デッドゾーン：メインの軸では 7 % 固定（スライダーにはなし）。ゲーム内で調整できないため、書き込みません。
  • 反転：半分の順序（スロットルを参照）か、反対側の半分で行います。反転フラグはありません。
  • 設定：デバイスごとのオン/オフ（モード Custom または Disable）。Arma 2 には JoyPro が書き込むゲーム全体のオプションがなく、フォースフィードバックやテレメトリーもありません。
  • 監視：ゲーム内で変更した割り当てやスライダーはゲーム終了後に検出され、JoyPro がそれを取り込むかどうかを尋ねます。
  • HUD：HUD はプロセスからゲームを見つけ、割り当てを表示します。
技術的な内部情報

#Arma 2 連携の内部

コード：Arma 3 と共通の Arma プロファイルのコード（ArmaProfileIntegration.cs、ArmaGameData.cs）の上にある engine\Games\Arma2Integration.cs と、軸モデル engine\AxisModels\Arma2.cs（ゲーム Arma2 と Arma2OA）。

  • デバイス：class JoysticksList { class Joystick1 { guid="..."; name="..."; offset=256; isXInput=0; mode="Custom"; }; }。guid は DirectInput の インスタンス GUID（大文字、波かっこなし）、name は製品名です。新しいデバイスには最大の offset + 256 が付きます。エントリは残るため、デバイスの offset は変わりません。クラス名 Joystick1..N は保存のたびに振り直されるため、JoyPro は guid だけで照合します。mode は "Custom"、"Scheme"（Xbox パッドのスキーム）、"Disable" のいずれかです。sensitivity[]（16 個の値）は、ゲームの Customize ダイアログを確定した後にだけ現れます。値が既定値と異なる場合、JoyPro は isXInput の後にそれを作成します。
  • コード：ボタンは 0x20000 + offset + b（b は 0 ～ 31）。軸の半分は正が 0x30000 + offset + a、負が + a + 8（X、Y、Z、RotX、RotY、RotZ、Slider 1、Slider 2）。最初のハットは 0x40000 + offset + direction（8 方向）。インポートでは保存された軸全体のコードも読み取りますが、エクスポートでは書き込みません。
  • コマンド一覧：engine arma2oa refresh-db は Expansion\dta\bin.pbo から、engine arma2 refresh-db は Dta\bin.pbo から CfgDefaultKeysMapping を読み取り、languagecore.pbo の英語のメニュー名も使います。MOD が定義するものはプロファイルから追加されます。アクション数は Operation Arrowhead が 68、Arma 2 が 66 です。engine arma2oa catalog、engine arma2oa paths、engine arma2 catalog、engine arma2 paths。
  • インポート / エクスポート：engine arma2oa import、engine arma2oa scan、engine arma2oa export。engine arma2 import、engine arma2 scan、engine arma2 export（--mode clean|add|merge|merge-overwrite --nuke-untouched-devices --ignore-device <d> --dry-run）。
  • デバイスのスイッチ：engine ffb set --device "<name> {GUID}" --game Arma2|Arma2OA --param enabled=0|1（engine ffb set）。

#既知の制限

  • ゲームがどちらのスライダー方向を「より敏感」としているかは、まだ確認されていません。
  • Arma 2 にはジョイスティックの組み合わせ（モディファイア付きのボタン）がないため、JoyPro は書き込みません。
  • Arma 2 単体には、1 つのアクションで使う軸全体がありません。レバーの半分だけでヘリコプターのコレクティブがどう感じられるかは、まだ確認されていません。Operation Arrowhead での軸全体の方向も、実際の初回起動後に確認する必要があります。
  • テスト：engine\tests\smoke\arma.ps1（感度、ファミリーの範囲、デバイスのスイッチ）。ゲーム内では tools\e2e\games\Arma2Settings.ps1 -Game arma2oa|arma2（テスト用プロファイル JoyProE2E_OA / JoyProE2E_A2、メインメニュー > Options > Controls のみ）。
