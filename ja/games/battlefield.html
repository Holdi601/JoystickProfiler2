Battlefield

表示：

Battlefield 6 と Battlefield 2042 が読み取るジョイスティックは 1 つ だけで、割り当てにはデバイス名が含まれません。そのため、複数のデバイスからなる HOTAS は JoyPro の 仮想ジョイスティック を通じてのみ使えます。JoyPro は Battlefield のリレーションで使うすべての入力を 1 つの vJoy デバイスにまとめ、HidHide で本物のデバイスをゲームから隠します。ゲームのテキスト プロファイルにはジェット機とヘリコプターの割り当てが入っています。現在 JoyPro はそのキーボード キーを書き込み、ジョイスティックの割り当ては読み取るだけです。ジョイスティックの割り当ての書き込みは、ゲームのジョイスティック番号の付け方を一度確実に調べてからになります。旧作の Battlefield は情報の記載のみです。

初心者向け

#3 ステップで使えるようにする

  1. すべて自動で設定
    次に このボタンを使う
  2. 使用する
    次にゲームより先に 開始
  3. ゲームで vJoy を割り当てる
    ジョイスティック ページで
  1. スタート ページで すべて自動で設定 を押します。一覧を確認し、このボタンを使う を押します。JoyPro がジェット機とヘリコプター用のボタンを選びます。
  2. 仮想ジョイスティック ページを開きます。vJoy と HidHide がなければ、そこでインストールします。Battlefield の横にある 使用する を押します。ゲームを起動する前に 開始 を押します。
  3. ゲーム内でジョイスティック ページを開きます。行の欄をクリックしてから、ボタンを押します。ゲームには「vJoy Device」というジョイスティックが 1 つ見えます。

JoyPro はまだ Battlefield のジョイスティックの割り当てを書き込みません。そのため、手順 3 はご自身で行います。詳しくは以下を参照してください。

#JoyPro が Battlefield で行うこと

  • ゲーム用にデバイスを 1 つに：仮想モードでは、スティック、スロットル、ペダルが Battlefield からは 1 つの vJoy ジョイスティックに見え、本物のデバイスの入力は動かなくなります。ほかのプログラムからは、引き続き本物のデバイスが見えます。
  • キーボード キー：キーボードも対象にすると指定した場合、JoyPro はジェット機とヘリコプターのボタン アクションのキーボード キーを読み書きします。
  • ジョイスティックの割り当て：JoyPro は（警告付きで）読み取りますが、まだ書き込みません。ゲームのジョイスティック入力の番号の付け方が確認されていないためです。確認されるまでは、ゲームのジョイスティック ページで vJoy デバイスをご自身で割り当ててください。

#インポート

  1. ゲームを一度起動 して、設定プロファイルを書き出させます。それまでは、JoyPro は独自に用意したジェット機とヘリコプターのアクション表を一覧に使います。最初のインポートで、それがプロファイルのアクションに置き換わります。
  2. スタート を開き、Battlefield 6（または 2042）のカードの インポート を押します。キーボードのキーも必要なら キーボードのキーも取り込む にチェックを入れ、今すぐインポート を押します。

#仮想ジョイスティックの設定

  1. 仮想ジョイスティック ページを開きます。このページに必要なもの で、vJoy と HidHide がなければインストールします。
  2. ゲーム で Battlefield 6 を vJoy に切り替えます（JoyPro はそこで 使用する として提案します）。
  3. ページに 表に合わせて vJoy を設定 が表示されたら押してください。Battlefield は Rx / Ry 軸のあるジョイスティックを Xbox パッドとみなすため、JoyPro は Rx 軸と Ry 軸のない vJoy デバイスを設定します。vJoy に変更を反映するには Windows の再起動が必要です。
  4. ゲームを起動する前に 開始 を押し、遊び終わったら 停止 を押します。

#リレーションの作成と確認

リレーション ページで、HOTAS を Battlefield のジェット機とヘリコプターのアクションに割り当てます（リレーションの流れ）。vJoy デバイスに場所が割り当てられるのは、Battlefield のアクションを持つリレーションの入力だけです。ジェット機とヘリコプターは別の乗り物なので、同じボタンでそれぞれ別の操作をさせてもかまいません。

#エクスポート

  1. ゲームを閉じます。
  2. エクスポート を開き、自分のデバイスで置き換え のまま、Battlefield のカードの 今すぐエクスポート を押します。インポート時にキーボードにチェックを入れていれば、キーボード キーが書き込まれます（この選択はゲームごとに保存されます）。ジョイスティックの割り当ては「書き込まれていない」と表示されます。
  3. そのあと ゲームを一度起動 して割り当てを確認してください。Steam Cloud と EA は設定フォルダーを同期するので、クラウドのコピーが優先されることがあります。
ゲーム内: Battlefield での表示

仮想ジョイスティックの実行中は、ゲームに見えるジョイスティックは「vJoy Device」の 1 つだけです。Battlefield 6 では、航空機の行は歯車アイコン > CONTROLLER > EDIT SETTINGS > JOYSTICK > Aircraft EDIT（「AIRCRAFT PILOT CONTROL MAPPING」）にあります。各行には UNBOUND または割り当て（たとえば「AXIS 1 X -」）が表示されます。JoyPro が書き込んだキーボード キーは、ゲームのキーボード割り当てに表示されます。

#Battlefield で自分で行うこと

  • 上記のジョイスティック ページで ゲーム内で vJoy デバイスを割り当てます。行の欄をクリックしてから、入力を動かします。ゲームは最初に認識した入力を割り当てるため、ゲームから見えるのは vJoy だけにしておく必要があります（仮想ジョイスティックを実行中）。
  • このゲームでは Steam Input をオフにします。
  • それでもゲームに本物のデバイスが見える場合は（HidHide で隠したデバイスが Battlefield 6 に見えるという報告もあります）、プレイ中はそのデバイスを取り外してください。すべての入力は vJoy デバイスが受け持ちます。

#よくある落とし穴

  • ゲームにジョイスティック ページがない：ジョイスティックに Rx 軸または Ry 軸があり、ゲームが Xbox パッドとみなしています。これらの軸なしで vJoy を設定し（上記の手順 3）、Windows を再起動してください。
  • 行に揺れている軸が割り当てられる：ほかのデバイスがまだゲームから見えています。仮想ジョイスティックをゲームより先に開始するか、本物のデバイスを取り外してください。
  • 1 台のデバイスしかエクスポートされなかった：ゲームが読み取るジョイスティックは 1 つです。JoyPro は割り当てが最も多いデバイスを書き込み、それ以外は一覧で表示します（「use the virtual joystick」）。

#仮想ジョイスティックの仕組み

#JoyPro が読み書きするファイル

ゲーム ファイル これは何か
Battlefield 6 %USERPROFILE%\Documents\Battlefield 6\settings\steam\PROFSAVEbf6mp_profile と PROFSAVE_profile マルチプレイヤーとキャンペーンのプロファイル。テキストの行 GstKeyBinding.<category>.<Concept>.<slot>.axis <n>（.button、.negate、.type も）。EA app 版には steam フォルダーがありません
Battlefield 2042 %USERPROFILE%\Documents\Battlefield 2042\settings\PROFSAVE_profile 同じ形式

エクスポートでは、割り当てを持つフォルダー内のすべての *_profile に書き込むため、キャンペーンとマルチプレイヤーの内容が一致します。_profile の付かないバイナリの PROFSAVE ファイルには割り当てがなく、一切触れません。バックアップは他のエクスポートと同じ（.jpbak と JoyPro のバックアップ保存領域）で、JoyPro の名前とグループは <profile>.joypro-meta.json に入ります。

#Battlefield のエクスポートモード

変わるのはジェット機とヘリコプターのスロットだけです。兵士と地上車両のスロット、マウスとパッドのスロット、軸アクションのキー、JoyPro の対応表が読み取らないジョイスティックのコードは決して変わりません。

モード どうなるか
追加のみ 同じ乗り物の別のアクションが使っている入力への割り当てはスキップされ（「ゲームに書き込まれていません」の印が付きます）、スロットは空けられません。
更新（ゲームの割り当てを優先） プロファイルの入力にある別のアクションのスロットが空けられます。そのアクションの割り当て済みスロットは残ります。空きスロットが見つからない割り当ては書き込まれません。
更新（プロファイルを優先） 上と同じで、さらにそのアクションの他のスロット（キーボードのオプション使用時はキー）も空けられます。割り当て済みのスロットにはプロファイルの入力が入ります。
自分のデバイスで置き換え エクスポートが書き込むものの飛行用スロットが空けられます：キーをエクスポートする場合はキーボードのキー（ジョイスティックの割り当てが書き込まれるようになればジョイスティックも）。
+ ほかのデバイスもクリア 空にする他のデバイスはありません：ゲームはジョイスティックを 1 台しか読み取りません。

#一切変更しないもの

  • 歩兵、地上車両、輸送、ガンナーの割り当て。マウスとパッドのスロット。
  • 軸アクションのキーボードのキー（その組はゲームが管理します）と、キーボードのオプションを使わない場合のキーボードのキー。
  • ジョイスティックのスロット（番号の付け方が確認されるまで）。
  • HidHide が実際のデバイスを隠すのは、ゲームの実行ファイルからだけ、仮想ジョイスティックの動作中だけです。停止 で HidHide は以前の設定に正確に戻ります。

#軸とその他の設定

  • 乗り物の種類ごと：ゲームのプロファイルではジェット機とヘリコプターが別のカテゴリーです。JoyPro は両方に書き込みます。
  • 反転 のみ：軸は 2 つの半分として書き込まれ、反転 でそれが入れ替わります。カーブ、デッドゾーン、モディファイアはありません。
  • ハット：4 方向のみで、斜めはスキップされます。プレイヤーの報告では約 18 個のボタンが使えます。それ以上は確認されていません。
  • 監視：プロファイルファイルはゲーム終了後に監視されます（監視）。
  • HUD：ゲームの実行中、HUD が押したボタンごとにそのアクション名を表示します。
  • 仮想機能（トグル、軸の帯、短押し / 長押し ...）は、Battlefield 用の vJoy デバイスで動作します。

技術的な内部情報

#Battlefield 連携の内部

コード：engine\Games\BattlefieldIntegration.cs（Battlefield 6 と 2042 で 1 つのクラス）。virtual-joystick の vJoy プランナー、フォワーダー、HidHide セッション。

  • 割り当ての行：type は 0 がマウス、1 がパッド、2 がキーボード（button = DIK スキャンコード、255 = なし）、3 がジョイスティック。「何も割り当てられていない」は軸 56（Battlefield 6）または 27（2042）とボタン 60 です。negate 1 = そのスロットがアクションを負の方向に動かします。既定のプロファイルには、軸アクションごとに空のジョイスティックスロットが 2 つ（negate 0 と 1）あります。ボタンのアクションには、4 行を並び順の位置に入れたスロット n+1 が付きます。
  • デバイス：割り当てにはデバイス名がありません。JoyPro はジョイスティック 1 台分を書き込みます。このゲームは自身を 1 デバイスのゲーム（ジョイスティック 1 台、推奨モード virtual、vJoy の Rx と Ry 軸を避ける）と宣言しているため、プランナーは Rx / Ry に入力を割り当てず、engine vjoy configure-vjoy はそれらの軸なしでデバイスを設定します。
  • ジョイスティックの番号付け：Battlefield 4 の解読済みの方式から取った暫定の対応表です（X / Y は Axis1X / Axis1Y、Z / Rx / Ry / Rz は半分の軸のボタンコード 36-43、ボタン n はコード n-1、ハット n は 44 + 4(n-1) + 方向）。ゲーム独自の既定値はこれに合わないため、確認済みの対応表がない場合、JoyPro はジョイスティックの割り当てを警告付きで読み取り、何も書き込みません。実機での調査スクリプト tools\e2e\games\BattlefieldJoystickSurvey.ps1 が、確認済みの対応表 <engine>\TOOLS\Conversions\Battlefield6JoystickMap.tsv（Battlefield2042JoystickMap.tsv）を作ります。
  • コマンド：engine bf6 paths、engine bf6 catalog、engine bf6 scan、engine bf6 import、engine bf6 export --include-keyboard --mode clean|add|merge|merge-overwrite --dry-run、engine bf6 refresh-db。engine bf2042 export とその仲間も同様です。仮想モード：engine vjoy mode Battlefield6 virtual、engine vjoy map、engine vjoy apply-hidhide。

#既知の制限

  • ジョイスティックの割り当ては、調査で番号付けが確認されるまで書き込まれません。
  • Battlefield 2042 は、ゲームをインストールせずに同じ形式をもとに実装しています。
  • 約 18 個を超えるボタンと、半分の軸が軸全体として保存されるかどうかは、まだ確認されていません。
  • テスト：engine\tests\smoke\battlefield.ps1。調査スクリプト tools\e2e\games\BattlefieldJoystickSurvey.ps1、BattlefieldSurveyAuto.ps1、BattlefieldAdminSession.ps1（vJoy の設定のために Windows を再起動できる時間が必要）。
