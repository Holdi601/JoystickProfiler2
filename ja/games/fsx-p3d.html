FSX と Prepar3D

表示：

FSX、FSX: Steam Edition、Prepar3D v4、v5、v6 は、操作設定を %APPDATA% にある 1 つの XML ファイルに保存します。デバイスごとに軸、ボタン、ハットを含むマップが 1 つあり、さらにキーボードの設定があります。JoyPro はこのファイルをプロファイルに読み込み、リレーションでほかのゲームとまとめ、ブロック単位で書き戻します。書式、コメント、ほかのマップはそのまま残ります。シムごとにファイルが別なので、JoyPro ではそれぞれが別のゲームです。

この連携は公開情報をもとに作成したもので、テストは合成したテスト ファイルでしか行っていません。どのシムも、実際のインストール環境で JoyPro とのテストはまだです。最初のエクスポートのあと、シムの操作設定を開いて割り当てを確認し、違いがあればぜひ報告してください。

初心者向け

#3 ステップで使えるようにする

  1. すべて自動で設定
    スタート ページで
  2. このボタンを使う
    先に一覧を確認
  3. ゲームに書き込む
    シムは閉じたまま

事前準備：デバイスを接続した状態でシムを一度起動し、閉じます。

その後：シムの操作設定を開いて割り当てを確認します。この連携は実際のインストール環境ではまだテストしていません。違いがあれば報告してください。

以前にシムでボタンを割り当てたことがありますか？ その場合、スタート ページに インポートしてから空きを埋める が表示されます。今の割り当てはそのまま残り、空いているボタンにだけ新しい役割が付きます。クイック スタート：スティックを使えるようにする を参照してください。

#JoyPro が FSX と Prepar3D で行うこと

  • インポート：デバイスの軸、ボタン、ハットを、各軸の感度とヌル ゾーンごとプロファイルに取り込みます。キーボードのキーは、指定した場合に取り込みます。
  • リレーション：1 つのリレーションは、すべてのゲームで 1 つの機能です（FSX、MSFS、X-Plane の「Gear」を同じボタンに）。コマンドはシムの公開イベント名（GEAR_TOGGLE、AXIS_AILERONS_SET など）です。
  • エクスポート：JoyPro は、エクスポート先のシムで使用中の操作設定ファイルに書き込みます。

#割り当てをインポート

  1. スタート を開きます。シムのカードにはその画像が表示されます。コマンド リストを求められたら リスト作成 を押します。JoyPro は独自のイベント一覧と、操作設定ファイル（およびシム付属のテンプレート ファイル）に含まれるイベントを組み合わせます。
  2. カードの インポート を押します。プロファイルに追加 を選び、キーも取り込みたい場合は キーボードのキーも取り込む にチェックを入れます。
  3. 今すぐインポート を押します。リレーションを表示 で取り込んだ内容を開けます。

#リレーションの作成と確認

リレーション ページでは、リレーションのシムのイベントが、ほかのゲームの同じ機能と並んで表示されます。リレーションの流れ でそれらをまとめ、エクスポート ページで 今すぐ確認 を押します（確認）。

#エクスポート

  1. シムを閉じます。 シムは終了時にファイルを書き直します。fsx.exe または Prepar3D.exe の実行中は、JoyPro が書き込みを拒否します。
  2. エクスポート を開き、お使いのシムのカードを使います。
  3. JoyPro でデバイスを設定しているなら、自分のデバイスで置き換え と ほかのデバイスもクリア のままにします。カードの 今すぐエクスポート を押します。
ゲーム内: FSX と Prepar3D での表示

シムを起動して操作設定を開きます。デバイスの割り当てがそこに表示され、各軸の感度とヌル ゾーンはキャリブレーション ページに表示されます。正確なメニューの場所と、シムが JoyPro のファイルをどう表示するかは、まだ確認されていません。

#FSX と Prepar3D で自分で行うこと

  • デバイスを接続した状態で シムを一度起動 し、操作設定ファイルを書き出させます。
  • 最初のエクスポートのあとに 結果を確認します（上記参照）。お使いの PC でのこの連携の、初めての実地テストになります。
  • ハットは全体で 1 つとして割り当てられ、通常は視点のパン（PAN_VIEW）です。ハットの個別の方向に対するほかのイベントは書き込まれません。それらはシム内で割り当ててください。

#よくある落とし穴

  • 「シムが実行中です」：シムを閉じて、もう一度エクスポートします。
  • 差し直したらデバイスの割り当てが消えた：Windows がデバイスに新しい GUID を付けることがあります。その場合、同じ名前の接続デバイスが 1 台だけなら、JoyPro は名前でそのマップを見つけます（警告付き）。
  • モディファイア付きのジョイスティックの割り当てがない：この形式では、ジョイスティックのボタンにモディファイアを付けられません。キーには Ctrl、Shift、Alt を付けられます。

#JoyPro が読み書きするファイル

シム 操作ファイル
FSX（パッケージ版） %APPDATA%\Microsoft\FSX\Controls\Standard.XML（有効なファイルは fsx.cfg の [CONTROLS] Controls_Current から）
FSX: Steam Edition パッケージ版 FSX と併用時は %APPDATA%\Microsoft\FSX-SE\Controls\、単体でインストールした場合は %APPDATA%\Microsoft\FSX\Controls\
Prepar3D v4 / v5 / v6 %APPDATA%\Lockheed Martin\Prepar3D v<N>\Controls\Standard.xml（有効なファイルは Prepar3D.cfg の [CONTROLS] から）
すべて <file>.joypro.json（JoyPro が書き込んだ入力）、<file>.joypro-meta.json（次回のインポート用の名前、グループ、チューニング）

Prepar3D の Standard.xmlx（デバイスのプリセット）と、インストールフォルダー内の FSX のテンプレートは、コマンド一覧のために読み取るだけで、書き込みません。

#FSX と Prepar3D のエクスポートモード

モード シムで起きること
追加のみ ブロックを削除したり置き換えたりはしません。別のイベントがある入力への割り当ては書き込まれず、一覧に表示されます。
更新（ゲームの割り当てを優先） あなたの入力にあるイベント（競合）を置き換え、それ以外はすべて残します。
更新（プロファイルを優先） さらに、割り当てるイベントの他の入力も削除します（接続済みデバイス。キーボードはキーボードのオプション使用時のみ）。
自分のデバイスで置き換え 書き込むデバイスのメインのマップには、あなたの割り当てだけが残ります。
+ ほかのデバイスもクリア 接続されている他のデバイスのメインのマップを空にします（マップ自体は残ります）。

#一切変更しないもの

  • 接続されていないデバイスのマップ、インポートで無視したデバイス、JoyPro が転送先にしている vJoy デバイス。
  • スルーのマップ（... SLEW {GUID}）、Mouse Yoke、Mouse Look、Prepar3D の SimObject ごとのマップ、およびキーボードの割り当てをエクスポートしない場合のキーボードのマップ。
  • 2 つの通常キーの組み合わせ、コメント、書式、未知の要素。

#カーブと設定

  • 単位：グローバル。すべての機体で 1 つのファイルです。
  • 軸の設定（軸モデル fsx）：デバイスの軸ごとの感度（0 ～ 127）とヌルゾーン（0 ～ 127）。キャリブレーションのページと同じです。既定のカーブ は近い値に合わせます（デッドゾーンをヌルゾーンに、飽和を感度に）。カーブの形には対応するものがありません。更新モードでは、JoyPro の値が単なる既定値なら、シムで設定した値が残ります。
  • 反転：負の感度。
  • フォースフィードバック、ゲーム設定、テレメトリーはありません。監視はシムの終了後に変更を検出します。
技術的な内部情報

#FSX と Prepar3D 連携の内部

コード：engine\Games\FsxIntegration.cs（1 つのクラス、シムごとに 1 つのゲーム）、engine\Games\FsxControlsFile.cs（ブロック単位でのテキスト編集）、engine\Games\FsxEvents.cs（JoyPro のイベント一覧）。

  • 形式：<SimControls.Map> に <Name>、<Axis>（<Index> 0 ～ 7 = X、Y、Z、Rx、Ry、Rz、Slider、2 つ目のスライダー。<AxEvent>、<AxScale>、<AxNull>）、<Entry>（0 始まりのボタン <Index>、<Down> / <Up>、リピートするイベントには <DownRpt>1）、<POV>（ハット全体）。ヘッダーは encoding="Windows-1252"。
  • デバイス：DirectInput デバイスごとに <instance name>{<instance GUID>} という名前のマップ。GUID で照合し、見つからなければ、その名前を持つ接続済みデバイスがちょうど 1 台の場合に名前で照合します。ファイルにないデバイスには新しいマップを作ります。デバイスごとに 32 個のボタンと 8 本の軸が報告されています。
  • マッピング：JOY_X .. JOY_SLIDER2 を <Index> 0 ～ 7 に、JOY_BTN<n> を <Index> n-1 に、ハットはその上方向（JOY_BTN_POV1_U）に対応させます。
  • コマンド一覧：engine fsx refresh-db（と fsxse、p3d4、p3d5、p3d6）：JoyPro の名前が付いた約 150 のイベントと、あなたの操作ファイルとシムのテンプレートに出てくるすべてのイベント。AXIS_* のイベントは軸です。
  • インポート / エクスポート：engine fsx paths（有効なファイルが先頭）、engine fsx import、engine fsx scan、engine fsx export。engine fsxse export、engine p3d4 export、engine p3d5 export、engine p3d6 export も同様です。最初の書き込み前にバックアップします。

#既知の制限

  • すべて実際のインストールでの確認が必要です：Prepar3D v4 以降のヘッダーと <Name> にまだ GUID が入るかどうか、シムが書き込む正確なバイト、2 つ目のスライダーの軸名、まだ認識していないデバイス用に JoyPro が追加した新しいマップをシムが保持するかどうか。
  • FSX: Steam Edition の設定ファイル名は推測です。
  • テスト：文書化された形式から作った合成ファイルを使う engine\tests\smoke\fsx.ps1。
