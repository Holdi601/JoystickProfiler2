表示：

初心者向け

#3 ステップで使えるようにする

  1. すべて自動で設定
    スタート ページで
  2. このボタンを使う
    先に一覧を確認
  3. ゲームに書き込む
    X-Plane は閉じたままで

事前に：デバイスを接続して X-Plane を一度起動し、終了してください。

その後：X-Plane でデバイスをキャリブレーションしてください（Settings > Joystick）。割り当てもそこに表示されます。

以前に X-Plane でボタンを割り当てていましたか？ それならスタートページに インポートしてから空きを埋める が表示されます。今の割り当てはそのまま残り、空いているボタンだけに新しい役割が付きます。クイックスタート：スティックを使えるようにする を参照してください。

#JoyPro が X-Plane に対して行うこと

  • インポート：デバイスの軸の用途、ボタンのコマンド、反転フラグ、レスポンスカーブがプロファイルに入ります。
  • リレーション：1 つのリレーションは、すべてのゲームで 1 つの機能です（X-Plane、MSFS、DCS の「Gear」を同じボタンに）。X-Plane の飛行コマンドは、X-Plane 自身の Commands.txt から取得します。
  • エクスポート：JoyPro は、エクスポートするバージョンのジョイスティック設定に書き込みます。X-Plane では Settings > Joystick に割り当てが表示されます。

#X-Plane の割り当てをインポート

  1. 開始 を開きます。X-Plane 12（または X-Plane 11）のカードにはゲームの画像が表示されます。コマンドリストを求められた場合は リスト作成 を押します。JoyPro がインストールされた X-Plane の Resources\plugins\Commands.txt を読み取ります。
  2. カードの インポート を押し、プロファイルに追加 を選びます（このファイルには X-Plane のキーボードの割り当てはありません）。
  3. 今すぐインポート を押します。リレーションを表示 で取り込んだ内容を開けます。

#リレーションの作成と確認

リレーション ページでは、リレーションの X-Plane のコマンドや軸が、ほかのゲームの同じ機能の隣に表示されます。リレーションの流れ でつなげてから、エクスポートページで 今すぐ確認 を押してください（確認）。

#X-Plane へエクスポート

  1. X-Plane を閉じてください。 設定ウィンドウを閉じたときと終了時に設定を書き直します。どちらのバージョンも X-Plane.exe として動くため、どちらかが実行中だと JoyPro は書き込みを拒否します。
  2. エクスポート を開きます。インストールされているバージョンごとにカードがあります。
  3. JoyPro でデバイスを設定しているなら、自分のデバイスで置き換え と ほかのデバイスもクリア のままにします。カードの 今すぐエクスポート を押します。
ゲーム内: X-Plane での表示

X-Plane を起動して Settings > Joystick を開き、デバイスを選びます。各軸には JoyPro が書き込んだ用途が、ボタンにはそのコマンドが表示され、軸の Edit Response Curve には JoyPro が書き込んだ制御点と補間が表示されます。

#X-Plane で自分で行うこと

  • デバイスを接続して X-Plane を一度起動し、終了してください。 一度も起動していないバージョンには、まだ設定ファイルがありません。最初の起動ではチュートリアル飛行が始まります。X-Plane は終了時にジョイスティック設定を書き込みます。
  • キャリブレーションは X-Plane で行ってください。 キャリブレーションとヌルゾーンは X-Plane 側の設定（Settings > Joystick）で、JoyPro は書き込みません。
  • プラグインと機体のコマンドは JoyPro のリストにありません。これらは X-Plane で割り当ててください。JoyPro は変更しません。

#よくある落とし穴

  • 軸が効かない（「Multiple axes assigned to yaw」）：X-Plane は、接続中の 2 つの軸が同じ用途を共有していると、その用途を無視します。エクスポート時に警告が出ます。ほかのデバイスもクリア または置き換えで、もう一方の軸がクリアされます。
  • スロットルが逆に動く：X-Plane はスロットル軸を自動で反転します。JoyPro はあなたの反転設定をそのまま書き込むので、レバーが本当に逆向きに動くのでない限り、反転はオフのままにしてください。
  • X-Plane で作ったカーブが変わった：更新モードと「追加のみ」では、JoyPro のチューニングが直線ならカーブは残ります（警告あり）。「自分のプロファイルを優先」と置き換えでは JoyPro のカーブを書き込みます。
詳細

#JoyPro が読み書きするファイル

ファイル これは何か
<install>\Output\preferences\X-Plane Joystick Settings.prf 全デバイスの現在の割り当て（行単位）
<install>\Output\preferences\control profiles\<Name> - Joysticks.prf 保存済みの操作プロファイル。同じ形式
<file>.joypro.json、<file>.joypro-meta.json JoyPro が書き込んだ入力とカーブ。次回のインポート用の名前、グループ、調整
%LOCALAPPDATA%\x-plane_install_12.txt / _11.txt X-Plane のインストーラーがインストール先を記録している場所（読み取り専用）

X-Plane Keys.prf（キーボード）には決して触れません。Steam でインストールして一度も起動していないバージョンは、Steam のフォルダーで見つかります。別のフォルダーは 設定 > ゲーム で指定します。

#X-Plane でのエクスポート モード

モード X-Plane で起きること
追加のみ 空いている入力のみ。ほかの用途やコマンドがある入力への割り当ては書き込まず、一覧に表示します。X-Plane で別の軸にある軸の用途はそのまま残ります（警告）。
更新（ゲームの割り当てを優先） 自分の入力にあるほかの用途やコマンドを置き換え、それ以外はすべて残します。軸の用途は移動します（X-Plane は 2 本の軸が共有する用途を無視するため）。
更新（プロファイルを優先） さらに、割り当てる用途やコマンドを持っている接続中のデバイスのほかの軸とボタンも、そのカーブごと解除します。
自分のデバイスで置き換え さらに、書き込むデバイスにあるほかのすべての飛行軸とコマンドも解除します。
+ ほかのデバイスもクリア 書き込まない接続中のデバイスは、飛行の用途とコマンドを失います。

#一切変更しないもの

  • 接続されていないデバイスのスロット、インポートで無視したデバイス、JoyPro が入力を送り込む vJoy デバイス。
  • 視点、カメラ、VR、カスタム コマンドの軸、プラグインと機体のコマンド、キーボード。
  • キャリブレーションのキー（_joy_center、_joy_null、キャリブレーションの生データ）、_eq_pfc_*、そしてほかのすべての行。

#カーブと設定

  • 適用範囲：すべての機体に 1 つのファイルです（X-Plane は機体を操作プロファイルに結び付けられます。JoyPro は見つけたファイルに書き込みます）。
  • 応答カーブ（軸モデル xplane）：LINEAR、CATMULL_ROM、CUBIC_AVG による任意の数の点と、スロットル、プロペラ、ミクスチャー軸の固定範囲（ベータ、フェザー、カットオフ、FADEC など）。既定のカーブ は点に変換されます。変更していないカーブはバイト単位でそのままです。調整は 1 つのバージョンにも、両方（family:xplane）にも設定できます。
  • 逆転：_joy_rev_axis。反転設定はそのまま使います（X-Plane はスロットルを自分で逆転させます）。
  • ゲームの設定（設定 > ゲームのフォースフィードバック設定）：ピッチ、ロール、ヨーの操作の応答。X-Plane 12 では副操縦士の軸と、フォースフィードバック スティック用の "control-loaded axes" も。X-Plane 11 では安定増強装置。両方でフラップのデテント。変更するのは、ファイルにすでにある行だけです。
  • フォースフィードバック：X-Plane 自体にはありません。control-loaded のスイッチだけです。
  • テレメトリ記録：X-Plane の UDP データ出力（ポート 49000）から位置付きで記録するため、Tacview のトラックも作れます。
  • 監視機能：設定ファイルの変更は、X-Plane を閉じたあとに検出されます（監視機能）。
技術的な内部情報

#X-Plane 連携の内部

コード：engine\Games\XPlaneIntegration.cs（バージョンごとに 1 インスタンス）、engine\Games\XPlanePrf.cs、engine\AxisModels\XPlane.cs、engine\FfbModels\XPlane.cs、engine\Games\LegacyGameIds.cs（2 つのバージョンに分かれる前のプロファイルは、読み込み時に移行されます）。

  • 行：_joy_AXIS_use<i>（用途コード）、_joy_rev_axis<i>、_joy_BUTN_use<i>（コマンド パス、sim/none/none = 空き）、axis_response_curve<i>。全体での番号：軸 = スロット × 25 + 軸、ボタン = スロット × 160 + ボタン。
  • デバイス：スロットは _joy_unique_id<slot> VID:<dec>PID:<dec>。同じデバイスが複数ある場合は、DirectInput の HID インターフェイスのパスが _joy_location<slot> と一致する必要があります。ボタンはデバイスのボタンに続き、最初のハットが上から時計回りに 8 つのボタンとして並びます。ほかのハットは割り当てられません。デバイスごとにボタン 160 個と軸 25 本を読み込みます。
  • 用途コード：両バージョンとも 0 ～ 66。X-Plane 12 ではスロットル 9、副操縦士のピッチ/ロール/ヨー/ブレーキ/ティラー、左右のホイール ブレーキが加わります。コード 74 ～ 77 と視点の軸はカタログにありません。
  • コマンド一覧：engine xplane12 refresh-db / engine xplane11 refresh-db：そのバージョンの軸の表と、Commands.txt の飛行コマンドのグループ（sim/flight_controls、engines、autopilot、lights など。sim/view、operation、replay などは除く）。
  • インポート / エクスポート：engine xplane12 import、engine xplane12 scan、engine xplane12 export（--mode、--nuke-untouched-devices、--dry-run）、engine xplane11 export も同様です。先に .jpbak にバックアップします。
  • 設定とカーブ：engine ffb set --game XPlane12、engine binds tuning set --scope game:XPlane12 --curve-points 0:0,0.4:0.3,1:1、engine binds tuning preview（X-Plane 12.4.3 で測定し、誤差 0.0001 以内）。

#既知の制限

  • 用途コード 74 ～ 77 の意味。HID と DirectInput の軸の順序の違いは推測です。
  • カーブなしの X-Plane の Control Sensitivity は、プレビューに含まれていません。
  • X-Plane 11 は、インストール済みのファイルに対してのみ確認しています。ゲーム内メニューでの確認はこれからです。
  • テスト：engine\tests\smoke\xplane.ps1。ゲーム内（X-Plane 12）では、割り当てと応答カーブが 33 ステップ中 33 ステップで合格しました。tools\e2e\games\XPlaneCurves.ps1 は、すべての軸を JoyPro のプレビューと照らし合わせて確認します。
