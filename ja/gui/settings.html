設定

表示：

設定ページには、JoyPro のすべての設定が、開閉できる 25 のセクションにまとめられています。検索ボックスでは単語で設定を探せ（「トレイ」、「アップデート」、「写真」）、上部のタブでセクションに移動でき、セクションの順番も自由に変えられます。すべての設定はすぐに保存され、再起動の後も残ります。保存ボタンはありません。

  • 設定を検索：単語を入力します（「トレイ」）。一致する設定があるセクションだけが残り、開いた状態になります。
  • 上部のタブ でセクションに移動します。
  • セクションのハンドルかタブを ドラッグ すると、セクションを好きな順番に並べられます。
  • 変更した設定 は、この PC にすぐに保存されます。ほかのものも変える設定がいくつかあります：ゲームのフォルダー、DCS のファイル、ローカル AI、オプションのコンポーネント。フォースフィードバックの設定は、開いているプロファイルに保存されます。
初心者向け

#ページの使い方

  • セクションを開く：タイトルをクリックします。右上の すべて開く / すべて閉じる で、すべてのセクションを開閉します。その横の小さな矢印で、JoyPro の順番に戻し、ゲーム だけを開いた状態にします。
  • 設定を探す：設定を検索 に単語を入力します。一致する設定があるセクションだけが残り、開いた状態になります。x で検索をクリアします。
  • 自分の順番：セクションのハンドル（または上部のタブ）をドラッグして移動します。JoyPro は、どのセクションが開いているかと、その順番を覚えています。
  • 設定はすぐに反映されます。いくつかの設定には「次回起動時」と書かれています。

初回起動では ゲーム だけが開きます。ほかはすべてクリック 1 つで開けます。ほとんどの人に必要なのは ゲーム、外観、言語、JoyProについてとアップデート だけです。

#各セクション

#ゲーム

JoyPro が対応していて、持っているゲームごとに 1 枚のカード。カバー画像、「インストール済み」または「未インストール」、ゲームの場所、操作設定の保存場所が表示されます。

  • セットアップを再実行 で 初回起動のウィンドウ がもう一度開きます：持っているゲームにチェックを入れ、フォルダーをリンクし、設定の場所を決めます。再検出 でゲームをもう一度探します（ゲームをインストールしたり移動したりした後）。
  • ゲーム設定を監視：JoyPro が管理している操作設定をゲーム内で変えると、ゲームを閉じた後に、その変更をプロファイルに取り込むかどうかを JoyPro が尋ねます（ゲームの監視）。
  • JoyPro が出力する vJoy デバイス：なし（既定）では、すべての vJoy デバイスを通常のデバイスとして扱います（例：VoiceAttack が動かすもの）。番号を指定すると、その vJoy デバイスが JoyPro 自身の出力を運ぶことを JoyPro に伝えます（仮想ジョイスティック）。インポートではそれを除外し、エクスポートでは決して空にしません。
  • War Thunder: ゲームのアーカイブから完全なコマンド リストを読み込む：オン（既定）にすると、JoyPro はゲームの gui.vromfs.bin と lang.vromfs.bin を読み取り専用で展開し、すべての飛行機とヘリコプターのアクションを取得します。オフ：JoyPro が知っている War Thunder のアクションの独自リストだけを使います。
  • Hell Let Loose: Vietnam: インストール済みの別のゲームの Oodle ライブラリを使用：このゲームのファイルは圧縮されていて、読み取るためのライブラリが付属していません。許可すると、JoyPro はこの PC にある別のゲームのライブラリを、その場所のまま使います。オフ：JoyPro 独自のゲームパッドのキー一覧を使います。Xbox パッド モードにはこれで十分です。再度確認 で答えを忘れます。
  • カードごとに：フォルダーを選択... / .exeを選択... でゲームのフォルダーをリンクします（ポータブル版のインストール、別のドライブ）。検出結果を使用 でリンクを解除します。非表示 で、持っていないゲームを JoyPro のどこにも表示しないようにします（そのゲームの割り当ては残ります）。非表示のゲームは最後に 再表示 付きで一覧表示されます。
ゲーム内: リンクしたフォルダーと非表示のゲーム

ここではゲームは何も変わりません。リンクしたフォルダーで、インポートとエクスポートの読み書き先が決まります。非表示のゲームにはエクスポートのカードがなく、監視もされません。

#割り当て

  • 割り当てページとリレーション ページで入力に追従：ボタンを押す（または軸を大きく動かす）と、ページがそのリレーションに移動します。もう一度押すと、そのボタンの次のリレーションに移ります。記録中と入力中は動作しません。
  • 入力に追従して移動したときにリストの上にメモを表示（"BTN 8 on WarBRD: Gear (1/3)"）。既定ではオフです。
  • 記録: 離したときに押された状態のボタンも取り込む：3 段スイッチの中央位置やモード スイッチは、常に押された状態です。チェックを入れると、記録中にそれを離したときに、そのボタンとして扱われます。

#周りを見る：ヘッドトラッキングまたはVR

セットアップ ウィザードの質問 ヘッドトラッキングまたはVRを使いますか？ への回答です。ヘッドトラッキング（TrackIR、顔を追跡する Web カメラ、Tobii アイトラッカー）や VR では、頭を回して周りを見ます。

  • はい：設定はフライトシムで HOTAS に視点用のボタンを置かず、視点をリセットするボタンだけを置きます。
  • いいえ：周りを見る操作を高い優先度でスティックまたはスロットルのハットに置きます。
  • 変更した後、もう一度設定 で、回答に関係するシムのセットアップ ウィザードが開きます。ヘッドトラッキングと周りを見る操作を参照してください。

#ツアー

JoyPro のすべてのツアーを 1 か所に（ヘルプモードとツアー）：

  • ようこそ画面を表示 で、初回起動時の質問をもう一度開きます：何をしたいか、どのツアーが合うか。
  • ヘルプモード（F1） でヘルプモードをオンにします。何かをクリックすると、その働きが表示されます。
  • 次回起動時に再度確認：JoyPro の次回起動時にようこそ画面がもう一度表示され、どのツアーも未表示に戻ります。
  • 基本だけ / すべての機能：一覧のツアーで表示するステップの数（再起動の後も保持されます）。
  • 一覧：ようこそ画面の 5 つのツアーと、各ページの ... ページのツアー。それぞれに ツアーを開始 があり、最後まで進めると 表示済み になります。

#起動

起動時に前回のプロファイルを開く（既定でオン）は、最後に開いていたプロファイルを開きます。パスはその下に表示されます。メモではプロファイルの履歴を説明しています：すべての変更は自動で保存され、保存のたびに 履歴（上部バー）のバージョンになります。古いバージョンは間引かれます：直近 1 日はすべて、その後 7 日間は 1 時間に 1 つ、60 日間は 1 日に 1 つ、それ以降は 1 週間に 1 つ。プロファイルごとに最大 200 MB、全体で最大 1 GB です。保持にしたバージョンは残ります。

#下部バーのページ

下部バーのページごとに 1 行。使わないページのチェックを外します。行をハンドルでドラッグする（または矢印を使う）と順番が変わります。非表示のページも、ほかのページから開けて（例：モディファイア ページを開く）、開いている間はバーに表示されます。設定は非表示にできません。既定にリセット で、すべてのページを表示した JoyPro の順番に戻します。

#言語

JoyPro の言語：英語とほかの 38 言語、または Windows の言語（Windows の表示言語。JoyPro にその言語がない場合は英語）。翻訳は機械によるもので、不自然に聞こえることがあります。ゲームのコマンド名はゲームでの名前のままです。タスクトレイの補助プログラムのメニューも言語に従います。

#外観

  • 配色：ライト、ダーク、システム（Windows に従う）、そして 使用 と 編集 のある独自のテーマ。
  • 文字サイズ（Ctrl+Plus、Ctrl+Minus、Ctrl+0）と UI の拡大率（ウィンドウ全体：文字、ボタン、画像、余白）。どちらも Windows の表示スケールに上乗せされます。それぞれの横に リセット があります。
  • テーマ エディター: 独自の色とフォント：ライトから新しいテーマ / ダークから新しいテーマ でテーマを作り始めます。インポート... で、誰かが共有したテーマ ファイルを読み込みます。次に名前を付け、フォント、行間、見出しの大きさ、すべての色を選びます。小さな JoyPro ページのライブ プレビューとコントラストの確認（コントラストを修正 付きの「読みにくいテキストがあります」）があります。色の下に このテーマを使用、保存、複製、エクスポート...、色をリセット、削除 があります。

#バックグラウンドで実行（タスクトレイ）

JoyPro がゲーム内での操作設定の変更に気づけるのは、動いている間だけです。JoyPro を閉じた後は、小さな補助プログラムがタスクトレイのアイコンとして監視を続けます。CPU の使用はほとんどなく、メモリーも数 MB です。

  • Windows と同時に起動（タスクトレイ）：サインインすると補助プログラムが起動します。JoyPro のウィンドウは開きません。管理者権限は不要です。
  • 閉じるとタスクトレイへ：JoyPro を閉じても（X）、補助プログラムが監視を続けます。オフ：JoyPro を閉じると監視も終わります。
  • タスクトレイのアイコン：クリックで JoyPro を開きます（またはゲームの変更を確認します）。右クリックで「ゲーム設定を監視中」のオン / オフと「終了」があります。

#確認

JoyPro は、取り消しにくい変更の前に確認します。オフにできる質問がここに一覧表示されます：リレーションからアクションを削除するとき、まだエクスポートしていない変更が失われるインポート、プロファイルが一度もインポートしていないゲームへの初めてのエクスポート、割り当てを削除するエクスポート、インポート時の監視のヒント。「今後は確認しない」でオフにした質問は、ここでチェックが外れて表示されます。すべての確認を再開 で、すべてをオンに戻します。

#JoyProについてとアップデート

#プライバシー

JoyPro にはアカウントもテレメトリーもありません。オンラインに接続するのは、アップデートの確認、メーカーの製品写真（許可した後）、この PC にないゲームのカバー画像、オプションの AI モデルのダウンロード、オプションのドライバー、不足している .NET Framework の場合だけです。

  • メーカーの製品写真：デバイスごとに確認（既定）、常にダウンロード、しない（JoyPro の図のみ）。すべてのデバイスで再度確認 で、デバイスごとの答えを忘れます。
  • 参照写真を自動でダウンロード：デバイスが現れると、その参照写真をバックグラウンドで取得し（元のアドレス、または Web アーカイブから）、確認してデータ フォルダーに保存します。オフ：JoyPro が写真を提案し、クリックを待ちます。
  • JoyPro のリリースの画像（コックピット、デバイスの 3D ビュー）：確認する、常にダウンロード、しない。コックピット ページと、レイアウト ページのデバイスの 3D ビューで使われます。
  • インターネットからのゲーム カバー画像：この PC の Steam に画像がないカバーを 1 回だけダウンロードします。次回起動時に反映されます。

ツールチップ ここに表示されている保存済みの設定をすべて削除します（ffb clear）。ゲームは独自の値を使用します。

ここに表示されている保存済みの設定をすべてプロファイルから削除します。次のエクスポートから、ゲームは再び自身の値を使います。

先に確認しません。

詳細（英語）

#接続中のみ

チェック ボックス説明済み

DCSのフォースフィードバックの表に、現在接続されているデバイスだけを表示します。

#プロファイルのみ

チェック ボックス説明済み

表に、プロファイルが使うデバイスだけを表示します。

#切り替えの変更を自動適用

チェック ボックス説明済み

オンの場合、表で「軸の入れ替え」「X 反転」「Y 反転」にチェックを入れると、「適用」を押さなくても、そのデバイスがすぐにプロファイルに保存されます。

#選択項目を適用

ボタン説明済み

選択したすべてのデバイスの「軸の入れ替え」「X 反転」「Y 反転」をプロファイルに保存します。DCS には次の DCS エクスポートで反映されます。

ゲーム内: 次のエクスポートと DCS の起動の後、それらのデバイスは逆方向に押します。
