GUI のページ

フォースフィードバック

表示：

JoyPro は、飛んでいるゲームからライブのテレメトリー（対気速度、迎角、G、ギア、機銃、被弾など）を読み取り、VPforce Rhino のようなフォースフィードバック スティックの力に変えます：失速時のバフェット、G がかかったときのスティックの重さ、ギアとフラップの振動、機銃の連射、滑走路の振動、そして対気速度とともに硬くなりトリムに追従するセンタリング スプリング。スティックの動きはノードのグラフで決まり、自分で変更できます。DCS World、IL-2 Great Battles、IL-2 Korea、War Thunder で使えます。

初心者向け

#4 つの手順で力を感じる

  1. ページのスイッチを オン にします。JoyPro は 5 秒ごとに対応ゲームを探すようになります。それまでは何も動きません。
  2. デバイスと力 で 更新 を押し、フォースフィードバック スティックを選びます。最初は 強さ と 最大の力 をそのままにしておきます（最大の力はすべてのエフェクトの上限で、既定は 60 %）。
  3. ↔ 方向テスト を押します。JoyPro がスティックを軽く押し、どちらに動いたかを尋ねるので、ボタンで答えます。X / Y 反転 が自動で設定され、センタリング スプリングとトリムも確認されます。
  4. ゲーム でゲームを選び、テレメトリ エクスポート の下の インストール を押します（先にゲームを閉じてください）。これで DCS や IL-2 がテレメトリーを JoyPro に送るようになります（War Thunder は自分で送ります）。あとは飛ぶだけです。
ゲーム自身のフォースフィードバックをオフにする

JoyPro が自分でスティックを動かします。そのスティックについて、ゲームのフォースフィードバックをオフにしてください（DCS：機体の FFB オプション、IL-2：Settings > Input devices、War Thunder：フォースフィードバックをオフ）。そうしないとゲームがデバイスを占有し、JoyPro は力を送れません。

ゲーム内: 感じられること

失速が近づくとスティックが震え、G がかかると重くなり、ギアやフラップが動く間は振動し、滑走路では速度に応じて振動し、機銃は連射で反動し、被弾（IL-2）すると横に揺れます。センタリング スプリングは速く飛ぶほど硬くなり、トリム（ゲームのトリム、または JoyPro 自身のトリム ボタン）で中心が動きます。メニューやゲームの一時停止中は、JoyPro がすべてのエフェクトを止めてスティックを放します（JoyPro がセンタリング スプリングを提供している場合は、それだけが残ります）。

詳細

#設定タブ

デバイスと力：デバイス、強さ（すべてのエフェクト）、最大の力（軸ごとの絶対上限。どのエフェクトも、エフェクトの合計も、これを超えません）、方向（X 反転 / Y 反転、デバイスごとに保存）、↔ 方向テスト、センタリング（「JoyPro がセンタリング スプリングを提供」、トリムに必要）、スプリングの硬さ（グラフにスプリングがない軸に使う単純なスプリング）。

方向テスト の手順（各手順は ▶ 準備完了 を待ちます。■ キャンセル でいつでもすべての力を止められます）：

  1. ▶ 開始 を押します。JoyPro がスティックを 2 秒間右に押します（20 %）。答える：どちらに動きましたか？
  2. JoyPro がスティックを 2 秒間前に押します。答える：どちらに動きましたか？
  3. センタリングスプリング。答える：中央に戻りますか？
  4. トリム：中心が 35 % 前に移ります。答える：動いて、その位置にとどまりましたか？

手順 4 の後、このデバイスの X / Y 反転 が保存されます。↻ この手順を繰り返す で今の手順をやり直します。

「動かなかった」を選ぶと、その軸の設定はそのままで、確認すべき点が表示されます（VPforce のスティックでは、トリムのために Configurator 自身のスプリングをオフにする必要があります）。⏮ 最初からやり直す で最初から始めます。テスト中はスティックを専有する必要があるので、JoyPro のフォースフィードバックがゲーム用に動いている間は実行できません。

ゲーム：ゲームを選び、このゲームのフォースフィードバック、その 強さ、その グラフ（内蔵 または自分のグラフファイルのいずれか。エディターで開く）、内蔵グラフのエフェクトのスイッチ（バフェット、G、ギア、フラップ、スピードブレーキ、滑走路、振動、機銃、被弾、スプリング）、独自のグラフまたは強さを持つ機体（機体を追加、削除）、テレメトリ エクスポート（インストール、削除、ドライ ラン）。強さは掛け算です：全体 x ゲーム x 機体。その後で最大の力の上限がかかります。

#グラフエディター

グラフは、テレメトリーを力に変える方法を表します。値はワイヤーを通って左から右へ流れ、0..1（方向が意味を持つ場合は -1..1）に正規化されます：

  • テレメトリ ノードは、ゲームのキーを 1 つ（ac.ias、ac.aoa、ac.g ...）読み取り、最小/最大で正規化します。
  • グループ、カーブ（ドラッグで形を変えるベジェ曲線）、数式ノードと状態を持つノード（ローパス、変化率制限、しきい値）が値を加工します。
  • 出力 はエフェクトです：一定の力、周期的な力（サイン波、矩形波、三角波、のこぎり波。強さと周波数は入力から決まります）、スプリング（硬さ、中心 = トリム）、ダンパー、摩擦。同じ軸と同じスロットにある同じ種類の出力は競合し（最も強いものが勝ちます）、スロットが違えば合算されます。
  • デバイスからの 入力：デバイスのボタン / ハット（どのデバイスでも。⏺ ボタンを押してください... で取り込みます）、スティック位置、トリム（⇕ トリム ボタンを割り当て は 6 つのボタンを尋ねます：スティック位置にトリム、機首下げ、機首上げ、左、右、リセット）。

ノードの種類を選んで グラフに追加 し、ポートから別のポートへドラッグしてつなぎ、選択して 選択項目を削除 します。内蔵から新規作成 は JoyPro のフライトグラフのコピーから始めます。保存 / 名前を付けて保存 でグラフファイルを書き出し、読み込み / 再スキャン で読み込みます。その後、設定タブでそのグラフをゲームや機体に選びます。

#テレメトリーインスペクター

実行中のゲームのすべてのテレメトリーキーを、値、名称、単位付きでリアルタイムに表示します。キーや名称で絞り込めます。テレメトリノードにどのキーを入れればよいか、その値の範囲はどうかを確かめるのに使います。

技術的な内部情報

#ページの仕組み

ビューモデル：MainWindowViewModel.FfbTelemetry.cs（設定、ゲーム、機体、セットアップ、プロセス）、MainWindowViewModel.FfbDirectionTest.cs（テストウィザード）、FfbGraphEditorViewModel.cs（エディター）。Views/Controls/FfbGraphCanvas.cs、FfbCurveEditor.cs。フォースフィードバックは専用のプロセス JoyPro.Ffb.exe（gui/JoyPro.Ffb、グラフエンジンは gui/JoyPro.Ffb.Core）で動きます。

ゲームの起動からスティックの解放までのフォースフィードバックのプロセス：

# 誰が どうなるか
1 JoyPro ページがオンの間、5 秒ごと：対応しているゲームが実行中か？
2 JoyPro フォースフィードバックのプロセスを開始します：JoyPro.Ffb run --game DCS --game-pid N --parent-pid M --protocol。
3 ゲーム テレメトリを送ります（DCS では UDP ポート 41992）。
4 フォースフィードバックのプロセス 最初の力でスティックを（排他的に）確保します。その後、テレメトリが届く間は 1 秒に 50 回、変わった効果の値だけを送ります。
5 フォースフィードバックのプロセス テレメトリが止まる（メニュー、一時停止）：STOP ALL、スティックは解放されます（「センタリングスプリング」がオンならスプリングは残ります）。
  • ライフサイクル：プロセスはプロセスハンドルでゲームを追い、ゲームか JoyPro が終わると終了します。一定の力と周期的な力はすべて持続時間 0.3 秒で、繰り返し再開されます。そのため、プロセスが固まったり強制終了されたりしても、スティックに力が残ることはありません。テレメトリーのタイムアウト（0.5 秒）、ゲームの終了、JoyPro の終了、あらゆるエラーで STOP ALL を実行します。
  • 設定：<data>\Ffb\Telemetry\telemetry-ffb.json（<data> = %LOCALAPPDATA%\JoyPro2）。グラフは <data>\Ffb\Telemetry\Graphs\*.jpffb.json（形式 joypro-ffb-graph）、最後の状態は status.json にあります。
  • エンジン：engine ffb telemetry status（ページの状態）、engine ffb telemetry config set / engine ffb telemetry config clear（--game、--plane：ゲームと機体ごと）、engine ffb telemetry effects、engine ffb telemetry setup dcs とほかのゲームのセットアップ（インストール、削除、--dry-run。ゲームのファイルは先にバックアップされます）。
  • ゲーム：DCS（Export.lua の 1 行、UDP）、IL-2 Great Battles と Korea（ゲームのテレメトリーデバイス出力、UDP）、War Thunder（ゲームのローカル Web サーバー、ポート 8111、セットアップ不要）。設定 > ゲーム で非表示にしたゲームは表示されず、検出もされません。
  • 方向：正の力は、X では右へ、Y ではパイロット側へ押します。デバイスごと（インスタンス GUID 単位）の X / Y 反転で、力とスプリングの中心が反転します。

リファレンス：ffb-telemetry、同じテレメトリーの記録：telemetry-recording。

詳細（英語）

#JoyPro がセンタリング スプリングを提供（トリムに必要）

チェック ボックス説明済み

ツールチップ オン: JoyPro がスティックを駆動している間は常にセンタリング スプリングを保持し（ゲームの一時停止中も）、トリムでその中心を移動します。オフ: JoyPro はスプリングを送信せず、スティック自体のセンタリングが働きます（JoyPro によるトリムなし）。

オン: JoyPro がスティックを動かしている間、ゲームの一時停止中もセンタリング スプリングを保ち、トリムでその中心が移動します。

オフ: JoyPro はスプリングを送りません。スティック自身のセンタリングが働き、JoyPro によるトリムはありません。

詳細（英語）

#インストール

選択中のゲームのテレメトリ エクスポート: 「インストール」はゲームに JoyPro のテレメトリ エクスポートを追加し、「削除」はそれを取り除き、「ドライ ラン」は「インストール」で何が変わるかを表示します。

先にゲームを閉じてください。

#オン

チェック ボックス説明済み

選択中のノードの設定の中のスイッチです。例: Constant ノードの Active、Invert、一定のフォースの「方向を反転」、スプリングの「中心を反転」。

そのノードや効果の動作を変更します。グラフとともに保存されます。

詳細（英語）

#⏺ ボタンを押してください...

ボタン説明済み

ツールチップ 次に任意のデバイス（スティック、スロットル、パネル）のボタンまたはハットを押してください。それがこのノードの入力になります。

グラフ エディターでデバイスのボタン ノードを選択中: 「⏺ ボタンを押してください...」は、いずれかのデバイスで次に押されるボタンまたはハットを待ちます。それがノードの入力になります。

残すにはグラフを保存してください。

詳細（英語）

#⇕ トリム ボタンを割り当て（それぞれ押す）

ボタン説明済み

ツールチップ 6 つのボタンを順番に尋ねます: スティック位置にトリム、機首下げ、機首上げ、左、右、リセット。待つとスキップします。

グラフ エディターで Trim ノードを選択中: 6 つのボタンを順番に求めます。待つとその 1 つをスキップします。

ボタン ノードがない入力にはボタン ノードが追加されます。

詳細（英語）
