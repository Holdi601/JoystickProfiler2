GUI のページ

レイアウト

表示：

レイアウト ページには、各デバイスの画像と、すべてのボタン、ハット、軸の働きが表示されます。上部で切り替える 2 つのセクションがあります：デバイス画像（一度に 1 つのデバイス：見る、マーカーを直す、画像上で割り当てる）と チートシート（すべてのデバイスの印刷用画像、機体ごと）。このページでゲームが変わることはありません。ただし 割り当て モードで作った割り当ては、ほかの割り当てと同じようにプロファイルに入ります。

初心者向け

#何がどこに？（レイアウト ウィンドウ）

何がどこに? を押すと、すべてのデバイスを表示するウィンドウが開きます。各操作部の横に、ゲームでのその働きが書かれています。このページの右上、スタート ページ、タスクトレイのメニューにあります。

  1. ゲーム と 機体 を選びます。
  2. ボタンを押すか、軸やハットを動かします。その行が光り、その機能が上部に大きな文字で表示されます。
  3. 飛行中はウィンドウを 2 台目のモニターに置いておけます。次回も同じ場所に開きます。

ゲームに追従 は、プレイ中のゲームに、DCS では乗っている機体にも切り替えます。詳細：何がどこに？ 各ボタンの働きを見る。

#DCS のニーボードに割り当てを表示

JoyPro は、DCS の各機体のニーボードに割り当てのページを置けます。コックピットの中でそのまま読めます。

  1. このページ上部の チートシート を押します。
  2. ニーボード の部分を探します。DCS のニーボード（OpenKneeboard でも表示） のままにします。
  3. ニーボードに置く を押します。
  4. DCS を起動し、機体に乗ってニーボードを開きます。そこにページがあります。

ボタンを変えましたか？ もう一度 ニーボードに置く を押すと、JoyPro が自分のページを置き換えます。ほかのニーボードのページはそのままです。詳細：DCS のニーボードで割り当てを見る。

#デバイス画像

  • 左：デバイス。 スティック、スロットル、ペダル、パネルごとに 1 枚のカードがあり、モデルと「ユーザー レイアウト · マーカー 47 個」または「参照画像」が表示されます。カードをクリックすると画像が表示されます。モデル... でどのモデルかを指定します（JoyPro の推測が違う場合）。入れ替えボタンで、割り当てを別のデバイスに移せます。
  • 中央：画像。 JoyPro によるデバイスの図、メーカーの写真、または自分の写真で、各入力にその働きを示すラベルが付きます（"Weapon Release"、"Gear Up/Down"）。
  • 右：選んだ入力（ラベルか凡例の行をクリック）と 凡例：デバイスのすべての入力とその割り当て、「25 個中 7 個の入力を割り当て済み」。

#3 つのモード

  • 表示（V）：各入力の働きを見ます。
  • 編集（E）：ラベルを実際のボタンの上にドラッグしたり、自分の写真を使ったり、マーカー アシスタントを開始したりします。
  • 割り当て（B）：入力をクリックし、右でリレーションを選んで この入力に割り当て を押します。割り当てはプロファイルに入ります。

#チートシート

ボタンの横にすべての割り当てを書き込んだデバイスの画像です。印刷したり、2 台目の画面に表示しておいたりできます。デバイス、ゲーム、機体にチェックを入れ、デバイスごとの概要 と 機体ごとに 1 枚 のどちらか、または両方を選んで、チートシートを作成 を押します。画像（PNG）は出力フォルダーに保存され、プレビューに表示されます。

ゲーム内: チートシートと割り当てモード

チートシートには、1 つの機体でのボタンの働きが表示されます。プレビューのボックスでゲームを選ぶと、そのゲーム自身のコマンド名で表示されます。割り当て モードで作った割り当ては、割り当てページで記録した割り当てと同じように、次のエクスポートでゲームに書き込まれます。

詳細

#表示される画像

  1. 自分のレイアウトファイル（JoyPro 1 のレイアウト、自分で選んだ画像）。
  2. 自分で撮ったデバイスの写真。
  3. メーカーの参考写真（ビューごとに 1 枚）。許可した後にだけダウンロードされます。
  4. JoyPro によるデバイスの図。
  5. その種類（スティック、スロットル、ペダル ...）の輪郭。

キャンバスの上の画像ストリップには、デバイスの画像ごとにボタンがあります。3D ボタンの横のボックスで図のスタイルを選びます：線 か、太い輪郭線の下に平らな色を塗ったもの（色は 設定 > 図）。3D モデルのあるデバイスには 3D ビュー があります。ドラッグで回転、ホイールでズーム、ダブルクリックでリセットします。チートシートに印刷されるのも、編集モードで扱うのも、平面の図のほうです。

#どのモデル？

JoyPro は、USB ID、名前、デバイスが報告する入力を、数百種類のモデルを収めたカタログと照らし合わせてデバイスを判別します。判別できないとき（グリップを交換できるベース、複数の製品で同じ USB ID、未知のデバイス）は、画像の上で尋ねます：どれですか？ と候補のタイルが表示され、最も可能性が高い ものが先頭に並び、最も可能性の高いものを使用、リストにない: カタログを検索、今はしない から選びます。未知のデバイスでは種類も選びます。モデル... > 別のモデルを選択... でいつでも選び直せます。

#マーカーアシスタント

表示中の画像に部位の位置情報がないとき（「この画像にはまだ位置がありません」）、マーカーアシスタントを使えば 1 分ほどで配置できます：

  1. マーカーを配置（足りないものが少しだけなら 配置する）。
  2. デバイスのボタンかハットの方向を押す（ほかのデバイスは無視されます）か、その他 > 軸 を選んで軸を動かします。
  3. 画像上のその部位の場所をクリックします。
  4. 繰り返します。完了 で保存します。

デバイスが手元にない場合は、次に配置: X が次の入力を示します。クリックするとそこに置かれ、後で はほかの入力の後でもう一度尋ねます。位置のない入力はチップとして表示され、画像の上にドラッグできます。元に戻す は最後の配置を取り消し、スキップ は次の入力に進み、停止 は一時停止します。その他 には、軸、停止、操作部を追加（JoyPro が知らない操作部：ボタン、スイッチ、ハット、ミニスティック、エンコーダー、軸）、画像から削除 があります。

#検出されたスポット (試験的)

その他 > 検出されたスポット (試験的) は、写真の中でボタン、ハット、スイッチに見える場所に細い破線の円を描きます。円の近くをクリックする（またはチップをドロップする）と、マーカーが円の中心に置かれます。JoyPro はその場所がどの入力かは知らないので、自分では何も配置しません。写真で動作し（JoyPro の図では動作しません）、オフラインで動きます。

#表と線

位置情報のある画像では、ツールバーの 表 で JoyPro 1 のチートシートの見た目を描きます。画像の周りに操作部のグループごとの表があり、部位への線が引かれ、各行に割り当てたリレーション、2 列目にモディファイアの割り当てが入ります。プレビューのボックスで行に表示する内容を選びます：リレーション名、またはゲームと機体を 1 つ選んでそのゲーム自身のメニュー名。編集モードでは、表（固定されます）、その右端、線の区間、点をドラッグします。サイドパネルには モディファイア列、行 + / 行 −、固定、線を再配置、線を削除、個別の表に分割、再グループ化、自動配置、リセット があります。リレーションを行にドラッグ からリレーションをドラッグして行にドロップすると、そこに割り当てられます。

#1 ページに複数のビュー

複数ビュー は、1 つのデバイスの画像を複数 1 ページに並べます（正面と側面など、すべてのボタンが見えるように）：ビューを追加、ユーザーの画像...、整列、このビューを編集、ビューを削除、ページを削除、1 枚の画像に戻す。ページの形式は、印刷用に A4 か Letter、画面用に 16:9 / 21:9 / 32:9 です。チートシートはこのページを印刷します。

#JoyPro を修正する

入力がない、または位置が違うときは、編集モードで直します（ドラッグ、操作部を追加、画像から削除、凡例で名前を変更）。変更はすべて、JoyPro のデータに重ねる自分のレイヤーとしてこの PC に保存されます。JoyPro に修正を送信... は変更を小さなファイルとして保存し、入力済みの GitHub の Issue フォームを開きます。送信するかどうかはそこで決めます。モデル... > JoyPro の既定にリセット... は、デバイスに加えた変更をすべて削除します（先に確認があり、リセットを元に戻す で戻せます）。

#キー

V / E / B でモード切り替え、N でマーカーを配置（レイアウトファイル）、Del で削除、Ctrl+Z / Ctrl+Y で元に戻す・やり直し、Ctrl+S で保存、+ / - でズーム、0 か F で全体表示、編集モードでは矢印キーで微調整（Shift：10 px）、Alt を押しながらドラッグでスナップなし。画像ファイルをドロップすると、デバイスの自分の写真になります。

#全デバイスを 1 ページに

チェック ボックス説明済み

#割り当ての一覧（大きな文字）

チェック ボックス説明済み

ツールチップ オフ: レイアウトページと同じチートシートの画像。

オン: 各ページには、この機体で何かを行う操作部だけが、大きな文字で操作部ごとにまとめて表示され、モディファイアが必要な割り当てには色付きのタグが付きます。

割り当ての多いデバイスは 2 ページ目に続きます。

#ニーボードに置く

ボタン説明済み

「ニーボードに置く」は、各機体のチートシートをその機体のニーボードに置きます。機体とデバイスごとに 1 ページで、チェックしたデバイスとシートのスタイルを使ってチートシートと同じように描かれます。

DCS では、コックピット内のその機体のニーボードでページを見られます。

#チートシートを作成

ボタン説明済み2 ×

ツールチップ 出力フォルダーに画像（PNG）を作成します。ゲームには影響しません。

チェックしたデバイス、ゲーム、機体とシートのスタイルで出力フォルダーにチートシートを作成し、プレビューに表示します。

未保存のレイアウト ファイルの編集は先に保存されます。画像のないデバイスにチェックが入っていると、メッセージを表示して停止します。
