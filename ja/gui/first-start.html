GUI のページ

初回起動のセットアップ

表示：

「JoyPro2 へようこそ: 所有ゲーム」ウィンドウは、初回起動時に JoyPro がゲームを探した後、1 回だけ開きます。JoyPro が対応するすべてのゲームが、見つかったものから順に一覧表示されます。ここで、持っているゲームを指定し、JoyPro が探さなかった場所にインストールされたゲームをリンクし、ゲームの操作設定用に別のフォルダーを JoyPro に指定します。同じウィンドウは、設定 > ゲーム > セットアップを再実行 でもう一度開けます。新しいユーザー向けの手順は 初回起動 にあります。

各行で どうなるか
このゲームを所有しています のチェックを外す JoyPro はそのゲームをどこにも表示しなくなります。そのゲームの割り当ては残ります。
インストール先 の横の 参照... または .exe... そのフォルダーがゲームになります。別のドライブにあるコピーに便利です。
操作設定の保存先 の横の 参照... JoyPro はそこでゲームの操作設定を読み書きします。

その後、下にある 3 つのボタンのどれかを押します：

押すボタン
次にすること
完了
JoyPro がゲームを保存します。初回起動時は、ようこそ画面が何をしたいかを尋ねます。
完了してすべて自動で設定
JoyPro がゲームを保存します。その後、クイック セットアップが重要な機能をスティックに割り当てます。
後で
何も変わりません。初回起動時は、次にようこそ画面が表示されます。
初心者向け

#ゲームごとに 1 行

各行には、ゲームのカバー画像、名前、状態があります：

  • チェックあり、フォルダーあり：JoyPro がゲームを見つけました（どうやって見つけたかが行に表示されます：Steam、既知の場所、Windows のアプリ一覧）。
  • チェックなし：JoyPro は見つけられませんでした。持っていないなら問題ありません。非表示には なっていない ので、インストールすればすぐに JoyPro が見つけます。

できること：

  1. 見つかったゲームのチェックを外す：持っていない、または興味のないゲームの場合です。JoyPro のどこにも表示されなくなります（ゲームのカード、エクスポートのカード、監視、ゲームの一覧）。そのゲームの割り当てはプロファイルに残ります。
  2. 別の場所にインストールしたゲーム（ポータブル版のコピー、別のドライブ）：チェックを入れ、インストール先 の横の 参照... でフォルダーを選ぶか、.exe... でゲームのプログラムやランチャーを選びます。
  3. 操作設定の保存先：ユーザー フォルダーに操作設定を保存するゲームがあります。別の場所にある場合（例：Saved Games\DCS ではなく Saved Games\DCS.openbeta）、そこで 参照... を押します。
  4. 完了 を押します。後で はウィンドウを閉じ、何も変えません。
  5. または 完了してすべて自動で設定 を押します：JoyPro がゲームを保存し、スティックを自動で設定します。クイック スタート を参照してください。
ヒント

完了 の後、JoyPro は持っているすべてのゲームのコマンド一覧を、あなた自身のインストールから作ります。スタート ページに進行状況と、まだない一覧についてのお知らせが表示されます。

詳細

#詳細

  • リンクしたフォルダーは、ゲームの目印となるファイル（bin\DCS.exe、bin\game\Il-2.exe、X4.exe ...）で確認されます。行には「目印を検出」、または「目印が見つかりませんが、フォルダーは選択どおりに保持されます」と表示されます。リンクしたフォルダーは、すべての処理（インポート、エクスポート、コマンド一覧）でインストール先として扱われ、検出で置き換えられることはありません。
  • 検出結果を使用（インストール先または設定）はリンクを解除し、JoyPro がゲームを検出し直します。
  • 所有していない（すべての場所で非表示） は、JoyPro が見つけられなかったゲームに表示されます。選ばなければ、そのゲームは「未インストール」のままで、インストールされれば自動で表示されます。選ぶと、見つかったゲームのチェックを外した場合と同じように非表示になります。
  • 操作設定をインストール先に保存するゲーム（IL-2、Falcon BMS、X-Plane ...）は、設定の場所が読み取り専用で表示されます。
  • 非表示にしたゲームは、設定 > ゲーム の最後に 再表示 付きで並びます。
技術的な内部情報

#ウィンドウの仕組み

ウィンドウは Views/GameSetupWindow.axaml（フォルダーの選択、完了、後で は .axaml.cs）、ビューモデルは MainWindowViewModel.GameSetup.cs、行は Models/GameSetupItem.cs です。このウィンドウは、ui-settings.json に gameSetupDone が設定されておらず、起動時の検出（engine games installs）が応答したときに一度だけ開きます。完了 は、変更した行ごとに engine games install set（または clear）、engine games config set（または clear）を実行し、続いて非表示にしたゲームと表示したゲームについて engine games install disable / enable を 1 回実行し、もう一度検出して、セットアップ完了の印を付け、足りないコマンド一覧を作るために engine db check-updates を開始します。リファレンス：ゲームのインストール。

#このゲームを所有しています

チェック ボックス説明済み

「このゲームを所有しています」: JoyPro が見つけたゲームやリンクしたゲームには、最初からチェックが入っています。

持っていない検出済みのゲームのチェックを外すと、「完了」で JoyPro のすべての場所で非表示になります。以前に非表示にしたゲームにチェックを入れると、「完了」で再び表示されます。

詳細（英語）

#所有していない（すべての場所で非表示）

チェック ボックス説明済み

ツールチップ それ以外の場合、ゲームがインストールされると JoyPro が検出します

JoyPro が見つけられなかったゲームに表示されます。チェックすると、「完了」で、チェックを外した検出済みのゲームと同じようにすべての場所で非表示になります。

チェックしない場合、ゲームは「未インストール」のままで、インストールすれば JoyPro が自動で見つけます。

詳細（英語）

#参照...

ボタン説明済み

ツールチップ ゲームのフォルダーをリンクします（ポータブル版、別ドライブ）。そのフォルダーがインストール先として扱われます

「インストール先」>「参照...」: JoyPro が見つけられなかったゲームのフォルダーを選びます。例: ポータブル版や別のドライブにあるもの。

JoyPro は選んだものからゲームのフォルダーを取得し、ゲームにチェックを入れ、ゲームの目印となるファイルがあるか確認します。

詳細（英語）

#.exe...

ボタン説明済み

ツールチップ 代わりにゲームの.exeまたはランチャーを選んでください。JoyProがゲームのフォルダーをリンクします

.exe...: フォルダーの代わりに、ゲームのプログラムまたはランチャーを選びます。JoyPro はその隣にあるゲームのフォルダーをリンクし、ゲームの目印となるファイルがあるか確認します。

「完了」で書き込まれます。

#参照...

ボタン説明済み

ツールチップ ゲームが操作設定を保存する場所。例：Saved Games\\DCS ではなく Saved Games\\DCS.openbeta

操作設定をインストール先や Windows のレジストリに保存するゲームには表示されません。

#やさしいことば: 大きな文字、短い文

チェック ボックス説明済み

ツールチップ ツアーとヘルプで大きな文字ととても短い文を使います。「設定 > ツアー」でいつでも変更できます。

ツアーとヘルプで大きな文字と短い文を使います。

初回起動時のみ: 「やさしいことば」で、ツアーとヘルプが大きなカードと最も短い文になります。

#後で

ボタン説明済み

ツールチップ 何も変更しません。設定 > ゲーム > セットアップを再実行 で再表示できます

このウィンドウを閉じます。何も変わりません。

何も変更せずにウィンドウを閉じます。フォルダーはリンクされず、ゲームも非表示になりません。

次回の起動時にウィンドウが自動で開くことはありません。設定 > ゲーム >「セットアップを再実行」で再び表示できます。

詳細（英語）

#完了

ボタン説明済み

ゲームを保存して、このウィンドウを閉じます。

選択内容を保存してウィンドウを閉じます。リンクしたフォルダーと設定の場所が書き込まれ、チェックを外した検出済みのゲームは非表示に、チェックしたゲームは表示されます。その後、JoyPro はゲームを再検出し、お持ちのゲームのコマンド リストを作成します。

いずれかの手順が失敗した場合、ウィンドウは開いたままになり、どのゲームかが表示されます。

詳細（英語）

#完了してすべて自動で設定

ボタン説明済み

ツールチップ ゲームを保存し、JoyProが重要な機能をスティックとスロットルに自動で割り当てて、結果を表示します

ゲームを保存します。それから JoyPro がスティックを設定します。

初回起動時のみ: 「完了してすべて自動で設定」は、「完了」と同じようにゲームを保存し、その後、まだ何も割り当てられていないゲームについて JoyPro がデバイスを自動でセットアップします。

スティック、スロットル、ペダルを見つけ、それぞれに通常の役割を与え、重要な機能をパイロットが期待する場所に配置します。
