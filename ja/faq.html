ヘルプとトラブルシューティング

表示：

まずは短い回答から。それぞれ手順のページにリンクしています。

#簡単な回答

ACE COMBAT 8 でスティックが反応しません。 ACE COMBAT 8 は Xbox コントローラーしか認識しません。JoyPro はスティックを仮のコントローラー（仮想 Xbox パッド）に変えます。まずゲームを起動します。タイトル画面で Alt+Tab で JoyPro に切り替え、開始 を押してください。Xbox 専用ゲームを HOTAS で遊ぶ を参照してください。

開始すると「早すぎます」と表示されます。 ゲームが起動する前に 開始 を押しています。ゲームを起動してタイトル画面まで待ちます。次に Alt を押したまま Tab を押し、停止 をクリックしてから 開始 をクリックします。Alt+Tab でゲームに戻ってください。

ViGEmBus はどうやってインストールしますか？ ライセンスの下のボックスは何ですか？ ViGEmBus は無料の補助ソフトで、仮のコントローラーに必要です。仮想ジョイスティックページで、まずライセンスの下のボックスにチェックを入れます。これでダウンロードに同意したことになります。次に ViGEmBus をインストール を押します。Windows が許可を求めるので はい をクリックします。これは一度だけです。

セットアップで「まれに使う追加の操作の一部は入りきりませんでした」と表示されます。問題ですか？ いいえ。スティックのボタン数がゲームの操作の数より少ないだけです。重要な操作はすべてスティックに入っています。セットアップ画面の 一部を変更 で、入らなかったものを確認できます。

後から 1 つのボタンを変えるには？ 割り当て を開き、一覧でゲームの操作をクリックし、入力を記録 をクリックして新しいボタンを押します。その後、もう一度ゲームに送ります：エクスポート、選択したゲームをエクスポート。後から 1 つのボタンを変える を参照してください。

クイックセットアップを元に戻すには？ ゲームのカード（エクスポートページ）の 前回のエクスポートを元に戻す で、ゲームの以前のボタンが戻ります。JoyPro 内の変更は Ctrl+Z で戻せます。クイックセットアップを元に戻す を参照してください。

デバイスが JoyPro の一覧にありません。 それでも使えます。JoyPro は同じ種類の一般的なデバイスと同じように設定します。スティックを動かすと操縦、ボタン 1 で射撃、最初のハットでトリム、最初のレバーがスロットルです。サポートファイルを添えて Discord で教えてください。対応デバイス を参照してください。

コックピットで割り当てを見るには？ DCS ではニーボードで見られます。レイアウトページの チートシート、ニーボードに置く です。DCS のニーボードで割り当てを見る を参照してください。セカンドモニターでは 何がどこに? を使います（詳しく）。

ツアーやようこそ画面をもう一度表示するには？ 右上の ヘルプ > ツアー...、または 設定 > ツアー > ようこそ画面を表示 です。JoyPro のフォルダーにある JoyPro 2 - Tour をダブルクリックしても開けます。

やさしいことばとは？ ツアーとヘルプで、大きな文字ととても短い文を使う表示です。ようこそ画面で やさしいことば: 大きな文字、短い文 にチェックを入れるか、設定 > ツアー で切り替えてください。やさしいことば、ツアー、F1 を参照してください。

このボタンは何をするの？ F1 を押してからボタンをクリックします。ボタンは実行されず、小さなウィンドウで説明が表示されます。終了するにはもう一度 F1 を押します。

#問題が起きたとき：サポートファイル

いちばん早くサポートを受ける方法は サポートファイル です。問題を理解するのに必要な情報がすべて入っているので、2 つ目のファイルを頼まれることはありません。

初心者向け
  1. 設定 > 問題を報告 を開きます。
  2. 何が起きましたか？ に、何をしたか、どうなると思っていたかを書きます。
  3. 開いているプロファイルとその履歴を含める はチェックしたままにしてください（とても役立ちます。割り当てやデバイス名を共有したくない場合はチェックを外してください）。
  4. レポート作成 を押します。JoyPro がファイルに含める内容を一覧表示するので、確認します。zip は Documents\JoyPro2\Problem Reports に保存され、エクスプローラーで表示されます。
  5. GitHub Issue ページを開く を押して zip を Issue にドラッグするか、Discord に投稿してください。

JoyPro が自分で何かをアップロードすることはありません。ファイル内のすべてのテキストで、Windows のユーザー名は置き換えられます。

詳細

ファイルの内容：summary.txt（バージョン、システム、フォルダー、ゲームの環境、接続中のデバイス、除外したもの）、少なくとも直近 14 日分の JoyPro のログ（最大 100 MB）、クラッシュ レポートと直近のエラー、JoyPro の設定ファイルと状態ファイル、vJoy と HidHide の状態を含むデバイス、ゲームごとの監視機能の記録、バックアップの一覧と最新のバックアップ セット、そして同意した場合は開いているプロファイル、その履歴、ゲームの現在の割り当てファイル、JoyPro 1 のプロファイル。

技術的な内部情報

サポート ファイルは engine support bundle が作ります（--list を付けると、書き出さずに内容を表示します）。

#ゲーム監視が「変更をプロファイルに取り込みますか？」と聞いてくる

JoyPro が管理しているゲームの中で操作設定を変えると、ゲームを閉じた後に JoyPro がその変更をプロファイルに取り込むかどうかを聞きます。そのボタンを複数のリレーションが使っている場合は、変更がどのリレーションに属するか、または新しいリレーションを作るかを聞きます。

  • JoyPro 自身のエクスポートでこの質問が出ることはありません。エクスポートのたびにゲームのファイルを記録しているからです。
  • ゲームごとにはスタートページのカードの 変更を監視 で、すべてのゲームでは 設定 > ゲーム の

    ゲーム設定を監視 でオフにできます。

  • JoyPro を閉じている間も監視を続けるには：設定 > バックグラウンドで実行 > Windows と同時に起動（タスクトレイ）。
技術的な内部情報

エンジン：engine sync status、engine sync diff、engine sync apply、engine sync accept。詳細：ゲーム設定の監視。

#よくある質問

JoyPro 2.7 は速くなりましたか？ はい、特に待ち時間が長かったところで。プロファイルが早く開きます。確認は、検索欄に入力している間にも最初のカードをすぐに表示します。スタート ページはゲームをバックグラウンドで調べるので、ウィンドウが遅くなりません。エクスポート後のクリックも素早く反応し、操作を止めると JoyPro はメモリを解放します。War Thunder の操作設定は約 5 倍速く読み込まれ、とても長いフォルダー パスにあるゲームも動作します。

エクスポート後、ゲームに割り当てが表示されません。 エクスポート中にゲームは閉じていましたか？ ゲームの実行中は JoyPro が書き込みを拒否し、カードにその理由が表示されます。独自の手順が必要なゲームもあります。Falcon BMS はランチャーで Launch を押したときにキーファイルを作成します。MSFS ではデバイスに JoyPro のプリセットやインポートファイルが必要な場合があります（ゲームのページを参照）。カードの結果と出力パネルを確認してください。ゲーム の各ゲームのページに固有の注意点があります。ACE COMBAT 8 と Hell Let Loose: Vietnam はエクスポートせず、仮のコントローラーを使います。

ゲームの既定の割り当てがデバイスに残っています（DCS）。 自分のデバイスで置き換え と ほかのデバイスもクリア を使ってください。書き込まれるデバイスからは、エクスポートした機体での DCS の既定の割り当てが削除されます。設定 > DCS: デフォルト割り当て で、DCS のインストール自体の既定の割り当てをオフにできます。

以前の操作設定に戻したい。 エクスポートページのゲームのカードで 前回のエクスポートを元に戻す を押します。エクスポート前のファイルをバイト単位で正確に復元します。もっと古いバックアップは、エクスポートページの下にある ゲーム設定のバックアップ にあります。

エクスポートで「ゲームに書き込まれていません」と表示されます。 追加のみ でエクスポートしたところ、ゲームがそのボタンをすでに別の機能に使っていました。確認にはカードが表示され、「更新」でエクスポートして置き換える、別のボタンへ移動、このままにする を選べます。

スティックの ID が変わった／デバイスを交換した。 インポートでは、同じ名前のデバイスは 1 台のデバイスとして扱われます。割り当てを新しいデバイスに移すには デバイスを置き換え... を使います（設定、レイアウトページのデバイスカード、または割り当てページのメニューで選択中の割り当てのデバイスに対して）。

ゲームが見つかりません。 設定 > ゲーム で 再検出 するか、フォルダーを選択... でポータブル版のインストールをリンクしてください。JoyPro がまだ対応していないゲームは ゲーム対応状況 に記載しています。

JoyPro での変更は元に戻せますか？ はい。上部バーの 元に戻す / やり直し（Ctrl+Z / Ctrl+Y）で、再起動後も戻せます。履歴 にはプロファイルのすべてのバージョンが一覧表示されます。

JoyPro はアンチチートに対して安全ですか？ JoyPro はゲームのメモリを読まず、何も注入しません。ゲームが閉じている間に設定ファイルを書き込むだけです。オプションの仮想デバイス（vJoy、ViGEmBus、HidHide）は署名済みのドライバーですが、ゲームによっては仮想デバイスを拒否することがあります。ゲーム対応状況 の各ゲームの注意点を参照してください。
