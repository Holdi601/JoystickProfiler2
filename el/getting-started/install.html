Πρώτα βήματα

Λήψη και εγκατάσταση

Εμφάνιση:

Το JoyPro 2 είναι δωρεάν και ανοιχτού κώδικα (GPL-3.0). Δεν υπάρχει λογαριασμός, εγγραφή ή τηλεμετρία.

Για αρχάριους

#Τρία βήματα

  1. Ανοίξτε τη σελίδα εκδόσεων στο GitHub και κατεβάστε το JoyPro2-<version>-win-x64.zip (στα Assets).
  2. Κάντε δεξί κλικ στο zip, Εξαγωγή όλων..., και επιλέξτε έναν φάκελο στον οποίο μπορείτε να γράψετε, για παράδειγμα C:\JoyPro2 ή έναν φάκελο στα Έγγραφά σας. (Όχι C:\Program Files: το JoyPro ενημερώνεται μόνο του στον δικό του φάκελο.)
  3. Ανοίξτε τον φάκελο και κάντε διπλό κλικ στο JoyPro.Gui (το πρόγραμμα με το εικονίδιο joystick· όταν εμφανίζονται οι επεκτάσεις αρχείων, λέγεται JoyPro.Gui.exe).

Τα Windows λένε Τα Windows προστάτευσαν τον υπολογιστή σας; Κάντε κλικ στο Περισσότερες πληροφορίες και μετά στο Εκτέλεση οπωσδήποτε. Τα Windows το ρωτούν μία φορά για ένα πρόγραμμα από το διαδίκτυο που δεν γνωρίζουν ακόμη.

Στην πρώτη εκκίνηση το JoyPro ψάχνει τα παιχνίδια σας και τα δείχνει σε ένα παράθυρο: δείτε Πρώτη εκκίνηση. Είστε νέοι στο JoyPro; Πατήστε εκεί Τέλος, και ρύθμισέ τα όλα για μένα και ακολουθήστε τη Γρήγορη έναρξη: να λειτουργήσει το stick μου.

Μετά ένα καλωσόρισμα ρωτά τι θέλετε να κάνετε και ξεκινά την περιήγηση που σας ταιριάζει. Το JoyPro 2 - Tour στον ίδιο φάκελο ανοίγει ξανά αυτό το καλωσόρισμα οποιαδήποτε στιγμή. Θέλετε μεγάλα γράμματα και σύντομες προτάσεις; Τσεκάρετε Απλές λέξεις: μεγάλα γράμματα, σύντομες προτάσεις στο καλωσόρισμα (Απλές λέξεις, περιηγήσεις και F1).

#Τι χρειάζεστε

  • Windows 10 ή 11, 64 bit.
  • Το .NET Framework 4.8 για τη μηχανή του JoyPro. Τα Windows 10 και 11 το έχουν ήδη· αν λείπει, το JoyPro προσφέρει το πρόγραμμα εγκατάστασης της Microsoft.
  • Τίποτε άλλο: το zip περιέχει τα πάντα (το πρόγραμμα δεν χρειάζεται ξεχωριστή εγκατάσταση του .NET 9).

#Ενημερώσεις

Το JoyPro ελέγχει στο GitHub για νεότερη έκδοση όταν ξεκινά (Ρυθμίσεις: Έλεγχος για ενημερώσεις κατά την εκκίνηση). Μια νεότερη έκδοση ανοίγει ένα παράθυρο με το τι άλλαξε και Ενημέρωση τώρα / Αργότερα / Παράλειψη αυτής της έκδοσης. Τα προφίλ και οι ρυθμίσεις σας μένουν.

Για προχωρημένους

#Πού κρατά τα πράγματά του το JoyPro

Τα προφίλ σας βρίσκονται στον φάκελο Έγγραφα, στο JoyPro2. Εκεί πηγαίνουν και οι αναφορές προβλημάτων. Μια ενημέρωση αντικαθιστά μόνο τον φάκελο του προγράμματος: τα προφίλ, οι ρυθμίσεις, οι λίστες εντολών, τα αντίγραφα ασφαλείας και το ιστορικό σας μένουν. Η πλήρης λίστα φακέλων βρίσκεται στις τεχνικές λεπτομέρειες.

#Προαιρετικά στοιχεία

Οι Ρυθμίσεις > Στοιχεία εγκαθιστούν, με ένα κλικ το καθένα και με τη συναίνεσή σας: vJoy (εικονικό joystick), HidHide (κρύβει φυσικές συσκευές από ένα παιχνίδι) και ViGEmBus (εικονικό χειριστήριο Xbox), για τη λειτουργία Εικονικό joystick. Το Ρυθμίσεις > Τοπικό AI μπορεί να κατεβάσει ένα προαιρετικό μοντέλο AI για τον βοηθό· όλα λειτουργούν και χωρίς αυτό.

#Σύνδεση στο διαδίκτυο

Το JoyPro συνδέεται στο διαδίκτυο μόνο για: τον έλεγχο ενημερώσεων (GitHub), τις φωτογραφίες προϊόντων των κατασκευαστών για τις συσκευές σας (μόνο αφού πείτε ναι ανά συσκευή), εξώφυλλα παιχνιδιών που λείπουν από τον υπολογιστή σας (μπορεί να απενεργοποιηθεί), το προαιρετικό μοντέλο AI, τα προαιρετικά στοιχεία και ένα πρόγραμμα εγκατάστασης .NET Framework που λείπει. Αυτοί οι ιστότοποι βλέπουν τη διεύθυνση IP σας. Λεπτομέρειες: Απόρρητο.

Τεχνικές λεπτομέρειες

#Όλοι οι φάκελοι του JoyPro

Τι Πού
Το πρόγραμμα ο φάκελος που αποσυμπιέσατε (με engine\engine.exe, vjoy\, tray\, τα δεδομένα που περιέχει το JoyPro στο DB\)
Τα προφίλ σας Documents\JoyPro2 (ή όπου τα αποθηκεύετε)
Ρυθμίσεις %APPDATA%\JoyPro2 (ui-settings.json, export-settings.json, hud.json ...)
Λίστες εντολών παιχνιδιών που δημιουργήθηκαν στον υπολογιστή σας %LOCALAPPDATA%\JoyPro2\GameData
Αντίγραφα ασφαλείας αρχείων παιχνιδιών %LOCALAPPDATA%\JoyPro2\GameBackups (τα 30 νεότερα ανά παιχνίδι)
Ιστορικό προφίλ (αναίρεση και μετά από επανεκκίνηση) %LOCALAPPDATA%\JoyPro2\ProfileHistory
Αρχεία καταγραφής %LOCALAPPDATA%\JoyPro2\Logs (διαγράφονται μόνα τους μετά από λίγες ημέρες)
Αναφορές προβλημάτων Documents\JoyPro2\Problem Reports

#Μέσα στο πακέτο

  • JoyPro.Gui.exe: η εφαρμογή Avalonia (.NET 9, αυτόνομη).
  • JoyPro 2 - Tour.cmd: ξεκινά το JoyPro.Gui.exe --welcome, το καλωσόρισμα με τις περιηγήσεις του (το παραδίδει σε ένα JoyPro που ήδη τρέχει).
  • engine\engine.exe: η μηχανή (.NET Framework 4.8). Το GUI την εκτελεί για κάθε ενέργεια· μπορείτε επίσης να την εκτελέσετε σε κονσόλα (γραμμή εντολών της μηχανής).
  • vjoy\JoyPro.VJoy.exe (προωθητής εικονικού joystick), JoyPro.Ffb.exe (ανάδραση δύναμης από τηλεμετρία), tray\JoyPro.Tray.exe (παρακολούθηση όσο το GUI είναι κλειστό).
  • Η ενημέρωση κατεβάζει το zip της έκδοσης, το ελέγχει με το δημοσιευμένο αρχείο .sha256 και το εγκαθιστά.
  • Δημιουργία από τον πηγαίο κώδικα: dotnet build gui/JoyPro.Gui/JoyPro.Gui.csproj (δημιουργεί και τη μηχανή· χρειάζεται τα εργαλεία build του .NET Framework 4.8), δείτε το README του αποθετηρίου.
