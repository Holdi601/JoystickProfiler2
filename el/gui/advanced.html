Σελίδες του προγράμματος

Για προχωρημένους

Εμφάνιση:

Η σελίδα Για προχωρημένους είναι η κονσόλα για ειδικούς. Κάθε λειτουργία που χρειάζεται ένας κανονικός χρήστης έχει το δικό της κουμπί στις άλλες σελίδες· εδώ πληκτρολογείτε μόνοι σας τις εντολές της μηχανής του JoyPro, ακριβώς όπως τις περιγράφει η γραμμή εντολών της μηχανής, και η απάντηση εμφανίζεται στο πλαίσιο Έξοδος.

Για αρχάριους

#Χρειάζομαι αυτή τη σελίδα;

Συνήθως όχι. Υπάρχει για τρεις περιπτώσεις:

  • Κάποιος (ένας βοηθός στο Discord, το wiki) σας ζητά να εκτελέσετε μια εντολή, για παράδειγμα profile summary, για να δει τι συμβαίνει.
  • Θέλετε να αλλάξετε πολλές σχέσεις ή αντιστοιχίσεις μαζί σε έναν επεξεργαστή κειμένου: Επεξεργασία σχέσεων και Επεξεργασία αντιστοιχίσεων.
  • Θέλετε μια γρήγορη επισκόπηση του ανοιχτού σας προφίλ: Σύνοψη προφίλ.

#Εκτέλεση εντολής

  1. Πληκτρολογήστε την εντολή στο Εντολή χωρίς τη λέξη engine, για παράδειγμα profile summary ή relations list --game DCS.
  2. Αφήστε επιλεγμένο το Συμπερίληψη --profile: η εντολή τότε λειτουργεί στο προφίλ που έχετε ανοιχτό.
  3. Πατήστε Εκτέλεση. Η απάντηση εμφανίζεται στο πλαίσιο Έξοδος στο κάτω μέρος (πατήστε Έξοδος στην κάτω γραμμή αν είναι κλειστό).
Προσοχή

Οι εντολές που πληκτρολογούνται εδώ μπορούν να αλλάξουν το προφίλ και τα παιχνίδια σας ακριβώς όπως τα κουμπιά. Κάθε αλλαγή του προφίλ είναι μια έκδοση στο Ιστορικό (επάνω γραμμή), οπότε μπορείτε να επιστρέψετε· τα αρχεία των παιχνιδιών αποθηκεύονται ως αντίγραφα ασφαλείας πριν από μια εξαγωγή.

Για προχωρημένους

#Τα πλαίσια

Πλαίσιο Τι προσθέτει Επιλογή μηχανής
Εντολή επεξεργαστή Το πρόγραμμα που ανοίγει για το Επεξεργασία σχέσεων / Επεξεργασία αντιστοιχίσεων (και για πληκτρολογημένα relations edit / binds edit). Το {file} αντιπροσωπεύει το προσωρινό αρχείο, π.χ. code --wait {file}. Κενό: Notepad. --editor (καθολική)
Αρχείο εξόδου Γράφει την απάντηση μιας πληκτρολογημένης εντολής σε αυτό το αρχείο αντί για τον πίνακα Έξοδος. Μόνο για εντολές που πληκτρολογούνται εδώ· τα κουμπιά των άλλων σελίδων δεν το χρησιμοποιούν ποτέ. --out (καθολική)
Έξοδος κειμένου Ενεργό (προεπιλογή): ευανάγνωστο κείμενο. Ανενεργό: JSON, όπως το διαβάζουν τα scripts. Μόνο για εντολές που πληκτρολογούνται εδώ. --text (καθολική)
Καθολικά ορίσματα Οποιεσδήποτε άλλες καθολικές επιλογές τοποθετούνται πριν από την εντολή, π.χ. --status true. οι καθολικές επιλογές
Εντολή Η εντολή και οι επιλογές της. Τα εισαγωγικά κρατούν μαζί μια διαδρομή με κενά. οι εντολές
Συμπερίληψη --profile Προσθέτει --profile "<open profile>". Αποεπιλέξτε το για εντολές που δεν χρειάζονται προφίλ (db summary, games installs). --profile
  • Τα relations list και binds list που πληκτρολογούνται εδώ ανανεώνουν επίσης τις λίστες των σελίδων Σχέσεις και Αντιστοιχίσεις με την απάντηση.
  • Η γραμμή εντολών της τελευταίας εκτέλεσης είναι η πρώτη γραμμή του πίνακα Έξοδος ($ engine --profile ... profile summary): αντιγράψτε την για να εκτελέσετε το ίδιο σε ένα τερματικό.
  • Το Επεξεργασία σχέσεων γράφει όλες τις σχέσεις σε ένα προσωρινό αρχείο JSON, το ανοίγει στον επεξεργαστή σας και το διαβάζει ξανά όταν κλείσει ο επεξεργαστής· οι σελίδες Σχέσεις, Αντιστοιχίσεις και Τροποποιητές επαναφορτώνονται. Ένα βήμα αναίρεσης.
Τεχνικές λεπτομέρειες

#Πίσω από τη σελίδα

View model: MainWindowViewModel.cs (RunCustomCommandAsync, RelationsEditAsync, BindsEditAsync, RunEngineSummaryAsync, RunProfileSummaryAsync)· τα ορίσματα δημιουργούνται στο RunEngineAsync, την ίδια μέθοδο που χρησιμοποιεί κάθε κουμπί του GUI. Μια πληκτρολογημένη εντολή χωρίζεται από το TokenizeCli (με σεβασμό στα εισαγωγικά), τα καθολικά ορίσματα μπαίνουν πρώτα, μετά --profile, --status, --benchmark, --history-note (μόνο για τις δικές αλλαγές του GUI), --out, --editor, οι επιλογές διόρθωσης φόρτωσης από τις Ρυθμίσεις και --text. Μια εντολή που αλλάζει το προφίλ εκτελείται με το κλείδωμα προφίλ και δημιουργεί μια έκδοση ιστορικού όπως κάθε άλλη αλλαγή.

Μηχανή: engine summary, engine profile summary, engine relations edit, engine binds edit και κάθε εντολή της γραμμής εντολών της μηχανής. Αναφορά: Αντιστοιχία GUI και CLI (ποιο κουμπί εκτελεί ποια εντολή).

#Έξοδος κειμένου

Πλαίσιο ελέγχουγραμμένο

Ενεργό: μια εντολή που πληκτρολογείτε εδώ απαντά σε ευανάγνωστο κείμενο.

Ανενεργό: απαντά σε JSON, όπως το διαβάζουν το GUI και τα σενάρια.

Περισσότερες λεπτομέρειες (στα αγγλικά)

#Συμπερίληψη --profile

Πλαίσιο ελέγχουγραμμένο

Ενεργό: η πληκτρολογημένη εντολή παίρνει --profile "<open profile>", ώστε να διαβάζει και να αλλάζει το προφίλ που έχετε ανοιχτό.

Αποεπιλέξτε το για εντολές που δεν χρειάζονται προφίλ.

Περισσότερες λεπτομέρειες (στα αγγλικά)

#Εκτέλεση

Κουμπίγραμμένο

Εκτελεί την εντολή που πληκτρολογήσατε στο πεδίο Εντολή μέσω της μηχανής και δείχνει την απάντηση στο πλαίσιο Έξοδος. Οι εντολές relations list και binds list ανανεώνουν επίσης τις σελίδες Σχέσεις και Αντιστοιχίσεις.

Μια εντολή που αλλάζει το προφίλ είναι ένα βήμα αναίρεσης· μια εντολή που γράφει σε ένα παιχνίδι κρατά πρώτα αντίγραφο ασφαλείας των αρχείων του παιχνιδιού, όπως και τα κουμπιά.

Περισσότερες λεπτομέρειες (στα αγγλικά)

#Επεξεργασία σχέσεων

Κουμπίγραμμένο

Ανοίγει όλες τις σχέσεις του προφίλ ως ένα αρχείο JSON στον επεξεργαστή σας· όταν κλείσετε τον επεξεργαστή, το JoyPro διαβάζει ξανά το αρχείο και οι σελίδες Σχέσεις, Αντιστοιχίσεις και Τροποποιητές ανανεώνονται.

Ένα βήμα αναίρεσης.

Περισσότερες λεπτομέρειες (στα αγγλικά)

#Επεξεργασία αντιστοιχίσεων

Κουμπίγραμμένο

Ανοίγει όλες τις αντιστοιχίσεις του προφίλ ως ένα αρχείο JSON στον επεξεργαστή σας· όταν κλείσετε τον επεξεργαστή, το αρχείο διαβάζεται ξανά και οι σελίδες ανανεώνονται.

Ένα βήμα αναίρεσης.
