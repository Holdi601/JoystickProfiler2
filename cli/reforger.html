#engine reforger paths

written
engine reforger paths
For beginners

Lists where JoyPro finds the joystick preset of Arma Reforger on this PC. The first one is what engine reforger scan, engine reforger import and engine reforger export use when you give no path. Detect in the Other Games panel (Start page, Expert import) runs it and puts the first one into File / Folder.

engine reforger paths --text
Advanced
  • %USERPROFILE%\Documents\My Games\ArmaReforger\profile\.save\settings\customInputConfigs\JoyPro.conf, listed as soon as the game's settings folder exists. The file itself is JoyPro's preset: the first export writes it.
  • A config location you set yourself (engine games config set, Settings > Games) comes first.
  • No options. Reads only; it also works while the game runs or when it is not installed.
Technical internals
  • Output: JSON (Game, DisplayName, ConfigPaths, Warnings), or text with --text ("Arma Reforger Config Paths", "Paths: " and one line per location). Exit code 0, also when nothing was found (empty list).
  • engine reforger without an action runs paths.
  • Before the first export the listed file does not exist yet; a scan or import then reports Reforger input config not found: <path>.
  • Related: engine reforger scan, engine games paths, engine games install set; game page arma-reforger.

What it does Lists where JoyPro looks for this game's controls on this machine: files, folders or registry keys (your config location from games config set first). A file the game has not written yet can be listed (e.g. Arma Reforger's JoyPro.conf, Project Wingman's Input.ini).

Example

engine reforger paths --text

#engine reforger catalog

written
engine reforger catalog
For beginners

Lists the Arma Reforger actions JoyPro manages (its command list): id, axis or button, category and title. An export writes only these actions, and the relation editor and the search list them.

engine reforger catalog --text
Advanced
  • The list is %LOCALAPPDATA%\JoyPro2\GameData\DB\ArmaReforger\actions.tsv (when that folder does not exist, the DB\ArmaReforger folder next to the engine).
  • It is built from the game's archives by engine reforger refresh-db, or by the first scan, import or export.
  • catalog only shows the list; it never builds it. Titles that look like ids are shown readable.
  • No options. Reads only; works without the game installed.
