Engine (CLI)

engine media

Show:

1 commands of engine media. Each with every option and every value it takes, what it does, which GUI buttons use it, and an example.

  • media

#engine media

written
engine media [games|aircraft|sources] [--no-internet-pictures]

Official pictures: game covers from Steam on this PC, else downloaded once from Steam's store or the publisher's site, else the game's executable icon; DCS aircraft pictures from the modules; sources = the web source per game; warnings also in the --text output

For beginners

Lists the pictures JoyPro shows for games and DCS aircraft: a cover per game and each DCS module's icon and menu picture. The GUI asks for it once per session in the background.

engine media games --text
Advanced
  • games: per game JoyPro knows, the first picture that works: the cover Steam keeps on this PC for a game of your library, else a cover downloaded once from the game's web source (Steam's store, or the publisher's site), else the icon of the game's own executable (Star Citizen, Falcon BMS, DCS). A game without any gets JoyPro's badge in the GUI.
  • aircraft: per DCS aircraft, the icon and main menu picture its module ships (Skins\1\icon.png, Skins\1\ME\BackGround-*.png, found through the module's entry.lua); seat and game-mode variants use their base aircraft.
  • sources: the web source of every game's cover (address, kind, page it was taken from); nothing is downloaded.
  • Without an argument: games and aircraft.
  • --no-internet-pictures neither downloads a cover nor uses one downloaded before (GUI: "Game covers from the internet" off in Settings > Privacy). A failed download is tried again a day later, not on every run.
Technical internals
  • Output: JSON (Games with GameId, Name, Cover, CoverSource steam-cache/download/exe-icon, CoverKind cover/logo, CoverUrl, SteamAppIds; Aircraft with Plane, Module, DisplayName, Icon, Background; Warnings), or text with --text (one line per game and aircraft, then Warning: ... lines).
  • Exit code 0; 1 with the usage line engine media [games|aircraft|sources] [--no-internet-pictures].
  • Downloaded covers are kept in %LOCALAPPDATA%\JoyPro2\Media\Covers\<GameId>.<ext> (with a .source file, and a .miss file after a failed download); executable icons in %LOCALAPPDATA%\JoyPro2\Media\<GameId>.png.
  • Related: engine games installs, engine overlay map; privacy: privacy.

What it does Official pictures for the GUI: game covers (Steam on this PC, else downloaded once from Steam's store or the publisher's site, else the game's executable icon) and DCS aircraft pictures from the modules; sources lists the web source per game. Warnings show in the JSON and the --text output.

OptionValuesMeaning
--no-internet-picturesswitch (no value)

engine media --text
