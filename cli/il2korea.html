#engine il2korea paths

written
engine il2korea paths
For beginners

Lists where JoyPro finds the key mapping of IL-2 Korea on this PC. The first one is what engine il2korea scan, engine il2korea import and engine il2korea export use when you give no path. Detect in the Other Games panel (Start page, Expert import) runs it and puts the first one into File / Folder.

engine il2korea paths --text
Advanced
  • <install>\data\input\general.actions first, then the other *.actions files of that folder (newest first). <install> is the installation JoyPro found (data\input or game\data\input below it).
  • A warning says when the folder or the file is missing: start the game, open Settings > Key mapping and press ACCEPT once.
  • A config location you set yourself (engine games config set, Settings > Games) comes first.
  • No options. Reads only; it also works while the game runs or when it is not installed.
Technical internals
  • Output: JSON (Game, DisplayName, ConfigPaths, Warnings), or text with --text ("IL-2 Series: Korea Config Paths", "Paths: " and one line per location). Exit code 0, also when nothing was found (empty list).
  • engine il2korea without an action runs paths.
  • Related: engine il2korea scan, engine games paths, engine games install set; game page il2-korea.

What it does Lists where JoyPro looks for this game's controls on this machine: files, folders or registry keys (your config location from games config set first). A file the game has not written yet can be listed (e.g. Arma Reforger's JoyPro.conf, Project Wingman's Input.ini).

Example

engine il2korea paths --text

#engine il2korea catalog

written
engine il2korea catalog
For beginners

Lists the IL-2 Korea actions JoyPro manages (its command list): id, axis or button, category and title. An export writes only these actions, and the relation editor and the search list them.

engine il2korea catalog --text
Advanced
  • The list is %LOCALAPPDATA%\JoyPro2\GameData\DB\IL2Korea\actions.tsv (when that folder does not exist, the DB\IL2Korea folder next to the engine).
  • It is built from your general.actions by engine il2korea refresh-db, or by the first scan, import or export.
  • catalog only shows the list; it never builds it. Titles that look like ids are shown readable.
  • No options. Reads only; works without the game installed.
