Kom igång

Ladda ner och installera

Visa:

JoyPro 2 är gratis och öppen källkod (GPL-3.0). Det finns inget konto, ingen registrering och ingen telemetri.

För nybörjare

#Tre steg

  1. Öppna sidan med versioner på GitHub och ladda ner JoyPro2-<version>-win-x64.zip (under Assets).
  2. Högerklicka på zip-filen, välj Extrahera alla... och välj en mapp som du kan skriva i, till exempel C:\JoyPro2 eller en mapp i Dokument. (Inte C:\Program Files: JoyPro uppdaterar sig självt i sin egen mapp.)
  3. Öppna mappen och dubbelklicka på JoyPro.Gui (programmet med joystickikonen; när filnamnstillägg visas heter det JoyPro.Gui.exe).

Säger Windows Windows skyddade datorn? Klicka på Mer information och sedan på Kör ändå. Windows frågar detta en gång för ett program som laddats ned från internet och som det inte känner till än.

Vid första starten letar JoyPro efter dina spel och visar dem i ett fönster: se Första start. Ny i JoyPro? Tryck på Klar, och ställ in allt åt mig där och följ Snabbstart: få min styrspak att fungera.

Sedan frågar en välkomstskärm vad du vill göra och startar den rundtur som passar dig. JoyPro 2 - Tour i samma mapp öppnar välkomstskärmen igen när som helst. Vill du ha stor text och korta meningar? Kryssa i Enkla ord: stor text, korta meningar på välkomstskärmen (Enkla ord, rundturer och F1).

#Vad du behöver

  • Windows 10 eller 11, 64 bitar.
  • .NET Framework 4.8 för JoyPros motor. Windows 10 och 11 har det redan; om det saknas erbjuder JoyPro installationsprogrammet från Microsoft.
  • Inget annat: zip-filen innehåller allt (programmet behöver inte .NET 9 installerat separat).

#Uppdateringar

JoyPro söker efter en nyare version på GitHub när det startar (Inställningar: Sök efter uppdateringar vid start). En nyare version öppnar ett fönster med vad som har ändrats och Uppdatera nu / Senare / Hoppa över den här versionen. Dina profiler och inställningar finns kvar.

Avancerat

#Var JoyPro sparar saker

Dina profiler ligger i mappen Dokument, i JoyPro2. Problemrapporter hamnar också där. En uppdatering ersätter bara programmappen: dina profiler, inställningar, kommandolistor, säkerhetskopior och historik finns kvar. Den fullständiga listan över mappar finns under Tekniska detaljer.

#Valfria komponenter

Inställningar > Komponenter installerar, med ett klick vardera och med ditt samtycke: vJoy (virtuell joystick), HidHide (döljer fysiska enheter för ett spel) och ViGEmBus (virtuell Xbox-handkontroll), för läget Virtuell joystick. Inställningar > Lokal AI kan ladda ned en valfri AI-modell för assistenten; allt fungerar utan den.

#Att gå ut på nätet

JoyPro går ut på nätet bara för: uppdateringskontrollen (GitHub), tillverkarnas produktfoton av dina enheter (bara efter att du har sagt ja per enhet), spelomslag som saknas på din dator (kan stängas av), den valfria AI-modellen, de valfria komponenterna och ett installationsprogram för .NET Framework som saknas. De webbplatserna ser din IP-adress. Detaljer: Integritet.

Tekniska detaljer

#Alla JoyPros mappar

Vad Var
Programmet mappen du packade upp (med engine\engine.exe, vjoy\, tray\, de data som JoyPro levererar i DB\)
Dina profiler Documents\JoyPro2 (eller var du än sparar dem)
Inställningar %APPDATA%\JoyPro2 (ui-settings.json, export-settings.json, hud.json ...)
Spelens kommandolistor byggda på din dator %LOCALAPPDATA%\JoyPro2\GameData
Säkerhetskopior av spelfiler %LOCALAPPDATA%\JoyPro2\GameBackups (de 30 senaste per spel)
Profilhistorik (ångra även efter omstart) %LOCALAPPDATA%\JoyPro2\ProfileHistory
Loggar %LOCALAPPDATA%\JoyPro2\Logs (tas bort automatiskt efter några dagar)
Problemrapporter Documents\JoyPro2\Problem Reports

#Inuti paketet

  • JoyPro.Gui.exe: Avalonia-appen (.NET 9, fristående).
  • JoyPro 2 - Tour.cmd: startar JoyPro.Gui.exe --welcome, välkomstfönstret med dess rundturer (lämnar över det till ett JoyPro som redan körs).
  • engine\engine.exe: motorn (.NET Framework 4.8). GUI:t kör den för varje åtgärd; du kan också köra den i en konsol (motorns kommandorad).
  • vjoy\JoyPro.VJoy.exe (vidarebefordrare för virtuell joystick), JoyPro.Ffb.exe (force feedback från telemetri), tray\JoyPro.Tray.exe (bevakning medan GUI:t är stängt).
  • Uppdateringen laddar ned versionens zip-fil, kontrollerar den mot den publicerade .sha256-filen och installerar den.
  • Bygga från källkod: dotnet build gui/JoyPro.Gui/JoyPro.Gui.csproj (bygger också motorn; kräver byggverktygen för .NET Framework 4.8), se repositoriets README.
