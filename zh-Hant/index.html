JoyPro 2

#一個設定檔搞定您所有的裝置，適用於每款飛行與太空遊戲。

JoyPro 會在每架飛機和每款遊戲中，把同一個功能放在同一個按鈕上：起落架、襟翼、反制措施、配平、油門。它可以自動幫您設定搖桿、油門和腳舵。免費且開放原始碼（GPL-3.0），不需要帳號，也沒有遙測。

下載 Windows 版快速入門：讓我的搖桿能用Discord

#我想要……

讓我的搖桿能用JoyPro 會幫您全部設定好。您只需要看一看、點一點。用我的飛行搖桿玩 ACE COMBAT適用於只認得 Xbox 手把的遊戲。JoyPro 會建立一個模擬手把。飛 DCS World 或 Falcon BMS每架飛機的按鈕都集中在一處，從遊戲讀取，再寫回遊戲。讓人帶我四處看看導覽會指向真正的按鈕，任何按鈕都能按 F1 取得說明。從 JoyPro 1 過來每個舊功能現在的位置。您的舊設定檔可以直接開啟。

這些是 JoyPro 歡迎畫面中的答案。JoyPro 只會在第一次啟動後問一次。

#2.7 新功能

全部幫我設定好開始頁面上的一張卡片就能設定好您的裝置；第一次啟動結束後按 完成，並全部幫我設定好。頭部追蹤JoyPro 會詢問您是否使用頭部追蹤或 VR，並把環顧四周放到適合的位置。一個功能用兩個輸入同一個功能放在兩個按鈕或兩個裝置上。什麼在哪裡？查看您裝置上每個按鈕的功能。DCS 膝板您的綁定以頁面形式顯示在座艙的膝板上。F1 和導覽任何按鈕的說明、指向真正按鈕的導覽、簡單用語。

#JoyPro 的運作方式

快速的方式。 JoyPro 幫您完成。

  1. 全部幫我設定好
    在「開始」頁面
  2. 使用這些按鈕
    看一下清單
  3. 寫入我的遊戲
    JoyPro 會保留備份
  4. 開飛
    您的按鈕都設定好了

您自己的方式。 每個按鈕都由您決定。

  1. 匯入
    您遊戲中的綁定
  2. 關聯
    一個功能，每款遊戲
  3. 綁定
    每個一個按鈕或軸
  4. 匯出
    到每款遊戲
  • 關聯 是一個功能（「Gear Up/Down」），以及它在每款遊戲和每架飛機中的動作。
  • 綁定 是關聯所在的按鈕或軸。一個關聯可以有好幾個綁定。
  • 匯出 會把它寫入每款遊戲自己的控制檔案。它會先建立備份，而且您可以復原。
  • 之後在遊戲中變更了東西？JoyPro 會在遊戲關閉後詢問您是否要採用。

#從這裡開始

下載與安裝解壓縮、啟動，完成。它需要什麼，以及它把東西存放在哪裡。快速入門點幾下就有能用的按鈕。支援的裝置每支搖桿都能用。JoyPro 認得名稱的裝置清單。說明與常見問題常見問題，以及出問題時要用的支援檔案。我要如何……簡短的解答，每頁一個。10 分鐘做出您的第一個設定檔快速的方式和手動的方式。

#主要流程

匯入遊戲把您在遊戲中做好的綁定帶進設定檔。建立關聯搜尋、勾選、新增；建議與自動群組。匯出四種模式，以及每種模式會在遊戲中變更什麼。檢查遊戲中會出什麼問題，並提供一鍵修正。

每個頁面都有三個層級：新手（不需要電腦知識）、進階（所有選項）和 技術細節（引擎指令和程式碼）。用頁面頂端的切換鈕選擇其中一個。

#其他一切

每個 GUI 頁面1102 個控制項，每個都說明它的作用以及背後執行的內容。遊戲已支援 36 款遊戲，研究過 57 款。每款遊戲一個頁面。引擎命令列452 個指令，每個選項和值。從 JoyPro 1 到 2改進了什麼，附上數字。
