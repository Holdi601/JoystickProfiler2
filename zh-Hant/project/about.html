關於、授權與社群

顯示：

JoyPro 是一個業餘專案，最初是為了一位飛行員自己的搖桿而開始，因為也能幫助其他飛行員而分享出來。JoyPro 2 延續 JoyPro 1，理念相同，但圍繞它的是全新的程式（改進了什麼）。

#授權

JoyPro 是依據 GNU 通用公共授權條款第 3 版或更新版本 發布的自由軟體（LICENSE）。您可以使用、研究、分享和修改它。它 不提供任何擔保：JoyPro 在寫入任何遊戲檔案之前都會先備份，但請您還是自己保留備份。第三方元件及其授權列在 THIRD_PARTY_NOTICES.md 中。

#一段話說明隱私權

JoyPro 沒有帳號，也沒有遙測。它只會在以下情況連上網路：檢查更新（GitHub）、下載製造商提供的您裝置的產品照片（每個裝置都要您同意後才會下載）、您電腦上缺少的遊戲封面（可關閉）、選用的 AI 模型、設定 > 元件 中的選用驅動程式，以及缺少的 .NET Framework 安裝程式。問題報告是您電腦上的一個檔案；除非您自己把它附加到某處，否則不會上傳任何東西。詳細資訊：隱私權。

#協助與社群

  • Discord：discord.gg/yK4gQA9xgk，可提問、分享想法和參與測試。
  • GitHub issues：JoystickProfiler2/issues。請附上支援檔案（方法）。
  • 這是一個利用空閒時間進行的專案：會盡可能提供協助，但不保證修正或時程。

#參與貢獻

原始碼放在 GitHub 上。想法和問題請到 Discord 或開 GitHub issue。本網站是從原始碼產生的，所以描述的是目前的版本。

技術細節

使用 dotnet build gui/JoyPro.Gui/JoyPro.Gui.csproj 建置；測試：dotnet test gui/JoyPro.Gui.Tests 和 engine/tests/engine_smoke_test.ps1。架構圖是 ARCHITECTURE.md。本網站由 website/build.py 從原始碼產生；新的按鈕或引擎指令都需要說明，否則網站的完整性檢查會失敗。
