GUI 頁面

匯出

顯示：

「匯出」頁面會把您的設定檔寫入遊戲。它有三個編號步驟，接著是專家選項和遊戲設定備份。各種模式的完整說明，以及它們在每款遊戲中的作用，請參閱 匯出到您的遊戲。

給新手

#由上到下的頁面內容

  1. 檢查您的設定檔：立即檢查 會執行 檢查；它的卡片會出現在更下方。
  2. JoyPro 寫入遊戲的方式：四個選項（取代我的裝置上的綁定、更新，保留遊戲的綁定、更新，以我的設定檔為準、僅新增），以及勾選項 同時清除我的其他裝置。
  3. 匯出到遊戲：設定檔中有綁定的每款遊戲一張卡片。勾選卡片並按 匯出已勾選的遊戲，或在某張卡片上按 立即匯出。卡片上的 復原上次匯出 會還原該遊戲的檔案。

下方：選項與路徑（進階），接著是 檢查發現的問題、同一個按鈕重複使用 和 遊戲設定備份。

進階

#卡片和記住的選擇

  • 只有當遊戲有已綁定的關聯，而且曾經啟動過一次（它的控制檔已存在）時，卡片一開始才會勾選。您變更的勾選會保留，依設定檔分別記住。
  • DCS 卡片有 飛機...：設定檔中的每架飛機（和輸入層），附上圖片以及它有多少個關聯已綁定；只有勾選的飛機會被寫入（全部 / 無）。
  • 每張卡片都會顯示上次的結果（「已匯出 14:02」或引擎的錯誤）。
  • 未安裝的遊戲不會有卡片；頁面會列出它們的名稱，並附上 設定 > 遊戲 的連結。
  • 卡片上的 預覽（若有提供）會以試執行方式執行匯出，並顯示會變更哪些內容。
技術細節

#頁面的背後

檢視模型：MainWindowViewModel.ExportGames.cs（卡片、匯出、復原）、MainWindowViewModel.ExportDefaults.cs（模式預設值、標記）、MainWindowViewModel.Backups.cs。引擎：engine profile games 填入卡片；engine dcs export、engine il2 export、engine starcitizen export 和 engine <game> export 負責寫入；engine backups list / engine backups restore 用於復原和備份清單；engine profile game-state 用於「要先匯入嗎？」的問題。

#同時清除我的其他裝置（在匯出的機型中，我的設定檔中沒有綁定的裝置會失去所有綁定）

核取方塊已撰寫2 ×

工具提示 移除您的設定檔未使用的裝置的所有綁定（會先詢問；並建立備份）

未連接的裝置、匯入時忽略的裝置，以及 JoyPro 轉送到的 vJoy 裝置，永遠不會被清除。
