GUI 頁面

設定精靈

顯示：

設定精靈會一次為您的遊戲設定好控制。它會查看您已連接的裝置，為每個裝置指定一個角色（主搖桿、油門、腳舵、面板……），為遊戲中飛機的重要功能建立關聯，把它們綁定到您的裝置上，並以速查表的形式顯示結果。在您的設定檔變更之前，您會先檢閱所有內容，而且按一次 復原 就能全部還原。它不使用 AI：相同的選擇永遠產生相同的計畫。

從「開始」頁面開啟它。它的卡片「設定您的裝置」有兩個按鈕：

  • 全部幫我設定好（藍色的那個）：快速設定。它會自動執行這個精靈，不顯示步驟，最後停在一份簡單的清單上，列出什麼放在哪裡。請參閱 快速入門。
  • 逐步設定...：包含全部五個步驟的精靈，讓您自己選擇每一步。

沒有那張卡片時（每款遊戲都已設定好），請按「開始」頁面 您的遊戲 下方的 自動設定我的裝置...，或在「綁定」頁面上按。

快速設定（全部幫我設定好）會略過這些步驟執行同一個規劃器。它使用裝置的常規角色，所有飛機一視同仁，不使用修飾鍵，並沿用您上次在 功能要放在哪裡？ 中的選擇。對於飛行模擬遊戲，它只問一個問題：您使用頭部追蹤或 VR 嗎？

給新手

#五個步驟

步驟顯示在頂端；底部的 返回 和 下一步 用來在步驟之間移動。您可以隨時關閉視窗：在 套用 之前關閉的精靈，下次會以您離開時的狀態回來。

#1. 遊戲

您在「開始」頁面上監看的遊戲會被勾選。勾選這次設定要涵蓋的遊戲。這不會變更 JoyPro 監看哪些遊戲。

#2. 裝置

JoyPro 會辨識您的搖桿、油門、腳舵和面板，並為每一個提出一個角色：「此裝置的用途」。在它的清單中可以變更角色。每隻手一個裝置：同一隻手的第二支搖桿會被設為「未使用」，除非您另外選擇。可以裝多種握把的底座會詢問是哪個握把。右側的方塊會用文字說明 JoyPro 將如何使用它們。重新偵測 會重新讀取裝置（請先插上裝置）。

#3. 優先順序

  • 您的飛機：搜尋一架飛機（「F-16」、「直升機」、「Star Citizen」），然後按 加為下一個優先順序（新的一列）或 加為同等（加入選取的列）。飛機排得越高，它的功能就能得到越好的位置。同一列中的飛機同等計算；您沒有列出的飛機優先順序最低。
  • 修飾鍵：修飾鍵是一個您按住的按鈕（就像 Shift），讓其他每個按鈕做第二件事。選擇要用幾個；盡量少 只會在您的按鈕不夠用時才使用一個。
  • 模式開關（階段層）：一個會保持位置的開關，可以依戰鬥階段改變您按鈕的功能。
  • 功能要放在哪裡？：一個滑桿。左端：每架飛機同一件事用同一按鈕。右端：依真實飛機的位置。預設在中間。機砲和油門永遠不會移動。請參閱 功能要放在哪裡？。
  • 您使用頭部追蹤或 VR 嗎？ 僅適用於飛行模擬遊戲。如果您靠轉動頭部環顧四周（TrackIR、具臉部追蹤的網路攝影機、Tobii 或 VR），或打算這麼做，選 是：裝置上不放視角按鈕，只放「視角重新置中」。否：環顧四周會放到搖桿或油門的帽子開關上，緊接在最重要的按鈕之後。請參閱 頭部追蹤與環顧四周。

#4. 計畫

JoyPro 會製作計畫：它放置了多少功能、哪些無法放置、它建立的修飾鍵、它遵循的規則，以及每架飛機的品質分數（100 % = 每個功能都在最佳位置上）。

#5. 檢閱

選擇一個 裝置 和一架 飛機，就能看到 JoyPro 畫的裝置線稿，以及什麼綁定在哪裡。在清單中選取一個功能，可以把它移到空著的輸入、和另一個功能交換，或把它從計畫中移除。未放置 會列出放不下的功能，最重要的排在前面。

滿意之後：按 套用到我的設定檔，然後按 匯出到我的遊戲（會開啟「匯出」頁面）。只有匯出時，您的遊戲才會變更。

進階

#詳細資料

  • 角色：主搖桿（在每架飛機中為右手）、直升機搖桿（在直升機中為右手，用於第二支搖桿，例如力回饋底座）、左搖桿（在太空遊戲中為左手；沒有油門時的油門側）、油門、總距桿（在直升機中為左手）、腳舵（方向舵和腳尖煞車）、面板（印刷標籤相符的系統開關：「LDG GEAR UP」會得到起落架）、鍵盤 joystick 和虛擬裝置（保留，不綁定新的內容）、未使用。
  • 您的設定檔優先：已經在您某個關聯中的指令會留在那裡，已經綁定在本次設定的某個裝置上的關聯會保留它的輸入。您關閉的指令會保持關閉。
  • 功能要放在哪裡？ 滑桿從 每架飛機同一件事用同一按鈕 到 依真實飛機的位置。中間以下，每個功能用一個關聯，適用所有飛機；從中間開始，真實 HOTAS 上把該功能放在別處的飛機會得到自己的關聯，越往右，真實位置的影響越強。快速設定和開始頁面會使用您上次的選擇（一開始是中間）。
  • 第 3 步的選擇會被記住；下一次精靈會以它們開始。
  • 套用 會把所有內容作為一項變更寫入：設定檔歷程記錄中的一個版本，名稱為「設定精靈：N 個關聯，M 個綁定」。復原（Ctrl+Z）會把它全部撤回。
  • 開啟此表 會在您的圖片檢視器中以原尺寸顯示速查表，方便列印。
  • 當 設定 > 使用統計 > 讓新飛機採用我最常用飛機的配置 開啟時，新的配置會依照您同類型中最常用的飛機。
在遊戲中: 套用和匯出之後

在您匯出之前什麼都不會發生。套用 並匯出後，每款遊戲的控制檔案都會包含精靈建立的綁定：在 DCS 中，當滑桿靠近 每架飛機同一件事用同一按鈕 時，每架選擇的飛機都會在同一個按鈕上有相同的功能；Star Citizen 會把太空船操控放在搖桿上，平移軸放在左手搖桿上；面板會得到它們標籤上所寫的系統。如果裝置應該失去遊戲原本的綁定，請用 取代我的裝置上的綁定 匯出。

技術細節

#精靈的背後

視窗 Views/SetupWizardWindow.axaml，檢視模型 ViewModels/SetupWizardViewModel.cs（它自己的檢視模型，由 MainWindowViewModel.SetupWizard.cs 以監看中的遊戲建立），規劃器 engine/SetupWizard/*.cs。每個步驟都是一個引擎指令，所以 CLI 會產生相同的計畫：engine setup devices（辨識和角色、--role、--grip）、engine setup aircraft（優先清單）、engine setup plan（--games、--priorities "A>B|C"、--modifiers、--prefer-fewer 或 --use-all-modifiers、--placement（舊名稱 --realism）、--phase-layers、以 --cockpit-file 傳入 engine cockpits 的座艙項目；寫入計畫 JSON）、engine setup render（每個裝置一張標註頁）、engine setup apply（--plan，一個設定檔版本）。移動、對調、移除和放回會在 GUI 中編輯計畫（SetupPlanEdit），並在套用前再次檢查。參考：設定精靈。

#套用

按鈕已撰寫

將這些按鈕放入 JoyPro。遊戲暫時不會改變。

第 5 步：一步把計畫的關聯、綁定和修飾鍵寫進您的設定檔：在設定檔的「歷程記錄」中只算一個版本，一次「復原」就能全部撤回。

計畫會先經過檢查；有問題時會停止並顯示提示。
