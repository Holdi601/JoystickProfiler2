首次啟動設定

顯示：

「歡迎使用 JoyPro2：您的遊戲」視窗會在首次啟動、JoyPro 找過您的遊戲之後開啟一次。它會列出 JoyPro 支援的每款遊戲，找到的排在前面。您可以在這裡指出您有哪些遊戲、連結安裝在 JoyPro 沒找過的位置的遊戲，以及為遊戲的控制設定指定另一個資料夾。從 設定 > 遊戲 > 重新執行設定 可以再次開啟同一個視窗。新使用者的逐步說明在 首次啟動。

每一列中 會發生什麼
取消勾選 我有這個遊戲 JoyPro 會在所有地方隱藏這款遊戲。您為它設定的綁定會保留。
安裝位置 旁的 瀏覽... 或 .exe... 那個資料夾就是遊戲。適合放在其他磁碟機上的副本。
操控設定儲存於 旁的 瀏覽... JoyPro 會在那裡讀取和寫入遊戲的控制設定。

然後按底部三個按鈕中的一個：

您按下

JoyPro 會儲存您的遊戲。首次啟動時，歡迎畫面會詢問您想做什麼。

JoyPro 會儲存您的遊戲。接著快速設定會把重要的功能放到您的搖桿上。

給新手

#每款遊戲一列

每一列都有遊戲的封面、名稱和狀態：

  • 已勾選，有資料夾：JoyPro 找到了這款遊戲（該列會說明是怎麼找到的：Steam、已知位置、Windows 應用程式清單）。
  • 未勾選：JoyPro 沒有找到它。如果您沒有這款遊戲，這樣沒關係；它 不會 被隱藏，而且只要您安裝它，JoyPro 就會找到它。

您可以做的事：

  1. 取消勾選找到的遊戲（您沒有或不在意的遊戲）：它會在 JoyPro 的所有地方被隱藏（遊戲卡片、匯出卡片、監看程式、遊戲清單）。您為它設定的綁定會保留在設定檔中。
  2. 安裝在其他位置的遊戲（可攜式副本、其他磁碟機）：勾選它，然後按 安裝位置 旁的 瀏覽... 選擇它的資料夾，或按 .exe... 選擇遊戲的程式或啟動器。
  3. 操控設定儲存於：有些遊戲會把控制設定存在您的使用者資料夾中。如果您的設定在其他地方，例如 Saved Games\DCS.openbeta 而不是 Saved Games\DCS，請按那裡的 瀏覽...。
  4. 按 完成。稍後 會關閉視窗，不變更任何東西。
  5. 或按 完成，並全部幫我設定好：JoyPro 會儲存您的遊戲，並自動設定您的搖桿。請參閱 快速入門。
提示

按下 完成 後，JoyPro 會從您自己的安裝為您擁有的每款遊戲建立指令清單。「開始」頁面會顯示進度，並為仍然缺少的清單顯示通知。

進階

#詳細資料

  • 連結的資料夾會以遊戲的標記檔案（bin\DCS.exe、bin\game\Il-2.exe、X4.exe ...）進行檢查：該列會顯示「已找到標記」，或「找不到標記，但仍保留您選擇的資料夾」。連結的資料夾在所有方面（匯入、匯出、指令清單）都視為安裝位置，偵測永遠不會取代它。
  • 使用偵測結果（安裝位置或設定檔）會忘記您的連結；JoyPro 會重新偵測遊戲。
  • 我沒有（到處隱藏） 會提供給 JoyPro 沒找到的遊戲：不勾選時，遊戲會保持「未安裝」，安裝後就會自動出現；勾選時，遊戲會像未勾選的已找到遊戲一樣被隱藏。
  • 把控制設定存放在安裝位置中的遊戲（IL-2、Falcon BMS、X-Plane ...）會以唯讀方式顯示它們的設定檔位置。
  • 隱藏的遊戲會列在 設定 > 遊戲 的最後面，並附有 再次顯示。
技術細節

#視窗的背後

視窗 Views/GameSetupWindow.axaml（+ .axaml.cs 用於資料夾選擇器、完成和稍後），檢視模型 MainWindowViewModel.GameSetup.cs，列 Models/GameSetupItem.cs。當 ui-settings.json 中未設定 gameSetupDone，且啟動時的偵測（engine games installs）已回應時，視窗會開啟一次。完成 會針對每一個變更的列執行 engine games install set（或 clear）、engine games config set（或 clear），然後為隱藏和顯示的遊戲執行一次 engine games install disable / enable，重新偵測，把設定標示為完成，並啟動 engine db check-updates 以建置缺少的指令清單。參考：遊戲安裝。

#我有這個遊戲

核取方塊已撰寫

「我有這個遊戲」：一開始，JoyPro 找到或您連結的每個遊戲都會勾選。

取消勾選您沒有的已找到遊戲，「完成」就會在 JoyPro 各處隱藏它；勾選您之前隱藏的遊戲，「完成」就會再次顯示它。

#稍後

按鈕已撰寫

工具提示 不做任何變更；設定 > 遊戲 > 重新執行設定可再次顯示此頁

關閉此視窗。不會有任何變更。

#完成

按鈕已撰寫

儲存遊戲並關閉此視窗。

儲存您的選擇並關閉視窗：寫入連結的資料夾和設定位置，隱藏未勾選的已找到遊戲並顯示勾選的遊戲，然後 JoyPro 會重新偵測遊戲，並建立您擁有之遊戲的指令清單。

#完成，並全部幫我設定好

按鈕已撰寫

工具提示 儲存您的遊戲，然後 JoyPro 會自動把重要功能放到您的搖桿和油門上，並顯示結果

儲存遊戲。然後 JoyPro 會自動設定好搖桿。

僅在第一次啟動時：「完成，並全部幫我設定好」會像「完成」一樣儲存您的遊戲，然後 JoyPro 會為尚未指派任何東西的遊戲自行設定您的裝置。

它會找到您的搖桿、油門和腳舵，給每個裝置它通常的工作，並把重要的功能放在飛行員預期的位置。
