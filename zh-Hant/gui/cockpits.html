GUI 頁面

座艙

顯示：

「座艙」頁面是真實和虛構座艙的參考資料，編排方式就像飛行手冊中的座艙章節：選擇一架飛機、它的版本和座位，然後閱讀總覽、每個握把一頁（搖桿、油門、週期桿、總距桿）並附 HOTAS 表格，以及每個面板一頁。它不會變更您的設定檔或遊戲中的任何東西；它幫助您決定哪個功能要放在哪個按鈕上，而 使用此配置 會用一架飛機的搖桿和油門配置開啟設定精靈。

給新手

#三個部分

  • 左側：選擇器。 一個搜尋方塊（「F-16」、「Hornet」、「TMS」）、類型、遊戲、年代、角色 和 國家 的篩選條件、飛機清單，以及它下方的 版本 / Block / Tranche（例如 F-16C Block 50）。
  • 中間：手冊。 座艙總覽 和每個握把的分頁、每個面板一頁的 面板 清單、用來切換上一頁和下一頁的 ◀ / ▶，以及 搜尋此座艙（「battery」、「autopilot」）。
  • 右側（視窗較窄時在上方）：座艙指南。 用淺顯的文字說明每個區域、面板和控制項。它的功能是什麼？ 會開啟控制項的說明。

#握把頁面上會看到什麼

握把的線稿，附有編號標註和 HOTAS 表格：每個控制項和方向一列（按下、長按、按住），每個模式一欄（NAV、A-A、A-G；或 TGP、HUD）。這是真實飛機使用每個按鈕的方式，很適合當作您自己綁定的範本。

#圖片

如果您已安裝的遊戲中有這架飛機，根據我的遊戲產生圖片 會畫出遊戲的座艙，每個可點擊的控制項都會編號，並以遊戲中的名稱標示。對於您沒有的飛機，JoyPro 提供可下載的 圖片包；對於沒有任何遊戲收錄的座艙，則提供上面加了 JoyPro 標籤的 經過驗證的照片。

在遊戲中: 不會寫入任何東西

不會寫入任何東西到遊戲中。與我的設定比較 會在 HOTAS 表格中標示出您開啟的設定檔已經為該遊戲和飛機綁定了哪些功能，讓您一眼就看出還缺少什麼。

進階

#機型變體的按鈕

  • 與我的設定比較：開啟設定檔時，如果您的某個關聯在該遊戲和飛機中涵蓋了 HOTAS 表格中的某個功能，該功能就會加上標記，並顯示關聯的名稱和輸入。隱藏 會移除這些標記。
  • 使用此配置：開啟設定精靈，以該變體的搖桿和油門配置作為您綁定的範本（它的飛機會排在優先清單的第一位）。
  • 匯出此頁（PNG） / 所有頁面（PDF）：把顯示的頁面或該變體的所有頁面，以您的繪圖風格（設定 > 線稿）輸出到 Documents\JoyPro2\Cockpits；開啟資料夾 會開啟它。
  • 座位：有兩個座位（前座和後座）的版本，每個座位各有一組頁面。

#圖片從哪裡來

當您開啟一個變體時，JoyPro 會顯示以下項目中第一個存在的：

  1. 來自您遊戲的圖片：總覽、握把、每個面板一頁。
  2. 來自 JoyPro 發行版的圖片包：JoyPro 會先詢問（下載 / 現在不要；設定 > 隱私權：詢問、一律或永不）。之後它會顯示步驟 1 的遊戲圖片。
  3. 經過驗證的照片：下載後，每張照片一頁，附有 JoyPro 的編號標籤。
  4. JoyPro 自己的線稿。
  • 根據我的遊戲產生圖片 會讀取遊戲自己的檔案（DCS、X-Plane 12、MSFS 2020、IL-2 Great Battles、Nuclear Option、Star Citizen、War Thunder），並在這台電腦上繪製座艙。每張圖片大約需要兩秒；大型 DCS 模組有 50 到 80 張。圖片會和您的遊戲資料存放在一起，絕不會放在遊戲資料夾中。
  • 它旁邊的方塊可以在 遊戲中的圖片 和 JoyPro 線稿（依繪製結果描繪的線稿，採用您的繪圖風格）之間切換。當您有多個遊戲都有這架飛機時，第二個方塊可以選擇要用哪一組。
  • 來自 JoyPro 發行版的圖片包（展開區）：從遊戲繪製的座艙圖片，適用於您無法自行產生的飛機。下載我所有飛機的圖片 或 下載此遊戲的全部內容 會先顯示總大小；下載時會顯示進度，並可取消；總和檢查碼不符的圖片包不會被安裝。
  • 經過驗證的照片：對於沒有任何遊戲提供良好圖片的飛機（客機、太空船、部分直升機和噴射機），下載照片 會從每張照片的原始網址（或網頁封存的副本）取得照片，逐一與 JoyPro 的記錄比對，並保存在這台電腦上。之後手冊中每張照片會有一頁，附有 JoyPro 的編號標籤和照片的來源標示。
  • 照片（在頁面下方）：真實照片的連結。JoyPro 在載入任何照片之前都會先詢問：是、否、座艙一律允許、永不。

#座艙導覽

區域（左側控制台、主面板、頭頂面板）> 面板（「ENG & JET START control panel」）> 控制項（每個開關、按鈕和旋鈕，以及它們的位置）。點選控制項會開啟顯示它的頁面，並圈出它的標註；點選標註會在導覽中選取它。全部展開 / 全部關閉 會展開或關閉所有區域。

技術細節

#頁面的背後

  • 檢視模型：CockpitsViewModel.cs（選擇器、篩選、比較、使用配置）、CockpitsViewModel.Pages.cs（手冊頁面、匯出）、CockpitsViewModel.Guide.cs、CockpitsViewModel.Pictures.cs、CockpitsViewModel.PicturePacks.cs、CockpitsViewModel.VerifiedPhotos.cs；頁面檢視 ManualPageView。
  • 資料：DB\Cockpits\*.json（飛機、變體、控制項、面板）、DB\Cockpits\drawings、line-drawings、guide、photo-labels（每張經過驗證的照片一個檔案）。
  • 在這台電腦上：遊戲圖片在 <data>\GameData\CockpitPictures\<game>\<aircraft>（pictures.json、index.json），經過驗證的照片在 <data>\CockpitPhotos\<aircraft>，連結的照片在下載快取中；照片相關的回答和裝置照片的回答存放在一起（cockpit:<aircraft>）。
  • 引擎：engine cockpits（list、search、get --json 用於 使用此配置、compare 用於 與我的設定比較、render 用於 PNG/PDF、pictures build|status|check、photos）。參考：cockpits、privacy。

#是

按鈕已撰寫5 ×

回答這架飛機的照片問題：「是」會立刻載入它的照片連結，「否」則不會，「座艙一律允許」會不經詢問載入每架飛機的照片，「永不」會停止所有座艙照片。

在選了「否」之後，「顯示此飛機的照片」就等於「是」。
