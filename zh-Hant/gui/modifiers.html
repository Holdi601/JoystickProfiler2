GUI 頁面

修飾鍵

顯示：

修飾鍵是一個切換按鈕：按住它時，其他按鈕會做別的事。一個按鈕，好幾種功能。「修飾鍵」頁面會列出設定檔的切換按鈕，顯示每一個用在哪裡，並可以建立、重新命名和刪除它們。您在 綁定頁面 上把修飾鍵加到綁定上；匯出時會把它寫入每款支援修飾鍵的遊戲。

給新手

#什麼是修飾鍵

大多數搖桿的按鈕比現代飛機的功能少。修飾鍵能讓按鈕加倍：選一個按鈕當切換按鈕（通常是小指撥桿），按住它時，其他每個按鈕都會有第二種功能。

  • 沒有按住切換按鈕：扳機發射機砲。
  • 按住切換按鈕：同一個扳機投放武器。

#頁面

  • 左側：修飾鍵庫。 每個修飾鍵一張卡片：一個勾選方塊、它的按鈕鍵帽（「BTN 5」）、名稱、裝置，以及有多少關聯使用它（「3 個綁定」）。
  • 右上：選取的修飾鍵。 它的鍵帽、裝置和 使用於關聯：每個使用它的關聯。
  • 新增修飾鍵。 輸入一個名稱（「Pinky」），按 錄製修飾鍵輸入，再按下裝置上的切換按鈕，然後按 建立修飾鍵。
  • 底部有 重新命名 和 刪除已勾選的修飾鍵。

#建立您的第一個修飾鍵

  1. 輸入一個名稱，例如 Pinky。
  2. 按 錄製修飾鍵輸入，再按下您想當作切換按鈕的按鈕。
  3. 按 建立修飾鍵。
  4. 前往 綁定 頁面，選擇一個關聯，把修飾鍵加到它的綁定上。要這樣做之後，修飾鍵在遊戲中才會有作用。
在遊戲中: 按住切換按鈕

下次匯出後，這個綁定就需要按住切換按鈕：在 DCS 中，修飾鍵會出現在該飛機的修飾鍵清單中，控制欄位會顯示「Pinky + JOY_BTN1」。不支援修飾鍵的遊戲（請參閱各遊戲頁面）會收到不含修飾鍵的綁定，「檢查」會列出這類綁定。

進階

#詳細資料

  • 暫時修飾鍵。 還沒用在任何綁定上的修飾鍵，無法儲存在設定檔檔案本身中（設定檔把修飾鍵和綁定存在一起）。JoyPro 會把它和設定檔的歷程記錄存在一起（drafts.json），直到您在綁定頁面上附加它為止；再次開啟設定檔時它會回來。
  • 反向。 勾選後，修飾鍵會在 沒有 按住按鈕時生效（「放開時切換」的層）。
  • 同一個按鈕用兩次 會被拒絕：當另一個修飾鍵已經使用該裝置和輸入時，建立修飾鍵 會告訴您（「此輸入已被修飾鍵『Shift』使用」）。
  • 重新命名 會在每個使用該修飾鍵的綁定中變更它的名稱（如果在綁定頁面上選了綁定，引擎會以該關聯作為起點）。遊戲會在下次匯出時看到新名稱。
  • 刪除 會從設定檔的每個綁定中移除勾選的修飾鍵。綁定會保留，只是沒有修飾鍵。JoyPro 會先詢問，復原（Ctrl+Z）可以把它們放回去。
  • 同時也被綁定為一般按鈕的修飾鍵按鈕，會由 檢查 回報。
  • 多個修飾鍵可以組合使用（「Shift A + Shift B」）；配置頁面的綁定模式會在 搭配修飾鍵 下列出某個輸入的所有組合。

技術細節

#頁面的背後

檢視模型：MainWindowViewModel.cs（RefreshModifiersAsync、CreateModifierOnSelectedBindAsync、RenameModifierAsync、DeleteSelectedModifiersEverywhereAsync、RecordModifierInputAsync），暫時修飾鍵存放在 pendingModifiersByName 中，由自動儲存保存（profile-history）。修飾鍵會以 reformer 字串（名稱、裝置、輸入、反向）寫在綁定上。

引擎：engine binds modifier list 填入修飾鍵庫，engine binds modifier add 把修飾鍵加到關聯的綁定上，engine binds modifier rename 和 engine binds modifier remove 修改和刪除它；之後頁面會重新讀取 engine binds list。錄製使用和綁定頁面相同的擷取服務（DirectInput 和鍵盤，錄製逾時和預熱時間來自 設定 > 綁定）。

依遊戲而定：DCS 會把修飾鍵寫入 <aircraft>\modifiers.lua 以及每個綁定的 reformers；IL-2 和使用登錄的遊戲在有自己的組合鍵語法時會使用該語法，重新匯入時會把名稱帶回來（匯入）。
