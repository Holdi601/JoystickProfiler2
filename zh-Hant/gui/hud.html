GUI 頁面

HUD

顯示：

HUD 會在您玩遊戲時把您的裝置顯示在螢幕上，就像直播主的控制器覆蓋層：搖桿圖片會跟著您的搖桿傾斜，推桿和軸會以長條移動，按住的按鈕會亮起並顯示名稱，還有一行文字說明按下的按鈕在執行中的遊戲裡做什麼（「Gear Toggle」）。它可以顯示在遊戲上方、OBS 中，或兩者都顯示，各自有自己的小工具。這個頁面就是它的設計工具。

給新手

#點三下啟動 HUD

  1. 在底部列中開啟 HUD。移動搖桿時，預覽就已經會跟著動了。
  2. 保持勾選 在我的螢幕上（覆蓋在遊戲上方）。
  3. 按 啟動 HUD（在 開始 頁面上也有）。啟動您的遊戲：HUD 會顯示在遊戲上方，而且絕不會搶走遊戲的滑鼠或鍵盤。

停止 HUD（同一個按鈕）會關閉它。您在這裡設定的一切都會保留，重新啟動後也還在。

#螢幕上有什麼

  • 每個裝置一個 小工具：一開始會顯示搖桿、油門和腳舵，面板和鍵盤則是隱藏的（在 小工具 清單中勾選它們）。每個小工具可以顯示裝置的照片、搖桿位置、以長條顯示的軸、按鈕和帽子開關。
  • 飛機小工具：您正在飛的飛機的搖桿和油門，以遊戲畫出的樣子顯示，跟著您的搖桿和油門移動。
  • 遊戲標題：遊戲或 DCS 飛機和它的圖片。
  • 按鈕的功能：最後按下的幾個按鈕，以及它們在執行中遊戲裡的動作。

在預覽中拖曳小工具即可移動它；點一下就能在右側變更它。自動排列 會把它們沿著底部排列：油門和左手裝置在左邊，腳舵在中間，右手搖桿在右邊。

在遊戲中: 您在遊戲中看到的內容

HUD 視窗是透明的，會保持在視窗模式和無邊框遊戲的上方。點擊會穿透它傳到遊戲。它不會出現在工作列或 Alt+Tab 中。獨佔全螢幕會把它遮住（這是 Windows 的限制）：請把遊戲切換成無邊框模式。按下按鈕的那一行會寫出該遊戲和飛機的動作名稱，例如 F-16C 中的「Weapon Release」和 IL-2 中的「Fire guns」。

進階

#HUD 顯示位置

這三種輸出彼此獨立：

輸出 給誰 方式
在我的螢幕上（覆蓋在遊戲上方） 您 遊戲上方的透明視窗
OBS 頁面（瀏覽器來源，透明） 您的直播（建議） JoyPro 只在這台電腦上提供一個頁面；複製 會把它的網址放到剪貼簿
直播視窗（視窗擷取） 使用視窗擷取直播 一般視窗（可以放在遊戲後面），背景為透明或色鍵

取消勾選 在我的螢幕上，就能在乾淨的畫面上遊玩，而直播仍會顯示 HUD；或是在兩者上顯示不同的小工具：每個小工具都有兩個勾選方塊，一個是螢幕（您的螢幕），一個是 OBS（直播）。預覽：我的螢幕 / 直播 會切換設計工具顯示的內容。每秒最多更新次數（15、30 或 60；30 既流暢又輕量）。

#設定 OBS（瀏覽器來源）

  1. 勾選 OBS 頁面（瀏覽器來源，透明），然後按 啟動 HUD。
  2. 按網址（http://127.0.0.1:8765/hud）旁邊的 複製。
  3. 在 OBS 中：Sources > + > Browser。把網址貼到 URL，Width 設為 1920，Height 設為 1080。其他都不需要：背景是透明的，也不需要自訂 CSS。
  4. 選擇性：勾選 Shutdown source when not visible，讓 OBS 在沒有使用它的場景中停止該頁面。

頁面會在一個縮放到來源大小的 1920 x 1080 畫面上，以和應用程式相同的位置和樣式，畫出勾選給直播的小工具。連接埠被其他程式佔用了？請在 連接埠 下選擇另一個，然後重新複製網址。

改用視窗擷取：勾選 直播視窗，選擇背景（透明、綠色、洋紅色、藍色或您的顏色）。在 OBS 中新增 Window Capture，並設定 Capture Method: Windows 10 (1903 and up)；如果使用顏色背景，請加上該顏色的 Chroma Key 濾鏡。如果透明背景在您的 OBS 中顯示為黑色，請改用瀏覽器來源或顏色背景。

OBS 瀏覽器來源如何取得 HUD：先傳送一個頁面，之後只傳送變更。

# 誰 會發生什麼
1 OBS 瀏覽器來源開啟 http://127.0.0.1:8765/hud。
2 JoyPro 傳送頁面：版面配置、樣式和圖片。
3 OBS 開啟 /hud/events。它會保持開啟。
4 JoyPro 傳送狀態（軸、按鈕、按鈕的功能），每秒最多 30 次，而且只在有變化時傳送。
5 JoyPro 當小工具、位置或樣式改變時，再次傳送版面配置。

#小工具

小工具 會列出每個裝置，以及標題、綁定跑馬燈和飛機小工具。重新載入裝置 會重新讀取已連接的裝置；顯示全部 會為您的螢幕勾選每個小工具；自動排列 和 重設位置 會把它們擺好位置。

每個小工具（在預覽或清單中點選它）：

  • 在我的螢幕上顯示、在直播中顯示、大小、此小工具的樣式（HUD 的樣式或任何其他樣式）。
  • 顯示：名稱、類型（搖桿、油門）、圖片、圖片隨搖桿傾斜、按鈕亮起、以名稱顯示按住的按鈕、軸和操縱桿、軸名稱、軸數值、搖桿位置（萬向架）、帽子開關。標題小工具：它的圖片。
  • 圖片：照片（製造商的圖片，已去背）、配置（您在 配置 頁面上的 JoyPro 配置圖片，按下的按鈕會在所在位置亮起）、自動（有照片時使用照片）。
  • 此底座上的握把：適用於可裝多種握把的底座（VPforce Rhino、Virpil WarBRD）；握把決定圖片和按鈕名稱。
  • 搖桿軸：搖桿元素的 X、Y 和扭轉軸從哪裡來。自動 使用裝置自己的軸；如果握把本身是一個沒有軸的獨立裝置，就從它所在的底座取得軸。

飛機小工具：搖桿、油門、油門行程條、搖桿位置、控制項亮起、以名稱顯示按住的控制項；飛機（自動：您正在飛的飛機，或這台電腦上設定的任何圖片）和 跟隨（帶動它的搖桿和油門）。它的圖片來自遊戲自己的座艙圖片（座艙 > 根據我的遊戲產生圖片，或圖片包），否則使用 JoyPro 的真實握把線稿。

#40 種樣式

樣式 有 40 種預設：玻璃、霓虹、極簡，簡潔類（霧面淺色、實況主簡潔、實況主醒目、緊湊、大字、粉彩、僅輪廓），座艙顯示器類（軍用綠色 HUD、琥珀色 MFD、客機 PFD、玻璃座艙、夜視、紅色座艙照明、向量線框、復古終端機、復古戰機、全像），遊戲與類型（太空模擬橘、全像青、賽博龐克、合成波、霓虹粉、賽車、戰術沙色、海軍藍與金、匿蹤、幽靈），色彩主題（極地、沙漠、海洋、日落、皇家、碳纖維）以及易讀性（高對比、高對比淺色、單色、單色淺色）。› 會切換到下一種。

下方：一鍵套用強調色、強調色、按下 和 不透明度，接著是各元素的設計選項：卡片（背景、邊框、圓角、陰影）、文字（字型、大小、字距、顏色、名稱粗體）、搖桿元素（圓環、方形、十字準線、雷達、圓點；大小、光暈）、橫條和拉桿（形狀、高度、空白部分）以及 按鈕和標籤（形狀）。變更任何選項後，樣式會變成「自訂設計（已變更）」：儲存樣式 會以您取的名稱保存它，復原變更 會回到預設樣式，匯出樣式... / 匯入樣式... 可以用檔案分享它，刪除 會移除您自己的樣式。

#按鈕的功能與 DCS 飛機

按鈕的功能：顯示幾行、停留多久（秒）、字型大小、顯示裝置與按鈕 和 僅在遊戲執行時。點擊穿透 讓滑鼠點擊穿過 HUD 視窗（在 HUD 啟動時套用）。

JoyPro 會依處理程序找出正在執行的遊戲（DCS、IL-2、Star Citizen 以及它支援的所有其他遊戲），並只顯示該遊戲的綁定。DCS 還需要知道飛機：請在 DCS 飛機 下選擇，或按 安裝 DCS 掛鉤，讓 DCS 在每次任務開始時告訴 JoyPro 是哪架飛機（一個小型 Lua 檔案，加上 Export.lua 中一行有防護的程式碼，會先備份；移除 會逐位元組把檔案還原；請先關閉 DCS）。檢查 會告訴您掛鉤是否已安裝。

技術細節

#頁面的背後

檢視模型：MainWindowViewModel.Hud.cs（裝置、小工具、版面）、MainWindowViewModel.HudStyles.cs（預設樣式、自訂樣式、匯入/匯出）、MainWindowViewModel.HudStream.cs（輸出、直播頁面、飛機小工具）、MainWindowViewModel.HudAxes.cs（搖桿軸）、MainWindowViewModel.Overlay.cs（啟動/停止、執行中的遊戲、按鈕文字行、DCS 掛鉤）。檢視：Views/HudWindow.axaml、Views/Controls/HudSurface.axaml、HudElements.cs、HudPanel.cs。預設樣式：Models/HudStylePresets.cs。

  • 裝置：engine hud devices 會提供每個已連接裝置的型號、類型、使用的手、產品圖片、軸及其角色、按鈕及其名稱和控制項 ID（Controls，供飛機小工具使用），以及標有按鈕位置的配置圖片。
  • 執行中遊戲的綁定：engine overlay map（--game、--plane、--unit）：已綁定的按鈕及其修飾鍵和標題。帶有修飾鍵的綁定會在按住其修飾鍵時顯示；符合的修飾鍵最多的綁定優先。
  • DCS 掛鉤：engine overlay dcs-hook status / install / remove（--path、--dry-run）：Scripts\JoyProOverlay.lua，加上 Export.lua 中一行以 pcall 包住的程式碼；DCS 會把單位類型傳送到 127.0.0.1:1992（UDP）。掛鉤會呼叫它所取代的其他指令碼（SRS、Tacview）的匯出函式。
  • 直播伺服器：Services/HudStreamServer.cs、HudStreamHub.cs、Resources/hud-stream.html；只繫結到 127.0.0.1，使用其他主機名稱的要求會被拒絕。GET /hud（頁面）、/hud/events（Server-Sent Events：layout、state）、/hud/img/<id>（PNG 圖片）、/hud/state（JSON）。沒有頁面連線時，它只會監聽。
  • 遊玩時的負擔：Services/HudInputPump.cs 只保留每個裝置最新的報告，並以選定的頻率套用；元素只在變更時重新繪製；每份報告都不會配置記憶體；圖片只裁切一次（飛機握把高 480 px）。由 HUD 長時間穩定性測試依 CPU、配置和記憶體預算進行測量。
  • 設定：%APPDATA%\JoyPro2\hud.json（位置、大小、每個小工具在螢幕和直播的勾選、含所有選項的樣式、自訂樣式、輸出、連接埠、背景、更新頻率）。樣式檔案：*.joypro-hudstyle.json（"format": "joypro-hud-style"）。
