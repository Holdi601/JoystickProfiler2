GUI 頁面

配置

顯示：

「配置」頁面會顯示您每個裝置的圖片，以及每個按鈕、帽子開關和軸的功能。它有兩個區段，在頂端切換：裝置圖片（一次一個裝置：查看、修正標記、在圖片上綁定）和 速查表（所有裝置的可列印圖片，每架飛機一份）。這個頁面上的任何東西都不會變更遊戲，只有在 綁定 模式中建立的綁定例外，它會像其他綁定一樣加入您的設定檔。

給新手

#什麼在哪裡？（配置視窗）

什麼在哪裡？ 會開啟一個顯示您所有裝置的視窗。每個控制項旁邊都會寫出它在遊戲中的功能。您可以在本頁右上角、「開始」頁面和系統匣選單中找到它。

  1. 選擇一個 遊戲 和一架 飛機。
  2. 按下按鈕，或移動軸或帽子開關。它那一列就會亮起來，功能也會以大字顯示在頂端。
  3. 飛行時可以把視窗放在第二台螢幕上。它會回到您上次放的位置。

跟隨遊戲 會切換到您正在玩的遊戲，在 DCS 中還會切換到您正在飛的飛機。更多資訊：什麼在哪裡？查看每個按鈕的功能。

#DCS 膝板上的綁定

JoyPro 可以在每架 DCS 飛機的膝板上放一頁您的綁定。您可以直接在座艙中閱讀。

  1. 按本頁頂端的 速查表。
  2. 找到 膝板 區塊。保持 DCS 膝板（OpenKneeboard 也可顯示）。
  3. 按 放到膝板上。
  4. 啟動 DCS，進入一架飛機，然後打開膝板。您的頁面就在那裡。

變更了按鈕？再按一次 放到膝板上：JoyPro 會取代它自己的頁面。您的其他膝板頁面會保留。更多資訊：在 DCS 膝板上查看我的綁定。

#裝置圖片

  • 左側：您的裝置。 每支搖桿、油門、腳舵或面板一張卡片，顯示它的型號，以及「您的配置 · 47 個標記」或「參考圖片」。點一張卡片就會顯示它的圖片。型號... 用來指定它是哪個型號（如果 JoyPro 猜錯了）；交換按鈕會把它的綁定移到另一個裝置。
  • 中間：圖片。 JoyPro 畫的裝置線稿、製造商的照片或您自己的照片，每個輸入上都有一個標籤說明它的功能（「Weapon Release」、「Gear Up/Down」）。
  • 右側：選取的輸入（點一個標籤或圖例中的一列）和 圖例：裝置的每個輸入和它的綁定，「25 個輸入中有 7 個已綁定」。

#三種模式

  • 檢視（V）：查看每個輸入的功能。
  • 編輯（E）：把標籤拖到真正的按鈕上、使用您自己的照片、啟動標記助理。
  • 綁定（B）：點一個輸入，在右側選擇一個關聯，然後按 綁定到此輸入。這個綁定會加入您的設定檔。

#速查表

您裝置的圖片，每個綁定都寫在按鈕旁邊，可以列印出來或放在第二台螢幕上。勾選裝置、遊戲和飛機，選擇 每個裝置一份總覽 和／或 每架飛機一張，然後按 建立速查表。圖片（PNG）會存到輸出資料夾；預覽會顯示它們。

在遊戲中: 速查表和綁定模式

速查表會顯示按鈕在一架飛機中的功能；在預覽方塊中選擇遊戲時，會使用該遊戲自己的指令名稱。在 綁定 模式中建立的綁定，會在下次匯出時寫入遊戲，就像在「綁定」頁面上錄製的綁定一樣。

進階

#會顯示哪張圖片

  1. 您自己的配置檔（JoyPro 1 的配置圖、您選擇的圖片）。
  2. 您拍的裝置照片。
  3. 製造商的參考照片（每個視角一張），只有在您同意後才會下載。
  4. JoyPro 的裝置線稿。
  5. 該類型的外框（搖桿、油門、腳舵 ...）。

畫布上方的圖片列中，裝置的每張圖片都有一個按鈕。3D 按鈕旁的方塊用來選擇繪圖風格：連線 或粗輪廓下的平塗色彩（顏色在 設定 > 線稿 中設定）。有 3D 模型的裝置會有 3D 視圖：拖曳可旋轉，滾輪可縮放，按兩下可重設。速查表列印的是平面線稿，編輯模式也是在平面線稿上操作。

#這是哪個型號？

JoyPro 會依 USB ID、名稱和裝置回報的輸入，對照包含數百種型號的目錄來識別裝置。當它無法判斷時（可換握把的底座、多種產品共用一個 USB ID、未知的裝置），會在圖片上方詢問：是哪一個？，並以圖塊列出候選型號，最可能 的排在最前面，另有 採用最可能的、未列出：搜尋目錄、現在不要。對於未知的裝置，您還要選擇它的類型。型號... > 選擇其他型號... 隨時都可以重新詢問。

#標記助理

當顯示的圖片還不知道任何部件的位置時（「此圖片上尚無位置」），標記助理可以在一分鐘內把它們放好：

  1. 放置標記（只缺少幾個時則為 放置它們）。
  2. 按下裝置上的按鈕或帽子開關方向（其他裝置會被忽略），或選擇 更多 > 軸 並移動一個軸。
  3. 在圖片上點選該部件的位置。
  4. 重複以上步驟；完成 會儲存。

如果裝置不在手邊，現在放置：X 會說出下一個輸入的名稱；按一下即可放在那裡，稍後 會在其他輸入之後再詢問它，沒有位置的輸入會以標籤顯示，您可以把它們拖曳到圖片上。復原 會撤回上一次放置；略過 會跳到下一個輸入；停止 會暫停。更多 包含軸、停止、新增控制項（JoyPro 不認識的控制項：按鈕、開關、帽子開關、迷你搖桿、旋鈕編碼器、軸）以及 從圖片中移除。

#偵測到的位置（實驗性）

更多 > 偵測到的位置（實驗性） 會在照片上看起來像按鈕、帽子開關或開關的位置畫出細虛線圓圈。在圓圈附近按一下（或放下標籤），標記就會放在圓圈的中心。JoyPro 不知道某個位置是哪個輸入，所以不會自行放置任何東西；它只適用於照片，不適用於 JoyPro 的線稿，而且可離線運作。

#表格與連線

在已知位置的圖片上，表格（工具列）會畫出 JoyPro 1 的速查表樣式：圖片周圍每組控制項各一個表格，有連線指向各部件，每一列顯示綁定的關聯，第二欄顯示修飾鍵綁定。預覽方塊用來選擇各列顯示的內容：關聯名稱，或某個遊戲和飛機，並使用該遊戲自己的選單標題。在編輯模式下，您可以拖曳表格（它會被固定）、表格的右邊緣、連線的線段或某個點；側邊面板有 修飾鍵欄、列 + / 列 −、已固定、重新繞線、移除連線、拆成單一表格、重新群組、自動排列 和 重設。從 將關聯拖曳到某一列 拖曳出的關聯放到某一列上，就會綁定在那裡。

#一頁多個視圖

多視圖 會在一頁上放置同一裝置的多張圖片（正面和側面，讓每個按鈕都涵蓋到）：新增視圖、您的影像...、排列、編輯此視圖、移除視圖、移除頁面、回到單一圖片。頁面格式在列印時為 A4 或 Letter，在螢幕上為 16:9 / 21:9 / 32:9。速查表會列印整個頁面。

#修正 JoyPro

當某個輸入缺少或位置錯誤時，請在編輯模式中修正（拖曳、新增控制項、從圖片中移除、在圖例中重新命名）。所有內容都會保存在這台電腦上，作為您疊加在 JoyPro 資料之上的一層。將修正傳送給 JoyPro... 會把變更存成一個小檔案，並在 GitHub 上開啟預先填好的問題回報表單；要不要送出由您在那裡決定。型號... > 重設為 JoyPro 預設值... 會移除您對某個裝置的所有變更（會先詢問；復原重設 可以把它們放回去）。

#按鍵

V / E / B 切換模式，N 放置標記（配置檔），Del 移除，Ctrl+Z / Ctrl+Y 復原和取消復原，Ctrl+S 儲存，+ / - 縮放，0 或 F 符合視窗大小，編輯模式下用方向鍵微調（Shift：10 px），按住 Alt 拖曳時不會自動對齊，拖放進來的圖片檔會成為您的裝置照片。
