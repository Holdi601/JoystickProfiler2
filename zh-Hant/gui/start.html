GUI 頁面

開始

顯示：

JoyPro 開啟時會顯示「開始」頁面。它會顯示已設定的內容、接下來要做什麼，以及您的遊戲：匯入 會把您在遊戲中建立的綁定帶進 JoyPro；匯出 則把它們寫回去。逐步說明匯入：匯入遊戲。

給新手

#由上到下

  • 通知：缺少的必要元件、需要建立或更新的指令清單、要傳送的當機報告、可用的更新。
  • 設定您的裝置：自動設定卡片。JoyPro 會查看（唯讀）您哪些遊戲還沒有指派任何東西，並列出它們的名稱：「為 War Thunder 和 Star Citizen 設定裝置」。全部幫我設定好（藍色按鈕）會自動完成一切；逐步設定... 會開啟設定精靈，並勾選這些遊戲。您自己建立過綁定的遊戲列在它下方：匯入，然後填補空缺 會先把您的綁定帶進來，然後設定只會使用空著的控制項。已在設定檔中的遊戲：填補空缺...。什麼在哪裡？ 會顯示您的裝置，以及每個控制項的功能。
  • 一覽設定檔：關聯（以及其中有幾個是軸）、有幾個已綁定、修飾鍵、已連接的裝置、已安裝的遊戲。
  • 後續步驟：JoyPro 目前的建議（「3 個關聯還沒有按鈕：綁定它們」、「VPforce Rhino FFB Base 尚未使用：自動指派」、「把您的綁定寫入遊戲：匯出」）。
  • 您的遊戲：每款遊戲一張卡片，包含 匯入、匯出、更新（它的指令清單）、復原匯出、監看變更 和一個隱藏按鈕。自動設定我的裝置... 會執行設定精靈。
  • 您的裝置：已連接的裝置和它們的圖片；點一下會開啟「配置」頁面。裝置上出現橘色的 哪個握把？ 或 哪個型號？，表示 JoyPro 無法分辨它是哪一個：點一下就會開啟「配置」頁面並顯示選項，您的答案會被保留。
  • 每款遊戲的 近期活動 和遊戲監看開關；HUD 卡片。
進階

#匯入精靈

  1. 選擇一個遊戲（按它卡片上的 匯入）。
  2. 選擇方式：加入我的設定檔（建議） 或 從此遊戲重新開始、鍵盤、未連接的裝置、DCS 飛機。先預覽 會在輸出面板中顯示遊戲有哪些內容，而不會變更任何東西。
  3. 立即匯入：結果會留在卡片上方（「完成：您的設定檔現在有 214 個關聯」），並附上 查看我的關聯。

在卡片下方，進階匯入 提供每個遊戲的所有選項（DCS、IL-2、Star Citizen，以及 載入遊戲 中的所有其他遊戲），可以掃描 / 匯入 / 匯出。

#在寫入任何內容之前停止指令（JoyPro 僅在讀取期間提供此功能）

按鈕已撰寫

忙碌區域中的「取消」：要求正在執行的引擎指令在下一個安全點停止；標籤會變成「正在取消...」。

JoyPro 只在指令仍在讀取時才提供這個選項，所以它停止時還沒有寫入任何東西。

#一律下載

#否

#開

開關已撰寫

工具提示 遊戲關閉後，JoyPro 會詢問是否將您在遊戲中變更的綁定帶入您的設定檔

遊戲監看的主開關：遊戲關閉後，JoyPro 會詢問是否要把您在遊戲中變更的綁定放進您的設定檔。

只有勾選「監看變更」的遊戲會被監看；關閉時，不會監看任何遊戲。
