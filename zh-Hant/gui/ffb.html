GUI 頁面

力回饋

顯示：

JoyPro 會從您正在飛的遊戲讀取即時遙測資料（空速、攻角、G 力、起落架、機砲、命中……），並把它轉換成 VPforce Rhino 這類力回饋搖桿上的力道：失速抖振、G 力下的搖桿重量、起落架和襟翼的震動、機砲連射、跑道震動，以及隨空速變硬並跟隨配平的置中彈簧。搖桿的行為是一張由節點組成的圖表，您可以修改它。它適用於 DCS World、IL-2 Great Battles、IL-2 Korea 和 War Thunder。

給新手

#四個步驟取得力回饋

  1. 把頁面的開關切換到 開。JoyPro 現在會每 5 秒尋找一次支援的遊戲；在此之前不會執行任何東西。
  2. 在 裝置與力 下按 重新整理，然後選擇您的力回饋搖桿。一開始先把 強度 和 最大力量 保持原樣（最大力量會限制每個效果，預設為 60 %）。
  3. 按 ↔ 方向測試。JoyPro 會輕輕推動搖桿，並詢問它往哪個方向移動：請用按鈕回答。它會幫您設定 反轉 X / Y，並檢查置中彈簧和配平。
  4. 在 遊戲 下選擇您的遊戲，然後按 遙測匯出 下的 安裝（請先關閉遊戲）。這會讓 DCS 或 IL-2 把遙測資料傳給 JoyPro（War Thunder 會自己傳送）。然後就可以飛了。
關閉遊戲自己的力回饋

JoyPro 會自己驅動搖桿。請關閉遊戲對該搖桿的力回饋（DCS：飛機的 FFB 選項；IL-2：Settings > Input devices；War Thunder：關閉力回饋），否則遊戲會佔用裝置，JoyPro 就無法傳送力道。

在遊戲中: 您會感覺到什麼

接近失速時搖桿會抖動；承受 G 力時會變重；起落架和襟翼移動時會震動；在跑道上會隨速度震動；機砲會一陣一陣地後座；被擊中時（IL-2）會往側面震一下。飛得越快，置中彈簧就越硬，而配平（遊戲的配平，或 JoyPro 自己的配平按鈕）會移動它的中心。在選單中或遊戲暫停時，JoyPro 會停止所有效果並放開搖桿（如果置中彈簧是由 JoyPro 提供的，只有它會保留）。

進階

#設定頁籤

裝置與力：裝置、強度（所有效果）、最大力量（每個軸的硬性上限：任何效果或效果總和都不會超過它）、方向（反向 X / 反向 Y，依裝置儲存）、↔ 方向測試、回中（「由 JoyPro 提供回中彈簧」，配平需要）以及 彈簧硬度（圖表沒有提供彈簧的軸所用的一般彈簧）。

方向測試，逐步進行（每一步都會等待 ▶ 就緒；■ 取消 隨時可以停止所有力）：

  1. 按 ▶ 開始。JoyPro 會把搖桿往右推 2 秒（20 %）。回答：它往哪個方向移動？
  2. JoyPro 會把搖桿往前推 2 秒。回答：它往哪個方向移動？
  3. 回中彈簧。回答：它會彈回來嗎？
  4. 配平：中心點往前移動 35 %。回答：它有移動並停住嗎？

第 4 步之後，反向 X / Y 會為這個裝置儲存。↻ 重複此步驟 會重做目前的步驟。

「它沒有移動」會保留該軸的設定，並說明要檢查什麼（在 VPforce 搖桿上：必須關閉 Configurator 自己的彈簧才能配平）。⏮ 重新開始 會從頭開始。測試需要獨佔搖桿：當 JoyPro 的力回饋正在為某個遊戲執行時，測試會拒絕啟動。

遊戲：選擇一個遊戲、此遊戲的力回饋、它的 強度、它的 圖表（內建 或您的某個圖表檔案；在編輯器中開啟）、內建圖表各效果的開關（buffet、gforce、gear、flaps、speedbrake、runway、shake、guns、hits、spring）、有自己圖表或強度的飛機（新增飛機、移除）以及 遙測匯出（安裝、移除、試執行）。強度是相乘的：全域 x 遊戲 x 飛機，然後再套用最大力量上限。

#圖表編輯器

圖表決定遙測資料如何變成力。數值經由連線從左流到右，正規化為 0..1（方向有意義時為 -1..1）：

  • 遙測 節點讀取遊戲的一個鍵（ac.ias、ac.aoa、ac.g ...），並以最小值/最大值正規化。
  • 群組、曲線（可拖曳的 Bezier 曲線）、數學運算和有狀態的節點（低通、變化率限制、門檻）會塑造這些數值。
  • 輸出 就是效果：恆定力、週期性（正弦波、方波、三角波、鋸齒波；強度和頻率由輸入對應而來）、彈簧（硬度，中心 = 配平）、阻尼、摩擦。同一軸和同一槽位上的同類輸出會互相競爭（最強的勝出）；不同槽位的會相加。
  • 來自您裝置的 輸入：裝置按鈕 / 帽子開關（任何裝置；⏺ 現在請按下按鈕... 會擷取它）、搖桿位置、配平（⇕ 指派配平按鈕 會要求六個按鈕：配平到搖桿位置、機頭朝下、機頭朝上、左、右、重設）。

選擇節點類型並按 加入圖表，從一個連接埠拖曳到另一個連接埠來連線，選取後按 刪除選取項目。由內建圖表新增 會從 JoyPro 飛行圖表的副本開始；儲存 / 另存為 會寫入圖表檔案，載入 / 重新掃描 會讀取它們。然後在設定頁籤上為遊戲或飛機選擇該圖表。

#遙測檢視器

即時顯示執行中遊戲的每個遙測鍵，以及它的數值、標題和單位。可依鍵或標題篩選。用它來查看要在遙測節點中填入哪個鍵，以及它的範圍。

技術細節

#頁面的背後

檢視模型：MainWindowViewModel.FfbTelemetry.cs（設定、遊戲、飛機、安裝設定、處理程序）、MainWindowViewModel.FfbDirectionTest.cs（測試精靈）、FfbGraphEditorViewModel.cs（編輯器）；Views/Controls/FfbGraphCanvas.cs、FfbCurveEditor.cs。力回饋在自己的處理程序 JoyPro.Ffb.exe 中執行（gui/JoyPro.Ffb，圖表引擎在 gui/JoyPro.Ffb.Core）。

從遊戲啟動到放開搖桿的力回饋處理程序：

# 誰 會發生什麼
1 JoyPro 頁面為開啟時每 5 秒檢查一次：是否有支援的遊戲正在執行？
2 JoyPro 啟動力回饋處理程序：JoyPro.Ffb run --game DCS --game-pid N --parent-pid M --protocol。
3 遊戲 傳送遙測資料（DCS 使用 UDP 連接埠 41992）。
4 力回饋處理程序 在第一個力道出現時（獨占）接管搖桿。之後在遙測資料抵達期間，每秒 50 次，只傳送有變化的效果值。
5 力回饋處理程序 遙測停止（選單、暫停）：STOP ALL，並放開搖桿（開啟「回中彈簧」時彈簧保留）。
  • 生命週期：處理程序透過遊戲的處理程序控制代碼追蹤遊戲，並隨遊戲或 JoyPro 一起結束。每個恆定力和週期性力的持續時間都是 0.3 秒，並會重新啟動，因此當處理程序停止回應或被終止時，不會有力殘留在搖桿上。遙測逾時（0.5 秒）、遊戲結束、JoyPro 結束以及發生任何錯誤時，都會 STOP ALL。
  • 設定：<data>\Ffb\Telemetry\telemetry-ffb.json（<data> = %LOCALAPPDATA%\JoyPro2）；圖表位於 <data>\Ffb\Telemetry\Graphs\*.jpffb.json（格式 joypro-ffb-graph）；最後的狀態在 status.json 中。
  • 引擎：engine ffb telemetry status（頁面的狀態）、engine ffb telemetry config set / engine ffb telemetry config clear（--game、--plane：依遊戲和飛機）、engine ffb telemetry effects、engine ffb telemetry setup dcs 以及其他遊戲的安裝設定（安裝、移除、--dry-run；遊戲檔案會先備份）。
  • 遊戲：DCS（Export.lua 中的一行，UDP）、IL-2 Great Battles 和 Korea（遊戲的遙測裝置輸出，UDP）、War Thunder（遊戲在連接埠 8111 上的本機網頁伺服器，不需設定）。在 設定 > 遊戲 中隱藏的遊戲不會顯示，也不會被搜尋。
  • 方向：正向的力在 X 軸上往右推，在 Y 軸上往飛行員方向推；依裝置（以執行個體 GUID 區分）反向 X / Y 會翻轉力和彈簧中心。

參考：ffb-telemetry，錄製相同的遙測資料：telemetry-recording。
