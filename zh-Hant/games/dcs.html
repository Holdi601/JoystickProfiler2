給新手

#3 個步驟就能用

  1. 全部幫我設定好
    在「開始」頁面
  2. 使用這些按鈕
    先查看清單
  3. 寫入我的遊戲
    保持 DCS 關閉

事前準備：如果「開始」頁面上的 DCS 卡片要求指令清單，請先按 建立清單。

接著：啟動 DCS。您的綁定會依飛機出現在 Options > Controls 中。

您之前在 DCS 中綁定過按鈕嗎？那麼「開始」頁面會提供 匯入，然後填補空缺。您的綁定會保留，只有空閒的按鈕會被指派新功能。請參閱 快速入門：讓我的搖桿能用。

#功能要放在哪裡？

設定過程會用一個滑桿問您一個重要問題。這在 DCS 中最重要，因為您會飛很多不同的飛機。

左端 右端
每架飛機同一件事用同一按鈕 依真實飛機的位置
每架飛機的起落架都在同一個按鈕上。容易學習。 每個按鈕的作用都和真實搖桿上同一位置的按鈕相同。

快速設定會使用您上次的選擇（第一次是中間）。機槍和油門永遠不會變動。請參閱 功能應該放在哪裡？。

#沒有頭部追蹤也能環顧四周

沒有 TrackIR，也沒有 VR？設定過程會把環顧四周放到您搖桿的一個帽子開關上：前、後、左、右。油門上的拇指搖桿可以用來控制視角軸。請參閱 頭部追蹤與環顧四周。

設定過程會先問一個問題：您使用頭部追蹤或 VR 嗎？ 是（頭部追蹤、臉部追蹤、Tobii 或 VR，或您打算購買一個）：您的裝置上不放視角按鈕，只放「視角置中」。否：環顧四周會放在您搖桿的帽子開關上順手的位置。

#膝板上的綁定

DCS 可以在膝板上為每架飛機顯示一頁。JoyPro 會把您的按鈕清單放到那裡：開啟 配置，按 速查表，然後按 放到膝板上。在座艙中打開膝板：您的頁面就在那裡。請參閱 在 DCS 膝板上查看我的綁定。

#JoyPro 為 DCS 做了什麼

  • 匯入：每架飛機在您搖桿、油門和腳舵上的綁定，會連同您的修飾鍵和軸設定一起進入您的設定檔。預設情況下，您裝置上生效中的 DCS 預設綁定也會一起匯入，這樣再次匯出時就不會遺失任何內容。
  • 關聯：一個關聯就是所有飛機中的同一個功能。「Weapon release」可以是 F-16C 和 A-10C II 中的投彈按鈕，在您的搖桿上只用一個按鈕。
  • 匯出：JoyPro 會寫入每架已勾選飛機的檔案。之後 DCS 就會在 Options > Controls 中顯示您的綁定。

#匯入您的 DCS 綁定

  1. 開啟 開始 頁面。DCS 卡片會顯示遊戲的圖片。如果卡片要求指令清單，請先按 建立清單：JoyPro 會用 DCS 自己的 Lua 讀取每個已安裝的模組（DCS 保持關閉；需要幾秒到一分鐘）。
  2. 在 DCS 卡片上按 匯入。保持勾選 我所有的 DCS 飛機，或取消勾選後挑選您飛的飛機。
  3. 按 立即匯入。查看我的關聯 會開啟匯入的內容。

#建立並檢查關聯

在 關聯 頁面上，每個關聯會依飛機列出其動作。使用飛機篩選器查看單一模組，並使用 關聯流程 把多架飛機的動作合併到一個關聯中。接著在「匯出」頁面按 檢查：它會在 DCS 之前找出在同一架飛機中同時做兩件事的按鈕。

#匯出到 DCS

  1. 關閉 DCS。 DCS 執行期間 JoyPro 會拒絕寫入，因為 DCS 在結束時會寫入自己的檔案。
  2. 開啟 匯出。在 DCS 卡片上，飛機... 會列出您設定檔中的每架飛機：只有已勾選的飛機會被寫入，其他飛機的檔案會完全保持原樣。
  3. 如果您是用 JoyPro 設定搖桿，請保留第一個選項 取代我的裝置上的綁定 和 同時清除我的其他裝置。然後在 DCS 卡片上按 立即匯出。
在遊戲中: 您在 DCS 中會看到什麼

啟動 DCS 並開啟 Options > Controls，然後在上方選擇飛機。您的綁定會以 DCS 自己的指令名稱出現在您裝置的欄位中；JoyPro 移除的 DCS 預設綁定會顯示為空白儲存格；您的修飾鍵會出現在 DCS 的修飾鍵清單中。軸曲線會顯示在該軸的 Axis Tune 中。您沒有勾選的其他飛機看起來和以前一樣。

#您在 DCS 中需要自己做的事

  • 綁定不需要其他任何步驟。如果您使用其他 Saved Games 資料夾（例如 Saved Games\DCS.openbeta），請在 設定 > 遊戲 的 操控設定儲存於 中設定一次。
  • 為了讓 HUD 知道目前的飛機，以及從遙測資料產生力回饋，JoyPro 會在 DCS 中安裝一個小型腳本，只需一次（請參閱「進階」）；這時也請關閉 DCS。

#常見問題

  • 「DCS 正在執行」：關閉 DCS（包括啟動器的背景程序），然後重新匯出。
  • 某架飛機保留了舊的綁定：在 DCS 卡片的 飛機... 中沒有勾選它，或者設定檔中沒有它的關聯。
  • 搖桿上有您從沒設定過的綁定：這些是 DCS 在 JoyPro 沒有寫入的裝置上的預設綁定。請勾選 同時清除我的其他裝置，或參閱下方的 預設綁定。
  • 兩個相同的裝置：DCS 以執行個體 ID 區分它們；請保持開啟 將同名裝置視為同一裝置，這樣 Windows 指派了新 ID 的裝置仍會被視為同一個裝置。
  • DCS 顯示的某個指令「不在清單中」：它是由模組加入的（例如搭配社群按鍵包的 Input Command Injector）。當「開始」頁面顯示 您的 DCS 模組變更了控制清單；請重新產生命令清單 時，請在該頁面按一次 重新整理 DB：JoyPro 會用和 DCS 相同的方式讀取模組的指令。在此之前，JoyPro 在您的 DCS 綁定檔案中找到的指令已經是已知的，並會標示為 來自您的 DCS 檔案。
進階

#JoyPro 讀取和寫入的檔案

檔案 這是什麼
%USERPROFILE%\Saved Games\DCS\Config\Input\<aircraft>\joystick\<device>.diff.lua 一架飛機中一個裝置上的綁定，以相對於 DCS 預設值的差異儲存（keyDiffs、帶有 added / removed 的 axisDiffs、ffDiffs）
...\<aircraft>\joystick\<device>.jp JoyPro 的副本，含關聯名稱和群組，下次匯入時會讀回
...\<aircraft>\keyboard\Keyboard.diff.lua 鍵盤（僅在您匯出鍵盤綁定時）
...\<aircraft>\modifiers.lua 飛機的修飾鍵

<aircraft> 是模組宣告的輸入設定檔名稱（例如 F-16C_50、FA-18C_hornet）。其他 Saved Games 資料夾（DCS.openbeta）可在 設定 > 遊戲 中設定。檔案寫入時不含位元組順序標記（BOM），因為 DCS 的 Lua 無法載入它。

#來自模組的指令

有些模組會在 DCS 的控制清單中加入指令：

  • Input Command Injector（Quaggles 製作，常搭配社群按鍵包）：額外的指令位於 Saved Games\DCS\InputCommands\<module>\Input\<profile>\joystick\default.lua（以及 keyboard），而 DCS 安裝中的注入器（Scripts\Hooks）會在 DCS 載入控制設定時，把它們併入模組自己的清單。
  • 位於 Saved Games\DCS\Mods\aircraft 的模組：它們帶有自己的指令清單。

JoyPro 的指令清單（建立清單 / 重新整理 DB）會以和 DCS 相同的方式讀取它們：從您的 DCS 安裝實際使用的 Saved Games 資料夾讀取（OpenBeta 安裝為 DCS.openbeta），已安裝注入器時會併入注入器的指令，並使用與 DCS 相同的指令 ID。當您的模組變更時，「開始」頁面會顯示 您的 DCS 模組變更了控制清單；請重新產生命令清單；按一次 重新整理 DB 就會帶入新的指令。

如果某個指令存在於您的 DCS 綁定檔案中，但尚未在指令清單中（例如在建立清單之後才加入的模組），JoyPro 仍然認得它：JoyPro 會從檔案取得它確切的 ID 和名稱，在「關聯」頁面上標示為 來自您的 DCS 檔案，並由「開始」頁面建議重新建立清單。

檔案 這是什麼
Saved Games\DCS\InputCommands\... Input Command Injector 的額外指令（唯讀）
<data>\GameData\DcsCommandsFromYourFiles.tsv 在您的 DCS 綁定檔案中找到、但指令清單中沒有的指令

#DCS 的匯出模式

每種模式都以裝置檔在 DCS 中 生效 的綁定為基礎：裝置的預設值，減去檔案移除的部分，再加上檔案新增的部分。之後 JoyPro 只寫入與預設值真正不同的部分，就像 DCS 自己會做的那樣。

模式 匯出的飛機中會發生什麼
僅新增 不會移除任何東西。如果綁定的按鈕已被 DCS 用於另一個指令（包括 DCS 預設值），就不會寫入，並標示為「未寫入遊戲」。
更新，保留遊戲的綁定 寫入您的綁定；DCS 的預設值和您在遊戲中的綁定都保留，但您使用的按鈕上其他指令的綁定除外。
更新，以我的設定檔為準 同上，而且您綁定的每個指令在該飛機中會失去其他按鈕（在每個裝置檔，以及沒有檔案的已連接裝置上；DCS 預設值也算在內）。
取代我的裝置上的綁定 您寫入的裝置在匯出的飛機中只會有您的綁定，DCS 預設值會被移除。
+ 同時清除我的其他裝置 在該飛機中沒有綁定的已連接裝置，會失去在那裡的所有綁定，包括 DCS 預設值。

「匯出」頁面上的選項（位於 選項與路徑（進階） 下）：

  • 保留鍵盤預設值（開啟）：不寫入鍵盤檔案。關閉：寫入您的鍵盤綁定，並只移除被它們佔用的 DCS 預設按鍵；其他所有預設按鍵都保留。
  • 我的裝置在其他所有飛機中也失去 DCS 預設綁定（關閉）：搭配「取代」時，寫入的裝置在您沒有匯出的每架已安裝飛機中也會被清空。輸入層（UI layer、camera、general）永遠不會被變更。

#永遠不會變更的內容

  • 未連接的裝置，其檔案會逐位元組保持不變。
  • 匯入時忽略的裝置，以及 JoyPro 轉送輸入的 vJoy 裝置，永遠不會被清除。
  • 在任何模式下，鍵盤都不會被清除或接管；滑鼠綁定永遠不會寫入。
  • 您沒有勾選的飛機，以及輸入層（UI layer、camera、general layer）會保留它們的檔案。
  • 被清空的裝置檔中的力回饋設定（ffDiffs）會保留。

#預設綁定

DCS 會依飛機為每種裝置類型提供各自的預設值（Warthog 搖桿的預設值與一般搖桿不同）。JoyPro 透過它依據指令清單從您的 DCS 建立的 乾淨設定檔 得知這些預設值：每架飛機和每種裝置類型各一份。「取代」和「同時清除」會從它們寫入的裝置上精確移除這些預設值。

對於 JoyPro 不寫入的裝置，設定 > DCS：預設綁定 提供兩種直接變更 DCS 安裝本身的做法，除非您開啟，否則兩者都是關閉的：從每個搖桿檔案中移除預設值（每個原始檔案都保留為 <file>.nocombo.bak），或把 DCS 的裝置專屬預設檔案移到 JoyPro 的備份資料夾。修補過的檔案在會強制檢查完整性的伺服器上無法通過檢查；還原 DCS 檔案 會把所有原始檔案放回去。DCS 更新後，JoyPro 會在啟動時重新套用已開啟的選項。

裝置檔只保存與 DCS 預設值不同的部分：在 DCS 中生效的綁定 = 預設值，減去檔案移除的部分，再加上檔案新增的部分。每種匯出模式會決定哪些綁定應該生效；之後 JoyPro 只寫入差異。以下是一架飛機中的範例：

在飛機中 裝置檔中寫入的內容
您保留的 DCS 預設綁定 不寫入：它本來就是預設值（只會列在 .jp 中）
您不想要的 DCS 預設綁定 一行「removed」
您自己的、不是預設值的綁定 一行「added」
調校不同（曲線、反向）的預設綁定 一行「changed」

#飛機、曲線、力回饋

  • 依飛機：每個關聯都會依飛機保存其動作；匯出只會寫入勾選的飛機。
  • 軸曲線：死區、X 和 Y 飽和度、曲率或 11 點的使用者曲線、反向和滑桿，依飛機以 DCS 自己的篩選器寫入（也就是 Axis Tune 所顯示的內容）。預設曲線 適用於所有遊戲；也可以為 DCS 或單一飛機設定曲線（綁定 > 軸回應）。
  • 遊戲內力回饋：設定 > DCS 力回饋 可依裝置設定交換軸、反轉 X 和反轉 Y（engine dcs ffb set）。遙測力回饋：力回饋 頁面會安裝 JoyPro 的掛鉤 Saved Games\DCS\Scripts\Hooks\JoyProFfb.lua（DCS 必須關閉；SRS 或 Tacview 等其他腳本會繼續運作）。
  • HUD：安裝 DCS 掛鉤後，HUD 會顯示您正在駕駛的飛機的綁定（HUD 頁面 > 安裝 DCS 掛鉤：一個小型 Lua 檔案，加上 Export.lua 中受保護的一行，會先備份），您也可以手動選擇飛機。
  • 監看程式：您在 DCS 的 Options > Controls 中變更的綁定會在 DCS 關閉後被偵測到；JoyPro 會詢問是否採用。只會比較檔案有變更的飛機，比較基準是裝置的預設值加上其差異。
技術細節

#DCS 整合的內部運作

程式碼：engine\EngineDcsImport.cs、engine\EngineDcsExport.cs、engine\EngineDcsExport.Modes.cs、engine\EngineDcsRefresh.cs、engine\DcsDeviceNames.cs、engine\DcsCommandNames.cs、engine\EngineDcsDefaultsStrip.cs。

  • 裝置名稱：DCS 將搖桿命名為 <DirectInput instance name> {<instance GUID>}，執行個體名稱與 DirectInput 回報的完全相同，包括頭尾的空格。JoyPro 自己的名稱會去除這些空格；DcsDeviceNames 可雙向轉換。匯出時，檔案會以已連接裝置的原始名稱命名；未連接的裝置沿用現有檔案的名稱；否則使用 JoyPro 的名稱。舊版 JoyPro 以去除空格的名稱寫入的檔案，在沒有 DCS 命名的檔案時會被讀取，並在寫入後移除（已備份）。
  • 指令清單：engine dcs refresh id 會在 DCS 自己的 bin\luae.exe 中執行每個模組的輸入 Lua（不開啟遊戲視窗），同時分成多個執行；無論 DCS 使用哪種語言，英文指令名稱都來自安裝中的 l10n\en\LC_MESSAGES\input.mo。engine dcs refresh clean 會建立乾淨設定檔：使用 DCS 自己的 InputData.clearProfile，為每種裝置類型搭配一個假搖桿，寫入暫存的 Saved Games 資料夾（您的 Config\Input 永遠不會被變更）。檔案：%LOCALAPPDATA%\JoyPro2\GameData\CleanProfile\DCS\<aircraft>.cf、...\<aircraft>\<device type>.cf、KeyboardCleanProfile\DCS\<aircraft>.cf。
  • 匯入：engine dcs import（--planes、--only-connected、--merge-same-name、--include-defaults、--include-keyboard，以及 --import-* 調校參數）；engine dcs scan 會顯示相同內容，但不變更設定檔。
  • 匯出：engine dcs export --mode clean|add|merge|merge-overwrite --nuke-untouched-devices true|false --keep-keyboard-defaults true|false --clean-all-aircraft true|false --planes <csv> --ignore-device <d>；--clear-keyboard-defaults true（僅限命令列）還會移除已寫入飛機的所有其他 DCS 預設按鍵。備份：首次寫入前，每個檔案都會備份為 <file>.jpbak 並存入 %LOCALAPPDATA%\JoyPro2\GameBackups。
  • 檢查：engine dcs verify-clean 會讓 DCS 自己的 Lua 列出您的搖桿上仍然生效的每個預設綁定（唯讀；--include-disconnected 會使用假搖桿，--dump-active 可比較匯出前後的差異）。
  • 安裝中的預設綁定：engine dcs strip-defaults（apply|restore|status|auto，標記行 -- [[DCS_STRIP_JOYSTICK_DEFAULTS v1]]，原始檔保留為 .nocombo.bak，每個修補過的檔案都要先由 DCS 的載入器載入成功才算數）以及 engine dcs device-luas（list|remove|restore；檔案會連同清單檔移到 <data>\DcsDefaults\DeviceLuas）。DCS 或其更新程式執行時，兩者都會拒絕執行。
  • 力回饋：engine dcs ffb list、engine dcs ffb set、engine dcs ffb clear。
  • HUD 掛鉤：engine overlay dcs-hook status（install / remove）：DCS 會將機種傳送到 127.0.0.1:1992。

#已知限制

  • 只有已安裝的模組才會有指令清單和乾淨設定檔。
  • 執行過 DCS 軸精靈的裝置，會保留精靈的指派作為其預設值（wizard.lua，依裝置執行個體）；JoyPro 不會變更它。
  • DCS 在飛機之間共用的輸入層（General、UI layer、Combined Arms）不會寫入。
  • 測試：engine\tests\smoke\dcsexportmodes.ps1（每種模式、往返、逐位元組復原）、smoke\dcskeyboard.ps1、smoke\dcsdefaults.ps1；遊戲內為 tools\e2e\games\DCS.ps1 和 DCSCurves.ps1。
