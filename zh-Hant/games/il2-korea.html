給新手

#3 個步驟就能用

  1. 全部幫我設定好
    在「開始」頁面
  2. 使用這些按鈕
    先查看清單
  3. 寫入我的遊戲
    保持遊戲關閉

事前準備：儲存一次按鍵對應。開啟 Settings > Key mapping 並按 ACCEPT。關閉遊戲。

接著：您的綁定會出現在每架飛機的 Settings > Key mapping 中。

您之前在 IL-2 Korea 中綁定過按鈕嗎？那麼「開始」頁面會提供 匯入，然後填補空缺。您的綁定會保留，只有空閒的按鈕會被指派新功能。請參閱 快速入門：讓我的搖桿能用。

#沒有頭部追蹤也能環顧四周

沒有 TrackIR，也沒有 VR？設定過程會把快速視角放到您搖桿的一個帽子開關上：前、後、左、右。如果您的油門有迷你搖桿，視角軸會放在它上面。請參閱 頭部追蹤與環顧四周。

#JoyPro 為 IL-2 Korea 做了什麼

  • 匯入：按鍵對應中位於搖桿、油門、腳舵或面板上的每個動作，都會連同修飾鍵、每個軸的反向設定和曲線編輯器的值一起進入您的設定檔。如果您要求，鍵盤按鍵也會一併匯入。
  • 關聯：一個關聯就是您所有遊戲中的同一個功能，例如 Korea、IL-2 Great Battles 和 DCS 中的「Gear」都在同一個按鈕上。Korea 所有飛機共用一份按鍵對應。
  • 匯出：JoyPro 會寫入按鍵對應，並為您的每個裝置指定裝置編號，就像遊戲自己的「assign device number」對話方塊一樣。

#匯入您的 Korea 綁定

  1. 開啟 開始 頁面。IL-2 Series: Korea 卡片會顯示遊戲的圖片。如果卡片要求指令清單，請按 建立清單：JoyPro 會讀取遊戲的 general.actions（每個動作都會取得 JoyPro 自己的名稱和說明）。
  2. 在卡片上按 匯入。選擇 加入我的設定檔，如果也要匯入飛行按鍵，請勾選 同時取得鍵盤按鍵。
  3. 按 立即匯入。查看我的關聯 會開啟匯入的內容。

#建立並檢查關聯

在 關聯 頁面上，關聯的 Korea 動作會和您其他遊戲中的同一功能並列。使用 關聯流程 將它們連結起來，然後在「匯出」頁面按 立即檢查：它會找出在 Korea 中同時做兩件事的按鈕（檢查功能）。

#匯出到 IL-2 Korea

  1. 關閉遊戲。 當 IL2Series.exe 正在執行時，JoyPro 會拒絕寫入。
  2. 開啟 匯出。IL-2 Series: Korea 卡片會顯示其中有多少關聯已綁定。
  3. 如果您是用 JoyPro 設定搖桿，請保留 取代我的裝置上的綁定 和 同時清除我的其他裝置。然後在卡片上按 立即匯出。
在遊戲中: 您在 IL-2 Korea 中會看到什麼

啟動遊戲並開啟 Settings > Key mapping。您的綁定會在動作列中（例如 Basic 頁籤上），並標示裝置名稱和編號（「joy 2」）；遊戲不會詢問裝置編號。軸設定列上的曲線圖示會開啟響應編輯器，顯示 JoyPro 寫入的值。力回饋和軸雜訊濾波會顯示在 Settings > Input devices 中。

#您在 IL-2 Korea 中需要自己做的事

  • 儲存一次按鍵對應。 當您在 Key mapping 中按 ACCEPT 時，遊戲會寫入 general.actions。第一次啟動時也會顯示遊戲的使用者協議。沒有 general.actions 就沒有可匯出的目標。
  • 獨立版預設安裝在 Program Files 下，而 Windows 可能會保護該資料夾。這時匯出會明確告訴您，而不會只寫入一半的檔案。
  • 如要使用 JoyPro 自己根據遊戲遙測資料產生的力回饋，力回饋 頁面會把 JoyPro 的位址加入遊戲的 startup.cfg（請先關閉遊戲）。請為該搖桿關閉遊戲自己的力回饋。

#常見問題

  • 「IL-2 Korea 正在執行」：關閉遊戲，然後重新匯出。
  • 裝置被略過：沒有裝置編號又未連接的裝置無法取得編號。請插上它，然後重新匯出。
  • 使用「僅新增」後缺少一個綁定：該輸入在遊戲中已被用於另一個動作。檢查功能會把它列在「未寫入遊戲」下。
進階

#JoyPro 讀取和寫入的檔案

檔案 這是什麼
<install>\data\input\general.actions 按鍵對應設定檔「General」（JSON）：使用的裝置、修飾鍵、每個動作及其輸入、Relative Control 數值
<install>\data\input\known.devices.json 遊戲看過的每個裝置及其裝置編號
<install>\data\input\general.pitch 俯仰曲線（「General (Common pitch curve)」）
<install>\data\input\shared.responses 其他軸的曲線
<install>\data\NSData\UserData\UserSettings.json Settings > Input devices：力回饋和軸雜訊濾波器（input 區段）
<install>\data\startup.cfg JoyPro 的遙測位址（只在您設定遙測力回饋時）
general.actions.joypro-meta.json JoyPro 存放在檔案旁的名稱、群組、修飾鍵和調校，下次匯入時會讀回

Steam 版的 <install> 為 steamapps\common\IL2Series，獨立版則為啟動器下的 game 資料夾。current.map 由遊戲編譯；JoyPro 永遠不會寫入它。

#IL-2 Korea 的匯出模式

模式 遊戲中會發生什麼
僅新增 不會移除任何東西。放在遊戲用於其他動作之輸入上的綁定不會寫入，並會列出。
更新，保留遊戲的綁定 寫入您的綁定；遊戲的其他輸入保留，但在您指派給其他動作的輸入上的遊戲綁定除外。
更新，以我的設定檔為準 同上，而且您綁定的每個動作會失去其他輸入（搖桿；鍵盤只在開啟鍵盤選項時）。
取代我的裝置上的綁定 您寫入的裝置的每個搖桿輸入都會被釋放；然後寫入您的綁定。
+ 同時清除我的其他裝置 在您設定檔中沒有綁定的已連接裝置會失去它們的搖桿輸入。

#永遠不會變更的內容

  • 鍵盤按鍵、滑鼠輸入，以及「取代」模式下軸上的按鍵組（鍵盤只在開啟鍵盤選項時變更）。
  • 未連接的裝置、匯入無法讀取的行、匯入時忽略的裝置，以及 JoyPro 轉送輸入的 vJoy 裝置。
  • current.map、每個裝置的力回饋檔案，以及遊戲的其他設定。

#曲線、Relative Control、力回饋

  • 細緻度：全域。所有飛機共用一個按鍵對應；俯仰曲線設定檔預設會指派給每架飛機。
  • 軸曲線（軸模型 il2korea）：指數（-100 到 100）、中央和邊緣死區、俯仰的中心偏移；俯仰、滾轉和偏航還有內建的回應曲線和操縱面負載。單向軸（油門、煞車）在整個行程上有指數和低端 / 高端死區。攝影機軸沒有編輯器，也不會取得曲線。數值採用檔案的單位；遊戲顯示的死區是它的四倍。
  • Relative Control（軸輸入的 ◆ 按鈕）：開啟 / 關閉、死區（0 到 80 %）和靈敏度（1 到 20），與對話方塊中顯示的相同。
  • 遊戲設定（設定 > 遊戲的力回饋設定）：開啟力回饋、震動強度、回饋強度、低速和高速搖桿力道、力道中性再平衡、地形接觸和軸雜訊濾波器，以遊戲顯示的 % 為單位。
  • 遙測力回饋 和錄製：來自遊戲的遙測輸出，與 Great Battles 相同（只有 CSV，沒有 Tacview 航跡）。
  • 監看程式：general.actions 的變更會在遊戲關閉後被偵測到（監看程式）。
技術細節

#Korea 整合的內部運作

程式碼：engine\Games\Il2KoreaIntegration.cs，engine\AxisModels 中的軸模型 il2korea。

  • 輸入：dev<N>_b<button, 0-based>、dev<N>_axis_<x|y|z|w|s|t|p|q>（X、Y、Z、RX、RY、RZ、滑桿 1、滑桿 2），記號前的 - = 反向，* = Relative Control，帽子開關為 dev<N>_pov<hat>_<angle>，按鍵為 key_<name>，組合以 + 連接。
  • 裝置：known.devices.json 以 DirectInput 執行個體 GUID（採 IL-2 的位元組順序）為每個裝置建立索引鍵，並保存其 deviceId（編號，-1 = 無）和 ident（vid_pid）。JoyPro 寫入的裝置會保留其編號；沒有編號的已連接裝置會從 1 開始取得最低的空閒編號。
  • 指令清單：engine il2korea refresh-db 會加入按鍵對應檔中的動作。沒有輸入的動作不在 general.actions 中，所以全新的清單約有 318 個動作。JoyPro 不會讀取遊戲的封裝檔。
  • 匯入 / 匯出：engine il2korea import、engine il2korea scan、engine il2korea export（--mode、--nuke-untouched-devices、--include-keyboard、--dry-run）；engine il2korea paths 會顯示檔案。
  • 設定與曲線：engine ffb set --device * --game IL2Korea --param ffForce=80、engine binds tuning set --scope game:IL2Korea（或 family:il2）、engine binds tuning preview（與遊戲編譯的表誤差在 1e-6 以內，但中心偏移的平坦側除外）。
  • 遙測：engine ffb telemetry setup il2korea。

#已知限制

  • 遊戲自己的動作文字位於其封裝檔中，JoyPro 不會讀取；JoyPro 使用自己的名稱。
  • Key mapping 頁面上約有 60 個動作在全新的 general.actions 中沒有輸入，因此不會出現在剛建立的清單中。
