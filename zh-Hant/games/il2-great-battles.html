給新手

#3 個步驟就能用

  1. 全部幫我設定好
    在「開始」頁面
  2. 使用這些按鈕
    先查看清單
  3. 寫入我的遊戲
    保持 IL-2 關閉

事前準備：讓 IL-2 寫入一次按鍵對應。開啟 Settings > Key mapping 並按 ACCEPT。關閉 IL-2。

接著：您的綁定會出現在每架 IL-2 飛機的 Settings > Key mapping 中。

您之前在 IL-2 中綁定過按鈕嗎？那麼「開始」頁面會提供 匯入，然後填補空缺。您的綁定會保留，只有空閒的按鈕會被指派新功能。請參閱 快速入門：讓我的搖桿能用。

#沒有頭部追蹤也能環顧四周

沒有 TrackIR，也沒有 VR？設定過程會把快速視角放到您搖桿的一個帽子開關上：前、後、左、右。如果您的油門有迷你搖桿，視角軸會放在它上面。請參閱 頭部追蹤與環顧四周。

#JoyPro 為 IL-2 Great Battles 做了什麼

  • 匯入：按鍵對應中位於搖桿、油門、腳舵或面板上的每個動作，都會連同修飾鍵、軸反向和軸響應設定列一起進入您的設定檔。如果您要求，鍵盤按鍵也會一併匯入。
  • 關聯：一個關聯就是您所有遊戲中的同一個功能。IL-2 所有飛機共用一份按鍵對應，所以關聯中的 IL-2 動作在每架 IL-2 飛機上都有效。
  • 匯出：JoyPro 會寫入遊戲 data\input 資料夾中的按鍵對應檔案。IL-2 會在 Settings > Key mapping 中顯示您的綁定。

#匯入您的 IL-2 綁定

  1. 開啟 開始 頁面。IL-2 Great Battles 卡片會顯示遊戲的圖片。如果卡片要求指令清單，請按 建立清單：JoyPro 會讀取您的 IL-2 已寫入的按鍵對應檔案。
  2. 在卡片上按 匯入。選擇 加入我的設定檔（或 從此遊戲重新開始），如果也要匯入飛行按鍵，請勾選 同時取得鍵盤按鍵。
  3. 按 立即匯入。查看我的關聯 會開啟匯入的內容。

#建立並檢查關聯

在 關聯 頁面上，關聯中的每個 IL-2 動作都會和您其他遊戲中的同一功能並列。使用 關聯流程 將它們連結起來，然後在「匯出」頁面按 立即檢查：它會在遊戲之前找出在 IL-2 中同時做兩件事的按鈕（檢查功能）。

#匯出到 IL-2

  1. 關閉 IL-2。 當 Il-2.exe 正在執行時，JoyPro 會拒絕寫入。
  2. 開啟 匯出。IL-2 卡片會顯示其中有多少關聯已綁定。
  3. 如果您是用 JoyPro 設定搖桿，請保留 取代我的裝置上的綁定 和 同時清除我的其他裝置。然後在 IL-2 卡片上按 立即匯出。
在遊戲中: 您在 IL-2 中會看到什麼

啟動 IL-2 並開啟 Settings > Key mapping。您的綁定會在每個頁籤（例如 Plane controls）的動作列中，位於您的裝置上。JoyPro 寫入的軸響應，就是遊戲從這次啟動起所使用的軸響應。JoyPro 設定的力回饋和雜訊濾波值會顯示在 Settings > Input devices 中。

#您在 IL-2 中需要自己做的事

  • 讓 IL-2 寫入一次按鍵對應。 如果 data\input 中還沒有 global.actions，請開啟 Settings > Key mapping 並按 ACCEPT。沒有這個檔案就沒有東西可以匯入，指令清單也只會包含遊戲已寫入的動作。
  • 力回饋和雜訊濾波值：請開啟一次 Settings > Input devices 並按 ACCEPT，讓遊戲建立它的 current.devices 檔案。JoyPro 會修改這個檔案，但不會建立它。
  • 如要使用 JoyPro 自己根據遊戲遙測資料產生的力回饋，力回饋 頁面會把 JoyPro 的位址加入遊戲的 startup.cfg（請先關閉 IL-2）。然後為該搖桿關閉 IL-2 自己的力回饋。

#常見問題

  • 「IL-2 正在執行」：完全關閉遊戲，然後重新匯出。
  • 綁定跑到錯誤的裝置上：IL-2 以 devices.txt 中的編號區分裝置。JoyPro 寫入的裝置會保留它的編號；新裝置會取得最小的空閒編號。在匯出和匯入之間，請不要在遊戲中重新編號裝置。
  • 使用「僅新增」後缺少一個綁定：該按鈕在 IL-2 中已被用於另一個動作。檢查功能會把它列在「未寫入遊戲」下；請用 更新 匯出，或移動該綁定。
  • 力回饋值沒有改變：遊戲還沒有 current.devices（見上文）。
進階

#JoyPro 讀取和寫入的檔案

檔案 這是什麼
<install>\data\input\global.actions 按鍵對應：每個動作一行，`action, input, invert
<install>\data\input\devices.txt 裝置清單：每個搖桿的編號、DirectInput GUID 和名稱
<install>\data\input\current.responses 每個動作的軸回應列（置中、單向），適用於所有飛機
<install>\data\input\global.pitch 帶有中心偏移的俯仰列（只在您設定時建立）
<install>\data\input\jp.actions JoyPro 的副本，含關聯名稱、群組、修飾鍵和調校，下次匯入時會讀回
<install>\data\input\current.devices Settings > Input devices：力回饋和搖桿雜訊濾波器（就地變更）
<install>\data\startup.cfg 力回饋數值和 JoyPro 的遙測位址

current.map 由 IL-2 在每次啟動時從這些檔案編譯；JoyPro 永遠不會寫入它。

#IL-2 的匯出模式

模式 IL-2 中會發生什麼
僅新增 不會移除任何東西。如果綁定的輸入已被 IL-2 用於另一個動作，就不會寫入，並標示為「未寫入遊戲」。
更新，保留遊戲的綁定 寫入您的綁定；IL-2 的其他綁定保留，但您使用的輸入上其他動作的綁定除外。
更新，以我的設定檔為準 同上，而且您綁定的每個動作會失去其他輸入（搖桿；鍵盤只在開啟鍵盤選項時）。
取代我的裝置上的綁定 您寫入的搖桿只保留您的綁定。
+ 同時清除我的其他裝置 在您設定檔中沒有綁定的已連接搖桿會失去它們的綁定。

global.actions 保留遊戲的順序；新的行會加在最後。

#永遠不會變更的內容

  • 未連接搖桿的行、匯入時忽略的裝置，以及 JoyPro 轉送輸入的 vJoy 裝置。
  • 滑鼠行（包括搭配鍵盤按鍵的滑鼠輸入）、TrackIR，以及含有 JoyPro 無法讀取之輸入的行。
  • 鍵盤，除非您匯出鍵盤綁定。
  • current.map 和遊戲的其他檔案。

#飛機、曲線、力回饋

  • 細緻度：全域。每個動作一個按鍵對應和一個回應列，涵蓋所有飛機。
  • 軸曲線（軸模型 il2）：置中軸有中央死區、邊緣死區和曲線（「sensitivity balance」）；油門等單向軸有低端和高端死區；俯仰還有中心偏移。預設曲線 會換算成 IL-2 的模型；您也可以只為 IL-2 設定曲線，或為 IL-2 系列設定（Great Battles 和 Korea 會讀取彼此的值）。反向會寫在該動作的行上。
  • 遊戲設定（設定 > 遊戲的力回饋設定）：搖桿雜訊濾波器、開啟力回饋、回饋強度和震動。即使匯出時沒有 IL-2 綁定，仍會寫入這些設定。
  • 遙測力回饋：JoyPro 依據遊戲的遙測輸出產生自己的效果（力回饋）。同一個輸出也供遙測錄製使用（CSV；遙測沒有世界座標，所以沒有 Tacview 航跡）。
  • HUD：IL-2 執行時，會顯示所按按鈕的 IL-2 綁定（HUD）。
  • 監看程式：您在 Key mapping 中變更的綁定會在 IL-2 關閉後被偵測到；JoyPro 會詢問是否採用（監看程式）。
技術細節

#IL-2 整合的內部運作

程式碼：engine\EngineIl2.cs（匯入、匯出、檔案）、engine\EngineIl2DbRefresh.cs（指令清單）、engine\AxisModels（模型 il2）、engine\EngineFfbTelemetry.cs（遙測設定）。

  • 輸入：joy<N>_b<button, 0-based>、joy<N>_axis_<x|y|z|...>、joy<N>_pov<hat>_<angle>，鍵盤按鍵使用 DirectInput 名稱，軸配對為 <input>/<input>，修飾鍵為 <modifier>+<input>。IL-2 的帽子開關從 0 開始編號，JoyPro 從 1 開始（JOY_BTN_POV1_* 即 pov0）。
  • 裝置：devices.txt 列出 <number>,"<GUID>",<name>|；IL-2 會把 DirectInput 執行個體 GUID 的最後 8 個位元組反轉後寫成一組。每種模式都會保留已列出的編號。
  • 指令清單：engine db refresh-il2 會讀取遊戲寫入的 *.actions 檔案（不含 jp.actions）；遊戲的分頁（Service、Camera controls、Plane controls、Weapons controls ...）就是類別。遊戲只會寫入有輸入的動作，所以全新安裝的清單約有 376 個動作。
  • 匯入 / 匯出：engine il2 import、engine il2 scan、engine il2 export（--mode clean|add|merge|merge-overwrite --nuke-untouched-devices true|false --ignore-device <d>）。備份：首次寫入前，每個檔案都會備份為 <file>.jpbak 並存入備份庫。
  • 設定與曲線：engine ffb set --device * --game IL2Game、engine binds tuning set --scope game:IL2Game 或 family:il2、engine binds tuning preview。
  • 遙測：engine ffb telemetry setup il2 會在 startup.cfg 的 telemetrydevice 區段中加入一行位址 127.0.0.1:41994，永遠不會變更其他工具的位址；--remove 會將檔案逐位元組還原。
  • 監看程式：engine sync status、engine sync diff（受監看：global.actions、devices.txt、current.responses、current.devices、startup.cfg）。

#已知限制

  • 在遊戲檔案中沒有輸入的動作，不會出現在剛建立的指令清單中。
  • 對於使用 JoyPro 遙測力回饋的搖桿，必須關閉遊戲自己的力回饋。
  • 測試：engine\tests\smoke\il2.ps1；遊戲內為 tools\e2e\games\IL2Game.ps1（綁定，38 個步驟全部通過）和 IL2GameCurves.ps1（遊戲編譯的回應與 JoyPro 預覽的比對）。
