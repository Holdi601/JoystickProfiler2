給新手

#3 個步驟就能用

#ACE COMBAT 8

  1. 全部幫我設定好
    然後按 使用這些按鈕
  2. 設定模擬手把
    然後按 測試
  3. 啟動遊戲
    在標題畫面：Alt+Tab，按 開始

#ACE COMBAT 7

  1. 啟動遊戲一次
    然後關閉
  2. 全部幫我設定好
    然後按 使用這些按鈕
  3. 寫入我的遊戲
    保持遊戲關閉

#ACE COMBAT 8：只需設定一次

  1. 在「開始」頁面按 全部幫我設定好。或在歡迎畫面選擇 用我的飛行搖桿玩 ACE COMBAT：接著會有簡短導覽帶您完成每個步驟。
  2. 查看各項操作放在哪裡的清單。按 使用這些按鈕。
  3. 按 設定模擬手把。設定視窗會關閉，並開啟「虛擬 Joystick」頁面。
  4. 模擬手把需要一個名為 ViGEmBus 的免費小幫手。勾選授權條款下方的方塊，然後按 安裝 ViGEmBus。Windows 會要求權限：點選 是。這只需要做一次。
  5. 按 測試。移動您的搖桿，手把圖片會跟著動。按下按鈕：它會亮起來。

您不需要切換任何設定。ACE COMBAT 8 會自動使用模擬手把。頁面上會顯示「自動使用 Xbox 手把：此遊戲只讀取 Xbox 控制器」。這款遊戲不需要 HidHide：反正它也看不到您的實體搖桿。

#ACE COMBAT 8：每次遊玩時

  1. 啟動 ACE COMBAT 8。等到標題畫面出現。
  2. 按住 Alt 再按 Tab。您就回到 JoyPro 了。
  3. 按 開始。
  4. 再按一次 Alt+Tab。您就回到遊戲了。起飛吧！
  5. 玩完後，按 停止。
先啟動遊戲，再按「開始」

請在遊戲顯示標題畫面後才按 開始。按太早了？JoyPro 會顯示「太早了」。按 停止，再按 開始。每次遊玩都要這樣做。

#ACE COMBAT 8 的操作對應

在您的 HOTAS 上 在模擬手把上 在遊戲中
搖桿往前、後、左、右 左搖桿 俯仰與滾轉
油門桿 往前：RT。往後：LT。 加速與減速
搖桿扭轉（或腳舵） LB 和 RB，約從 30 % 起 向左與向右偏航
搖桿上一個空閒的帽子開關 右搖桿 環顧四周
您的熱焰彈按鈕 同時按 L3 和 R3 熱焰彈（尚未在遊戲中確認）
您的通訊開關或 AI 選單帽子開關 十字鍵 僚機指令
名為「High-G」的按鈕關聯 兩個扳機都按到底 高 G 迴轉

「虛擬 Joystick」頁面的 即時測試 頁籤會說明每個按鈕的作用，例如「A: Fire machine gun」。

熱焰彈尚未在遊戲中確認

JoyPro 會同時按下 L3 和 R3 來施放熱焰彈。目前還沒有人在遊戲中確認過。JoyPro 也會這樣提示您。

#用帽子開關環顧四周

遊戲使用模擬手把的右搖桿來環顧四周。JoyPro 會把它放到您搖桿上一個空閒的帽子開關。按住帽子開關的某個方向，視角就會轉向那邊。通常是搖桿最上方的帽子開關。這個帽子開關在您的其他遊戲中仍保有原本的功能，例如 DCS 中的配平。請參閱 頭部追蹤與環顧四周。

#ACE COMBAT 7：快速方式

  1. 連接所有裝置後啟動 ACE COMBAT 7 一次，然後結束遊戲。遊戲會在關閉時寫入 Input.ini。
  2. 在「開始」頁面按 全部幫我設定好。查看清單。按 使用這些按鈕。
  3. 關閉遊戲。 按 寫入我的遊戲。JoyPro 會保留舊檔案的副本。

您之前在 ACE COMBAT 7 中綁定過按鈕嗎？那麼「開始」頁面會提供 匯入，然後填補空缺。您的綁定會保留，只有空閒的按鈕會被指派新功能。

#ACE COMBAT 7：匯入您自己的綁定

  1. 連接所有裝置後啟動 ACE COMBAT 7 一次，然後結束遊戲。
  2. 開啟 開始 頁面。在該檔案出現之前，JoyPro 會使用自己的 20 個飛行動作清單。卡片上的 更新 會根據您的檔案建立清單。
  3. 在 ACE COMBAT 7 卡片上按 匯入，保留 加入我的設定檔（建議），然後按 立即匯入。

#建立並檢查關聯

一個關聯可以同時包含 ACE COMBAT 7 和 ACE COMBAT 8 中同一功能的動作。這樣兩款遊戲都能從同一個按鈕取得它（關聯流程）。檢查功能會找出在 ACE COMBAT 7 中同時做兩件事的按鈕。按底部列的 檢查，或「匯出」頁面上的 立即檢查（檢查功能）。

#匯出

  • ACE COMBAT 7：關閉遊戲，開啟 匯出，保留 取代我的裝置上的綁定 和 同時清除我的其他裝置，然後在該遊戲的卡片上按 立即匯出。
  • ACE COMBAT 8：匯出不會寫入任何內容，並會告知您。只要 開始 處於開啟狀態，您的綁定就會透過模擬手把傳到遊戲。
在遊戲中: 您在 ACE COMBAT 中會看到什麼

ACE COMBAT 8 只會看到一個 Xbox 手把：選單顯示手把按鈕，而 SYSTEM > CONTROLS > CONTROLLER > BUTTON MAPPING 會列出九個可重新對應的動作（向左與向右偏航、加速、減速、機槍射擊、發射飛彈、切換武器、切換目標、雷達地圖）及其手把按鈕。您的搖桿會像手把的左搖桿一樣移動選單焦點。

ACE COMBAT 7 沒有可重新對應飛行搖桿綁定的選單：它會從 Input.ini 讀取綁定。它的操作選單是否會顯示這些綁定，目前尚未確認。JoyPro 的遊戲內測試已確認：遊戲在結束時重寫檔案，仍會保留 JoyPro 寫入的每個值。

#您需要自己做的事

  • ACE COMBAT 8：每次遊玩時，在標題畫面按 開始（見上文）。
  • ACE COMBAT 8：在 BUTTON MAPPING 中變更手把按鈕後，請在遊戲卡片上按 更新。接著在「虛擬 Joystick」頁面按 更新對應。JoyPro 就會依照您的新按鈕運作。
  • ACE COMBAT 7：連接每個裝置各啟動遊戲一次。檔案中沒有對應區段的裝置會被略過，並顯示「請在連接此裝置的情況下啟動遊戲一次」。請為這款遊戲關閉 Steam Input。

#常見問題

  • ACE COMBAT 8 沒有反應：是不是太早按了 開始？按 停止，然後在標題畫面按 開始。
  • ACE COMBAT 8：機頭方向相反：您是否在遊戲中設定了「Pitch Controls: Inverted」？請參閱「進階」。
  • ACE COMBAT 8：沒有 ViGEmBus：沒有它，遊戲就看不到您的搖桿。請在「虛擬 Joystick」頁面安裝。
  • ACE COMBAT 7：軸停在一半：遊戲會把同一動作在所有裝置上的值加以平均。油門在 100 %，而同一動作在滑桿上為 -100 %，結果就是 50 %。每個軸動作只綁定在一個裝置上（更新，以我的設定檔為準 會清除其他裝置上的綁定）。
  • ACE COMBAT 7：同型號的兩支搖桿 共用一個區段；遊戲無法區分它們。

更多：用 HOTAS 玩只支援 Xbox 手把的遊戲。

進階

#模擬手把的運作方式

  • 不需要 HidHide。 ACE COMBAT 8 只讀取 Xbox 手把，所以永遠看不到您的實體搖桿。不需要隱藏任何東西，Windows 也不會要求系統管理員權限。HidHide 只用於設為 vJoy 的遊戲。
  • 模式會自動切換。 在您尚未選擇模式之前，遊戲會使用 Xbox 手把。在「虛擬 Joystick」頁面上選擇其他模式，JoyPro 就會保留您的選擇。
  • 以遊戲的配置為優先：每個對應 ACE COMBAT 8 動作的關聯，都會固定到遊戲為該動作所用的手把控制項（從遊戲存檔讀取）。俯仰和滾轉對應到左搖桿，環顧四周對應到右搖桿。
  • 油門：油門拉桿驅動兩個扳機。往前是 RT，往後是 LT，中間是空檔。即使「decelerate」位於另一個關聯（例如腳尖煞車）中，這也能運作。
  • 偏航：搖桿扭轉（沒有時則用腳舵）在偏移約 30 % 時按下 LB 和 RB。
  • 環顧四周：如果視角動作上沒有軸，一個空閒的帽子開關會驅動右搖桿（「Hat to axes」）。按住某個方向時，搖桿會一直推到底；斜向則同時移動兩個軸。JoyPro 會使用您其他遊戲的視角或檢視關聯所用的帽子開關，否則使用搖桿最上方的帽子開關。視角動作上若有空閒的小搖桿，一律以它為優先。
  • 熱焰彈：L3 和 R3 同時按下 120 ms，來自您的熱焰彈或反制措施關聯。尚未在遊戲中確認。
  • 僚機指令 放在十字鍵上，來自您的通訊開關或 AI 選單帽子開關。
  • 高 G 迴旋：名為「High-G」的按鈕關聯會按住兩個扳機。帶有 DCS 的 ASC Direct Control（Su-27、Su-33 和 J-11A 的「眼鏡蛇按鈕」）的關聯也一樣。扳機上的油門仍會繼續運作。
  • 一個輸入，一項工作：驅動上述功能之一的輸入會從表中移除，因此絕不會同時按下兩個控制項。
  • 您的曲線會傳到手把。 軸回應（綁定頁面）的死區、飽和度、曲線和反向會套用到手把的搖桿或扳機。若要讓 ACE COMBAT 8 有自己的曲線，請在 套用於 下只勾選 ACE COMBAT 8。否則以 預設曲線 為準。
  • 俯仰：DCS 的反向設定永遠不會傳到手把。預設情況下，往前推搖桿會讓機頭朝下。如果遊戲中設為「Pitch Controls: Inverted」，請只為 ACE COMBAT 8 取消勾選「反向」（軸回應，套用於：ACE COMBAT 8）。
  • 滾轉方向相反：JoyPro 會直接傳遞滾轉。請只為 ACE COMBAT 8 在滾轉關聯上勾選「反向」。
  • 手把容納不下的部分（手把只有兩個搖桿、兩個扳機、14 個按鈕和十字鍵）會列在「虛擬 Joystick」頁面上。
  • 多個遊戲共用手把：ACE COMBAT 7 和 8 都可以使用它，各自有自己的表。開啟自動啟動時，正在執行的遊戲的表會生效。否則請在 「開始」與「測試」使用的 Xbox 手把表 下選擇。
  • 自動啟動 會在遊戲啟動後約 3 秒內、標題畫面出現之前建立手把。對這款遊戲來說可能太早：這時請在標題畫面按 停止，再按 開始。
  • 專家：vJoy、HidHide、轉送頻率和各種模式位於 顯示進階詳細資訊（vJoy、HidHide、模式） 下。
  • ACE COMBAT Zero 隨附在 ACE COMBAT 8 資料夾中（ACZero\acz.exe）。它尚未經過研究：若要試用，請手動為 ACE COMBAT 8 按 開始，然後啟動 Zero。未經測試。

#ACE COMBAT 7 的匯出模式

每個動作和裝置一個輸入。選單按鍵（UI_*）和 JoyPro 無法讀取的組合鍵永遠不會被變更。

模式 會發生什麼
僅新增 在該裝置上已有值的動作會保留原值；如果綁定所在的輸入已被遊戲用於其他動作，就不會寫入，並標示為「未寫入遊戲」。
更新，保留遊戲的綁定 寫入設定檔中的值；同一輸入上的其他動作會被釋放；該動作在其他裝置上的值保留（遊戲會取平均值的軸會被回報）。
更新，以我的設定檔為準 同上，並且設定檔綁定的每個動作在其他已連接裝置上都會被清除。
取代我的裝置上的綁定 JoyPro 寫入的區段只保留您可讀取的值；寫入的軸仍會在其他已連接裝置上被清除。
+ 同時清除我的其他裝置 其他已連接裝置的可讀取值會被清除。

Input.ini 的註解、順序、編碼和換行符號都會保留。ACE COMBAT 8 沒有匯出模式：不會寫入任何內容。

#永遠不會變更的內容

  • ACE COMBAT 7：鍵盤、選單按鍵、組合鍵、未連接裝置的區段、匯入時忽略的裝置，以及 JoyPro 轉送輸入的 vJoy 裝置。
  • ACE COMBAT 8：遊戲的所有檔案，以及 HidHide。

#軸、監看程式、HUD

  • ACE COMBAT 7：全域綁定（沒有飛機設定檔）；只有反向（:R），沒有曲線或死區；遊戲每個裝置最多讀取 32 個按鈕、8 個軸和 4 個帽子開關（各四個方向）；沒有修飾鍵。
  • 監看程式：ACE COMBAT 7 的 Input.ini 會在遊戲關閉後受到監看（監看程式）；ACE COMBAT 8 沒有 JoyPro 寫入的內容，所以沒有東西需要監看。
  • HUD：遊戲執行時，HUD 會顯示每個按下按鈕的動作名稱。
  • 兩款遊戲都沒有力回饋和遙測。
技術細節

#ACE COMBAT 整合的內部運作

程式碼：engine\Games\AceCombat7Integration.cs、engine\Games\AceCombat8Integration.cs；virtual-joystick 的手把規劃器與轉送器；手把本身的功能位於 engine\VJoy\XboxPadAutoSetup.cs。

  • ACE COMBAT 7 區段：Joystick- + DirectInput 產品 GUID（PID 高位字 + VID，接著是 504944564944，即「PIDVID」）。物件 X Y Z Rx Ry Rz Slider1 Slider2、Button1-Button32、POV_U/D/L/R1-4；選項 :P / :N（半軸）、:R（反向）、:C（-1..1 當作 0..1）；組合 &、!、+、>、<；空值表示未綁定。JoyPro 將軸寫為 X 或 Y:R，按鈕寫為 ButtonN，帽子開關方向寫為 POV_<U|D|L|R><n>。組合鍵和半軸在匯入時會被回報，但不會被讀取。
  • ACE COMBAT 7 動作：軸 Flight_Pitch/Roll/Yaw/Throttle/CameraPitch/CameraYaw；按鈕 Flight_Gun/Missile/Target/Weapon/Radar/Flare/View/AccelerationDeceleration/AutoPilot/Pause 以及 Flight_HatSwitchUp/Down/Left/Right。engine ac7 refresh-db 會從您的檔案取得 Flight_* 鍵。
  • ACE COMBAT 8：System.sav 是帶有 Checksum 的 Unreal GVAS；它以 Unreal 按鍵名稱保存九個手把按鍵（YawLeftKey_Controller = Gamepad_LeftShoulder ...）。engine ac8 refresh-db 會將它們讀成每個控制項一個 Pad_* 動作，按鍵位於清單的第 5 欄；搖桿則來自 JoyPro 自己的表。
  • 手把模式：遊戲宣告 MaxJoysticks 0，建議模式為 xbox，因此沒有已儲存的選擇時，它的模式就是 xbox（VJoySettings.ModeOf）。engine vjoy mode AceCombat8 xbox 會儲存一個選擇。engine vjoy map、engine vjoy forwarder-config --xbox-game AceCombat8。沒有 HidHide 步驟：只有這類遊戲處於虛擬模式時，engine vjoy apply-hidhide 會顯示「HidHide is not needed」，也不會以提升的權限啟動任何東西。
  • 手把功能：油門分割（XB_TRIGGERS）、偏航（「Axis ends to buttons」，末端區 0.35）、熱焰彈組合鍵（IGamePadChords.PadChords，Confirmed = false）、十字鍵、高 G 按住（PadHolds）和視角帽子開關（hat-axes，IGamePadConventions.PadLookActions = Pad_CameraYaw / Pad_CameraPitch）會在每次規劃時重新建立。Pad_Pitch 預設為反向（PadInvertDefault）。
  • 檢查：engine vjoy pad-check 會回報設定檔在手把上能觸及的功能（俯仰、滾轉、機砲、飛彈、目標、油門分割、偏航、組合鍵、按住、十字鍵、視角），並附上分數。
  • 指令：engine ac7 paths、engine ac7 scan、engine ac7 import、engine ac7 export；engine ac8 scan、engine ac8 import、engine ac8 export（不寫入任何內容）。

#已知限制

  • ACE COMBAT 7：控制選單是否會顯示搖桿綁定，以及在俯仰上使用 :R、油門上使用 :C 的實際飛行，目前都尚未確認。
  • ACE COMBAT 8：熱焰彈組合鍵（L3 + R3）和視角按鈕尚未在遊戲中確認。
  • ACE COMBAT 8：只有遊戲本身支援的少數搖桿（一款 Thrustmaster 和一款 HORI 型號）不需手把即可運作；JoyPro 不會寫入它們的設定。
  • 測試：engine\tests\smoke\acecombat7.ps1、acecombat8.ps1；遊戲內為 tools\e2e\games\AceCombat7Settings.ps1（匯出、啟動、改寫後的檔案仍保有每個值、匯入）和 AceCombat8Xbox.ps1（以虛擬手把操作選單，手把在標題畫面出現後建立）。
