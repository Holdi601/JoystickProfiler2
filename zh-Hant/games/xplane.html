給新手

#3 個步驟就能用

  1. 全部幫我設定好
    在「開始」頁面
  2. 使用這些按鈕
    先查看清單
  3. 寫入我的遊戲
    保持 X-Plane 關閉

之前：在連接裝置的情況下啟動 X-Plane 一次，然後結束。

之後：在 X-Plane 中校正您的裝置（Settings > Joystick）。您的指派也會顯示在那裡。

您之前在 X-Plane 中綁定過按鈕嗎？那麼開始頁面會提供 匯入，然後填補空缺。您的綁定會保留，只有空著的按鈕會被指派新功能。請參閱快速入門：讓我的搖桿能用。

#JoyPro 能為 X-Plane 做什麼

  • 匯入：您裝置的軸用途、按鈕指令、反轉標記和回應曲線會帶入您的設定檔。
  • 關聯：一個關聯就是您所有遊戲中的同一個功能（X-Plane、MSFS 和 DCS 中的「Gear」放在同一個按鈕上）。X-Plane 的飛行指令來自它自己的 Commands.txt。
  • 匯出：JoyPro 會寫入您匯出的那個版本的 joystick 偏好設定。X-Plane 會在 Settings > Joystick 中顯示您的指派。

#匯入您的 X-Plane 指派

  1. 開啟 開始。X-Plane 12（或 X-Plane 11）卡片會顯示遊戲的圖片。如果它要求指令清單，請按 建立清單：JoyPro 會讀取已安裝 X-Plane 的 Resources\plugins\Commands.txt。
  2. 按卡片上的 匯入，選擇 加入我的設定檔（X-Plane 的這個檔案中沒有鍵盤綁定）。
  3. 按 立即匯入。查看我的關聯 會開啟匯入的內容。

#建立並檢查關聯

在 關聯 頁面上，關聯中的 X-Plane 指令或軸會位於您其他遊戲的相同功能旁邊。用關聯流程把它們連在一起，然後在匯出頁面按 立即檢查（檢查）。

#匯出到 X-Plane

  1. 關閉 X-Plane。 它會在設定視窗關閉時和結束時重寫偏好設定。兩個版本都以 X-Plane.exe 執行，所以只要其中一個在執行，JoyPro 就會拒絕寫入。
  2. 開啟 匯出。每個已安裝的版本都有自己的卡片。
  3. 如果您是用 JoyPro 設定裝置，請保留 取代我的裝置上的綁定 和 同時清除我的其他裝置。然後在卡片上按 立即匯出。
在遊戲中: 您在 X-Plane 中會看到什麼

啟動 X-Plane 並開啟 Settings > Joystick，然後選擇您的裝置。每個軸都會顯示 JoyPro 寫入的用途，按鈕會顯示它們的指令，而軸上的 Edit Response Curve 會顯示 JoyPro 寫入的節點和插值方式。

#您需要在 X-Plane 中自己做的事

  • 在連接裝置的情況下啟動 X-Plane 一次，然後結束。 從未啟動過的版本還沒有偏好設定檔案。第一次啟動時會進行教學飛行，而 X-Plane 會在結束時寫入它的 joystick 偏好設定。
  • 在 X-Plane 中校正。 校正和空區由 X-Plane 負責（Settings > Joystick）；JoyPro 絕不會寫入它們。
  • 外掛和飛機的指令不在 JoyPro 的清單中：請在 X-Plane 中綁定它們，JoyPro 不會更動。

#常見問題

  • 某個軸沒有作用（「Multiple axes assigned to yaw」）：X-Plane 會忽略兩個已連接軸共用的用途。匯出時會發出警告；同時清除我的其他裝置 或「取代」會清除另一個軸的設定。
  • 油門方向相反：X-Plane 會自行反轉油門軸。JoyPro 會原封不動地寫入您的反向設定，所以除非您的油門桿真的是反方向，否則請保持反向關閉。
  • 您在 X-Plane 中製作的曲線被改了：在「更新」模式和「僅新增」中，若 JoyPro 的調校是線性的，曲線會保留（並發出警告）；「以我的設定檔為準」和「取代」則會寫入 JoyPro 的曲線。
進階

#JoyPro 讀取和寫入的檔案

檔案 這是什麼
<install>\Output\preferences\X-Plane Joystick Settings.prf 所有裝置目前的指派（以行為單位）
<install>\Output\preferences\control profiles\<Name> - Joysticks.prf 已儲存的控制設定檔，格式相同
<file>.joypro.json、<file>.joypro-meta.json JoyPro 寫入的輸入和曲線；名稱、群組和調校，供下次匯入使用
%LOCALAPPDATA%\x-plane_install_12.txt / _11.txt X-Plane 安裝程式列出其安裝位置的地方（唯讀）

X-Plane Keys.prf（鍵盤）從不更動。由 Steam 安裝但從未啟動過的版本，會在它的 Steam 資料夾中找到。其他資料夾請在 設定 > 遊戲 中設定。

#X-Plane 的匯出模式

模式 X-Plane 中會發生什麼事
僅新增 只使用空閒的輸入。如果某個綁定所在的輸入已有其他用途或指令，該綁定不會寫入並會列出；X-Plane 在另一個軸上的軸用途會保留在原處（警告）。
更新，保留遊戲的綁定 取代您輸入上的其他用途或指令，其他一切保留；軸用途會搬移（兩個軸共用同一用途時，X-Plane 會忽略它）。
更新，以我的設定檔為準 另外也會解除已連接裝置上擁有您所綁定用途或指令的其他軸和按鈕，連同它們的曲線。
取代我的裝置上的綁定 另外也會解除您寫入的裝置上其他所有飛行軸和指令。
+ 同時清除我的其他裝置 您未寫入的已連接裝置會失去它們的飛行用途和指令。

#永遠不會變更的內容

  • 未連接裝置的插槽、匯入時忽略的裝置，以及 JoyPro 轉送輸入用的 vJoy 裝置。
  • 視角、攝影機、VR 和自訂指令的軸、外掛程式和飛機的指令，以及鍵盤。
  • 校正鍵（_joy_center、_joy_null、原始校正資料）、_eq_pfc_* 以及其他每一行。

#曲線與設定

  • 細分程度：所有飛機共用一個檔案（X-Plane 可以把飛機連結到控制設定檔；JoyPro 會寫入它找到的檔案）。
  • 反應曲線（軸模型 xplane）：任意數量的控制點，搭配 LINEAR、CATMULL_ROM 或 CUBIC_AVG，以及油門、螺旋槳和混合比軸的固定範圍（beta、順槳、切斷、FADEC ...）。預設曲線 會轉成控制點；未變更的曲線保留原本的位元組。調校可以只針對一個版本，或同時套用到兩個版本（family:xplane）。
  • 反轉：_joy_rev_axis，維持您的反向設定不變（X-Plane 會自行反轉油門）。
  • 遊戲設定（設定 > 遊戲的力回饋設定）：俯仰、滾轉和偏航的控制反應；X-Plane 12 另有副駕駛軸，以及供力回饋搖桿使用的 "control-loaded axes"；X-Plane 11 有增穩系統；兩者都有襟翼段位。只會變更檔案中已有的行。
  • 力回饋：X-Plane 本身沒有力回饋；只有 control-loaded 開關。
  • 遙測錄製：來自 X-Plane 的 UDP 資料輸出（連接埠 49000），包含位置，因此可以產生 Tacview 軌跡。
  • 監看程式：偏好設定中的變更會在 X-Plane 關閉後被偵測到（監看程式）。
技術細節

#X-Plane 整合的內部運作

程式碼：engine\Games\XPlaneIntegration.cs（每個版本一個執行個體）、engine\Games\XPlanePrf.cs、engine\AxisModels\XPlane.cs、engine\FfbModels\XPlane.cs、engine\Games\LegacyGameIds.cs（分成兩個版本之前的設定檔會在載入時遷移）。

  • 行：_joy_AXIS_use<i>（用途代碼）、_joy_rev_axis<i>、_joy_BUTN_use<i>（指令路徑，sim/none/none = 空閒）、axis_response_curve<i>。全域索引：軸 = 插槽 × 25 + 軸，按鈕 = 插槽 × 160 + 按鈕。
  • 裝置：插槽為 _joy_unique_id<slot> VID:<dec>PID:<dec>；遇到相同的裝置時，DirectInput HID 介面路徑必須等於 _joy_location<slot>。按鈕是裝置本身的按鈕，接著是第一個帽子開關，從上方開始順時針算作 8 個按鈕；其他帽子開關不對應。每個裝置讀取 160 個按鈕和 25 個軸。
  • 用途代碼：兩個版本都是 0 到 66；X-Plane 12 另外加上油門 9、副駕駛的俯仰/滾轉/偏航/煞車/前輪轉向，以及兩個機輪煞車。代碼 74 到 77 和視角軸未編目。
  • 指令清單：engine xplane12 refresh-db / engine xplane11 refresh-db：該版本的軸對照表，加上 Commands.txt 中的飛行指令群組（sim/flight_controls、engines、autopilot、lights ...；不含 sim/view、operation、replay ...）。
  • 匯入 / 匯出：engine xplane12 import、engine xplane12 scan、engine xplane12 export（--mode、--nuke-untouched-devices、--dry-run），engine xplane11 export 也相同。會先備份為 .jpbak。
  • 設定和曲線：engine ffb set --game XPlane12、engine binds tuning set --scope game:XPlane12 --curve-points 0:0,0.4:0.3,1:1、engine binds tuning preview（在 X-Plane 12.4.3 中實測，誤差在 0.0001 以內）。

  • X-Plane 11 只對照其已安裝的檔案檢查過；遊戲內選單的檢查尚待進行。
