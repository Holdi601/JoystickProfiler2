Tiny Combat Arena

顯示：

Tiny Combat Arena 是一款所有飛機共用一組綁定的空戰飛行遊戲。它把控制設定存在 Windows 登錄檔中（Unity 的設定存放區）：每個裝置、每個 Control Mapper 分頁（Flight、Weapons、Camera、View Select、Map UI、System）各有一個 Rewired joystick 對應表。JoyPro 會把這些對應表讀入您的設定檔，並把您的綁定寫回每個裝置的正確分頁。

給新手

#3 個步驟就能用

  1. 全部幫我設定好
    在「開始」頁面
  2. 使用這些按鈕
    先查看清單
  3. 寫入我的遊戲
    保持遊戲關閉

之前：先啟動 Tiny Combat Arena 一次並開啟它的 Control Mapper。然後關閉遊戲。

之後：您的綁定會出現在遊戲 Control Mapper 的各個分頁上。

您之前在 Tiny Combat Arena 中綁定過按鈕嗎？那麼開始頁面會提供 匯入，然後填補空缺。您的綁定會保留，只有空著的按鈕會被指派新功能。請參閱快速入門：讓我的搖桿能用。

#JoyPro 能為 Tiny Combat Arena 做什麼

  • 匯入：您已連接裝置的 joystick 對應表會從每個分頁帶入您的設定檔：包含反向設定的軸、按鈕、帽子開關方向，以及軸上的按鈕（例如 Throttle Up / Down）。
  • 關聯：一個關聯就是一個功能，適用於每架飛機。
  • 匯出：JoyPro 會把每個綁定寫入其分頁的對應表（俯仰寫入 Flight、機砲寫入 Weapons、視角寫入 View Select），每個對應表的其餘部分維持原樣。

#匯入您的綁定

  1. 先啟動 Tiny Combat Arena 一次，開啟 Control Mapper（遊戲接著會為每個已連接的裝置儲存一個對應表），然後關閉遊戲。
  2. 開啟 開始，按 Tiny Combat Arena 卡片上的 匯入，再按 立即匯入。

#建立並檢查關聯

和其他遊戲一樣建立關聯（關聯流程）。JoyPro 目前還沒有為這款遊戲手工製作的功能對照表：設定精靈和自動指派會使用一份從遊戲自己的名稱和分類推導出來的對照表。接著在匯出頁面執行檢查。

#匯出到 Tiny Combat Arena

  1. 關閉 Tiny Combat Arena。 遊戲執行時（處理程序 Arena）JoyPro 會拒絕寫入；當您在 Control Mapper 中按 Done 時，遊戲會儲存所有對應表。
  2. 開啟 匯出，保持 取代我的裝置上的綁定 並搭配 同時清除我的其他裝置，然後按 Tiny Combat Arena 卡片上的 立即匯出。
在遊戲中: 您在 Tiny Combat Arena 中會看到什麼

開啟遊戲的 Control Mapper 並選擇您的裝置：您的綁定位於 Flight、Weapons、Camera、View Select 和 Map UI 分頁上。對應工具以 Rewired 的編號為輸入命名：「Axis 0」是 X 軸，按鈕 1 顯示為「Button 0」，第一個帽子開關的上方向顯示為「Hat 0 Up」。前往對應工具的選單路徑目前尚未確認。

#您需要在 Tiny Combat Arena 中自己做的事

  • 先啟動遊戲一次，再進行第一次匯入或匯出，讓它建立登錄機碼。第一次啟動時會要求快速設定遊戲和頭部追蹤；依您的喜好回答即可。
  • 曲線：遊戲自己的搖桿與方向舵曲線以及油門速度存在它的設定檔案中；請在遊戲中設定，JoyPro 不會寫入它們。

#常見問題

  • 「Tiny Combat Arena 正在執行」：關閉遊戲，然後再匯出一次。
  • 某個裝置被略過：兩個已連接的相同型號裝置在遊戲的對應表中無法區分；JoyPro 會略過它們並發出警告。
  • Logitech Extreme 3D 或 T.16000M 的扭轉軸或油門：遊戲的 Rewired 能辨識這些裝置，並把它們的對應表存在另一個機碼下；JoyPro 目前還無法處理它們。
  • 帽子開關的斜向方向不見了：JoyPro 只寫入帽子開關的四個主要方向。
進階

#JoyPro 讀寫哪些內容

位置 這是什麼
HKCU\Software\TinyCombat\Arena 遊戲在登錄檔中的 Unity 設定；Rewired 的值是二進位資料（UTF-8 文字加一個零位元組），名稱以 _h<hash> 結尾
每個裝置和分頁一個值，名稱中含有 dataType=ControllerMap 和該裝置的 hardwareIdentifier 一個裝置在一個分頁上的 joystick 對應表（Rewired XML），屬於玩家 Player
<install>\Arena_Data\sharedassets*.assets 遊戲的 Rewired 動作清單：唯讀，用於指令清單
%USERPROFILE%\AppData\LocalLow\TinyCombat\Arena\Settings\Controls.cfg 遊戲的曲線和油門速度：不寫入

每次寫入前，JoyPro 都會把玩家的控制器對應表值存入備份區；復原上次匯出 會把它們寫回。

分頁就是 Rewired 的對應表類別：0 System、3 Flight、8 Weapons、11 Camera、4 View Select、9 Map UI。每個動作會放到其動作類別對應的分頁（Flight Control 到 Flight、Weapon Control 到 Weapons、Camera Control 到 Camera、View Control 到 View Select、Map Control 到 Map UI、Default 到 System）。

#Tiny Combat Arena 的匯出模式

Tiny Combat Arena 是只有飛行的遊戲：每個可指派的動作都算是 JoyPro 管理的動作。

模式 您裝置的對應表會發生什麼事
僅新增 遊戲的內容完全不變；如果某個綁定的輸入已經控制另一個動作（或軸的另一個方向），該綁定就會被略過並列出。
更新，保留遊戲的綁定 如果您把某個輸入指派給另一個動作，原本在該輸入上的動作會失去它；該動作保留其他輸入。
更新，以我的設定檔為準 同上，而且您綁定的每個動作都會在 JoyPro 能讀取的已連接裝置上失去其他輸入。
取代我的裝置上的綁定 已寫入裝置的其他所有可指派動作都會被解除，所有分頁皆然。
+ 同時清除我的其他裝置 其他已連接的裝置（每個型號一個）會失去這些動作；沒有已存對應表的裝置會得到空的對應表，這在遊戲中不會造成任何改變，因為遊戲不會為未知裝置提供預設綁定。

#永遠不會變更的內容

  • 玩家無法指派的動作（選單導覽和幾個固定動作）。
  • 鍵盤和滑鼠的對應表、校正對應表、輸入行為、控制器指派，以及遊戲的設定檔。
  • 未連接的裝置、同一型號的兩個以上裝置、匯入時忽略的裝置，以及 JoyPro 轉送輸入用的 vJoy 裝置。

#細分程度、曲線及其他

  • 細分程度：全域，所有飛機共用一組綁定。
  • 軸曲線：不寫入（遊戲的曲線存放在 Controls.cfg 中）。
  • 鍵盤和修飾鍵：不寫入。
  • 力回饋、遙測：無。
  • 監看程式：監聽遊戲機碼的登錄檔變更通知（監看程式）。
  • HUD：HUD 透過遊戲的處理程序（Arena）找到遊戲。
技術細節

#Tiny Combat Arena 整合的內部運作

程式碼：engine\Games\TinyCombatArenaIntegration.cs（登錄機碼、玩家名稱、分頁、目錄結構），建構在 engine\Games\RewiredMapIntegration.cs 之上（讀寫 Rewired joystick 對應表，與 Nuclear Option 共用）。

  • 裝置：未知裝置的 hardwareGuid 為零，hardwareIdentifier = WindowsRawInput + 去掉空白的 HID 產品字串 + PID + VID。匯出時裝置必須已連接，因為機碼是由它的 HID 產品名稱和 VID/PID 組成的。
  • 元素：軸 X、Y、Z、Rx、Ry、Rz = 0 到 5，按鈕 n = 31 + n，帽子開關 h（從 1 起算）的 Up / Right / Down / Left = 160 + 4(h-1) + 0 到 3。Mapper 會在按鈕元素上寫入 axisRange 1；JoyPro 也寫入 1，但比對按鈕時不看這個值。
  • 指令清單：engine tinycombatarena refresh-db 從第一個能解析的 Arena_Data\sharedassets*.assets 讀取 Rewired InputManager；玩家無法指派的動作會被排除，軸動作另外會有使用遊戲方向名稱的各方向列（DB\TinyCombatArena\actions.tsv）。
  • 指令：engine tinycombatarena paths、engine tinycombatarena catalog、engine tinycombatarena scan、engine tinycombatarena import、engine tinycombatarena export（簡稱 engine tca）；復原用 engine backups restore。

#已知限制

  • 遊戲的 Rewired 能辨識的裝置（hardwareGuid 不為零）不在處理範圍內。
  • 帽子開關的斜向和鍵盤綁定不會寫入。
  • 測試：engine\tests\smoke\tinycombatarena.ps1；在遊戲中執行 tools\e2e\games\TinyCombatArenaSettings.ps1（隨機 vJoy 軸上的 Pitch、Roll 和 Yaw、兩個按鈕和一個帽子開關方向會出現在 Flight、Weapons 和 View Select 分頁上，而且在遊戲結束後匯入時能全部讀回）。
