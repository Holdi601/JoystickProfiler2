Arma 2 與 Operation Arrowhead

顯示：

Arma 2 和 Arma 2: Operation Arrowhead 會把您的綁定存放在玩家設定檔中：每個動作一行數字代碼，另外還有一份遊戲看過的搖桿清單。兩款遊戲共用一個資料夾，但檔案是分開的，所以 JoyPro 會把它們當成兩款遊戲。JoyPro 只讀寫飛機和直升機的綁定；步兵、載具和選單的綁定會保持不變。Operation Arrowhead 也涵蓋 Combined Operations、BAF、PMC、ACR 和 DayZ mod。

給新手

#3 個步驟就能用

  1. 全部幫我設定好
    在「開始」頁面
  2. 使用這些按鈕
    先查看清單
  3. 寫入我的遊戲
    保持遊戲關閉

事前準備：連接所有裝置後啟動遊戲一次。開啟 Options > Controls > Controllers。然後結束遊戲。您玩的兩款遊戲都要各做一次。

接著：您的綁定就會出現在 Options > Controls 中。

您之前在 Arma 2 中綁定過按鈕嗎？那麼「開始」頁面會提供 匯入，然後填補空缺。您的綁定會保留，只有空閒的按鈕會被指派新功能。請參閱 快速入門：讓我的搖桿能用。

#JoyPro 為 Arma 2 做了什麼

  • 匯入：您搖桿、油門和腳舵上的飛機與直升機綁定，會連同每個軸的靈敏度滑桿一起進入您的設定檔。
  • 關聯：一個關聯就是所有遊戲中的同一個功能。Arma 2 和 Operation Arrowhead 在其中是兩款遊戲，所以一個關聯可以同時包含兩者。
  • 匯出：JoyPro 只重寫飛行動作的按鍵行。鍵盤和滑鼠綁定會保留，這些動作上的也一樣。

#匯入您的 Arma 2 綁定

  1. 開啟 開始 頁面。如果 Arma 2 或 Operation Arrowhead 卡片要求指令清單，請按 建立清單：JoyPro 會從遊戲檔案讀取動作及其英文名稱（唯讀，不需要先啟動遊戲）。
  2. 在您所玩遊戲的卡片上按 匯入，並保留 加入我的設定檔。
  3. 按 立即匯入。查看我的關聯 會開啟匯入的內容。

JoyPro 只管理您的搖桿：不會匯入或匯出鍵盤綁定，而且 Arma 2 不支援搭配修飾鍵的搖桿按鈕。

#建立並檢查關聯

使用 關聯流程 將各遊戲中的同一功能連結起來，然後在「匯出」頁面按 檢查。匯出時會把直升機和固定翼飛機視為不同的載具：同一個按鈕同時用在兩者上不算衝突。武器和視角動作則兩者都算。

#匯出到 Arma 2

  1. 關閉遊戲。 Arma 2 會自己儲存設定檔，因此遊戲執行期間 JoyPro 會拒絕寫入。
  2. 開啟 匯出，並勾選 Arma 2 或 Operation Arrowhead 卡片。
  3. 如果您是用 JoyPro 設定搖桿，請保留 取代我的裝置上的綁定 和 同時清除我的其他裝置。然後在卡片上按 立即匯出。
在遊戲中: 您在 Arma 2 中會看到什麼

啟動遊戲並在主選單開啟 Options > Controls。您的綁定會出現在飛機和直升機動作上，就在您的鍵盤按鍵旁邊。在 Controllers 下會列出並啟用您的裝置，裝置的 Customize 會顯示 JoyPro 為每個軸設定的靈敏度滑桿。

#您在 Arma 2 中需要自己做的事

  • 連接所有裝置後啟動遊戲一次，並開啟 Options > Controls > Controllers。遊戲第一次看到裝置時，會把它加入清單；清單中沒有的裝置，JoyPro 無法寫入，並會提示您連接該裝置後啟動遊戲一次。
  • 遊戲中被停用的裝置，只要取得綁定，匯出時就會被啟用（匯出結果會說明）。
  • 如果兩款遊戲您都玩，請各啟動一次：每款都有自己的設定檔和裝置清單。

#常見問題

  • 「遊戲正在執行」：結束 Arma 2 或 Operation Arrowhead，然後重新匯出。
  • 腳舵或油門會發射武器或轉動視角：遊戲第一次看到裝置時，會把所有搖桿預設值都加給它（X 軸傾斜、Y 軸機頭、帽子開關轉動視角，以及幾個按鈕），腳舵和油門也不例外。取代我的裝置上的綁定 會移除這些預設值。
  • 32 號以上的按鈕或第二個帽子開關沒有作用：Arma 2 只讀取 32 個按鈕、8 個軸和第一個帽子開關。超出範圍的綁定 JoyPro 會略過。
  • 更換 USB 連接埠後裝置被略過：遊戲會把新的 ID 視為新裝置。請連接該裝置後啟動遊戲一次。
  • 只有 Arma 2：油門只在半個行程有作用：沒有 Operation Arrowhead 的 Arma 2 無法把油門桿的前後兩半合併到同一個動作上。
進階

#JoyPro 讀取和寫入的檔案

檔案 這是什麼
%USERPROFILE%\Documents\ArmA 2\<name>.ArmA2OAProfile Operation Arrowhead（以及 Combined Operations、DayZ 模組）：key<Action>[]={...}; 行、class JoysticksList 和其他選項
%USERPROFILE%\Documents\ArmA 2\<name>.ArmA2Profile 單獨的 Arma 2，格式相同
%USERPROFILE%\Documents\ArmA 2 Other Profiles\<name>\<name>.<ext> 您的其他設定檔（與 Arma 3 不同，沒有破折號）
<profile>.joypro-meta.json JoyPro 為已寫入綁定保存的名稱、群組和調校，下次匯入時會讀回
<profile>.jpbak 首次寫入前的副本，以及 JoyPro 的版本化備份庫

JoyPro 永遠不會變更 <name>.vars.<ext> 或影像設定 ArmA2.cfg / ArmA2OA.cfg，當設定檔是二進位（rapified）檔案時會停止。其他每個位元組都保持不變：換行符號、開頭的 Tab、各行的順序。缺少的已編目按鍵行會加在最後一個按鍵行之後（缺少一行表示「使用遊戲的預設值」）。

#Arma 2 的匯出模式

只有已編目的飛機和直升機動作所在的行會變更。鍵盤、滑鼠、TrackIR 和 Xbox 手把代碼，以及鍵盤組合鍵，一律保留。

模式 設定檔中會發生什麼
僅新增 不會移除任何東西。如果綁定的代碼已被同一載具的另一個動作使用，就不會寫入，並標示為「未寫入遊戲」。
更新，保留遊戲的綁定 寫入您的代碼；您移到別處的同一載具其他動作的代碼會被捨棄。該動作的其他代碼保留。
更新，以我的設定檔為準 同上，而且您綁定的動作會失去已連接搖桿上的其他搖桿代碼。
取代我的裝置上的綁定 飛行行還會失去已寫入裝置的所有其他代碼，包括遊戲的自動預設值。
+ 同時清除我的其他裝置 其他已連接搖桿的代碼也一樣。未連接的搖桿會保留它的代碼。

#永遠不會變更的內容

  • 步兵、載具、選單，以及所有不是已編目飛行動作的行。
  • 鍵盤、滑鼠、TrackIR 和 Xbox 手把代碼。
  • 未連接的搖桿、代碼範圍在清單中沒有對應裝置的代碼、匯入時忽略的裝置，以及 JoyPro 轉送輸入的 vJoy 裝置。
  • 裝置清單：JoyPro 不新增項目，只變更現有項目的 sensitivity[] 和模式；joystickSensitivity[]、控制器方案、滑鼠和 TrackIR 設定都保留。

#載具、曲線、設定

  • 細緻度：所有飛機和直升機共用一組綁定；依遊戲區分（Arma 2、Operation Arrowhead）。
  • 以半軸處理軸：Arma 2 將軸的每一半綁定到一個動作。JoyPro 的軸關聯會兩半都寫入：俯仰（機頭向下 / 機頭向上）、滾轉（向左 / 向右傾斜）、方向舵（左 / 右踏板）、街機式轉向、推力變化率（增加 / 減少推力），以及視角和縮放。
  • 油門：「Thrust (Analogue)」是飛機的油門，也是直升機的絕對總距桿；「Brake (Analogue)」是減速板。在 Operation Arrowhead 中，JoyPro 會把拉桿的兩半都放到該動作上，負半軸在前（反向時正半軸在前），遊戲會把它們合併成一個完整的軸。單獨的 Arma 2 只會取得一半。
  • 靈敏度：每個裝置和實體軸一個滑桿（Customize 對話方塊，-1 到 1），儲存為 10 的滑桿值次方。它適用於所有載具。JoyPro 只寫入您為 Arma 2 / Operation Arrowhead（或兩者皆是，family:arma2）設定的值，或來自匯入的值；當同一軸上的兩個關聯不一致時，按名稱排序的第一個會勝出，並發出警告。
  • 死區：主軸上固定為 7 %（滑桿上沒有）；遊戲中無法調整，也不會寫入。
  • 反向：透過兩半的順序（請參閱「油門」）或使用相反的那一半；沒有反向旗標。
  • 設定：每個裝置的開啟 / 關閉（模式 Custom 或 Disable）。Arma 2 沒有 JoyPro 會寫入的全遊戲選項，也沒有力回饋和遙測。
  • 監看程式：您在遊戲中變更的綁定或滑桿會在遊戲關閉後被偵測到；JoyPro 會詢問是否採用。
  • HUD：HUD 會依據遊戲的處理程序找到遊戲，並顯示您的綁定。
技術細節

#Arma 2 整合的內部運作

程式碼：engine\Games\Arma2Integration.cs，建立在與 Arma 3 共用的 Arma 設定檔程式碼（ArmaProfileIntegration.cs、ArmaGameData.cs）之上，以及軸模型 engine\AxisModels\Arma2.cs（遊戲 Arma2 和 Arma2OA）。

  • 裝置：class JoysticksList { class Joystick1 { guid="..."; name="..."; offset=256; isXInput=0; mode="Custom"; }; }。guid 是 DirectInput 的 執行個體 GUID，大寫，不含大括號；name 是產品名稱。新裝置會取得目前最高的 offset + 256；項目會保留，所以裝置會保有它的 offset。類別名稱 Joystick1..N 在每次儲存時都會重新編號，因此 JoyPro 只依 guid 比對。mode 為 "Custom"、"Scheme"（Xbox 手把方案）或 "Disable"。sensitivity[]（16 個值）只有在遊戲的 Customize 對話方塊確認過後才會出現；當某個值與預設值不同時，JoyPro 會在 isXInput 之後建立它。
  • 代碼：按鈕為 0x20000 + offset + b（b 為 0 到 31）；半軸為 0x30000 + offset + a（正），+ a + 8（負）（X、Y、Z、RotX、RotY、RotZ、Slider 1、Slider 2）；第一個帽子開關為 0x40000 + offset + direction（八個方向）。匯入也會讀取已儲存的整軸代碼；匯出永遠不會寫入它們。
  • 指令清單：engine arma2oa refresh-db 從 Expansion\dta\bin.pbo 讀取 CfgDefaultKeysMapping，engine arma2 refresh-db 則從 Dta\bin.pbo 讀取，並搭配 languagecore.pbo 的英文選單名稱；設定檔會加入模組定義的內容。Operation Arrowhead 有 68 個動作，Arma 2 有 66 個。engine arma2oa catalog、engine arma2oa paths、engine arma2 catalog、engine arma2 paths。
  • 匯入 / 匯出：engine arma2oa import、engine arma2oa scan、engine arma2oa export；engine arma2 import、engine arma2 scan、engine arma2 export（--mode clean|add|merge|merge-overwrite --nuke-untouched-devices --ignore-device <d> --dry-run）。
  • 裝置開關：engine ffb set --device "<name> {GUID}" --game Arma2|Arma2OA --param enabled=0|1（engine ffb set）。

#已知限制

  • 遊戲所說的「more sensitive」是哪個滑桿方向，目前尚未確認。
  • Arma 2 沒有搖桿組合鍵（按鈕搭配修飾鍵）；JoyPro 不會寫入任何組合鍵。
  • 單獨的 Arma 2 沒有放在單一動作上的完整軸；它的直升機總距桿只用拉桿的一半時手感如何，目前尚未確認。Operation Arrowhead 中完整軸的方向，也仍需在真正的首次啟動後確認。
  • 測試：engine\tests\smoke\arma.ps1（靈敏度、family 範圍、裝置開關）；遊戲內為 tools\e2e\games\Arma2Settings.ps1 -Game arma2oa|arma2（測試設定檔 JoyProE2E_OA / JoyProE2E_A2，只操作主選單 > Options > Controls）。
