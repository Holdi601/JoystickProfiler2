給新手

#3 個步驟就能用

  1. 全部幫我設定好
    在「開始」頁面
  2. 使用這些按鈕
    先查看清單
  3. 寫入我的遊戲
    保持 Arma 3 關閉

事前準備：連接所有裝置後啟動 Arma 3 一次，然後結束遊戲。

接著：您的綁定就會出現在 Options > Controls 中。

您之前在 Arma 3 中綁定過按鈕嗎？那麼「開始」頁面會提供 匯入，然後填補空缺。您的綁定會保留，只有空閒的按鈕會被指派新功能。請參閱 快速入門：讓我的搖桿能用。

#JoyPro 為 Arma 3 做了什麼

  • 匯入：您搖桿、油門和腳舵上的飛機與直升機綁定，會連同每個軸的靈敏度、死區和陡度一起進入您的設定檔。
  • 關聯：一個關聯就是所有遊戲中的同一個功能。「Gear」在 Arma 3、DCS 和其他遊戲中可以是同一個開關。
  • 匯出：JoyPro 只重寫飛行動作的按鍵行。您的鍵盤和滑鼠綁定會保留，這些動作上的也一樣。

#匯入您的 Arma 3 綁定

  1. 開啟 開始 頁面。如果 Arma 3 卡片要求指令清單，請按 建立清單：JoyPro 會從遊戲設定讀取動作及其英文名稱（唯讀，不需要先啟動遊戲）。
  2. 在 Arma 3 卡片上按 匯入，並保留 加入我的設定檔。
  3. 按 立即匯入。查看我的關聯 會開啟匯入的內容。

Arma 3 中不會匯入或匯出鍵盤綁定：JoyPro 只管理您的搖桿。

#建立並檢查關聯

使用 關聯流程 將各遊戲中的同一功能連結起來，然後在「匯出」頁面按 檢查。匯出時會把直升機和固定翼飛機視為不同的載具：同一個按鈕同時用在固定翼動作和直升機動作上不算衝突；兩個固定翼動作用同一個按鈕才算。

#匯出到 Arma 3

  1. 關閉 Arma 3。 遊戲會在結束時以及您變更設定時儲存設定檔，因此遊戲執行期間 JoyPro 會拒絕寫入。
  2. 開啟 匯出，並勾選 Arma 3 卡片。
  3. 如果您是用 JoyPro 設定搖桿，請保留 取代我的裝置上的綁定 和 同時清除我的其他裝置。然後在卡片上按 立即匯出。
在遊戲中: 您在 Arma 3 中會看到什麼

啟動遊戲並在主選單開啟 Options > Controls。您的綁定會出現在飛機和直升機動作上，就在您原有的鍵盤按鍵旁邊。在 Controllers 下會列出並啟用您的裝置；裝置的 Customize 會顯示 JoyPro 寫入的靈敏度、死區和陡度。

#您在 Arma 3 中需要自己做的事

  • 連接所有裝置後啟動 Arma 一次。 遊戲第一次看到裝置時，會把它加入清單（並分配它的編號範圍）。清單中沒有的裝置，JoyPro 無法寫入：它會略過該裝置，並提示您連接後啟動遊戲一次。
  • 您在遊戲 Controllers 清單中停用的裝置，只要取得綁定，匯出時就會被啟用（匯出結果會說明），除非您在 JoyPro 中為 Arma 3 將它設為關閉（enabled=0，請參閱「技術細節」）。

#常見問題

  • 「Arma 3 正在執行」：結束遊戲，然後重新匯出。
  • 裝置被略過：Arma 還沒看過這個裝置，或它取得了新的 ID（換一個 USB 連接埠會產生新的項目和新的編號範圍）。請連接該裝置後啟動遊戲一次。
  • 同一個軸上有兩個曲線不同的關聯：Arma 每個實體軸只有一條曲線。依名稱排序的第一個關聯優先；匯出結果會列出兩者。
  • 油門只在半個行程有作用：類比推力需要油門桿的前後兩半。JoyPro 會把固定翼油門和減速板寫成全行程軸；請確認該關聯是綁在軸上，而不是按鈕上。
進階

#JoyPro 讀取和寫入的檔案

檔案 這是什麼
%USERPROFILE%\Documents\Arma 3\<name>.Arma3Profile 預設設定檔：key<Action>[]={...}; 行、class JoysticksList（裝置及其陣列）和遊戲選項
%USERPROFILE%\Documents\Arma 3 - Other Profiles\<name>\<name>.Arma3Profile 您的其他設定檔（資料夾和檔案名稱經過 URL 編碼，例如 Mission%20Builder）
<profile>.joypro-meta.json JoyPro 為已寫入綁定保存的名稱、群組和調校，下次匯入時會讀回
<profile>.jpbak 首次寫入前的副本，以及 JoyPro 的版本化備份庫

JoyPro 永遠不會變更 <name>.vars.Arma3Profile 或 .3den.Arma3Profile，當設定檔是二進位（rapified）檔案而非文字時會停止。-profiles= 資料夾或其他「文件」資料夾可以在「匯出」頁面的 選項與路徑（進階） 下設定。

#Arma 3 的匯出模式

只有已編目的飛機和直升機動作所在的行會變更。鍵盤、滑鼠、TrackIR 和 Xbox 手把的代碼一律保留。

模式 設定檔中會發生什麼
僅新增 不會移除任何東西。如果綁定的代碼已被同一載具的另一個動作使用，就不會寫入，並標示為「未寫入遊戲」。
更新，保留遊戲的綁定 寫入您的代碼；您移到別處的同一載具其他動作的代碼會被捨棄。該動作的其他代碼保留。
更新，以我的設定檔為準 同上，而且您綁定的動作會失去已連接搖桿上的其他搖桿代碼。
取代我的裝置上的綁定 飛行行還會失去已寫入裝置的所有其他代碼。
+ 同時清除我的其他裝置 其他已連接搖桿的代碼也一樣。未連接的搖桿會保留它的代碼。

#永遠不會變更的內容

  • 步兵、載具、視角和選單動作；所有不是已編目飛行動作的行。
  • 鍵盤、滑鼠、TrackIR 和 Xbox 手把代碼。
  • 未連接的搖桿、代碼範圍在清單中沒有對應裝置的代碼、匯入時忽略的裝置，以及 JoyPro 轉送輸入的 vJoy 裝置。
  • 裝置清單本身：JoyPro 不新增項目，只變更現有項目的陣列、模式和類比點按值。

#載具、曲線、遊戲設定

  • 細緻度：所有飛機和直升機共用一組綁定。有些動作是共用的（方向舵、起落架）。
  • 軸曲線，依裝置和實體軸，與 Customize 對話方塊保存的方式相同：每一半各有靈敏度（-1 = 三次方，0 = 線性，+1 = 立方根）、死區（0 到 0.1）和陡度（1.0、1.2、1.5、1.9、2.4 或 3.0；其他值會對齊到最接近的值並發出警告）。陡度是乘數並會飽和，不是指數。JoyPro 只寫入您為 Arma 3 設定的值或來自匯入的值；您 JoyPro 的一般曲線不會帶過去。
  • 反向：Arma 沒有反向旗標。JoyPro 透過綁定軸的相反那一半來反向。
  • 整軸油門：「Thrust (Analog)」和「Speedbrake (Analog)」會取得拉桿的兩半，負半軸在前（拉桿往前）；反向時正半軸在前。
  • 遊戲設定：直升機進階飛行模型及其自動配平、儀表、粗暴降落、風和應力損傷選項，以及遊戲手把震動；每個裝置的開啟 / 關閉和類比點按門檻。請在 設定 > 遊戲的力回饋設定 中設定（選擇 Arma 3），或使用 engine ffb set。即使匯出時沒有 Arma 3 綁定，仍會寫入這些設定，且不會變更任何按鍵行。
  • 力回饋：Arma 3 沒有搖桿力回饋選項。
  • 監看程式：您在遊戲中變更的綁定或曲線會在遊戲關閉後被偵測到；JoyPro 會詢問是否採用。
  • HUD：HUD 會依據遊戲的處理程序找到遊戲，並顯示您的 Arma 3 綁定。
技術細節

#Arma 3 整合的內部運作

程式碼：engine\Games\Arma3Integration.cs，建立在與 Arma 2 共用的 Arma 設定檔程式碼（ArmaProfileIntegration.cs、ArmaGameData.cs）之上，以及軸模型 engine\AxisModels\Arma3.cs 和設定模型 engine\FfbModels\Arma3.cs。

  • 裝置：class JoysticksList { class Joystick1 { guid="..."; name="..."; offset=256; isXInput=0; sensitivity[]={...}; deadZone[]={...}; steepness[]={...}; mode="Custom"; ... }; }。guid 是 DirectInput 的 執行個體 GUID，大寫，不含大括號。offset 是 256 的 N 倍，在遊戲第一次看到裝置時指定；拔除裝置後項目仍會保留。mode="Disabled" 會關閉裝置。
  • 代碼（帶正負號的 32 位元，off = 裝置的 offset）：按鈕為 0x20000 + off + button；軸為 0x30000 + off + a，a 為 0 到 7 時是正半軸，a + 8 是負半軸（X、Y、Z、RotX、RotY、RotZ、Slider 1、Slider 2）；帽子開關為 0x40000 + off + direction（八個方向，一個帽子開關）。鍵盤代碼是 DIK 編號。
  • 陣列：sensitivity[]（16 個值，先是正半軸再是負半軸）、deadZone[]（8 個）和 steepness[]（8 個）。缺少的陣列只有在某個值與預設值不同時才會建立，位置在遊戲儲存順序中的前一個陣列之後，其他軸則填入遊戲的預設值。匯入 + 匯出會逐位元組一致。
  • 指令清單：engine arma3 refresh-db 會從 bin.pbo > config.bin 讀取 CfgDefaultKeysPresets，並從 languagecore_f.pbo 的 stringtable.xml 讀取英文選單名稱；設定檔會加入模組的動作。共 51 個動作。engine arma3 catalog 會列出它們，engine arma3 paths 會顯示找到的設定檔。
  • 匯入 / 匯出：engine arma3 import、engine arma3 scan；engine arma3 export --mode clean|add|merge|merge-overwrite --nuke-untouched-devices --ignore-device <d> --dry-run。
  • 設定：engine ffb set --device "<name> {GUID}" --game Arma3 --param enabled=0|1（還有 analogClickHigh、analogClickLow）；全遊戲設定使用 --device * 搭配 RTDEnabled、RTDAutoTrim、RTDFullHUD、RTDRoughLanding、RTDWindDynamic、RTDStressDamage、vibrations。

#已知限制

  • 搭配修飾鍵的搖桿按鈕尚未確認；JoyPro 不會為 Arma 3 寫入修飾鍵和鍵盤綁定。
  • 每個裝置最多可編碼 256 個按鈕、8 個軸和一個帽子開關（依檔案格式而定）。
  • Customize 滑桿是否會把相同的值寫入兩半，以及某些動作額外疊加的個別動作曲線，目前都尚未確認（預覽只顯示裝置曲線）。
  • 測試：engine\tests\smoke\arma.ps1（陣列、設定、整軸油門、衝突警告、匯入往返、只含設定的匯出）；遊戲內為 tools\e2e\games\Arma3Settings.ps1（測試設定檔 JoyProE2E，只操作主選單 > Options > Controls）。
