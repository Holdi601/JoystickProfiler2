Project Wingman

顯示：

Project Wingman 是一款使用 Unreal Engine 4 的街機風格空戰遊戲。它可以同時讀取多個 DirectInput 裝置，並把綁定存在純文字的 Input.ini 中，每個綁定都以裝置名稱及其在遊戲裝置清單中的位置命名；曲線和死區則存在遊戲存檔中。JoyPro 會把兩者讀入您的設定檔，並寫回去。鍵盤、滑鼠、手把和帽子開關則維持遊戲原本的設定。

給新手

#3 個步驟就能用

  1. 全部幫我設定好
    在「開始」頁面
  2. 使用這些按鈕
    先查看清單
  3. 寫入我的遊戲
    保持 Project Wingman 關閉

之前：先啟動遊戲一次，然後關閉。為這款遊戲關閉 Steam Input。

之後：您的綁定會出現在遊戲的 Controls 中。新增或移除了控制器？請再匯出一次。

您之前在 Project Wingman 中綁定過按鈕嗎？那麼開始頁面會提供 匯入，然後填補空缺。您的綁定會保留，只有空著的按鈕會被指派新功能。請參閱快速入門：讓我的搖桿能用。

#JoyPro 能為 Project Wingman 做什麼

  • 匯入：飛行動作（俯仰、滾轉、偏航、推力、兩個視角軸和按鈕）的每個 joystick 綁定都會帶入您的設定檔，對應到您的實體裝置，並包含反向、曲線和死區。
  • 關聯：Project Wingman 中的「Fire missile」可以和您其他遊戲的武器投放屬於同一個關聯。
  • 匯出：JoyPro 把您的綁定寫入 Input.ini，並把曲線和死區寫入遊戲存檔。

#匯入您的 Project Wingman 綁定

  1. 如果您從未啟動過這款遊戲，請先啟動一次，讓它的資料夾產生。
  2. 開啟 開始。如果 Project Wingman 卡片要求指令清單，請按 建立清單：JoyPro 會從遊戲自己的檔案讀取飛行動作。
  3. 按卡片上的 匯入，保持 加入我的設定檔（建議），再按 立即匯入。

#建立並檢查關聯

在 關聯 頁面把 Project Wingman 的動作和您的其他遊戲連在一起（關聯流程），然後在匯出頁面執行 檢查：它會找出在遊戲中同時做兩件事的按鈕。

#匯出到 Project Wingman

  1. 關閉 Project Wingman。 遊戲執行時 JoyPro 會拒絕寫入。
  2. 開啟 匯出，勾選 Project Wingman 卡片。
  3. 保持 取代我的裝置上的綁定 並搭配 同時清除我的其他裝置，如果您也會在遊戲中綁定，則選擇 更新，保留遊戲的綁定。按卡片上的 立即匯出。
在遊戲中: 您在 Project Wingman 中會看到什麼

開啟遊戲的 Controls。KEY BINDINGS 和 AXIS BINDINGS 會在每一列的下一個空欄位顯示您的綁定，以去掉空格的裝置名稱加上編號命名，例如「VJOYDEVICE 8 BUTTON 24」或「VJOYDEVICE 8 AXIS 1」，您設為反向的地方會勾選 Invert 方塊。CURVES + DEADZONES 會顯示 JoyPro 為每個軸寫入的 CURVE 和 DEADZONE。

#您需要在 Project Wingman 中自己做的事

  • 新增或移除控制器後請再匯出一次。 遊戲依裝置在其裝置清單中的位置編號，而控制器接上或拔除時，這個位置就會改變。JoyPro 會根據匯出時已連接的裝置計算它。
  • 帽子開關：這款遊戲無法綁定帽子開關。請在 Controls > Miscellaneous 中設定 Hat Function 1 / 2（WEAPON 或 VIEW）。
  • 為這款遊戲關閉 Steam Input；Steam Input 手把會顯示為一個額外的裝置。

#常見問題

  • 綁定指向錯誤的裝置：匯出後新增或移除了控制器。請連接您平常使用的裝置後再匯出一次。匯入時若裝置編號有變動，會發出警告。
  • 帽子開關綁定被拒絕：這是刻意的設計，請參閱上方的 Hat Function。
  • 油門在下半段變成煞車：「Thrust Axis」在 Project Wingman 中是置中軸：高於中央時加速，低於中央時煞車。
進階

#JoyPro 讀取和寫入的檔案

檔案 這是什麼
%LOCALAPPDATA%\ProjectWingman\Saved\Config\WindowsNoEditor\Input.ini 綁定，位於 [/Script/Engine.InputSettings] 區段：ActionMappings=(...) 和 AxisMappings=(...) 行
%LOCALAPPDATA%\ProjectWingman\Saved\SaveGames\savegame.sav 每個軸動作的曲線和死區（<Axis>Curve、<Axis>Deadzone）以及帽子開關的功能
<install>\ProjectWingman\Content\Paks\pakchunk0-WindowsNoEditor.pak 唯讀：DefaultInput.ini，遊戲的預設綁定和動作清單
...\Input.ini.joypro-meta.json 已匯出綁定的 JoyPro 資料（名稱、群組、調校），供下次匯入使用

只要在遊戲選單中變更綁定，遊戲就會立即寫入 Input.ini，而且只寫入您變更過的清單；其他清單來自 pak 的預設值。由於寫入的清單會取代預設值，JoyPro 會先為缺少的清單寫入預設值。Steam Cloud 會同步存檔資料夾。

#Project Wingman 的匯出模式

只移除已編目飛行動作的 joystick 對應；鍵盤、手把、滑鼠、選單列以及未連接的裝置都保留。

模式 會發生什麼
僅新增 如果某個綁定所在的輸入已被遊戲用於另一個飛行動作，該綁定就不會寫入（標示為「未寫入遊戲」）；遊戲本身的綁定形式（Invert）保留。
更新，保留遊戲的綁定 另外，如果設定檔把某個輸入指派給另一個動作，也會移除遊戲在該輸入上的對應；該動作的其他對應保留。
更新，以我的設定檔為準 另外也會移除設定檔所綁定的每個動作的其他 joystick 對應，讓搬移真正完整搬移。
取代我的裝置上的綁定 匯出的裝置會失去其他 joystick 對應（這是只有飛行的遊戲）。
+ 同時清除我的其他裝置 其他已連接的裝置也一樣。

#永遠不會變更的內容

  • 鍵盤、滑鼠和手把的對應、選單列、帽子開關。
  • 未連接的裝置、匯入時忽略的裝置，以及 JoyPro 轉送輸入的 vJoy 裝置。
  • Input.ini 的其他每一行（順序和換行符號保持不變），以及 savegame.sav 的其他每個位元組。

#曲線、死區、其他設定

  • 每個軸動作，所有裝置共用：俯仰、滾轉、推力、偏航和兩個視角軸的 CURVE（選單中的 0.00 到 2.00，1.00 = 直線）和 DEADZONE（0 到 100 %）。遊戲的預設值：俯仰和滾轉 25 %，視角 10 %，推力和偏航 0 %。
  • 每個綁定的 反向（欄位的 Invert 方塊）。
  • 遊戲的公式未知。JoyPro 的預覽假設死區會重新縮放，曲線則是指數（尚未確認）。
  • 全域：沒有飛機專屬設定檔。沒有修飾鍵（遊戲本身沒有），沒有力回饋。
  • 監看程式：遊戲關閉後會監看 Input.ini 和 savegame.sav（監看程式）。
  • HUD：遊戲執行時，HUD 會顯示每個按下按鈕的動作名稱。
技術細節

#Project Wingman 整合的內部運作

程式碼：engine\Games\ProjectWingmanIntegration.cs、engine\Games\ProjectWingmanSaveGame.cs、engine\AxisModels\ProjectWingman.cs（軸模型 projectwingman）。

  • 按鍵：Joystick_<name>_<place>_Axis<n>、..._Button<n>。<name> 是去掉空格的 DirectInput 產品名稱（VPforce Rhino FFB Joystick 會變成 VPforceRhinoFFBJoystick），而不是 HID 字串。<place> 是裝置在遊戲清單中的位置（Controls > Miscellaneous），也就是 DirectInput 順序的倒序；XInput 手把不在這份清單中。Axis<n> 依 X Y Z Rx Ry Rz Slider Slider 的順序，從 0 開始計算裝置實際擁有的軸；Button<n> 從 0 開始計算。名稱中含逗號的按鍵會加上引號。
  • 反向 = Scale=-1.000000。
  • 預設值：pak 預設值中的 Android_* 按鍵會保留，因為選單中每個對應顯示一個欄位，而這些按鍵就是空欄位。
  • savegame.sav：Unreal GVAS；FloatProperty <Axis>Curve（選單數值的一半）和 <Axis>Deadzone（0..1），就地編輯，或新增在結尾的 None 之前。沒有校驗碼。
  • 指令清單：engine pw refresh-db 讀取 pak 的 DefaultInput.ini 和您的 Input.ini：6 個軸和 14 個按鈕。
  • 指令：engine pw paths、engine pw catalog、engine pw scan、engine pw import、engine pw export --mode clean|add|merge|merge-overwrite --nuke-untouched-devices --dry-run。

#已知限制

  • 裝置編號會隨您的控制器而改變：更換硬體後請重新匯出。
  • 帽子開關和修飾鍵會被拒絕。
  • 曲線公式是暫定的假設。
  • 完整的遊戲內測試還有一輪尚未進行；匯出和匯入已在遊戲中確認過。
  • 測試：engine\tests\smoke\projectwingman.ps1（依真實格式製作的測試資料）；在遊戲中執行 tools\e2e\games\ProjectWingmanSettings.ps1（隨機軸、按鈕、反向、曲線和死區；讀回控制設定頁面；還原設定和存檔資料夾）。
