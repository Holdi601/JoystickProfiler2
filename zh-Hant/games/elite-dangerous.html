給新手

#3 個步驟就能用

  1. 全部幫我設定好
    在「開始」頁面
  2. 使用這些按鈕
    先查看清單
  3. 寫入我的遊戲
    保持 Elite Dangerous 關閉

事前準備：在遊戲中儲存一次操控設定。變更一項飛船操控，儲存，然後關閉遊戲。

接著：啟動遊戲時，保持預設集中的每個裝置都已連接。您的綁定會出現在 Options > Controls 中。

您之前在 Elite Dangerous 中綁定過按鈕嗎？那麼「開始」頁面會提供 匯入，然後填補空缺。您的綁定會保留，只有空閒的按鈕會被指派新功能。請參閱 快速入門：讓我的搖桿能用。

#JoyPro 為 Elite Dangerous 做了什麼

  • 匯入：您搖桿、油門和面板上的飛船飛行綁定，會連同反向和死區設定，以及您的油門是只能往前還是含倒退，一起進入您的設定檔。
  • 關聯：一個關聯就是所有遊戲中的同一個功能。「Landing gear」在 Elite、Star Citizen 和 DCS 中可以是同一個開關。
  • 匯出：JoyPro 會直接編輯您的 Ship 預設集（Custom.4.x.binds）。檔案中的其他內容都會保留。

#匯入您的 Elite 綁定

  1. 開啟 開始 頁面。如果 Elite Dangerous 卡片要求指令清單，請按 建立清單：JoyPro 會從遊戲內建的預設集和您儲存的預設集收集遊戲動作（唯讀）。
  2. 在 Elite Dangerous 卡片上按 匯入。保留 加入我的設定檔。如果您也想把飛行按鍵帶進 JoyPro，請勾選 同時取得鍵盤按鍵。
  3. 按 立即匯入。查看我的關聯 會開啟匯入的內容。

把半個軸當作按鈕或修飾鍵使用的綁定，無法保存在 JoyPro 設定檔中：匯入時會略過它並顯示警告，匯出時則會把它留在遊戲中。

#建立並檢查關聯

使用 關聯流程 將各遊戲中的同一功能連結起來。然後在「匯出」頁面按 檢查。除了同時做兩件事的按鈕之外，檢查功能還會在 未寫入遊戲 下列出上次匯出時沒有位置可放的每個綁定，並提供 移到另一個按鈕 和 保持原樣。

#匯出到 Elite

  1. 關閉 Elite Dangerous。 遊戲執行期間 JoyPro 會拒絕寫入。
  2. 開啟 匯出，並勾選 Elite Dangerous 卡片。
  3. 如果您是用 JoyPro 設定搖桿，請保留 取代我的裝置上的綁定 和 同時清除我的其他裝置。然後在卡片上按 立即匯出。
  4. 閱讀結果：放不下的綁定以及 JoyPro 保留的半軸綁定，都會以淺白的文字列出。
在遊戲中: 您在 Elite Dangerous 中會看到什麼

啟動遊戲並開啟 Options > Controls，然後進入飛船操控。您的綁定會出現在每個動作的 Primary 或 Secondary 欄中，就在您保留的鍵盤按鍵旁邊。反向的軸會顯示 INVERTED，油門會在其軸範圍下顯示 Forward only 或 Full range，而偏航轉滾轉和頭部視角的各列會顯示您在 JoyPro 中設定的值。

#您在 Elite 中需要自己做的事

  • 在遊戲中儲存一次操控設定。 JoyPro 只會寫入您自己儲存過的預設集。如果您的 Ship 操控仍在使用內建預設集（Generic Joystick，或遊戲的某個 HOTAS 預設集），請在 Options > Controls（Ship）中變更一項操控，儲存，然後關閉遊戲：Elite 就會建立並使用 Custom.4.x.binds。
  • 啟動遊戲時，保持預設集中的每個裝置都已連接。如果預設集中指定的裝置找不到，Elite 會忽略整個預設集。當您的預設集指定了未連接的裝置時，JoyPro 會發出警告。

#常見問題

  • 「Elite Dangerous 正在執行」：結束遊戲，然後重新匯出。
  • 「遊戲中沒有空位」：Elite 每個動作只保留兩個輸入。如果某個鍵盤按鍵佔了一個位置，而您的兩個關聯又把這個動作放到兩個按鈕上，就只有第一個按鈕放得下。請移動第二個按鈕，或保持原樣。
  • 兩支相同的搖桿：Elite 只用 USB ID 區分裝置。兩個已連接的同型號裝置無法對應到遊戲的索引，所以 JoyPro 會兩個都略過。
  • 遊戲載入了另一個預設集：啟動時缺少預設集中的某個裝置。請連接它、在 JoyPro 中替換它，或在遊戲中清除它的綁定。
  • Elite 中沒有 帽子開關斜向：每個帽子開關只有四個方向。
進階

#JoyPro 讀取和寫入的檔案

檔案 這是什麼
%LOCALAPPDATA%\Frontier Developments\Elite Dangerous\Options\Bindings\<preset>.4.<minor>.binds 您的預設集（XML）：每個動作都有 Primary 和 Secondary，軸有 Binding、Inverted 和 Deadzone，還有 ThrottleRange 等數值設定。JoyPro 會寫入 Ship 預設集的最新次要版本。
...\Bindings\StartPreset.4.start 各類別（General、Ship、SRV、On Foot）使用哪個預設集；唯讀
...\Bindings\<preset>.4.<minor>.binds.joypro-meta.json JoyPro 為已寫入綁定保存的名稱、群組、修飾鍵和調校，下次匯入時會讀回
...\Bindings\<preset>.4.<minor>.binds.jpbak 首次寫入前的副本，以及 JoyPro 的版本化備份庫
<install>\Products\<product>\ControlSchemes\*.binds、DeviceMappings.xml 內建預設集和遊戲的裝置名稱；唯讀

檔案以文字方式編輯：換行符號、Tab、宣告、重複的元素、數值設定、您的鍵盤配置和未知的元素都會逐位元組保持不變。JoyPro 永遠不會寫入安裝資料夾、不會編輯 StartPreset.4.start，也不會變更舊版 3.x 用戶端的檔案。

銀河地圖動作屬於 General 預設集。只有在 General 和 Ship 使用同一個檔案時，JoyPro 才會寫入它們；否則會略過並發出警告。

#Elite 的匯出模式

每種模式都只作用於飛行動作和已連接搖桿的位置。

模式 預設集中會發生什麼
僅新增 綁定只會放到空位上。如果綁定的輸入已被另一個飛行動作使用，就不會寫入，並標示為「未寫入遊戲」。
更新，保留遊戲的綁定 在您使用的輸入上，另一個飛行動作的位置會被釋放。您的綁定會優先放到空位，所以只要還有空位，您移動過的動作會保留舊的輸入。
更新，以我的設定檔為準 同上，而且您綁定的每個動作會失去它在您搖桿上的其他位置（鍵盤只在開啟鍵盤選項時）。
取代我的裝置上的綁定 在您寫入的裝置上，每個保存該裝置綁定、但不在您設定檔中的飛行位置都會被清空（{NoDevice}；軸還會設為 Inverted 0 和 Deadzone 0）。
+ 同時清除我的其他裝置 匯出未使用的已連接搖桿，其飛行位置也一樣。

保存鍵盤按鍵、滑鼠或遊戲手把輸入，或 JoyPro 不寫入之裝置的位置，永遠不會被覆寫。如果沒有剩餘的位置，該綁定就不會寫入，設定檔會保留一個標記（「綁定未寫入，遊戲中沒有空位」）。如果軸動作唯一的位置保存了您設定檔中的另一個軸，也是如此。

#永遠不會變更的內容

  • SRV、徒步、攝影機、殖民、UI 和滑鼠動作，即使它們位於同一個檔案中。
  • 鍵盤、滑鼠和遊戲手把位置；鍵盤只在開啟鍵盤選項時寫入，且永遠不會被清除。
  • 未連接裝置的位置、匯入時忽略的裝置，以及 JoyPro 轉送輸入的 vJoy 裝置。
  • 半軸綁定和半軸修飾鍵：匯出會保留它們，並逐一列出，例如「'Cycle Next Ship'：保留了遊戲的綁定 ... 搭配 ... RZ 軸，正半軸作為修飾鍵」。
  • 動作的 <Hold> 和 <ToggleOn> 保持原樣。

#艦船、曲線、遊戲設定

  • 細緻度：所有艦船和戰機共用一個 Ship 預設集。SRV 和徒步預設集不會寫入。
  • 修飾鍵：每個位置最多三個；可以是按鍵或任何裝置的按鈕。JoyPro 會將它的修飾鍵寫成遊戲的 <Modifier> 項目。
  • 軸設定：每個軸動作有反向和死區（0 到 1）；Elite 沒有飽和度和曲線。反向會在您的關聯中保留 DCS 的方向：Elite 對俯仰、油門和垂直推進器的計算方向相反，所以對這些軸而言，檔案中的 Inverted 是您的反向設定翻轉後的值。油門關聯的 滑桿 會設定 Throttle Axis Range：有滑桿 = 只往前，沒有滑桿 = 含倒車的完整範圍（多個油門關聯不一致時會發出警告）。
  • 遊戲設定：偏航轉為滾轉（一般、關閉飛行輔助、降落）、其靈敏度、鍵盤油門增量、頭部視角模式、增量、靈敏度、平滑化和切換時重設。請在 設定 > 遊戲的力回饋設定 中設定（選擇 Elite Dangerous），或使用 engine ffb set。只會就地寫入您設定過的項目；檔案中缺少的設定會被回報，但永遠不會新增。滑鼠、SRV 和徒步設定不在管理範圍內。
  • 力回饋：Elite 沒有搖桿力回饋。
  • 遙測錄製：JoyPro 可以將 Status.json 和日誌（Saved Games\Frontier Developments\Elite Dangerous，唯讀）錄製成 CSV 工作階段；遊戲不提供世界座標，所以沒有 Tacview 航跡。
  • 監看程式：您在遊戲控制選單中變更的綁定會在遊戲關閉後被偵測到；JoyPro 會詢問是否採用。遊戲只有在您於控制選單中儲存時才會寫入預設集。
  • HUD：HUD 會依據遊戲的處理程序找到遊戲，並顯示您的 Elite 綁定。
技術細節

#Elite 整合的內部運作

程式碼：engine\Games\EliteDangerousIntegration.cs、軸模型 engine\AxisModels\EliteDangerous.cs 和設定模型 engine\FfbModels\EliteDangerous.cs。

  • 裝置 ID：%04X%04X，即大寫十六進位的 USB 廠商 ID 和產品 ID（231D0125）。列在安裝中 DeviceMappings.xml 裡的裝置，會改以其符號名稱寫入（T16000M、ThrustMasterWarthogJoystick、VPCThrottle，包含 Alternatives）。JoyPro 只寫入已連接的裝置。相同的裝置需要遊戲的 DeviceIndex，但其順序沒有文件說明：因此略過。
  • 輸入名稱：按鈕為 Joy_1 ... Joy_N，Joy_POV<h>Up/Right/Down/Left（帽子開關 1 到 4），Joy_XAxis ... Joy_RZAxis，滑桿為 Joy_UAxis / Joy_VAxis，鍵盤為 Key_*。永遠不會建立 Pos_Joy_* / Neg_Joy_*（半軸）。
  • 反向：檔案的 Inverted = 關聯的反向 XOR 動作的自然方向（PitchAxisRaw、ThrottleAxis、AheadThrust、VerticalThrustRaw、它們的替代與降落版本、HeadLookPitchAxisRaw、CamTranslateYAxis、ExplorationFSSRadioTuningX_Raw 為 1；其他所有軸為 0）。匯入會以相同方式讀回。回報軸方向相反的裝置在 DCS 中也需要反向，而 XOR 會把這一點帶過去。
  • 指令清單：engine elite refresh-db 會唯讀地讀取遊戲寫入的 .binds（其中列出它認得的每個元素）和內建預設集；只會加入艦船飛行元素，已知的動作保留 ID 和標題。engine elite catalog 會列出清單，engine elite paths 會顯示 JoyPro 找到的檔案。
  • 匯入 / 匯出：engine elite import 和 engine elite scan；engine elite export --mode clean|add|merge|merge-overwrite --nuke-untouched-devices --include-keyboard --ignore-device <d> --dry-run。
  • 遊戲設定：engine ffb set --device * --game EliteDangerous --param <key>=<value>（yawToRollMode、yawToRollSensitivity、throttleIncrement、headlookAccumulate、...）。

#已知限制

  • 兩個相同的裝置會被略過；缺少某個裝置會讓遊戲忽略整個預設集。
  • 遊戲選單中死區滑桿的刻度，以及遊戲在死區之外如何重新縮放，目前尚未確認。
  • 按鈕：玩家回報約 32 個；更高的編號也曾成功過。四個帽子開關，沒有斜向。
  • 檔案中沒有的動作會被略過並發出警告（新增動作是否可行尚未確認）。
  • 測試：engine\tests\smoke\elite.ps1；遊戲內為 tools\e2e\games\Elite.ps1（綁定與模式矩陣）和 tools\e2e\games\EliteSettings.ps1（反向方向、油門範圍、遊戲設定）。
