FSX 與 Prepar3D

顯示：

FSX、FSX: Steam Edition 以及 Prepar3D v4、v5 和 v6 會把您的操控設定保存在 %APPDATA% 中的一個 XML 檔案裡：每個裝置一個對應表，包含它的軸、按鈕和帽子開關，另外還有鍵盤。JoyPro 會把這個檔案讀入您的設定檔，在關聯中與您的其他遊戲結合，然後逐區塊寫回，並保留格式、註解和其他對應表。每個模擬器在 JoyPro 中都是獨立的遊戲，因為各自有自己的檔案。

這項整合是依據公開資料撰寫的，只有一個合成的測試檔案驗證：這些模擬器都還沒有在實際安裝上用 JoyPro 測試過。第一次匯出後，請開啟模擬器的操控設定並檢查指派結果，如有不同之處，請回報給我們。

給新手

#3 個步驟就能用

  1. 全部幫我設定好
    在「開始」頁面
  2. 使用這些按鈕
    先查看清單
  3. 寫入我的遊戲
    保持模擬器關閉

事前準備：連接裝置後啟動模擬器一次，然後關閉它。

接著：開啟模擬器的操控設定並檢查指派結果。這項整合尚未在實際安裝上測試：如有不同之處，請回報給我們。

您之前在模擬器中綁定過按鈕嗎？那麼「開始」頁面會提供 匯入，然後填補空缺。您的綁定會保留，只有空閒的按鈕會被指派新功能。請參閱 快速入門：讓我的搖桿能用。

#JoyPro 為 FSX 和 Prepar3D 做了什麼

  • 匯入：您裝置的軸、按鈕和帽子開關會連同每個軸的靈敏度和零區一起進入您的設定檔。如果您要求，鍵盤按鍵也會一併匯入。
  • 關聯：一個關聯就是您所有遊戲中的同一個功能（FSX、MSFS 和 X-Plane 中的「Gear」都在同一個按鈕上）。指令是模擬器公開的事件名稱（GEAR_TOGGLE、AXIS_AILERONS_SET ...）。
  • 匯出：JoyPro 會寫入您所匯出模擬器的作用中操控檔案。

#匯入您的綁定

  1. 開啟 開始 頁面。您模擬器的卡片會顯示它的圖片。如果卡片要求指令清單，請按 建立清單：JoyPro 會把自己的事件清單，與您的操控檔案（以及模擬器自己的範本檔案）中提到的事件結合起來。
  2. 在卡片上按 匯入。選擇 加入我的設定檔，如果也要匯入按鍵，請勾選 同時取得鍵盤按鍵。
  3. 按 立即匯入。查看我的關聯 會開啟匯入的內容。

#建立並檢查關聯

在 關聯 頁面上，關聯的模擬器事件會和您其他遊戲中的同一功能並列。使用 關聯流程 將它們連結起來，然後在「匯出」頁面按 立即檢查（檢查功能）。

#匯出

  1. 關閉模擬器。 模擬器結束時會重寫檔案；當 fsx.exe 或 Prepar3D.exe 正在執行時，JoyPro 會拒絕寫入。
  2. 開啟 匯出，並使用您模擬器的卡片。
  3. 如果您是用 JoyPro 設定裝置，請保留 取代我的裝置上的綁定 和 同時清除我的其他裝置。然後在卡片上按 立即匯出。
在遊戲中: 您在 FSX 和 Prepar3D 中會看到什麼

啟動模擬器並開啟它的操控設定：您裝置的指派會顯示在那裡，每個軸的靈敏度和零區則在其校準頁面上。確切的選單路徑以及模擬器如何顯示 JoyPro 的檔案，目前尚未確認。

#您在 FSX 和 Prepar3D 中需要自己做的事

  • 連接裝置後 啟動模擬器一次，讓它寫入操控檔案。
  • 第一次匯出後 檢查結果（見上文）。這是這項整合在您電腦上的第一次實際測試。
  • 帽子開關會整個一起指派，通常用於視角平移（PAN_VIEW）。單一帽子開關方向上的其他事件不會被寫入；請在模擬器中綁定它們。

#常見問題

  • 「模擬器正在執行」：關閉它，然後重新匯出。
  • 重新插拔後裝置失去了綁定：Windows 可能會給裝置一個新的 GUID。此時如果剛好只有一個已連接的裝置使用該名稱，JoyPro 就會依名稱找到它的對應表（並顯示警告）。
  • 缺少一個搭配修飾鍵的搖桿綁定：這個格式不支援搖桿按鈕的修飾鍵。按鍵可以搭配 Ctrl、Shift 和 Alt。
進階

#JoyPro 讀取和寫入的檔案

模擬器 控制設定檔
FSX（盒裝版） %APPDATA%\Microsoft\FSX\Controls\Standard.XML（使用中的檔案取自 fsx.cfg [CONTROLS] Controls_Current）
FSX: Steam Edition 與盒裝 FSX 並存時為 %APPDATA%\Microsoft\FSX-SE\Controls\，單獨安裝時為 %APPDATA%\Microsoft\FSX\Controls\
Prepar3D v4 / v5 / v6 %APPDATA%\Lockheed Martin\Prepar3D v<N>\Controls\Standard.xml（使用中的檔案取自 Prepar3D.cfg [CONTROLS]）
全部 <file>.joypro.json（JoyPro 寫入的輸入）、<file>.joypro-meta.json（供下次匯入使用的名稱、群組和調校）

Prepar3D 的 Standard.xmlx（裝置預設集）和安裝資料夾中 FSX 的範本會為了建立指令清單而讀取，永遠不會被寫入。

#FSX 和 Prepar3D 的匯出模式

模式 模擬器中會發生什麼
僅新增 永遠不會移除或取代區塊。放在已有其他事件的輸入上的綁定不會寫入，並會列出。
更新，保留遊戲的綁定 取代您輸入上的事件（衝突的那個），其他一切保留。
更新，以我的設定檔為準 還會移除您所綁定事件的其他輸入（已連接裝置；鍵盤只在開啟鍵盤選項時）。
取代我的裝置上的綁定 您寫入的裝置的主要對應只保留您的綁定。
+ 同時清除我的其他裝置 其他已連接裝置的主要對應會被清空（對應本身保留）。

#永遠不會變更的內容

  • 未連接裝置的對應、匯入時忽略的裝置，以及 JoyPro 轉送輸入的 vJoy 裝置。
  • Slew 對應（... SLEW {GUID}）、Mouse Yoke、Mouse Look、Prepar3D 的個別 SimObject 對應，以及鍵盤對應（除非您匯出鍵盤綁定）。
  • 由兩個一般按鍵組成的組合鍵、註解、格式和未知的元素。

#曲線與設定

  • 細緻度：全域，所有飛機共用一個檔案。
  • 軸設定（軸模型 fsx）：每個裝置軸的靈敏度（0 到 127）和零區（0 到 127），與校準頁面上相同。預設曲線 會被換算過去（死區對應零區，飽和度對應靈敏度）；曲線形狀沒有對應的設定。在「更新」模式下，當 JoyPro 的值只是單純的預設值時，模擬器中設定的值會保留。
  • 反向：負的靈敏度。
  • 沒有力回饋、遊戲設定或遙測。監看程式會在模擬器關閉後偵測變更。

#FSX 和 Prepar3D 整合的內部運作

程式碼：engine\Games\FsxIntegration.cs（一個類別，每個模擬器一個遊戲）、engine\Games\FsxControlsFile.cs（以文字方式編輯整個區塊）、engine\Games\FsxEvents.cs（JoyPro 的事件清單）。

  • 格式：<SimControls.Map>，含 <Name>、<Axis>（<Index> 0 到 7 = X、Y、Z、Rx、Ry、Rz、Slider、第二個滑桿；<AxEvent>、<AxScale>、<AxNull>）、<Entry>（從 0 起算的按鈕 <Index>、<Down> / <Up>，重複事件為 <DownRpt>1）和 <POV>（整個帽子開關）。標頭 encoding="Windows-1252"。
  • 裝置：每個 DirectInput 裝置一個對應，名稱為 <instance name>{<instance GUID>}；依 GUID 比對，否則在恰好只有一個已連接裝置使用該名稱時依名稱比對。檔案中沒有的裝置會得到新的對應。每個裝置回報 32 個按鈕和 8 個軸。
  • 對應：JOY_X .. JOY_SLIDER2 對應到 <Index> 0 到 7，JOY_BTN<n> 對應到 <Index> n-1，帽子開關放在其向上方向（JOY_BTN_POV1_U）。
  • 指令清單：engine fsx refresh-db（以及 fsxse、p3d4、p3d5、p3d6）：約 150 個帶有 JoyPro 標題的事件，加上您的控制設定檔和模擬器範本中提到的每個事件；AXIS_* 事件是軸。
  • 匯入 / 匯出：engine fsx paths（使用中的檔案排在最前）、engine fsx import、engine fsx scan、engine fsx export，以及 engine fsxse export、engine p3d4 export、engine p3d5 export、engine p3d6 export 的對應指令。首次寫入前會先備份。

#已知限制

  • 所有內容都需要在實際安裝上檢查：Prepar3D v4+ 的標頭以及 <Name> 是否仍帶有 GUID、模擬器寫入的確切位元組、第二個滑桿的軸名稱，以及模擬器是否會保留 JoyPro 為它尚未看過的裝置新增的對應。
  • FSX: Steam Edition 的設定檔名稱是推斷出來的。
  • 測試：engine\tests\smoke\fsx.ps1，使用依據文件格式建立的合成檔案。
