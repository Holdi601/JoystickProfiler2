給新手

#3 個步驟就能用

  1. 全部幫我設定好
    在「開始」頁面
  2. 使用這些按鈕
    先查看清單
  3. 寫入我的遊戲
    保持 War Thunder 關閉

之前：先登入一次。插上您的裝置，啟動遊戲並開啟 Controls 一次。然後結束遊戲。

之後：登入。您的綁定會出現在 Controls 中。

您之前在 War Thunder 中綁定過按鈕嗎？那麼開始頁面會提供 匯入，然後填補空缺。您的綁定會保留，只有空著的按鈕會被指派新功能。請參閱快速入門：讓我的搖桿能用。

#JoyPro 能為 War Thunder 做什麼

  • 匯入：您裝置上的飛機與直升機快捷鍵和軸會帶入您的設定檔，並包含遊戲 Axis setup 對話方塊中的每個值，以及全遊戲控制選項（靈敏度、反向、WEP、自動配平、力回饋）。
  • 關聯：一個關聯就是每款遊戲中的同一個功能。「Gear」在 War Thunder、DCS 和 IL-2 中可以是同一個開關。
  • 匯出：JoyPro 會就地編輯 machine.blk。戰車、船艦、潛艦、步兵和選單絕不會被更動。

#匯入您的 War Thunder 綁定

  1. 開啟 開始。如果 War Thunder 卡片要求指令清單，請按 建立清單：JoyPro 會從遊戲的封存檔讀取飛機和直升機動作（唯讀；290 個動作）。設定 > 遊戲 可以關閉這項功能；JoyPro 接著會使用自己較短的清單。
  2. 按 War Thunder 卡片上的 匯入。保持 加入我的設定檔。如果您也想把飛行按鍵放進 JoyPro，請勾選 同時取得鍵盤按鍵。
  3. 按 立即匯入。查看我的關聯 會開啟匯入的內容。

#建立並檢查關聯

用關聯流程把您各款遊戲的相同功能連在一起，然後在匯出頁面按 檢查。在 War Thunder 中，把飛機的油門和直升機的總距桿放在同一個軸上沒有問題；但兩個飛機動作放在同一個按鈕上就不行。

#匯出到 War Thunder

  1. 關閉 War Thunder。 遊戲在執行期間會不時儲存檔案，結束時也會儲存，所以遊戲執行時 JoyPro 會拒絕寫入。
  2. 開啟 匯出，勾選 War Thunder 卡片。
  3. 如果您是用 JoyPro 設定搖桿，請保留 取代我的裝置上的綁定 和 同時清除我的其他裝置。然後在卡片上按 立即匯出。
在遊戲中: 您在 War Thunder 中會看到什麼

啟動遊戲並登入。在機庫中按 Esc，開啟 Controls。您的綁定位於飛機和直升機區段中；某個軸的 Axis setup 對話方塊會顯示它的死區、非線性、倍率、修正和反向。靈敏度列、力回饋倍率和自動配平只會在 Realistic 和 Full-real 控制模式中列出。點選 Mouse aim / Simplified / Realistic / Full-real 分頁會改變您的控制模式，而不是篩選清單。

#您需要在 War Thunder 中自己做的事

  • 讓遊戲先列出每個裝置一次。 War Thunder 會在自己的表格中依裝置為按鈕和軸編號。插上裝置，啟動遊戲並開啟 Controls：遊戲接著會把該裝置加入 machine.blk。JoyPro 會略過遊戲尚未列出的裝置。
  • 第一次匯出前先登入一次，讓您帳號的檔案產生。

#常見問題

  • 「War Thunder 正在執行」：結束遊戲，然後再匯出一次。
  • 某個裝置被略過：遊戲尚未列出它、兩個已連接的裝置共用同一個 VID:PID，或它的按鈕或軸數量與遊戲記錄的不同（所有編號都會錯位）。請在插上裝置的情況下，在遊戲中開啟 Controls。
  • 登入後舊的綁定又回來了：您是手動還原了副本。請改用 復原上次匯出：JoyPro 會提高檔案的版本，讓伺服器不會取代它。
  • 帽子開關斜向方向、滑鼠按鈕和軸修飾鍵 無法寫入。
進階

#JoyPro 讀取和寫入的檔案

檔案 這是什麼
%USERPROFILE%\Documents\My Games\WarThunder\Saves\<uid>\production\machine.blk 您的控制設定（hotkeys{}、axes{}、params{}、deviceMapping{}）和遊戲的設定區塊；<uid> 是您的帳號（由 Saves\lastlogin.blk 指出；登入前為 Saves\last）
...\production\machine.blk.joypro-meta.json JoyPro 為已寫入綁定保存的名稱、群組和調校，下次匯入時會讀回
machine.blk.jpbak 首次寫入前的副本，以及 JoyPro 的版本化備份庫
匯出的控制預設配置（最上層為 controls{}） 也可以匯入和匯出；遊戲全域選項只會寫入 machine.blk

machine.blk 是相對於 basePresetPaths 中所指定基礎預設配置的差異：某個快速鍵的第一個區塊會取代預設配置中該快速鍵的整份清單，空的 ID_X{} 表示未綁定，缺少的軸屬性表示「沿用預設配置的值」。JoyPro 會寫入已編目的快速鍵區塊、axisId 和已編目軸的軸值，以及您設定的個別選項鍵。其他每一行都保留原文字；deviceMapping{} 只會讀取。

#War Thunder 的匯出模式

只有已編目的飛機和直升機控制才算數。衝突是指同一個輸入上的另一個此類控制。

模式 machine.blk 中會發生什麼事
僅新增 只有在沒有其他飛機或直升機控制使用該輸入時，才會寫入快速鍵；它從不移除區塊，也不取代已綁定的軸。被略過的綁定會標示「未寫入遊戲」。
更新，保留遊戲的綁定 您的快速鍵會加在該控制的其他快速鍵旁邊；只會移除衝突（您的軸上另一個控制的軸會改成 axisId -1）。
更新，以我的設定檔為準 同上，而且您綁定的控制會在遊戲列出的已連接裝置上失去其他快速鍵（鍵盤只在開啟鍵盤選項時）。
取代我的裝置上的綁定 同上，而且已寫入裝置上的其他飛機和直升機快速鍵與軸都會被解除。
+ 同時清除我的其他裝置 在您設定檔中沒有綁定的已連接裝置也一樣。

當 JoyPro 綁定某個控制時，空的 ID_X{} 會被取代。檔案中缺少的控制會出現警告：此時您的快速鍵會取代基礎預設配置中該控制的預設值。

#永遠不會變更的內容

  • 戰車、船艦、潛艇、步兵和選單的快速鍵與軸。
  • deviceMapping{}、config{}，以及 JoyPro 未設定的每一行設定。
  • 滑鼠綁定、未連接的裝置、匯入時忽略的裝置，以及 JoyPro 轉送輸入用的 vJoy 裝置。
  • 鍵盤，除非您匯出鍵盤綁定。
  • 相對控制、保持數值和軸範圍維持檔案中的設定，除非您自己設定。

#飛機、曲線、遊戲選項

  • 細分程度：所有飛機共用一組控制，所有直升機共用一組（遊戲沒有各飛機專屬的綁定）。
  • 修飾鍵：快速鍵的最後一個按鈕是主要輸入，區塊中的其他按鈕和按鍵是它的修飾鍵。每個快速鍵最多三個替代組合。
  • 軸曲線使用遊戲本身的單位，與 Axis setup 對話方塊中顯示的相同：死區（0 到 0.5）、非線性（0 到 3，顯示為 1 到 4）、倍率、修正、反向、相對控制及其靈敏度和步進、停用軸時保持數值。沒有 War Thunder 值的關聯會套用擬合後的 JoyPro 曲線：倍率 = 1 / 飽和度 X，死區隨之縮放，並取最接近的非線性值；滑桿則把死區和飽和度之間的行程對應到整個範圍。與基礎預設配置相同的值會省略該行，就像遊戲本身存檔時一樣。
  • 遊戲選項：飛機和直升機的滾轉、俯仰和偏航靈敏度、反向 Y 軸（飛機、直升機）、反向油門、按住油門啟用 WEP、自動配平、開啟力回饋（遊戲需要重新啟動）及其倍率。請在 設定 > 遊戲的力回饋設定（選擇 War Thunder）或用 engine ffb set 設定。即使匯出時沒有 War Thunder 綁定也會寫入；匯入會採用檔案中的值。
  • 雲端副本：登入時，遊戲會比對檔案第一行的 version:i=N 和伺服器上的版本。JoyPro 會保留這個版本，所以您的新內容會被上傳。復原上次匯出 會給還原後的檔案一個比被取代檔案更高的版本，讓伺服器上的副本不會蓋回來。
  • 遙測力回饋：力回饋 頁面會根據遊戲的本機網頁伺服器（127.0.0.1:8111，由執行中的遊戲提供；不需要任何設定）來驅動您的力回饋搖桿。請為該搖桿關閉遊戲本身的力回饋。
  • 遙測錄製：JoyPro 可以從同一個伺服器錄製一次出擊，並匯出為 CSV 或 Tacview 格式（以 0/0 為中心的平面地圖，因為遊戲沒有真實的地理位置）。
  • 監看程式：您在遊戲中變更的綁定、軸值或選項，會在遊戲關閉後被偵測到；按鍵順序改變或遊戲的差異寫法不算是變更。
  • HUD：HUD 透過遊戲的處理程序找到遊戲，並顯示您的 War Thunder 綁定。
技術細節

#War Thunder 整合的內部運作

程式碼：engine\Games\WarThunderIntegration.cs、engine\Games\WarThunderVromfs.cs、軸模型 engine\AxisModels\WarThunder.cs，以及設定模型 engine\FfbModels\WarThunder.cs。

  • 裝置：deviceMapping{ joystick{ devId:t="0738:2215" name:t="..." buttonsOffset:i= buttonsCount:i= axesOffset:i= axesCount:i= } }。devId 是 DirectInput 產品的 VID:PID；遊戲只用 devId 對應裝置，所以兩個相同的裝置會合併成一個。joyButton = buttonsOffset + 本機索引（先是按鈕，接著每個帽子開關四個：上、右、下、左）；axisId = axesOffset + 依 DirectInput 順序的本機索引（X、Y、Z、Rx、Ry、Rz、兩個滑桿），接著每個帽子開關兩個。engine games devices 會顯示 JoyPro 對每個裝置看到的內容。
  • 格式：BLK 文字，name:type=value，區塊名稱可重複（解析為有序清單），CRLF。controls.version 低於 5 的檔案屬於舊版，不會讀取。
  • 指令清單：engine warthunder refresh-db 從 gui.vromfs.bin 讀取 shortcutsgroupaircraft.nut 和 shortcutsgrouphelicopter.nut，從 lang.vromfs.bin（lang/controls.csv）讀取標題，解壓到暫存資料夾後再刪除；只保留 ID 和標題。--no-game-archives（設定 > 遊戲：取消勾選「War Thunder：從遊戲封存檔讀取完整指令清單」）會改用 JoyPro 自己的 116 個動作清單；不含 ID_ 的 ID 是軸。--path 接受一個以一般檔案存放控制指令碼的資料夾。
  • 匯入 / 匯出：engine warthunder import、engine warthunder scan；engine warthunder export --mode clean|add|merge|merge-overwrite --nuke-untouched-devices --include-keyboard --ignore-device <d> --dry-run。
  • 基礎預設配置：由於沒有官方預設配置數值的對照表，匯出會明確寫入每個已調校的軸屬性（從不以「與基礎相同」為由省略某行），因此不論基礎預設配置是哪一個，檔案都是正確的；匯入時，檔案未設定的屬性會使用程式碼中的預設值。
  • 遊戲選項：engine ffb set --device * --game WarThunder --param <key>=<value>（joyFX、forceGain 0..100、aileronsMultiplier ... 以 % 表示、invertY、invertYHelicopter、invertT、holdThrottleForWEP、autotrim）。
  • 遙測：engine ffb telemetry setup 和 engine telemetry record；只在遊戲執行時，JoyPro 每秒輪詢 /state 20 次，並每隔一次請求輪詢 /indicators。

#已知限制

  • 沒有隨附基礎預設配置數值的對照表（見上文）。
  • 有一次監看程式沒有偵測到「按住油門啟用 WEP」的變更，另有一個靈敏度讀回時差了 1。
  • 每個裝置讀取 128 個按鈕和 4 個帽子開關；帽子開關的斜向、滑鼠按鈕和軸修飾鍵不會寫入。
  • 測試：在遊戲中執行 tools\e2e\games\WarThunderSettings.ps1（vJoy 軸上的綁定、俯仰和油門的 Axis setup 對話方塊、Controls 頁面的值，以及匯入遊戲改寫後的檔案）。

此遊戲的所有技術說明（由儲存庫產生）： war-thunder.md.
