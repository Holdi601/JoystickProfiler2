給新手

#3 個步驟就能用

  1. 全部幫我設定好
    在「開始」頁面
  2. 使用這些按鈕
    先查看清單
  3. 寫入我的遊戲
    保持 X4 關閉

之前：先為每個裝置指定一次欄位。在 X4 的控制設定中，開啟 Manage Controllers/Joysticks。把每個裝置指定到一個欄位，然後正常離開遊戲。

之後：您的綁定會出現在 Settings > Controls 中。

您之前在 X4 中綁定過按鈕嗎？那麼開始頁面會提供 匯入，然後填補空缺。您的綁定會保留，只有空著的按鈕會被指派新功能。請參閱快速入門：讓我的搖桿能用。

#JoyPro 能為 X4 做什麼

  • 匯入：您的搖桿、油門和腳舵的太空飛行綁定會帶入您的設定檔，並包含遊戲的反向和油門模式。
  • 關聯：一個關聯就是每款遊戲中的同一個功能。「Boost」在 X4、Elite Dangerous 和 Star Citizen 中可以是同一個按鈕。
  • 匯出：JoyPro 會在您裝置的欄位上就地編輯 inputmap.xml。選單、第一人稱、鍵盤和滑鼠綁定都會保留。

#匯入您的 X4 綁定

  1. 開啟 開始。如果 X4 卡片要求指令清單，請按 建立清單：JoyPro 會從您的安裝讀取遊戲的控制項（唯讀）。
  2. 按 X4 卡片上的 匯入。保持 加入我的設定檔。如果您也想把飛行按鍵放進 JoyPro，請勾選 同時取得鍵盤按鍵。
  3. 按 立即匯入。查看我的關聯 會開啟匯入的內容。

#建立並檢查關聯

用關聯流程把您各款遊戲的相同功能連在一起，然後在匯出頁面按 檢查。joystick 綁定請不要使用修飾鍵：X4 的 joystick 綁定不接受修飾鍵。

#匯出到 X4

  1. 關閉 X4。 遊戲在每次遊玩結束時會寫入 inputmap.xml 和 config.xml，所以遊戲執行時 JoyPro 會拒絕寫入。
  2. 開啟 匯出，勾選 X4 卡片。
  3. 如果您是用 JoyPro 設定搖桿，請保留 取代我的裝置上的綁定 和 同時清除我的其他裝置。然後在卡片上按 立即匯出。
在遊戲中: 您在 X4 中會看到什麼

啟動遊戲並開啟 Settings > Controls。您的綁定位於每個太空飛行控制項的控制器 / joystick 欄中，在您裝置的欄位上。Invert Controller / Joystick Axes 會顯示 JoyPro 設定的反向，而雙向油門、joystick 死區和自適應轉向等列會顯示您的值。自動滾轉和震動位於遊戲設定中。

#您需要在 X4 中自己做的事

  • 先為每個裝置指定一次欄位。 在 X4 的控制設定中，開啟 Manage Controllers/Joysticks，把每支搖桿、每個油門和每組腳舵指定到一個欄位，然後正常離開遊戲。X4 接著會在 config.xml 中記住該裝置。沒有這個項目的裝置每次遊玩時都會換到不同的欄位，所以 JoyPro 會略過它（「在 X4 中將裝置指定到欄位一次」）。在那裡被設為「none」的裝置也會被略過。
  • 匯出前請先插上您的裝置。

#常見問題

  • 「X4 正在執行」：離開遊戲，然後再匯出一次。
  • 某個裝置被略過：它在 X4 中沒有固定到欄位。請在 Manage Controllers/Joysticks 中指定它。
  • 欄位 1 上的搖桿做出手把的動作：欄位 1 是 X4 預設對應表中的手把欄位，所以放在那裡的搖桿會繼承原廠的手把綁定。取代我的裝置上的綁定 會移除它們。
  • 64 號以上的按鈕或第二個帽子開關沒有作用：X4 每個裝置讀取 64 個按鈕、8 個軸和一個帽子開關。JoyPro 會略過超出範圍的綁定並發出警告。
  • 某個反向設定沒有被更動：一個反向設定會套用到該控制項上的所有裝置。當您的關聯彼此不一致，或有手把綁定在同一個控制項上時，JoyPro 會保留遊戲原本的值並發出警告。
進階

#JoyPro 讀取和寫入的檔案

檔案 這是什麼
%USERPROFILE%\Documents\Egosoft\X4\<id>\inputmap.xml 目前生效的綁定（每個控制和輸入的 <action>、<state>、<range>）以及 <config> 參數（反向、死區、雙向油門、自適應轉向）。<id> 是 Steam 帳號的資料夾。
...\X4\<id>\config.xml 裝置插槽（<joysticks>）以及震動、自動滾轉和手把模式等遊戲設定；讀取插槽，並就地編輯設定
...\X4\<id>\inputmap.xml.joypro-meta.json JoyPro 為已寫入綁定保存的名稱、群組和調校，下次匯入時會讀回
inputmap.xml.jpbak、config.xml.jpbak 首次寫入前的副本，以及 JoyPro 的版本化備份庫

檔案以文字方式寫入：宣告、換行符號、縮排、區段註解、<config>、根屬性以及每一行未變動的內容都逐位元組保持不變。新的行會放進所屬區段，接在控制編號較小的同類項目最後一筆之後。JoyPro 從不更動已存的設定檔 inputmap_1.xml 到 inputmap_5.xml，也不碰您的存檔。Steam Cloud 會同步該資料夾；它會同步哪些檔案尚未確認。

#X4 的匯出模式

衝突是指同一個插槽和輸入上的另一個飛行控制。控制在地圖和詳細監視器中的分身算是同一個控制。

模式 inputmap.xml 中會發生什麼事
僅新增 不移除任何東西。如果某個綁定的輸入已被另一個飛行控制使用，該綁定不會寫入，並標示「未寫入遊戲」。
更新，保留遊戲的綁定 您的行會加在該控制的其他輸入旁邊；只會移除衝突。
更新，以我的設定檔為準 同上，而且您綁定的控制會在已連接裝置的固定插槽上失去其他行（開啟鍵盤選項時也會失去鍵盤的行）。
取代我的裝置上的綁定 已寫入插槽上不在您設定檔中的飛行綁定會被移除，插槽 1 上原廠的手把飛行綁定也一樣。
+ 同時清除我的其他裝置 對於 config.xml 固定給匯出未使用的已連接裝置的插槽，也同樣處理。沒有固定裝置的插槽不予處理：它的裝置是未知的。

X4 的選單會把某些控制綁在一起："Toggle Travel Mode" 也會在地圖中設定相同的輸入，"Dock" 同時也負責解除停靠。JoyPro 會像選單一樣成組寫入和移除這些控制，而且從不移除第一人稱的 "Interact" 分身。

#永遠不會變更的內容

  • 選單、地圖、第一人稱、選項和無障礙控制；環形選單項目。
  • 鍵盤和滑鼠的行；鍵盤只在開啟鍵盤選項時寫入，只限飛行控制，而且從不使用 X4 選單拒絕的按鍵（Escape、Delete、Ctrl+X/C/V ...）。
  • 未連接或未固定的裝置的插槽、手把、匯入時忽略的裝置，以及 JoyPro 轉送輸入用的 vJoy 裝置。
  • JoyPro 未設定的每一行 <config>。

#曲線和遊戲設定

  • 細分程度：所有飛船共用一組綁定（太空飛行控制）。
  • 反向 是每個控制一個值，適用於所有裝置（invert_steering_yaw、_pitch、_roll、invert_throttle、invert_strafe_*）。您的關聯維持 DCS 的方向；X4 本身的 HOTAS 對應把俯仰、滾轉和油門視為反向，因此對這幾項，JoyPro 會把參數設成與您的反向設定相反。只有當該控制上的所有 JoyPro 軸都一致時，它才會設定參數。
  • 雙向油門 依照油門關聯的 滑桿 設定：滑桿 = 只能向前，非滑桿 = 中間位置為零推力。
  • 死區：X4 對所有 joystick 的所有軸只有一個死區。關聯的死區不會寫入（匯出時會說明）；請在 設定 > 遊戲的力回饋設定（選擇 X4）或用 engine ffb set 設定遊戲的死區。同一個地方還有自適應轉向、震動、自動滾轉和手把模式。您在那裡儲存的設定優先於關聯；如果它與關聯相反，會出現警告。
  • X4 沒有個別軸的曲線或飽和度；沒有力回饋；沒有遙測。
  • 監看程式：您在遊戲中變更的綁定或選項，會在遊戲關閉後被偵測到（inputmap.xml 和 config.xml），JoyPro 會詢問是否要採用。
  • HUD：HUD 透過遊戲的處理程序找到遊戲，並顯示您的 X4 綁定。

#X Rebirth 和 X3

X Rebirth 使用與 X4 相同的 inputmap.xml 用語，但它的指令清單需要另外從安裝目錄擷取。X3（Reunion、Terran Conflict、Albion Prelude）使用另一套引擎，檔案格式未知。兩者都只有文件記錄：JoyPro 不會匯入或匯出它們。

#X4 整合的內部運作

程式碼：engine\Games\X4Integration.cs、engine\Games\X4CatalogSource.cs，以及設定模型 engine\FfbModels\X4.cs。

  • 插槽：綁定會指明一個來源：INPUT_SOURCE_JOYBUTTONS（按鈕和帽子開關）或 INPUT_SOURCE_JOYAXES，插槽 1 不加字尾，其他插槽加 _2 到 _8。config.xml 以 DirectInput 執行個體 GUID 把裝置對應到插槽，並以 X4 自己的格式寫出（{42cec570-0a3f-11f0-80-0b-44-45-53-54-00-00}）；num 0 到 7 是插槽，disabled="1" 表示沒有。JoyPro 只寫入目前已啟用的項目與已連接裝置相符的插槽。
  • 代碼：按鈕 1 到 11 使用 X4 的手把名稱（INPUT_XBUTTON_A ... BIGBUTTON），12 到 64 為 INPUT_XBUTTON_12 ...；帽子開關為 INPUT_XBUTTON_DPAD_*（八個方向）；軸為 INPUT_JOYAXIS_X ... RZ、SLIDER1、SLIDER2。範圍不加 sgn。鍵盤：INPUT_KEYCODE_<DIK>，搭配 _SHIFT / _CONTROL。
  • 指令清單：engine x4 refresh-db 以唯讀方式從 .cat/.dat 封存檔讀取 gameoptions.lua 和英文文字頁面，並讀取 X4.exe 的名稱表；共 128 個太空飛行控制（6 個軸、122 個按鈕）。列會顯示為 "Yaw (Primary Steering Axis)"、"Roll (Secondary Steering Axis)"。engine x4 catalog 列出清單，engine x4 paths 顯示找到的檔案。
  • 匯入 / 匯出：engine x4 import、engine x4 scan；engine x4 export --mode clean|add|merge|merge-overwrite --nuke-untouched-devices --include-keyboard --ignore-device <d> --dry-run。
  • 遊戲設定：engine ffb set --device * --game X4 --param <key>=<value>；參數會就地編輯，缺少的參數會新增為 <config> 的最後一行。即使匯出時沒有 X4 綁定，仍會寫入已儲存的設定。

#已知限制

  • 沒有固定插槽的裝置會被略過；JoyPro 目前還不會自行固定它們。
  • joystick 修飾鍵不會寫入：它們在檔案中的標記方式尚未確認。
  • 每個裝置 64 個按鈕、8 個軸和一個帽子開關；八個插槽，與手把共用。
  • 震動：遊戲的滑桿顯示的是數值乘以 100 後捨去小數的結果（21 % 顯示為 20）；檔案中保留精確的數值。
  • 測試：engine\tests\smoke\x4.ps1（也包括目錄更新）；在遊戲中執行 tools\e2e\games\X4.ps1（綁定和模式矩陣，在它自己的設定檔資料夾中）和 tools\e2e\games\X4Settings.ps1（反向、油門模式、遊戲設定）。
