G-Rebels

顯示：

G-Rebels 是一款以 Unreal Engine 5 打造的賽博龐克飛行戰鬥遊戲：您駕駛 VTOL 飛越巨型城市。遊戲會把您開啟的每支搖桿放到一個 頻道（0 到 5）上，並在兩個存檔中依頻道保存每個軸的角色（俯仰、滾轉、偏航、推力、平移、上升 / 下降）和按鈕綁定。JoyPro 會把這些角色和綁定讀入您的設定檔並寫回；鍵盤、遊戲手把和滑鼠則維持遊戲原本的設定。

給新手

#3 個步驟就能用

  1. 全部幫我設定好
    在「開始」頁面
  2. 使用這些按鈕
    先查看清單
  3. 寫入我的遊戲
    保持 G-Rebels 關閉

事前準備，在遊戲中為每個裝置各做一次：在 OPTIONS > INPUT > DEVICES 下為它指定頻道。在它的 JST 頁籤上變更一個軸角色。綁定一個按鈕。（詳情如下。）

接著：您的綁定會顯示在裝置的 JST 頁籤上。

您之前在 G-Rebels 中綁定過按鈕嗎？那麼「開始」頁面會提供 匯入，然後填補空缺。您的綁定會保留，只有空閒的按鈕會被指派新功能。請參閱 快速入門：讓我的搖桿能用。

#JoyPro 為 G-Rebels 做了什麼

  • 匯入：每個頻道的軸角色（哪個搖桿軸是俯仰、滾轉、偏航、推力、側向平移、上升 / 下降）連同反向設定，以及 JoyPro 認得的按鈕綁定，都會以您的實體裝置進入您的設定檔。
  • 關聯：G-Rebels 中的「Pitch」可以和您其他遊戲中的俯仰是同一個關聯。
  • 匯出：JoyPro 會在您裝置的頻道上設定軸角色和按鈕綁定。它永遠不會新增頻道或裝置：這部分您要在遊戲中自己做一次。

#匯入您的 G-Rebels 綁定

  1. 開啟 開始 頁面。如果 G-Rebels 卡片要求指令清單，請按 建立清單：JoyPro 會寫入自己的遊戲軸角色和按鈕表。
  2. 在 G-Rebels 卡片上按 匯入，保留 加入我的設定檔（建議），然後按 立即匯入。
  3. 查看我的關聯 會開啟匯入的內容。

#建立並檢查關聯

在 關聯 頁面將您的關聯綁定到 G-Rebels 動作（請參閱 關聯流程），然後在「匯出」頁面執行 檢查。G-Rebels 每個軸只允許一個角色，每個動作和頻道只允許一個按鈕；檢查功能會顯示哪裡有兩個關聯想用同一個輸入。

#匯出到 G-Rebels

  1. 關閉 G-Rebels。 遊戲執行期間 JoyPro 會拒絕寫入。
  2. 開啟 匯出，並勾選 G-Rebels 卡片。
  3. 如果您是用 JoyPro 設定搖桿，請保留 取代我的裝置上的綁定 和 同時清除我的其他裝置。然後在卡片上按 立即匯出。
在遊戲中: 您在 G-Rebels 中會看到什麼

開啟 OPTIONS > INPUT > CONTROLS 以及您裝置的 JST<channel> 頁籤（頻道 0 為 JST0）。在 AXIS 下，每個搖桿軸（X、Y、Z、RX、RY、RZ、Slider、Dial）會顯示 JoyPro 設定的角色（YAW、THRUST、ROLL、PITCH、SIDE STRAFE、UP / DOWN 或 NONE）。在 BUTTONS 下，已綁定的動作會顯示您的按鈕，例如「Enhanced Raw Input Controller 0 Button 5」。

#您在 G-Rebels 中需要自己做的事

在第一次匯出前，每個裝置各做一次：

  1. 開啟裝置：OPTIONS > INPUT > DEVICES 會列出每支搖桿，並標示 DEACTIVATED。為您要使用的每個裝置指定一個頻道（0 - CHANNEL ... 5 - CHANNEL）。沒有頻道的裝置會在匯出時被略過，並顯示「請在 OPTIONS > INPUT > DEVICES 中開啟它」。
  2. 在裝置的 JST 頁籤上 變更一個軸角色。遊戲要到這時才會儲存該頻道的軸設定列；JoyPro 只會直接修改這些列，永遠不會新增。只開啟頁籤不會儲存任何內容。
  3. 在遊戲中 綁定一個按鈕 一次。按鈕檔案會在第一次綁定時出現。

#常見問題

  • 軸角色沒有被寫入：該頻道還沒有已儲存的軸設定列。請在遊戲中該頻道的 JST 頁籤上變更一個軸角色，關閉遊戲，然後重新匯出。
  • 缺少一個按鈕綁定：目前在遊戲的按鈕中只確認了 Primary Fire；其他動作會在得知名稱後陸續加入。
  • 多個 Raw Input 裝置共用按鍵：使用 虛擬 Joystick 把整套 HOTAS 放到一個裝置上；這樣就只需要一個頻道。
進階

#JoyPro 讀取和寫入的檔案

檔案 這是什麼
%LOCALAPPDATA%\G_Rebels\Saved\SaveGames\SaveOptions.sav 裝置及其頻道（依 HID 路徑），以及每個頻道每個軸的一列軸設定：角色、反向、死區、倍數
%LOCALAPPDATA%\G_Rebels\Saved\SaveGames\EnhancedInputUserSettings.sav 按鈕綁定，每個動作和頻道一個對應
...\SaveOptions.sav.joypro-meta.json JoyPro 保存的已匯出綁定資料（名稱、群組），下次匯入時會讀回

兩個存檔在首次寫入前都會備份（旁邊的 .jpbak 和 JoyPro 的備份庫）。

#G-Rebels 的匯出模式

每個軸一個角色，每個動作和頻道一個按鍵。軸角色和按鈕適用相同的規則。

模式 會發生什麼
僅新增 角色只會放到尚未有角色的軸上；已有其他角色的軸會被略過，並標示為「未寫入遊戲」。
更新，保留遊戲的綁定 設定檔的角色會放到其軸上（原本在那裡的角色會移除）；該角色在其他軸上保留。按鈕：該按鍵上其他動作的對應會移除。
更新，以我的設定檔為準 同上，而且該角色在已連接頻道上的其他軸會設為 NONE。
取代我的裝置上的綁定 已寫入頻道上的其他所有角色都會變成 NONE。
+ 同時清除我的其他裝置 JoyPro 不寫入的已啟用、已連接頻道也一樣。

#永遠不會變更的內容

  • 鍵盤、遊戲手把、滑鼠和遊戲的其他選項。
  • 裝置未連接的頻道會保留它的角色。
  • 匯入時忽略的裝置，以及 JoyPro 轉送輸入的 vJoy 裝置。
  • 遊戲的裝置清單：JoyPro 永遠不會開啟或關閉裝置，也不會新增頻道。

#軸與其他設定

  • 全域：每個頻道一組綁定，沒有飛機設定檔。
  • 反向 會隨角色一起寫入。帽子開關（POV 列）、死區和靈敏度目前還不會寫入。
  • 沒有全遊戲設定，也沒有力回饋。
  • 監看程式：您在遊戲中變更的角色或綁定會在遊戲關閉後被偵測到（監看程式）。
  • HUD：G-Rebels 執行時，HUD 會顯示每個按下按鈕的動作名稱。
  • 遊戲每個裝置最多讀取 96 個按鈕和 24 個軸，沒有帽子開關。
技術細節

#G-Rebels 整合的內部運作

程式碼：engine\Games\GRebelsIntegration.cs、engine\Games\GRebelsSaveOptions.cs、engine\Games\GvasKeyMappings.cs。

  • SaveOptions.sav：Unreal GVAS（UE 5.8，帶有型別樹的屬性標籤）。Joysticks 保存 S_Controller_Save { DeviceID (HID path), Enabled, MultiID (channel) }；AxisOptions 保存 S_Input_Axis_Save { Key, Offset, Multiplier, Role, Inverted, DeadZone }，按鍵如 RawInput_Controller0_AxisY，角色則為列舉值（0 Yaw、1 Thrust、2 Roll、3 Pitch、4 Side strafe、5 Up/down、6 None）。沒有校驗碼：JoyPro 會就地編輯固定大小的值。
  • EnhancedInputUserSettings.sav：Unreal Enhanced Input 的玩家對應按鍵。對應名稱為 <ACTION>JST<channel>（PRIMARYFIREJST0），按鍵為 RawInput_Controller<channel>_Button<n>，n 為 DirectInput 按鈕編號。對應清單會被改寫；其他每個位元組都保持不變。
  • 裝置：依 HID 路徑比對到遊戲指定給它們的頻道。
  • 指令清單：JoyPro 自己的表（DB\GRebels\actions.tsv，軸角色和按鈕；不讀取遊戲的檔案）。engine grebels refresh-db 會將它寫入遊戲資料資料夾；已存在的列保留原有項目。
  • 指令：engine grebels paths、engine grebels catalog、engine grebels scan、engine grebels import、engine grebels export --mode clean|add|merge|merge-overwrite --nuke-untouched-devices --dry-run。

#已知限制

  • 帽子開關、死區和靈敏度不會寫入。
  • 按鈕中只有 Primary Fire 已在遊戲中確認。
  • 永遠不會新增項目：頻道、軸設定列和按鈕檔案都必須由遊戲建立。
  • 測試：engine\tests\smoke\grebels.ps1；遊戲內為 tools\e2e\games\GRebelsSettings.ps1（兩次啟動：第一次讓 vJoy 取得頻道並儲存軸設定列，第二次檢查隨機角色和 JST0 上的 Primary Fire；之後會還原存檔資料夾）。
