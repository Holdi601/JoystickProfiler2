WARDOGS

顯示：

WARDOGS 是一款使用 Unreal Engine 5 的直升機戰鬥遊戲。它自己的 joystick 外掛會讀取每個 DirectInput 裝置，並把綁定存在一個設定檔案中：六個飛行軸和飛行動作，每個都帶有它所屬的裝置。JoyPro 會把這個區段讀入您的設定檔並寫回去，連同 HOTAS 頁面的靈敏度、死區和 Enable HOTAS 開關。鍵盤、滑鼠和檔案的其他所有部分都維持原樣。

給新手

#3 個步驟就能用

  1. 全部幫我設定好
    在「開始」頁面
  2. 使用這些按鈕
    先查看清單
  3. 寫入我的遊戲
    保持 WARDOGS 關閉

之前：在遊戲中開啟 Settings > GAMEPAD > HOTAS 一次。然後關閉遊戲。

之後：Enable HOTAS 已開啟，您的綁定會出現在 HOTAS 頁面上。

您之前在 WARDOGS 中綁定過按鈕嗎？那麼開始頁面會提供 匯入，然後填補空缺。您的綁定會保留，只有空著的按鈕會被指派新功能。請參閱快速入門：讓我的搖桿能用。

#JoyPro 能為 WARDOGS 做什麼

  • 匯入：HOTAS 頁面的綁定會帶入您的設定檔：Pitch、Roll、Yaw、總距桿（Throttle）、兩個視角軸和飛行動作（Fire、Flares、Reload、Horn、Ping ...），每個都在各自的裝置上，並包含反向、靈敏度和死區。
  • 關聯：一個關聯可以同時用於 WARDOGS 和您的其他遊戲：例如在 WARDOGS 和 DCS 的直升機中，都把「Collective」放在您的油門桿上。
  • 匯出：JoyPro 把直升機綁定寫入遊戲的設定檔案，並開啟 Enable HOTAS，讓遊戲使用它們。

#匯入您的 WARDOGS 綁定

  1. 開啟 開始。如果 WARDOGS 卡片要求指令清單，請按 建立清單：JoyPro 會根據您自己的設定檔案和它自己的軸對照表建立清單。
  2. 按 WARDOGS 卡片上的 匯入。保持 加入我的設定檔（建議）。
  3. 按 立即匯入。查看我的關聯 會開啟匯入的內容。

#建立並檢查關聯

在 關聯 頁面，把 WARDOGS 的動作和您其他遊戲的相同功能連在一起，請參閱關聯流程。接著在匯出頁面執行 檢查：它會搶在遊戲之前，找出在 WARDOGS 中同時做兩件事的按鈕。

#匯出到 WARDOGS

  1. 關閉 WARDOGS。 遊戲結束時會重寫整個設定檔案，所以遊戲執行時 JoyPro 會拒絕寫入。
  2. 開啟 匯出，勾選 WARDOGS 卡片。
  3. 如果您是用 JoyPro 設定搖桿，請保留 取代我的裝置上的綁定 和 同時清除我的其他裝置。然後在卡片上按 立即匯出。
在遊戲中: 您在 WARDOGS 中會看到什麼

啟動 WARDOGS 並開啟 Settings > GAMEPAD > HOTAS。Enable HOTAS 已開啟，每一列軸會顯示您的裝置和軸，以及它的反向方塊、Sensitivity 和 Deadzone 滑桿，而動作會顯示您的按鈕。選單中動作按鈕從 0 開始計算，但半軸按鈕從 1 開始，所以同一個按鈕可能顯示兩個不同的編號。

#您需要在 WARDOGS 中自己做的事

  • 第一次匯出前 先開啟 HOTAS 頁面一次。JoyPro 只會寫入遊戲的 joystick 區段；如果檔案中還沒有這個區段，匯出會停止，並請您在遊戲中開啟該頁面。
  • Enable HOTAS 開啟時會關閉滑鼠和鍵盤飛行。JoyPro 每次寫入綁定時都會開啟它。若要自己控制它，請在 設定 > 遊戲的力回饋設定（遊戲 WARDOGS）中設定：您在那裡儲存的值會在每次匯出時寫入。
  • 「Garage / Vendor」和「Free Look Reset」目前還不在 JoyPro 的清單中。請先在遊戲中綁定一次，然後按 WARDOGS 卡片上的 更新：JoyPro 會加入它在您的檔案中找到的動作。

#常見問題

  • 「WARDOGS 正在執行」：關閉遊戲，然後再匯出一次。
  • 某個裝置在遊戲中顯示 NOT CONNECTED：遊戲以 VID:PID 和 DirectInput 名稱來命名裝置。請在連接該裝置的情況下再匯出一次：JoyPro 會修正與具有相同 VID:PID 的已連接裝置不一致的名稱。
  • 兩個相同的裝置：WARDOGS 無法區分它們（它們會得到相同的名稱）。請使用虛擬 Joystick，或在 WARDOGS 的綁定中只保留其中一個。
  • 綁定在飛行中沒有作用：請檢查 HOTAS 頁面上的 Enable HOTAS；它關閉時，遊戲會忽略所有 joystick 綁定。
進階

#JoyPro 讀取和寫入的檔案

檔案 這是什麼
%LOCALAPPDATA%\Wardogs\Saved\Config\WindowsClient\GameUserSettings.ini [/Script/WDJoystick.WDJoystickSettings] 區段中的綁定；[/Script/WDGame.WDUserSettings] 中的遊戲全域開關 Enable HOTAS（bUseHOTASHelicopters）和 Self-Centering Collective（bCollectiveSelfCentering）
...\GameUserSettings.ini.joypro-meta.json 已匯出綁定的 JoyPro 資料（關聯名稱、群組、調校），供下次匯入讀回
...\GameUserSettings.ini.jpbak 第一次寫入前的備份（也保存在 JoyPro 的備份區中）

同一個檔案中的鍵盤綁定，以及 Saved\SaveGames\EnhancedInputUserSettings.sav，都不會讀取或寫入。JoyPro 不會從安裝目錄讀取任何內容：指令清單的來源是您的設定檔案。

#WARDOGS 的匯出模式

遊戲每個動作只使用一個綁定。每種模式都只處理 JoyPro 已編目的直升機動作；檔案的其他行和區段從不變更。

模式 會發生什麼
僅新增 只有在動作的欄位是空的，且沒有其他已編目動作使用該按鈕或軸時，才會寫入綁定；否則會略過並標示「未寫入遊戲」。已綁定的欄位從不被取代。
更新，保留遊戲的綁定 您的綁定會佔用該動作的欄位（取代原本的輸入）。同一個輸入上的另一個已編目動作會失去它。該動作的第二行保留。
更新，以我的設定檔為準 同上，而且該動作多出來的行會被移除，讓搬移的動作完整搬移。
取代我的裝置上的綁定 您寫入的裝置只保留您對已編目動作的綁定。
+ 同時清除我的其他裝置 設定檔中沒有綁定的已連接裝置會失去它們的已編目綁定。

匯出沒有 WARDOGS 綁定的設定檔時，只會寫入您儲存的遊戲全域設定。

#永遠不會變更的內容

  • 鍵盤和滑鼠綁定、鍵盤存檔，以及 joystick 區段以外的每個區段（兩個遊戲全域開關除外）。
  • JoyPro 未編目的動作：它們的行保持原樣。
  • 未連接的裝置、匯入時忽略的裝置，以及 JoyPro 轉送輸入的 vJoy 裝置。
  • 綁定行中的未知欄位：保持原樣。

#軸、靈敏度、死區

  • 全域：WARDOGS 沒有飛機或載具設定檔；綁定適用於每一架直升機。
  • 每個軸：反向、靈敏度（0.1 到 2.0，1 = 不變）和 死區（0 到 0.5），使用 HOTAS 頁面本身的單位，四捨五入到小數點後兩位。匯入會把它們保存為該關聯的 WARDOGS 調校，所以您的其他遊戲會保留各自的曲線。
  • 沒有 WARDOGS 值時，JoyPro 會從您的基本曲線擬合出這些值：死區直接沿用，靈敏度則依照到飽和點為止的斜率。滑桿的死區不會沿用，因為 WARDOGS 把總距桿當成置中的軸。曲率和自訂曲線無法表達；匯出時會發出警告。
  • 遊戲沒有預覽，公式也未知。JoyPro 的預覽假設先反向、死區重新縮放，再乘以靈敏度，並在滿行程處截斷（尚未確認）。
  • 遊戲設定：Enable HOTAS 和 Self-Centering Collective（適用於雙搖桿配置：放手時總距桿會回到滯空位置；使用油門桿時請保持關閉），位於 設定 > 遊戲的力回饋設定。只有在檔案中已有該鍵時才會寫入。WARDOGS 沒有力回饋。
  • 監看程式：您在 HOTAS 頁面上變更的綁定，會在遊戲關閉後被偵測到；JoyPro 會詢問是否要採用（監看程式）。
  • HUD：WARDOGS 執行時，HUD 會顯示每個按下的按鈕對應的動作名稱。
技術細節

#WARDOGS 整合的內部運作

程式碼：engine\Games\WardogsIntegration.cs、engine\AxisModels\Wardogs.cs（軸模型 wardogs）、engine\FfbModels\Wardogs.cs（兩個遊戲全域開關）。

  • 檔案：ASCII、CRLF、無 BOM，第一行是 ;METADATA=(Diff=true, UseCommands=true)。軸的行一律六行齊全，順序為 Pitch、Throttle、Roll、Yaw、LookPitch、LookYaw；每個已綁定的動作一行 ActionBindings=(Action=<action>,Binding=(...))，新的行加在最後一行之後。軸以 DeviceIdentifier="" 解除綁定；動作則刪除它的行。浮點數使用六位小數。名稱維持 ASCII（非 ASCII 名稱會讓引擎改存成 UTF-16）。
  • 欄位名稱：大部分欄位是雜湊後的代號（_aaaa...）。JoyPro 從不寫死這些名稱：它依照每個欄位在可讀錨點（DeviceIdentifier、bInvert、Positive、Sensitivity、DeadZone）旁的位置找出欄位，一旦結構改變就停止。
  • 裝置：DeviceIdentifier="VID:PID:<DirectInput instance name>"，VID 和 PID 取自 DirectInput 產品 GUID，名稱完全依照 DirectInput 回報的內容，包括頭尾的空格（從不修剪）。軸編號是 DIJOYSTATE2 的欄位（0 X、1 Y、2 Z、3 Rx、4 Ry、5 Rz、6/7 滑桿）；按鈕從 0 開始計算。
  • 指令清單：engine wardogs refresh-db 根據您的設定檔案加上 JoyPro 的軸建立清單；engine wardogs catalog 列出清單，engine wardogs paths 顯示 JoyPro 尋找的位置。
  • 匯入 / 匯出：engine wardogs scan、engine wardogs import、engine wardogs export --mode clean|add|merge|merge-overwrite --nuke-untouched-devices --ignore-device <d> --dry-run。
  • 遊戲設定：engine ffb set --device * --game Wardogs --param enableHotas=true（或 selfCenteringCollective）。

#已知限制
