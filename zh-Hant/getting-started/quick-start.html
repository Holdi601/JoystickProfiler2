快速入門：讓我的搖桿能用

顯示：

您希望搖桿能在遊戲中使用。您不想先學會 JoyPro。這一頁就是為您準備的。

JoyPro 會查看您的搖桿、油門和腳舵。它會自動把重要的遊戲控制項放到上面。您看一下結果，點兩個藍色按鈕。就這樣。

  1. 全部幫我設定好
    在「開始」頁面
  2. 使用這些按鈕
    在新視窗中
  3. 寫入我的遊戲
    下一個藍色按鈕
  4. 開飛
    啟動您的遊戲
給新手

#開始之前

  • 下載 JoyPro 並解壓縮：下載與安裝。
  • 插上您的搖桿、油門和腳舵。
  • 先啟動遊戲一次，然後關閉。有些遊戲要到那時才會建立控制檔案。
  • JoyPro 寫入遊戲時，請保持遊戲關閉。

#快速的方式，逐步說明

  1. 啟動 JoyPro。 第一次啟動時，會有一個視窗顯示您的遊戲。請按 完成，並全部幫我設定好。這樣就可以跳過步驟 2。
  2. 按「全部幫我設定好」。 您可以在開始頁面的「設定您的裝置」卡片中找到它。在歡迎畫面（第一次啟動後 JoyPro 提出的第一個問題）回答 讓我的搖桿直接能用 效果相同。
  3. 看一下清單。 它會說明每個按鈕的功能，例如「按鈕 4：武器重新裝彈」。放大顯示圖片 會顯示您的搖桿及每個按鈕。
  4. 按「使用這些按鈕」。 現在 JoyPro 有了您的按鈕。您的遊戲還不會改變。
  5. 按「寫入我的遊戲」。 現在您的遊戲有了您的按鈕。JoyPro 會保留一份舊按鈕的副本。
  6. 開飛。 開始頁面會顯示「成功了！」。啟動您的遊戲並開始飛行。

一次只會有一個按鈕是藍色的。點選藍色的按鈕，下一個就會變成藍色。

#關於頭部追蹤的問題

對於飛行模擬遊戲，清單會問：您使用頭部追蹤或 VR 嗎？ 如果您靠轉動頭部環顧四周（TrackIR、具臉部追蹤的網路攝影機、Tobii 或 VR），或打算這麼做，請回答 是。這樣搖桿上不會放視角按鈕，只放「視角重新置中」。如果您用搖桿環顧四周，請回答 否：環顧四周會放到一個帽子開關上。請參閱 頭部追蹤與環顧四周。

底部的那一行

「所有重要按鈕都已設定好。有幾個不常用的額外功能放不下了（18）。這沒關係。」這是好消息。您的搖桿按鈕比遊戲的控制項少。重要的功能都已經放在您的搖桿上了。

#遊戲中已經有按鈕設定

您之前在遊戲中設定過按鈕嗎？那麼 寫入我的遊戲 會問一個問題：

答案 會發生什麼
使用新的 JoyPro 的按鈕會取代舊的。JoyPro 會保留一份舊按鈕的副本。
同時保留舊的 您的新按鈕會加在舊按鈕旁邊。不會移除任何東西。
取消 不會寫入任何東西。準備好時再按一次 寫入我的遊戲。

#ACE COMBAT 和其他只支援 Xbox 手把的遊戲

ACE COMBAT 8 和 Hell Let Loose: Vietnam 只認得 Xbox 手把。它們看不到您的搖桿。JoyPro 會把您的搖桿變成一個模擬手把（虛擬 Xbox 手把）。這些遊戲不會被寫入任何東西。

  1. 全部幫我設定好
    然後按 使用這些按鈕
  2. 設定模擬手把
    第二個藍色按鈕
  3. 測試
    移動您的搖桿
  4. 啟動遊戲
    等標題畫面出現
  5. Alt+Tab，開始
    然後按 Alt+Tab 回去
  1. 按 全部幫我設定好，再按 使用這些按鈕。
  2. 下一個藍色按鈕是 設定模擬手把。虛擬 Joystick 頁面會開啟。
  3. 第一次使用時，需要一個名為 ViGEmBus 的免費輔助程式。請勾選授權條款下方的方塊。然後按 安裝 ViGEmBus。Windows 會要求權限：請點選 是。
  4. 按 測試。移動您的搖桿。手把圖片也會跟著動。
  5. 啟動遊戲。等標題畫面出現。
  6. 按住 Alt 再按 Tab。您就回到 JoyPro 了。按 開始。
  7. 再按一次 Alt+Tab。您就回到遊戲了。起飛吧！
先啟動遊戲，再按「開始」

請在遊戲顯示標題畫面後才按 開始。按太早了？JoyPro 會顯示「太早了」。按 停止，再按 開始。每次遊玩都要這樣做。

更多關於這些遊戲的說明：用 HOTAS 玩只支援 Xbox 手把的遊戲和ACE COMBAT。

#出了問題？

  • 找不到遊戲或搖桿。 插上您的搖桿，或先啟動遊戲一次。然後按 重試。
  • 您想自己多做一些選擇。 請按 逐步設定。這會開啟包含所有步驟的設定精靈。
  • 您想找回舊的按鈕。 請參閱復原快速設定。
  • 您想讓某個功能換一個按鈕。 請參閱之後更改一個按鈕。

#簡單用語

您想要大字和非常短的句子嗎？請在歡迎畫面或第一個視窗中勾選 簡單用語：大字、短句。每張導覽卡片上也都有 更簡單的用詞。請參閱簡單用語、導覽和 F1。

進階

#快速設定會做什麼

  • 它就是自動執行的設定精靈。它使用預設值：您的裝置及其一般用途、每架飛機同等重要、不使用修飾鍵。
  • 它只會設定您的搖桿上還沒有任何綁定的遊戲。開始頁面的卡片會列出這些遊戲：「為 War Thunder 和 Star Citizen 設定裝置」。
  • 功能要放在哪裡？ 沿用您上次在精靈中的選擇（一開始為中間值）。請參閱功能應該放在哪裡？。
  • JoyPro 不認得的裝置，會依照同類裝置的一般方式設定。移動搖桿就能操縱，按鈕 1 開火，第一個帽子開關配平，第一根推桿是油門。頂端的方塊會說明這一點。
  • 做些修改 會顯示工具：移動、對調或略過某個功能，以及把它放回去。它也會顯示放不下的內容。
  • 您自己做過綁定的遊戲會列在卡片下方。匯入，然後填補空缺 會先匯入您的綁定；之後設定只會使用空閒的控制項。設定檔中已有的遊戲則會顯示 填補空缺...。
  • 使用這些按鈕 是設定檔歷程記錄中的一個步驟。按一次 復原（Ctrl+Z）就能全部還原。
  • 寫入我的遊戲 就是這些遊戲的匯出。它會先備份遊戲檔案，與匯出頁面相同。
  • 之後會有一段簡短的導覽，告訴您以後要在哪裡變更按鈕。最後會顯示「完成！開始玩遊戲吧」。
技術細節

#快速設定的背後

快速流程會執行精靈的引擎步驟，但不顯示出來：engine setup devices、engine setup aircraft 和 engine setup plan，直到檢閱為止。使用這些按鈕 會執行 engine setup apply（一個設定檔版本）。寫入我的遊戲 會以匯出頁面的設定和備份執行該遊戲的匯出。對於只支援手把的遊戲，則改為開啟虛擬 Joystick 頁面；它們的對照表來自 engine vjoy map。GUI：開始頁面上的 QuickSetupCommand、StartQuickSetupAsync（MainWindowViewModel.AutoSetupStart.cs），視窗為 Views/SetupWizardWindow.axaml。
