入門

下載與安裝

顯示：

JoyPro 2 是免費的開放原始碼軟體（GPL-3.0）。不需要帳號、不需要註冊，也沒有遙測。

給新手

#三個步驟

  1. 開啟 GitHub 上的發行頁面，下載 JoyPro2-<version>-win-x64.zip（在 Assets 下）。
  2. 在 zip 檔上按右鍵，選擇 全部解壓縮...，並選擇一個您有寫入權限的資料夾，例如 C:\JoyPro2 或您「文件」中的某個資料夾。（不要用 C:\Program Files：JoyPro 會在自己的資料夾中自我更新。）
  3. 開啟資料夾，按兩下 JoyPro.Gui（有搖桿圖示的程式；如果顯示副檔名，它會顯示為 JoyPro.Gui.exe）。

Windows 顯示 Windows 已保護您的電腦？按一下 其他資訊，然後按 仍要執行。對於從網際網路下載、Windows 還不認識的程式，它只會問一次。

第一次啟動時，JoyPro 會尋找您的遊戲，並在一個視窗中顯示它們：請參閱第一次啟動。第一次使用 JoyPro？請在那裡按 完成，並全部幫我設定好，並依照快速入門：讓我的搖桿能用操作。

接著歡迎畫面會詢問您想做什麼，並啟動適合您的導覽。同一個資料夾中的 JoyPro 2 - Tour 隨時都能再次開啟這個歡迎畫面。想要大字和短句？請在歡迎畫面中勾選 簡單用語：大字、短句（簡單用語、導覽和 F1）。

#您需要什麼

  • Windows 10 或 11，64 位元。
  • JoyPro 的引擎需要 .NET Framework 4.8。Windows 10 和 11 已經內建；如果缺少，JoyPro 會提供 Microsoft 的安裝程式。
  • 不需要其他東西：zip 檔包含一切（程式不需要另外安裝 .NET 9）。

#更新

JoyPro 啟動時會到 GitHub 檢查是否有新版本（設定：啟動時檢查更新）。有新版本時會開啟一個視窗，顯示變更內容以及 立即更新 / 稍後 / 略過此版本。您的設定檔和設定都會保留。

進階

#JoyPro 把東西存放在哪裡

您的設定檔位於「文件」資料夾中的 JoyPro2。問題報告也會存放在那裡。更新只會取代程式資料夾：您的設定檔、設定、指令清單、備份和歷程記錄都會保留。完整的資料夾清單請見「技術細節」。

#選用元件

設定 > 元件 只需按一下並經您同意，即可安裝：vJoy（虛擬 joystick）、HidHide（對遊戲隱藏實體裝置）和 ViGEmBus（虛擬 Xbox 手把），供虛擬 Joystick模式使用。設定 > 本機 AI 可以為助理下載選用的 AI 模型；沒有它一切也能正常運作。

#連線上網

JoyPro 只會為了以下用途連線上網：檢查更新（GitHub）、裝置製造商的產品照片（每個裝置都要先經您同意）、您電腦上缺少的遊戲封面（可以關閉）、選用的 AI 模型、選用元件，以及缺少的 .NET Framework 安裝程式。這些網站會看到您的 IP 位址。詳細資訊：隱私權。

技術細節

#JoyPro 的所有資料夾

內容 位置
程式 您解壓縮的資料夾（含 engine\engine.exe、vjoy\、tray\，以及 JoyPro 附帶在 DB\ 中的資料）
您的設定檔 Documents\JoyPro2（或您儲存它們的任何位置）
設定 %APPDATA%\JoyPro2（ui-settings.json、export-settings.json、hud.json ...）
在您電腦上建立的遊戲指令清單 %LOCALAPPDATA%\JoyPro2\GameData
遊戲檔案備份 %LOCALAPPDATA%\JoyPro2\GameBackups（每個遊戲保留最新的 30 份）
設定檔歷程記錄（重新啟動後仍可復原） %LOCALAPPDATA%\JoyPro2\ProfileHistory
記錄檔 %LOCALAPPDATA%\JoyPro2\Logs（幾天後會自動刪除）
問題報告 Documents\JoyPro2\Problem Reports

#套件內容

  • JoyPro.Gui.exe：Avalonia 應用程式（.NET 9，獨立式）。
  • JoyPro 2 - Tour.cmd：啟動 JoyPro.Gui.exe --welcome，也就是附有導覽的歡迎畫面（若 JoyPro 已在執行，會交給它處理）。
  • engine\engine.exe：引擎（.NET Framework 4.8）。GUI 的每個動作都會執行它；您也可以在主控台中執行它（引擎命令列）。
  • vjoy\JoyPro.VJoy.exe（虛擬 joystick 轉送程式）、JoyPro.Ffb.exe（遙測力回饋）、tray\JoyPro.Tray.exe（GUI 關閉時的監看程式）。
  • 更新會下載發行版 zip，對照公開的 .sha256 檔案檢查後再安裝。
  • 從原始碼建置：dotnet build gui/JoyPro.Gui/JoyPro.Gui.csproj（也會建置引擎；需要 .NET Framework 4.8 建置工具），請參閱儲存庫的 README。
