入門

10 分鐘建立您的第一個設定檔

顯示：

讓按鈕能用有兩種方式。快速的方式只要點幾下：由 JoyPro 完成工作。手動的方式比較花時間：每個按鈕都由您決定。您可以先用快速的方式開始，之後再手動修改。

給新手

#快速的方式

  1. 全部幫我設定好
    在「開始」頁面
  2. 使用這些按鈕
    看一下清單
  3. 寫入我的遊戲
    JoyPro 會保留備份
  4. 開飛
    您的按鈕都設定好了
  1. 在開始頁面上按 全部幫我設定好。第一次啟動時，完成，並全部幫我設定好 的效果相同。
  2. 查看各項操作放在哪裡的清單。按 使用這些按鈕。
  3. 關閉您的遊戲。按 寫入我的遊戲。
  4. 啟動您的遊戲並開始飛行。

ACE COMBAT 8 和其他只支援 Xbox 手把的遊戲，最後一步不同：設定模擬手把。完整的逐步說明：快速入門：讓我的搖桿能用。

出了問題？請參閱復原快速設定。

#手動設定

您的遊戲中已經有綁定了嗎？或者您想自己決定每個按鈕？那就走這條路。

  1. 匯入
    您遊戲中的綁定
  2. 關聯
    一個功能，每款遊戲
  3. 綁定
    每個一個按鈕或軸
  4. 匯出
    到每款遊戲
  1. 匯入。 在開始頁面上，按您遊戲卡片上的 匯入，再按 立即匯入。JoyPro 會讀取您的綁定並建立設定檔。遊戲不會改變。（匯入遊戲）
  2. 關聯。 開啟 關聯。關聯是一個功能（「Gear Up/Down」），包含它在每款遊戲中的動作。若要涵蓋第二款遊戲，請開啟一個關聯，並在某個建議上按 新增。（建立關聯）
  3. 綁定。 開啟 綁定。選擇一個關聯，按 錄製輸入，然後按下您搖桿上的按鈕。若是軸，請把它推到底。（綁定頁面）
  4. 檢查。 按底部列中的 檢查。修正紅色卡片。（檢查）
  5. 匯出。 關閉遊戲。開啟 匯出，保持 取代我的裝置上的綁定 和 同時清除我的其他裝置（這會移除遊戲中您搖桿上的舊綁定；JoyPro 會先備份它們）。勾選遊戲，按 匯出已勾選的遊戲。（匯出）

接著啟動遊戲：您的綁定就在它的控制選單中。

在遊戲中做了修改？

您關閉遊戲後，JoyPro 會詢問是否要把您的變更帶入設定檔。

遊戲卡片上的 復原上次匯出 會把遊戲的檔案完全放回原本的樣子。

#已經有綁定了？兩種方式混用

開始頁面會列出您自己做過綁定的遊戲。匯入，然後填補空缺 會先帶入您的綁定。接著設定只會使用空著的按鈕。您自己的綁定會保留。

進階

#手動操作的更快方法

  • 逐步設定...（開始頁面）會開啟設定精靈的完整步驟：您的遊戲、您的裝置及其角色、您的飛機優先順序、規劃，以及檢閱。
  • 填補空缺...（開始頁面）對設定檔中已有的遊戲做同樣的事。您的綁定會留在原處。
  • 根據我的所有動作自動建立關聯...（關聯頁面）會把每架飛機和每個遊戲中的相同功能歸為一組（自動群組）。您會先看到預覽。
  • 自動指派 會把未綁定的關聯放到裝置上最合適的控制項。用 AI 配置 接受用一般文字描述的需求（「把配平放在帽子開關上」），並在套用前顯示每一項變更。
  • 跟隨輸入（關聯頁面和綁定頁面）：按下一個按鈕，它的關聯就會開啟。
技術細節

#背後的運作

快速方式會自動執行設定精靈的引擎步驟（engine setup plan、engine setup apply），然後執行遊戲的匯出。手動方式則使用匯入（engine dcs import 和其他遊戲的匯入）、關聯指令（engine relations add）、綁定（engine binds set）、檢查（engine profile validate）和匯出（engine dcs export 等）。每次變更都是設定檔的一個版本，因此重新啟動後仍可復原。
