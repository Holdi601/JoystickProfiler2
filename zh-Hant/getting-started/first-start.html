入門

第一次啟動

顯示：

JoyPro 第一次啟動時，會尋找您的遊戲。然後在一個視窗「您的遊戲」中顯示它們。之後，歡迎畫面會詢問您想做什麼。

  1. 您的遊戲
    檢查清單
  2. 完成，並全部幫我設定好
    或 完成
  3. 快速設定
    或歡迎畫面
給新手

#「您的遊戲」視窗

JoyPro 會花幾秒鐘尋找您的遊戲。然後視窗會為每款遊戲顯示一列。

您看到的 代表的意思 您可以做的事
已勾選且有資料夾的列 JoyPro 找到了這款遊戲。 不需要做任何事。如果您不想在 JoyPro 中使用它，請取消勾選。
未勾選的列 JoyPro 沒有找到這款遊戲。 如果您沒有這款遊戲，就不需要做任何事。安裝在別的地方？請勾選它並按 瀏覽...。
操控設定儲存於 遊戲存放控制設定的位置。 如果您的設定在別的地方，例如 Saved Games\DCS.openbeta，請在那裡按 瀏覽...。

未勾選的遊戲並不會被隱藏。一旦您安裝它，JoyPro 就會找到它。

#三個按鈕

按鈕 接下來會發生什麼
完成，並全部幫我設定好 JoyPro 會儲存您的遊戲。然後自動設定您的搖桿、油門和腳舵。
完成 JoyPro 會儲存您的遊戲。然後歡迎畫面會詢問您想做什麼。
稍後 什麼都不會改變。接著會出現歡迎畫面。

第一次使用 JoyPro？請按 完成，並全部幫我設定好。然後依照快速入門：讓我的搖桿能用操作。

想要大字和短句？請在這個視窗中勾選 簡單用語：大字、短句。

您隨時都可以再次開啟這個視窗：設定 > 遊戲 > 重新執行設定。

#歡迎畫面

按 完成 或 稍後 之後，JoyPro 會詢問一次：您想做什麼？它會把適合您遊戲的答案標示為 建議。

答案 會開始什麼
用我的飛行搖桿玩 ACE COMBAT 快速設定和模擬手把（虛擬 Xbox 手把）。
DCS World 或 Falcon BMS DCS 做法的導覽：匯入、關聯、曲線、匯出、檢查。
讓我的搖桿直接能用 快速設定。
帶我看看 一趟輕鬆的 JoyPro 導覽，一步一步來。
我用過 JoyPro 1 JoyPro 1 的每個功能現在在哪裡。它可以開啟您的舊設定檔。
不要導覽 什麼都不做。

按 開始。現在不要 會關閉歡迎畫面。它不會自己再出現；若要找回它，請參閱簡單用語、導覽和 F1。

#沒有「儲存」按鈕

您不需要先建立設定檔。JoyPro 會為您建立一個。它會在每次變更後儲存（頂端列顯示「已儲存」）。復原 和 取消復原 都能用，重新啟動後也可以。

進階

#詳細資料

  • 在其他位置的遊戲（可攜式安裝、另一個磁碟機）：勾選它，然後按 安裝位置 旁的 瀏覽...，或按 .exe... 選擇遊戲的程式。
  • 您連結的資料夾會立即檢查：「已找到標記」或「找不到標記，但仍保留您選擇的資料夾」。使用偵測結果 會取消這個連結。
  • 把控制設定存放在安裝目錄中的遊戲（IL-2、IL-2 Korea、IL-2 1946、Falcon BMS、X-Plane、搭配 BYOJoystick 的 VTOL VR）會以唯讀方式顯示位置；使用登錄檔的遊戲（Nuclear Option）也一樣。
  • 隱藏的遊戲在各處都視為未安裝（匯出卡片、監看程式、篩選、HUD ...）；您為它建立的關聯會保留在設定檔中。設定 > 遊戲 會列出隱藏的遊戲，並提供 再次顯示。
  • 完成，並全部幫我設定好 以快速方式回應歡迎畫面：設定流程會開啟，而歡迎畫面不會在旁邊開啟。

#指令清單

JoyPro 需要每個遊戲的指令清單（指令的名稱和 ID）。它會根據您的安裝建立一次清單。開始頁面會顯示通知，針對每個遊戲提供 建立清單，或 建立所有缺少的清單。遊戲更新後，會出現一張卡片顯示「遊戲已更新：請更新其指令清單」，並提供 更新。

  • DCS 會依據已安裝的模組建立清單，不需要開啟遊戲視窗。IL-2 讀取遊戲寫出的按鍵對應檔案。其他遊戲讀取它們自己的檔案（全新安裝時的指令清單）。
  • Ctrl+S 會立即儲存設定檔。歷程記錄 列出每個版本。
技術細節

#內部如何運作

  • GUI 在啟動時執行一次 engine games installs（不會輪詢），並只顯示一次這個視窗（%APPDATA%\JoyPro2\ui-settings.json 中的 gameSetupDone）。檢視模型：MainWindowViewModel.GameSetup.cs，視窗：Views/GameSetupWindow.axaml。
  • 完成 會透過引擎寫入所有內容：engine games install set / clear、engine games config set / clear、engine games install disable / enable，然後重新偵測。
  • 已連結資料夾的標記檔案：bin\DCS.exe、bin\game\Il-2.exe、X4.exe ...
  • 各遊戲的偵測（engine\GameInstalls.cs 和各個 GameIntegration）：Steam 媒體庫資料夾和應用程式 ID、已知的安裝位置、Windows 的解除安裝清單和應用程式清單，以及使用者自己的連結，偵測結果從不會取代這個連結。
  • 指令清單：對於沒有清單的遊戲，engine db check-updates 會回報 no-catalog；建立清單時會執行該遊戲的 refresh-db（DCS 為 engine dcs refresh id + engine dcs refresh clean、engine db refresh-il2、engine db refresh-starcitizen、engine <game> refresh-db），而且只寫入 %LOCALAPPDATA%\JoyPro2\GameData。
