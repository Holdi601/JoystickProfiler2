主要流程

匯出到您的遊戲

顯示：

匯出是讓您的搖桿在遊戲中能用的步驟。JoyPro 會把您的關聯和綁定寫入每款遊戲的控制設定檔，也就是遊戲自己的 Controls 選單所儲存的同一批檔案。飛行時不會有任何東西在背景執行：匯出之後，遊戲會一如往常讀取它自己的檔案。

給新手

#三個步驟完成匯出

開啟底部列中的 匯出。這個頁面由上到下有三張編號的卡片：

  1. 檢查您的設定檔。 按 立即檢查。JoyPro 會找出在遊戲中會出問題的地方，例如在同一架飛機中做兩件事的按鈕。修正它找到的問題（每個問題點一下即可），或保持不動；檢查絕不會阻擋匯出。請參閱檢查。
  2. JoyPro 如何寫入遊戲。 從四種選擇中挑一種。如果您不確定，就保留第一種：取代我的裝置上的綁定 並勾選 同時清除我的其他裝置。這樣您的搖桿就會完全照您的設定檔運作，不會多做別的事。
  3. 匯出到遊戲。 您的設定檔中有綁定的每款遊戲都會有一張帶圖片的卡片。勾選遊戲並按 匯出已勾選的遊戲，或按某張卡片上的 立即匯出。

請先關閉遊戲。 遊戲會在結束時寫入它的控制檔案，所以 JoyPro 會拒絕匯出到正在執行的遊戲，並告訴您原因。

#哪種選擇適合我？

選項 適合的情況 遊戲自己的綁定會怎樣
取代我的裝置上的綁定 JoyPro 是您設定搖桿的地方 在您設定檔中的裝置上，只會保留您的綁定（針對您匯出的飛機）。
更新，保留遊戲的綁定 您也會在遊戲中綁定東西，並想保留它們 您的綁定會寫入；只有當遊戲綁定位於您用於其他功能的按鈕上時，才會被移除。
更新，以我的設定檔為準 和上面一樣，但您在 JoyPro 中把動作移到了其他按鈕 和上面一樣，而且您綁定的每個動作在遊戲中都會失去它的其他按鈕，所以移動就是真正的移動。
僅新增 您第一次試用 JoyPro 不會移除任何東西。如果遊戲已經把某個按鈕用於別的功能，您的綁定就會被略過，並由檢查告訴您。

同時清除我的其他裝置（選項下方的勾選方塊）：您設定檔中沒有綁定的已連接裝置，在匯出的飛機中會失去它們的綁定。如果您想要乾淨地重新開始，請保持勾選；如果您只在遊戲中使用第二個裝置，請取消勾選。

#設計上就很安全

  • JoyPro 在更改遊戲檔案之前，會 先把它複製成備份。每張卡片都有 復原上次匯出：它會把檔案完全放回原本的樣子，一個位元組都不差。
  • 第一次匯出 到已經有自己綁定的遊戲時，會詢問一次：「要先匯入嗎？」。如果您想保留您在遊戲中做的設定，請選擇 先匯入；若要取代它，請選擇 仍然匯出。
  • 沒有插上 的裝置會保留它們的綁定。您的 滑鼠 和 手把 綁定絕不會被更動。

#您在遊戲中會注意到什麼

啟動遊戲並開啟它的控制選單：您的綁定就在那裡，位於每個裝置的欄中，使用遊戲的名稱。在 DCS 中依飛機顯示；在 Star Citizen 中依艦船動作顯示；在 IL-2 中則在 Key mapping 中。下方的在遊戲中一節列出了每一類遊戲。

#讓綁定進入遊戲的其他方式

方式 它的作用
寫入我的遊戲（快速設定） 快速設定的匯出。它會寫入它設定的遊戲，並同樣先備份。請參閱快速入門。
模擬手把（虛擬 Xbox 手把） ACE COMBAT 8 和 Hell Let Loose: Vietnam 不會被寫入任何東西。它們的匯出會說明這一點。當 開始 開啟時，您的搖桿會驅動模擬手把。請參閱只支援 Xbox 手把的遊戲。
DCS 膝板 這不是綁定的匯出：而是每架飛機一頁、在座艙中列出您按鈕功能的頁面。請參閱膝板。

#各遊戲的選項

在 選項與路徑（進階） 中：

  • DCS：DCS 卡片上的 飛機... 清單（只寫入勾選的飛機）；DCS：保留鍵盤預設值（開啟）；我的裝置在其他所有飛機中也失去 DCS 預設綁定（關閉）。
  • Star Citizen：SC：保留鍵盤預設值、優先採用本機順序。
  • 其他遊戲：一個 試執行 方塊，顯示會變更什麼但不寫入。
  • 路徑：每個遊戲可使用不同的 Saved Games 或設定資料夾；此設定檔專用的路徑和忽略的裝置 讓目前開啟的設定檔使用自己的設定，而不是這台電腦的設定。

#標記：「未寫入遊戲」

「僅新增」（以及遊戲沒有空位可放另一個輸入的任何模式，例如每個動作只有兩個輸入的 Elite Dangerous）會略過部分綁定。設定檔會記住每一個被略過的綁定，連同佔用該輸入的遊戲動作和日期；檢查會為每個標記顯示一張卡片，提供 用「更新」匯出以取代、移到另一個按鈕 和 保持原樣。每次匯出都會取代該遊戲和飛機的標記，所以之後的匯出寫入該綁定時，標記就會消失。

#記住的設定

模式、同時清除 勾選、各遊戲選項和路徑都保存在 JoyPro 的設定中；您自己勾選的遊戲和 DCS 飛機則依設定檔保存。「取代」和「同時清除」在每次匯出前都會詢問（可在 設定 > 確認 中關閉這個詢問）。

#匯出之後

  • 卡片上的 復原上次匯出 會還原該遊戲最新的備份。完整清單位於匯出頁面底部的 遊戲設定備份 中。
  • 匯出會為 遊戲監看 記錄遊戲的檔案：JoyPro 自己的匯出之後不會再詢問「要採用變更嗎？」；但您之後在遊戲中所做的變更會（監看程式）。
  • JoyPro 會在遊戲檔案旁保存自己的資料，因此之後匯入時能找回關聯名稱、群組、修飾鍵和曲線（重新匯入）。

#在遊戲中

匯出後玩家會看到什麼，取決於遊戲的類型。下面每款遊戲都遵循相同的規則：JoyPro 只寫入其指令清單中的動作、遊戲執行時拒絕寫入、先備份檔案，而且絕不會猜測它無法對應的裝置或動作（它會略過並發出警告）。

在遊戲中: 飛行模擬器：DCS、IL-2（Great Battles、Korea、1946、Cliffs of Dover）、Falcon BMS、X-Plane、MSFS、FSX、Prepar3D

JoyPro 會接管它寫入的裝置。使用 取代 時，這些裝置的其他所有綁定在匯出的飛機中都會消失；使用 同時清除 時，其他已連接的裝置也會被清除（DCS：連同它們的 DCS 預設綁定）。

  • DCS World：在 Options > Controls 中選擇飛機：您的綁定位於裝置的欄中，被移除的預設綁定會顯示為空白儲存格，您的修飾鍵位於修飾鍵清單中。只有勾選的飛機會改變。JoyPro 只寫入與 DCS 預設值不同的部分，就像 DCS 自己的做法一樣。
  • IL-2 Great Battles：Settings > Key mapping 會顯示您的綁定和軸回應。滑鼠相關的行和 JoyPro 不認得的行都會保留。
  • IL-2 Korea：按鍵對應設定檔「General」。
  • Falcon BMS：啟動器會在下次 Launch 時建立按鍵檔和軸對應，所以請透過啟動器啟動 BMS。
  • MSFS 2024 / 2020：在 Controls 中，裝置會顯示 JoyPro 的預設組合。
  • X-Plane 11 / 12：Settings > Joystick 會顯示指派。
在遊戲中: 有步兵、載具或選單的遊戲：Star Citizen、War Thunder、Arma 3 / 2、Arma Reforger、WARDOGS、Nuclear Option、Hell Let Loose、Battlefield

JoyPro 只更動飛行動作（飛機、直升機、太空船）。您的步行、載具和選單綁定會一個位元組都不差地保留。取代 和 同時清除 只會釋放 JoyPro 認得的飛行動作。

  • Star Citizen：Options > Keybindings 會顯示您 joystick（js1、js2、...）上的艦船動作。使用 取代 或 同時清除 時，若 js1 被寫入或未使用，遊戲自己在 js1 上的 joystick 預設綁定會被關閉。
  • War Thunder：Controls 會顯示飛機綁定；戰車和船艦的控制不變。
  • Arma 3 / Arma 2：設定檔的按鍵設定；只有飛機和直升機動作會改變。
在遊戲中: 太空遊戲：Elite Dangerous、X4: Foundations
  • Elite Dangerous 每個動作保留兩個輸入（Primary 和 Secondary）。沒有空位的綁定會被標示為「未寫入」，並提供「移到另一個按鈕」或「保持原樣」。步行和 SRV 綁定會保留。
  • X4：遊戲的輸入設定；只有已收錄的艦船動作會改變。
在遊戲中: 只讀取一個裝置或只支援 Xbox 手把的遊戲
  • 設為 vJoy 的遊戲（只讀取少數裝置的遊戲）：匯出會把綁定寫到 vJoy 裝置上。您遊玩時，JoyPro 會把您的搖桿複製到它上面，而 HidHide 只對該遊戲隱藏您的實體裝置。遊戲會看到一個包含所有功能的裝置。請參閱虛擬 Joystick。
  • 只支援 Xbox 手把的遊戲（ACE COMBAT 8、Hell Let Loose: Vietnam）：不會寫入任何東西，匯出也會說明這一點。當 開始 開啟時，您的搖桿會驅動模擬手把（虛擬 Xbox 手把）。不需要 HidHide。請參閱用 HOTAS 玩只支援 Xbox 手把的遊戲。

#內部如何運作

一次匯出，從點擊到寫入檔案：

# 誰 會發生什麼
1 您 在匯出頁面上按 匯出已勾選的遊戲。
2 JoyPro 向引擎詢問該遊戲的狀態（profile game-state --game <id>）：是否已匯入、已匯出、有綁定。
3 JoyPro 需要時詢問您：第一次匯出（「先匯入？」），或會移除綁定的模式（設定 > 確認）。
4 引擎 執行 <game> export --mode <m> --nuke-untouched-devices <b> ...：遊戲執行時會拒絕，先備份每個檔案（GameBackups 和 .jpbak），並只寫入目錄中收錄的動作。
5 引擎 儲存同步記錄（指紋和基準）以及匯出標記，然後回答：已寫入、已略過、SkippedTakenInputs。
6 JoyPro 遊戲的卡片顯示「已匯出 14:02」，並且 復原上次匯出 已可使用。
  1. GUI。 ExportSelectedGamesAsync / ExportGameNowAsync（MainWindowViewModel.ExportGames.cs）會詢問 AskAboutFirstExportAsync（engine profile game-state）和 ConfirmRiskyExportAsync，然後 ExportGameAsync 選擇卡片對應的匯出程式：dcs、il2、starcitizen 或登錄表中的遊戲。指令依頁面上的設定組成，例如 RunDcsExportAsync：engine dcs export --mode clean --keep-keyboard-defaults true --nuke-untouched-devices true --clean-all-aircraft false --ignore-device <d> --planes F-16C_50|FA-18C_hornet。每次呼叫引擎都經過同一個地方 RunEngineAsync，帶有 --profile 和 --status true（忙碌區域的進度和取消），並依序執行，確保兩個指令不會同時寫入。
  2. 引擎。 engine\Program.cs 把 dcs / il2 / starcitizen 交給各自的匯出程式，其他每個遊戲交給 Games.GameRegistry（每個遊戲一個 GameIntegration）。DCS：EngineDcsExport.Modes.cs 會針對每個裝置檔案計算 DCS 目前生效的綁定（乾淨設定檔減去 removed，加上 added 和 changed），決定哪些應該生效，並只寫入與預設值真正不同的部分。
  3. 安全措施。 GameExportSafety.BackupBeforeOverwrite 會把每個檔案複製為 <file>.jpbak，並存入版本化備份區（%LOCALAPPDATA%\JoyPro2\GameBackups\<date-time>_<game>\，附 manifest.json；每個遊戲保留最新的 30 組）。使用登錄檔的遊戲（Nuclear Option）會對可能變更的值建立快照。匯出時新建立的檔案會記錄為「原本不存在」，所以還原時會再把它移除。
  4. 之後。 同步記錄（<data>\Sync\<game>.json：每個檔案的大小、時間和 SHA-256，以及每個綁定的雜湊）讓監看程式對 JoyPro 自己的變更保持安靜。ExportSkippedBinds.cs 會填入 SkippedTakenInputs；匯出指令再把它們轉成設定檔的標記。設定檔的歷程記錄會在每次匯出前保留一個檢查點。

#命令列上的每種模式

GUI 選項 引擎選項
取代我的裝置上的綁定 + 同時清除我的其他裝置（預設） --mode clean --nuke-untouched-devices true
取代我的裝置上的綁定 --mode clean --nuke-untouched-devices false
更新，以我的設定檔為準（+ 同時清除） --mode merge-overwrite --nuke-untouched-devices true|false
更新，保留遊戲的綁定（+ 同時清除） --mode merge --nuke-untouched-devices true|false
僅新增 --mode add（不使用 nuke）

各遊戲：engine dcs export、engine il2 export、engine starcitizen export，以及登錄表中每個遊戲的 engine <game> export（例如 engine warthunder export、engine msfs2024 export、engine xplane12 export；每個都接受 --mode、--dry-run、--include-keyboard 和 --nuke-untouched-devices）。復原：engine backups restore。測試：engine\tests\smoke\dcsexportmodes.ps1（每種模式、往返、逐位元組復原）和 engine\tests\smoke\roundtrip.ps1（匯入、clean + nuke、再次匯入後遊戲維持原樣）。
