主要流程

匯入遊戲

顯示：

匯入會讀取遊戲已儲存的控制設定，並把它們轉換成 JoyPro 設定檔：每個功能一個關聯，並附帶它的按鈕或軸。這是最快的入門方式：您在各遊戲中已設定好的一切都會帶進來，從此由 JoyPro 集中保管。

給新手

#點三下完成匯入

  1. 開啟 開始（底部列中的第一個按鈕）。在 您的遊戲 下，JoyPro 在您電腦上找到的每款遊戲都有一張帶圖片的卡片。在您最常玩的遊戲上按 匯入。
  2. JoyPro 會詢問 方式：
    • 加入我的設定檔（建議） 會保留您現有的內容，並加入遊戲的綁定。
    • 從此遊戲重新開始 會用遊戲中的內容取代您的關聯（JoyPro 會先保留一份您設定檔的副本）。
    • 同時取得鍵盤按鍵 也會帶入鍵盤上的飛行指令。裝置綁定一律會取得。
    • DCS 的話：我所有的 DCS 飛機，或取消勾選後選擇飛機。
  3. 按 立即匯入。片刻之後，卡片會顯示「完成：您的設定檔現在有 214 個關聯（180 個已綁定）」，而 查看我的關聯 會開啟它們。若改按 先預覽，則會顯示遊戲中的內容，而不做任何更改。

沒有開啟設定檔？JoyPro 會為您建立一個，並從此自動儲存（沒有「儲存」按鈕：每個變更都會儲存，而且可以復原，重新啟動後也可以）。

#遊戲中會改變什麼？

什麼都不會改變。 匯入只會讀取遊戲的檔案。無論您之後是否匯出，遊戲的綁定都會完全維持原樣。

#匯入，然後讓 JoyPro 填補空缺

在開始頁面上，「設定您的裝置」卡片會列出您自己做過綁定的遊戲。匯入，然後填補空缺 會先匯入這類遊戲。接著 立即填補空缺... 會把重要的功能放到仍然空著的按鈕上。您自己的綁定會保留。對於已在您設定檔中的遊戲，卡片會提供 填補空缺...。

#第一次匯入之前：指令清單

JoyPro 需要知道每款遊戲的指令（它們的名稱和 ID）。它會從您自己的安裝建立一次這份清單。缺少清單時，開始頁面會顯示 建立清單（或 建立所有缺少的清單）；遊戲更新後，遊戲卡片會提供 更新。這需要幾秒到幾分鐘不等（DCS 會讀取每個模組）。

進階

#選項及其作用

選項 預設 效果
加入我的設定檔 / 重新開始 新增 「加入」會合併到目前開啟的設定檔；「重新開始」會在確認並複製一份設定檔後，取代其中的關聯。
同時取得鍵盤按鍵 您上次的選擇 綁定到按鍵的飛行指令也會一併匯入。
同時匯入未連接的裝置 開啟 目前未插上的裝置也會匯入（適合稍後才連接的搖桿）。關閉：會略過並計入數量。
將同名裝置視為同一裝置 開啟 Windows 偶爾會給裝置一個新的 ID；它的舊檔案和新檔案會被視為同一個裝置，歸到已連接的 ID 下。同時插上的兩個相同裝置則會分開處理。
包含預設值（DCS，進階形式） 開啟 DCS 對匯入裝置生效的每個預設綁定都會匯入，讓「匯入後再以取代 + 同時清除匯出」能讓 DCS 維持原樣。同一個輸入上，您自己的綁定優先於預設值。
匯入反向 / 滑桿 / 曲率 / 死區 / 飽和度（進階形式） 關閉 對於不是 JoyPro 自己匯出的綁定，採用 在遊戲中 設定的值。JoyPro 匯出過的綁定不需要這些選項也能取回它的調校。
DCS：忽略 *_easy 飛機 關閉 飛機的簡易模式副本會被排除。

進階匯入（開始頁面的卡片下方，以及進階頁面）為每個遊戲提供所有引擎選項，並有 掃描（預覽）、匯入 和 匯出。每個選擇都會記住，供下次匯入使用。

#名稱、群組和修飾鍵都會回來

遊戲檔案只保存裝置、輸入，也許還有一條曲線。JoyPro 匯出時會在旁邊保存自己的資料，匯入時再把它讀回來：

遊戲 JoyPro 的資料 還原的內容
DCS <aircraft>\joystick\<device>.jp、modifiers.lua 關聯名稱、群組（依順序）、帶名稱的修飾鍵、反向、滑桿、死區、飽和度、曲線
IL-2 Great Battles data\input\jp.actions 名稱、群組、別名、修飾鍵、精確的調校
登錄表中的遊戲（X-Plane、Elite、X4、Arma、MSFS、War Thunder、BMS ...） <config>.joypro-meta.json 名稱、群組、別名、修飾鍵、調校
Star Citizen actionmaps.jp 名稱

以遊戲目前的狀態為準：匯出後您在 DCS 中變更的曲線會保留。JoyPro 從未匯出過的綁定，會以遊戲的動作來命名，並加上群組 DCS、IL2 或 GENERATED + 遊戲名稱。

#兩道防護

  • 尚未匯出的變更。 如果您在 JoyPro 中變更了綁定，但還沒匯出到這個遊戲，匯入會把舊的綁定帶回來。JoyPro 會先詢問。
  • 已經匯入過？ 當設定檔中已有該遊戲時，您之後在遊戲中所做的變更會透過 遊戲監看 進來（遊戲關閉後會詢問）；要再次匯入仍然只需按一下。
在遊戲中: 匯入在各類遊戲中讀取什麼

匯入絕不會寫入遊戲資料夾。它讀取的內容：

  • DCS：每架飛機和每個裝置的綁定、您的修飾鍵，以及在使用「包含預設值」時，DCS 為每個裝置準備的預設綁定。
  • IL-2 Great Battles / Korea：按鍵對應和軸回應。
  • Star Citizen：該分支（LIVE、PTU ...）的按鍵綁定，以及遊戲在 js1 上的 joystick 預設綁定。
  • 有步兵或載具的遊戲（War Thunder、Arma、Reforger、WARDOGS ...）：只讀取飛行動作；其他一切都會被忽略，而不是刪除。
  • MSFS：模擬器的輸入設定檔（Steam 或 Microsoft Store 版本），以及在您要求時，模擬器的預設組合。

遊戲無法區分的裝置（在某些遊戲中，同一型號的兩個裝置）以及半軸綁定（Elite）會被略過，並在結果中列出。

技術細節

#內部如何運作

  1. GUI。 StartImportWizard → RunImportWizardAsync（MainWindowViewModel.GameHub.cs）。它會詢問 AskAboutUnexportedChangesAsync（引擎的 sync pending），確認「重新開始」並保留一份設定檔副本（BackupProfileBeforeChange("before-import")），然後呼叫該遊戲的匯入：ImportDcsAsync、ImportIl2Async、ImportStarCitizenAsync 或 ImportRegistryGameAsync。先預覽 會以 scan 執行相同流程（PreviewImportWizardAsync），並開啟輸出面板。
  2. 引擎。 DCS 的指令為：engine dcs import [--path <Saved Games\DCS>] --merge --include-defaults [--plane <a> --plane <b>] --include-keyboard true|false --ignore-easy-planes false --only-connected false --merge-same-name true。匯入程式會讀取每個裝置檔案，依 DirectInput 執行個體 GUID 和名稱對應裝置，把每個指令 ID 對應到遊戲的指令清單（%LOCALAPPDATA%\JoyPro2\GameData 中的 DB\<game>），並為每個功能和輸入建立一個關聯。載入時的修正（--load-corrections、--correction-mode）會以把握程度分數重新對應已改名的指令 ID。
  3. 設定檔。 關聯會依名稱和相同的輸入合併；修飾鍵依 modifiers.lua（DCS）或遊戲的 Shift 設定建立。設定檔以不可分割的方式儲存，每次儲存都是 <data>\ProfileHistory 中的一個版本（重新啟動後仍可復原）。
  4. 監看程式。 匯入一個沒有同步記錄的遊戲時，會記錄該遊戲的檔案，讓您之後在遊戲中所做的變更能被偵測到（<data>\Sync\<game>.json）。

#讀取的檔案

遊戲 檔案
DCS Saved Games\DCS\Config\Input\<aircraft>\{joystick,keyboard}\*.diff.lua 和 modifiers.lua，加上 JoyPro 根據您的 DCS 安裝建立的乾淨設定檔
IL-2 Great Battles / Korea data\input\*.actions 和軸反應設定
Star Citizen 該分支的 actionmaps.xml
MSFS Steam 遠端資料夾或 Microsoft Store 存檔

GUI 選項對應的引擎選項：加入 --merge、鍵盤 --include-keyboard true、未連接的裝置 --only-connected false、同名 --merge-same-name true、簡易模式飛機 --ignore-easy-planes true。尚未匯出變更的防護是 engine sync pending。

引擎指令：engine dcs import、engine dcs scan、engine il2 import、engine starcitizen import，以及登錄表中每個遊戲的 engine <game> import（例如 engine warthunder import、engine msfs2024 import）。重新匯入規則：重新匯入。測試：engine\tests\smoke\dcsincludedefaults.ps1、engine\tests\smoke\roundtrip.ps1、gui\JoyPro.Gui.Tests\ImportSettingsPersistTests.cs。
