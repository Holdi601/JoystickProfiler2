Alustamine

Esimene käivitus

Näita:

Kui JoyPro esimest korda käivitub, otsib see sinu mänge. Seejärel näitab see neid aknas „Sinu mängud“. Pärast seda küsib tervitus, mida sa teha tahad.

  1. Sinu mängud
    kontrolli loendit
  2. Valmis, ja seadista kõik minu eest
    või Valmis
  3. Kiirseadistus
    või tervitus
Algajatele

#Aken „Sinu mängud“

JoyPro otsib mõni sekund sinu mänge. Seejärel näitab aken iga mängu kohta üht rida.

Mida näed Mida see tähendab Mida saad teha
Märgitud rida kaustaga JoyPro leidis mängu. Mitte midagi. Eemalda märge, kui sa ei taha seda JoyPros.
Märkimata rida JoyPro ei leidnud mängu. Mitte midagi, kui sul seda pole. On see mujal? Märgi see ja vajuta Sirvi....
Juhtimine salvestatud kausta Kus mäng oma juhtimisseadeid hoiab. Vajuta seal Sirvi..., kui sinu omad on mujal, näiteks Saved Games\DCS.openbeta.

Märkimata mäng pole peidetud. Kui selle paigaldad, leiab JoyPro selle.

#Kolm nuppu

Nupp Mis juhtub edasi
Valmis, ja seadista kõik minu eest JoyPro salvestab sinu mängud. Seejärel seadistab see ise sinu juhtkangi, gaasikangi ja pedaalid.
Valmis JoyPro salvestab sinu mängud. Seejärel küsib tervitus, mida sa teha tahad.
Hiljem Midagi ei muutu. Järgmisena tuleb tervitus.

Oled JoyProga uus? Vajuta Valmis, ja seadista kõik minu eest. Seejärel järgi juhendit Kiirstart: pane mu juhtkang tööle.

Tahad suurt teksti ja lühikesi lauseid? Märgi selles aknas Lihtsad sõnad: suur tekst, lühikesed laused.

Akna saad igal ajal uuesti avada: Seaded > Mängud > Käivita häälestus uuesti.

#Tervitus

Pärast nuppu Valmis või Hiljem küsib JoyPro ühe korra: mida sa teha tahad? Sinu mängudele sobiva vastuse märgib see kui soovitatud.

Vastus Mis algab
Mängi ACE COMBAT-i minu juhtkangiga Kiirseadistus ja asenduspult (virtuaalne Xboxi pult).
DCS World või Falcon BMS Ringkäik DCS-i viisil: import, seosed, kõverad, eksport, kontroll.
Pane lihtsalt mu juhtkang tööle Kiirseadistus.
Juhata mind ringi Rahulik ringkäik JoyPros, samm-sammult.
Olen kasutanud JoyPro 1-te Kus iga JoyPro 1 funktsioon nüüd asub. See oskab avada sinu vana profiili.
Ringkäiku pole Mitte midagi.

Vajuta Alusta. Mitte praegu sulgeb tervituse. See ei tule ise tagasi; selle tagasisaamiseks vaata Lihtsad sõnad, ringkäigud ja F1.

#Nuppu Salvesta pole

Sa ei pea kõigepealt profiili tegema. JoyPro teeb selle sinu eest. See salvestab pärast iga muudatust („Salvestatud“ ülemisel ribal). Võta tagasi ja Tee uuesti töötavad, ka pärast taaskäivitust.

Täpsem

#Üksikasjad

  • Mäng mujal (kaasaskantav paigaldus, teine ketas): märgi see ja vajuta Sirvi... välja Paigaldus kõrval või .exe..., et valida mängu programm.
  • Lingitud kausta kontrollitakse kohe: "Marker leitud" või "Markerit ei leitud, kuid kaust jäetakse nii, nagu sa selle valisid". Kasuta tuvastatut unustab lingi.
  • Mängud, mis hoiavad oma juhtseadeid paigalduses (IL-2, IL-2 Korea, IL-2 1946, Falcon BMS, X-Plane, VTOL VR koos BYOJoystickuga), näitavad asukohta ainult lugemiseks; samuti registrimängud (Nuclear Option).
  • Peidetud mängu loetakse kõikjal paigaldamata mänguks (ekspordikaardid, jälgija, filtrid, HUD ...); sinu seosed selle jaoks jäävad profiili. Seaded > Mängud loetleb peidetud mängud koos nupuga Kuva uuesti.
  • Valmis, ja seadista kõik minu eest vastab tervitusele kiire teega: avaneb seadistus ja tervitus selle kõrval ei avane.

#Käsuloendid

JoyPro vajab iga mängu käskude loendit (nende nimesid ja ID-sid). See koostab loendi üks kord sinu paigaldusest. Avaleht näitab teadet nupuga Koosta loend iga mängu kohta või Koosta kõik puuduvad loendid. Pärast mängu värskendust ütleb kaart "Mäng on värskendatud: värskenda selle käsuloendit" koos nupuga Värskenda.

  • DCS koostab selle paigaldatud moodulitega, ilma mänguaknata. IL-2 loeb klahvide vastendusfaile, mida mäng kirjutab. Teised mängud loevad oma faile (käsuloendid värske paigalduse korral).
  • Ctrl+S salvestab profiili kohe. Ajalugu loetleb kõik versioonid.
Tehniline

#Kuidas see seest töötab

  • GUI käivitab alguses ühe engine games installs (pidevat pärimist pole) ja näitab akent üks kord (gameSetupDone failis %APPDATA%\JoyPro2\ui-settings.json). Vaatemudel: MainWindowViewModel.GameSetup.cs, aken Views/GameSetupWindow.axaml.
  • Valmis kirjutab kõik mootori kaudu: engine games install set / clear, engine games config set / clear, engine games install disable / enable, seejärel tuvastab uuesti.
  • Lingitud kausta markerfailid: bin\DCS.exe, bin\game\Il-2.exe, X4.exe ...
  • Tuvastamine mängu kohta (engine\GameInstalls.cs ja iga GameIntegration): Steami teekide kaustad ja rakenduste ID-d, tuntud paigalduskohad, Windowsi desinstallimis- ja rakenduste loendid ning kasutaja enda link, mida tuvastamine kunagi ei asenda.
  • Käsuloendid: engine db check-updates teatab loendita mängu kohta no-catalog; koostamine käivitab mängu refresh-db (engine dcs refresh id + engine dcs refresh clean DCS-i jaoks, engine db refresh-il2, engine db refresh-starcitizen, engine <game> refresh-db) ja kirjutab ainult kausta %LOCALAPPDATA%\JoyPro2\GameData.
