# JoyPro 2.2.7

Microsoft Flight Simulator 2024 exports that reach the sim, a complete command list, and a support file for problem
reports.

## New
- **Support file:** Settings > Report a problem > "Create support file" saves one zip with JoyPro's logs, a summary
  of your system, games and devices, and JoyPro's copies of the game files it read or wrote. JoyPro shows what is in
  it before saving; nothing is uploaded. Send it along with a problem report.
- Microsoft Flight Simulator 2024: every export also writes an import file per device and category into
  Documents\JoyPro\MSFS 2024 import files. Load it in the sim (Controls > your device > category > cogwheel > Import)
  for aircraft the sim has already set up; the Export page shows the steps and opens the folder.

## Fixed
- Microsoft Flight Simulator 2024: the relation editor offers every action of the sim's Controls menu (for example
  all ATC panel choices), not only the ones you had bound.
- "Arm Auto Throttle" no longer shows up as an ATC request.
- The game watcher notices changes made in Microsoft Flight Simulator 2024 again.
- Importing into a profile made with an earlier version keeps your relations and their names (no duplicates).

## Changed
- More detailed logs for imports, exports and the game watcher.
