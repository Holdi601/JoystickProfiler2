# JoyPro 2.7.2

## New
- **Copy detent mode to another axis.** The detent section has **Copy detent mode to another axis...**: Thrust Left
  gets the same detent mode as Thrust Right in one step (on/off, what aircraft without afterburner get, your own
  afterburner values per aircraft; Ctrl+Z undoes it). The other lever can borrow this lever's calibration until you
  calibrate it. The curve's **Copy to another axis...** stays off while detent mode makes the curve shown; its tooltip
  now points to the new button.
- **The curve shows where the afterburner starts.** When detent mode bends the curve shown, the graph marks your
  device's detent (dashed line) and the afterburner range of the game's throttle (orange band).
- **Move to...: press the button they go to.** In **Move N action(s) to...** press **Press the button they go to**,
  then the button (or axis) on your device: the relation on it is picked, no typing.
- **No afterburner per aircraft group.** A detent group has a **No afterburner** button: those aircraft get full power
  (or full collective) at your detent.

## Fixed
- **Falcon BMS 4.38.2: export and import work again, per aircraft.** The new BMS launcher (3.x) keeps your binds in
  `User\Config\JSON`, one file per device and aircraft (F-16, F-15ABCD), and rebuilds the older files from them every
  time it closes or launches. JoyPro still wrote those older files, so the launcher replaced JoyPro's binds, and the
  watcher then offered the emptied files as "the game's changes". JoyPro now reads and writes the JSON files: buttons go
  into each aircraft whose key file has the command (an F-15 command only into the F-15), axes into every aircraft of
  the device, backups first, and the watcher follows the JSON files. Hat binds, the shifted layer and throttle detents
  are not written into the new files yet; the export lists them so you can set them in the BMS launcher. Older BMS
  versions work as before.
- **The watcher no longer empties your profile in passing.** When taking over a game's changes would remove many
  binds (more than 10, or more than a fifth of that game's binds), JoyPro now says how many, warns that the game or
  its launcher may have rewritten its files (as the Falcon BMS 4.38.2 launcher does, or an update), and makes
  **Keep my JoyPro binds** the default button. Taking over is still possible with **Take over anyway**.
- **Helicopters in detent mode.** DCS helicopters (AH-64D, Ka-50, Mi-8, Mi-24, UH-1H, Gazelle, CH-47F, OH-58D) and the
  A-4E, L-39ZA, C-130J and Yak-52 were unknown to detent mode, so "Aircraft without afterburner: full power at the
  detent" did nothing for them. They now get full collective / power at the detent. When an own DCS curve of the
  relation keeps detent mode off, the group now says how to hand it back (**Use the default curve again**).
- **Detent mode and the dead zone.** A dead zone on the default curve stays a real dead zone at the idle end of the
  travel (it was only approximated by DCS's user curve), and with a calibrated idle cut-off a dead zone of a few percent
  no longer makes DCS drop the bend entirely ("cannot express the detent curve"). Resting in the idle detent now always
  gives the aircraft's idle, never the cut-off, and the DCS curves follow the wanted one more closely (for example
  0.4 % instead of 2.2 % for the F/A-18C on a throttle with an idle cut-off).
