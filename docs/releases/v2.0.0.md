# JoyPro 2.0.0

The first public version of JoyPro 2: one profile for all your devices, in every flight and space game. JoyPro 2 is
the successor of JoystickProfiler (JoyPro 1) with the same idea, relations and binds, and a completely new app.

## Highlights

- **One profile, many games.** A relation is one function ("Gear Up/Down", "Pitch") that links the matching command
  of every game and aircraft. Bind it once; the export writes it into each game's own control files.
- **Many games.** 36 titles are handled by JoyPro, each version separately: DCS World, IL-2 Sturmovik (Great Battles
  and Korea), War Thunder, Microsoft Flight Simulator 2020 and 2024, X-Plane 12, Falcon BMS, Star Citizen, Elite
  Dangerous, Nuclear Option and more (several of them marked experimental). Start page > *Supported games* shows what
  JoyPro does for each one.
- **Built from your own installation.** JoyPro ships no game data: it builds each game's command list on your PC.
- **Safe export.** Every export makes a backup first and can be undone per game. Export modes: keep the game's binds,
  let your profile win, only add, or replace everything on your devices.
- **Import** the binds you already made in a game; re-import keeps JoyPro's names, groups, modifiers and tuning.
- **Setup help.** A first-start wizard, Auto Group (sorts every action of your games into relations), Auto Assign
  (puts your relations on the best controls of your devices, any combination of devices), suggestions for what is
  missing, and a search across all games.
- **Binds and modifiers.** Record a bind by pressing the button or moving the axis; modifier buttons give your other
  buttons a second meaning.
- **Axis tuning.** Curves, dead zones and saturation for all games, per game, per family or per DCS aircraft, written
  in each game's own response model; detent mode for throttles with an afterburner gate.
- **Device pictures and cheat sheets.** Layout pages with a picture of your exact device model, printable cheat
  sheets per game and aircraft, and an in-game HUD that shows what the pressed button does.
- **Cockpits.** A cockpit reference for 236 aircraft with HOTAS tables and panels; pictures of the real cockpits can
  be made from your DCS World and X-Plane 12 installation.
- **Game config watcher.** When you change controls in a game, JoyPro notices and offers to take the change over.
- **Virtual joystick and force feedback.** Optional vJoy forwarding (with HidHide) or a virtual Xbox pad for games
  that read too few devices, virtual functions (macros, long press, turbo), and force feedback from game telemetry.
- **38 languages** besides English, including all EU languages, Japanese, Korean and Chinese (Simplified and
  Traditional). JoyPro follows the Windows language; Settings > Language picks another one.
- **Updates.** JoyPro checks GitHub Releases for a newer version, shows what changed, checks the download's checksum
  and installs it on request. Profiles and settings stay.
- **Privacy.** No account, no telemetry. JoyPro goes online only for update checks, game covers missing on this PC
  (can be switched off) and the downloads you agree to (device photos, the optional AI model and drivers).

## Install

Download `JoyPro2-2.0.0-win-x64.zip`, check it against `JoyPro2-2.0.0-win-x64.zip.sha256` if you like, unpack it
into a folder of your choice and start `JoyPro.Gui.exe`. Windows 10 or 11 (64-bit). The .NET runtime is included;
the engine needs .NET Framework 4.8, which Windows has (JoyPro offers Microsoft's installer if it is missing).
