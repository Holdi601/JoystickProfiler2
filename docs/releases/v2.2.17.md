# JoyPro 2.2.17

## New
- **Several views of a device on one page** (Layout): add pictures of the same device from different angles, move
  and scale them on a page (A4 or Letter, portrait or landscape; 16:9, 21:9, 32:9). The cheat sheets print the page.
- **Reset to default** (Layout): put a device's picture, markers and drawing back to JoyPro's; Settings > Drawings
  resets all your layout changes. Both ask first and can be undone.
- **Duplicate** in the relation editor: a copy of the open relation ("<name> (copy)"), one undo step.
- **Model menu** on every Layout device: choose another model, "This is not my device", or undo the last choice.
- Pictures for the WinCtrl CarrierAce MFD C and the Razer Tartarus V2.

## Fixed
- The function shown under a relation's name ("Function: ...") appears only when it really covers the relation;
  relations that keep a button position with a different function per aircraft say so, and suggestions no longer
  assume one function for them. Click it to set or clear the function.
- DCS actions with a raw command name as title (Spitfire, Bf 109, Mosquito, P-47, Yak-52, CH-47F, ...) show a readable
  name; titles of modules added after the start no longer stay as raw ids.
- Searching the catalog (for example "flaps") finds every matching action, also when there are many; aircraft names
  count in the search.
- Every hat shows its press on the Layout page (the ViperAce trim hat press is button 19); a bound input without a
  place on the picture is listed under "Other controls".
- The Layout device list keeps the swap button away from the "Reference picture" chip.
