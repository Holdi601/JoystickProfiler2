# JoyPro 2.2.4

A fix release for Microsoft Flight Simulator.

## Fixed
- Microsoft Flight Simulator 2024: import now also brings in the devices you never changed in the sim's Controls
  menu (for example rudder pedals on their factory preset). For a connected device without a profile of your own,
  JoyPro reads the default preset the sim uses for it and says so in the import notes.
