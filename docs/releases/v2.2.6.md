# JoyPro 2.2.6

A fix release for Microsoft Flight Simulator 2024 and imported relation names.

## Fixed
- Microsoft Flight Simulator 2024: import no longer creates relations for devices that are not set up in the sim (for
  example MFD panels). JoyPro takes a device's default preset only when the sim uses it for every aircraft it knows.
- Microsoft Flight Simulator 2024 (Microsoft Store version): JoyPro's presets that the sim could not read are made
  again at the next export, and import reads JoyPro's own copy of them meanwhile.
- No more warning about several profiles of a device that is not connected.

## Changed
- Imported relations are named after the action ("Arm Auto Throttle") instead of starting with the game's name. The
  game is added in brackets only when a relation of another game already has that name.
