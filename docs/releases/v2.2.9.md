# JoyPro 2.2.9

Microsoft Flight Simulator 2024: your binds go straight into the profiles the sim uses.

## New
- **Write into my MSFS profiles** (on by default): an export to MSFS 2024 updates the profile the sim uses for each
  device and category, in the Microsoft Store and the Steam version, so no import in the sim is needed. JoyPro writes
  only while the sim is closed, backs up the whole save first (Export > Game config backups restores it) and checks
  what it wrote. The export shows per device which profile was updated, and names every bind it could not write.
- The import files are now optional ("import files for every device"). A file carries the name of your active
  profile, so the sim's Import offers to overwrite it instead of adding a second profile.

## Fixed
- A bind removed in the sim no longer comes back on import, and the game watcher now asks about it after the sim
  closes. Binds you add in the sim are offered the same way.
- Import reads only the binds the sim really uses: JoyPro's own presets no longer add binds for devices that have a
  profile of their own.
- Every bind goes into the right category profile (for example Active Pause into General).
- Relations of MSFS 2024 no longer show "1 aircraft"; they apply to every aircraft.
