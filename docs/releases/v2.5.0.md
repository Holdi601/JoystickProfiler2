# JoyPro 2.5.0

## New
- **The export replaces the binds on your devices by default** ("Replace on my devices" with "Also clear my other
  devices"), like JoyPro 1. It touches only the aircraft you export; your keyboard keeps its default keys. A mode you
  picked yourself before stays.
- **The export modes work the same in every game:**
  - "Only add" never removes or changes a bind of the game. A bind whose button the game already uses for something
    else is not written; the relation shows a warning and the Check offers to export with "Update", move it to another
    button, or keep it. The warning goes away by itself once the bind reaches the game.
  - "Update, keep the game's binds" writes your binds and removes only a game bind on a button you give another
    action. An action you moved keeps its old button too.
  - "Update, my profile wins" does the same and also takes your actions off their other buttons in that aircraft, so a
    moved action really moves.
  - Both "Update" modes no longer remove binds only because JoyPro wrote them once.
- The first export to a game this profile never imported from asks once: **Import first** or export anyway. A backup
  is made either way, and "Undo export" brings every file back.
- **DCS:** the import takes every default bind that is active in the game for your devices, also DCS's general joystick
  defaults and the defaults of a connected device without a file yet. "Include defaults" is on by default. The files
  JoyPro writes hold only real differences from DCS's defaults; a default with changed curve, dead zone, saturation or
  invert is written the way DCS writes it.
- **vJoy** devices are imported and exported like any other device. Settings names the one vJoy device JoyPro uses
  itself; only that one is left out.
- Game paths and the list of ignored devices belong to the PC, not to the profile; a profile can keep its own. A path
  you typed is never replaced by the detected one.
- The import says once per game that changes made in the game come in through "Watch for changes", with a button to
  turn watching on.
- **The Check speaks plain words.** Every card says what is wrong with the aircraft, buttons and commands as the game
  names them, what happens in the game, and what to click: the two buttons with their relations, one sentence, a short
  table of aircraft and commands, what caused it (the history entry, for example "Manage with AI" on 21 Oct), one
  recommended fix, "Keep only on ..." / "Keep both" / "More".
- Errors get fixes like the warnings and their own red icon: "One button does two things" (keep one, keep both, move
  one to another button, switch off) and "One button runs two commands" (keep one command, keep both).
- Each card has its own "Open '<relation>'" per relation: the relation opens with exactly the commands and aircraft of
  the card marked and scrolled into view; Back returns to the card.
- A command the game's list no longer has is shown with its stored name and where it is, with "Remove" and "Find
  similar".
- **HUD:** each stick element can take X, Y and twist from any device's axis. *Automatic* takes them from the base a
  grip sits on (buttons from the grip, axes from the base).

## Changed
- Opening a profile removes actions of a relation that have no aircraft ticked (one undo step, logged). Suggestions you
  dismissed stay dismissed; relations without a bind always stay.
- A hidden game is hidden everywhere: also in the game filters of the Relations and Binds pages, the catalog, the
  action search, the suggestions and the HUD. Settings > Games is the one place that shows it again.
- Problem reports go to Documents\JoyPro2\Problem Reports. Reports in the old folder move there once.
- The support file also holds your JoyPro 1 profiles (Documents\JoyPro) when you include your profile.
- The Export page lists the export modes as a clear list of choices, one per line.

## Fixed
- Import your binds from a game and export them again with "Replace on my devices": the game now keeps exactly what it
  had, in every game. IL-2 lost its mouse binds, its Enter key binds and the invert and dead zones of its axes, and a
  throttle set to one side came back centred. Star Citizen switched off the game's own joystick binds and could put
  another stick on js1. Elite Dangerous and Nuclear Option cleared the binds of a device that was not plugged in. MSFS
  lost its menu and map binds.
- An export never clears a device that is not plugged in, a device on the import's ignore list, mouse binds or binds
  JoyPro cannot read, in any game and any mode. An export no longer changes the keyboard files of aircraft it does not
  export.
- In games with infantry, ground vehicles or menus (Star Citizen, War Thunder, Arma, Arma Reforger, Wardogs, Hell Let
  Loose, Battlefield) every export mode changes only the flight binds.
- Keys spelled the JoyPro 1 way (LeftAlt) and the DCS way (LAlt) are the same key. Two modifiers on the same key become
  one, and your binds stay.
- IL-2: a key shared with a DCS action in one relation (for example Left Alt) is written correctly.
- The right-click menu of an action in a relation ("Move to another button..." and the others) opens on the whole card,
  not only on its title line. The same on the Binds page.
- Layout page: a picture you pick ("Photo 4 · Virpil", "Top · Razer", a drawing) is kept at once and no longer falls
  back to JoyPro's line drawing. The markers belong to that picture, and the line above the device list names the model
  and the picture instead of "Placeholder ... (match 30%)".
- The marker assistant sits in the corner of the picture instead of over its middle, and you can drag it.
- The Engine Output panel is no longer squeezed: drag the bar above it. JoyPro keeps the height.
- HUD: a grip without its own X/Y (for example a VKB grip on a VPforce Rhino base) no longer puts the stick element in
  a corner; a missing axis stays in the middle. The HUD costs the game nothing: only what changed is drawn again.
- An action title shown twice in a row ("Display Select Switch - LEFT [VSD Page]Display Select Switch - LEFT [VSD
  Page]") is shown once everywhere.
- Aircraft with the seat in their name no longer show it twice ("F-15E Strike Eagle (Pilot)").
- The Check's "Open both relations" opened only the first relation.
