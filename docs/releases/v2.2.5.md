# JoyPro 2.2.5

A fix release for Microsoft Flight Simulator 2024.

## Fixed
- Import no longer creates relations for devices that have a default preset in the sim but no binds in it (for
  example MFD panels). JoyPro now takes a device's default preset only when the sim really uses it for that device.

## Changed
- Import: a new option "Also import default presets the sim may not use" brings in a device's default preset when
  JoyPro cannot tell whether the sim uses it. The import notes name these devices.
