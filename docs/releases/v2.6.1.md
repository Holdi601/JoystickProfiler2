# JoyPro 2.6.1

## New
- **Check: ignore a warning, and the list of ignored ones.** "Same command on two buttons", "One button does two
  things" and "One button runs two commands" have **Ignore** (it replaces "Keep both", which was the wrong word for
  three or more buttons): the binds stay as they are and the card goes away. When the command lands on one more button
  later, the card comes back by itself, marked new, with "Shown again: now also on ..." - so you can work through the
  warnings once and then only see the new ones. **Ignored warnings (n)** next to the search lists everything you
  ignored in the cards' words, with **Show again** for each and **Show all again**. Every step is one Ctrl+Z.
- **Add actions:** the list has two parts: *Name has every word* (the action's title has every word you typed) and,
  below it, *Same meaning* (found by what the action does: the same function, a synonym or a description), each with
  its count. Actions already in the open relation stay greyed at the very bottom.

## Fixed
- **DCS: commands that mods add are in the command list.** Commands that DCS mods add (for example the Input Command
  Injector with a community keybinds pack, or modules in Saved Games\DCS\Mods) are now in the command list, with the
  same ids DCS gives them, so a relation no longer says "not in its list" for a command DCS shows. JoyPro reads the
  Saved Games folder your DCS installation really uses (DCS.openbeta for an OpenBeta installation). When your mods
  change, the Start page says "Your DCS mods changed the controls list; rebuild the command list": press **Refresh
  DB** once. A command that is in your DCS bind files but not yet in the list is known anyway and marked "from your
  DCS files".
- **Add actions search:** when something matches all of several words, actions that match only some of them are left
  out. "master reset" in the F-14 lists only "MASTER RESET" and "Master Caution Reset" and is understood as the master
  caution reset; before, it also listed every exterior lights master and master arm switch by the word "master". A
  single word ("master" still finds all 35 titles with it in the F-14, "reset" still finds "MASTER RESET") and a
  sentence that nothing matches completely ("make the plane go faster") find everything that means it, as before.
- **Add actions:** titles with every word you typed stay above the actions that only mean the same in every sort and
  grouping (Sort: Game and the other sort levels, By function, the game chips, Show more). With Sort: Game, a game's
  actions used to be sorted by title only, which put "Exterior Lights Master Switch" and "Master arm" above "MASTER
  RESET" for "master reset".
