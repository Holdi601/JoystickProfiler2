# JoyPro 2.2.2

A fix release for Microsoft Flight Simulator and follow input.

## Fixed
- Microsoft Flight Simulator 2024 (Microsoft Store version): exporting could fail with "The APPX file can not be
  accessed". The next export repairs JoyPro's presets.
- Microsoft Flight Simulator 2020 and 2024: import now brings in every bind of your devices, including the general
  ones (camera and cockpit views, zoom, active pause and so on), and export writes them back. In MSFS 2024 they go
  into a preset of the General category.
- Microsoft Flight Simulator: import no longer adds old devices that are not connected any more (the sim keeps a
  profile of every device it has ever seen). JoyPro lists the devices it left out; tick "Also import devices that are
  not connected" to bring them in.
- An input bound to two actions with a different invert setting now becomes two relations, so the export keeps each
  action's own invert.

## Changed
- Follow input: the note over the list after a jump is now off by default; the list only selects the relation.
  Switch the note back on in Settings > Binds.
