# JoyPro 2.2.1

A fix release for tooltips and follow input.

## Fixed
- Tooltips no longer pop up instantly after a key press, button press or axis movement. They appear only after you
  move the mouse and rest it on an item, and only while JoyPro is the active window.
- Analog keyboards (for example Wooting) no longer make the lists jump while you type through their extra axis
  inputs. Their keys still jump to the relations they are bound to.

## Changed
- Follow input acts only while JoyPro is the active window and never while you type in a text box.
- Settings > Binds: the note over the list after a jump can be hidden.
- Settings > Devices: a keyboard's axes can be switched on for follow input and recording.
