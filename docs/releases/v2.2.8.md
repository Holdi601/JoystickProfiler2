# JoyPro 2.2.8

A small follow-up for the Microsoft Flight Simulator 2024 import files.

## Changed
- The MSFS 2024 import files are now in Documents\JoyPro2\MSFS 2024 import files, next to your JoyPro 2 profiles
  (files from 2.2.7 move there at the next export).
- The export lists which import files are new or changed, so you only import those again in the sim.

## Fixed
- The import steps name the right menu: the cogwheel of the device's profile, not the preset's.
