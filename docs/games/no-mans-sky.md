# No Man's Sky (Hello Games)

Status: **not installed here; not integrated.** Best route: **virtual Xbox pad** (ViGEm).

- **No flight-stick support.** Not added with the later updates either: a Thrustmaster stick is not detected (WEB,
  2023/2024 tests and forum).
- **Input:**
  - keyboard/mouse;
  - controllers through Steam Input action sets ("In Flight"; Options > Controls > "Remap via Steam Input");
  - native XInput as well.
- **Binds:**
  - keyboard: `<install>\Binaries\SETTINGS\TKGAMESETTINGS.MXML` (XML text);
  - pad: Steam Input configurations, which Steam manages. JoyPro does not write those.
- No anti-cheat.

**JoyPro:**
- `engine vjoy mode` with the Xbox pad gives the HOTAS two sticks and two triggers. The game's default pad layout
  applies.
- A real throttle axis cannot be kept: the triggers are thrust and brake.
- An integration would only add a catalog of the pad layout (no file to write).
