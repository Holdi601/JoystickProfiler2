**Every joystick, throttle, pedal, button box and game controller that Windows sees works with JoyPro**, also when it is
not in this list. JoyPro reads all of them the same way: you press a button, JoyPro sees it.

The list below is JoyPro's device catalog. For a device in it, JoyPro also knows:

- what the device is (stick, throttle, pedals ...), so **Set it all up for me** can plan which hand does what;
- often a picture with the buttons marked, so the Layout page shows your binds on the device;
- the names of its buttons ("Trigger", "TMS up") instead of "Button 3".

A device that is not in the list still works for binding, import and export. JoyPro asks you once what it is (stick,
throttle, pedals ...), and the Layout page draws a plain picture for it.

:::tip My device is missing
Tell us on the [Discord](https://discord.gg/yK4gQA9xgk) or in a GitHub issue. The **support file** (Settings > Help)
lists your devices with their USB ids; that is all we need to add one.
:::

## The catalog

"USB id" is the number pair Windows reports for the device (vendor and product). "By name" means JoyPro recognises the
device by the name Windows shows. "Buttons marked" means JoyPro has a picture of this model with every button marked.
