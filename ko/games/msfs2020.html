Microsoft Flight Simulator 2020

표시:

MSFS 2020은 장치마다 조작 프로필을 하나씩 보관하며, 이 프로필을 모든 기체에서 사용합니다. Steam 버전에서는 각 프로필이 시뮬레이터의 Steam remote 폴더에 있는 작은 XML 파일입니다. JoyPro는 이 파일을 프로필로 읽어 오고, 바인딩을 그 자리에서 다시 씁니다. Microsoft Store 버전의 프로필은 가져오기만 하고 쓰지는 않습니다. MSFS 2024와 달리 프리셋 패키지, 가져오기 파일, 기체별 프로필이 없습니다.

#3단계로 바로 사용하기

  1. 모두 알아서 설정
    시작 페이지에서
  2. 이 버튼 사용
    먼저 목록을 확인
  3. 내 게임에 쓰기
    시뮬레이터는 닫아 둔 채로

먼저: 시뮬레이터(Settings > Controls)에서 장치마다 프로필을 한 번 만드세요. JoyPro는 Steam 버전에만 씁니다. Microsoft Store 버전은 가져오기만 할 수 있습니다.

그다음: 시뮬레이터를 시작하세요. 모든 기체에서 바인딩이 Settings > Controls에 들어가 있습니다.

전에 MSFS 2020에서 버튼을 바인딩한 적이 있나요? 그러면 시작 페이지에 가져온 후 빈 곳 채우기가 나타납니다. 기존 바인딩은 그대로 두고, 비어 있는 버튼에만 새 역할이 주어집니다. 빠른 시작: 내 스틱 작동시키기를 참조하세요.

#JoyPro가 MSFS 2020에서 하는 일

  • 가져오기: 연결된 각 장치(Steam 또는 Microsoft Store)의 프로필이 프로필로 들어옵니다. 비행 바인딩, General 바인딩(카메라, 시점, 일시 정지), Sensitivity 페이지의 축 설정이 포함됩니다.
  • 관계: 관계 하나는 하나의 기능입니다. MSFS 2020에는 장치마다 프로필이 하나씩이므로, 관계는 모든 기체에 적용됩니다.
  • 내보내기: JoyPro는 Steam 버전의 remote 폴더에 있는 장치 프로필을 편집합니다. 시뮬레이터는 다음 시작 때 이를 읽습니다.

#MSFS 2020 바인딩 가져오기

  1. 시작을 열고 Microsoft Flight Simulator 2020 카드에서 가져오기를 누르세요.
  2. 연결되지 않은 장치도 가져오기(꺼짐): MSFS는 지금까지 인식한 모든 장치의 프로필을 보관합니다. 꺼 두면 지금 연결된 장치만 가져옵니다. 시뮬레이터가 사용하지 않을 수도 있는 기본 프리셋도 가져오기(꺼짐)를 켜면, 자체 프로필이 없는 장치에 대해 시뮬레이터가 제공하는 프리셋을 추가합니다. 시뮬레이터가 그 프리셋을 쓰는지 알 수 없는 경우에도 추가합니다.
  3. 지금 가져오기를 누르거나, 프로필을 바꾸지 않고 시뮬레이터에 있는 것을 보려면 먼저 확인을 누르세요.

#관계 만들기와 확인

모든 게임과 마찬가지로 관계 페이지에서 관계를 만든 다음(관계 흐름 참조), 내보내기 페이지에서 확인을 실행하세요. 여기서는 비행기의 스로틀과 헬기의 콜렉티브가 같은 축에 있어도 확인 기능이 오류로 보고하지 않습니다. MSFS 2020에는 기체 목록이 따로 없기 때문입니다.

#MSFS 2020으로 내보내기

  1. MSFS 2020을 닫으세요. 시뮬레이터가 실행 중이면 JoyPro는 쓰기를 거부합니다.
  2. 내보내기를 열고, JoyPro에서 장치를 설정한다면 내 장치에서 교체와 다른 장치도 지우기를 그대로 둔 채 MSFS 2020 카드의 지금 내보내기를 누르세요.
  3. 시뮬레이터를 시작하세요. remote 폴더는 Steam Cloud 폴더이므로 Steam이 바뀐 파일을 동기화합니다.
게임에서: MSFS 2020에서 보이는 것

Settings > Controls를 열고 장치를 고르세요. 바인딩이 장치 프로필의 시뮬레이터 동작 이름 아래에 들어가 있고, 장치의 Sensitivity 페이지에는 JoyPro가 쓴 축 곡선이 표시됩니다. 모든 기체에서 같은 프로필을 사용합니다.

#MSFS 2020에서 직접 해야 할 일

  • 시뮬레이터에서 장치마다 프로필을 한 번 만드세요(Settings > Controls). JoyPro는 기존 프로필만 편집합니다. 프로필이 없는 장치에 대해서는 내보내기가 "먼저 시뮬레이터에서 만드세요"라고 알려 줍니다.
  • Microsoft Store 버전: JoyPro는 프로필을 가져오지만 쓸 수는 없습니다. 내보내기에는 Steam 버전을 쓰거나, 시뮬레이터에서 바인딩을 설정하세요.
  • 기체로 제한된 관계: MSFS 2020은 이를 구분해서 보관할 수 없습니다. 시작 페이지의 다른 게임 양식에서 내보낼 기체를 쓰면 기체 하나로 제한된 관계도 모든 기체에 내보냅니다.

#자주 하는 실수

  • "MSFS 2020 실행 중입니다": 시뮬레이터를 닫고 다시 내보내세요.
  • 시뮬레이터에 예전 바인딩이 보임: Steam Cloud가 예전 사본을 되돌렸습니다. 시뮬레이터를 닫고 다시 내보내세요.
  • 장치에 프로필이 여러 개 있음: JoyPro는 다른 게임 양식의 게임 프로필에서 고른 프로필이나 하나뿐인 프로필을 사용합니다. 그렇지 않으면 이름 목록을 담은 경고와 함께 그 장치를 건너뜁니다.
  • 바인딩이 빠짐: 동작 하나에는 입력 조합을 최대 두 개(Primary와 Secondary)까지 보관합니다. 세 번째는 보고되고 제외됩니다.

#JoyPro가 읽고 쓰는 파일

파일 설명
<Steam>\userdata\<id>\1250410\remote\inputprofile_<n> 장치 프로필 하나. 확장자 없는 XML. 제자리에 씀(먼저 .jpbak 백업)
<Steam>\userdata\<id>\1250410\remote\profile_00 장치 프로필에 대한 시뮬레이터의 바이너리 색인: 읽기만 함, 절대 쓰지 않음
%LOCALAPPDATA%\Packages\Microsoft.FlightSimulator_8wekyb3d8bbwe\SystemAppData\wgs\<user>\ Microsoft Store판 세이브: 읽기만 함(가져오기와 스캔)
<install>\Input\*.xml, fs-base\en-US.locPak 시뮬레이터에 들어 있는 프리셋과 메뉴 이름: 읽기만 함
%LOCALAPPDATA%\JoyPro2\Ownership\MSFS, ...\Backups\MSFS JoyPro의 소유 데이터와 백업. Steam 폴더에는 절대 두지 않음

Steam remote 폴더는 Steam Cloud 폴더입니다. 이미 있는 inputprofile_* 파일만 편집합니다. 시뮬레이터의 profile_00이 특정 파일을 지정하므로, 새 파일은 인식되지 않습니다.

#MSFS 2020의 내보내기 모드

모드 장치 프로필에서 일어나는 일
추가만 바인딩은 프로필에서 그 입력 조합에 다른 동작이 없는 곳에만 쓰입니다. 그렇지 않으면 "기록되지 않은 바인딩, 게임에서 버튼이 사용 중" 아래에 표시됩니다. 아무것도 제거되지 않습니다.
업데이트, 게임의 바인딩 유지 사용자의 조합에 있던 다른 동작은 그 조합을 잃습니다. 나머지는 모두 남으며, 동작의 예전 조합도 남습니다.
업데이트, 내 프로필 우선 위와 같고, 바인딩한 모든 동작은 연결된 장치의 프로필에서 다른 조합을 잃습니다.
내 장치에서 교체 JoyPro가 바인딩하는 연결된 장치의 프로필에는 사용자의 바인딩만 남습니다.
+ 다른 장치도 지우기 프로필에 바인딩이 없는 연결된 장치의 프로필은 비워집니다.

#절대 건드리지 않는 것

  • 메뉴, 월드 맵, 개발자 컨텍스트(MENU, MENU_*, WORLDMAP_*, DEBUG, DEVMODE*, EDITOR_*, MISSION_FLOW_TOOLS). 모든 모드에서.
  • 키보드, 마우스, 게임패드 프로필(GUID="{0}"): MSFS에서는 키보드 바인딩을 쓰지 않습니다.
  • 연결되지 않은 장치의 프로필, profile_00, Store판 세이브, 가져오기에서 무시한 장치, JoyPro가 입력을 보내는 vJoy 장치.

#곡선과 그 밖의 것

  • 단위: 장치마다 프로필 하나, 모든 기체 공통.
  • 축 곡선: 장치의 Sensitivity 페이지. 물리 축마다 한 세트: Sensitivity +와 -, Neutral, Dead zone, Extremity dead zone, Reactivity, 곡선 없음 플래그, 반전. MSFS 2020에는 동작별 재정의가 없으므로, 재정의를 요구하는 관계(릴레이션)는 장치 페이지에 들어가고 경고가 붙습니다. 곡선 미리 보기는 시뮬레이터와 일치합니다(MSFS 2020에서 측정). 튜닝 범위 family:msfs는 두 시뮬레이터를 모두 포함합니다. axis-curves를 참고하세요.
  • 포스 피드백: MSFS에는 자체 포스 피드백이 없습니다.
  • 텔레메트리 기록: SimConnect를 통해 읽기만 하며, 시뮬레이터 설치 폴더의 SimConnect.dll(또는 MSFS SDK의 것)을 씁니다. JoyPro에는 들어 있지 않습니다.
  • HUD: HUD는 프로세스(FlightSimulator)로 시뮬레이터를 찾아 바인딩을 보여 줍니다.
  • 감시 기능: JoyPro는 inputprofile_* 파일과 Store판 세이브의 containers.index를 감시하고, 시뮬레이터가 닫힌 뒤 묻습니다(감시 기능).

#MSFS 2020 연동의 내부

코드: engine\Games\MsfsIntegration.cs(두 시뮬레이터에 클래스 하나, sim == 2020), MsfsProfileFile.cs(줄 단위 편집기), MsfsUserProfiles.cs(Steam과 Store 읽기), MsfsSimDefaults.cs, MsfsGameData.cs, MsfsAircraft.cs, engine\AxisModels\Msfs.cs.

  • 형식: XML 조각(fragment 적합성으로 읽음): <Version>, <FriendlyName>, <Device DeviceName GUID ProductID>, <Axis AxisName AxisSensitivy AxisDeadZone ...>가 있는 <Axes>(철자가 틀린 속성 이름은 시뮬레이터의 것), <Context ContextName> / <Action ActionName Flag> / <Primary> / <Secondary> / <KEY Information>code</KEY>. 풀린 동작은 제거됩니다. 새 동작은 폴더의 다른 프로필에서 그 동작이 속한 컨텍스트에, 없으면 목록의 컨텍스트에, 그것도 없으면 PLANE에 들어갑니다(경고와 함께).
  • 장치: GUID는 DirectInput 인스턴스 GUID이므로, 읽을 때 장치가 연결되어 있지 않아도 됩니다. ProductID는 10진수 USB product ID입니다. 코드: 버튼 N = N-1, 햇 256-259, 축 1026/1042/1058, 770/786/802, 슬라이더 514/530. 조합의 마지막 KEY가 주 입력이고, 같은 장치의 다른 버튼은 수정키입니다.
  • 명령 목록: engine msfs2020 refresh-db는 시뮬레이터의 프리셋(<install>\Input, 공식 패키지)과 en-US.locPak에 이름이 있는 모든 비행 이벤트를 읽습니다. 처음 부분은 MSFS 2024의 목록과 공유합니다.
  • 명령: engine msfs2020 paths, engine msfs2020 catalog, engine msfs2020 scan, engine msfs2020 import(--game-profile, --include-disconnected, --include-sim-defaults), engine msfs2020 export(--mode, --nuke-untouched-devices, --dry-run, --aircraft <key>). 실행 취소는 engine backups restore로.
  • 예전 프로필: JoyPro에 MSFS 게임이 하나뿐이던 때 저장한 프로필(MSFS:<action>)은 불러올 때 시뮬레이터마다 노드를 하나씩 받습니다.

#알려진 한계

  • Microsoft Store판은 읽기만 합니다. 그 세이브 폴더를 경로로 한 내보내기는 거부됩니다.
  • 새 inputprofile_* 파일은 만들지 않습니다. 장치에는 시뮬레이터에서 만든 프로필이 있어야 합니다.
  • Steam Cloud가 예전 프로필을 되돌려 놓을 수 있습니다.
  • 절반 축, 햇 대각선, 두 번째 햇은 읽지도 쓰지도 않습니다. 동작마다 조합은 최대 두 개입니다.
  • MSFS 2020에 들어 있는 프리셋은 실제 설치에서 확인하지 않았으므로, 2020 프리셋이 기본값으로 인정되려면 장치 이름도 담고 있어야 합니다.
  • 테스트: engine\tests\smoke\msfs.ps1(Sensitivity 페이지, 재정의, 플래그, 충돌, 병합). 시뮬레이터 안에서는 tools\e2e\games\MsfsCurves.ps1(바인딩, Sensitivity 페이지, 비행 중 버튼과 축 곡선을 SimConnect로 다시 읽음).
