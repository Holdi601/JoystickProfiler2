IL-2 Sturmovik: Great Battles

표시:

IL-2 Great Battles는 모든 기체에 공통인 키 매핑 하나를 게임 설치 폴더 안의 텍스트 파일(data\input)에 보관합니다. JoyPro는 이 키 매핑을 프로필로 읽어 오고, 관계에서 그 동작을 다른 게임과 묶을 수 있게 해 주며(IL-2와 DCS의 "Gear"가 같은 버튼에), 다시 씁니다. 게임은 시작할 때 파일을 컴파일하므로, 비행 중에는 JoyPro의 어떤 것도 실행되지 않습니다.

  2. 이 버튼 사용
    먼저 목록을 확인

    IL-2는 닫아 둔 채로

먼저: IL-2가 키 매핑을 한 번 쓰게 하세요. Settings > Key mapping을 열고 ACCEPT를 누르세요. IL-2를 닫으세요.

그러면: 모든 IL-2 기체에서 바인딩이 Settings > Key mapping에 들어가 있습니다.

전에 IL-2에서 버튼을 바인딩한 적이 있나요? 그러면 시작 페이지에 가져온 후 빈 곳 채우기가 나타납니다. 기존 바인딩은 그대로 두고, 비어 있는 버튼에만 새 역할이 주어집니다. 빠른 시작: 내 스틱 작동시키기를 참조하세요.

#헤드 트래킹 없이 주위 둘러보기

TrackIR도 VR도 없나요? 설정은 스냅 시점을 스틱의 햇 하나(앞, 뒤, 왼쪽, 오른쪽)에 넣습니다. 스로틀에 미니 스틱이 있으면 시점 축은 그곳에 넣습니다. 헤드 트래킹과 주위 둘러보기를 참조하세요.

#JoyPro가 IL-2 Great Battles에서 하는 일

  • 가져오기: 키 매핑에서 스틱, 스로틀, 페달, 패널에 놓인 모든 동작이 수정키, 축 반전, 축 응답 행과 함께 프로필로 들어옵니다. 키보드 키는 요청할 때 들어옵니다.
  • 관계: 관계 하나는 모든 게임에서 하나의 기능입니다. IL-2에는 모든 기체에 공통인 키 매핑이 하나 있으므로, 관계의 IL-2 동작은 모든 IL-2 기체에서 작동합니다.
  • 내보내기: JoyPro가 게임의 data\input 폴더에 키 매핑 파일을 씁니다. IL-2는 Settings > Key mapping에 바인딩을 보여 줍니다.

#IL-2 바인딩 가져오기

  1. 시작을 여세요. IL-2 Great Battles 카드에 게임 이미지가 보입니다. 명령 목록을 요청하면 목록 생성을 누르세요. JoyPro가 IL-2가 쓴 키 매핑 파일을 읽습니다.
  2. 카드에서 가져오기를 누르세요. 내 프로필에 추가(또는 이 게임에서 다시 시작)를 고르고, 비행 키도 원하면 키보드 키도 가져오기를 체크하세요.
  3. 지금 가져오기를 누르세요. 내 관계 보기를 누르면 들어온 내용이 열립니다.

#관계 만들기와 확인

관계 페이지에서 관계의 IL-2 동작은 모두 다른 게임의 같은 기능 옆에 놓입니다. 관계 흐름으로 이를 묶은 다음, 내보내기 페이지에서 지금 확인을 누르세요. 게임보다 먼저, IL-2에서 두 가지 일을 하는 버튼을 찾아냅니다(확인).

#IL-2로 내보내기

  1. IL-2를 닫으세요. Il-2.exe가 실행 중이면 JoyPro는 쓰기를 거부합니다.
  2. 내보내기를 여세요. IL-2 카드에 관계 중 몇 개가 바인딩되었는지 표시됩니다.
  3. JoyPro에서 스틱을 설정한다면 내 장치에서 교체와 다른 장치도 지우기를 그대로 두세요. IL-2 카드의 지금 내보내기를 누르세요.
게임에서: IL-2에서 보이는 것

IL-2를 시작하고 Settings > Key mapping을 여세요. 바인딩이 각 탭(예: Plane controls)의 동작 행에 장치별로 들어가 있습니다. JoyPro가 쓴 축 응답은 이번 시작부터 게임이 사용합니다. JoyPro가 설정한 포스 피드백과 노이즈 필터 값은 Settings > Input devices에 표시됩니다.

#IL-2에서 직접 해야 할 일

  • IL-2가 키 매핑을 한 번 쓰게 하세요. data\input에 아직 global.actions가 없다면 Settings > Key mapping을 열고 ACCEPT를 누르세요. 이 파일이 없으면 가져올 것이 없고, 명령 목록에는 게임이 쓴 동작만 들어갑니다.
  • 포스 피드백과 노이즈 필터 값을 위해: Settings > Input devices를 한 번 열고 ACCEPT를 눌러 게임이 current.devices 파일을 만들게 하세요. JoyPro는 이 파일을 바꿀 뿐 만들지는 않습니다.
  • 게임 텔레메트리를 이용한 JoyPro 자체 포스 피드백을 쓰려면, 포스 피드백 페이지가 게임의 startup.cfg에 JoyPro의 주소를 추가합니다(먼저 IL-2를 닫으세요). 그런 다음 그 스틱에 대해 IL-2 자체 포스 피드백을 끄세요.

#자주 하는 실수

  • "IL-2 실행 중입니다": 게임을 완전히 닫고 다시 내보내세요.
  • 바인딩이 엉뚱한 장치에 있음: IL-2는 devices.txt의 번호로 장치를 구분합니다. JoyPro가 쓰는 장치는 번호를 유지하고, 새 장치는 비어 있는 가장 낮은 번호를 받습니다. 내보내기와 가져오기 사이에 게임에서 장치 번호를 바꾸지 마세요.
  • "추가만" 후 바인딩이 빠짐: IL-2에서 그 버튼을 다른 동작에 쓰고 있었습니다. 확인 기능이 이를 "게임에 기록되지 않음" 아래에 보여 줍니다. 업데이트로 내보내거나 바인딩을 옮기세요.
  • 포스 피드백 값이 바뀌지 않음: 게임에 아직 current.devices가 없습니다(위 참조).
고급

#JoyPro가 읽고 쓰는 파일

파일 설명
<install>\data\input\global.actions 키 매핑: 동작마다 한 줄 `action, input, invert
<install>\data\input\devices.txt 장치 목록: 각 조이스틱의 번호, DirectInput GUID, 이름
<install>\data\input\current.responses 동작별 축 응답 행(중앙형, 한쪽 방향). 모든 기체 공통
<install>\data\input\global.pitch 중앙 이동이 있는 피치 행(중앙 이동을 정했을 때만 만들어짐)
<install>\data\input\jp.actions 관계(릴레이션) 이름, 그룹, 수정키, 튜닝이 담긴 JoyPro의 사본. 다음 가져오기에서 다시 읽음
<install>\data\input\current.devices Settings > Input devices: 포스 피드백과 조이스틱 노이즈 필터(제자리에서 변경)
<install>\data\startup.cfg 포스 피드백 값과 JoyPro의 텔레메트리 주소

current.map은 IL-2가 시작할 때마다 이 파일들로 컴파일합니다. JoyPro는 절대 쓰지 않습니다.

#IL-2의 내보내기 모드

모드 IL-2에서 일어나는 일
추가만 아무것도 제거되지 않습니다. IL-2가 이미 다른 동작에 쓰는 입력에 걸린 바인딩은 쓰이지 않고 "게임에 기록되지 않음" 표시가 붙습니다.
업데이트, 게임의 바인딩 유지 사용자의 바인딩이 들어갑니다. IL-2의 다른 바인딩은 남지만, 사용자가 쓰는 입력에 걸린 다른 동작의 바인딩은 예외입니다.
업데이트, 내 프로필 우선 위와 같고, 바인딩한 모든 동작은 다른 입력을 잃습니다(조이스틱. 키보드는 키보드 옵션이 있을 때만).
내 장치에서 교체 쓰는 조이스틱에는 사용자의 바인딩만 남습니다.
+ 다른 장치도 지우기 프로필에 바인딩이 없는 연결된 조이스틱은 바인딩을 잃습니다.

global.actions는 게임의 순서를 유지하며, 새 줄은 끝에 들어갑니다.

#절대 건드리지 않는 것

  • 연결되지 않은 조이스틱의 줄, 가져오기에서 무시한 장치, JoyPro가 입력을 보내는 vJoy 장치.
  • 마우스 줄(키보드 키와 함께 쓰는 마우스 입력도), TrackIR, JoyPro가 읽을 수 없는 입력이 있는 줄.
  • 키보드. 키보드 바인딩을 내보낼 때는 예외입니다.
  • current.map과 게임의 다른 파일.

#기체, 곡선, 포스 피드백

  • 단위: 전체 공통. 키 매핑 하나와 동작별 응답 행 하나가 모든 기체에 적용됩니다.
  • 축 곡선(축 모델 il2): 중앙형 축에는 중앙 데드존, 가장자리 데드존, 곡선("sensitivity balance"). 스로틀 같은 한쪽 방향 축에는 낮은 쪽과 높은 쪽 데드존. 피치에는 중앙 이동. 기본 곡선은 IL-2의 모델에 맞게 근사합니다. IL-2 전용이나 IL-2 계열 전용 곡선도 정할 수 있습니다(Great Battles와 Korea는 서로의 값을 읽습니다). 반전은 동작의 줄에 씁니다.
  • 게임 설정(설정 > 게임의 포스 피드백 설정): 조이스틱 노이즈 필터, 포스 피드백 켜기, 피드백 세기, 흔들림. IL-2 바인딩이 없는 내보내기도 이 설정은 씁니다.
  • 텔레메트리 포스 피드백: 게임의 텔레메트리 출력으로 만드는 JoyPro 자체 효과(포스 피드백). 같은 출력으로 텔레메트리 기록도 합니다(CSV. 텔레메트리에 월드 위치가 없으므로 Tacview 트랙은 없음).
  • HUD: IL-2가 실행되는 동안 누른 버튼의 IL-2 바인딩을 보여 줍니다(HUD).
  • 감시 기능: Key mapping에서 바꾼 바인딩은 IL-2가 종료된 뒤 감지되며, JoyPro가 그 변경을 가져올지 묻습니다(감시 기능).
기술 정보

#IL-2 연동의 내부

코드: engine\EngineIl2.cs(가져오기, 내보내기, 파일), engine\EngineIl2DbRefresh.cs(명령 목록), engine\AxisModels(모델 il2), engine\EngineFfbTelemetry.cs(텔레메트리 설정).

  • 입력: joy<N>_b<button, 0-based>, joy<N>_axis_<x|y|z|...>, joy<N>_pov<hat>_<angle>, 키보드 키는 DirectInput 이름, 축 쌍은 <input>/<input>, 수정키는 <modifier>+<input>. IL-2는 햇 번호를 0부터, JoyPro는 1부터 셉니다(JOY_BTN_POV1_*는 pov0).
  • 장치: devices.txt에는 <number>,"<GUID>",<name>|가 나열됩니다. IL-2는 DirectInput 인스턴스 GUID의 마지막 8바이트를 뒤집어 한 그룹으로 씁니다. 모든 모드는 이미 나열된 번호를 유지합니다.
  • 명령 목록: engine db refresh-il2는 게임이 쓴 *.actions 파일을 읽습니다(jp.actions는 제외). 게임의 탭(Service, Camera controls, Plane controls, Weapons controls ...)이 범주가 됩니다. 게임은 입력이 있는 동작만 쓰므로, 새로 설치한 상태의 목록에는 약 376개 동작이 있습니다.
  • 가져오기 / 내보내기: engine il2 import, engine il2 scan, engine il2 export(--mode clean|add|merge|merge-overwrite --nuke-untouched-devices true|false --ignore-device <d>). 백업: 처음 쓰기 전에 모든 파일을 <file>.jpbak와 백업 저장소에 저장합니다.
  • 설정과 곡선: engine ffb set --device * --game IL2Game, engine binds tuning set --scope game:IL2Game 또는 family:il2, engine binds tuning preview.
  • 텔레메트리: engine ffb telemetry setup il2는 startup.cfg의 telemetrydevice 섹션에 주소 줄 127.0.0.1:41994 하나를 추가하며, 다른 도구의 주소는 절대 바꾸지 않습니다. --remove는 파일을 바이트 단위까지 복원합니다.
  • 감시 기능: engine sync status, engine sync diff(감시 대상: global.actions, devices.txt, current.responses, current.devices, startup.cfg).

#알려진 한계

  • 게임 파일에 입력이 없는 동작은 새로 만든 명령 목록에 들어 있지 않습니다.
  • JoyPro의 텔레메트리 포스 피드백을 받는 스틱은 게임 자체의 포스 피드백을 꺼야 합니다.
  • 테스트: engine\tests\smoke\il2.ps1. 게임 안에서는 tools\e2e\games\IL2Game.ps1(바인딩, 38단계 중 38단계)과 IL2GameCurves.ps1(게임이 컴파일한 응답을 JoyPro의 미리 보기와 비교).
