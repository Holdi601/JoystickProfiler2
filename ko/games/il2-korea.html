IL-2 Series: Korea

표시:

IL-2 Series: Korea는 IL-2 Great Battles와 같은 계열이지만, 키 매핑을 새 JSON 형식으로 보관합니다. 모든 기체에 공통인 프로필 하나("General")가 게임 설치 폴더 안에 있습니다. JoyPro는 이를 프로필로 읽어 오고, 관계에서 그 동작을 다른 게임과 묶고, 게임 곡선 편집기의 응답 곡선과 포스 피드백 설정까지 포함해 다시 씁니다.

먼저: 키 매핑을 한 번 저장하세요. Settings > Key mapping을 열고 ACCEPT를 누르세요. 게임을 닫으세요.

그러면: 모든 기체에서 바인딩이 Settings > Key mapping에 들어가 있습니다.

전에 IL-2 Korea에서 버튼을 바인딩한 적이 있나요? 그러면 시작 페이지에 가져온 후 빈 곳 채우기가 나타납니다. 기존 바인딩은 그대로 두고, 비어 있는 버튼에만 새 역할이 주어집니다. 빠른 시작: 내 스틱 작동시키기를 참조하세요.

#헤드 트래킹 없이 주위 둘러보기

TrackIR도 VR도 없나요? 설정은 스냅 시점을 스틱의 햇 하나(앞, 뒤, 왼쪽, 오른쪽)에 넣습니다. 스로틀에 미니 스틱이 있으면 시점 축은 그곳에 넣습니다. 헤드 트래킹과 주위 둘러보기를 참조하세요.

#JoyPro가 IL-2 Korea에서 하는 일

  • 가져오기: 키 매핑에서 스틱, 스로틀, 페달, 패널에 놓인 모든 동작이 수정키, 축마다의 반전, 곡선 편집기 값과 함께 프로필로 들어옵니다. 키보드 키는 요청할 때 들어옵니다.
  • 관계: 관계 하나는 모든 게임에서 하나의 기능입니다. 예를 들어 Korea, IL-2 Great Battles, DCS의 "Gear"가 같은 버튼에 있습니다. Korea에는 모든 기체에 공통인 키 매핑이 하나 있습니다.
  • 내보내기: JoyPro는 키 매핑을 쓰고, 게임 자체의 "assign device number" 대화 상자처럼 각 장치에 장치 번호를 줍니다.

#Korea 바인딩 가져오기

  1. 시작을 여세요. IL-2 Series: Korea 카드에 게임 이미지가 보입니다. 명령 목록을 요청하면 목록 생성을 누르세요. JoyPro가 게임의 general.actions를 읽습니다(모든 동작에 JoyPro 자체 이름과 설명이 붙습니다).
  2. 카드에서 가져오기를 누르세요. 내 프로필에 추가를 고르고, 비행 키도 원하면 키보드 키도 가져오기를 체크하세요.
  3. 지금 가져오기를 누르세요. 내 관계 보기를 누르면 들어온 내용이 열립니다.

#관계 만들기와 확인

관계 페이지에서 관계의 Korea 동작은 다른 게임의 같은 기능 옆에 놓입니다. 관계 흐름으로 이를 묶은 다음, 내보내기 페이지에서 지금 확인을 누르세요. Korea에서 두 가지 일을 하는 버튼을 찾아냅니다(확인).

#IL-2 Korea로 내보내기

  1. 게임을 닫으세요. IL2Series.exe가 실행 중이면 JoyPro는 쓰기를 거부합니다.
  2. 내보내기를 여세요. IL-2 Series: Korea 카드에 관계 중 몇 개가 바인딩되었는지 표시됩니다.
  3. JoyPro에서 스틱을 설정한다면 내 장치에서 교체와 다른 장치도 지우기를 그대로 두세요. 카드의 지금 내보내기를 누르세요.
게임에서: IL-2 Korea에서 보이는 것

게임을 시작하고 Settings > Key mapping을 여세요. 바인딩이 동작 행(예: Basic 탭)에 장치 이름과 번호("joy 2")와 함께 들어가 있습니다. 게임은 장치 번호를 묻지 않습니다. 축 행의 곡선 아이콘을 누르면 JoyPro가 쓴 값으로 응답 편집기가 열립니다. 포스 피드백과 축 노이즈 필터는 Settings > Input devices에 표시됩니다.

#IL-2 Korea에서 직접 해야 할 일

  • 키 매핑을 한 번 저장하세요. Key mapping에서 ACCEPT를 누르면 게임이 general.actions를 씁니다. 처음 시작할 때는 게임의 사용자 동의서도 나옵니다. general.actions가 없으면 내보낼 곳이 없습니다.
  • 단독 실행 버전은 기본적으로 Program Files 아래에 설치되며, Windows가 이 폴더를 보호할 수 있습니다. 그러면 내보내기는 파일을 절반만 쓰지 않고 그렇다고 알려 줍니다.
  • 게임 텔레메트리를 이용한 JoyPro 자체 포스 피드백을 쓰려면, 포스 피드백 페이지가 게임의 startup.cfg에 JoyPro의 주소를 추가합니다(먼저 게임을 닫으세요). 그 스틱에 대해 게임 자체 포스 피드백을 끄세요.

#자주 하는 실수

  • "IL-2 Korea 실행 중입니다": 게임을 닫고 다시 내보내세요.
  • 장치가 건너뛰어짐: 장치 번호가 없고 연결되지도 않은 장치는 번호를 받을 수 없습니다. 장치를 연결하고 다시 내보내세요.
  • "추가만" 후 바인딩이 빠짐: 게임에서 그 입력을 다른 동작에 쓰고 있었습니다. 확인 기능이 이를 "게임에 기록되지 않음" 아래에 보여 줍니다.
고급

#JoyPro가 읽고 쓰는 파일

파일 설명
<install>\data\input\general.actions 키 매핑 프로필 "General"(JSON): 사용하는 장치, 수정키, 입력이 있는 모든 동작, Relative Control 값
<install>\data\input\known.devices.json 게임이 본 적 있는 모든 장치와 그 장치 번호
<install>\data\input\general.pitch 피치 곡선("General (Common pitch curve)")
<install>\data\input\shared.responses 다른 축의 곡선
<install>\data\NSData\UserData\UserSettings.json Settings > Input devices: 포스 피드백과 축 노이즈 필터(섹션 input)
<install>\data\startup.cfg JoyPro의 텔레메트리 주소(텔레메트리 포스 피드백을 설정했을 때만)
general.actions.joypro-meta.json 파일 옆에 두는 JoyPro의 이름, 그룹, 수정키, 튜닝. 다음 가져오기에서 다시 읽음

Steam판에서 <install>은 steamapps\common\IL2Series이고, 단독 런처판에서는 그 아래의 game 폴더입니다. current.map은 게임이 컴파일하며, JoyPro는 절대 쓰지 않습니다.

#IL-2 Korea의 내보내기 모드

모드 게임에서 일어나는 일
추가만 아무것도 제거되지 않습니다. 게임이 다른 동작에 쓰는 입력에 걸린 바인딩은 쓰이지 않고 목록에 표시됩니다.
업데이트, 게임의 바인딩 유지 사용자의 바인딩이 들어갑니다. 게임의 다른 입력은 남지만, 사용자가 다른 동작에 준 입력에 걸린 게임 바인딩은 예외입니다.
업데이트, 내 프로필 우선 위와 같고, 바인딩한 모든 동작은 다른 입력을 잃습니다(조이스틱. 키보드는 키보드 옵션이 있을 때만).
내 장치에서 교체 쓰는 장치의 모든 조이스틱 입력이 풀린 다음, 사용자의 바인딩이 들어갑니다.
+ 다른 장치도 지우기 프로필에 바인딩이 없는 연결된 장치는 조이스틱 입력을 잃습니다.

#절대 건드리지 않는 것

  • 키보드 키, 마우스 입력, 교체 모드에서 축에 걸린 키 쌍(키보드는 키보드 옵션이 있을 때만 바뀜).
  • 연결되지 않은 장치, 가져오기가 읽을 수 없는 줄, 가져오기에서 무시한 장치, JoyPro가 입력을 보내는 vJoy 장치.
  • current.map, 장치별 포스 피드백 파일, 게임의 다른 설정.

#곡선, Relative Control, 포스 피드백

  • 단위: 전체 공통. 모든 기체에 키 매핑 하나. 피치 곡선 프로필은 기본적으로 모든 기체에 지정됩니다.
  • 축 곡선(축 모델 il2korea): 지수(-100~100), 중앙과 가장자리 데드존, 피치의 중앙 오프셋. 피치, 롤, 요에는 내장 응답 곡선과 조종면 부하도 있습니다. 한쪽 방향 축(스로틀, 브레이크)은 전체 이동 범위에 걸친 지수와 낮은/높은 데드존을 받습니다. 카메라 축에는 편집기가 없어 곡선을 받지 않습니다. 값은 파일의 단위이며, 게임은 데드존을 네 배 크게 보여 줍니다.
  • Relative Control(축 입력의 ◆ 버튼): 켜기/끄기, 데드존(0~80 %), 감도(1~20). 대화 상자에 보이는 그대로입니다.
  • 게임 설정(설정 > 게임의 포스 피드백 설정): 포스 피드백 켜기, 흔들림 세기, 피드백 세기, 저속과 고속의 스틱 힘, 힘 중립 재조정, 지면 접촉, 축 노이즈 필터. 게임에 보이는 대로 % 단위입니다.
  • 텔레메트리 포스 피드백과 기록: Great Battles와 마찬가지로 게임의 텔레메트리 출력에서 가져옵니다(CSV만, Tacview 트랙 없음).
  • 감시 기능: general.actions의 변경은 게임이 종료된 뒤 감지됩니다(감시 기능).
기술 정보

#Korea 연동의 내부

코드: engine\Games\Il2KoreaIntegration.cs, engine\AxisModels의 축 모델 il2korea.

  • 입력: dev<N>_b<button, 0-based>, dev<N>_axis_<x|y|z|w|s|t|p|q>(X, Y, Z, RX, RY, RZ, 슬라이더 1, 슬라이더 2), 토큰 앞의 - = 반전, * = Relative Control, 햇 dev<N>_pov<hat>_<angle>, 키 key_<name>, 조합은 +로.
  • 장치: known.devices.json은 모든 장치를 DirectInput 인스턴스 GUID(IL-2의 바이트 순서)로 구분하며, deviceId(번호, -1 = 없음)와 ident(vid_pid)를 담습니다. JoyPro가 쓰는 장치는 번호를 유지하고, 번호가 없는 연결된 장치는 1부터 시작해 가장 낮은 빈 번호를 받습니다.
  • 명령 목록: engine il2korea refresh-db는 키 매핑 파일의 동작을 추가합니다. 입력이 없는 동작은 general.actions에 없으므로, 새 목록에는 약 318개 동작이 있습니다. JoyPro는 게임의 압축 아카이브를 읽지 않습니다.
  • 가져오기 / 내보내기: engine il2korea import, engine il2korea scan, engine il2korea export(--mode, --nuke-untouched-devices, --include-keyboard, --dry-run). engine il2korea paths는 파일을 보여 줍니다.
  • 설정과 곡선: engine ffb set --device * --game IL2Korea --param ffForce=80, engine binds tuning set --scope game:IL2Korea(또는 family:il2), engine binds tuning preview(중앙 오프셋의 평평한 쪽을 빼면 게임이 컴파일한 표와 1e-6까지 일치).
  • 텔레메트리: engine ffb telemetry setup il2korea.

#알려진 한계

  • 게임 자체의 동작 텍스트는 압축 아카이브에 들어 있는데, JoyPro는 이를 읽지 않으므로 자체 이름을 씁니다.
  • Key mapping 페이지의 동작 중 약 60개는 새 general.actions에 입력이 없어서, 새로 만든 목록에 들어 있지 않습니다.
  • 테스트: engine\tests\smoke\il2korea.ps1, il2koreainstall.ps1. 게임 안에서는 tools\e2e\games\IL2Korea.ps1(49단계 중 49단계), IL2KoreaCurves.ps1, IL2KoreaSettings.ps1.
