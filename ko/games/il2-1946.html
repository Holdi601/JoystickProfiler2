IL-2 Sturmovik: 1946

표시:

IL-2 Sturmovik: 1946은 조작 설정을 조종사마다 게임 폴더 안의 일반 ini 파일에 보관하고, 축 응답은 conf.ini에 보관합니다. 장치는 Windows 장치 순서상의 위치로만 구분합니다. JoyPro는 현재 조종사의 조작 설정을 프로필로 읽어 오고, 관계에서 다른 게임과 묶을 수 있게 해 주며, 한 줄씩 다시 쓰고 파일의 나머지 바이트는 모두 그대로 둡니다.

먼저: 장치를 평소 순서대로 연결하세요. 게임을 닫으세요.

그러면: 현재 조종사의 바인딩이 Main Menu > Controls에 들어가 있습니다.

전에 IL-2 1946에서 버튼을 바인딩한 적이 있나요? 그러면 시작 페이지에 가져온 후 빈 곳 채우기가 나타납니다. 기존 바인딩은 그대로 두고, 비어 있는 버튼에만 새 역할이 주어집니다. 빠른 시작: 내 스틱 작동시키기를 참조하세요.

#헤드 트래킹 없이 주위 둘러보기

TrackIR도 VR도 없나요? 설정은 스냅 시점을 스틱의 햇 하나(앞, 뒤, 왼쪽, 오른쪽)에 넣습니다. 헤드 트래킹과 주위 둘러보기를 참조하세요.

#JoyPro가 IL-2 1946에서 하는 일

  • 가져오기: 스틱, 스로틀, 페달에 있는 현재 조종사의 바인딩이 축마다의 데드 밴드와 곡선과 함께 프로필로 들어옵니다. 키보드 키는 요청할 때 들어옵니다.
  • 관계: 관계 하나는 모든 게임에서 하나의 기능입니다(1946, Great Battles, DCS의 "Gear").
  • 내보내기: JoyPro는 조종사의 settings.ini와 conf.ini의 축 줄을 씁니다. 게임은 Controls 페이지에 바인딩을 보여 줍니다.

#IL-2 1946 바인딩 가져오기

  1. 시작을 여세요. IL-2 Sturmovik: 1946 카드에 게임 이미지가 보입니다. 명령 목록을 요청하면 목록 생성을 누르세요. JoyPro가 자체 명령 목록과 파일에 나오는 명령을 합칩니다.
  2. 카드에서 가져오기를 누르세요. 내 프로필에 추가를 고르고, 비행 키도 원하면 키보드 키도 가져오기를 체크하세요.
  3. 지금 가져오기를 누르세요. 내 관계 보기를 누르면 들어온 내용이 열립니다.

#관계 만들기와 확인

관계 페이지에서 관계의 1946 명령은 다른 게임의 같은 기능 옆에 놓입니다. 관계 흐름으로 이를 묶은 다음, 내보내기 페이지에서 지금 확인을 누르세요(확인).

#IL-2 1946으로 내보내기

  1. 게임을 닫으세요. il2fb.exe가 실행 중이면 JoyPro는 쓰기를 거부합니다. 게임은 Apply를 누르면 settings.ini를, 종료할 때 conf.ini를 다시 씁니다.
  2. 내보내기를 여세요. IL-2 Sturmovik: 1946 카드에 관계 중 몇 개가 바인딩되었는지 표시됩니다.
  3. JoyPro에서 스틱을 설정한다면 내 장치에서 교체와 다른 장치도 지우기를 그대로 두세요. 카드의 지금 내보내기를 누르세요.
게임에서: IL-2 1946에서 보이는 것

게임을 시작하고 Main Menu > Controls를 여세요. 바인딩이 명령 행에 표시됩니다. 예: JoyButton 7 ID4(네 번째 장치의 버튼 7), Hat Switch -135 ID14, 목록 끝의 U Slider axis ID4. Controls > Input에는 JoyPro가 바인딩된 각 축에 쓴 데드 밴드와 곡선 슬라이더가 표시됩니다.

#IL-2 1946에서 직접 해야 할 일

  • 장치를 같은 순서로 유지하세요. 게임은 이름이 아니라 Windows 순서대로 "장치 0, 1, 2, 3"을 저장합니다. 다른 순서로 장치를 연결했다면 다시 내보내세요.
  • Steam Cloud는 게임이 종료될 때 Users 폴더를 동기화합니다. 게임이 닫혀 있는 동안 JoyPro가 바꾼 파일은 다음 시작 때 업로드됩니다.
  • 내보낸 조종사로 비행하세요. JoyPro는 현재 조종사의 파일을 먼저 사용합니다(Users\all.ini에 어느 조종사인지 나옴). 다른 조종사라면 내보내기 페이지의 **옵션 및 경로 (전문가용)**에서 그 조종사의 settings.ini를 지정하세요.

#자주 하는 실수

  • 장치가 거부됨: 게임은 처음 네 개의 게임 컨트롤러만 읽습니다. 다섯 번째 이후 위치의 장치에는 쓸 수 없습니다.
  • 수정키를 쓰는 바인딩이 빠짐: 게임은 조이스틱 버튼을 누를 때 누르고 있는 키를 무시하므로, JoyPro는 수정키가 있는 조이스틱 바인딩을 건너뜁니다(경고와 함께). 키에는 수정키를 하나 쓸 수 있습니다.
  • 바인딩이 엉뚱한 스틱에 있음: 장치 순서가 바뀌었습니다. 다시 내보내세요.
고급

#JoyPro가 읽고 쓰는 파일

파일 설명
<install>\Users\<pilot>\settings.ini 조종사의 바인딩, 섹션 [HotKey move](축), pilot, gunner, misc, aircraftView, orders ...
<install>\Users\all.ini 조종사 목록과 현재 조종사(읽기만 함)
<install>\Users\default.ini 새 조종사용 템플릿(명령 목록을 위해서만 읽음)
<install>\conf.ini 축 응답, 섹션 [rts_joystick] / [rts_joystick<k>]
settings.ini.joypro.json JoyPro가 쓴 입력

Steam판에서 <install>은 steamapps\common\IL 2 Sturmovik 1946입니다. JoyPro는 줄을 제자리에서 편집합니다.

#IL-2 1946의 내보내기 모드

모드 게임에서 일어나는 일
추가만 아무것도 제거되지 않습니다. 게임이 다른 명령에 쓰는 입력에 걸린 바인딩은 쓰이지 않고 목록에 표시됩니다.
업데이트, 게임의 바인딩 유지 사용자의 바인딩이 들어갑니다. 사용자가 다른 명령에 준 입력에 걸린 게임 바인딩은 제거되고, 나머지는 남습니다(게임은 명령마다 입력 두 개를 유지합니다).
업데이트, 내 프로필 우선 위와 같고, 바인딩한 모든 명령은 다른 입력을 잃습니다(키보드는 키보드 옵션이 있을 때만).
내 장치에서 교체 쓰는 장치는 관리 대상 섹션에서 다른 줄을 모두 잃습니다.
+ 다른 장치도 지우기 연결된 다른 장치는 줄을 잃습니다.

#절대 건드리지 않는 것

  • 연결되지 않은 장치의 줄, 가져오기가 읽을 수 없는 줄, 마우스 줄(MouseAXE_X, MouseLeft), 키보드 줄(키보드는 키보드 옵션이 있을 때만).
  • 다른 조종사의 파일(그 조종사로 내보내지 않는 한), 그리고 conf.ini의 다른 모든 줄.

#곡선과 설정

  • 단위: 조종사별. 한 조종사의 모든 기체가 바인딩을 공유하며, 축 응답은 장치 축마다 따로입니다.
  • 축 응답(축 모델 il21946): 데드밴드(0~50), 스틱 10 %~100 % 지점의 곡선 점 열 개(선형 출력의 백분율), 필터, 한쪽 방향 플래그. 기본 곡선은 근사해서 맞춥니다. 데드존은 데드밴드로, 형태는 열 개의 점으로(선형이 상한이므로 선형보다 위의 곡선은 표현할 수 없음), 슬라이더는 한쪽 방향으로. 업데이트 모드에서는 JoyPro의 곡선이 그냥 기본값이면 게임에서 정한 곡선이 남습니다.
  • 반전: 명령 앞의 -. 장치 축마다 명령 하나만 응답 줄을 받습니다(두 번째 명령에는 경고).
  • 포스 피드백과 게임 설정은 없습니다. 감시 기능은 게임이 종료된 뒤 변경을 감지합니다.
기술 정보

#1946 연동의 내부

코드: engine\Games\Il21946Integration.cs, engine\Games\Il2LegacyIntegration.cs, engine\Games\Il2LegacyInput.cs, engine\Games\LegacyIniFile.cs.

  • 줄: <trigger>[ <trigger>]=<command>. 축 AXE_<X|Y|Z|RX|RY|RZ|U|V> JoystickDevice<d>, 버튼 Joystick<b> JoystickDevice<d>(b는 0부터 셈), 햇 Pov<angle> JoystickPov<d*4+h>, 키 [<modifier> ]<key>. 새 줄은 게임처럼 입력을 먼저 씁니다.
  • 장치: 인덱스로만 구분합니다. JoystickDevice<d>는 DirectInput 순서에서 d번째 게임 컨트롤러이며, JoyPro는 이를 그 인덱스의 연결된 장치에 맞춥니다. 장치는 최대 4개(JoystickDevice0..3), 각각 축 8개와 햇 4개.
  • 축 줄: 1<axis>[<device>]= 정수 13개: 데드밴드, 곡선 점 열 개, 필터, 한쪽 방향(0 중앙, 1 한쪽 방향, 2 한쪽 방향 반대). [rts] JoyProfile=k가 섹션을 고릅니다.
  • 명령 목록: engine il21946 refresh-db: JoyPro 자체 명령 목록과, Users\default.ini, conf.ini, 조종사들의 settings.ini에 이름이 나오는 모든 명령. id는 <section>.<command>(pilot.Gear, move.power4).
  • 가져오기 / 내보내기: engine il21946 paths(현재 조종사가 먼저), engine il21946 import, engine il21946 scan, engine il21946 export. 처음 쓰기 전에 두 파일을 백업합니다.

#알려진 한계

  • 영어가 아닌 게임 언어에서의 키 이름은 아직 확인되지 않았습니다.
  • 장치당 버튼 한도: 파일은 128개를 허용하지만, 플레이어들은 32개를 보고합니다.
  • 테스트: engine\tests\smoke\il21946.ps1. 게임 안에서는 tools\e2e\games\IL21946.ps1(Controls 페이지의 바인딩, Input 페이지의 응답, 게임의 다시 쓰기와 그 가져오기. 33단계 중 29단계, 완전히 통과한 실행은 아직 없음).
