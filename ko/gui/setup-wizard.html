GUI 페이지

설정 마법사

표시:

설정 마법사는 게임의 컨트롤을 한 번에 설정합니다. 연결된 장치를 살펴보고, 각 장치에 역할(주 스틱, 스로틀, 페달, 패널 ...)을 주고, 게임 기체의 중요한 기능으로 관계를 만들고, 그것을 장치에 바인딩한 다음, 결과를 치트 시트로 보여 줍니다. 프로필이 바뀌기 전에 모든 것을 검토하며, 실행 취소 한 번으로 모두 되돌립니다. AI 없이 실행됩니다. 같은 선택은 항상 같은 계획을 만듭니다.

시작 페이지에서 여세요. "장치 설정" 카드에 버튼이 두 개 있습니다:

  • 모두 알아서 설정(파란 버튼): 빠른 설정입니다. 단계를 보여 주지 않고 이 마법사를 알아서 실행하며, 무엇이 어디로 가는지 보여 주는 간단한 목록에서 멈춥니다. 빠른 시작을 보세요.
  • 단계별로 설정...: 다섯 단계를 모두 거치는 이 마법사로, 각 단계를 직접 고릅니다.

그 카드가 없으면(모든 게임이 이미 설정됨), 시작 페이지의 내 게임 아래나 바인딩 페이지에서 **내 장치 자동 설정...**을 누르세요.

  1. 게임
    설정할 게임
  2. 장치
    각 장치의 용도
  3. 우선순위
    기체, 수정키, 기능을 둘 위치
  4. 계획
    JoyPro가 배치한 것
  5. 검토
    확인한 다음 내 프로필에 적용

빠른 설정(모두 알아서 설정)은 이 단계들 없이 같은 플래너를 실행합니다. 장치의 일반적인 역할을 쓰고, 모든 기체를 똑같이 다루며, 수정키는 쓰지 않고, **기능을 어디에 둘까요?**에서 마지막으로 고른 값을 씁니다. 비행 시뮬레이터에서는 질문 하나만 합니다: 헤드 트래킹이나 VR을 사용하시나요?

초보자용

#다섯 단계

단계는 위쪽에 나옵니다. 아래쪽의 뒤로와 다음으로 단계 사이를 이동합니다. 창은 언제든 닫을 수 있습니다. 적용 전에 닫은 마법사는 닫았던 상태 그대로 돌아옵니다.

#1. 게임

시작 페이지에서 감시하는 게임이 체크되어 있습니다. 이 설정에 포함할 게임을 체크하세요. 이것으로 JoyPro가 감시하는 게임이 바뀌지는 않습니다.

#2. 장치

JoyPro가 스틱, 스로틀, 페달, 패널을 알아보고 각각에 역할을 제안합니다: "이 장치의 용도". 목록에서 역할을 바꾸세요. 한 손에 장치 하나: 같은 손을 위한 두 번째 스틱은 따로 고르지 않으면 "사용 안 함"이 됩니다. 여러 그립을 끼울 수 있는 베이스는 그립을 묻습니다. 오른쪽 상자에 JoyPro가 장치를 어떻게 쓸지 글로 나옵니다. 다시 감지는 장치를 다시 읽습니다(먼저 장치를 꽂으세요).

#3. 우선순위

  • 내 기체: 기체를 검색하고("F-16", "헬리콥터", "Star Citizen") 다음 우선순위로 추가(새 줄) 또는 같은 순위로 추가(선택한 줄에)를 누르세요. 기체가 위에 있을수록 그 기능이 더 좋은 자리를 받습니다. 한 줄에 있는 기체는 같게 치고, 목록에 넣지 않은 기체는 가장 낮게 칩니다.
  • 수정키: 수정키는 (Shift처럼) 누르고 있으면 다른 모든 버튼이 두 번째 일을 하게 하는 버튼입니다. 몇 개를 쓸지 고르세요. 가능한 한 적게는 버튼이 모자랄 때만 하나를 씁니다.
  • 모드 스위치(단계 레이어): 고정되는 스위치로 전투 단계마다 버튼이 하는 일을 바꿀 수 있습니다.
  • 기능을 어디에 둘까요?: 슬라이더입니다. 왼쪽 끝: 모든 기체에서 같은 일은 같은 버튼. 오른쪽 끝: 실제 기체와 같은 위치. 처음에는 가운데에 있습니다. 기관포와 스로틀은 절대 옮겨지지 않습니다. 기능을 어디에 둘까요?를 보세요.
  • 헤드 트래킹이나 VR을 사용하시나요? 비행 시뮬레이터 전용입니다. 머리를 움직여 주위를 둘러보거나(TrackIR, 얼굴 추적 웹캠, Tobii 또는 VR) 그럴 계획이라면 예: 장치에 시점 버튼을 넣지 않고 "시점 중앙 맞추기"만 넣습니다. 아니요: 둘러보기를 가장 중요한 버튼 바로 다음으로 스틱이나 스로틀의 햇에 둡니다. 헤드 트래킹과 주위 둘러보기를 참고하세요.

#4. 계획

JoyPro가 계획을 만듭니다: 배치한 기능 수, 배치하지 못한 것, 만든 수정키, 따른 규칙, 그리고 기체별 품질 점수(100 % = 모든 기능이 가장 좋은 자리에 있음).

#5. 검토

장치와 기체를 고르면 무엇이 어디에 바인딩되었는지 JoyPro가 그린 장치 도면으로 볼 수 있습니다. 목록에서 기능을 선택해 빈 입력으로 옮기거나, 다른 기능과 맞바꾸거나, 계획에서 뺄 수 있습니다. 미배치에는 맞지 않은 것이 중요한 순서대로 나옵니다.

마음에 들면: 내 프로필에 적용, 그다음 내 게임으로 내보내기(내보내기 페이지가 열림). 게임은 내보내기를 해야만 바뀝니다.

고급

#세부 정보

  • 역할: 메인 스틱(모든 기체에서 오른손), 헬기 스틱(헬리콥터에서 오른손. 포스 피드백 베이스 같은 두 번째 스틱용), 왼쪽 스틱(우주 게임에서 왼손. 스로틀이 없을 때 스로틀 쪽), 스로틀, 컬렉티브(헬리콥터에서 왼손), 페달(러더와 토 브레이크), 패널(인쇄된 라벨이 맞는 시스템 스위치: "LDG GEAR UP"은 랜딩 기어를 받음), 키보드 조이스틱과 가상 장치(유지되며 새로 바인딩되는 것 없음), 사용 안 함.
  • 내 프로필 우선: 이미 내 관계 중 하나에 있는 명령은 거기 그대로 있고, 이 설정의 장치에 이미 바인딩된 관계는 그 입력을 유지합니다. 직접 끈 명령은 꺼진 채로 있습니다.
  • 기능을 어디에 둘까요? 슬라이더는 모든 기체에서 같은 일은 같은 버튼부터 실제 기체와 같은 위치까지 움직입니다. 가운데보다 왼쪽에서는 모든 기체에 대해 기능마다 관계가 하나입니다. 가운데부터는 실제 HOTAS에서 그 기능이 다른 곳에 있는 기체가 자기 관계를 받으며, 오른쪽으로 갈수록 실제 위치의 영향이 커집니다. 빠른 설정과 시작 페이지는 마지막 선택을 씁니다(처음에는 가운데).
  • 3단계의 선택은 기억되며, 다음 마법사는 그 선택으로 시작합니다.
  • 적용은 모든 것을 하나의 변경으로 기록합니다. 프로필 기록 내역에 "Setup wizard: N relations, M binds"라는 이름의 버전 하나가 생깁니다. 실행 취소(Ctrl+Z)로 전부 되돌립니다.
  • 시트 열기는 치트 시트를 이미지 뷰어에서 원래 크기로 보여 줍니다. 거기서 인쇄할 수 있습니다.
  • 설정 > 사용 통계 > 새 기체를 가장 많이 쓰는 기체처럼 배치가 켜져 있으면, 새 레이아웃은 같은 종류에서 가장 많이 쓰는 기체를 따릅니다.
게임에서: 적용과 내보내기 뒤

내보내기 전까지는 아무 변화도 없습니다. 적용하고 내보내면 각 게임의 컨트롤 파일에 마법사의 바인딩이 들어갑니다. 슬라이더가 모든 기체에서 같은 일은 같은 버튼 가까이 있으면 DCS에서는 고른 모든 기체가 같은 버튼에 같은 기능을 갖습니다. Star Citizen은 우주선 조종을 스틱에, 스트레이프 축을 왼쪽 스틱에 받고, 패널은 라벨에 적힌 시스템을 받습니다. 게임에 있던 바인딩을 장치에서 지워야 한다면 내 장치에서 교체로 내보내세요.

기술 정보

#마법사의 내부

창 Views/SetupWizardWindow.axaml, 뷰 모델 ViewModels/SetupWizardViewModel.cs(자체 뷰 모델. 감시 중인 게임과 함께 MainWindowViewModel.SetupWizard.cs가 만듦), 플래너 engine/SetupWizard/*.cs. 모든 단계가 엔진 명령이므로 CLI도 같은 계획을 만듭니다: engine setup devices (인식과 역할, --role, --grip), engine setup aircraft (우선순위 목록), engine setup plan (--games, --priorities "A>B|C", --modifiers, --prefer-fewer 또는 --use-all-modifiers, --placement(예전 이름 --realism), --phase-layers, --cockpit-file로 넘기는 engine cockpits의 조종석 항목. 계획 JSON을 씀), engine setup render (장치마다 콜아웃 시트 하나), engine setup apply (--plan, 프로필 버전 하나). 이동, 교체, 제거, 되돌리기는 GUI에서 계획을 편집하며(SetupPlanEdit), 적용 전에 다시 검사됩니다. 참고: 설정 마법사.
