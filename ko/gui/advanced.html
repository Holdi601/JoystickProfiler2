GUI 페이지

고급

표시:

고급 페이지는 전문가용 콘솔입니다. 일반 사용자에게 필요한 모든 기능은 다른 페이지에 자체 버튼이 있습니다. 여기서는 엔진 명령줄에 설명된 그대로 JoyPro 엔진의 명령을 직접 입력하며, 답은 출력 패널에 나옵니다.

초보자용

#이 페이지가 필요한가요?

보통은 필요 없습니다. 이 페이지는 세 가지 경우를 위해 있습니다:

  • 누군가(Discord의 도우미, 위키)가 무슨 일이 일어나는지 보려고 profile summary 같은 명령을 실행해 달라고 할 때.
  • 텍스트 편집기에서 여러 관계나 바인딩을 한꺼번에 바꾸고 싶을 때: 관계 편집과 바인딩 편집.
  • 열린 프로필을 빠르게 훑어보고 싶을 때: 프로필 요약.

#명령 실행하기

  1. 명령에 engine이라는 단어 없이 명령을 입력하세요. 예: profile summary 또는 relations list --game DCS.
  2. --profile 포함을 체크된 상태로 두세요. 그러면 명령이 열린 프로필에서 작동합니다.
  3. 실행을 누르세요. 답이 아래쪽의 출력 패널에 나옵니다(닫혀 있으면 하단 바의 출력을 누르세요).
주의

여기서 입력한 명령은 버튼과 똑같이 프로필과 게임을 바꿀 수 있습니다. 프로필의 모든 변경은 기록 내역(위쪽 막대)에 버전으로 남으므로 되돌릴 수 있습니다. 게임 파일은 내보내기 전에 백업됩니다.

고급

#입력 상자

상자 추가되는 것 엔진 옵션
편집기 명령 관계 편집 / 바인딩 편집(그리고 직접 입력한 relations edit / binds edit)에 열리는 프로그램입니다. {file}은 임시 파일을 뜻합니다. 예: code --wait {file}. 비어 있으면 메모장. --editor(전역)
출력 파일 직접 입력한 명령의 답을 출력 패널 대신 이 파일에 씁니다. 여기서 입력한 명령에만 적용되며, 다른 페이지의 버튼은 이것을 쓰지 않습니다. --out(전역)
텍스트 출력 켜짐(기본값): 읽기 쉬운 텍스트. 꺼짐: 스크립트가 읽는 형식의 JSON. 여기서 입력한 명령에만 적용됩니다. --text(전역)
전역 인수 명령 앞에 놓이는 그 밖의 전역 옵션. 예: --status true. 전역 옵션
명령 명령과 그 옵션. 따옴표로 감싸면 공백이 있는 경로가 하나로 유지됩니다. 명령
--profile 포함 --profile "<open profile>"을 추가합니다. 프로필이 필요 없는 명령(db summary, games installs)에는 체크를 해제하세요. --profile
  • 여기서 입력한 relations list와 binds list는 그 답으로 관계 페이지와 바인딩 페이지의 목록도 새로 고칩니다.
  • 마지막 실행의 명령줄은 출력 패널의 첫 줄($ engine --profile ... profile summary)입니다. 이것을 복사하면 터미널에서 똑같이 실행할 수 있습니다.
  • 관계 편집은 모든 관계를 임시 JSON 파일에 쓰고 편집기로 연 다음, 편집기를 닫으면 다시 읽어 들입니다. 관계, 바인딩, 수정키 페이지가 다시 불러와집니다. 실행 취소 한 단계입니다.
기술 정보

#페이지의 내부

뷰 모델: MainWindowViewModel.cs(RunCustomCommandAsync, RelationsEditAsync, BindsEditAsync, RunEngineSummaryAsync, RunProfileSummaryAsync). 인수는 GUI의 모든 버튼이 쓰는 것과 같은 메서드인 RunEngineAsync에서 만들어집니다. 입력한 명령은 TokenizeCli가 나누고(따옴표 존중), 전역 인수가 먼저 오고, 그다음 --profile, --status, --benchmark, --history-note(GUI 자체 변경에만), --out, --editor, 설정의 불러오기 보정 옵션, --text가 옵니다. 프로필을 바꾸는 명령은 프로필 잠금과 함께 실행되며, 다른 모든 변경처럼 기록 내역 버전을 만듭니다.

엔진: engine summary, engine profile summary, engine relations edit, engine binds edit, 그리고 엔진 명령줄의 모든 명령. 참고: GUI와 CLI 대응 (어느 버튼이 어느 명령을 실행하는지).

이 페이지의 바탕이 된 기능 문서(저장소에서 생성):

  • GUI / CLI parity EN
  • Game config backups EN

#이 페이지의 모든 컨트롤

프로그램 소스에서 읽은 조작 요소 7개: 작성됨 7개, 소스의 정보(툴팁, 코드 주석, 엔진 호출)가 있는 것 0개, 아직 보완할 것 0개.

#텍스트 출력

체크 상자작성됨

켜면 여기에 입력한 명령이 읽기 쉬운 텍스트로 답합니다.

끄면 GUI와 스크립트가 읽는 형식인 JSON으로 답합니다.

자세히 보기(영어)

#--profile 포함

체크 상자작성됨

켜면 입력한 명령에 --profile "<open profile>"이 붙어, 열려 있는 프로필을 읽고 바꿉니다.

프로필이 필요 없는 명령에는 체크를 해제하세요.

자세히 보기(영어)

#실행

버튼작성됨

명령에 입력한 명령을 엔진으로 실행하고 결과를 출력 패널에 보여 줍니다. relations list와 binds list는 관계 및 바인딩 페이지도 새로 고칩니다.

프로필을 바꾸는 명령은 실행 취소 한 단계입니다. 게임에 쓰는 명령은 버튼과 마찬가지로 먼저 게임 파일을 백업합니다.

자세히 보기(영어)

#관계 편집

버튼작성됨

프로필의 모든 관계를 하나의 JSON 파일로 편집기에서 엽니다. 편집기를 닫으면 JoyPro가 파일을 다시 읽고 관계, 바인딩, 수정키 페이지를 새로 고칩니다.

실행 취소 한 단계입니다.

자세히 보기(영어)

#바인딩 편집

버튼작성됨

프로필의 모든 바인딩을 하나의 JSON 파일로 편집기에서 엽니다. 편집기를 닫으면 파일을 다시 읽고 페이지를 새로 고칩니다.

실행 취소 한 단계입니다.

#엔진 요약

아무것도 바꾸지 않습니다.
