첫 시작 설정

표시:

"JoyPro2에 오신 것을 환영합니다: 내 게임" 창은 첫 시작 때 JoyPro가 게임을 찾은 뒤 한 번 열립니다. JoyPro가 지원하는 모든 게임이 나오며, 찾은 게임이 먼저 나옵니다. 여기서 가진 게임을 알려 주고, JoyPro가 찾지 않은 곳에 설치된 게임을 연결하고, 게임의 컨트롤을 위한 다른 폴더를 JoyPro에 지정합니다. 같은 창이 설정 > 게임 > 설정 다시 실행에서 다시 열립니다. 새 사용자를 위한 안내는 첫 시작에 있습니다.

각 줄에서 일어나는 일
이 게임을 가지고 있음 체크 해제 JoyPro가 모든 곳에서 그 게임을 숨깁니다. 그 게임의 바인딩은 남습니다.
설치 옆의 찾아보기... 또는 .exe... 그 폴더가 게임이 됩니다. 다른 드라이브에 있는 사본에 좋습니다.
조작 설정 저장 위치 옆의 찾아보기... JoyPro가 그곳에서 게임의 컨트롤을 읽고 씁니다.

그런 다음 아래쪽의 세 버튼 중 하나를 누르세요:

누르는 버튼
다음 단계
완료
JoyPro가 게임을 저장합니다. 첫 시작 때는 환영 화면이 무엇을 하고 싶은지 묻습니다.
완료하고 모두 알아서 설정
JoyPro가 게임을 저장합니다. 그런 다음 빠른 설정이 중요한 기능을 스틱에 둡니다.
나중에
아무것도 바뀌지 않습니다. 첫 시작 때는 다음에 환영 화면이 나옵니다.
초보자용

#게임마다 한 줄

각 줄에는 게임 표지, 이름, 상태가 있습니다:

  • 체크됨, 폴더 있음: JoyPro가 게임을 찾았습니다(어떻게 찾았는지 줄에 나옵니다: Steam, 알려진 위치, Windows 앱 목록).
  • 체크 안 됨: JoyPro가 찾지 못했습니다. 그 게임이 없다면 괜찮습니다. 숨겨진 것이 아니므로 설치하는 즉시 JoyPro가 찾습니다.

할 수 있는 일:

  1. 가지고 있지 않거나 관심 없는 찾은 게임의 체크를 해제하세요: JoyPro 전체(게임 카드, 내보내기 카드, 감시, 게임 목록)에서 숨겨집니다. 그 게임의 바인딩은 프로필에 남습니다.
  2. 다른 곳에 설치한 게임(포터블 사본, 다른 드라이브): 체크하고 설치 옆의 **찾아보기...**를 눌러 폴더를 고르거나, **.exe...**를 눌러 게임 프로그램이나 런처를 고르세요.
  3. 조작 설정 저장 위치: 어떤 게임은 사용자 폴더에 컨트롤을 보관합니다. 다른 곳에 있다면(예: Saved Games\DCS 대신 Saved Games\DCS.openbeta) 그곳의 **찾아보기...**를 누르세요.
  4. 완료를 누르세요. 나중에는 아무것도 바꾸지 않고 창을 닫습니다.
  5. 또는 완료하고 모두 알아서 설정을 누르세요. JoyPro가 게임을 저장하고 스틱을 알아서 설정합니다. 빠른 시작을 보세요.
팁

완료를 누르면 JoyPro가 가진 모든 게임의 명령 목록을 내 설치본에서 만듭니다. 시작 페이지에 진행 상황과 아직 없는 목록에 대한 알림이 나옵니다.

고급

#세부 정보

  • 연결한 폴더는 게임의 표식 파일(bin\DCS.exe, bin\game\Il-2.exe, X4.exe ...)로 확인합니다. 행에는 "표식 발견" 또는 "표식을 찾을 수 없지만 폴더는 선택한 대로 유지됩니다"가 표시됩니다. 연결한 폴더는 모든 작업(가져오기, 내보내기, 명령 목록)에서 설치 폴더로 취급되며, 감지가 이것을 대체하는 일은 없습니다.
  • 감지된 항목 사용(설치 또는 설정)은 내 링크를 잊습니다. JoyPro가 게임을 다시 감지합니다.
  • **가지고 있지 않음 (모든 곳에서 숨김)**은 JoyPro가 찾지 못한 게임에 제공됩니다. 이것을 고르지 않으면 게임은 "설치되지 않음"으로 남고 설치되면 자동으로 나타납니다. 고르면 체크를 해제한 발견된 게임처럼 숨겨집니다.
  • 조작 설정을 설치 폴더에 보관하는 게임(IL-2, Falcon BMS, X-Plane ...)은 설정 위치를 읽기 전용으로 보여 줍니다.
  • 숨긴 게임은 설정 > 게임의 맨 끝에 다시 표시와 함께 나열됩니다.
기술 정보

#창의 내부

창 Views/GameSetupWindow.axaml(폴더 선택기, 완료, 나중에는 .axaml.cs), 뷰 모델 MainWindowViewModel.GameSetup.cs, 행 Models/GameSetupItem.cs. 이 창은 ui-settings.json에 gameSetupDone이 설정되지 않았고 시작 시 감지(engine games installs)가 답했을 때 한 번 열립니다. 완료는 바뀐 행마다 engine games install set (또는 clear), engine games config set (또는 clear)을 실행하고, 숨기거나 표시한 게임에 대해 engine games install disable / enable을 한 번 실행한 뒤, 다시 감지하고, 설정 완료로 표시하고, 없는 명령 목록을 만들기 위해 engine db check-updates를 시작합니다. 참고: 게임 설치.

#이 게임을 가지고 있음

체크 상자작성됨

"이 게임을 가지고 있음": JoyPro가 찾았거나 내가 연결한 모든 게임은 처음에 체크되어 있습니다.

가지고 있지 않은 발견된 게임의 체크를 해제하면 완료를 누를 때 JoyPro 모든 곳에서 숨겨집니다. 전에 숨긴 게임을 체크하면 완료를 누를 때 다시 표시됩니다.

자세히 보기(영어)

#가지고 있지 않음 (모든 곳에서 숨김)

체크 상자작성됨

툴팁 그렇지 않으면 설치되었을 때 JoyPro가 게임을 찾습니다

JoyPro가 찾지 못한 게임에 표시됩니다: 체크하면 완료를 누를 때 체크 해제한 발견된 게임처럼 모든 곳에서 숨깁니다.

체크하지 않으면 게임은 "설치 안 됨"으로 남고, 설치하면 JoyPro가 스스로 찾습니다.

자세히 보기(영어)

#찾아보기...

버튼작성됨

툴팁 게임 폴더를 연결합니다 (포터블 설치, 다른 드라이브). 이 폴더가 설치 위치로 간주됩니다

설치 > 찾아보기...: JoyPro가 찾지 못한 게임의 폴더를 고르세요. 예: 포터블 복사본이나 다른 드라이브에 있는 게임.

JoyPro가 고른 위치에서 게임 폴더를 정하고, 게임을 체크한 뒤 게임의 표시 파일이 있는지 확인합니다.

#찾아보기...

버튼작성됨

툴팁 게임이 조작 설정을 보관하는 위치. 예: Saved Games\\DCS 대신 Saved Games\\DCS.openbeta

조작 설정 저장 위치 > 찾아보기...: 게임이 감지된 위치가 아닌 곳에 조작 설정을 보관할 때 그 위치를 고르세요. 예: Saved Games\DCS 대신 C:\Users\Pilot\Saved Games\DCS.openbeta.

조작 설정을 설치 폴더나 Windows 레지스트리에 보관하는 게임에는 제공되지 않습니다.

자세히 보기(영어)

#감지된 항목 사용

버튼작성됨

툴팁 지정한 설정 위치를 잊고 JoyPro가 다시 찾습니다

행에 내 설정 위치가 있을 때 표시됩니다: 그 위치를 지워, JoyPro가 감지된 위치에서 다시 게임의 조작 설정을 찾게 합니다.

#나중에

이 창을 닫습니다. 아무것도 바뀌지 않습니다.

아무것도 바꾸지 않고 창을 닫습니다: 폴더를 연결하지 않고 게임도 숨기지 않습니다.

다음 시작 때 창이 자동으로 다시 열리지 않습니다. 설정 > 게임 > 설정 다시 실행으로 다시 열 수 있습니다.

#완료

버튼작성됨

게임 목록을 저장하고 이 창을 닫습니다.

선택을 저장하고 창을 닫습니다: 연결한 폴더와 설정 위치가 기록되고, 체크 해제한 발견된 게임은 숨기고 체크한 게임은 표시한 뒤, JoyPro가 게임을 다시 감지하고 가진 게임의 명령 목록을 만듭니다.

단계가 실패하면 창이 열린 채로 남고 어느 게임인지 알려 줍니다.

#완료하고 모두 알아서 설정

버튼작성됨

툴팁 게임을 저장한 다음 JoyPro가 중요한 기능을 스틱과 스로틀에 자동으로 할당하고 결과를 보여 줍니다

게임 목록을 저장합니다. 그다음 JoyPro가 스틱을 설정합니다.

첫 시작 때만: "완료하고 모두 알아서 설정"은 "완료"처럼 게임을 저장한 뒤, 아직 아무것도 할당되지 않은 게임에 대해 JoyPro가 장치를 자동으로 설정합니다.

스틱, 스로틀, 페달을 찾아 각각 일반적인 역할을 주고, 중요한 기능을 조종사가 기대하는 위치에 둡니다.
