GUI 페이지

가상 조이스틱

표시:

어떤 게임은 조이스틱을 몇 개만 받거나, 엉뚱한 것을 잡거나, 다른 장치를 꽂으면 순서를 뒤섞습니다. 가상 모드에서 JoyPro는 게임의 바인딩이 쓰는 모든 축, 버튼, 햇을 가상 조이스틱 하나(vJoy)에 모으거나, 게임패드만 읽는 게임이라면 가상 Xbox 360 패드에 모읍니다. 게임은 입력이 절대 바뀌지 않는 장치 하나를 보고, 프로필은 실제 장치를 그대로 유지합니다. 게다가 가상 기능은 Joystick Gremlin이 하는 일을 합니다: 축 구간을 버튼으로, 토글, 짧게/길게 누르기, 시프트 레이어, 매크로, 모드.

초보자용

#네 단계로 사용하기

  1. 게임 아래에서 게임을 vJoy로 바꾸세요(게임패드만 받는 게임은 Xbox 패드). 장치를 하나만 읽는다고 알려진 게임에는 사용이 있는 추천이 나옵니다. Xbox 컨트롤러만 읽는 게임(ACE COMBAT 8, Hell Let Loose: Vietnam)은 다른 모드를 고르기 전까지 자동으로 Xbox 패드를 쓰며, 페이지에 그 이유가 나옵니다. 목록은 이름순으로 정렬됩니다.
  2. 내보내기 페이지에서 게임을 다시 내보내세요. JoyPro가 바인딩을 가상 조이스틱에 씁니다. 프로필은 실제 장치를 그대로 유지합니다.
  3. 시작을 누르세요. 게임 종류마다 규칙이 하나 있으며, 패드 투어, 도움말, 페이지에서 똑같이 설명합니다:
    • Xbox 패드(ACE COMBAT, Hell Let Loose: Vietnam): 먼저 게임을 시작하고 타이틀 화면을 기다린 다음 시작을 누르세요. 너무 일찍 눌렀나요? 중지를 누른 다음 시작을 누르세요. 이 게임들은 내보내기가 없고 전환도 필요 없으므로 1, 2단계는 건너뜁니다.
    • vJoy: 게임을 시작하기 전에 시작을 누르세요. JoyPro가 HidHide로 그 게임에서 실제 장치를 숨기고(Windows가 한 번 관리자 권한을 묻습니다), 모든 입력을 실시간으로 가상 조이스틱에 복사합니다.
  4. 다 끝나면 중지를 누르세요. HidHide는 이전과 똑같은 설정으로 돌아갑니다. 숨겨진 채로 남는 것은 없습니다.

이 페이지에 필요한 것은 무료 드라이버를 보여 줍니다: vJoy(vJoy로 설정한 게임용), ViGEmBus(Xbox 패드), HidHide(vJoy 게임용). 이것들은 JoyPro의 일부가 아니며, 필요한 것을 그곳에서 클릭 한 번으로 설치하세요. Xbox 컨트롤러만 읽는 게임(ACE COMBAT 8, Hell Let Loose: Vietnam)에는 ViGEmBus만 필요합니다. 이런 게임은 실제 장치를 보지 않으므로 HidHide가 필요 없고 Windows가 관리자 권한을 묻지도 않습니다.

Xbox 전용 게임만 있나요?

그러면 페이지 이름이 가상의 컨트롤러가 되고, 이 게임들에 필요한 것만 보여 줍니다: ViGEmBus 카드, 테스트, 시작. vJoy, HidHide, 모드 목록은 전문가용 세부 정보 표시(vJoy, HidHide, 모드) 뒤에 있습니다. Xbox 전용 게임을 HOTAS로 플레이하기를 보세요.

먼저 테스트하기

테스트는 vJoy나 HidHide를 건드리지 않고 장치를 읽어, 게임이 받게 될 것을 실시간 테스트 탭에 보여 줍니다. 스틱을 움직이고 막대를 보세요.

게임에서: 게임에서 바뀌는 것

게임의 컨트롤 메뉴에는 장치 하나, "vJoy Device"가 보이며 그 버튼과 축에 바인딩이 있습니다. 실제 장치는 가상 조이스틱이 실행되는 동안 그 게임에서만 보이지 않으며, 다른 모든 프로그램은 계속 실제 장치를 봅니다. 곡선, 데드존, 반전은 여전히 JoyPro가 내보내는 게임 자체의 설정에서 옵니다. Xbox 패드에서는 다릅니다. 이 게임들은 내보내기가 없으므로 JoyPro가 각 축 곡선을 직접 적용합니다(바인딩 페이지, 축 응답).

고급

#네 가지 탭

개요: 무엇이고 어떻게 쓰는지. vJoy(버전, 장치), HidHide, JoyPro 세션의 상태(새로 고침, vJoy 장치에 축, 버튼, 햇이 모자랄 때 표에 맞게 vJoy 설정, 충돌 뒤 HidHide 복원, vJoy를 최대치로 설정: 축 8개, 버튼 128개, 햇 4개, Windows 재시작 필요). 이 페이지에 필요한 것. 게임(게임마다 기본 / vJoy / Xbox 패드, 게임이 조이스틱 하나에서 읽는 것과 그 위의 경고). 옵션: 실제 장치 숨기기(HidHide, 권장), 가상 게임이 시작되고 끝날 때 자동으로 시작하고 중지하기(JoyPro가 3초마다 게임을 찾음. vJoy는 게임 전에 시작을 누르는 것이 여전히 가장 안전함. 위의 Xbox 패드 게임은 타이틀 화면 뒤에 시작하는 것이 좋음).

매핑: 표입니다. 가상 게임이 쓰는 각 실제 입력은 가상 조이스틱에서 고정된 자리를 가집니다. 축은 비어 있으면 같은 축을 쓰고(X는 X 그대로), 버튼과 햇은 다음 빈 번호를 받습니다. 기존 자리는 절대 바뀌지 않으므로 게임의 바인딩은 실행할 때마다 같습니다. 매핑 업데이트는 새 입력에 자리를 주고 표를 프로필에 저장합니다.

기능: 가상 기능, 그 모드, Gremlin 가져오기, 그래프(아래).

실시간 테스트: 포워더가 기록하는 대로 각 vJoy 장치의 축 막대, 눌린 버튼과 햇을 포워더 로그와 함께 보여 줍니다. 가상 조이스틱 실시간 표시(모든 게임이 가상의 컨트롤러를 쓰는 플레이어에게는 가상의 컨트롤러 실시간 표시)로 막대를 켜고 끕니다. Xbox 패드에서는 매핑된 각 조작부에 하는 일과 출처가 표시되고("A: Fire machine gun (VKB Gunfighter BTN1)", "LX: Roll (Rhino X)"), 눌린 버튼은 켜집니다.

#Xbox 패드

  • 자동으로: 조이스틱은 읽지 않고 Xbox 컨트롤러만 읽는 게임은 직접 모드를 고르지 않은 동안 Xbox 패드를 씁니다("자동으로 Xbox 패드"). 직접 고른 것이 우선하며 유지됩니다. ViGEmBus 드라이버가 없으면 게임 카드가 그렇다고 알려 주고 클릭 한 번으로 설치를 제안합니다.
  • 축 곡선: 이 게임들은 내보내기를 받지 않으므로 JoyPro가 관계의 축 곡선(데드존, 포화, 곡률 또는 사용자 곡선, 반전. 게임 자체 곡선, 없으면 기본 곡선)을 패드의 스틱이나 트리거에 직접 적용합니다. 바인딩 페이지의 축 응답에 그렇게 표시됩니다. vJoy 게임은 곡선이 내보내기에 들어 있으므로 원래 값을 그대로 받습니다.
  • 패드를 쓰는 게임이 여러 개일 때: 게임마다 자기 패드 표를 가지며, 한 번에 하나만 활성입니다. 자동 시작이면 실행 중인 게임의 표를 씁니다. 시작과 테스트는 실행 중인 게임의 표를, 없으면 "시작"와 "테스트"용 Xbox 패드 테이블에서 고른 표를 씁니다(프로필에 보관).
  • 자동 설정(ACE COMBAT 8 실시간 테스트에서 얻은 것으로, 모든 프로필에 적용): 스로틀이 두 트리거를 모두 움직이고(앞으로 RT, 뒤로 LT), 브레이크 축은 LT를 차지하지 않습니다. LB/RB의 요는 스틱 비틀기에서, 없으면 러더 페달에서 약 30 % 편향으로 옵니다. ACE COMBAT 8의 플레어(L3 + R3 동시, 아직 게임에서 확인되지 않음)는 플레어 / CMS 앞쪽 버튼에서, 윙맨 D-pad는 통신 스위치나 AI 메뉴 햇에서 옵니다. Change target의 햇 방향은 Y를 움직입니다. 코브라 버튼(DCS ASC Direct Control)이나 이름이 "High-G"인 버튼 관계는 High-G 선회를 위해 두 트리거를 모두 누른 채로 둡니다. 입력 하나가 패드 조작부 두 개를 움직이는 일은 없으며, 더 이상 어떤 관계도 채우지 않는 패드 슬롯은 자동으로 사라집니다.
  • 패드에서 반전: DCS의 반전은 패드에 전달되지 않습니다. ACE COMBAT 8의 피치는 기본으로 반대입니다(게임 기본 Pitch Controls에서는 앞으로 밀면 기수가 내려감). 축 응답에서 적용 대상 아래에 그 게임만 체크하고 그 게임의 축을 뒤집으세요. DCS는 자기 설정을 유지합니다. engine vjoy pad-check는 프로필이 패드에서 무엇에 닿는지 보여 줍니다.

#가상 기능

기능은 가상 조이스틱 안에서, 내 장치와 게임이 받는 것 사이에서 실행됩니다. 게임과 종류를 고르고 기능 추가를 누른 뒤, 편집기에서 입력과 출력을 설정하세요.

기능 하는 일
축 구간 축을 최대 16개 구간으로 나누고, 구간마다 버튼 하나(스로틀 디텐트)
버튼 순환 누를 때마다 다음 출력으로 넘어감
토글(래치) 다시 누를 때까지 켜진 채로 있는 누름 버튼
스위치를 켜기/끄기 펄스로 고정식 스위치가 위치마다 펄스 하나를 보냄
짧게 / 길게 / 두 번 누르기 버튼 하나에 일 세 가지
시프트 레이어 시프트 버튼을 누르고 있는 동안 입력이 다른 출력으로 감
축 합치기 / 나누기 페달 두 개를 러더 하나로, 축 하나를 둘로
축 곡선 데드존, 포화, 곡률, 반전, 슬라이더
축 끝을 버튼으로, 축을 햇으로, 버튼을 축으로, 축을 인코더 펄스로 변환
터보, 매크로 누르고 있는 동안 반복. 누름과 키의 연속 동작
햇을 버튼으로, 버튼을 햇으로, 다시 매핑 햇과 다시 매핑
모드 스위치 모드를 바꿈(전환, 누르는 동안, 토글, 순환, 이전으로)

편집기: 이름, 켜짐, 키보드 출력(출력과 매크로 단계가 키를 누를 수 있게 함. 실제로 실행될 때만), 노드 보기(입력 → 기능 → 출력, 출력이 작동하는 동안 켜짐), 가장자리를 끌 수 있는 축 구간 막대, 곡선, 작동 모드, 전환할 모드, 입력(장치와 입력, 지우기), 출력(vJoy 버튼이나 축, Xbox 조작부나 키. 관계 바인딩은 그 출력에 관계를 바인딩), 설정과 매크로 단계. 시험해 보기는 편집기 안에서 슬라이더와 누름 버튼으로 기능을 실행합니다. vJoy나 게임에는 아무것도 가지 않습니다. 저장은 기능을 보관하며, 실행 중인 가상 조이스틱은 중지 후 다시 시작하면 반영합니다.

연결: 입력은 장치 대신 다른 기능의 출력을 읽을 수 있습니다. 입력의 장치 목록에서 ⚙ f1 ...을 고르거나, 모든 기능의 그래프에서 출력 점(오른쪽 가장자리)을 입력 점(왼쪽 가장자리)으로 끄세요. 순환 연결은 거부됩니다. 연결선을 클릭한 뒤 ×를 누르면 연결이 끊깁니다.

모드(레이어): 상황마다(전투, 착륙 ...) 입력에 다른 일을 줍니다. 모드는 다른 모드를 상속할 수 있으며, 기능은 체크한 모드에서 작동합니다(없으면 모든 모드). 모드 추가, 이름 바꾸기, ×(제거), 시작 시(포워더가 시작할 때의 모드). 현재 모드에는 실시간 표시가 붙습니다.

#Joystick Gremlin에서 옮겨 오기

게임을 고르고, 필요하면 게임의 기능과 모드 바꾸기를 체크한 다음 **Gremlin 프로필 가져오기...**를 눌러 .xml(R13 또는 R14)을 고르세요. JoyPro는 먼저 보고서를 보여 줍니다: 무엇으로 바꾸는지, 무엇을 할 수 없는지(활성화 조건, 마우스 동작, Python 플러그인, 소리 ...), 무엇이 가져왔지만 다른지. 가져오기를 누르기 전에는 아무것도 저장되지 않습니다. 모드, 다시 매핑, 곡선, 매크로, 합친 축, tempo, chain, toggle 컨테이너가 기능과 모드가 됩니다. 그다음 게임을 vJoy로 설정하고, vJoy 출력의 관계를 유지하거나 바인딩한 뒤 내보내고 시작하세요. HidHide와 포워더가 Gremlin의 장치 숨기기와 백그라운드 프로그램을 대신합니다.

# 누가 일어나는 일
1 사용자 시작을 누르세요.
2 엔진 vjoy map: 새 입력이 슬롯을 받고, 표는 프로필에 저장됩니다.
3 엔진 vjoy forwarder-config: 표와 기능을 해석한 결과.
4 엔진 vjoy apply-hidhide은 먼저 기록을 쓰고, 그다음 vJoy 게임에서 실제 장치를 숨깁니다(HidHide가 관리자 권한을 한 번 요청합니다). Xbox 컨트롤러만 읽는 게임: "HidHide가 필요 없음", 확인 창 없음.
5 JoyPro.VJoy run --sink vjoy --parent-pid N: 매 회차(예: 1초에 144번) 장치를 읽고, 기능을 실행하고, vJoy 또는 Xbox 패드에 씁니다.

중지:

# 누가 일어나는 일
1 사용자 중지를 누릅니다.
2 JoyPro.VJoy 중지: 출력은 중립, 키는 놓임.
3 엔진 vjoy restore-hidhide이 이전 설정을 그대로 되돌립니다.
  • 매핑 표: 프로필 안(Pr0file.VirtualJoystick). engine vjoy map(--prune, --reset), engine vjoy mode(게임마다 native | virtual | xbox), engine vjoy status, engine vjoy settings(JoyPro가 쓰는 vJoy 장치), engine vjoy configure-vjoy(vJoyConfig. 피하는 축 말고는 아무것도 빼지 않음), engine vjoy limits.
  • 내보내기, 가져오기, 동기화: 가상 게임을 내보내거나 가져오거나 동기화하는 동안에는 바인딩이 vJoy 슬롯을 가리키고, 끝나면 프로필에 실제 장치가 돌아옵니다. vJoy 장치가 없으면 메시지와 함께 내보내기가 멈춥니다.
  • HidHide 세션: engine vjoy apply-hidhide, engine vjoy restore-hidhide, engine vjoy recover: 무엇이든 바꾸기 전에 기록(journal)을 쓰므로 충돌 뒤에도 복원할 수 있습니다(HidHide 복원).
  • 기능과 모드: engine vjoy functions types, engine vjoy functions list, engine vjoy functions add --game, engine vjoy functions set --game, engine vjoy functions remove --game, engine vjoy functions test(시뮬레이션. vJoy로는 아무것도 가지 않음), engine vjoy modes list. 프로필에 게임별로 저장되며(VJoySettings.Functions[game], VJoySettings.Modes[game]), 그 출력은 표에 예약됩니다. 엔진의 테스트, 편집기의 미리 보기, 포워더에서 같은 평가 코드가 실행됩니다. 기능은 매 회차 의존 순서대로 평가되며, 회차마다 메모리를 할당하지 않습니다(기능 50개에 회차당 약 10 µs).
  • Gremlin: engine vjoy import-gremlin(보고서용 --dry-run, --replace, --vjoy-device).
  • 포워더: gui/JoyPro.VJoy(JoyPro.VJoy.exe run --config ... --sink vjoy|dry). 입력은 비독점 DirectInput, 출력은 vJoyInterface.dll / ViGEmBus. 테스트는 dry 싱크를 쓰며 HidHide를 쓰지 않습니다.

vJoy, HidHide, JoyPro의 세션, 게임을 다시 확인하고 페이지를 업데이트합니다.

읽기 전용입니다.

#표에 맞게 vJoy 설정

버튼작성됨

툴팁 vJoyConfig를 한 번 실행하여 (Windows가 관리자 권한을 요청) vJoy 장치가 표에 필요한 축, 버튼, 햇을 갖도록 합니다. 장치에서 아무것도 제거하지 않습니다.

vJoy 장치에 표에 필요한 축, 버튼, 햇이 없을 때 표시됩니다: vJoyConfig를 한 번 실행해 없는 것을 추가합니다.

장치에서 무언가를 빼는 일은 절대 없습니다.

자세히 보기(영어)

#HidHide 복원

버튼작성됨

툴팁 JoyPro가 변경하기 전의 설정으로 HidHide를 되돌립니다 (예: JoyPro나 PC가 비정상 종료된 후).

JoyPro의 HidHide 세션이 열려 있을 때 표시됩니다: JoyPro가 바꾸기 전의 설정을 HidHide에 되돌립니다. 예를 들어 JoyPro나 PC가 충돌한 뒤에 사용합니다.

자세히 보기(영어)

#vJoy를 최대치로 설정

버튼작성됨

툴팁 JoyPro가 사용하는 각 vJoy 장치에 축 8개, 버튼 128개, 햇 4개 (관리자 권한 요청 한 번). 적용하려면 Windows를 다시 시작해야 하며 JoyPro는 Windows를 직접 다시 시작하지 않습니다.

먼저 묻고, vJoyConfig를 한 번 실행해 JoyPro가 쓰는 각 vJoy 장치에 축 8개, 버튼 128개, 햇 4개를 줍니다.

적용되려면 Windows를 다시 시작해야 합니다. JoyPro는 Windows를 절대 다시 시작하지 않습니다.

자세히 보기(영어)

#가상으로 설정된 게임에서 실제 장치 숨기기 (HidHide)

체크 상자작성됨

툴팁 꺼짐: 게임이 실제 장치와 가상 조이스틱을 모두 보게 되어 입력이 이중으로 들어갈 수 있습니다. 권장: 켜기.

기본값은 켜짐: 시작은 가상으로 설정된 게임에서 HidHide로 실제 장치를 숨겨, 게임이 가상 장치만 보게 합니다.

끄면 그 게임들이 실제 장치와 가상 장치를 모두 보게 되어 입력이 두 번 들어갈 수 있습니다.

자세히 보기(영어)

#가상으로 설정된 게임이 시작되고 끝날 때 자동으로 시작/중지

체크 상자작성됨2 ×

기본값은 꺼짐. 켜면 JoyPro가 3초마다 가상으로 설정된 게임을 찾아, 게임이 시작되면 가상 조이스틱을 시작하고 게임이 끝나면 멈춥니다.

일부 게임은 시작할 때만 장치를 찾으므로, 게임보다 먼저 시작을 누르는 것이 여전히 가장 안전합니다.

#매핑 업데이트

버튼작성됨

툴팁 새 입력에 슬롯을 지정하고 표를 프로필에 저장합니다. 이미 슬롯이 있는 입력은 이동하지 않습니다.

매핑 탭: 가상 게임이 쓰는 새 입력마다 가상 조이스틱의 슬롯을 주고 표를 프로필에 저장합니다.

이미 슬롯이 있는 입력은 절대 옮겨지지 않으므로 게임의 바인딩은 그대로 유지됩니다.
