도움말

도움말 및 문제 해결

표시:

짧은 답변부터 보여 드립니다. 각 답변에는 단계별 안내 페이지 링크가 있습니다.

#빠른 답변

ACE COMBAT 8에서 스틱이 작동하지 않아요. ACE COMBAT 8은 Xbox 컨트롤러만 압니다. JoyPro가 스틱을 가상의 컨트롤러(가상 Xbox 패드)로 바꿉니다. 먼저 게임을 시작하세요. 타이틀 화면에서 Alt+Tab으로 JoyPro로 전환한 뒤 시작을 누르세요. HOTAS로 Xbox 전용 게임 하기를 참고하세요.

시작을 누르면 "너무 이릅니다"라고 나와요. 게임이 실행되기 전에 시작을 눌렀기 때문입니다. 게임을 시작하고 타이틀 화면을 기다리세요. 그런 다음 Alt를 누른 채 Tab을 누르고, 중지를 클릭한 뒤 시작을 클릭하세요. Alt+Tab으로 게임으로 돌아가세요.

ViGEmBus는 어떻게 설치하나요? 라이선스 아래의 상자는 뭔가요? ViGEmBus는 무료 도우미 프로그램입니다. 가상의 컨트롤러에 필요합니다. 가상 조이스틱 페이지에서 먼저 라이선스 아래의 상자를 체크하세요. 다운로드에 동의한다는 뜻입니다. 그런 다음 ViGEmBus 설치를 누르세요. Windows가 권한을 요청하면 예를 클릭하세요. 한 번만 하면 됩니다.

설정에서 "드물게 쓰는 추가 조작 일부는 자리가 없었습니다"라고 나와요. 문제가 있나요? 아니요. 스틱의 버튼 수가 게임의 조작 수보다 적을 뿐입니다. 중요한 조작은 모두 스틱에 들어가 있습니다. 설정 창의 일부 변경에서 들어가지 못한 조작을 볼 수 있습니다.

나중에 버튼 하나만 바꾸려면? 바인딩을 열고 목록에서 게임 조작을 클릭한 뒤 입력 기록을 클릭하고 새 버튼을 누르세요. 그런 다음 다시 게임으로 보내세요: 내보내기, 체크한 게임 내보내기. 나중에 버튼 하나 바꾸기를 참고하세요.

빠른 설정을 되돌리려면? 게임 카드(내보내기 페이지)의 마지막 내보내기 취소를 누르면 게임의 예전 버튼 설정이 돌아옵니다. JoyPro 안에서는 Ctrl+Z로 되돌립니다. 빠른 설정 되돌리기를 참고하세요.

내 장치가 JoyPro 목록에 없어요. 그래도 작동합니다. JoyPro는 같은 종류의 일반적인 장치처럼 설정합니다. 스틱을 움직이면 조종되고, 버튼 1은 발사, 첫 번째 햇은 트림, 첫 번째 레버는 스로틀입니다. 지원 파일과 함께 Discord에서 알려 주세요. 지원되는 장치를 참고하세요.

조종석에서 바인딩을 보려면? DCS에서는 니보드에서 볼 수 있습니다. 레이아웃 페이지, 치트 시트, 니보드에 넣기. DCS 니보드에서 바인딩 보기를 참고하세요. 보조 모니터에서는 **무엇이 어디에?**를 사용하세요(자세히).

투어나 환영 화면을 다시 보려면? 오른쪽 위 도움말 > 투어..., 또는 설정 > 투어 > 환영 화면 표시. 또는 JoyPro 폴더에서 JoyPro 2 - Tour를 더블클릭하세요.

쉬운 말이란? 투어와 도움말에서 큰 글씨와 아주 짧은 문장을 쓰는 모드입니다. 환영 화면에서 쉬운 말: 큰 글씨, 짧은 문장을 체크하거나, 설정 > 투어에서 바꾸세요. 쉬운 말, 투어, F1을 참고하세요.

버튼이 무슨 일을 하나요? F1을 누른 다음 버튼을 클릭하세요. 버튼은 실행되지 않고 작은 창에서 설명해 줍니다. 끝내려면 F1을 다시 누르세요.

#문제가 생겼을 때: 지원 파일

도움을 가장 빨리 받는 방법은 지원 파일입니다. 문제를 파악하는 데 필요한 모든 것이 들어 있어서, 다른 파일을 또 보내 달라고 할 필요가 없습니다.

초보자용
  1. 설정 > 문제 신고를 여세요.
  2. **어떤 일이 있었나요?**에 무엇을 했고 무엇을 기대했는지 적으세요.
  3. 열린 프로필과 그 기록 내역 포함은 체크한 채로 두세요(큰 도움이 됩니다. 바인딩과 장치 이름을 공유하고 싶지 않다면 체크를 해제하세요).
  4. 보고서 만들기를 누르세요. JoyPro가 파일에 들어갈 내용을 보여 주면 확인하세요. zip 파일이 Documents\JoyPro2\Problem Reports에 저장되고 탐색기에 표시됩니다.
  5. GitHub 이슈 페이지 열기를 누르고 zip 파일을 이슈에 끌어다 놓거나, Discord에 올리세요.

JoyPro가 직접 업로드하는 것은 없습니다. 파일 안의 모든 텍스트에서 Windows 사용자 이름이 다른 문자로 바뀝니다.

고급

파일에 들어 있는 것: summary.txt(버전, 시스템, 폴더, 게임 환경, 연결된 장치, 제외된 항목), 최소 최근 14일간의 JoyPro 로그(최대 100 MB), 충돌 보고서와 최근 오류, JoyPro의 설정과 상태 파일, vJoy와 HidHide 상태를 포함한 장치, 게임별 감시 기록, 백업 목록과 최신 백업 세트, 그리고 동의한 경우 열려 있는 프로필, 그 기록 내역, 게임의 현재 바인딩 파일, JoyPro 1의 프로필.

기술 정보

지원 파일은 engine support bundle이 만듭니다(--list는 파일을 쓰지 않고 내용만 보여 줌).

#게임 감시 기능이 "변경 내용을 프로필에 반영할까요?"라고 물어요

JoyPro가 관리하는 게임 안에서 조작 설정을 바꾸면, 게임이 종료된 뒤 JoyPro가 변경 내용을 프로필에 반영할지 묻습니다. 그 버튼을 여러 관계가 쓰고 있으면, 변경이 어느 관계에 속하는지 또는 새 관계를 만들지 묻습니다.

  • JoyPro 자신의 내보내기로는 이 질문이 나오지 않습니다. 내보낼 때마다 게임 파일의 상태를 기록하기 때문입니다.
  • 한 게임만 끄려면 시작 페이지 카드의 변경 감시를, 모든 게임을 끄려면 설정 > 게임의

    게임 설정 감시를 사용하세요.

  • JoyPro를 닫아도 계속 감시하려면: 설정 > 백그라운드에서 실행 > Windows와 함께 시작 (알림 영역에서).
기술 정보

엔진: engine sync status, engine sync diff, engine sync apply, engine sync accept. 자세한 내용: 게임 설정 감시 기능.

#자주 묻는 질문

JoyPro 2.7은 더 빨라졌나요? 네, 가장 오래 기다리던 곳에서요. 프로필이 더 빨리 열립니다. 확인은 검색창에 입력하는 동안에도 첫 카드를 바로 보여 줍니다. 시작 페이지는 게임을 백그라운드에서 살펴보므로 창이 느려지지 않습니다. 내보내기 뒤의 클릭도 빠르게 반응하고, 작업을 멈추면 JoyPro가 메모리를 돌려줍니다. War Thunder의 조작 설정은 약 다섯 배 빨리 불러오고, 아주 긴 폴더 경로에 있는 게임도 작동합니다.

내보낸 뒤에도 게임에 바인딩이 보이지 않아요. 내보내는 동안 게임이 닫혀 있었나요? 게임이 실행 중이면 JoyPro는 써넣기를 거부하며, 카드에 그 이유가 표시됩니다. 따로 단계가 필요한 게임도 있습니다. Falcon BMS는 런처에서 Launch를 누를 때 키 파일을 만들고, MSFS에서는 장치에 JoyPro의 프리셋이나 가져오기 파일이 필요할 수 있습니다(해당 게임 페이지 참고). 카드의 결과와 출력 패널을 확인하세요. 게임 아래의 게임별 페이지에 세부 사항이 있습니다. ACE COMBAT 8과 Hell Let Loose: Vietnam은 내보내기를 하지 않고 가상의 컨트롤러를 사용합니다.

게임의 기본 바인딩이 아직 장치에 남아 있어요(DCS). 내 장치에서 교체와 다른 장치도 지우기를 사용하세요. 써넣은 장치는 내보낸 기체에서 DCS의 기본값을 잃습니다. 설정 > DCS: 기본 바인딩에서는 DCS 설치 폴더 자체의 기본값을 끌 수 있습니다.

예전 조작 설정으로 돌아가고 싶어요. 내보내기 페이지의 게임 카드에서 마지막 내보내기 취소를 누르세요. 내보내기 전의 파일이 바이트 하나까지 그대로 복원됩니다. 더 오래된 백업은 내보내기 페이지 맨 아래의 게임 설정 백업에 있습니다.

내보내기에서 "게임에 기록되지 않음"이라고 나와요. 추가만으로 내보냈는데, 게임이 이미 그 버튼을 다른 기능에 쓰고 있기 때문입니다. 확인 결과에 '업데이트'로 내보내 교체하기, 다른 버튼으로 이동, 그대로 두기가 있는 카드가 나옵니다.

스틱 ID가 바뀌었어요 / 장치를 교체했어요. 가져오기는 이름이 같은 장치를 하나의 장치로 취급합니다. 바인딩을 새 장치로 옮기려면 **장치 교체...**를 사용하세요(설정, 레이아웃 페이지의 장치 카드, 또는 바인딩 페이지 메뉴에서 선택한 바인딩의 장치).

게임이 없어요. 설정 > 게임에서 다시 감지를 누르거나, 포터블 설치는 **폴더 선택...**으로 연결하세요. JoyPro가 아직 다루지 않는 게임은 게임 지원에 나와 있습니다.

JoyPro에서 변경을 되돌릴 수 있나요? 네. 위쪽 막대의 실행 취소 / 다시 실행(Ctrl+Z / Ctrl+Y)을 쓰면 되고, 재시작한 뒤에도 됩니다. 기록 내역에는 프로필의 모든 버전이 나와 있습니다.

JoyPro는 안티치트에 안전한가요? JoyPro는 게임 메모리를 읽지 않고 아무것도 주입하지 않으며, 게임이 닫혀 있을 때 설정 파일을 씁니다. 선택 사항인 가상 장치(vJoy, ViGEmBus, HidHide)는 서명된 드라이버이지만, 게임에 따라 가상 장치를 거부할 수도 있습니다. 게임 지원의 게임별 참고 사항을 확인하세요.
