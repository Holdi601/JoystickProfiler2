시작하기

다운로드 및 설치

표시:

JoyPro 2는 무료 오픈 소스(GPL-3.0)입니다. 계정, 가입, 텔레메트리가 없습니다.

초보자용

#세 단계

  1. GitHub의 릴리스 페이지를 열고 (Assets 아래에서) JoyPro2-<version>-win-x64.zip을 다운로드하세요.
  2. zip 파일을 마우스 오른쪽 단추로 클릭하고 **모두 압축 풀기...**를 선택한 뒤, 쓰기 권한이 있는 폴더를 고르세요. 예: C:\JoyPro2 또는 문서 폴더 안의 폴더. (C:\Program Files는 안 됩니다. JoyPro는 자기 폴더 안에서 스스로 업데이트합니다.)
  3. 폴더를 열고 JoyPro.Gui를 더블클릭하세요(조이스틱 아이콘이 있는 프로그램; 파일 확장자를 표시하면 JoyPro.Gui.exe로 보입니다).

Windows가 Windows의 PC 보호라고 표시하나요? 추가 정보를 클릭한 다음 실행을 클릭하세요. Windows는 인터넷에서 내려받은, 아직 모르는 프로그램에 대해 한 번 이것을 묻습니다.

처음 시작하면 JoyPro가 게임을 찾아서 창에 보여 줍니다: 처음 시작을 참고하세요. JoyPro가 처음인가요? 거기서 완료하고 모두 알아서 설정을 누르고 빠른 시작: 내 스틱 작동시키기를 따라 하세요.

그러면 환영 화면이 무엇을 하고 싶은지 묻고, 나에게 맞는 투어를 시작합니다. 같은 폴더의 JoyPro 2 - Tour로 언제든 환영 화면을 다시 열 수 있습니다. 큰 글씨와 짧은 문장을 원하나요? 환영 화면에서 쉬운 말: 큰 글씨, 짧은 문장을 체크하세요(쉬운 말, 투어, F1).

#필요한 것

  • Windows 10 또는 11, 64비트.
  • JoyPro 엔진용 .NET Framework 4.8. Windows 10과 11에는 이미 들어 있으며, 없으면 JoyPro가 Microsoft의 설치 프로그램을 제공합니다.
  • 그 밖에는 필요 없습니다. zip 파일에 모든 것이 들어 있습니다(프로그램을 위해 .NET 9를 따로 설치할 필요가 없습니다).

#업데이트

JoyPro는 시작할 때 GitHub에서 새 버전이 있는지 확인합니다(설정: 시작 시 업데이트 확인). 새 버전이 있으면 변경 내용과 함께 지금 업데이트 / 나중에 / 이 버전 건너뛰기가 있는 창이 열립니다. 프로필과 설정은 그대로 남습니다.

고급

#JoyPro가 파일을 보관하는 곳

프로필은 문서 폴더의 JoyPro2에 있습니다. 문제 보고서도 그곳에 저장됩니다. 업데이트는 프로그램 폴더만 교체하므로 프로필, 설정, 명령 목록, 백업, 기록 내역은 그대로 남습니다. 전체 폴더 목록은 기술 정보에 있습니다.

#선택 구성 요소

설정 > 구성 요소에서 가상 조이스틱 모드용으로 vJoy(가상 조이스틱), HidHide(게임에서 실제 장치를 숨김), ViGEmBus(가상 Xbox 패드)를 동의하에 각각 클릭 한 번으로 설치합니다. 설정 > 로컬 AI에서 도우미용 선택 AI 모델을 내려받을 수 있습니다. 모델이 없어도 모든 기능이 작동합니다.

#온라인 연결

JoyPro가 온라인에 연결하는 경우는 다음뿐입니다: 업데이트 확인(GitHub), 장치 제조사의 제품 사진(장치마다 허락한 후에만), PC에 없는 게임 표지(끌 수 있음), 선택 AI 모델, 선택 구성 요소, 그리고 .NET Framework가 없을 때의 설치 프로그램. 이 사이트들은 사용자의 IP 주소를 볼 수 있습니다. 자세한 내용: 개인 정보 보호.

기술 정보

#JoyPro의 모든 폴더

항목 위치
프로그램 압축을 푼 폴더(engine\engine.exe, vjoy\, tray\, JoyPro가 함께 제공하는 DB\의 데이터 포함)
프로필 Documents\JoyPro2(또는 저장한 위치)
설정 %APPDATA%\JoyPro2(ui-settings.json, export-settings.json, hud.json ...)
PC에서 만든 게임 명령 목록 %LOCALAPPDATA%\JoyPro2\GameData
게임 파일 백업 %LOCALAPPDATA%\JoyPro2\GameBackups(게임마다 최신 30개)
프로필 기록 내역(재시작 후에도 실행 취소) %LOCALAPPDATA%\JoyPro2\ProfileHistory
로그 %LOCALAPPDATA%\JoyPro2\Logs(며칠 뒤 자동 삭제)
문제 보고서 Documents\JoyPro2\Problem Reports

#패키지 내용

  • JoyPro.Gui.exe: Avalonia 앱(.NET 9, 자체 포함).
  • JoyPro 2 - Tour.cmd: JoyPro.Gui.exe --welcome을 실행해 투어가 있는 환영 화면을 엽니다(실행 중인 JoyPro가 있으면 거기에 넘김).
  • engine\engine.exe: 엔진(.NET Framework 4.8). GUI가 모든 작업에 엔진을 실행하며, 콘솔에서 직접 실행할 수도 있습니다(엔진 명령줄).
  • vjoy\JoyPro.VJoy.exe(가상 조이스틱 전달기), JoyPro.Ffb.exe(텔레메트리 포스 피드백), tray\JoyPro.Tray.exe(GUI가 닫혀 있을 때의 감시 기능).
  • 업데이트는 릴리스 zip을 내려받아 게시된 .sha256 파일로 검증한 뒤 설치합니다.
  • 소스에서 빌드: dotnet build gui/JoyPro.Gui/JoyPro.Gui.csproj(엔진도 빌드하며 .NET Framework 4.8 빌드 도구가 필요함). 저장소의 README를 참고하세요.
