초보자용

#"내 게임" 창

JoyPro가 몇 초 동안 게임을 찾습니다. 그런 다음 게임마다 한 줄씩 보여 주는 창이 나타납니다.

보이는 것 뜻 할 수 있는 일
폴더가 있는 체크된 줄 JoyPro가 게임을 찾았습니다. 아무것도 하지 않아도 됩니다. JoyPro에서 쓰고 싶지 않다면 체크를 해제하세요.
체크되지 않은 줄 JoyPro가 게임을 찾지 못했습니다. 게임이 없다면 아무것도 하지 않아도 됩니다. 다른 곳에 있나요? 체크하고 **찾아보기...**를 누르세요.
조작 설정 저장 위치 게임이 조작 설정을 보관하는 곳입니다. 내 설정이 다른 곳에 있다면 거기서 **찾아보기...**를 누르세요. 예: Saved Games\DCS.openbeta.

체크하지 않은 게임도 숨겨지지 않습니다. 설치하면 JoyPro가 찾아냅니다.

#세 버튼

버튼 다음에 일어나는 일
완료하고 모두 알아서 설정 JoyPro가 게임을 저장합니다. 그런 다음 스틱, 스로틀, 페달을 알아서 설정합니다.
완료 JoyPro가 게임을 저장합니다. 그런 다음 환영 화면에서 무엇을 하고 싶은지 묻습니다.
나중에 아무것도 바뀌지 않습니다. 다음으로 환영 화면이 나옵니다.

JoyPro가 처음인가요? 완료하고 모두 알아서 설정을 누르세요. 그런 다음 빠른 시작: 내 스틱 작동시키기를 따라 하세요.

큰 글씨와 짧은 문장을 원하나요? 이 창에서 쉬운 말: 큰 글씨, 짧은 문장을 체크하세요.

이 창은 언제든 다시 열 수 있습니다: 설정 > 게임 > 설정 다시 실행.

#환영 화면

완료나 나중에를 누르면 JoyPro가 한 번 묻습니다: 무엇을 하고 싶으세요? 게임에 맞는 답에는 추천 표시가 붙습니다.

답 시작되는 것
비행 스틱으로 ACE COMBAT 하기 빠른 설정과 가상의 컨트롤러(가상 Xbox 패드).
DCS World 또는 Falcon BMS DCS 방식 투어: 가져오기, 관계, 곡선, 내보내기, 확인.
스틱이 그냥 작동하게 해 주세요 빠른 설정.
둘러보기 안내 JoyPro를 차근차근 천천히 둘러보는 투어입니다.
JoyPro 1을 사용했습니다 JoyPro 1의 각 기능이 지금 어디에 있는지 보여 줍니다. 예전 프로필을 열 수도 있습니다.
투어 없음 없음.

시작을 누르세요. 나중에를 누르면 환영 화면이 닫힙니다. 저절로 다시 나오지는 않습니다. 다시 보려면 쉬운 말, 투어, F1을 참고하세요.

#저장 버튼은 없습니다

프로필을 먼저 만들 필요가 없습니다. JoyPro가 하나 만들어 줍니다. 변경할 때마다 저장합니다(위쪽 막대에 "저장됨"). 실행 취소와 다시 실행은 재시작한 뒤에도 작동합니다.

#세부 정보

  • 다른 곳에 있는 게임(포터블 설치, 다른 드라이브): 체크한 뒤 설치 옆의 **찾아보기...**를 누르거나, **.exe...**로 게임 프로그램을 고르세요.
  • 연결한 폴더는 바로 확인됩니다: "표식 발견" 또는 "표식을 찾을 수 없지만 폴더는 선택한 대로 유지됩니다". 감지된 항목 사용은 연결을 지웁니다.
  • 설치 폴더에 컨트롤을 저장하는 게임(IL-2, IL-2 Korea, IL-2 1946, Falcon BMS, X-Plane, BYOJoystick을 쓰는 VTOL VR)은 위치를 읽기 전용으로 보여 줍니다. 레지스트리 게임(Nuclear Option)도 마찬가지입니다.
  • 숨긴 게임은 모든 곳(내보내기 카드, 감시 기능, 필터, HUD ...)에서 설치되지 않은 것으로 취급됩니다. 그 게임에 대한 관계는 프로필에 남습니다. 설정 > 게임에 숨긴 게임이 다시 표시와 함께 나열됩니다.
  • 완료하고 모두 알아서 설정은 환영 화면에 빠른 방법으로 답합니다: 설정이 열리고, 환영 화면은 그 옆에 열리지 않습니다.

#명령 목록

JoyPro에는 게임마다 명령 목록(이름과 ID)이 필요합니다. 설치본에서 한 번 만듭니다. 시작 페이지에 게임마다 목록 생성 또는 누락된 목록 모두 생성이 있는 알림이 나옵니다. 게임이 업데이트되면 "게임이 업데이트됨: 명령 목록을 업데이트하세요" 카드가 업데이트와 함께 나옵니다.

  • DCS는 게임 창 없이 설치된 모듈로 목록을 만듭니다. IL-2는 게임이 쓰는 키 매핑 파일을 읽습니다. 다른 게임은 자체 파일을 읽습니다(새로 설치했을 때의 명령 목록).
  • Ctrl+S는 프로필을 즉시 저장합니다. 기록 내역에 모든 버전이 나열됩니다.
기술 정보

#내부 작동 방식

  • GUI는 시작할 때 engine games installs를 한 번 실행하고(폴링 없음) 창을 한 번만 보여 줍니다(%APPDATA%\JoyPro2\ui-settings.json의 gameSetupDone). 뷰 모델: MainWindowViewModel.GameSetup.cs, 창: Views/GameSetupWindow.axaml.
  • 완료는 모든 것을 엔진을 통해 씁니다: engine games install set / clear, engine games config set / clear, engine games install disable / enable, 그다음 다시 감지합니다.
  • 연결한 폴더의 표식 파일: bin\DCS.exe, bin\game\Il-2.exe, X4.exe ...
  • 게임별 감지(engine\GameInstalls.cs와 각 GameIntegration): Steam 라이브러리 폴더와 앱 ID, 알려진 설치 위치, Windows 제거 및 앱 목록, 그리고 사용자가 직접 연결한 폴더(감지가 이를 대체하는 일은 없음).
  • 명령 목록: engine db check-updates는 목록이 없는 게임에 no-catalog를 보고합니다. 생성 시에는 게임의 refresh-db를 실행하며(DCS는 engine dcs refresh id + engine dcs refresh clean, engine db refresh-il2, engine db refresh-starcitizen, engine <game> refresh-db), %LOCALAPPDATA%\JoyPro2\GameData에만 씁니다.
