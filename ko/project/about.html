프로젝트

소개, 라이선스, 커뮤니티

표시:

JoyPro는 취미 프로젝트입니다. 한 파일럿이 자기 스틱을 위해 시작했고, 다른 파일럿에게도 도움이 되어 공유하게 되었습니다. JoyPro 2는 같은 아이디어로 JoyPro 1을 잇고, 그 주위에 새 프로그램을 만들었습니다(좋아진 점).

#라이선스

JoyPro는 GNU General Public License 버전 3 이상(LICENSE)에 따른 자유 소프트웨어입니다. 사용하고, 연구하고, 공유하고, 바꿀 수 있습니다. 어떤 보증도 없습니다: JoyPro는 게임 파일을 쓰기 전에 매번 백업하지만, 그래도 직접 백업해 두세요. 서드파티 구성 요소와 그 라이선스는 THIRD_PARTY_NOTICES.md에 있습니다.

#한 단락으로 보는 개인 정보 보호

JoyPro에는 계정도 원격 측정도 없습니다. 온라인에 연결하는 경우는 업데이트 확인(GitHub), 제조사의 장치 제품 사진(장치마다 허락한 뒤에만), PC에 없는 게임 표지(끌 수 있음), 선택 사항인 AI 모델, 설정 > 구성 요소의 선택 사항인 드라이버, 없는 .NET Framework 설치 프로그램뿐입니다. 문제 보고서는 PC에 있는 파일입니다. 직접 어딘가에 첨부하지 않는 한 아무것도 업로드되지 않습니다. 자세히: 개인 정보 보호.

#도움말과 커뮤니티

  • Discord: 질문, 아이디어, 테스트를 위한 discord.gg/yK4gQA9xgk.
  • GitHub 이슈: JoystickProfiler2/issues. 지원 파일을 첨부하세요(방법).
  • 여가 시간에 하는 프로젝트입니다. 가능할 때 도와드리지만, 수정이나 날짜는 약속하지 않습니다.

#기여하기

소스는 GitHub에 있습니다. 아이디어와 문제는 Discord나 GitHub 이슈로 알려 주세요. 이 웹사이트는 소스로 만들어지므로 현재 버전을 설명합니다.

기술 정보

빌드는 dotnet build gui/JoyPro.Gui/JoyPro.Gui.csproj, 테스트는 dotnet test gui/JoyPro.Gui.Tests와 engine/tests/engine_smoke_test.ps1입니다. 아키텍처 지도는 ARCHITECTURE.md입니다. 이 웹사이트는 website/build.py가 소스에서 생성합니다. 새 버튼이나 엔진 명령에는 설명이 필요하며, 없으면 사이트의 완전성 검사가 실패합니다.
