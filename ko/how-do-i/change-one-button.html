어떻게 하나요

나중에 버튼 하나 바꾸기

표시:

JoyPro가 스틱을 설정했거나 직접 설정했습니다. 이제 한 가지 기능에 다른 버튼을 쓰고 싶습니다. 아래 네 단계면 됩니다: 바인딩 페이지에서 세 단계, 그다음 내보내기 한 번.

  1. 바인딩
    아래쪽 막대에서
  2. 게임 조작 선택
    목록에서
  3. 입력 기록
    버튼을 누르세요
  4. 내보내기
    게임으로 보내기
초보자용

#단계별로

  1. 아래쪽 막대에서 바인딩을 여세요. 설정한 모든 것이 거기에 있습니다.
  2. 목록에서 게임 조작을 클릭하세요. 예: "Gear Up/Down". 위의 검색 상자로 빠르게 찾을 수 있습니다.
  3. 입력 기록을 클릭하세요. 그런 다음 스틱의 새 버튼을 누르세요. 축이라면 끝까지 움직이세요.
  4. 다시 게임으로 보내세요. 먼저 게임을 닫으세요. 아래쪽 막대에서 내보내기를 여세요. 체크한 게임 내보내기를 누르세요.

입력 기록은 게임 조작을 고른 뒤에만 나타납니다. 먼저 하나를 고르세요.

#Xbox 전용 게임에서

ACE COMBAT 8과 Hell Let Loose: Vietnam은 내보내기를 하지 않습니다. 가상 조이스틱 페이지에서 중지를 누른 다음 시작을 누르세요. 그러면 가상의 컨트롤러(가상 Xbox 패드)가 새 버튼을 사용합니다.

#실행 취소

버튼을 잘못 눌렀나요? Ctrl+Z를 누르세요. 예전 버튼이 돌아옵니다.

고급

#다른 방법

  • 바꾸려는 버튼을 누르세요. 바인딩 페이지의 입력 따라가기는 누른 버튼의 관계를 엽니다.
  • 그림에서. 레이아웃 페이지의 바인딩 모드에서 입력을 클릭하고, 관계를 고른 뒤 이 입력에 바인딩을 누르세요.
  • 한 게임만. 시작 페이지의 게임 카드에 그 게임용 내보내기가 있습니다.
  • 같은 일을 하는 두 번째 버튼. 기능 하나에 버튼 여러 개를 참고하세요.
  • 같은 버튼을 두 관계에 두는 것은 허용됩니다. 확인이 한 기체에서 두 가지 일이 되는 곳을 알려 줍니다.
기술 정보

#내부 동작

입력 기록은 아무 장치의 다음 입력을 기다렸다가 바인딩을 설정합니다(engine binds set). 내보내기는 내보내기 페이지의 모드로 하는 게임의 내보내기입니다(내보내기). 변경마다 프로필 버전 하나이므로 재시작 후에도 Ctrl+Z가 작동합니다.
