어떻게 하나요

한 기능에 여러 버튼, 여러 동작을 한 번에

표시:

관계는 모든 게임에서 하나의 기능입니다. 예: "Gear Up/Down". 관계는 버튼이나 축 여러 개에 있을 수 있습니다. 그리고 관계의 여러 동작을 한 번에 다룰 수 있습니다.

초보자용

#버튼 두 개에 한 기능

관계에 두 번째 입력을 줄 수 있습니다. 예를 들어 스틱 두 개에 같은 기능을 둘 수 있습니다.

  1. 아래쪽 막대에서 바인딩을 여세요.
  2. 목록에서 관계를 클릭하세요.
  3. 다른 입력 부분을 찾으세요. 다른 입력 기록을 누르세요.
  4. 스틱의 두 번째 버튼을 누르세요(또는 축을 움직이세요).

이제 두 입력이 같은 일을 합니다. 목록의 카드에 +1이 표시됩니다.

  • 기본으로 설정은 그 입력을 기본 입력으로 만듭니다.
  • 제거는 입력을 다시 뺍니다.
입력을 하나만 두는 게임도 있습니다

어떤 게임은 기능마다 입력을 하나만 둡니다. 그런 게임은 기본 입력을 받습니다. 내보내기가 어느 입력이 들어가지 못했는지 알려 줍니다.

#여러 동작을 한 번에

관계 안에서 게임 동작 하나하나가 카드입니다. 카드 여러 개를 한 번에 고를 수 있습니다.

  1. 관계를 열고 관계 하나를 여세요.
  2. Ctrl을 누른 채 원하는 동작 카드를 클릭하세요. Shift+클릭도 됩니다. Ctrl+A는 모두 선택합니다.
  3. "동작 n개 선택됨" 막대가 나타납니다. 할 일을 고르세요:
버튼 하는 일
복사(Ctrl+C) 동작을 기억해 둡니다. 같은 종류의 다른 관계를 열고 붙여넣기(Ctrl+V)를 누르세요.
이동... 동작을 새 관계나 기존 관계로 옮깁니다.
제거(Del) 질문을 한 번 한 뒤 동작을 관계에서 뺍니다.

각각이 한 단계입니다. Ctrl+Z 한 번으로 되돌릴 수 있습니다.

#여러 관계의 동작 옮기기

  1. 관계 목록에서 Ctrl+클릭 또는 Shift+클릭으로 관계 여러 개를 고르세요.
  2. **동작 이동...**을 누르세요.
  3. 새 관계나 기존 관계를 고르세요.

모든 동작이 그 관계 하나로 옮겨집니다. 빈 관계는 삭제됩니다.

고급

#추가 입력 자세히 보기

  • 입력마다 고유한 장치, 수정키, 축 곡선이 있습니다. 장치 두 개에 있는 축이면 축 응답 위쪽에 입력 목록이 있습니다. 입력 1(기본 입력)이나 입력 2를 골라 각자의 곡선을 설정하세요.
  • 직접 선택한 입력 추가는 직접 고른 장치와 입력을 입력 하나로 더 추가합니다.
  • 장치의 모든 바인딩을 다른 장치로 복사: 첫 번째 장치와 두 번째 장치를 고르고 미리 보기를 한 뒤 복사를 누르세요. 첫 번째 장치의 모든 바인딩이 두 번째 장치의 대응하는 입력도 받습니다. 베이스 두 개에 같은 그립을 쓸 때 좋습니다.
  • 모든 페이지가 어느 입력으로든 관계를 찾습니다: 입력 따라가기, 레이아웃 페이지, 장치 필터, 전체로 하는 검색.
  • 내보내기: 게임이 동작마다 입력 여러 개를 저장하면 모든 입력을 기록하며, 기본 입력이 먼저입니다. 하나만 저장하면 기본 입력을 기록하고 나머지는 내보내기가 알려 줍니다. Elite Dangerous는 버튼 두 개, MSFS는 장치마다 두 개, 대부분의 게임은 축 하나를 저장합니다.

#여러 동작 자세히 보기

  • Ctrl이나 Shift를 누른 채 클릭하면 선택만 합니다. 동작의 기체 목록은 열리지 않습니다.
  • 동작의 오른쪽 클릭 메뉴에도 복사와 **다른 관계로 이동...**이 있습니다.
  • 복사와 **이동...**은 꺼진 기체까지 포함해 각 동작의 기체를 유지합니다.
  • 같은 종류의 관계만 제공됩니다: 버튼 관계는 버튼 동작을, 축 관계는 축 동작을 받습니다.
  • 새 관계로 이동...: 이름을 입력하세요. 새 관계는 이전 관계와 같은 종류이며, 바인딩과 그룹이 없습니다.
기술 정보

#내부 동작

추가 입력: Relation.ExtraBinds(입력 1 = 기본 바인딩). 엔진: engine binds extra add, engine binds extra list, engine binds extra move. 여러 동작: engine relations item copy-to, engine relations item move-to, engine relations mass move-actions. 각각 엔진 호출 하나이므로 프로필 버전 하나입니다. 참조: 관계 하나에 입력 여러 개, 여러 동작을 한 번에.
