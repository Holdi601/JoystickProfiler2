시작

JoyPro 2

#모든 비행 게임과 우주 게임에서 모든 장치를 위한 프로필 하나.

JoyPro는 모든 기체와 모든 게임에서 같은 기능을 같은 버튼에 둡니다: 랜딩 기어, 플랩, 대응 수단, 트림, 스로틀. 스틱, 스로틀, 페달을 알아서 설정할 수도 있습니다. 무료 오픈 소스(GPL-3.0)이며, 계정도 원격 측정도 없습니다.

Windows용 다운로드빠른 시작: 내 스틱 작동시키기Discord

#하고 싶은 일 ...

내 스틱 작동시키기JoyPro가 모두 설정합니다. 보고 클릭하기만 하면 됩니다.비행 스틱으로 ACE COMBAT 하기Xbox 컨트롤러만 아는 게임용입니다. JoyPro가 가상의 컨트롤러를 만듭니다.DCS World 또는 Falcon BMS 비행하기모든 기체의 버튼을 한곳에 모읍니다. 게임에서 읽어 오고 다시 써 넣습니다.안내 받기실제 버튼을 가리키는 투어와 모든 버튼의 F1 도움말.JoyPro 1에서 넘어오기예전 기능이 지금 어디에 있는지. 예전 프로필도 그대로 열립니다.

이것은 JoyPro 환영 화면의 답입니다. JoyPro는 처음 시작한 뒤 한 번만 묻습니다.

#2.7의 새 기능

모두 알아서 설정시작 페이지의 카드 하나가 장치를 설정합니다; 처음 시작한 뒤에는 완료하고 모두 알아서 설정.헤드 트래킹JoyPro가 헤드 트래킹이나 VR을 사용하는지 묻고, 주위 둘러보기를 알맞은 곳에 둡니다.한 기능에 입력 두 개같은 기능을 버튼 두 개나 장치 두 개에.무엇이 어디에?장치의 각 버튼이 무엇을 하는지 보세요.DCS 니보드바인딩을 조종석 니보드의 페이지로.F1과 투어모든 버튼에 대한 도움말, 실제 버튼을 가리키는 투어, 쉬운 말.

#JoyPro의 작동 방식

빠른 방법. JoyPro가 대신 해 줍니다.

  1. 모두 알아서 설정
    시작 페이지에서
  2. 이 버튼 사용
    목록 확인
  3. 내 게임에 쓰기
    JoyPro가 백업을 보관합니다
  4. 비행
    버튼이 들어가 있습니다

나만의 방법. 모든 버튼을 직접 정합니다.

  1. 가져오기
    게임의 바인딩
  2. 관계
    기능 하나, 모든 게임
  3. 바인딩
    각각 버튼이나 축 하나
  4. 내보내기
    모든 게임으로
  • **관계(릴레이션)**는 모든 게임과 기체의 동작을 담은 하나의 기능("Gear Up/Down")입니다.
  • 바인딩은 관계가 놓인 버튼이나 축입니다. 관계 하나에 여러 개가 있을 수 있습니다.
  • 내보내기는 이것을 각 게임의 컨트롤 파일에 씁니다. 먼저 백업을 만들며, 실행 취소할 수 있습니다.
  • 나중에 게임에서 무언가 바꾸었나요? 게임이 닫힌 뒤 JoyPro가 그것을 가져올지 묻습니다.

#여기서 시작

다운로드와 설치압축을 풀고 시작하면 끝. 필요한 것과 저장 위치.빠른 시작클릭 몇 번으로 작동하는 버튼.지원되는 장치모든 스틱이 작동합니다. JoyPro가 이름으로 아는 장치 목록.도움말과 FAQ자주 묻는 질문과 문제가 생겼을 때의 지원 파일.어떻게 하나요 ...한 페이지에 하나씩, 짧은 답.10분 만에 첫 프로필빠른 방법과 직접 하는 방법.

#주요 흐름

게임 가져오기게임에서 만든 바인딩을 프로필로 가져옵니다.관계 만들기검색, 체크, 추가; 추천과 자동 그룹.내보내기네 가지 모드와 각 모드가 게임에서 바꾸는 것.확인게임에서 무엇이 잘못될지, 클릭 한 번으로 고치기.

모든 페이지에는 세 가지 수준이 있습니다: 초보자용(PC 지식 불필요), 고급(모든 옵션), 기술 정보(엔진 명령과 코드). 페이지 위쪽의 전환 버튼으로 하나를 고릅니다.

#그 밖의 모든 것

모든 GUI 페이지조작 요소 1097개, 각각 하는 일과 그 뒤에서 실행되는 것.게임36개 타이틀 지원, 57개 조사. 게임마다 한 페이지.엔진 명령줄명령 451개, 모든 옵션과 값.JoyPro 1에서 2로무엇이 좋아졌는지, 숫자와 함께.
