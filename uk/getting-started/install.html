Завантаження та встановлення

Показати:

JoyPro 2 безкоштовний і з відкритим кодом (GPL-3.0). Немає облікового запису, реєстрації й телеметрії.

Для початківців

#Три кроки

  1. Відкрийте сторінку випусків на GitHub і завантажте JoyPro2-<version>-win-x64.zip (у розділі Assets).
  2. Клацніть zip правою кнопкою миші, виберіть Видобути все... і вкажіть теку, у яку можна записувати, наприклад C:\JoyPro2 або теку в Документах. (Не C:\Program Files: JoyPro оновлюється у власній теці.)
  3. Відкрийте теку й двічі клацніть JoyPro.Gui (програма зі значком joystick; якщо розширення файлів показано, вона називається JoyPro.Gui.exe).

Windows пише Windows захистив ваш комп'ютер? Натисніть Докладніше, потім Усе одно запустити. Windows питає про це один раз для програми з інтернету, якої ще не знає.

Під час першого запуску JoyPro шукає ваші ігри й показує їх у вікні: див. Перший запуск. Ви новачок у JoyPro? Натисніть там Готово, і налаштувати все за мене і дотримуйтеся Швидкий старт: як змусити мою ручку керування працювати.

Потім привітання запитує, що ви хочете зробити, і запускає тур, який вам підходить. JoyPro 2 - Tour у тій самій теці будь-коли знову відкриває це привітання. Хочете великий текст і короткі речення? Позначте у привітанні Прості слова: великий текст, короткі речення (Прості слова, тури та F1).

#Що потрібно

  • Windows 10 або 11, 64 біти.
  • .NET Framework 4.8 для рушія JoyPro. У Windows 10 і 11 він уже є; якщо його немає, JoyPro запропонує інсталятор від Microsoft.
  • Більше нічого: у zip є все (програмі не потрібен окремо встановлений .NET 9).

#Оновлення

Під час запуску JoyPro перевіряє на GitHub, чи є новіша версія (налаштування: Перевіряти оновлення під час запуску). Для новішої версії відкривається вікно з тим, що змінилося, і кнопками Оновити зараз / Пізніше / Пропустити цю версію. Ваші профілі й налаштування залишаються.

Розширені

#Де JoyPro зберігає дані

Ваші профілі лежать у папці «Документи», у JoyPro2. Туди ж потрапляють звіти про проблеми. Оновлення замінює лише папку програми: ваші профілі, налаштування, списки команд, резервні копії та історія залишаються. Повний список папок — у розділі «Технічні подробиці».

#Додаткові компоненти

Налаштування > Компоненти встановлює одним клацанням і з вашої згоди: vJoy (віртуальний joystick), HidHide (приховує фізичні пристрої від гри) і ViGEmBus (віртуальний геймпад Xbox) — для режиму Віртуальний joystick. Налаштування > Локальний ШІ може завантажити необов'язкову модель ШІ для помічника; усе працює й без неї.

#Вихід у мережу

JoyPro виходить у мережу лише для: перевірки оновлень (GitHub), фотографій ваших пристроїв від виробників (лише після вашої згоди для кожного пристрою), обкладинок ігор, яких немає на вашому ПК (можна вимкнути), необов'язкової моделі ШІ, додаткових компонентів і інсталятора .NET Framework, якщо його бракує. Ці сайти бачать вашу IP-адресу. Докладніше: Конфіденційність.

Технічні подробиці

#Усі папки JoyPro

Що Де
Програма папка, яку ви розпакували (з engine\engine.exe, vjoy\, tray\ і даними, що постачаються з JoyPro, у DB\)
Ваші профілі Documents\JoyPro2 (або де ви їх зберігаєте)
Налаштування %APPDATA%\JoyPro2 (ui-settings.json, export-settings.json, hud.json ...)
Списки команд ігор, створені на вашому ПК %LOCALAPPDATA%\JoyPro2\GameData
Резервні копії файлів ігор %LOCALAPPDATA%\JoyPro2\GameBackups (30 найновіших для кожної гри)
Історія профілю (скасування після перезапуску) %LOCALAPPDATA%\JoyPro2\ProfileHistory
Журнали %LOCALAPPDATA%\JoyPro2\Logs (видаляються самі через кілька днів)
Звіти про проблеми Documents\JoyPro2\Problem Reports

#Що в пакеті

  • JoyPro.Gui.exe: застосунок Avalonia (.NET 9, автономний).
  • JoyPro 2 - Tour.cmd: запускає JoyPro.Gui.exe --welcome — привітання з його турами (передає його вже запущеному JoyPro).
  • engine\engine.exe: рушій (.NET Framework 4.8). GUI запускає його для кожної дії; ви також можете запустити його в консолі (командний рядок рушія).
  • vjoy\JoyPro.VJoy.exe (пересилання на віртуальний joystick), JoyPro.Ffb.exe (Force Feedback з телеметрії), tray\JoyPro.Tray.exe (спостерігач, коли GUI закрито).
  • Оновлення завантажує zip випуску, перевіряє його за опублікованим файлом .sha256 і встановлює.
  • Збирання з вихідного коду: dotnet build gui/JoyPro.Gui/JoyPro.Gui.csproj (також збирає рушій; потрібні інструменти збирання .NET Framework 4.8), див. README репозиторію.
