Páginas da interface

Avançado

Mostrar:

A página Avançado é a consola para especialistas. Cada função de que um utilizador normal precisa tem o seu próprio botão nas outras páginas; aqui escreve você mesmo os comandos do motor do JoyPro, exatamente como a linha de comandos do motor os descreve, e a resposta aparece no painel Saída.

Para iniciantes

#Preciso desta página?

Normalmente não. Está lá para três casos:

  • Alguém (um ajudante no Discord, a wiki) pede-lhe para executar um comando, por exemplo profile summary, para ver o que se passa.
  • Quer mudar muitas relações ou atribuições de uma vez num editor de texto: Editar relações e Editar atribuições.
  • Quer uma visão geral rápida do seu perfil aberto: Resumo do perfil.

#Executar um comando

  1. Escreva o comando em Comando sem a palavra engine, por exemplo profile summary ou relations list --game DCS.
  2. Deixe Incluir --profile marcado: o comando trabalha então no perfil que tem aberto.
  3. Prima Executar. A resposta aparece no painel Saída em baixo (prima Saída na barra inferior se estiver fechado).
Cuidado

Os comandos escritos aqui podem mudar o seu perfil e os seus jogos exatamente como os botões. Cada alteração do perfil é uma versão no Histórico (barra superior), por isso pode voltar atrás; os ficheiros dos jogos têm backup antes de uma exportação.

Avançado

#As caixas

Caixa O que acrescenta Opção do motor
Comando do editor O programa que abre para Editar relações / Editar atribuições (e para relations edit / binds edit escritos à mão). {file} representa o ficheiro temporário, p. ex. code --wait {file}. Vazio: Bloco de Notas. --editor (global)
Ficheiro de saída Escreve a resposta de um comando escrito à mão neste ficheiro em vez de no painel Saída. Só para comandos escritos aqui; os botões das outras páginas nunca o usam. --out (global)
Saída de texto Ligado (predefinição): texto legível. Desligado: JSON, tal como os scripts o leem. Só para comandos escritos aqui. --text (global)
Argumentos globais Quaisquer outras opções globais colocadas antes do comando, p. ex. --status true. as opções globais
Comando O comando e as suas opções. As aspas mantêm junto um caminho com espaços. os comandos
Incluir --profile Acrescenta --profile "<open profile>". Desmarque-o para comandos que não precisam de perfil (db summary, games installs). --profile
  • relations list e binds list escritos aqui também atualizam as listas das páginas Relações e Atribuições com a resposta.
  • A linha de comando da última execução é a primeira linha do painel Saída ($ engine --profile ... profile summary): copie-a para executar o mesmo num terminal.
  • Editar relações escreve todas as relações num ficheiro JSON temporário, abre-o no seu editor e volta a lê-lo quando o editor fecha; as páginas Relações, Atribuições e Modificadores recarregam. Um só passo de desfazer.
Detalhes técnicos internos

#Por trás da página

View model: MainWindowViewModel.cs (RunCustomCommandAsync, RelationsEditAsync, BindsEditAsync, RunEngineSummaryAsync, RunProfileSummaryAsync); os argumentos são construídos em RunEngineAsync, o mesmo método que todos os botões da GUI usam. Um comando escrito é dividido por TokenizeCli (respeitando as aspas), os argumentos globais vêm primeiro, depois --profile, --status, --benchmark, --history-note (só para as alterações da própria GUI), --out, --editor, as opções de correção ao carregar das Configurações e --text. Um comando que altera o perfil corre com o bloqueio do perfil e cria uma versão no histórico como qualquer outra alteração.

Motor: engine summary, engine profile summary, engine relations edit, engine binds edit, e todos os comandos da linha de comandos do motor. Referência: Paridade entre GUI e CLI (que botão executa que comando).

#Incluir --profile

Caixa de verificaçãoescritos

Ativado: o comando escrito recebe --profile "<open profile>", por isso lê e altera o perfil que tem aberto.

Desmarque-o para comandos que não precisam de perfil.

Mais detalhes (em inglês)

#Executar

Botãoescritos

Executa o comando escrito em Comando através do motor e mostra a resposta no painel Saída. relations list e binds list também atualizam as páginas Relações e Atribuições.

Um comando que altera o perfil é um passo de desfazer; um comando que escreve num jogo faz primeiro backup dos ficheiros do jogo, tal como os botões.

Mais detalhes (em inglês)

#Editar relações

Botãoescritos

Abre todas as relações do perfil como um único ficheiro JSON no seu editor; quando fecha o editor, o JoyPro lê o ficheiro de novo e as páginas Relações, Atribuições e Modificadores são recarregadas.

Um passo de desfazer.

Mais detalhes (em inglês)

#Editar atribuições

Botãoescritos

Abre todas as atribuições do perfil como um único ficheiro JSON no seu editor; ao fechar o editor, o ficheiro é lido de novo e as páginas são recarregadas.

Um passo de desfazer.

Mais detalhes (em inglês)

#Resumo do motor

Botãoescritos

Uma contagem numa só linha no painel Saída: relations=..., binds=..., modifiers=... do perfil que o motor carregou.

Não altera nada.
