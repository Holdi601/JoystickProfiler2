Páginas da interface

Iniciar

Mostrar:

A página Início é onde o JoyPro abre. Mostra o que está configurado, o que fazer a seguir, e os seus jogos: Importar leva para o JoyPro as atribuições que fez num jogo; Exportar escreve-as de volta. A importação passo a passo: Importar um jogo.

Para iniciantes

#De cima para baixo

  • Avisos: requisitos em falta, listas de comandos para criar ou atualizar, um relatório de falha para enviar, uma atualização.
  • Configure os seus dispositivos: o cartão de configuração automática. O JoyPro vê (só leitura) quais dos seus jogos ainda não têm nada atribuído e diz os nomes: "Configure os seus dispositivos para War Thunder e Star Citizen". Configurar tudo por mim (o botão azul) faz tudo sozinho; Configurar passo a passo... abre o assistente de configuração com estes jogos marcados. Os jogos onde fez atribuições você mesmo aparecem por baixo: Importar e depois preencher lacunas traz primeiro as suas atribuições, e depois a configuração só usa os controlos livres. Jogos que já estão no seu perfil: Preencher lacunas.... O que está onde? mostra os seus dispositivos com o que cada controlo faz.
  • O perfil num relance: relações (e quantas são eixos), quantas estão atribuídas, modificadores, dispositivos ligados, jogos instalados.
  • Próximos passos: o que o JoyPro sugere agora ("3 relações ainda não têm botão: Atribuir", "VPforce Rhino FFB Base ainda não é usado: Atribuição automática", "Escreva as suas atribuições nos seus jogos: Exportar").
  • Os seus jogos: um cartão por jogo com Importar, Exportar, Atualizar (a lista de comandos dele), Desfazer exportação, Monitorizar alterações e um botão para ocultar. Configurar os meus dispositivos automaticamente... inicia o assistente de configuração.
  • Os seus dispositivos: os dispositivos ligados com as suas imagens; um clique abre a página Layout. Um Que punho? ou Que modelo? a laranja num dispositivo significa que o JoyPro não sabe qual é: um clique nele abre a página Layout com a escolha aberta, e a sua resposta fica guardada.
  • Atividade recente por jogo e o interruptor do monitor de jogos; o cartão HUD.
Avançado

#O assistente de importação

  1. Escolha um jogo (Importar no seu cartão).
  2. Escolha como: Adicionar ao meu perfil (recomendado) ou Recomeçar a partir deste jogo, o teclado, os dispositivos que não estão ligados, as aeronaves do DCS. Ver primeiro mostra o que o jogo tem no painel Saída sem alterar nada.
  3. Importar agora: o resultado fica por cima dos cartões ("Concluído: o seu perfil tem agora 214 relações") com Ver as minhas relações.

Por baixo dos cartões, a importação avançada oferece todas as opções por jogo (DCS, IL-2, Star Citizen e todos os outros jogos de Carregar jogos) com Scan / Import / Export.

Detalhes técnicos internos

#Por trás da página

MainWindowViewModel.GameHub.cs (cartões, assistente), MainWindowViewModel.Design.cs (painel), MainWindowViewModel.DbUpdates.cs (listas de comandos), MainWindowViewModel.DeviceCenter.cs (dispositivos), MainWindowViewModel.GameSync.cs (monitor). Motor: engine games installs, engine db check-updates, engine hud devices, engine sync status, engine dcs import / engine dcs scan e a importação e o scan dos outros jogos.

#Para o comando antes de escrever o que quer que seja (o JoyPro só oferece isto enquanto lê)

Botãoescritos

O JoyPro só o oferece enquanto o comando ainda está a ler, por isso nada foi escrito quando ele para.

#Tratar dispositivos com o mesmo nome como um só dispositivo (o ID mudou com o tempo)

Caixa de verificaçãoescritos2 ×

Dica O Windows dá de vez em quando um novo ID a um dispositivo. Ligado: as suas atribuições são lidas como um só dispositivo, no ID ligado (senão o mais recente). Dois dispositivos idênticos ligados ao mesmo tempo ficam separados.

Importação do DCS: o Windows dá de vez em quando um novo ID a um dispositivo.

Ativado, as atribuições dos seus IDs são lidas como um só dispositivo, no ID ligado; dois dispositivos idênticos ligados ao mesmo tempo ficam separados.
