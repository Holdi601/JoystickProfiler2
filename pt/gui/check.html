Páginas da interface

Verificar

Mostrar:

Verificar na barra inferior executa a verificação do perfil e mostra os resultados na página Exportar em Problemas encontrados pela verificação. O que cada tipo de cartão significa e como funcionam as correções: A Verificação.

Para iniciantes

#Usar a lista

  • A linha no topo conta os cartões: "Para ver: 0 erros, 1 aviso, 0 notas".
  • Pesquisa encontra cartões por relação, aeronave, botão e comando.
  • A primeira caixa mostra um tipo (Todos os problemas, erros, avisos, notas); a segunda ordena-os (Por relação, Por aeronave, Por jogo, Por certeza).
  • Expandir tudo / Recolher tudo abrem ou fecham todas as secções.
  • O botão azul com um visto num cartão é a sugestão do JoyPro; Mais tem as outras correções; Abrir '' salta para a relação com os comandos do cartão marcados.
  • Ignorar num cartão mantém as atribuições como estão e oculta o aviso. Volta sozinho, marcado como Novo e "Mostrado de novo: agora também em ...", quando o comando cai em mais um botão. Assim percorre a lista uma vez e depois só vê o que é novo.
  • Avisos ignorados (n) (só enquanto tiver ignorado alguns) lista os ocultos com Mostrar de novo para cada um e Mostrar todos de novo. Escrever "ignore list", "hidden" ou "muted" na pesquisa também a abre.
Avançado

#Corrigir muitos de uma vez

Corrigir tudo com uma regra aplica uma regra a todos os cartões de uma secção, Corrigir com IA aceita uma instrução em palavras simples; ambos mostram uma Pré-visualização com uma marca por alteração, Aplicar as marcadas aplica-as como um só passo de desfazer. Também logo após importações e adoções executa automaticamente as correções seguras depois de uma importação.

Detalhes técnicos internos

Views/Controls/CheckProblemsPanel.axaml, ViewModels/MainWindowViewModel.CheckCards.cs, MainWindowViewModel.Duplicates.cs, Models/CheckIssueModels.cs. Motor: engine profile validate, engine relations conflicts, engine relations duplicates, engine export-marks list.

Mais detalhes (em inglês)

#Também logo após importações e adoções

Caixa de verificaçãoescritos

Dica Quando uma importação ou adoção coloca uma ação numa segunda relação, o JoyPro corrige-a de imediato se tiver pelo menos esta certeza; o resto fica aqui para si.

Desligado por predefinição: quando uma importação ou a adoção de alterações do jogo coloca uma ação numa segunda relação, o JoyPro aplica de imediato a correção sugerida se tiver pelo menos tanta certeza como indica o controlo deslizante; o resto fica na verificação para si.

O aviso da importação diz quantas foram corrigidas.

#Corrigir tudo com uma regra

Botão de alternarescritos

Abre o painel de regras: uma regra para todos os cartões da secção; Pré-visualizar lista cada alteração com uma marca antes de acontecer qualquer coisa.

Mais detalhes (em inglês)

#Corrigir com IA

Botão de alternarescritos

Abre a caixa Corrigir com IA: descreva numa frase onde pertencem as ações de "ações ativadas em várias relações", por exemplo "manter as funções de trim nas relações Trim, tudo o resto nas relações Mode Button".

O JoyPro lê sozinho frases simples; a IA local opcional só ajuda com o resto.

Não altera nada.
