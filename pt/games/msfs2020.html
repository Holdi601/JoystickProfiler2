Microsoft Flight Simulator 2020

Mostrar:

O MSFS 2020 guarda um perfil de controlos por dispositivo, usado para todas as aeronaves. Na versão Steam, cada perfil é um pequeno ficheiro XML na pasta remote do Steam para o simulador; o JoyPro lê estes ficheiros para o seu perfil e escreve as suas atribuições de volta neles, no sítio. Os perfis da versão Microsoft Store são importados, não escritos. Ao contrário do MSFS 2024, não há pacote de predefinições, nem ficheiro de importação, nem perfil por aeronave.

Para iniciantes

#Pôr a funcionar em 3 passos

  1. Configurar tudo por mim
    na página Início
  2. Usar estes botões
    veja primeiro a lista
  3. Escrever no meu jogo
    com o simulador fechado

Antes: crie uma vez no simulador um perfil para cada dispositivo (Settings > Controls). O JoyPro só escreve a versão Steam; a versão Microsoft Store só pode ser importada.

Depois: inicie o simulador. As suas atribuições estão em Settings > Controls, em todas as aeronaves.

Já atribuiu botões no MSFS 2020 antes? Então a página Início oferece Importar e depois preencher lacunas. As suas atribuições ficam, e só os botões livres recebem novas funções. Veja Início rápido: pôr o meu manche a funcionar.

#O que o JoyPro faz pelo MSFS 2020

  • Importar: o perfil de cada dispositivo ligado (Steam ou Microsoft Store) entra no seu perfil: atribuições de voo, atribuições General (câmaras, vistas, pausa) e as configurações de eixo da página Sensitivity.
  • Relações: uma relação é uma função. Uma relação aplica-se a todas as aeronaves, porque o MSFS 2020 tem um perfil por dispositivo.
  • Exportar: o JoyPro edita os perfis de dispositivo na pasta remote da versão Steam. O simulador lê-os no próximo arranque.

#Importar as suas atribuições do MSFS 2020

  1. Abra Iniciar e prima Importar no cartão do Microsoft Flight Simulator 2020.
  2. Importar também dispositivos que não estão ligados (desligado): o MSFS guarda os perfis de todos os dispositivos que alguma vez viu; desligado significa só os dispositivos ligados agora. Importar também predefinições padrão que o simulador pode não usar (desligado) adiciona a predefinição que o simulador traz para um dispositivo sem perfil próprio, mesmo quando não se sabe se o simulador a usa.
  3. Prima Importar agora, ou Ver primeiro para ver o que o simulador tem sem alterar o seu perfil.

#Criar e verificar relações

Crie relações na página Relações como em todos os jogos (veja o fluxo das relações) e depois execute a Verificação na página Exportar. Aqui, a Verificação não assinala como erro o acelerador de um avião e o coletivo de um helicóptero no mesmo eixo: o MSFS 2020 não tem listas de aeronaves separadas.

#Exportar para o MSFS 2020

  1. Feche o MSFS 2020. O JoyPro recusa escrever enquanto o simulador está a correr.
  2. Abra Exportar, mantenha Substituir nos meus dispositivos com Limpar também os meus outros dispositivos se é no JoyPro que configura os seus dispositivos, e prima Exportar agora no cartão do MSFS 2020.
  3. Inicie o simulador. A pasta remote é uma pasta do Steam Cloud, por isso o Steam sincroniza os ficheiros alterados.
No jogo: O que vê no MSFS 2020

Abra Settings > Controls e escolha o seu dispositivo: as suas atribuições estão no perfil do dispositivo, com os nomes de ações do simulador, e a página Sensitivity do dispositivo mostra as curvas de eixo que o JoyPro escreveu. O mesmo perfil é usado em todas as aeronaves.

#O que faz você mesmo no MSFS 2020

  • Crie uma vez no simulador um perfil para cada dispositivo (Settings > Controls). O JoyPro só edita perfis existentes; para um dispositivo sem perfil, a exportação diz "crie primeiro um no simulador".
  • Versão Microsoft Store: o JoyPro importa os seus perfis, mas não os consegue escrever. Use a versão Steam para a exportação, ou defina as atribuições no simulador.
  • Relações limitadas a aeronaves: o MSFS 2020 não as consegue manter separadas. No formulário Outros jogos da página Início, Aeronave a exportar exporta também as relações limitadas a uma aeronave, para todas as aeronaves.

#Erros comuns

  • "O MSFS 2020 está a correr": feche o simulador e exporte outra vez.
  • O simulador mostra as suas atribuições antigas: o Steam Cloud repôs uma cópia mais antiga. Feche o simulador e exporte outra vez.
  • Um dispositivo tem vários perfis: o JoyPro usa o que foi escolhido com Perfil do jogo no formulário Outros jogos, ou o único que existe; caso contrário, o dispositivo é ignorado com um aviso que lista os nomes.
  • Falta uma atribuição: uma ação guarda no máximo duas combinações de entrada (Primary e Secondary); uma terceira é assinalada e deixada de fora.
Avançado

#Ficheiros que o JoyPro lê e escreve

Ficheiro O que é
<Steam>\userdata\<id>\1250410\remote\inputprofile_<n> um perfil de dispositivo, XML sem extensão; escrito no próprio sítio (primeiro um backup .jpbak)
<Steam>\userdata\<id>\1250410\remote\profile_00 o índice binário dos perfis de dispositivo do simulador: só leitura, nunca escrito
%LOCALAPPDATA%\Packages\Microsoft.FlightSimulator_8wekyb3d8bbwe\SystemAppData\wgs\<user>\ a gravação da Microsoft Store: só leitura (importação e análise)
<install>\Input\*.xml, o fs-base\en-US.locPak as predefinições que o simulador traz e os seus nomes de menu: só leitura
%LOCALAPPDATA%\JoyPro2\Ownership\MSFS, ...\Backups\MSFS os dados de propriedade e os backups do JoyPro, nunca na pasta da Steam

A pasta remote da Steam é uma pasta da Steam Cloud. Só são editados ficheiros inputprofile_* existentes: o profile_00 do simulador nomeia ficheiros específicos, por isso um ficheiro novo não seria usado.

#Os modos de exportação no MSFS 2020

Modo O que acontece nos perfis de dispositivo
Só adicionar Uma atribuição só é escrita onde o perfil não tem outra ação nessa combinação de entradas; caso contrário é listada em "Atribuições não escritas, botão ocupado no jogo". Nada é removido.
Atualizar, manter atribuições do jogo A outra ação na sua combinação perde-a; tudo o resto fica, também a combinação antiga de uma ação.
Atualizar, o meu perfil ganha Como acima, e cada ação que atribui perde as suas outras combinações nos perfis dos dispositivos ligados.
Substituir nos meus dispositivos Os perfis dos dispositivos ligados a que o JoyPro atribui ficam só com as suas atribuições.
+ Limpar também os meus outros dispositivos Os perfis dos dispositivos ligados sem atribuições no seu perfil são limpos.

#O que nunca é tocado

  • Os contextos de menu, mapa do mundo e programador (MENU, MENU_*, WORLDMAP_*, DEBUG, DEVMODE*, EDITOR_*, MISSION_FLOW_TOOLS), em todos os modos.
  • Os perfis de teclado, rato e comando (GUID="{0}"): as atribuições de teclado não são escritas no MSFS.
  • Os perfis de dispositivos que não estão ligados, o profile_00, a gravação da Store, os dispositivos ignorados da importação e o dispositivo vJoy para onde o JoyPro encaminha.

#Curvas e o resto

  • Granularidade: um perfil por dispositivo, para todas as aeronaves.
  • Curvas de eixo: a página Sensitivity do dispositivo, um conjunto por eixo físico: Sensitivity + e -, Neutral, Dead zone, Extremity dead zone, Reactivity, a opção sem curva e a inversão. O MSFS 2020 não tem substituição por ação: uma relação que peça uma recebe a página do dispositivo e um aviso. A pré-visualização da curva coincide com o simulador (medida no MSFS 2020). O âmbito de ajuste family:msfs abrange os dois simuladores; veja axis-curves.
  • Force feedback: o MSFS não tem nenhum próprio.
  • Gravação de telemetria: através do SimConnect, só leitura, com o SimConnect.dll da pasta de instalação do simulador (ou o do MSFS SDK; o JoyPro não traz nenhum).
  • HUD: o HUD encontra o simulador pelo seu processo (FlightSimulator) e mostra as suas atribuições.
  • Monitor de jogos: o JoyPro monitoriza os ficheiros inputprofile_* e o containers.index da gravação da Store, e pergunta depois de o simulador fechar (o monitor de jogos).

#O que é diferente do MSFS 2024

MSFS 2020 MSFS 2024
Destino da exportação os perfis da Steam, no próprio sítio os seus próprios perfis (Steam e Store), o pacote de predefinições do JoyPro, ficheiros de importação
Versão da Microsoft Store só importada importada e escrita
Perfis um por dispositivo por dispositivo e categoria, escolhidos por aeronave
Relações limitadas a aeronaves só com Aeronave a exportar (e então para todas as aeronaves) escritas nos perfis dessas aeronaves
Lista de ações num perfil só as ações atribuídas todas as ações dos seus contextos
Substituição de eixo por ação não sim
Detalhes técnicos internos

#Por dentro da integração do MSFS 2020

Código: engine\Games\MsfsIntegration.cs (uma classe para os dois simuladores, sim == 2020), MsfsProfileFile.cs (o editor por linhas), MsfsUserProfiles.cs (leitura Steam e Store), MsfsSimDefaults.cs, MsfsGameData.cs, MsfsAircraft.cs, engine\AxisModels\Msfs.cs.

  • Formato: um fragmento XML (lido com conformidade de fragmento): <Version>, <FriendlyName>, <Device DeviceName GUID ProductID>, <Axes> com <Axis AxisName AxisSensitivy AxisDeadZone ...> (os nomes de atributos com erros ortográficos são do simulador), <Context ContextName> / <Action ActionName Flag> / <Primary> / <Secondary> / <KEY Information>code</KEY>. Uma ação libertada é removida; uma ação nova vai para o contexto que tem nos outros perfis da pasta, senão para o seu contexto do catálogo, senão para PLANE (com um aviso).
  • Dispositivos: GUID é o GUID de instância DirectInput, por isso a leitura não precisa de nenhum dispositivo ligado; ProductID é o product ID USB em decimal. Códigos: botão N = N-1, hat 256-259, eixos 1026/1042/1058, 770/786/802, sliders 514/530; a última KEY de uma combinação é a entrada principal, os outros botões do mesmo dispositivo são modificadores.
  • Lista de comandos: engine msfs2020 refresh-db lê as predefinições do simulador (<install>\Input, os seus pacotes oficiais) e todos os eventos de voo que o en-US.locPak nomeia; partilha o seu início com a lista do MSFS 2024.
  • Comandos: engine msfs2020 paths, engine msfs2020 catalog, engine msfs2020 scan, engine msfs2020 import (--game-profile, --include-disconnected, --include-sim-defaults), engine msfs2020 export (--mode, --nuke-untouched-devices, --dry-run, --aircraft <key>); desfazer com engine backups restore.
  • Perfis antigos: os perfis guardados quando o JoyPro tinha um só jogo MSFS (MSFS:<action>) recebem um nó para cada simulador quando são carregados.

#Limites conhecidos

  • A versão Microsoft Store é só de leitura; uma exportação com a pasta de gravação dela como caminho é recusada.
  • Não são criados ficheiros inputprofile_* novos; um dispositivo precisa de um perfil criado no simulador.
  • A Steam Cloud pode repor um perfil mais antigo.
  • Os meios eixos, as diagonais dos hats e um segundo hat não são lidos nem escritos; no máximo duas combinações por ação.
  • As predefinições incluídas no MSFS 2020 não foram verificadas numa instalação real, por isso uma predefinição de 2020 também tem de ter o nome do dispositivo para ser tomada como predefinição.
  • Testes: engine\tests\smoke\msfs.ps1 (página Sensitivity, substituições, opções, conflitos, junção); no simulador tools\e2e\games\MsfsCurves.ps1 (atribuições, a página Sensitivity, botões e curvas de eixo num voo, lidos de volta através do SimConnect).
