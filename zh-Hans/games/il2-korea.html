显示：

IL-2 Series: Korea 与 IL-2 Great Battles 同属一个系列，但它用一种新的 JSON 格式保存按键映射：所有飞机共用一个配置（“General”），位于游戏安装目录中。JoyPro 会把它读入你的配置文件，通过关联把它的操作与你的其他游戏连接起来，并写回，包括游戏曲线编辑器中的响应曲线及其力反馈设置。

新手入门

#3 步上手

  1. 全部帮我设置好
    在开始页面
  2. 使用这些按钮
    先查看列表
  3. 写入我的游戏
    保持游戏关闭

之前：保存一次按键映射。打开 Settings > Key mapping 并按 ACCEPT。关闭游戏。

然后：你的绑定位于 Settings > Key mapping 中，适用于每一架飞机。

你以前在 IL-2 Korea 中绑定过按钮吗？那么开始页面会提供 导入，然后填补空缺。你的绑定会保留，只有空闲的按钮会获得新功能。参见 快速入门：让我的摇杆能用。

#没有头部追踪时环顾四周

没有 TrackIR，也没有 VR？设置会把快速视角放到你摇杆的一个苦力帽上：前、后、左、右。如果你的油门上有小摇杆，视角轴就放在它上面。参见 头部追踪和环顾四周。

#JoyPro 为 IL-2 Korea 做了什么

  • 导入：按键映射中位于摇杆、油门、脚舵或面板上的每个操作都会进入你的配置文件，连同修饰键、每个轴的反转以及曲线编辑器中的值。如果你需要，键盘按键也会一起导入。
  • 关联：一个关联就是你所有游戏中的同一个功能，例如 Korea、IL-2 Great Battles 和 DCS 中的“Gear”在同一个按钮上。Korea 对每架飞机使用同一套按键映射。
  • 导出：JoyPro 会写入按键映射，并像游戏自己的“分配设备编号”对话框那样，为你的每个设备分配一个设备编号。

#导入你的 Korea 绑定

  1. 打开 开始 页面。IL-2 Series: Korea 卡片会显示游戏的图片。如果它要求生成命令列表，按 生成列表：JoyPro 会读取游戏的 general.actions（每个操作都会获得 JoyPro 自己的名称和说明）。
  2. 在卡片上按 导入。选择 添加到我的配置文件，如果你也想导入飞行按键，请勾选 同时获取键盘按键。
  3. 按 立即导入。查看我的关联 会打开导入的内容。

#建立并检查关联

在 关联 页面上，关联中的 Korea 操作就在你其他游戏的同一功能旁边。用 关联流程 把它们连接起来，然后在导出页面按 立即检查：它会找出在 Korea 中做两件事的按钮（检查）。

#导出到 IL-2 Korea

  1. 关闭游戏。 当 IL2Series.exe 正在运行时，JoyPro 拒绝写入。
  2. 打开 导出。IL-2 Series: Korea 卡片会显示它有多少个关联已绑定。
  3. 如果你是在 JoyPro 中设置摇杆的，请保持选择 在我的设备上替换 并勾选 同时清除我的其他设备。在卡片上按 立即导出。
在游戏中: 你在 IL-2 Korea 中看到的内容

启动游戏并打开 Settings > Key mapping。你的绑定位于操作行中（例如 Basic 页签上），显示你设备的名称及其编号（“joy 2”）；游戏不会要求你分配设备编号。轴行的曲线图标会打开响应编辑器，其中是 JoyPro 写入的值。力反馈和轴噪声过滤显示在 Settings > Input devices 中。

#在 IL-2 Korea 中需要你自己做的事

  • 保存一次按键映射。 当你在 Key mapping 中按 ACCEPT 时，游戏会写入 general.actions。第一次启动时还会显示游戏的用户协议。没有 general.actions 就没有可以导出到的地方。
  • 独立版默认安装在 Program Files 下，Windows 可能会保护这个文件夹。这时导出会说明这一点，而不会只写入一半文件。
  • 如果要使用 JoyPro 自己基于游戏遥测数据的力反馈，力反馈 页面会把 JoyPro 的地址添加到游戏的 startup.cfg 中（请先关闭游戏）。为该摇杆关闭游戏自己的力反馈。

#常见问题

  • “IL-2 Korea 正在运行”：关闭游戏，然后重新导出。
  • 某个设备被跳过：没有设备编号且未连接的设备无法获得编号。插上它，然后重新导出。
  • 使用“仅添加”后某个绑定不见了：该输入在游戏中已用于另一个操作。检查会把它列在“未写入游戏”下。
高级

#JoyPro 读取和写入的文件

文件 这是什么
<install>\data\input\general.actions 按键映射配置“General”（JSON）：使用的设备、修饰键、每个操作及其输入、Relative Control 的值
<install>\data\input\known.devices.json 游戏见过的每个设备及其设备编号
<install>\data\input\general.pitch 俯仰曲线（“General (Common pitch curve)”）
<install>\data\input\shared.responses 其他轴的曲线
<install>\data\NSData\UserData\UserSettings.json Settings > Input devices：力反馈和轴噪声过滤器（input 段）
<install>\data\startup.cfg JoyPro 的遥测地址（只在你设置基于遥测数据的力反馈时）
general.actions.joypro-meta.json JoyPro 保存在文件旁边的名称、分组、修饰键和调校，下次导入时会读回

Steam 版的 <install> 是 steamapps\common\IL2Series，独立版则是独立启动器下的 game 文件夹。current.map 由游戏编译生成；JoyPro 从不写入它。

#IL-2 Korea 中的导出模式

模式 游戏中会发生什么
仅添加 不会移除任何内容。如果某个绑定的输入已被游戏用于另一个操作，该绑定不会被写入，并会被列出。
更新，保留游戏的绑定 写入你的绑定；游戏的其他输入保留，但你把某个输入给了另一个操作时，该输入上原有的游戏绑定除外。
更新，以我的配置文件为准 同上，此外，你绑定的每个操作都会失去它的其他输入（摇杆；键盘只在开启键盘选项时）。
在我的设备上替换 你写入的设备的每个摇杆输入都会被释放；然后写入你的绑定。
+ 同时清除我的其他设备 你的配置文件中没有绑定的已连接设备会失去它们的摇杆输入。

#绝不会改动的内容

  • 替换模式下的键盘按键、鼠标输入和轴上的按键对（键盘只在开启键盘选项时才会改变）。
  • 未连接的设备、导入无法读取的行、导入时忽略的设备，以及 JoyPro 转发到的 vJoy 设备。
  • current.map、每个设备的力反馈文件以及游戏的其他设置。

#曲线、Relative Control、力反馈

  • 粒度：全局。所有飞机共用一个按键映射；俯仰曲线配置默认分配给每架飞机。
  • 轴曲线（轴模型 il2korea）：指数（-100 到 100）、中心和边缘死区、俯仰的中心偏移；俯仰、横滚和偏航还有内置响应曲线和操纵面载荷。单向轴（油门、刹车）在整个行程上有指数以及低端/高端死区。相机轴没有编辑器，也不会获得曲线。数值使用文件中的单位；游戏中显示的死区是它的四倍。
  • Relative Control（轴输入的 ◆ 按钮）：开/关、死区（0 到 80 %）和灵敏度（1 到 20），与对话框中显示的一致。
  • 游戏设置（设置 > 游戏的力反馈设置）：力反馈开关、震动力度、反馈力度、低速和高速摇杆力、力中性再平衡、地形接触以及轴噪声过滤器，与游戏中一样以 % 表示。
  • 基于遥测数据的力反馈 和录制：来自游戏的遥测输出，与 Great Battles 相同（只有 CSV，没有 Tacview 航迹）。
  • 监视器：general.actions 中的更改会在游戏关闭后被发现（监视器）。
技术细节

#Korea 集成的内部原理

代码：engine\Games\Il2KoreaIntegration.cs，轴模型 il2korea 位于 engine\AxisModels 中。

  • 输入：dev<N>_b<button, 0-based>、dev<N>_axis_<x|y|z|w|s|t|p|q>（X、Y、Z、RX、RY、RZ、滑块 1、滑块 2），标记前加 - = 反转，* = Relative Control，苦力帽 dev<N>_pov<hat>_<angle>，按键 key_<name>，组合用 +。
  • 设备：known.devices.json 以 DirectInput 实例 GUID（按 IL-2 的字节顺序）作为每个设备的键，并保存其 deviceId（编号，-1 = 无）和 ident（vid_pid）。JoyPro 写入的设备保留它的编号；没有编号的已连接设备会获得从 1 开始的最小空闲编号。
  • 命令列表：engine il2korea refresh-db 会添加按键映射文件中的操作。没有输入的操作不在 general.actions 中，所以新生成的列表约有 318 个操作。JoyPro 不读取游戏的打包归档。
  • 导入 / 导出：engine il2korea import、engine il2korea scan、engine il2korea export（--mode、--nuke-untouched-devices、--include-keyboard、--dry-run）；engine il2korea paths 显示这些文件。
  • 设置和曲线：engine ffb set --device * --game IL2Korea --param ffForce=80，engine binds tuning set --scope game:IL2Korea（或 family:il2），engine binds tuning preview（与游戏编译的表一致到 1e-6，但中心偏移的平坦一侧除外）。
  • 遥测：engine ffb telemetry setup il2korea。

#已知限制

  • 游戏自己的操作文本在它的打包归档中，JoyPro 不读取这些归档；JoyPro 使用自己的名称。
  • Key mapping 页面上约有 60 个操作在全新的 general.actions 中没有输入，因此不在新生成的列表中。
  • 测试：engine\tests\smoke\il2korea.ps1、il2koreainstall.ps1；游戏内测试 tools\e2e\games\IL2Korea.ps1（49 个步骤全部通过）、IL2KoreaCurves.ps1、IL2KoreaSettings.ps1。
