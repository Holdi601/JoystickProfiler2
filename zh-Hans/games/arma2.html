Arma 2 和 Operation Arrowhead

显示：

Arma 2 和 Arma 2: Operation Arrowhead 把你的绑定保存在玩家配置文件中：每个操作一行数字代码，外加一份游戏见过的摇杆列表。这两个游戏共用一个文件夹，但文件是分开的，因此 JoyPro 把它们当作两个游戏。它只读取和写入固定翼飞机和直升机的绑定；步兵、载具和菜单绑定保持不变。Operation Arrowhead 还包括 Combined Operations、BAF、PMC、ACR 和 DayZ 模组。

新手入门

#3 步上手

  1. 全部帮我设置好
    在开始页面
  2. 使用这些按钮
    先查看列表
  3. 写入我的游戏
    保持游戏关闭

之前：在连接好所有设备的情况下启动一次游戏。打开 Options > Controls > Controllers，然后退出。你玩的两个游戏都要各做一次。

然后：你的绑定就在 Options > Controls 中。

你以前在 Arma 2 中绑定过按钮吗？那么开始页面会提供 导入，然后填补空缺。你的绑定会保留，只有空闲的按钮会获得新功能。参见 快速入门：让我的摇杆能用。

#JoyPro 为 Arma 2 做了什么

  • 导入：你的摇杆、油门和脚舵上的固定翼飞机和直升机绑定会连同每个轴的灵敏度滑块一起进入你的配置文件。
  • 关联：一个关联就是所有游戏中的同一个功能。Arma 2 和 Operation Arrowhead 在其中是两个游戏，所以一个关联可以同时包含两者。
  • 导出：JoyPro 只重写飞行操作的按键行。键盘和鼠标绑定保持不变，这些操作上的也一样。

#导入你的 Arma 2 绑定

  1. 打开 开始 页面。如果 Arma 2 或 Operation Arrowhead 卡片要求生成命令列表，按 生成列表：JoyPro 会从游戏文件中读取操作及其英文名称（只读，不需要先启动游戏）。
  2. 在你玩的游戏的卡片上按 导入，保持选择 添加到我的配置文件。
  3. 按 立即导入。查看我的关联 会打开导入的内容。

JoyPro 只管理你的摇杆：键盘绑定不会被导入或导出，而且 Arma 2 不支持带修饰键的摇杆按钮。

#建立并检查关联

用 关联流程 把你各个游戏中的同一功能连接起来，然后在导出页面按 检查。导出时直升机和固定翼飞机算作不同的载具：两者使用同一个按钮不算冲突。武器和视角操作对两者都适用。

#导出到 Arma 2

  1. 关闭游戏。 Arma 2 会自己保存配置文件，因此游戏运行时 JoyPro 拒绝写入。
  2. 打开 导出 并勾选 Arma 2 或 Operation Arrowhead 卡片。
  3. 如果你是在 JoyPro 中设置摇杆的，请保持选择 在我的设备上替换 并勾选 同时清除我的其他设备。在卡片上按 立即导出。
在游戏中: 你在 Arma 2 中看到的内容

启动游戏，在主菜单中打开 Options > Controls。你的绑定位于固定翼飞机和直升机操作上，在你的键盘按键旁边。在 Controllers 下会列出你的设备并处于启用状态，设备的 Customize 会显示 JoyPro 为每个轴设置的灵敏度滑块。

#在 Arma 2 中需要你自己做的事

  • 在连接好所有设备的情况下启动一次游戏，并打开 Options > Controls > Controllers。游戏第一次看到某个设备时才会把它加入列表；JoyPro 无法写入列表中没有的设备，并会提示你在连接该设备的情况下启动一次游戏。
  • 游戏中处于禁用状态的设备，如果获得了绑定，导出时会被开启（导出会说明这一点）。
  • 如果两个游戏你都玩，请分别启动一次：每个游戏都有自己的配置文件和设备列表。

#常见问题

  • “游戏正在运行”：退出 Arma 2 或 Operation Arrowhead，然后重新导出。
  • 脚舵或油门会发射武器或转动视角：游戏第一次看到某个设备时，会把所有摇杆默认绑定都加到它上面（X 轴滚转、Y 轴俯仰、苦力帽转视角、几个按钮），脚舵和油门也不例外。在我的设备上替换 会删除它们。
  • 32 号以上的按钮或第二个苦力帽没有作用：Arma 2 只读取 32 个按钮、8 个轴和第一个苦力帽。超出部分的绑定会被 JoyPro 跳过。
  • 更换 USB 接口后某个设备被跳过：游戏会把新的 ID 当作新设备。请在连接该设备的情况下启动一次游戏。
  • 仅 Arma 2：油门只在半个油门杆行程上起作用：没有 Operation Arrowhead 的 Arma 2 无法把一根油门杆的两半合并到一个操作上。
高级

#JoyPro 读取和写入的文件

文件 这是什么
%USERPROFILE%\Documents\ArmA 2\<name>.ArmA2OAProfile Operation Arrowhead（以及 Combined Operations、DayZ 模组）：key<Action>[]={...}; 行、class JoysticksList 和其他选项
%USERPROFILE%\Documents\ArmA 2\<name>.ArmA2Profile 单独的 Arma 2，格式相同
%USERPROFILE%\Documents\ArmA 2 Other Profiles\<name>\<name>.<ext> 你的其他配置（没有连字符，与 Arma 3 不同）
<profile>.joypro-meta.json JoyPro 为已写入的绑定保存的名称、分组和调校，下次导入时会读回
<profile>.jpbak 首次写入之前的副本，以及 JoyPro 带版本的备份存储

JoyPro 从不改动 <name>.vars.<ext> 或视频设置 ArmA2.cfg / ArmA2OA.cfg，如果配置是二进制（rapified）文件，它会停止。其他每个字节都保持不变：换行符、行首的制表符、各行的顺序。缺失的已收录按键行会添加在最后一个按键行之后（缺少该行表示“游戏默认值”）。

#Arma 2 中的导出模式

只有已收录的固定翼飞机和直升机操作的行会改变。键盘、鼠标、TrackIR 和 Xbox 手柄的代码以及键盘组合键始终保持不变。

模式 配置中会发生什么
仅添加 不会移除任何内容。如果某个绑定的代码已被同一载具的另一个操作使用，该绑定不会被写入，并标记为“未写入游戏”。
更新，保留游戏的绑定 写入你的代码；同一载具的另一个操作上、被你放到别处的代码会被丢弃。该操作的其他代码保留。
更新，以我的配置文件为准 同上，此外，你绑定的操作会失去已连接摇杆上的其他摇杆代码。
在我的设备上替换 飞行相关的行还会失去已写入设备的所有其他代码，包括游戏的自动默认值。
+ 同时清除我的其他设备 其他已连接摇杆的代码也是如此。未连接的摇杆保留它的代码。

#绝不会改动的内容

  • 步兵、载具、菜单以及其他所有不属于已收录飞行操作的行。
  • 键盘、鼠标、TrackIR 和 Xbox 手柄的代码。
  • 未连接的摇杆、编号范围在列表中没有对应设备的代码、导入时忽略的设备，以及 JoyPro 转发到的 vJoy 设备。
  • 设备列表：JoyPro 不会添加条目，只会更改现有条目的 sensitivity[] 和模式；joystickSensitivity[]、控制器方案、鼠标和 TrackIR 设置保持不变。

#载具、曲线、设置

  • 粒度：所有固定翼飞机和直升机共用一套绑定；按游戏区分（Arma 2、Operation Arrowhead）。
  • 轴按两半处理：Arma 2 把轴的每一半绑定到一个操作。JoyPro 的轴关联会写入两半：俯仰（机头向下 / 机头向上）、横滚（左倾 / 右倾）、方向舵（左脚舵 / 右脚舵）、街机式转弯、推力增减速率（增加 / 减少推力）以及环视和缩放。
  • 油门：“Thrust (Analogue)”是固定翼飞机的油门，也是直升机的绝对总距；“Brake (Analogue)”是减速板。在 Operation Arrowhead 中，JoyPro 把油门杆的两半都放到该操作上，负半在前（反转时正半在前），游戏会把它们合成一个完整的轴。单独的 Arma 2 只获得一半。
  • 灵敏度：每个设备和物理轴一个滑块（Customize 对话框，-1 到 1），保存为 10 的滑块值次方。它对所有载具都有效。JoyPro 只写入你为 Arma 2 / Operation Arrowhead（或两者，family:arma2）设置的值或来自导入的值；如果同一个轴上的两个关联不一致，按名称排第一个的生效，并给出警告。
  • 死区：主轴固定为 7 %（滑块没有）；不能在游戏中调整，也不会被写入。
  • 反转：通过两半的顺序（见油门）或使用相反的一半实现；没有反转标志。
  • 设置：每个设备的开/关（模式 Custom 或 Disable）。Arma 2 没有 JoyPro 会写入的全局游戏选项，没有力反馈，也没有遥测数据。
  • 监视器：你在游戏中更改的绑定或滑块会在游戏关闭后被发现；JoyPro 会询问是否采用这些更改。
  • HUD：HUD 通过进程识别游戏，并显示你的绑定。
技术细节

#Arma 2 集成的内部原理

代码：engine\Games\Arma2Integration.cs，基于与 Arma 3 共用的 Arma 配置代码（ArmaProfileIntegration.cs、ArmaGameData.cs）和轴模型 engine\AxisModels\Arma2.cs（游戏 Arma2 和 Arma2OA）。

  • 设备：class JoysticksList { class Joystick1 { guid="..."; name="..."; offset=256; isXInput=0; mode="Custom"; }; }。guid 是 DirectInput 的 实例 GUID，大写，不带花括号；name 是产品名称。新设备获得最高的 offset + 256；条目会保留，所以设备会保持自己的 offset。类名 Joystick1..N 每次保存时都会重新编号，所以 JoyPro 只按 guid 匹配。mode 为 "Custom"、"Scheme"（Xbox 手柄方案）或 "Disable"。sensitivity[]（16 个值）只有在游戏的 Customize 对话框确认过之后才会出现；当某个值与默认值不同时，JoyPro 会在 isXInput 之后创建它。
  • 代码：按钮 0x20000 + offset + b（b 为 0 到 31）；半轴正向为 0x30000 + offset + a，负向为 + a + 8（X、Y、Z、RotX、RotY、RotZ、Slider 1、Slider 2）；第一个苦力帽 0x40000 + offset + direction（八个方向）。导入时也会读取已保存的整轴代码；导出从不写入它们。
  • 命令列表：engine arma2oa refresh-db 从 Expansion\dta\bin.pbo 读取 CfgDefaultKeysMapping，engine arma2 refresh-db 则从 Dta\bin.pbo 读取，并使用 languagecore.pbo 中的英文菜单名称；配置还会加入模组定义的内容。Operation Arrowhead 有 68 个操作，Arma 2 有 66 个。engine arma2oa catalog、engine arma2oa paths、engine arma2 catalog、engine arma2 paths。
  • 导入 / 导出：engine arma2oa import、engine arma2oa scan、engine arma2oa export；engine arma2 import、engine arma2 scan、engine arma2 export（--mode clean|add|merge|merge-overwrite --nuke-untouched-devices --ignore-device <d> --dry-run）。
  • 设备开关：engine ffb set --device "<name> {GUID}" --game Arma2|Arma2OA --param enabled=0|1（engine ffb set）。

#已知限制

  • 游戏把哪个滑块方向称为“更灵敏”，尚未确认。
  • Arma 2 中不存在摇杆组合键（按钮加修饰键）；JoyPro 不会写入任何组合键。
  • 单独的 Arma 2 没有放在一个操作上的整轴；它的直升机总距在油门杆一半上的手感如何，尚未确认。Operation Arrowhead 中的整轴方向也还需要在真正的首次启动后确认。
  • 测试：engine\tests\smoke\arma.ps1（灵敏度、系列范围、设备开关）；游戏内测试 tools\e2e\games\Arma2Settings.ps1 -Game arma2oa|arma2（测试配置 JoyProE2E_OA / JoyProE2E_A2，只使用主菜单 > Options > Controls）。
