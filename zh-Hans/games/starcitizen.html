以前在 Star Citizen 中绑定过按钮？那么开始页面会提供 导入，然后填补空缺。你的绑定会保留，只有空闲的按钮会获得新功能。请参见快速入门：让我的摇杆工作。

#JoyPro 能为 Star Citizen 做什么

  • 导入：你在摇杆、油门和脚舵上的飞船绑定会导入你的配置文件，包括死区、曲线和反转。游戏自己在 js1 上的默认摇杆绑定也会一并导入，这样之后导出时就不会丢失。
  • 关联：一个关联就是所有游戏中的同一个功能。“起落架”可以是 Star Citizen、DCS 和 Elite Dangerous 中的同一个开关。
  • 导出：JoyPro 就地编辑 actionmaps.xml。步行、载具和菜单绑定，以及鼠标和手柄绑定都保持不变。

#导入你的 Star Citizen 绑定

  1. 打开开始页面。如果 Star Citizen 卡片要求命令列表，请按 生成列表：JoyPro 会从你的安装中读取游戏的操作（Data.p4k，只读）。游戏打补丁后，卡片上的 更新 会添加新的操作。
  2. 在 Star Citizen 卡片上按 导入。保持选择 添加到我的配置文件。只有当你也想把飞船按键放进 JoyPro 时，才勾选 同时获取键盘按键。
  3. 按 立即导入。查看我的关联 会打开导入的内容。

#建立并检查关联

每个飞船操作都是关联中的一个条目。用关联流程把你其他游戏中的相同功能合并进来，然后在导出页面上按 检查：它会在游戏之前找出在你的飞船上同时执行两件事的按钮。

#导出到 Star Citizen

  1. 关闭 Star Citizen。 游戏退出时会重写 actionmaps.xml，所以游戏运行时 JoyPro 会拒绝写入。
  2. 打开 导出 并勾选 Star Citizen 卡片。
  3. 如果你是在 JoyPro 中设置摇杆的，请保持选择 在我的设备上替换 并勾选 同时清除我的其他设备。在卡片上按 立即导出。
在游戏中: 你在 Star Citizen 中会看到什么

启动游戏，从主菜单打开 Options > Controls。选择你的设备（Joystick / HOTAS 1、2 ……）：它的死区和饱和度就是你在 JoyPro 中设置的值；Inversion Settings 和 Joystick Sensitivity Curves（Flight > Flight Movement）会显示你的反转、指数和曲线。你的飞船绑定位于每个设备的摇杆槽位上。被 JoyPro 关闭的游戏默认绑定显示为空。菜单显示的饱和度比文件中的值高 0.01（0.87 显示为 0.88）；游戏会保留精确值。

#你在 Star Citizen 中需要自己做的事

  • 绑定方面不需要再做别的。导出前插上你使用的所有设备：未连接的设备会保留其槽位和绑定，但 JoyPro 无法为它添加新的绑定。
  • 如果游戏位于与检测到的不同的文件夹中，请在导出页面的 选项和路径（供专家使用） 下设置一次路径，或在 设置 > 游戏 中链接该文件夹。

#常见问题

  • “Star Citizen 正在运行”：退出游戏（也要从启动器退出），然后再次导出。
  • 绑定落到了错误的摇杆上：保持 SC：优先使用本地顺序 开启（默认）。关闭时，槽位会按 Windows 报告设备的顺序排列，这可能会把一个设备的所有绑定移到另一个 js 编号上。
  • 某个设备没有分到槽位：游戏有八个摇杆槽位。JoyPro 会把同一个摇杆的重复条目（游戏中的名称和 JoyPro 中的名称）合并到一个槽位，但超过八个已连接且有绑定的设备就放不下了。
  • 某个默认绑定又回到了 js1 上：如果导出时 js1 上的设备没有连接，它就会回来。连接该设备，然后用替换模式再次导出。
高级

#JoyPro 读取和写入的文件

文件 这是什么
<install>\LIVE\user\client\0\Profiles\default\actionmaps.xml 你的重新绑定、摇杆槽位（<options type="joystick" instance="1..8" Product="...">）、每个槽位的选项组（反转、指数、曲线、灵敏度）以及设备选项（每个物理轴的死区、饱和度）
...\Profiles\default\attributes.xml 全游戏范围的设置（<Attr name="..." value="..."/>），只包含与游戏默认值不同的值
...\Profiles\default\actionmaps.jp JoyPro 保存的已写入文件副本，以注释形式带有关联名称，下次导入时会读回
...\Profiles\default\actionmaps.xml.joypro.json JoyPro 上次写入的轴设置，这样“更新”就能区分你在游戏中改过的值和它自己写的值
actionmaps.xml.jpbak、attributes.xml.jpbak 导出第一次写入前的副本，以及 JoyPro 带版本的备份库

导出会就地编辑 actionmaps.xml：只有飞船的重新绑定以及 JoyPro 写入的轴重新绑定的轴设置会改变。其他操作映射、鼠标和手柄的重新绑定、激活模式、修饰键、其他选项组和设备选项都逐字节保持不变。没有 Star Citizen 绑定的配置文件不会改动该文件。

#摇杆槽位

Star Citizen 用槽位来命名每个摇杆绑定：js1_button3、js2_x。该文件通过设备的 DirectInput 产品名称和产品 GUID 列出哪个设备占用哪个槽位。

  • 优先使用本地顺序（默认开启）：文件中已列出的已连接设备保留原来的槽位。其他设备按 Windows 报告的顺序填入空闲槽位。
  • 一个设备，一个槽位：同一个摇杆被列出两次（一次用游戏的名称，一次用 JoyPro 的实例名称，或是旧的第二个条目）时，只占用一个槽位。导出会删除重复的条目，并把它们的绑定移到该设备保留的槽位上。未连接设备的条目保持不变。
  • 两个已连接的同型号设备会被分开处理。
  • 更换槽位的设备会把它的选项组（反转、曲线）一起带走。没有分到槽位的设备会失去旧槽位的选项组，并给出警告。

#Star Citizen 中的导出模式

每种模式都只改动飞船操作。步行、载具和菜单映射逐字节保持不变。

模式 游戏中会发生什么
仅添加 游戏的绑定都不会改变。如果某个操作的摇杆槽位已有重新绑定或生效的默认值，该操作会保留它。如果某个绑定所用的输入已被另一个飞船操作使用，该绑定不会被写入，并被标记为“未写入游戏”。
更新，保留游戏的绑定 你的输入会写入该操作的摇杆槽位（Star Citizen 每个操作的每种输入类型只有一个槽位）。如果你把某个输入分配给另一个飞船操作，游戏在该输入上的绑定会被清除：它的重新绑定会被删除；如果该操作有默认值，则变为空的 js1_ ，这样默认值就不会回来。
更新，以我的配置文件为准 同上；如果开启了键盘选项，你绑定的操作还会失去它的键盘重新绑定。
在我的设备上替换 已写入的设备只保留你的飞船绑定。如果有设备在 js1 上，游戏中你的配置文件里没有的 js1 默认绑定会被关闭。
+ 同时清除我的其他设备 在你的配置文件中没有绑定的已连接设备会失去它们的飞船绑定；js1 未被使用时，js1 的默认绑定会被关闭。

导出页面上的选项（在 选项和路径（供专家使用） 下）：

  • SC：保留键盘默认设置（开启）：键盘保留游戏的默认按键。关闭：会写入你的键盘绑定，并清除它们所占用的默认按键。
  • SC：优先使用本地顺序（开启）：参见上文的摇杆槽位。

#游戏的默认摇杆绑定

Star Citizen 有一些默认摇杆绑定，在某个操作于 js1 上获得重新绑定之前，它们作用于 js1（Y 轴俯仰、X 轴偏航、Z 旋转横滚，以及几个按钮）。导入会把每个生效的默认绑定当作 js1 设备的绑定，这样你的配置文件就反映了游戏实际的行为。对于与默认值相同的绑定，导出不会写入重新绑定（只写真正的差异）。“替换”和“同时清除”会用空的重新绑定 js1_ 关闭你的配置文件中没有的默认绑定，就像游戏自己的菜单写入已清除的绑定那样，而且只在 js1 上的设备已连接时才这样做。因此，先导入，再用“替换 + 同时清除”导出，actionmaps.xml 会保持原样。

#绝不会改动的内容

  • 步行、地面载具和菜单绑定（Star Citizen 的地面载具算作单独的载具类别）。
  • 未连接的设备：它们保留自己的槽位和重新绑定。
  • 导入时忽略的设备，以及 JoyPro 转发到的 vJoy 设备。
  • 鼠标和手柄绑定；键盘也不会改动，除非你导出键盘绑定。
  • 激活模式、修饰键、其他选项组和设备选项。

#飞船、曲线、游戏设置

  • 粒度：所有飞船共用一套飞船绑定（游戏没有按飞船区分的绑定）。
  • 轴曲线，按游戏的保存方式分在两处：每个设备和物理轴的死区和饱和度；每个槽位和选项组的反转、指数（1 到 3）、11 点曲线和灵敏度。指数和曲线互斥，与游戏菜单中一样。没有 Star Citizen 数值的关联会根据其 JoyPro 曲线进行拟合：死区和饱和度写到设备轴上，曲率转换为最接近的指数，如果没有合适的指数，则转换为曲线。没有单向轴：游戏的绝对油门和相对油门是两个独立的操作。
  • 更新 会保留你在游戏中改过的轴数值（并给出警告）；替换 和 以我的配置文件为准 则使用你的配置文件中的数值。中性的关联会保留游戏自己的数值（自由视角保留其默认指数 2.5）。
  • 全游戏范围的设置（attributes.xml）：HOTAS 推力反转切换、相对油门的捕获时间和阈值、IFCS 灵敏度修正、ESP 开关、强度和阻尼、炮塔 ESP、飞行默认设置（油门保持、速度限制器、耦合模式、G-safe、自动精确模式、太空刹车）、反转飞行控制器以及 Vibration。可在 设置 > 游戏的力反馈设置（选择 Star Citizen）中或用 engine ffb set 设置它们。JoyPro 只就地修改你设置的那些行，不会创建该文件。ESP 强度滑块最大为 1.00，因此 JoyPro 提供 0 到 1 的范围。
  • 力反馈：无。Vibration 是游戏中唯一的此类设置。
  • 监视器：你在游戏菜单中更改的绑定或轴数值会在游戏关闭后被发现，JoyPro 会询问是否接受这些更改。它会比较 actionmaps.xml（仅飞船操作映射）以及 JoyPro 在 attributes.xml 中管理的设置。
  • HUD：HUD 通过进程识别该游戏，并显示你的 Star Citizen 绑定。
技术细节

#Star Citizen 集成的内部机制

代码：engine\EngineStarCitizen.cs、engine\EngineStarCitizenTuning.cs、轴模型 engine\AxisModels\StarCitizen.cs 以及设置模型 engine\FfbModels\StarCitizen.cs。

  • 设备名称：槽位的 Product 是 DirectInput 产品名称和产品 GUID，中间隔两个空格（vJoy Device {BEAD1234-0000-0000-0000-504944564944}）。以其他名称（实例 GUID）写入的槽位或 deviceoptions 块不会被游戏识别：游戏会用它的产品名重写该槽位，并丢弃该槽位的选项组。因此 JoyPro 会写入已连接设备的产品名称。
  • 命令列表：engine db refresh-starcitizen 从 Data.p4k（或用 --source 指定的解包副本）读取 Data\Libs\Config\defaultProfile.xml，写入 DB\StarCitizen\AllBinds.xml：每个操作及其选项组、摇杆选项树（父级和默认值，哪些组显示曲线）以及该操作的默认摇杆输入。engine starcitizen labels 从 global.ini 获取游戏中控件的名称。
  • 导入：engine starcitizen import（--include-keyboard、--device、--ignore-device）；每个轴重新绑定都会获得游戏实际使用的数值（槽位的叶子组，否则取你设置过的最近父级，否则取游戏默认值）以及其轴的设备选项，作为它的 game:StarCitizen 调校。engine starcitizen scan 显示同样的内容但不更改配置文件；engine starcitizen list-devices 列出文件中的摇杆槽位。
  • 导出：engine starcitizen export --mode clean|add|merge|merge-overwrite --nuke-untouched-devices true|false --keep-keyboard-defaults true|false --prefer-local-order true|false --include-keyboard true|false --ignore-device <d>。新的 deviceoptions 块放在第一个 <options> 之前；如果多个关联作用于同一个选项组或同一个物理轴且数值不同，会给出警告，并以名称排在最前的关联为准。
  • 游戏设置：engine ffb set --device * --game StarCitizen --param <Attr name>=<value>；已有的行会获得新值，新的行会插入到排序后的位置。
  • 备份：engine backups list 列出这些副本；卡片上的 撤销上次导出 会恢复最新的一份。

#已知限制

  • 八个摇杆槽位；每个设备的按钮上限不明（各来源说法不一）。
  • 游戏希望把新的 deviceoptions 块放在哪里、曲线插值方式（菜单通过各点绘制一条平滑样条）、指数的范围，以及灵敏度是否作用于摇杆，这些都尚未确认。全游戏范围设置的取值范围不在游戏的可读文件中。
  • Vibration 是否会驱动 DirectInput 力反馈摇杆尚未确认。
  • 测试：engine\tests\smoke\starcitizen.ps1（目录刷新、选项组和曲线的导入、逐字节的导入 + 导出、每项轴设置、冲突、槽位变化、就地修改 attributes.xml）；在游戏中运行 tools\e2e\games\StarCitizenSettings.ps1（主菜单 Options：设置、绑定和曲线）和 tools\e2e\games\StarCitizen.ps1（导出和导入模式矩阵）。
