新手入门

#3 步上手

  1. 全部帮我设置好
    在开始页面
  2. 使用这些按钮
    先查看列表
  3. 写入我的游戏
    保持模拟器关闭

之前：在模拟器中（Settings > Controls）为每个设备创建一次配置。JoyPro 只写入 Steam 版；Microsoft Store 版只能导入。

然后：启动模拟器。你的绑定位于 Settings > Controls 中，适用于每一架飞机。

你以前在 MSFS 2020 中绑定过按钮吗？那么开始页面会提供 导入，然后填补空缺。你的绑定会保留，只有空闲的按钮会获得新功能。参见 快速入门：让我的摇杆能用。

#JoyPro 为 MSFS 2020 做了什么

  • 导入：每个已连接设备的配置（Steam 版或 Microsoft Store 版）会进入你的配置文件：飞行绑定、General 绑定（相机、视角、暂停）以及 Sensitivity 页面上的轴设置。
  • 关联：一个关联就是一个功能。由于 MSFS 2020 每个设备只有一个配置，一个关联适用于所有飞机。
  • 导出：JoyPro 会编辑 Steam 版 remote 文件夹中的设备配置。模拟器会在下次启动时读取它们。

#导入你的 MSFS 2020 绑定

  1. 打开 开始 页面，在 Microsoft Flight Simulator 2020 卡片上按 导入。
  2. 同时导入未连接的设备（默认关闭）：MSFS 会保存它见过的每个设备的配置；关闭表示只导入当前已连接的设备。同时导入模拟器可能未使用的默认预设（默认关闭）会为没有自己配置的设备添加模拟器自带的预设，即使不确定模拟器是否使用它。
  3. 按 立即导入，或者按 先查看，在不更改你的配置文件的情况下查看模拟器中有什么。

#建立并检查关联

像其他游戏一样在 关联 页面上建立关联（参见 关联流程），然后在导出页面运行 检查。在这里，检查不会把固定翼飞机的油门和直升机的总距位于同一个轴上报告为错误：MSFS 2020 没有单独的飞机列表。

#导出到 MSFS 2020

  1. 关闭 MSFS 2020。 模拟器运行时 JoyPro 拒绝写入。
  2. 打开 导出，如果你是在 JoyPro 中设置设备的，请保持选择 在我的设备上替换 并勾选 同时清除我的其他设备，然后在 MSFS 2020 卡片上按 立即导出。
  3. 启动模拟器。remote 文件夹是一个 Steam 云文件夹，因此 Steam 会同步修改过的文件。
在游戏中: 你在 MSFS 2020 中看到的内容

打开 Settings > Controls 并选择你的设备：你的绑定位于该设备的配置中，使用模拟器的操作名称；设备的 Sensitivity 页面会显示 JoyPro 写入的轴曲线。每架飞机都使用同一个配置。

#在 MSFS 2020 中需要你自己做的事

  • 在模拟器中为每个设备创建一次配置（Settings > Controls）。JoyPro 只会编辑已有的配置；对于没有配置的设备，导出会提示“请先在模拟器中创建一个”。
  • Microsoft Store 版：JoyPro 会导入你的配置，但无法写入。请使用 Steam 版进行导出，或者在模拟器中设置绑定。
  • 限定于特定飞机的关联：MSFS 2020 无法把它们区分开。在开始页面的 其他游戏 表单中，导出飞机 也会导出限定于某一架飞机的关联，并应用到每一架飞机。

#常见问题

  • “MSFS 2020 正在运行”：关闭模拟器，然后重新导出。
  • 模拟器显示的是你的旧绑定：Steam 云恢复了一个较旧的副本。关闭模拟器，然后重新导出。
  • 某个设备有多个配置：JoyPro 会使用在 其他游戏 表单中用 游戏配置文件 选择的那个，或者唯一的那个；否则会跳过该设备，并给出列出这些配置名称的警告。
  • 某个绑定不见了：一个操作最多保存两个输入组合（Primary 和 Secondary）；第三个会被报告并略过。

#JoyPro 读取和写入的文件

文件 这是什么
<Steam>\userdata\<id>\1250410\remote\inputprofile_<n> 一个设备配置，无扩展名的 XML；就地写入（先备份为 .jpbak）
<Steam>\userdata\<id>\1250410\remote\profile_00 模拟器对设备配置的二进制索引：只读，永远不会被写入
%LOCALAPPDATA%\Packages\Microsoft.FlightSimulator_8wekyb3d8bbwe\SystemAppData\wgs\<user>\ Microsoft Store 版的存档：只读（导入和扫描）
<install>\Input\*.xml、fs-base\en-US.locPak 模拟器自带的预设及其菜单名称：只读
%LOCALAPPDATA%\JoyPro2\Ownership\MSFS、...\Backups\MSFS JoyPro 的归属数据和备份，从不放在 Steam 文件夹中

Steam 的 remote 文件夹是一个 Steam 云文件夹。只编辑已有的 inputprofile_* 文件：模拟器的 profile_00 指明了具体的文件，所以新文件不会被识别。

#MSFS 2020 中的导出模式

模式 设备配置中会发生什么
仅添加 只有当配置中该输入组合上没有其他操作时，绑定才会被写入；否则它会列在“未写入的绑定：按钮在游戏中已被占用”下。不会移除任何内容。
更新，保留游戏的绑定 你的组合上的另一个操作会失去它；其他一切保留，包括某个操作原来的组合。
更新，以我的配置文件为准 同上，此外，你绑定的每个操作都会失去它在已连接设备配置中的其他组合。
在我的设备上替换 JoyPro 绑定的已连接设备的配置只保留你的绑定。
+ 同时清除我的其他设备 你的配置文件中没有绑定的已连接设备，其配置会被清除。

#绝不会改动的内容

  • 在任何模式下：菜单、世界地图和开发者上下文（MENU、MENU_*、WORLDMAP_*、DEBUG、DEVMODE*、EDITOR_*、MISSION_FLOW_TOOLS）。
  • 键盘、鼠标和手柄配置（GUID="{0}"）：在 MSFS 中不会写入键盘绑定。
  • 未连接设备的配置、profile_00、Store 存档、导入时忽略的设备，以及 JoyPro 转发到的 vJoy 设备。

#曲线及其他

  • 粒度：每个设备一个配置，适用于所有飞机。
  • 轴曲线：设备的 Sensitivity 页面，每个物理轴一组：Sensitivity + 和 -、Neutral、Dead zone、Extremity dead zone、Reactivity、无曲线标志和反转。MSFS 2020 没有按操作的覆盖设置：要求单独设置的关联会使用设备页面的值，并给出警告。曲线预览与模拟器一致（在 MSFS 2020 中测量）。调校范围 family:msfs 涵盖两个模拟器；请参见 axis-curves。
  • 力反馈：MSFS 自身没有力反馈。
  • 遥测录制：通过 SimConnect，只读，使用模拟器安装文件夹中的 SimConnect.dll（或 MSFS SDK 中的；JoyPro 不附带）。
  • HUD：HUD 通过进程（FlightSimulator）识别模拟器，并显示它的绑定。
  • 监视器：JoyPro 监视 inputprofile_* 文件和 Store 存档的 containers.index，并在模拟器关闭后询问（监视器）。

#与 MSFS 2024 的不同之处

MSFS 2020 MSFS 2024
导出目标 就地写入 Steam 配置 你自己的配置（Steam 和 Store）、JoyPro 的预设包、导入文件
Microsoft Store 版 仅导入 导入并写入
配置 每个设备一个 按设备和类别，按飞机选择
限定飞机的关联 只在使用 导出飞机 时（然后适用于所有飞机） 写入这些飞机的配置中
配置中的操作列表 只有已绑定的操作 其上下文中的每个操作
按操作的轴覆盖 否 是
技术细节

#MSFS 2020 集成的内部原理

代码：engine\Games\MsfsIntegration.cs（两个模拟器共用一个类，sim == 2020）、MsfsProfileFile.cs（按行编辑器）、MsfsUserProfiles.cs（读取 Steam 和 Store）、MsfsSimDefaults.cs、MsfsGameData.cs、MsfsAircraft.cs、engine\AxisModels\Msfs.cs。

  • 格式：一个 XML 片段（按片段一致性读取）：<Version>、<FriendlyName>、<Device DeviceName GUID ProductID>、带 <Axis AxisName AxisSensitivy AxisDeadZone ...> 的 <Axes>（拼写错误的属性名是模拟器原有的）、<Context ContextName> / <Action ActionName Flag> / <Primary> / <Secondary> / <KEY Information>code</KEY>。被释放的操作会被移除；新操作放入它在该文件夹其他配置中所在的上下文，否则放入其目录上下文，再否则放入 PLANE（并给出警告）。
  • 设备：GUID 是 DirectInput 实例 GUID，所以读取时不需要连接设备；ProductID 是十进制的 USB 产品 ID。代码：按钮 N = N-1，苦力帽 256-259，轴 1026/1042/1058、770/786/802，滑块 514/530；组合中的最后一个 KEY 是主输入，同一设备的其他按钮是修饰键。
  • 命令列表：engine msfs2020 refresh-db 读取模拟器的预设（<install>\Input、其官方包）以及 en-US.locPak 中提到的每个飞行事件；它与 MSFS 2024 的列表共用初始部分。
  • 命令：engine msfs2020 paths、engine msfs2020 catalog、engine msfs2020 scan、engine msfs2020 import（--game-profile、--include-disconnected、--include-sim-defaults）、engine msfs2020 export（--mode、--nuke-untouched-devices、--dry-run、--aircraft <key>）；用 engine backups restore 撤销。
  • 旧配置文件：JoyPro 只有一个 MSFS 游戏时保存的配置文件（MSFS:<action>）在加载时会为每个模拟器各得到一个节点。

#已知限制

  • Microsoft Store 版是只读的；以其存档文件夹为路径的导出会被拒绝。
  • 不会创建新的 inputprofile_* 文件；设备需要有一个在模拟器中创建的配置。
  • Steam 云可能会把较旧的配置放回来。
  • 半轴、苦力帽斜向和第二个苦力帽不会被读取或写入；每个操作最多两个组合。
  • MSFS 2020 自带的预设没有在真实安装上检查过，所以 2020 的预设还必须带有设备名称，才会被当作默认值。
  • 测试：engine\tests\smoke\msfs.ps1（Sensitivity 页面、覆盖设置、标志、冲突、合并）；模拟器内测试 tools\e2e\games\MsfsCurves.ps1（绑定、Sensitivity 页面、飞行中的按钮和轴曲线，通过 SimConnect 读回）。
