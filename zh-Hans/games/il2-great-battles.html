新手入门

#3 步上手

  1. 全部帮我设置好
    在开始页面
  2. 使用这些按钮
    先查看列表
  3. 写入我的游戏
    保持 IL-2 关闭

之前：让 IL-2 写入一次它的按键映射。打开 Settings > Key mapping 并按 ACCEPT。关闭 IL-2。

然后：你的绑定位于 Settings > Key mapping 中，适用于每一架 IL-2 飞机。

你以前在 IL-2 中绑定过按钮吗？那么开始页面会提供 导入，然后填补空缺。你的绑定会保留，只有空闲的按钮会获得新功能。参见 快速入门：让我的摇杆能用。

#没有头部追踪时环顾四周

没有 TrackIR，也没有 VR？设置会把快速视角放到你摇杆的一个苦力帽上：前、后、左、右。如果你的油门上有小摇杆，视角轴就放在它上面。参见 头部追踪和环顾四周。

#JoyPro 为 IL-2 Great Battles 做了什么

  • 导入：按键映射中位于摇杆、油门、脚舵或面板上的每个操作都会进入你的配置文件，连同修饰键、轴反转和轴响应行。如果你需要，键盘按键也会一起导入。
  • 关联：一个关联就是你所有游戏中的同一个功能。IL-2 对每架飞机使用同一套按键映射，因此关联中的 IL-2 操作在每一架 IL-2 飞机中都有效。
  • 导出：JoyPro 会写入游戏 data\input 文件夹中的按键映射文件。IL-2 会在 Settings > Key mapping 中显示你的绑定。

#导入你的 IL-2 绑定

  1. 打开 开始 页面。IL-2 Great Battles 卡片会显示游戏的图片。如果它要求生成命令列表，按 生成列表：JoyPro 会读取你的 IL-2 已写入的按键映射文件。
  2. 在卡片上按 导入。选择 添加到我的配置文件（或 从此游戏重新开始），如果你也想导入飞行按键，请勾选 同时获取键盘按键。
  3. 按 立即导入。查看我的关联 会打开导入的内容。

#建立并检查关联

在 关联 页面上，关联中的每个 IL-2 操作都在你其他游戏的同一功能旁边。用 关联流程 把它们连接起来，然后在导出页面按 立即检查：它会在游戏之前找出在 IL-2 中做两件事的按钮（检查）。

#导出到 IL-2

  1. 关闭 IL-2。 当 Il-2.exe 正在运行时，JoyPro 拒绝写入。
  2. 打开 导出。IL-2 卡片会显示它有多少个关联已绑定。
  3. 如果你是在 JoyPro 中设置摇杆的，请保持选择 在我的设备上替换 并勾选 同时清除我的其他设备。在 IL-2 卡片上按 立即导出。
在游戏中: 你在 IL-2 中看到的内容

启动 IL-2 并打开 Settings > Key mapping。你的绑定位于每个页签（例如 Plane controls）的操作行中，在你的设备上。从这次启动开始，游戏会使用 JoyPro 写入的轴响应。JoyPro 设置的力反馈和噪声过滤值显示在 Settings > Input devices 中。

#在 IL-2 中需要你自己做的事

  • 让 IL-2 写入一次它的按键映射。 如果 data\input 中还没有 global.actions，请打开 Settings > Key mapping 并按 ACCEPT。没有这个文件就没有可导入的内容，而且命令列表中只会有游戏已写入的操作。
  • 关于力反馈和噪声过滤值：打开一次 Settings > Input devices 并按 ACCEPT，让游戏创建它的 current.devices 文件。JoyPro 会修改这个文件，但不会创建它。
  • 如果要使用 JoyPro 自己基于游戏遥测数据的力反馈，力反馈 页面会把 JoyPro 的地址添加到游戏的 startup.cfg 中（请先关闭 IL-2）。然后为该摇杆关闭 IL-2 自己的力反馈。

#常见问题

  • “IL-2 正在运行”：完全关闭游戏，然后重新导出。
  • 绑定跑到了错误的设备上：IL-2 通过 devices.txt 中的编号区分设备。JoyPro 写入的设备会保留它的编号；新设备会获得最小的空闲编号。在导出和导入之间，请不要在游戏中重新给设备编号。
  • 使用“仅添加”后某个绑定不见了：该按钮在 IL-2 中已用于另一个操作。检查会把它列在“未写入游戏”下；请用 更新 导出，或者移动该绑定。
  • 力反馈值没有变化：游戏还没有 current.devices（见上文）。
高级

#JoyPro 读取和写入的文件

文件 这是什么
<install>\data\input\global.actions 按键映射：每个操作一行，`action, input, invert
<install>\data\input\devices.txt 设备列表：每个摇杆的编号、DirectInput GUID 和名称
<install>\data\input\current.responses 每个操作的轴响应行（居中、单向），适用于所有飞机
<install>\data\input\global.pitch 带中心偏移的俯仰行（只在你设置时创建）
<install>\data\input\jp.actions JoyPro 的副本，带有关联名称、分组、修饰键和调校，下次导入时会读回
<install>\data\input\current.devices Settings > Input devices：力反馈和摇杆噪声过滤器（就地修改）
<install>\data\startup.cfg 力反馈值和 JoyPro 的遥测地址

current.map 由 IL-2 在每次启动时根据这些文件编译生成；JoyPro 从不写入它。

#IL-2 中的导出模式

模式 IL-2 中会发生什么
仅添加 不会移除任何内容。如果某个绑定的输入已被 IL-2 用于另一个操作，该绑定不会被写入，并标记为“未写入游戏”。
更新，保留游戏的绑定 写入你的绑定；IL-2 的其他绑定保留，但你使用的输入上属于另一个操作的绑定除外。
更新，以我的配置文件为准 同上，此外，你绑定的每个操作都会失去它的其他输入（摇杆；键盘只在开启键盘选项时）。
在我的设备上替换 你写入的摇杆只保留你的绑定。
+ 同时清除我的其他设备 你的配置文件中没有绑定的已连接摇杆会失去它们的绑定。

global.actions 保持游戏的顺序；新行放在末尾。

#绝不会改动的内容

  • 未连接摇杆的行、导入时忽略的设备，以及 JoyPro 转发到的 vJoy 设备。
  • 鼠标行（包括带键盘按键的鼠标输入）、TrackIR，以及带有 JoyPro 无法读取的输入的行。
  • 键盘，除非你导出键盘绑定。
  • current.map 和游戏的其他文件。

#飞机、曲线、力反馈

  • 粒度：全局。每个操作一个按键映射和一个响应行，适用于所有飞机。
  • 轴曲线（轴模型 il2）：居中轴有中心死区、边缘死区和曲线（“sensitivity balance”）；油门等单向轴有低端和高端死区；俯仰有中心偏移。默认曲线 会被换算成 IL-2 的模型；你也可以只为 IL-2 设置曲线，或为 IL-2 系列设置（Great Battles 和 Korea 会读取彼此的值）。反转写在操作所在的行上。
  • 游戏设置（设置 > 游戏的力反馈设置）：摇杆噪声过滤器、力反馈开关、反馈力度和震动。即使导出中没有 IL-2 的绑定，也会写入这些设置。
  • 基于遥测数据的力反馈：JoyPro 根据游戏的遥测输出生成自己的效果（力反馈）。同一输出也用于遥测录制（CSV；遥测数据中没有世界坐标，所以没有 Tacview 航迹）。
  • HUD：IL-2 运行时，显示所按按钮的 IL-2 绑定（HUD）。
  • 监视器：你在 Key mapping 中更改的绑定会在 IL-2 关闭后被发现；JoyPro 会询问是否采用这些更改（监视器）。
技术细节

#IL-2 集成的内部原理

代码：engine\EngineIl2.cs（导入、导出、文件）、engine\EngineIl2DbRefresh.cs（命令列表）、engine\AxisModels（模型 il2）、engine\EngineFfbTelemetry.cs（遥测设置）。

  • 输入：joy<N>_b<button, 0-based>、joy<N>_axis_<x|y|z|...>、joy<N>_pov<hat>_<angle>，键盘按键用 DirectInput 名称，轴对写成 <input>/<input>，修饰键写成 <modifier>+<input>。IL-2 的苦力帽从 0 开始编号，JoyPro 从 1 开始（JOY_BTN_POV1_* 就是 pov0）。
  • 设备：devices.txt 列出 <number>,"<GUID>",<name>|；IL-2 会把 DirectInput 实例 GUID 的最后 8 个字节反转后作为一组写入。每种模式都会保留已列出的编号。
  • 命令列表：engine db refresh-il2 读取游戏写入的 *.actions 文件（不包括 jp.actions）；游戏的标签页（Service、Camera controls、Plane controls、Weapons controls ……）就是类别。游戏只写入有输入的操作，所以全新安装时的列表约有 376 个操作。
  • 导入 / 导出：engine il2 import、engine il2 scan、engine il2 export（--mode clean|add|merge|merge-overwrite --nuke-untouched-devices true|false --ignore-device <d>）。备份：首次写入前，每个文件都会备份为 <file>.jpbak 并存入备份存储。
  • 设置和曲线：engine ffb set --device * --game IL2Game，engine binds tuning set --scope game:IL2Game 或 family:il2，engine binds tuning preview。
  • 遥测：engine ffb telemetry setup il2 会在 startup.cfg 的 telemetrydevice 段中添加一行地址 127.0.0.1:41994，从不更改其他工具的地址；--remove 会逐字节恢复该文件。
  • 监视器：engine sync status、engine sync diff（监视的文件：global.actions、devices.txt、current.responses、current.devices、startup.cfg）。

#已知限制

  • 游戏文件中没有输入的操作，不会出现在新生成的命令列表中。
  • 如果某个摇杆使用 JoyPro 基于遥测数据的力反馈，必须关闭游戏自己的力反馈。
  • 测试：engine\tests\smoke\il2.ps1；游戏内测试 tools\e2e\games\IL2Game.ps1（绑定，38 个步骤全部通过）和 IL2GameCurves.ps1（把游戏编译的响应与 JoyPro 的预览进行比较）。
