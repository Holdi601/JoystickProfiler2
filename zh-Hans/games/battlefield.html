新手入门

#3 步上手

  1. 全部帮我设置好
    然后点 使用这些按钮
  2. 使用
    然后在启动游戏前按 开始
  3. 在游戏中绑定 vJoy
    在游戏的摇杆页面
  1. 在开始页面按 全部帮我设置好。查看列表。按 使用这些按钮。JoyPro 会为喷气机和直升机选好按钮。
  2. 打开 虚拟摇杆 页面。如果缺少 vJoy 和 HidHide，请在那里安装。按 Battlefield 旁边的 使用。在启动游戏之前按 开始。
  3. 在游戏中打开摇杆页面。点击某一行的框，然后按下你的按钮。游戏只会看到一个摇杆：“vJoy Device”。

JoyPro 暂时还不写入 Battlefield 的摇杆绑定，所以第 3 步需要你自己完成。详情见下文。

#JoyPro 为 Battlefield 做了什么

  • 游戏只看到一个设备：在虚拟模式下，你的摇杆、油门和脚舵在 Battlefield 看来是一个 vJoy 摇杆，其输入的位置永远不会变化。其他所有程序仍然看到你的真实设备。
  • 键盘按键：当你选择包含键盘时，JoyPro 会读取和写入喷气机和直升机按钮操作的键盘按键。
  • 摇杆绑定：JoyPro 会读取它们（并给出警告），但暂时不会写入。游戏对摇杆输入的编号方式尚未确认；在确认之前，你需要自己在游戏的摇杆页面上绑定 vJoy 设备。

#导入

  1. 启动一次游戏，让它写入设置配置文件。在此之前，JoyPro 会列出自己的喷气机和直升机操作表；第一次导入时会用你配置文件中的操作替换它。
  2. 打开 开始 页面，在 Battlefield 6（或 2042）卡片上按 导入，如果需要键盘按键，勾选 同时获取键盘按键，然后按 立即导入。

#设置虚拟摇杆

  1. 打开 虚拟摇杆 页面。在 此页面需要的组件 下，如果缺少 vJoy 和 HidHide，请安装它们。
  2. 在 游戏 下，把 Battlefield 6 切换为 vJoy（JoyPro 会在那里用 使用 推荐它）。
  3. 如果页面提供 按表格设置 vJoy，请按下它：JoyPro 会把 vJoy 设备设置为不带 Rx 和 Ry 轴，因为 Battlefield 会把带 Rx / Ry 的摇杆当作 Xbox 手柄。Windows 必须重启，vJoy 的更改才会生效。
  4. 在启动游戏之前按 开始，玩完后按 停止。

#建立并检查关联

在 关联 页面把你的 HOTAS 绑定到 Battlefield 的喷气机和直升机操作上（关联流程）：只有包含 Battlefield 操作的关联，其输入才会在 vJoy 设备上获得位置。喷气机和直升机是不同的载具，所以同一个按钮在两者中可以有不同的作用。

#导出

  1. 关闭游戏。
  2. 打开 导出，保持选择 在我的设备上替换，在 Battlefield 卡片上按 立即导出。如果你在导入时勾选了键盘，就会写入键盘按键（这个选择按游戏分别保存）。摇杆绑定会被列为未写入。
  3. 之后 启动一次游戏 并查看绑定：Steam 云和 EA 会同步设置文件夹，云端的副本可能会覆盖本地的。
在游戏中: 你在 Battlefield 中看到的内容

虚拟摇杆运行时，游戏中唯一的摇杆是“vJoy Device”。在 Battlefield 6 中，飞机相关的行位于齿轮图标 > CONTROLLER > EDIT SETTINGS > JOYSTICK > Aircraft EDIT（“AIRCRAFT PILOT CONTROL MAPPING”）：每一行显示 UNBOUND 或绑定，例如“AXIS 1 X -”。JoyPro 写入的键盘按键会显示在游戏的键盘绑定中。

#在 Battlefield 中需要你自己做的事

  • 在上面提到的摇杆页面上 在游戏中绑定 vJoy 设备：点击某一行的框，然后移动该输入。游戏会绑定它看到的第一个输入，因此它应该只能看到 vJoy（虚拟摇杆正在运行）。
  • 为该游戏 关闭 Steam Input。
  • 如果游戏仍然能看到你的真实设备（有玩家反映 Battlefield 6 能看到被 HidHide 隐藏的设备），请在游玩时拔掉它们；vJoy 设备会承载所有输入。

#常见问题

  • 游戏中没有摇杆页面：摇杆带有 Rx 或 Ry 轴，游戏把它当作了 Xbox 手柄。把 vJoy 设置为不带这些轴（见上面第 3 步），然后重启 Windows。
  • 某一行绑定了一个抖动的轴：游戏仍然能看到另一个设备。请在启动游戏之前启动虚拟摇杆，或者拔掉真实设备。
  • 只导出了一个设备：游戏只读取一个摇杆；JoyPro 会写入绑定最多的设备，并列出其他设备（“使用虚拟摇杆”）。

#虚拟摇杆的工作原理

#JoyPro 读取和写入的文件

游戏 文件 这是什么
Battlefield 6 %USERPROFILE%\Documents\Battlefield 6\settings\steam\PROFSAVEbf6mp_profile 和 PROFSAVE_profile 多人游戏和战役配置，文本行 GstKeyBinding.<category>.<Concept>.<slot>.axis <n>（还有 .button、.negate、.type）；EA app 版本没有 steam 文件夹
Battlefield 2042 %USERPROFILE%\Documents\Battlefield 2042\settings\PROFSAVE_profile 格式相同

导出会写入该文件夹中所有包含绑定的 *_profile，因此战役和多人游戏保持一致。不带 _profile 的二进制 PROFSAVE 文件不包含绑定，永远不会被改动。备份与每次导出相同（.jpbak 和 JoyPro 的备份存储），JoyPro 的名称和分组保存在 <profile>.joypro-meta.json 中。

#Battlefield 中的导出模式

只有喷气机和直升机的槽位会改变。士兵和地面载具的槽位、鼠标和手柄槽位、轴操作上的按键，以及 JoyPro 的表读不了的摇杆代码，永远不会改变。

模式 会发生什么
仅添加 如果某个绑定的输入已被同一载具的另一个操作使用，该绑定会被跳过（标记为“未写入游戏”）；不会释放任何槽位。
更新，保留游戏的绑定 配置文件所用输入上另一个操作的槽位会被释放；该操作已绑定的槽位保留。找不到空闲槽位的绑定不会被写入。
更新，以我的配置文件为准 同上，此外，该操作的其他槽位（开启键盘选项时的按键）会被释放；已绑定的槽位会改用配置文件中的输入。
在我的设备上替换 导出所写内容的飞行槽位会被释放：导出按键时释放键盘按键（写入摇杆绑定后则释放摇杆槽位）。
+ 同时清除我的其他设备 没有其他设备需要清除：游戏只读取一个摇杆。

#绝不会改动的内容

  • 步兵、地面载具、运输和炮手的绑定；鼠标和手柄槽位。
  • 轴操作上的键盘按键（这些按键对由游戏管理），以及未开启键盘选项时的键盘按键。
  • 摇杆槽位，直到编号得到确认。
  • HidHide 只对游戏的可执行文件隐藏你的真实设备，而且只在虚拟摇杆运行期间；停止 会把 HidHide 精确恢复到之前的设置。

#轴和其他设置

  • 按载具类别：喷气机和直升机在游戏配置中是不同的类别；JoyPro 两者都会写入。
  • 只有 反转：轴被写成两半，反转 会交换它们。没有曲线或死区，也没有修饰键。
  • 苦力帽：只有四个方向，斜向会被跳过。玩家能看到大约 18 个按钮；超过这个数尚未确认。
  • 监视器：配置文件会在游戏关闭后被监视（监视器）。
  • HUD：游戏运行时，HUD 会显示每个按下按钮对应的操作名称。
  • 虚拟功能（切换、轴区段、短按 / 长按……）可以在 Battlefield 的 vJoy 设备上使用。

#Battlefield 集成的内部原理

代码：engine\Games\BattlefieldIntegration.cs（Battlefield 6 和 2042 共用一个类）；virtual-joystick 的 vJoy 规划器、转发器和 HidHide 会话。

  • 绑定行：type 0 为鼠标，1 为手柄，2 为键盘（button = DIK 扫描码，255 = 无），3 为摇杆；“未绑定”是轴 56（Battlefield 6）或 27（2042）以及按钮 60。negate 1 = 该槽位以负方向驱动操作。默认配置中每个轴操作有两个空的摇杆槽位（negate 0 和 1）；按钮操作获得槽位 n+1，它的四行放在排序后的位置。
  • 设备：绑定中不指明设备；JoyPro 写入一个摇杆。游戏声明自己是单设备游戏（1 个摇杆，建议模式 virtual，避开 vJoy 轴 Rx 和 Ry），因此规划器不会给任何输入分配 Rx / Ry，engine vjoy configure-vjoy 设置设备时也不包含它们。
  • 摇杆编号：一张取自 Battlefield 4 已解码方案的临时表（X / Y 为 Axis1X / Axis1Y，Z / Rx / Ry / Rz 为半轴按钮代码 36-43，按钮 n 为代码 n-1，苦力帽 n 为 44 + 4(n-1) + 方向）。游戏自己的默认值与它不符，所以在没有确认的表之前，JoyPro 读取摇杆绑定时会给出警告，并且不写入任何摇杆绑定。实时调查脚本 tools\e2e\games\BattlefieldJoystickSurvey.ps1 会生成确认的表 <engine>\TOOLS\Conversions\Battlefield6JoystickMap.tsv（Battlefield2042JoystickMap.tsv）。
  • 命令：engine bf6 paths、engine bf6 catalog、engine bf6 scan、engine bf6 import、engine bf6 export --include-keyboard --mode clean|add|merge|merge-overwrite --dry-run、engine bf6 refresh-db；engine bf2042 export 及其同类命令相同。虚拟模式：engine vjoy mode Battlefield6 virtual、engine vjoy map、engine vjoy apply-hidhide。

#已知限制

  • 在调查确认编号之前，不会写入摇杆绑定。
  • Battlefield 2042 是在没有安装游戏的情况下，根据相同格式实现的。
  • 大约 18 个以上的按钮，以及半轴是否会被保存为整轴，尚未确认。
  • 测试：engine\tests\smoke\battlefield.ps1；调查脚本 tools\e2e\games\BattlefieldJoystickSurvey.ps1、BattlefieldSurveyAuto.ps1、BattlefieldAdminSession.ps1（vJoy 设置需要一个可以重启 Windows 的时间段）。
