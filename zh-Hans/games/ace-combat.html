ACE COMBAT

显示：

ACE COMBAT 是一个街机风格的空战系列，它目前的两款 PC 游戏在 HOTAS 支持上截然不同。ACE COMBAT 8 不读取飞行摇杆，只读取 Xbox 手柄。JoyPro 会把你的摇杆、油门和脚舵变成一个模拟手柄（虚拟 Xbox 手柄），并且不往游戏里写入任何内容。ACE COMBAT 7 自己读取你的摇杆，并把绑定保存在一个文本文件 Input.ini 中：JoyPro 会像对待其他游戏一样读取和写入它。ACE COMBAT Zero 和 Assault Horizon 只有文档说明。

新手入门

#3 步上手

#ACE COMBAT 8

  1. 全部帮我设置好
    然后点 使用这些按钮
  2. 设置模拟手柄
    然后点 测试
  3. 启动游戏
    在标题画面：Alt+Tab，点 开始

#ACE COMBAT 7

  1. 启动一次游戏
    然后关闭它
  2. 全部帮我设置好
    然后点 使用这些按钮
  3. 写入我的游戏
    保持游戏关闭

#ACE COMBAT 8：一次性设置

  1. 在开始页面按 全部帮我设置好。也可以在欢迎界面选择 用我的飞行摇杆玩 ACE COMBAT：随后会有一段简短的导览带你完成每一步。
  2. 查看各个功能分配到哪里的列表。按 使用这些按钮。
  3. 按 设置模拟手柄。设置窗口会关闭，并打开虚拟摇杆页面。
  4. 模拟手柄需要一个名为 ViGEmBus 的免费辅助程序。勾选其许可协议下方的复选框，然后按 安装 ViGEmBus。Windows 会请求权限：点击 是。这一步只需要做一次。
  5. 按 测试。移动你的摇杆，手柄图片会跟着动。按一个按钮：它会亮起来。

你不需要切换任何东西。ACE COMBAT 8 会自动使用模拟手柄。页面上会显示“自动使用 Xbox 手柄：该游戏只读取 Xbox 手柄”。这个游戏不需要 HidHide：它反正看不到你的真实摇杆。

#ACE COMBAT 8：每次游玩时

  1. 启动 ACE COMBAT 8，等待它显示标题画面。
  2. 按住 Alt 再按 Tab，你就回到了 JoyPro。
  3. 按 开始。
  4. 再按一次 Alt+Tab，你就回到了游戏中。起飞吧！
  5. 玩完后，按 停止。
先开游戏，再按开始

只有在游戏显示标题画面时才按 开始。按早了？JoyPro 会提示“太早了”。先按 停止，再按 开始。每次游玩都要这样做。

#ACE COMBAT 8 中各功能的位置

在你的 HOTAS 上 在模拟手柄上 在游戏中
摇杆前推、后拉、左压、右压 左摇杆 俯仰和滚转
油门杆 前推：RT。后拉：LT。 加速和减速
摇杆扭转（或脚舵） LB 和 RB，约从 30 % 起 向左和向右偏航
摇杆上一个空闲的苦力帽 右摇杆 环顾四周
你的热焰弹按钮 L3 和 R3 同时按下 热焰弹（尚未在游戏中确认）
你的通讯开关或 AI 菜单苦力帽 十字键 僚机指令
一个名为“High-G”的按钮关联 两个扳机都按到底 高 G 转弯

虚拟摇杆页面的 实时测试 页签会显示每个按钮的作用，例如“A: Fire machine gun”。

热焰弹尚未在游戏中确认

JoyPro 会同时按下 L3 和 R3 来投放热焰弹。目前还没有人在游戏中确认过这一点，JoyPro 也会这样提示。

#用苦力帽环顾四周

游戏通过模拟手柄的右摇杆来环顾四周。JoyPro 会把它放到你摇杆上一个空闲的苦力帽上。按住苦力帽的某个方向，视角就会朝那边转。通常这是摇杆顶部的苦力帽。这个苦力帽在你的其他游戏中保持原来的功能，例如在 DCS 中用于配平。参见 头部追踪和环顾四周。

#ACE COMBAT 7：快速方法

  1. 在连接好所有设备的情况下 启动一次 ACE COMBAT 7，然后退出。游戏会在关闭时写入 Input.ini。
  2. 在开始页面按 全部帮我设置好。查看列表。按 使用这些按钮。
  3. 关闭游戏。 按 写入我的游戏。JoyPro 会保留一份旧文件的副本。

你以前在 ACE COMBAT 7 中绑定过按钮吗？那么开始页面会提供 导入，然后填补空缺。你的绑定会保留，只有空闲的按钮会获得新功能。

#ACE COMBAT 7：导入你自己的绑定

  1. 在连接好所有设备的情况下 启动一次 ACE COMBAT 7，然后退出。
  2. 打开 开始 页面。在该文件存在之前，JoyPro 使用自己的 20 个飞行操作列表。卡片上的 更新 会根据你的文件生成列表。
  3. 在 ACE COMBAT 7 卡片上按 导入，保持选择 添加到我的配置文件（推荐），然后按 立即导入。

#建立并检查关联

一个关联可以同时包含 ACE COMBAT 7 和 ACE COMBAT 8 中同一功能的操作。这样两个游戏都能从同一个按钮获得它（关联流程）。检查功能会找出在 ACE COMBAT 7 中同时做两件事的按钮。在底部栏按 检查，或在导出页面按 立即检查（检查）。

#导出

  • ACE COMBAT 7：关闭游戏，打开 导出，保持选择 在我的设备上替换 并勾选 同时清除我的其他设备，然后在它的卡片上按 立即导出。
  • ACE COMBAT 8：导出不会写入任何内容，并会说明这一点。只要 开始 处于开启状态，你的绑定就会通过模拟手柄传到游戏中。
在游戏中: 你在 ACE COMBAT 中看到的内容

ACE COMBAT 8 只会看到一个 Xbox 手柄：菜单中显示的是手柄按钮，SYSTEM > CONTROLS > CONTROLLER > BUTTON MAPPING 会列出九个可重新映射的操作（向左和向右偏航、加速、减速、机枪射击、导弹发射、切换武器、切换目标、雷达地图）及其手柄按钮。你的摇杆会像手柄的左摇杆一样移动菜单焦点。

ACE COMBAT 7 没有用于重新映射飞行摇杆绑定的菜单：它从 Input.ini 读取这些绑定。它的控制菜单是否会显示这些绑定目前尚未确认。JoyPro 的游戏内测试已确认：游戏在退出时重写该文件时，会保留 JoyPro 写入的每一个值。

#需要你自己做的事

  • ACE COMBAT 8：每次游玩时都要在标题画面按 开始（见上文）。
  • ACE COMBAT 8：在 BUTTON MAPPING 中更改手柄按钮后，在该游戏的卡片上按 更新，然后在虚拟摇杆页面按 更新映射。之后 JoyPro 就会跟随你的新按钮。
  • ACE COMBAT 7：在连接每个设备的情况下各启动一次游戏。文件中没有对应段落的设备会被跳过，并提示“请在连接此设备的情况下启动一次游戏”。为该游戏关闭 Steam Input。

#常见问题

  • ACE COMBAT 8 没有反应：是不是 开始 按得太早了？在标题画面先按 停止，再按 开始。
  • ACE COMBAT 8：机头朝错误的方向：你是否在游戏中设置了“Pitch Controls: Inverted”？请参见“高级”部分。
  • ACE COMBAT 8：没有 ViGEmBus：没有它，游戏就看不到你的摇杆。请在虚拟摇杆页面安装它。
  • ACE COMBAT 7：某个轴停在一半：游戏会把同一操作在所有设备上的值取平均。油门在 100 %，而同一操作在一个滑块上为 -100 %，结果就是 50 %。每个轴操作只在一个设备上绑定（更新，以我的配置文件为准 会清除其他设备上的绑定）。
  • ACE COMBAT 7：两个相同型号的摇杆 共用一个段落；游戏无法区分它们。

更多：用 HOTAS 玩只支持 Xbox 手柄的游戏。

高级

#模拟手柄的工作原理

  • 不需要 HidHide。 ACE COMBAT 8 只读取 Xbox 手柄，因此它根本看不到你的真实摇杆。不需要隐藏任何设备，Windows 也不会要求管理员权限。HidHide 只用于设为 vJoy 的游戏。
  • 模式会自动切换。 只要你还没有选择模式，游戏就使用 Xbox 手柄。在虚拟摇杆页面上选择其他模式后，JoyPro 会保留你的选择。
  • 游戏的布局优先：每个用于 ACE COMBAT 8 操作的关联都会固定到游戏为该操作使用的手柄控件上（从游戏存档中读取）。俯仰和横滚放在左摇杆，环视放在右摇杆。
  • 油门：油门杆同时驱动两个扳机。向前是 RT，向后是 LT，中间是空挡。即使“减速”放在另一个关联中（例如脚尖刹车），这也同样有效。
  • 偏航：摇杆扭转（没有时用脚舵）在偏转约 30 % 时按下 LB 和 RB。
  • 环视：如果环视操作上没有轴，一个空闲的苦力帽会驱动右摇杆（“苦力帽转轴”）。按住某个方向时，摇杆会一直推到底；斜向会同时移动两个方向。JoyPro 会选用你在其他游戏中用于环视或视角关联的苦力帽，否则使用摇杆顶部的苦力帽。环视操作上如果有空闲的小摇杆，总是优先使用它。
  • 干扰弹：L3 和 R3 同时按下 120 ms，来自你的干扰弹或对抗措施关联。尚未在游戏中确认。
  • 僚机指令 放在十字键上，来自你的通信开关或 AI 菜单苦力帽。
  • 高 G 转弯：名为“High-G”的按钮关联会按住两个扳机。带有 DCS 的 ASC Direct Control（Su-27、Su-33 和 J-11A 的“眼镜蛇按钮”）的关联也是如此。扳机上的油门照常工作。
  • 一个输入，一项功能：驱动上述某项功能的输入会从表中移除，因此它永远不会同时按下两个控件。
  • 你的曲线会传到手柄。 轴响应（绑定页面）中的死区、饱和度、曲线和反转会应用到手柄的摇杆或扳机上。如果要单独设一条曲线，在 应用于 下只勾选 ACE COMBAT 8。否则使用 默认曲线。
  • 俯仰：DCS 的反转不会传到手柄。默认情况下，向前推摇杆是机头向下。如果游戏中设置了“Pitch Controls: Inverted”，就只为 ACE COMBAT 8 取消勾选反转（轴响应，应用于：ACE COMBAT 8）。
  • 横滚方向反了：JoyPro 会原样传递横滚。在横滚关联上只为 ACE COMBAT 8 勾选反转。
  • 手柄 放不下的内容（两个摇杆、两个扳机、14 个按钮、十字键）会列在虚拟摇杆页面上。
  • 多个游戏使用手柄：ACE COMBAT 7 和 8 都可以使用它，各自有自己的表。开启自动启动时，正在运行的游戏的表会生效。否则在 “开始”和“测试”使用的Xbox 手柄表 下选择。
  • 自动启动 会在游戏启动后约 3 秒内、标题画面出现之前创建手柄。对这款游戏来说这可能太早了：这时请在标题画面按 停止，再按 开始。
  • 专家：vJoy、HidHide、转发频率和各种模式都在 显示专家详情（vJoy、HidHide、模式） 下。
  • ACE COMBAT Zero 随附在 ACE COMBAT 8 的文件夹中（ACZero\acz.exe）。它还没有经过研究：想尝试的话，手动为 ACE COMBAT 8 按 开始，然后启动 Zero。未经测试。

#ACE COMBAT 7 中的导出模式

每个操作和设备一个输入。菜单键（UI_*）和 JoyPro 不读取的组合永远不会被更改。

模式 会发生什么
仅添加 在该设备上已有值的操作会保留它；如果某个绑定所用的输入已被游戏用于另一个操作，该绑定不会被写入，并标记为“未写入游戏”。
更新，保留游戏的绑定 写入配置文件中的值；同一输入上的另一个操作会被释放；该操作在其他设备上的值保持不变（游戏会取平均值的轴会被报告）。
更新，以我的配置文件为准 同上，此外，配置文件绑定的每个操作在其他已连接设备上都会被清除。
在我的设备上替换 JoyPro 写入的段只保留你的可读值；已写入的轴仍会在其他已连接设备上被清除。
+ 同时清除我的其他设备 其他已连接设备的可读值会被清除。

Input.ini 的注释、顺序、编码和换行符保持不变。ACE COMBAT 8 没有导出模式：不会写入任何内容。

#绝不会改动的内容

  • ACE COMBAT 7：键盘、菜单键、组合、未连接设备的段、导入时忽略的设备，以及 JoyPro 转发到的 vJoy 设备。
  • ACE COMBAT 8：游戏的所有文件，以及 HidHide。

#轴、监视器、HUD

  • ACE COMBAT 7：全局绑定（没有飞机配置）；只有反转（:R），没有曲线或死区；游戏每个设备最多读取 32 个按钮、8 个轴和 4 个苦力帽（每个四个方向）；没有修饰键。
  • 监视器：ACE COMBAT 7 的 Input.ini 会在游戏关闭后被监视（监视器）；ACE COMBAT 8 没有 JoyPro 写入的内容，所以没有需要监视的。
  • HUD：游戏运行时，HUD 会显示每个按下按钮对应的操作名称。
  • 两款游戏都没有力反馈，也没有遥测数据。
技术细节

#ACE COMBAT 集成的内部原理

代码：engine\Games\AceCombat7Integration.cs、engine\Games\AceCombat8Integration.cs；virtual-joystick 的手柄规划器和转发器，手柄自身的功能在 engine\VJoy\XboxPadAutoSetup.cs 中。

  • ACE COMBAT 7 的段：Joystick- + DirectInput 产品 GUID（PID 高位字 + VID，然后是 504944564944，即“PIDVID”）。对象 X Y Z Rx Ry Rz Slider1 Slider2、Button1-Button32、POV_U/D/L/R1-4；选项 :P / :N（半轴）、:R（反向）、:C（-1..1 作为 0..1）；组合 &、!、+、>、<；空值表示未绑定。JoyPro 把轴写成 X 或 Y:R，按钮写成 ButtonN，苦力帽方向写成 POV_<U|D|L|R><n>。组合和半轴会在导入时报告，但不会被读取。
  • ACE COMBAT 7 的操作：轴 Flight_Pitch/Roll/Yaw/Throttle/CameraPitch/CameraYaw；按钮 Flight_Gun/Missile/Target/Weapon/Radar/Flare/View/AccelerationDeceleration/AutoPilot/Pause 和 Flight_HatSwitchUp/Down/Left/Right。engine ac7 refresh-db 从你的文件中获取 Flight_* 键。
  • ACE COMBAT 8：System.sav 是带 Checksum 的 Unreal GVAS；它以 Unreal 按键名保存九个手柄按键（YawLeftKey_Controller = Gamepad_LeftShoulder ……）。engine ac8 refresh-db 把它们读成每个控件一个 Pad_* 操作，按键放在列表的第 5 列；摇杆来自 JoyPro 自己的表。
  • 手柄模式：游戏声明 MaxJoysticks 为 0，建议模式为 xbox，因此没有保存的选择时，它的模式就是 xbox（VJoySettings.ModeOf）。engine vjoy mode AceCombat8 xbox 会保存一个选择。engine vjoy map、engine vjoy forwarder-config --xbox-game AceCombat8。没有 HidHide 步骤：如果只有这类游戏处于虚拟模式，engine vjoy apply-hidhide 会显示“不需要 HidHide”，并且不会以管理员身份启动任何程序。
  • 手柄功能：油门拆分（XB_TRIGGERS）、偏航（“轴末端转按钮”，末端区域 0.35）、干扰弹组合键（IGamePadChords.PadChords，Confirmed = false）、十字键、高 G 按住（PadHolds）和环视苦力帽（hat-axes，IGamePadConventions.PadLookActions = Pad_CameraYaw / Pad_CameraPitch）在每次规划时都会重新生成。Pad_Pitch 默认反向（PadInvertDefault）。
  • 检查：engine vjoy pad-check 报告配置文件在手柄上能控制到什么（俯仰、横滚、机炮、导弹、目标、油门拆分、偏航、组合键、按住、十字键、环视），并给出评分。
  • 命令：engine ac7 paths、engine ac7 scan、engine ac7 import、engine ac7 export；engine ac8 scan、engine ac8 import、engine ac8 export（不写入任何内容）。

#已知限制

  • ACE COMBAT 7：控制菜单是否显示摇杆绑定，以及俯仰带 :R、油门带 :C 的飞行，都尚未确认。
  • ACE COMBAT 8：干扰弹组合键（L3 + R3）和视角按钮尚未在游戏中确认。
  • ACE COMBAT 8：只有游戏本身支持的少数几款摇杆（一款 Thrustmaster 和一款 HORI 型号）不需要手柄也能使用；JoyPro 不会写入它们的设置。
  • 测试：engine\tests\smoke\acecombat7.ps1、acecombat8.ps1；游戏内测试 tools\e2e\games\AceCombat7Settings.ps1（导出、启动、重写后的文件仍包含所有值、导入）和 AceCombat8Xbox.ps1（使用虚拟手柄操作菜单，手柄在标题画面出现后创建）。
