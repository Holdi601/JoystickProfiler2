新手入门

#3 步上手

  1. 全部帮我设置好
    在开始页面
  2. 使用这些按钮
    先查看列表
  3. 写入我的游戏
    保持 Elite Dangerous 关闭

之前：在游戏中保存一次你的控制设置。更改一个飞船控制，保存，然后关闭游戏。

然后：启动游戏时，请保持预设中的每个设备都已连接。你的绑定位于 Options > Controls 中。

你以前在 Elite Dangerous 中绑定过按钮吗？那么开始页面会提供 导入，然后填补空缺。你的绑定会保留，只有空闲的按钮会获得新功能。参见 快速入门：让我的摇杆能用。

#JoyPro 为 Elite Dangerous 做了什么

  • 导入：你的摇杆、油门和面板上的飞船飞行绑定会连同它们的反转和死区设置一起进入你的配置文件，还包括你的油门是只能向前还是带倒车。
  • 关联：一个关联就是所有游戏中的同一个功能。“Landing gear”可以是 Elite、Star Citizen 和 DCS 中的同一个开关。
  • 导出：JoyPro 会就地编辑你的 Ship 预设（Custom.4.x.binds）。文件中的其他内容保持不变。

#导入你的 Elite 绑定

  1. 打开 开始 页面。如果 Elite Dangerous 卡片要求生成命令列表，按 生成列表：JoyPro 会从游戏自带的预设和你保存的预设中收集游戏的操作（只读）。
  2. 在 Elite Dangerous 卡片上按 导入。保持选择 添加到我的配置文件。如果你也想把飞行按键导入 JoyPro，请勾选 同时获取键盘按键。
  3. 按 立即导入。查看我的关联 会打开导入的内容。

把半个轴当作按钮或修饰键使用的绑定无法保存在 JoyPro 配置文件中：导入时会跳过它并给出警告，导出时会把它留在游戏中。

#建立并检查关联

用 关联流程 把你各个游戏中的同一功能连接起来。然后在导出页面按 检查。除了一个按钮做两件事的情况，检查还会在 未写入游戏 下列出上次导出时没有位置可放的每个绑定，并提供 移到另一个按钮 和 保持原样。

#导出到 Elite

  1. 关闭 Elite Dangerous。 游戏运行时 JoyPro 拒绝写入。
  2. 打开 导出 并勾选 Elite Dangerous 卡片。
  3. 如果你是在 JoyPro 中设置摇杆的，请保持选择 在我的设备上替换 并勾选 同时清除我的其他设备。在卡片上按 立即导出。
  4. 阅读结果：放不下的绑定以及 JoyPro 保留的半轴绑定都会用通俗的话列出来。
在游戏中: 你在 Elite Dangerous 中看到的内容

启动游戏并打开 Options > Controls，然后打开飞船控制。你的绑定位于每个操作的 Primary 或 Secondary 列中，在你保留的键盘按键旁边。反转的轴显示 INVERTED，油门在其轴范围下显示 Forward only 或 Full range，偏航转滚转和头部视角这几行显示你在 JoyPro 中设置的值。

#在 Elite 中需要你自己做的事

  • 在游戏中保存一次你的控制设置。 JoyPro 只会写入你自己保存过的预设。如果你的 Ship 控制仍在使用游戏自带的预设（Generic Joystick 或游戏的某个 HOTAS 预设），请在 Options > Controls（Ship）中更改一个控制，保存，然后关闭游戏：之后 Elite 会创建并使用 Custom.4.x.binds。
  • 启动游戏时，保持预设中的每个设备都已连接。如果预设中指明的某个设备找不到，Elite 会忽略整个预设。当你的预设指明了一个未连接的设备时，JoyPro 会发出警告。

#常见问题

  • “Elite Dangerous 正在运行”：退出游戏，然后重新导出。
  • “游戏中没有空位”：Elite 每个操作只有两个输入位置。如果一个键盘按键占用了一个位置，而你的两个关联把这个操作放到了两个按钮上，那么只有第一个按钮放得下。移动第二个按钮，或者保持原样。
  • 两个相同的摇杆：Elite 只通过 USB ID 区分设备。同一型号的两个已连接设备无法与游戏的索引对应，因此 JoyPro 会跳过这两个设备。
  • 游戏加载了另一个预设：启动时预设中的某个设备不在。请连接它、在 JoyPro 中更换它，或者在游戏中清除它的绑定。
  • Elite 中没有 苦力帽斜向：每个苦力帽只有四个方向。
高级

#JoyPro 读取和写入的文件

文件 这是什么
%LOCALAPPDATA%\Frontier Developments\Elite Dangerous\Options\Bindings\<preset>.4.<minor>.binds 你的预设（XML）：每个操作带 Primary 和 Secondary，轴带 Binding、Inverted 和 Deadzone，以及 ThrottleRange 等数值设置。JoyPro 写入 Ship 预设的最新次版本。
...\Bindings\StartPreset.4.start 每个类别（General、Ship、SRV、On Foot）使用哪个预设；只读
...\Bindings\<preset>.4.<minor>.binds.joypro-meta.json JoyPro 为已写入的绑定保存的名称、分组、修饰键和调校，下次导入时会读回
...\Bindings\<preset>.4.<minor>.binds.jpbak 首次写入之前的副本，以及 JoyPro 带版本的备份存储
<install>\Products\<product>\ControlSchemes\*.binds、DeviceMappings.xml 自带的预设和游戏的设备名称；只读

文件按文本编辑：换行符、制表符、声明、重复元素、数值设置、你的键盘布局和未知元素都逐字节保留。JoyPro 从不写入安装文件夹，从不编辑 StartPreset.4.start，也从不改动旧版 3.x 客户端的文件。

星系地图操作属于 General 预设。只有当 General 和 Ship 使用同一个文件时，JoyPro 才会写入它们；否则会跳过并给出警告。

#Elite 中的导出模式

每种模式都只处理飞行操作和已连接摇杆的位置。

模式 预设中会发生什么
仅添加 绑定只会放入空闲位置。如果某个绑定的输入已被另一个飞行操作使用，该绑定不会被写入，并标记为“未写入游戏”。
更新，保留游戏的绑定 你使用的输入上另一个飞行操作的位置会被释放。你的绑定优先放入空闲位置，因此只要还有空闲位置，你移动过的操作就会保留它原来的输入。
更新，以我的配置文件为准 同上，此外，你绑定的每个操作都会失去它在你的摇杆上的其他位置（键盘只在开启键盘选项时才处理）。
在我的设备上替换 在你写入的设备上，每个包含该设备绑定、但不在你的配置文件中的飞行位置都会被清空（{NoDevice}；轴还会设为 Inverted 0 和 Deadzone 0）。
+ 同时清除我的其他设备 导出未使用的已连接摇杆的飞行位置也是如此。

如果某个位置上是键盘按键、鼠标或手柄输入，或者是 JoyPro 不写入的设备，它永远不会被覆盖。如果没有剩余位置，绑定不会被写入，配置文件会保留一个标记（“未写入的绑定：游戏中没有空闲位置”）。如果某个轴操作唯一的位置上放着你配置文件中的另一个轴，也是同样的处理。

#绝不会改动的内容

  • SRV、徒步、相机、殖民、UI 和鼠标操作，即使它们位于同一个文件中。
  • 键盘、鼠标和手柄位置；键盘只在开启键盘选项时才会写入，并且永远不会被清除。
  • 未连接设备的位置、导入时忽略的设备，以及 JoyPro 转发到的 vJoy 设备。
  • 半轴绑定和半轴修饰键：导出会保留它们并逐一列出，例如“'Cycle Next Ship'：保留了游戏的绑定 ... 带 ... RZ 轴，正半轴作为修饰键”。
  • 操作的 <Hold> 和 <ToggleOn> 保持原样。

#飞船、曲线、游戏设置

  • 粒度：所有飞船和战机共用一个 Ship 预设。SRV 和徒步预设不会被写入。
  • 修饰键：每个位置最多三个；可以是按键，也可以是任何设备的按钮。JoyPro 把它的修饰键写成游戏的 <Modifier> 条目。
  • 轴设置：每个轴操作的反转和死区（0 到 1）；Elite 中没有饱和度，也没有曲线。反转在你的关联中保持 DCS 的方向：Elite 对俯仰、油门和垂直推进器的计算方向相反，所以对这些轴来说，文件中的 Inverted 是你的反转取反后的值。油门关联的 滑块 决定 Throttle Axis Range：滑块 = 仅向前，无滑块 = 带倒车的全范围（多个油门关联不一致时会给出警告）。
  • 游戏设置：偏航转横滚（普通、关闭飞行辅助、着陆）、其灵敏度、键盘油门增量、头部视角模式、增量、灵敏度、平滑以及切换时重置。在 设置 > 游戏的力反馈设置（选择 Elite Dangerous）中或用 engine ffb set 设置。只写入你设置过的设置，并就地修改；文件中缺少的设置会被报告，但绝不会被添加。鼠标、SRV 和徒步设置不受管理。
  • 力反馈：Elite 不支持摇杆力反馈。
  • 遥测录制：JoyPro 可以把 Status.json 和日志（Saved Games\Frontier Developments\Elite Dangerous，只读）录制为 CSV 会话；游戏不提供世界坐标，所以没有 Tacview 航迹。
  • 监视器：你在游戏控制菜单中更改的绑定会在游戏关闭后被发现；JoyPro 会询问是否采用这些更改。只有当你在游戏控制菜单中保存时，游戏才会写入预设。
  • HUD：HUD 通过进程识别游戏，并显示你的 Elite 绑定。
技术细节

#Elite 集成的内部原理

代码：engine\Games\EliteDangerousIntegration.cs、轴模型 engine\AxisModels\EliteDangerous.cs 和设置模型 engine\FfbModels\EliteDangerous.cs。

  • 设备 id：%04X%04X，即大写十六进制的 USB 厂商 id 和产品 id（231D0125）。安装目录的 DeviceMappings.xml 中列出的设备改用其符号名称写入（T16000M、ThrustMasterWarthogJoystick、VPCThrottle，包括 Alternatives）。JoyPro 只写入已连接的设备。相同的设备需要游戏的 DeviceIndex，但其顺序没有文档说明：因此跳过。
  • 输入名称：按钮 Joy_1 ... Joy_N，Joy_POV<h>Up/Right/Down/Left（苦力帽 1 到 4），Joy_XAxis ... Joy_RZAxis，滑块为 Joy_UAxis / Joy_VAxis，键盘为 Key_*。永远不会创建 Pos_Joy_* / Neg_Joy_*（半轴）。
  • 反转：文件中的 Inverted = 关联的反转 XOR 该操作的自然方向（PitchAxisRaw、ThrottleAxis、AheadThrust、VerticalThrustRaw 及其备用和着陆副本、HeadLookPitchAxisRaw、CamTranslateYAxis、ExplorationFSSRadioTuningX_Raw 为 1；其他所有轴为 0）。导入时以同样的方式读回。如果某个设备报告的轴方向是反的，在 DCS 中也需要反转，XOR 会把这一点沿用过来。
  • 命令列表：engine elite refresh-db 以只读方式读取游戏写入的 .binds（其中列出了游戏认识的每个元素）和自带的预设；只添加飞船飞行元素，已知操作保留其 id 和标题。engine elite catalog 列出命令列表，engine elite paths 显示 JoyPro 找到的文件。
  • 导入 / 导出：engine elite import 和 engine elite scan；engine elite export --mode clean|add|merge|merge-overwrite --nuke-untouched-devices --include-keyboard --ignore-device <d> --dry-run。
  • 游戏设置：engine ffb set --device * --game EliteDangerous --param <key>=<value>（yawToRollMode、yawToRollSensitivity、throttleIncrement、headlookAccumulate ……）。

#已知限制

  • 两个相同的设备会被跳过；缺少某个设备会让游戏忽略整个预设。
  • 游戏菜单中死区滑块的刻度，以及游戏如何在死区之外重新缩放，尚未确认。
  • 按钮：玩家报告约 32 个；更大的编号也曾经可用。四个苦力帽，没有斜向。
  • 文件中没有的操作会被跳过并给出警告（添加操作的方式尚未确认）。
  • 测试：engine\tests\smoke\elite.ps1；游戏内测试 tools\e2e\games\Elite.ps1（绑定和模式矩阵）和 tools\e2e\games\EliteSettings.ps1（反转方向、油门范围、游戏设置）。
