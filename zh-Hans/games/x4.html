新手入门

#3 步上手

  1. 全部帮我设置好
    在开始页面
  2. 使用这些按钮
    先查看列表
  3. 写入我的游戏
    保持 X4 关闭

之前：为每个设备分配一次槽位。在 X4 的控制设置中打开 Manage Controllers/Joysticks。把每个设备分配到一个槽位，然后正常退出游戏。

之后：你的绑定位于 Settings > Controls 中。

以前在 X4 中绑定过按钮？那么开始页面会提供 导入，然后填补空缺。你的绑定会保留，只有空闲的按钮会获得新功能。请参见快速入门：让我的摇杆工作。

#JoyPro 能为 X4 做什么

  • 导入：你的摇杆、油门和脚舵的太空飞行绑定会导入你的配置文件，包括游戏的反转和油门模式。
  • 关联：一个关联就是所有游戏中的同一个功能。“Boost”可以是 X4、Elite Dangerous 和 Star Citizen 中的同一个按钮。
  • 导出：JoyPro 在你设备的槽位上就地编辑 inputmap.xml。菜单、第一人称、键盘和鼠标绑定保持不变。

#导入你的 X4 绑定

  1. 打开开始页面。如果 X4 卡片要求命令列表，请按 生成列表：JoyPro 会从你的安装中读取游戏的控制项（只读）。
  2. 在 X4 卡片上按 导入。保持选择 添加到我的配置文件。如果你也想把飞行按键放进 JoyPro，请勾选 同时获取键盘按键。
  3. 按 立即导入。查看我的关联 会打开导入的内容。

#建立并检查关联

用关联流程把你各个游戏中的相同功能合并起来，然后在导出页面上按 检查。摇杆绑定请不要使用修饰键：X4 的摇杆绑定不接受修饰键。

#导出到 X4

  1. 关闭 X4。 游戏会在一次会话结束时写入 inputmap.xml 和 config.xml，所以游戏运行时 JoyPro 会拒绝写入。
  2. 打开 导出 并勾选 X4 卡片。
  3. 如果你是在 JoyPro 中设置摇杆的，请保持选择 在我的设备上替换 并勾选 同时清除我的其他设备。在卡片上按 立即导出。
在游戏中: 你在 X4 中会看到什么

启动游戏并打开 Settings > Controls。你的绑定位于每个太空飞行控制项的控制器/摇杆列中，在你设备的槽位上。Invert Controller / Joystick Axes 会显示 JoyPro 设置的反转，双向油门、摇杆死区和自适应转向这几行会显示你的值。自动滚转和震动位于游戏设置中。

#你在 X4 中需要自己做的事

  • 为每个设备分配一次槽位。 在 X4 的控制设置中打开 Manage Controllers/Joysticks，把每个摇杆、油门和脚舵分配到一个槽位，然后正常退出游戏。X4 随后会在 config.xml 中记住该设备。没有这种条目的设备在每次会话之间会在槽位间移动，所以 JoyPro 会跳过它（“请在 X4 中为该设备分配一次槽位”）。在那里设为“none”的设备也会被跳过。
  • 导出前插上你的设备。

#常见问题

  • “X4 正在运行”：退出游戏，然后再次导出。
  • 某个设备被跳过：它在 X4 中没有固定到槽位。请在 Manage Controllers/Joysticks 下分配它。
  • 槽位 1 中的摇杆执行了手柄的功能：槽位 1 是 X4 默认映射中的手柄槽位，所以放在那里的摇杆会继承默认的手柄绑定。在我的设备上替换 会移除它们。
  • 64 号以上的按钮或第二个苦力帽没有反应：X4 每个设备只读取 64 个按钮、8 个轴和一个苦力帽。超出范围的绑定 JoyPro 会跳过并给出警告。
  • 某个反转没有被修改：一个反转设置对该控制项上的所有设备都生效。如果你的关联之间不一致，或者有手柄绑定到同一个控制项，JoyPro 会保留游戏的值并发出警告。
高级

#JoyPro 读取和写入的文件

文件 这是什么
%USERPROFILE%\Documents\Egosoft\X4\<id>\inputmap.xml 生效的绑定（每个控制和输入的 <action>、<state>、<range>）以及 <config> 参数（反转、死区、双向油门、自适应转向）。<id> 是 Steam 账号的文件夹。
...\X4\<id>\config.xml 设备槽位（<joysticks>）以及震动、自动横滚和手柄模式等游戏设置；槽位只读取，设置则就地编辑
...\X4\<id>\inputmap.xml.joypro-meta.json JoyPro 为已写入的绑定保存的名称、分组和调校，下次导入时会读回
inputmap.xml.jpbak、config.xml.jpbak 首次写入之前的副本，以及 JoyPro 带版本的备份存储

该文件以文本方式写入：声明、换行符、缩进、各节的注释、<config>、根属性以及每个未改动的行都逐字节保持不变。新行会放在它所属的节中，位于同类且控制编号更小的最后一个条目之后。JoyPro 从不改动已保存的配置文件 inputmap_1.xml 到 inputmap_5.xml，也不改动你的存档。Steam Cloud 会同步该文件夹；具体同步哪些文件尚未确认。

#X4 中的导出模式

冲突是指同一槽位和输入上有另一个飞行控制。某个控制在地图和详细监视器中的孪生控制算作同一个控制。

模式 inputmap.xml 中会发生什么
仅添加 不删除任何内容。如果某个绑定的输入已被另一个飞行控制使用，该绑定不会被写入，并被标记为“未写入游戏”。
更新，保留游戏的绑定 你的行会与该控制的其他输入并存；只删除冲突项。
更新，以我的配置文件为准 同上，另外你绑定的控制会失去它在已连接设备的固定槽位上的其他行（开启键盘选项时还包括其键盘行）。
在我的设备上替换 已写入槽位上不在你配置文件中的飞行绑定会被删除，槽位 1 上自带的手柄飞行绑定也会被删除。
+ 同时清除我的其他设备 对于 config.xml 固定给已连接设备、但导出没有使用的槽位，也同样处理。没有固定设备的槽位不会改动：它对应的设备未知。

X4 的菜单会把一些控制绑在一起：“Toggle Travel Mode”会在地图中设置同一个输入，“Dock”同时也会解除停靠。JoyPro 像菜单一样成组写入和删除这些控制，并且从不删除第一人称视角的“Interact”孪生控制。

#绝不会改动的内容

  • 菜单、地图、第一人称、选项和辅助功能控制；环形菜单条目。
  • 键盘和鼠标行；只有开启键盘选项时才写入键盘，而且只针对飞行控制，从不使用 X4 菜单拒绝的按键（Escape、Delete、Ctrl+X/C/V ……）。
  • 未连接或未固定的设备的槽位、手柄、导入时被忽略的设备，以及 JoyPro 用于转发的 vJoy 设备。
  • JoyPro 没有设置的每一行 <config>。

#曲线和游戏设置

  • 粒度：所有飞船共用一套绑定（太空飞行控制）。
  • 反转是每个控制一个值，对所有设备有效（invert_steering_yaw、_pitch、_roll、invert_throttle、invert_strafe_*）。你的关联保持 DCS 的方向；X4 自带的 HOTAS 映射把俯仰、横滚和油门视为反转，所以对这几项 JoyPro 会把参数设为你的反转设置取反后的值。只有当该控制上的所有 JoyPro 轴都一致时，它才会设置该参数。
  • 双向油门取决于油门关联的 滑块 设置：滑块 = 只能向前，非滑块 = 中间位置为零推力。
  • 死区：X4 为每个摇杆的所有轴只设一个死区。关联的死区不会被写入（导出会说明这一点）；请在 设置 > 游戏的力反馈设置（选择 X4）中或用 engine ffb set 设置游戏的死区。自适应转向、震动、自动横滚和手柄模式也在同一个地方。你在那里保存的设置优先于关联；如果与关联相反，会给出警告。
  • X4 没有按轴的曲线或饱和度；没有力反馈；没有遥测。
  • 监视器：你在游戏中更改的绑定或选项会在游戏关闭后被发现（inputmap.xml 和 config.xml），JoyPro 会询问是否接受这些更改。
  • HUD：HUD 通过进程识别该游戏，并显示你的 X4 绑定。

#X Rebirth 和 X3

X Rebirth 使用与 X4 相同的 inputmap.xml 词汇，但它的命令列表需要从安装中另行提取。X3（Reunion、Terran Conflict、Albion Prelude）使用另一个引擎，文件格式未知。两者都只有文档记录：JoyPro 不会导入或导出它们。

#X4 集成的内部机制

代码：engine\Games\X4Integration.cs、engine\Games\X4CatalogSource.cs 以及设置模型 engine\FfbModels\X4.cs。

  • 槽位：绑定会指明来源：INPUT_SOURCE_JOYBUTTONS（按钮和苦力帽）或 INPUT_SOURCE_JOYAXES，槽位 1 不带后缀，其他槽位为 _2 到 _8。config.xml 通过 DirectInput 实例 GUID 把设备映射到槽位，以 X4 自己的格式书写（{42cec570-0a3f-11f0-80-0b-44-45-53-54-00-00}）；num 0 到 7 是槽位，disabled="1" 表示没有。JoyPro 只写入当前已启用条目与某个已连接设备匹配的槽位。
  • 编码：按钮 1 到 11 使用 X4 的手柄名称（INPUT_XBUTTON_A ... BIGBUTTON），12 到 64 为 INPUT_XBUTTON_12 ...；苦力帽为 INPUT_XBUTTON_DPAD_*（八个方向）；轴为 INPUT_JOYAXIS_X ... RZ、SLIDER1、SLIDER2。范围不带 sgn。键盘：INPUT_KEYCODE_<DIK>，加 _SHIFT / _CONTROL。
  • 命令列表：engine x4 refresh-db 以只读方式从 .cat/.dat 存档中读取 gameoptions.lua 和英文文本页，并读取 X4.exe 的名称表；共 128 个太空飞行控制（6 个轴，122 个按钮）。各行显示为“Yaw (Primary Steering Axis)”、“Roll (Secondary Steering Axis)”这样的形式。engine x4 catalog 列出该列表，engine x4 paths 显示找到的文件。
  • 导入 / 导出：engine x4 import、engine x4 scan；engine x4 export --mode clean|add|merge|merge-overwrite --nuke-untouched-devices --include-keyboard --ignore-device <d> --dry-run。
  • 游戏设置：engine ffb set --device * --game X4 --param <key>=<value>；参数就地编辑，缺少的参数会作为 <config> 的最后一行添加。即使导出时没有 X4 绑定，也会写入已保存的设置。

#已知限制

  • 没有固定槽位的设备会被跳过；JoyPro 目前还不会自己去固定它们。
  • 摇杆修饰键不会被写入：它们在文件中的标记方式尚未确认。
  • 每个设备 64 个按钮、8 个轴和一个苦力帽；八个槽位，与手柄共用。
  • 震动：游戏的滑块显示的是数值乘以 100 后截断的结果（21 % 显示为 20）；文件中保存的是精确值。
  • 测试：engine\tests\smoke\x4.ps1（也包括目录刷新）；在游戏中运行 tools\e2e\games\X4.ps1（绑定和模式矩阵，使用独立的配置文件夹）和 tools\e2e\games\X4Settings.ps1（反转、油门模式、游戏设置）。
