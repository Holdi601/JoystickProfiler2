入门

10 分钟完成你的第一个配置文件

显示：

让按钮能用有两种方式。快速方式只需点几下：由 JoyPro 来完成工作。手动方式需要更长时间：每个按钮都由你决定。你可以先用快速方式，之后再手动修改。

新手入门

#快速方式

  1. 全部帮我设置好
    在开始页面
  2. 使用这些按钮
    查看列表
  3. 写入我的游戏
    JoyPro 会保留备份
  4. 飞行
    你的按钮都已就位
  1. 在开始页面上，按 全部帮我设置好。首次启动时，完成，并全部帮我设置好 的作用相同。
  2. 查看各个功能分配到哪里的列表。按 使用这些按钮。
  3. 关闭你的游戏。按 写入我的游戏。
  4. 启动你的游戏，开始飞行。

对于 ACE COMBAT 8 和其他仅支持 Xbox 手柄的游戏，最后一步不同：设置模拟手柄。完整的分步说明：快速入门：让我的摇杆工作。

出了问题？请参见撤销快速设置。

#手动操作

你的游戏中已经有绑定了吗？或者你想自己决定每个按钮？那就走这条路。

  1. 导入
    你游戏中的绑定
  2. 关联
    一个功能，适用所有游戏
  3. 绑定
    每个分配一个按钮或轴
  4. 导出
    到每个游戏
  1. 导入。 在开始页面上，在你游戏的卡片上按 导入，然后按 立即导入。JoyPro 会读取你的绑定并创建一个配置文件。游戏不会改变。（导入游戏）
  2. 关联。 打开 关联。关联是一个功能（“Gear Up/Down”），包含它在每个游戏中的操作。要覆盖第二个游戏，请打开一个关联，并在某条建议上按 添加。（建立关联）
  3. 绑定。 打开 绑定。选择一个关联，按 录制输入，然后按下摇杆上的按钮。对于轴，请把它推到底。（绑定页面）
  4. 检查。 按底部栏中的 检查。修复红色卡片。（检查）
  5. 导出。 关闭游戏。打开 导出，保持 在我的设备上替换 和 同时清除我的其他设备（这会删除游戏中你摇杆上的旧绑定；JoyPro 会先备份它们）。勾选游戏，按 导出勾选的游戏。（导出）

然后启动游戏：你的绑定就在它的控制菜单中。

在游戏中改了设置？

你关闭游戏后，JoyPro 会询问是否把你的更改带入配置文件。

游戏卡片上的 撤销上次导出 会把游戏的文件完全恢复到原来的样子。

#已经有绑定了？两种方式结合使用

开始页面会列出你自己做过绑定的游戏。导入，然后填补空缺 会先导入你的绑定。然后设置只会使用空闲的按钮。你自己的绑定会保留。

高级

#更快的手动方式

  • 分步设置...（开始页面）会打开包含所有步骤的设置向导：你的游戏、你的设备及其角色、你的飞机优先级、方案、检查。
  • 填补空缺...（开始页面）对配置文件中已有的游戏做同样的事。你的绑定保持原位。
  • 根据我的所有操作自动生成关联...（关联页面）会把每架飞机和每个游戏中的相同功能归为一组（自动分组）。你会先看到预览。
  • 自动分配 会把未绑定的关联放到设备上最合适的控件上。用 AI 布局 接受用平常话表达的愿望（“配平放在苦力帽上”），并在应用之前显示每一项更改。
  • 跟随输入（关联页面和绑定页面）：按下一个按钮，它的关联就会打开。
技术细节

#背后的原理

快捷方式会自动运行设置向导的引擎步骤（engine setup plan、engine setup apply），然后执行该游戏的导出。手动方式使用导入（engine dcs import 和其他游戏的导入）、关联命令（engine relations add）、绑定（engine binds set）、检查（engine profile validate）和导出（engine dcs export 及其他）。每次更改都是一个配置文件版本，所以重启后仍可撤销。
