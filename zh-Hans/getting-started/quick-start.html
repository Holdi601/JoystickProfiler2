快速入门：让我的摇杆工作

显示：

你想让你的摇杆在游戏中能用。你不想先学习 JoyPro。这一页就是为你准备的。

JoyPro 会查看你的摇杆、油门和脚舵。它会自动把重要的游戏控制项放到它们上面。你查看结果，然后点击两个蓝色按钮。就这么简单。

  1. 全部帮我设置好
    在开始页面
  2. 使用这些按钮
    在新窗口中
  3. 写入我的游戏
    下一个蓝色按钮
  4. 飞行
    启动你的游戏
新手入门

#开始之前

  • 下载 JoyPro 并解压：下载和安装。
  • 插上你的摇杆、油门和脚舵。
  • 先启动一次游戏，然后关闭。有些游戏只有这时才会创建它们的控制文件。
  • JoyPro 写入游戏时，请保持游戏关闭。

#快速方式，一步一步

  1. 启动 JoyPro。 第一次启动时，会有一个窗口显示你的游戏。按 完成，并全部帮我设置好。然后你可以跳过第 2 步。
  2. 按“全部帮我设置好”。 它在开始页面的“设置设备”卡片中。在欢迎界面（首次启动后 JoyPro 提出的第一个问题）中回答 让我的摇杆直接能用 作用相同。
  3. 查看列表。 列表会说明每个按钮的作用，例如“按钮 4：武器重新装弹”。放大显示图片 会显示你的摇杆和每个按钮。
  4. 按“使用这些按钮”。 现在 JoyPro 有了你的按钮。你的游戏暂时还不会改变。
  5. 按“写入我的游戏”。 现在你的游戏有了你的按钮。JoyPro 会保留一份旧按钮的副本。
  6. 飞行。 开始页面会显示“成功了！”。启动你的游戏，开始飞行。

每次只有一个按钮是蓝色的。点击蓝色的那个，下一个就会变成蓝色。

#关于头部追踪的问题

对于飞行模拟游戏，列表会问：你使用头部追踪或 VR 吗？ 如果你靠转动头部来环顾四周（TrackIR、带面部追踪的网络摄像头、Tobii 或 VR），或者打算这样做，请回答 是。这样摇杆上不会放视角按钮，只放“视角回中”。如果你用摇杆环顾四周，请回答 否：环顾四周会放到一个苦力帽上。参见 头部追踪和环顾四周。

底部的那一行

“所有重要按钮都已设置好。有几个不常用的额外功能没有位置了（18）。这没关系。”这是好消息。你的摇杆按钮比游戏的控制项少。重要的控制项都已放在你的摇杆上。

#游戏中已经有按钮设置

以前在游戏中设置过按钮？那么 写入我的游戏 会问你一个问题：

回答 会发生什么
使用新的 JoyPro 的按钮会替换旧的按钮。JoyPro 会保留一份旧按钮的副本。
同时保留旧的 你的新按钮会放在旧按钮旁边。不会删除任何内容。
取消 不会写入任何内容。准备好后再按一次 写入我的游戏。

#ACE COMBAT 和其他仅支持 Xbox 手柄的游戏

ACE COMBAT 8 和 Hell Let Loose: Vietnam 只认识 Xbox 控制器。它们看不到你的摇杆。JoyPro 会把你的摇杆变成一个模拟手柄（虚拟 Xbox 手柄）。不会向这些游戏写入任何内容。

  1. 全部帮我设置好
    然后点 使用这些按钮
  2. 设置模拟手柄
    第二个蓝色按钮
  3. 测试
    推动你的摇杆
  4. 启动游戏
    等待它的标题画面
  5. Alt+Tab，开始
    然后按 Alt+Tab 回去
  1. 按 全部帮我设置好，然后按 使用这些按钮。
  2. 下一个蓝色按钮是 设置模拟手柄。虚拟摇杆页面会打开。
  3. 第一次使用时，它需要一个名为 ViGEmBus 的免费辅助程序。勾选许可证下面的复选框。然后按 安装 ViGEmBus。Windows 会请求权限：点击 是。
  4. 按 测试。推动你的摇杆。控制器图片也会跟着动。
  5. 启动游戏。等待它的标题画面。
  6. 按住 Alt 再按 Tab。你回到了 JoyPro。按 开始。
  7. 再按一次 Alt+Tab，你就回到了游戏中。起飞吧！
先开游戏，再按开始

只有在游戏显示标题画面时才按 开始。按早了？JoyPro 会提示“太早了”。先按 停止，再按 开始。每次游玩都要这样做。

关于这些游戏的更多内容：用 HOTAS 玩仅支持 Xbox 手柄的游戏和ACE COMBAT。

#出了问题？

  • 找不到游戏或摇杆。 插上你的摇杆，或先启动一次游戏。然后按 重试。
  • 你想自己多做些选择。 按 分步设置。这会打开包含所有步骤的设置向导。
  • 你想恢复原来的按钮。 请参见撤销快速设置。
  • 你想给某个功能换一个按钮。 请参见以后更改某一个按钮。

#简单用语

想要大字和非常短的句子？在欢迎界面或第一个窗口中勾选 简单用语：大字、短句。每张导览卡片上也有 更简单的用词。请参见简单用语、导览和 F1。

高级

#快速设置做了什么

  • 它就是自动运行的设置向导。它使用向导的默认设置：你的设备及其常规用途，所有飞机一视同仁，不使用修饰键。
  • 它只设置那些你的摇杆上还没有任何绑定的游戏。开始页面的卡片会列出这些游戏：“为 War Thunder 和 Star Citizen 设置设备”。
  • 功能放在哪里？ 取自你上次在向导中的选择（初始为中间档）。参见功能放在哪里？。
  • JoyPro 不认识的设备会按其同类常见设备来设置。移动摇杆控制方向，按钮 1 开火，第一个苦力帽用于配平，第一个推杆是油门。顶部的提示框会说明这一点。
  • 做些修改 会显示各种工具：移动、交换或略去某个功能，以及把它放回来。它还会显示放不下的内容。
  • 你自己做过绑定的游戏会列在卡片下方。导入，然后填补空缺 会先导入你的绑定；然后设置只使用空闲的控件。配置文件中已有的游戏会提供 填补空缺...。
  • 使用这些按钮 是配置文件历史记录中的一步。按一次 撤销（Ctrl+Z）就能全部撤回。
  • 写入我的游戏 就是对这些游戏执行导出。它会像导出页面一样，先备份游戏文件。
  • 之后会有一个简短的导览，告诉你以后在哪里更改按钮。导览以“完成！启动你的游戏”结束。
技术细节

#快速设置背后的原理

快捷路径会在不显示的情况下运行向导的引擎步骤：engine setup devices、engine setup aircraft 和 engine setup plan，直到检查这一步。使用这些按钮 运行 engine setup apply（一个配置文件版本）。写入我的游戏 以导出页面的设置和备份运行该游戏的导出。对于只支持手柄的游戏，它会改为打开虚拟摇杆页面；这些游戏的表格来自 engine vjoy map。GUI：开始页面上的 QuickSetupCommand、StartQuickSetupAsync（MainWindowViewModel.AutoSetupStart.cs），窗口 Views/SetupWizardWindow.axaml。
