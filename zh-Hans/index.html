JoyPro 2

#一个配置文件管理你的所有设备，适用于每一款飞行和太空游戏。

JoyPro 会在每架飞机、每款游戏中把同一个功能放在同一个按钮上：起落架、襟翼、干扰弹、配平、油门。它能自动设置你的摇杆、油门和脚舵。免费且开源（GPL-3.0），无需账户，没有遥测。

下载 Windows 版快速入门：让我的摇杆工作Discord

#我想……

让我的摇杆能用JoyPro 帮你全部设置好，你只需要看一看、点一点。用我的飞行摇杆玩 ACE COMBAT适用于只认得 Xbox 手柄的游戏。JoyPro 会创建一个模拟手柄。玩 DCS World 或 Falcon BMS所有飞机的按钮集中在一处，从游戏中读取，再写回游戏。带我熟悉一下指向真实按钮的导览，以及任意按钮上的 F1 帮助。从 JoyPro 1 过来每个旧功能现在在哪里。你的旧配置文件可以原样打开。

这些是 JoyPro 欢迎向导中的回答。JoyPro 只在首次启动后问一次。

#2.7 新功能

全部帮我设置好开始页面上的一张卡片就能设置好你的设备；首次启动结束后点 完成，并全部帮我设置好。头部追踪JoyPro 会询问你是否使用头部追踪或 VR，并把环顾四周放到合适的位置。一个功能用两个输入同一个功能放在两个按钮或两个设备上。什么在哪里？查看你设备上每个按钮的作用。DCS 膝板你的绑定作为页面显示在座舱的膝板上。F1 和导览任意按钮上的帮助、指向真实按钮的导览、简单用语。

#JoyPro 的工作方式

快捷方式。 JoyPro 替你完成。

  1. 全部帮我设置好
    在开始页面
  2. 使用这些按钮
    查看列表
  3. 写入我的游戏
    JoyPro 会保留备份
  4. 飞行
    你的按钮都已就位

你自己的方式。 每个按钮由你决定。

  1. 导入
    你游戏中的绑定
  2. 关联
    一个功能，适用所有游戏
  3. 绑定
    每个分配一个按钮或轴
  4. 导出
    到每个游戏
  • 一个 关联 就是一个功能（“Gear Up/Down”），以及它在每款游戏和每架飞机中对应的操作。
  • 一个 绑定 就是关联所在的按钮或轴。一个关联可以有多个绑定。
  • 导出 会把它写入每款游戏自己的控制文件。它会先做备份，而且你可以撤销。
  • 之后在游戏里改了什么？游戏关闭后，JoyPro 会询问是否接收这些更改。

#从这里开始

下载与安装解压、启动，搞定。它需要什么，以及它把东西存放在哪里。快速入门点几下就能让按钮工作。支持的设备任何摇杆都能用。这里列出 JoyPro 能按名称识别的设备。帮助与常见问题常见问题，以及出问题时要用的支持文件。我该如何……简短的回答，每个问题一页。10 分钟做出你的第一个配置文件快捷方式和手动方式。

#主要流程

导入游戏把你在游戏中做好的绑定导入配置文件。创建关联搜索、勾选、添加；建议和自动分组。导出四种模式，以及每种模式会改动游戏中的什么。检查游戏中可能出什么问题，并提供一键修复。

每个页面都有三个层级：新手（不需要电脑知识）、高级（所有选项）和 技术细节（引擎命令和代码）。页面顶部的切换开关用来选择层级。
