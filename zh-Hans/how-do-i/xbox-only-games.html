我该如何

用 HOTAS 玩只支持 Xbox 手柄的游戏

显示：

有些游戏只认得 Xbox 手柄，ACE COMBAT 8 和 Hell Let Loose: Vietnam 就是这样的游戏。它们完全看不到你的摇杆。JoyPro 会把你的摇杆、油门和脚舵变成一个模拟手柄（虚拟 Xbox 手柄）。游戏看到的是一个 Xbox 手柄，并用它来操作。

你的设备
JoyPro
游戏
摇杆、油门、脚舵
模拟手柄
（在 开始 开启期间创建）
ACE COMBAT 8 看到的是一个 Xbox 手柄
新手入门

#一次性设置

  1. 全部帮我设置好
    然后点 使用这些按钮
  2. 设置模拟手柄
    第二个蓝色按钮
  3. 安装 ViGEmBus
    先勾选复选框
  4. 测试
    推动你的摇杆
  1. 在开始页面按 全部帮我设置好。欢迎向导中的回答 用我的飞行摇杆玩 ACE COMBAT 也会带你到这里。
  2. 查看列表，然后按 使用这些按钮。
  3. 按 设置模拟手柄。设置窗口会关闭，并打开虚拟摇杆页面。
  4. 模拟手柄需要一个免费的小助手 ViGEmBus。勾选许可协议下方的复选框，然后按 安装 ViGEmBus。Windows 会请求权限：点击 是。这只需要做一次。
  5. 按 测试。移动你的摇杆，手柄图片会跟着动。按一个按钮：它会亮起来。

你不需要切换任何东西。JoyPro 会自动让这些游戏使用模拟手柄。页面上会显示“自动使用 Xbox 手柄：该游戏只读取 Xbox 手柄”。不会向游戏写入任何内容。

#每次游玩时

  1. 启动游戏
    等待它的标题画面
  2. Alt+Tab
    回到 JoyPro
  3. 开始
    模拟手柄已开启
  4. Alt+Tab
    回到游戏
  1. 启动游戏，等它显示标题画面。
  2. 按住 Alt 再按 Tab，你就回到了 JoyPro。
  3. 按 开始。
  4. 再按一次 Alt+Tab，你就回到了游戏中。起飞吧！
  5. 玩完后，按 停止。
先开游戏，再按开始

只有在游戏显示标题画面时才按 开始。按早了？JoyPro 会提示“太早了”。先按 停止，再按 开始。每次游玩都要这样做。

#ACE COMBAT 8 中各功能的位置

在你的 HOTAS 上 在模拟手柄上 在游戏中
摇杆前推、后拉、左压、右压 左摇杆 俯仰和滚转
油门杆 前推：RT。后拉：LT。 加速和减速
摇杆扭转（或脚舵） LB 和 RB，约从 30 % 起 向左和向右偏航
摇杆上一个空闲的苦力帽 右摇杆 环顾四周
你的热焰弹按钮 L3 和 R3 同时按下 干扰弹（尚未在游戏中确认）
你的通讯开关或 AI 菜单苦力帽 十字键 僚机指令
一个名为“High-G”的按钮关联 两个扳机都按到底 高 G 转弯

实时测试 选项卡上的列表会说明每个按钮的作用，例如“A: Fire machine gun”。

干扰弹尚未确认

JoyPro 会同时按下 L3 和 R3 来投放热焰弹。目前还没有人在游戏中确认过这一点，JoyPro 也会这样提示。

#有东西不正常？

  • 游戏没有反应。 是不是太早按了 开始？按 停止，再按 开始。
  • 机头方向反了。 你是否在游戏中设置了“Pitch Controls: Inverted”？那么请用顶部的 显示： 开关把本网页切换到 高级。
  • 没有 ViGEmBus。 没有它，游戏就看不到你的摇杆。请在虚拟摇杆页面安装它。

关于这些游戏的更多信息：ACE COMBAT、Hell Let Loose: Vietnam。

高级

#详情

  • 这些游戏不需要 HidHide。 它们只读取 Xbox 手柄，所以永远看不到你的真实摇杆，无需隐藏任何东西。HidHide 只用于设为 vJoy 的游戏。
  • 模式会自动切换。 只要你还没有选择模式，这些游戏就使用 Xbox 手柄。在虚拟摇杆页面选择其他模式后，JoyPro 会保留你的选择。
  • 你的曲线会传到手柄上。 轴响应（绑定页面）中的死区、饱和度、曲线和反转会应用到手柄的摇杆或扳机上。如果想要单独的曲线，在 应用于 下只勾选 ACE COMBAT 8。
  • 俯仰。 DCS 的反转永远不会传到手柄上。默认情况下，向前推杆会让机头向下。如果游戏中设置了“Pitch Controls: Inverted”，请只为 ACE COMBAT 8 取消勾选“反转”（轴响应，应用于：ACE COMBAT 8）。
  • 用苦力帽环顾四周。 如果视角操作没有绑定轴，摇杆上一个空闲的苦力帽会驱动右摇杆。按住苦力帽的某个方向时，摇杆就保持推出。在其他游戏中，这个苦力帽保持原来的功能（在 DCS 中是配平）。
  • 高 G 转弯。 名为“High-G”的按钮关联会同时按住两个扳机。绑定 DCS 的 ASC Direct Control（Su-27、Su-33、J-11A 的“眼镜蛇按钮”）的关联也一样。扳机上的油门照常工作。
  • 多个游戏共用手柄。 ACE COMBAT 7 和 8 都可以使用它，各自有自己的表。开启自动启动时，正在运行的游戏的表会生效；否则在 “开始”和“测试”使用的Xbox 手柄表 中选择。
  • 自动启动 会在游戏启动后约 3 秒内、标题画面出现之前创建手柄。对这些游戏来说这可能太早了：这时请在标题画面按 停止 再按 开始。
  • 专家选项。 vJoy、HidHide、转发频率和各种模式都在 显示专家详情（vJoy、HidHide、模式） 下。
  • ACE COMBAT 7 自己读取摇杆，它会正常导出 Input.ini（ACE COMBAT）。
技术细节

#模拟手柄的内部原理

  • 完全不读取摇杆的游戏，其 MaxJoysticks 为 0，建议模式为 xbox；没有保存的选择时，它的模式就是 xbox（VJoySettings.ModeOf）。engine vjoy mode 会保存一个选择。
  • 规划器会把每个关联的输入固定到游戏自身布局所用的手柄控件上（DB\<Game>\actions.tsv，第 5 列）。手柄自己的功能（油门拆分、偏航按钮、干扰弹组合键、方向键、High-G、视角苦力帽）来自 engine/VJoy/XboxPadAutoSetup.cs，每次规划时都会重新生成。
  • JoyPro.VJoy run --xbox-sink vigem 会创建手柄；测试使用 --xbox-sink dry，不会改变任何东西。
  • engine vjoy pad-check 报告一个配置文件能在手柄上实现哪些功能，并给出评分。参考：虚拟摇杆。
