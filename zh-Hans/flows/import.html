主要流程

导入游戏

显示：

导入会读取游戏已保存的控制设置，并把它们变成一个 JoyPro 配置文件：每个功能一个关联，带有它的按钮或轴。这是最快的入门方式：你在游戏中已经设置好的一切都会进来，从此 JoyPro 会把它们集中在一个地方管理。

新手入门

#点三下完成导入

  1. 打开开始页面（底部栏中的第一个按钮）。在 你的游戏 下，JoyPro 在你电脑上找到的每个游戏都有一张带图片的卡片。在你最常玩的游戏上按 导入。
  2. JoyPro 会询问方式：
    • 添加到我的配置文件（推荐） 会保留你已有的内容，并添加游戏的绑定。
    • 从此游戏重新开始 会用游戏中的内容替换你的关联（JoyPro 会先保存一份你的配置文件副本）。
    • 同时获取键盘按键 会把键盘上的飞行命令也带进来。设备绑定始终会获取。
    • 对于 DCS：我的所有 DCS 飞机，或者取消勾选并选择飞机。
  3. 按 立即导入。片刻之后，卡片会显示“完成：你的配置文件现在有 214 个关联（180 个已绑定）”，查看我的关联 会打开它们。先查看 则会显示游戏中有什么，而不做任何更改。

没有打开配置文件？JoyPro 会为你创建一个，并从此自动保存（没有保存按钮：每次更改都会保存，并且可以撤销，重启后也可以）。

#游戏中会改变什么？

什么都不会变。 导入只读取游戏的文件。无论你之后是否导出，游戏的绑定都会完全保持原样。

#导入，然后让 JoyPro 填补空缺

在开始页面上，“设置设备”卡片会列出你自己做过绑定的游戏。导入，然后填补空缺 会先导入这样的游戏。然后 立即填补空缺... 会把重要的功能放到仍然空闲的按钮上。你自己的绑定会保留。对于已在配置文件中的游戏，卡片会提供 填补空缺...。

#第一次导入之前：命令列表

JoyPro 需要知道每个游戏的命令（名称和 id）。它会根据你自己的安装生成一次这个列表。缺少列表时，开始页面会显示 生成列表（或 生成所有缺失的列表）；游戏更新后，游戏卡片会提供 更新。这需要几秒到几分钟不等（DCS 会读取每个模块）。

高级

#选项及其作用

选项 默认 效果
添加到我的配置文件 / 重新开始 添加 “添加”会合并到打开的配置文件中；“重新开始”会在确认并复制一份配置文件后替换其中的关联。
同时获取键盘按键 你上次的选择 绑定到按键的飞行命令也会导入。
同时导入未连接的设备 开启 当前没有插上的设备也会被导入（适用于你稍后才连接的摇杆）。关闭：它们会被跳过并计数。
将同名设备视为同一设备 开启 Windows 时不时会给设备分配新的 ID；它的新旧文件会被当作已连接 ID 上的同一个设备读取。同时插着的两个相同设备会被分开处理。
包括默认值（DCS，专家表单） 开启 导入设备在 DCS 中所有生效的默认绑定都会导入，这样先导入、再以“替换 + 同时清除”导出后，DCS 会保持原样。同一输入上，你自己的绑定优先于默认绑定。
导入反转 / 滑块 / 曲率 / 死区 / 饱和度（专家表单） 关 对于不是 JoyPro 自己导出的绑定，采用 在游戏中 设置的数值。JoyPro 导出过的绑定即使不开启这些选项，也会取回它的调校。
DCS：忽略 *_easy 飞机 关 飞机的简易模式副本会被略过。

专家导入（开始页面上卡片下方，以及高级页面）为每个游戏提供所有引擎选项，并带有 扫描（预览）、导入 和 导出。每个选择都会被记住，供下次导入使用。

#名称、分组和修饰键都会恢复

游戏文件只保存设备、输入，也许还有一条曲线。JoyPro 导出时会在旁边保存自己的数据，导入时再把它读回来：

游戏 JoyPro 的数据 恢复的内容
DCS <aircraft>\joystick\<device>.jp、modifiers.lua 关联名称、分组（按顺序）、带名称的修饰键、反转、滑块、死区、饱和度、曲线
IL-2 Great Battles data\input\jp.actions 名称、分组、别名、修饰键、精确的调校
注册表中的游戏（X-Plane、Elite、X4、Arma、MSFS、War Thunder、BMS ……） <config>.joypro-meta.json 名称、分组、别名、修饰键、调校
Star Citizen actionmaps.jp 名称

以游戏的当前状态为准：导出后你在 DCS 中修改过的曲线会被保留。JoyPro 从未导出过的绑定会得到一个由游戏操作生成的名称，以及分组 DCS、IL2 或 GENERATED + 游戏。

#两道保护

  • 尚未导出的更改。 如果你在 JoyPro 中更改了绑定，但还没有导出到这个游戏，导入会把旧的绑定带回来。JoyPro 会先询问。
  • 已经导入过？ 当配置文件中已有该游戏时，你之后在游戏中做的更改会通过 游戏监视器 导入（它会在游戏关闭后询问）；再次导入仍然只需点一下。
在游戏中: 导入在各类游戏中读取什么

导入从不写入游戏文件夹。它读取的内容：

  • DCS：每架飞机和每个设备的绑定、你的修饰键，如果选择“包括默认值”，还有 DCS 为每个设备提供的默认绑定。
  • IL-2 Great Battles / Korea：按键映射和轴响应。
  • Star Citizen：所在分支（LIVE、PTU ……）的按键绑定，以及游戏在 js1 上的摇杆默认绑定。
  • 带有步兵或载具的游戏（War Thunder、Arma、Reforger、WARDOGS ……）：只读取飞行操作；其他一切都会被忽略，而不是删除。
  • MSFS：模拟器（Steam 版或 Microsoft Store 版）的输入配置，以及在你要求时模拟器的默认预设。

游戏无法区分的设备（某些游戏中同一型号的两个设备）和半轴绑定（Elite）会被跳过，并在结果中列出。

技术细节

#内部工作原理

  1. GUI。 StartImportWizard → RunImportWizardAsync（MainWindowViewModel.GameHub.cs）。它先询问 AskAboutUnexportedChangesAsync（引擎 sync pending），确认“重新开始”并保存一份配置文件副本（BackupProfileBeforeChange("before-import")），然后调用该游戏的导入：ImportDcsAsync、ImportIl2Async、ImportStarCitizenAsync 或 ImportRegistryGameAsync。先查看 以 scan 执行同样的流程（PreviewImportWizardAsync），并打开输出面板。
  2. 引擎。 DCS：engine dcs import [--path <Saved Games\DCS>] --merge --include-defaults [--plane <a> --plane <b>] --include-keyboard true|false --ignore-easy-planes false --only-connected false --merge-same-name true。导入器读取每个设备文件，通过 DirectInput 实例 GUID 和名称识别设备，把每个命令 id 对应到游戏的命令列表（%LOCALAPPDATA%\JoyPro2\GameData 中的 DB\<game>），并为每个功能和输入生成一个关联。加载时修正（--load-corrections、--correction-mode）会以一个置信分数重新映射已改名的命令 id。
  3. 配置文件。 关联按名称和相同输入合并；修饰键根据 modifiers.lua（DCS）或游戏的 shift 设置创建。配置文件以原子方式保存，每次保存都是 <data>\ProfileHistory 中的一个版本（重启后仍可撤销）。
  4. 监视器。 导入一个还没有同步记录的游戏时，会记录该游戏的文件，这样你之后在游戏中做的更改就会被发现（<data>\Sync\<game>.json）。

#它读取的文件

游戏 文件
DCS Saved Games\DCS\Config\Input\<aircraft>\{joystick,keyboard}\*.diff.lua 和 modifiers.lua，以及 JoyPro 根据你的 DCS 安装生成的干净配置
IL-2 Great Battles / Korea data\input\*.actions 和轴响应
Star Citizen 该分支的 actionmaps.xml
MSFS Steam 远程文件夹或 Microsoft Store 存档

GUI 选项对应的引擎选项：添加 --merge，键盘 --include-keyboard true，未连接的设备 --only-connected false，同名 --merge-same-name true，简易飞机 --ignore-easy-planes true。针对尚未导出的更改的保护是 engine sync pending。

引擎命令：engine dcs import、engine dcs scan、engine il2 import、engine starcitizen import，以及每个注册表中的游戏使用 engine <game> import（例如 engine warthunder import、engine msfs2024 import）。重新导入规则：重新导入。测试：engine\tests\smoke\dcsincludedefaults.ps1、engine\tests\smoke\roundtrip.ps1、gui\JoyPro.Gui.Tests\ImportSettingsPersistTests.cs。
