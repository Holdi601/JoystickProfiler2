主要流程

建立关联

显示：

关联是一个功能，例如“Gear Up/Down”或“Throttle”。它包含该功能在你所飞的每个游戏和每架飞机中的操作：DCS F-16C 的“Landing Gear Up/Down”、IL-2 的“Gear”、War Thunder 的“Landing gear”、Star Citizen 的“Toggle landing gear”。你在绑定页面上给关联分配一个按钮或轴（也可以是多个，例如两个摇杆上的同一个按钮），之后该按钮在所有地方都执行同一个功能。

1 · 你的关联
2 · 它在每个游戏中的操作
3 · 导出写入什么
Gear Up/Down
输入 1：油门按钮 22（按住 Shift）
输入 2：摇杆按钮 5
DCS：F-16C、F/A-18C 和 A-10C 中的 Landing Gear Up/Down
这几架 DCS 飞机各自的控制设置
IL-2 Korea：Gear
IL-2 Korea 的按键映射
War Thunder：Landing gear
War Thunder 的控制文件

每个游戏都为它自己的操作获得相同的输入。导出会把它们写入每个游戏自己的控制文件，并先做备份。如果某个游戏每个操作保留的输入较少（Elite Dangerous 保留两个按钮，大多数游戏只保留一个轴），它会获得它能保留的数量，导出会告诉你哪一个没放下。

游戏 它的操作 你的输入 导出写入的位置

IL-2 Korea Gear 相同 IL-2 Korea 的按键映射
War Thunder Landing gear 相同 War Thunder 的控制文件
新手入门

#通俗地讲关联

把关联想象成一项任务的标签：“放下起落架”。每个游戏对这项任务的叫法都不同，并用自己的代码保存它。关联把它们全部收集在一起，所以你只需决定一次由哪个按钮来完成这项任务。

  • 关联页面：左侧是你的关联列表，中间是打开的关联，右侧是工具。
  • 绑定页面：每个关联位于哪个按钮或轴上。一个关联可以位于多个按钮或轴上。
  • 导出：把它写入每个游戏。

#一步一步创建关联

  1. 按 新建关联（或 Ctrl+N）并输入名称，例如 Gear。
  2. 在 添加操作 下输入它的作用：gear。你输入时 JoyPro 会搜索每个游戏和每架飞机，并且认识同一事物的其他说法（throttle 也会找到推力和直升机总距，flare 会找到干扰弹投放开关）。
  3. 结果按游戏分组显示。每个游戏中该功能的主要控制项排在最前面。勾选属于它的项目。
  4. 按 用 n 个操作创建关联。完成：打开绑定页面，按下你想用于它的按钮。

#让 JoyPro 来做

  • 此关联的建议 会列出其他游戏和飞机中含义相同的内容。添加 其中一项，或 全部添加。
  • 根据我的所有操作自动生成关联... 会为整个配置文件建立关联：把每架飞机和每个游戏的相同功能放在一起（按功能，称为自动分组）。你会先看到预览。
  • JoyPro 助手：输入一句话，例如“为每个游戏创建一个油门关联”，它就会去做。撤销此项 会撤回整个回答。

每次更改都可以用 Ctrl+Z 撤销，重启后也可以。

高级

#处理大量关联

  • 列表上方的 筛选：分组、游戏及其飞机、设备、是否已绑定、轴或按钮。搜索可以只查名称、查名称和操作，或者查全部（会被记住）。Ctrl/Shift+单击可以勾选多个关联进行 批量更改（分组、复制、删除）。
  • 打开的关联：就地重命名（Enter），它的类型（轴或按钮）、输入、功能标签（JoyPro 根据其功能目录认为该关联是什么）、建议缺失项（n）、复制（带或不带绑定）、删除。下方的 其操作：每个游戏操作一张卡片，带有游戏徽标、飞机和标题。拖动卡片的手柄可以改变顺序（或按 Alt+Up / Alt+Down）。
  • 操作的飞机（DCS）：单击某个操作会打开它的飞机，例如“84 架中的 82 架”，每架都有一个勾选框。同一个 DCS 命令 id 在另一架飞机中可能表示别的东西（a2001cdnil 在喷气机中是“Pitch”，在直升机中是“Cyclic Pitch”；一个座舱开关 id 在三架二战飞机中是三个不同的开关）：JoyPro 只添加该 id 含义相同的飞机，其他的会被标出。
  • 建议 来自四个来源，不使用任何 AI：功能目录（对照手册核实过）、你自己的风格（你在其他飞机中为这个功能放了什么）、含义相同时的相同 DCS id，以及任何游戏中相似的标题（从不包括相反方向）。85 分起为高，55 分起为中；弱建议只在你要求时显示。x 会永久驳回一个建议（它以关闭状态保留在关联中，所以不会再出现）。
  • 已在另一个关联中：某一行显示“已在“Flare”中”，并提供 移到此处。
  • 目录：按类别列出游戏或飞机的每个操作，用于浏览而不是搜索。
  • 自动分组 适用于 DCS、Falcon BMS、IL-2 Great Battles 和 Korea、Star Citizen、X4、Elite Dangerous、MSFS 2020 和 2024、X-Plane 11 和 12、War Thunder、Arma 3、Arma Reforger 以及 WARDOGS。按描述分组 只对一句话中提到的内容分组（“F-16 和 A-10 的所有无线电和通信功能”）。

#一个关联的多个输入

一个关联可以使用多个输入：两根摇杆上的同一功能，或第二个开火按钮。每个输入都有自己的设备、修饰键和轴曲线。输入 1 是主输入。

  • 添加一个：绑定页面，选中该关联，更多输入 > 录制另一个输入（或 添加手动选择的输入）。设为主输入 会把它与主输入互换；删除 会将其移除。
  • 每个输入一条曲线：对于位于两个设备上的轴，轴响应 顶部有一个 输入 列表。
  • 整个设备：把一个设备的每个绑定复制到另一个设备 会为第一个设备的每个绑定分配第二个设备上对应的输入（同一个握把装在两个底座上）。
  • 通过任一输入找到：跟随输入、布局页面、设备 筛选，以及用 全部 进行的搜索，也都能通过第二个输入找到关联。
  • 在游戏中：如果游戏每个操作可以保存多个输入，导出会全部写入，主输入在前。如果只能保存一个，则写入主输入，并列出其余的输入。

#同时处理多个操作

在打开的关联中，按住 Ctrl 或 Shift 单击操作卡片；Ctrl+A 全选。“已选择 n 个操作”栏提供：

按钮 作用
复制（Ctrl+C） 然后打开同一类型的另一个关联，按 粘贴（Ctrl+V）。操作会连同它们的飞机一起过来，包括已关闭的飞机。
移动到... 新建关联（输入名称；与原关联类型相同）或 现有关联（从可搜索的列表中选择）。只会列出同一类型的关联。
删除（Del） 询问一次后将它们移除。

操作的右键菜单中也有 复制 和 移动到另一个关联...。在关联列表中选择多个关联（Ctrl/Shift+单击），然后按 将操作移动到...：它们的所有操作都会移到一个关联中（新建或现有），清空后的关联会被删除。每个这样的操作都是一步：按一次 Ctrl+Z 即可撤销。更多信息：一个功能使用多个按钮。

#检查会查看什么

两个使用同一输入的关联如果都为同一架飞机开启了操作，就表示在那架飞机中一个按钮做两件事；一个操作在两个关联中都开启，则表示游戏会把它放在两个按钮上。检查 会列出这两种情况，并提供一键修复。

在游戏中: 关联在游戏中意味着什么

关联本身不会改变游戏中的任何东西。在下次导出时，关联中的每个操作都会获得该关联的输入，在启用该操作的每个游戏和每架飞机中都是如此：

  • DCS：在每架勾选的飞机中，该命令会获得这个按钮（如果绑定带有修饰键，则连同修饰键一起）。在该操作中被关闭的飞机会保留它原有的设置（使用替换模式时则什么都没有）。
  • IL-2、BMS、X-Plane、MSFS、War Thunder ……：每个游戏一个操作；它会获得这个按钮。
  • Star Citizen 和带步兵的游戏：只有飞船或飞机操作会获得这个按钮；步行绑定保持不变。
  • 轴关联 会带上绑定的曲线、死区、饱和度、反转和滑块设置，并以每个游戏自己的响应模型写入（DCS 曲率、IL-2 响应、MSFS 灵敏度、X-Plane 响应曲线 ……）。

因此，导出一次之后，“Throttle · BTN 22”就会在 F-16、F/A-18、A-10C、IL-2 Korea 和 War Thunder 中放下起落架，玩家在每个座舱中都能用同一个开关完成同一项任务。

技术细节

#内部工作原理

  • 数据模型（engine\CoreRelation.cs、CoreProfile.cs）：.pr0file 保存 Relation 对象；每个对象有名称、分组、IsAxis、一个 RelationItem 列表（游戏、id、带开/关状态的飞机、顺序）和一个 Bind（设备、输入、修饰键、按作用范围的轴调校）。修饰键是单独的对象，通过名称引用。配置文件以原子方式保存并带有版本（ProfileHistory.cs）。
  • 搜索（engine relations search）：一个索引涵盖每个游戏的命令列表（游戏数据文件夹中的 DB\<game>）、功能目录 DB\Functions（功能、同义词、游戏术语，对照手册核实过）以及按 id 的含义（EngineIdMeanings.cs：每架 DCS 飞机中相同 / 相近 / 不同）。GUI 在最后一次按键后 300 ms 运行搜索；快速命令交给一个长时间运行的 engine serve（引擎服务器），而不是每次新开一个进程。
  • 更改：relations add <name> --axis|--button --node Game:Id:Plane1|Plane2、relations suggest apply <relation> --add ... | --take | --never | --remove、relations rename、relations item move、relations aircraft set。每个都是一条引擎命令，因此是一步撤销。
  • 建议：relations suggest <relation> [--min high|medium|low]（评分如上）；relations suggest --all --missing 一次处理所有关联。
  • 自动分组：确定性规则加上学到的风格（你自己的关联中至少有两次独立的决定）；先预览，再应用。可选的本地 AI 模型只调用同样的工具；没有它时由离线规则作答。

当你搜索、创建关联和获取建议时会发生什么。关联页面向引擎服务器发出请求：

# 谁 会发生什么
1 你 在搜索框中输入“gear”。
2 引擎服务器 relations search "gear" --limit 200 --per-game 12 按游戏分行回答，主要控制排在最前，并说明每一项被找到的原因。
3 你 勾选几行，然后按 创建关联。
4 引擎服务器 relations add "Gear" --button --node DCS:d68...:F-16C_50\|FA-18C_hornet --node WarThunder:ID_GEAR:WarThunder 保存配置文件，并生成一个历史版本。
5 引擎服务器 relations suggest "Gear" 返回建议、它们的分数和原因。

引擎命令：engine relations search、engine relations add、engine relations suggest、engine relations browse、engine relations assistant、engine relations auto-group、engine relations from-text。文档：关联页面参考、自动分组、按描述分组、建议补充。
