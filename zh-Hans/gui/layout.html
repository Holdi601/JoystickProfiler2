界面页面

布局

显示：

布局页面显示你每个设备的图片，以及每个按钮、苦力帽和轴的作用。它有两个部分，在顶部切换：设备图片（一次一个设备：查看、修正标记、在图片上绑定）和 速查表（所有设备的可打印图片，按飞机生成）。这个页面上的任何操作都不会改动游戏，只有在 绑定 模式下做的绑定例外，它会像其他绑定一样进入你的配置文件。

新手入门

#什么在哪里？（布局窗口）

什么在哪里？ 会打开一个包含你所有设备的窗口。每个控件旁边都写着它在游戏中的作用。你可以在本页右上角、开始页面以及系统托盘菜单中找到它。

  1. 选择一个 游戏 和一架 飞机。
  2. 按下按钮，或移动轴或苦力帽，对应的行就会亮起。它的功能会以大字显示在顶部。
  3. 飞行时可以把窗口放在第二台显示器上。它会回到你上次放置的位置。

跟随游戏 会切换到你正在玩的游戏，在 DCS 中还会切换到你正在驾驶的飞机。更多：什么在哪里？查看每个按钮的作用。

#DCS 膝板上的绑定

JoyPro 可以在每架 DCS 飞机的膝板上放一页你的绑定。你在座舱里就能直接查看。

  1. 按本页顶部的 速查表。
  2. 找到 膝板 部分。保持选择 DCS 膝板（OpenKneeboard 也可显示）。
  3. 按 放到膝板上。
  4. 启动 DCS，进入一架飞机并打开膝板，你的页面就在那里。

改了某个按钮？再按一次 放到膝板上：JoyPro 会替换它自己的页面，你的其他膝板页面保持不变。更多：在 DCS 膝板上查看我的绑定。

#设备图片

  • 左侧：你的设备。 每个摇杆、油门、脚舵或面板一张卡片，显示型号以及“你的布局 · 47 个标记”或“参考图片”。点击卡片即可显示它的图片。型号... 用来说明它是哪个型号（如果 JoyPro 猜错了）；交换按钮会把它的绑定移到另一个设备上。
  • 中间：图片。 JoyPro 绘制的设备线稿、厂商的照片或你自己的照片，每个输入处都有一个标签，说明它的作用（“Weapon Release”、“Gear Up/Down”）。
  • 右侧：选中的输入（点击标签或图例中的一行）以及 图例：设备的每个输入及其绑定，“25 个输入中已绑定 7 个”。

#三种模式

  • 查看（V）：查看每个输入的作用。
  • 编辑（E）：把标签拖到真实的按钮上、使用你自己的照片、启动标记助手。
  • 绑定（B）：点击一个输入，在右侧选择一个关联，然后点 绑定到此输入。绑定会进入你的配置文件。

#速查表

你的设备图片，每个绑定都写在按钮旁边，可以打印出来，或者放在第二块屏幕上。勾选设备、游戏和飞机，选择 每个设备一张概览 和/或 每个飞机一张，然后按 生成速查表。图片（PNG）会保存到输出文件夹，预览中会显示它们。

在游戏中: 速查表和绑定模式

速查表显示按钮在一架飞机中的作用；在预览框中选择后，会使用该游戏自己的命令名称。在 绑定 模式下做的绑定会在下次导出时写入游戏，就像在绑定页面上录制的绑定一样。

高级

#显示哪张图片

  1. 你自己的布局文件（JoyPro 1 布局，或你选择的图片）。
  2. 你为该设备拍的照片。
  3. 厂商的参考照片（每个视角一张），只有在你同意后才会下载。
  4. JoyPro 绘制的设备线稿。
  5. 该类设备的轮廓（摇杆、油门、脚舵……）。

画布上方的图片栏为设备的每张图片提供一个按钮。3D 按钮旁边的框用于选择线稿样式：线条，或带粗轮廓的平涂色彩（颜色在 设置 > 线稿 中设置）。有 3D 模型的设备会有 3D 视图：拖动可旋转，滚轮可缩放，双击可复位。速查表打印的、编辑模式所处理的，都是平面线稿。

#是哪个型号？

JoyPro 根据设备的 USB id、名称和它报告的输入，在包含数百个型号的目录中识别设备。如果无法确定（可更换握把的底座、多个产品共用一个 USB id、未知设备），它会在图片上方询问：是哪一款？，并以磁贴列出候选型号，最有可能 的排在最前，还有 保留最有可能的、未列出：搜索目录、暂不。对于未知设备，你还需要选择它的类型。型号... > 选择其他型号... 可以随时再次询问。

#标记助手

当显示的图片上没有某个部件的位置时（“此图片上尚无位置”），标记助手能在一分钟内把它们放好：

  1. 放置标记（只缺少几个时为 放置它们）。
  2. 按下设备上的一个按钮或苦力帽方向（其他设备会被忽略），或者点 更多 > 轴 并移动一个轴。
  3. 在图片上点击该部件的位置。
  4. 重复以上步骤；完成 会保存。

设备不在手边时，现在放置：X 会告诉你下一个输入；点击一下就把它放在那里，以后再说 会在其他输入之后再询问它，没有位置的输入会显示为标签，你可以把它们拖到图片上。撤销 撤回上一次放置；跳过 转到下一个输入；停止 暂停。更多 中有轴、停止、添加控件（JoyPro 不认识的控件：按钮、开关、苦力帽、迷你摇杆、编码器、轴）和 从图片中移除。

#检测到的位置（实验性）

更多 > 检测到的位置（实验性） 会在照片上看起来像按钮、苦力帽或开关的位置画出细虚线圆圈。在圆圈附近点击（或放下标签）会把标记放在圆圈中心。JoyPro 不知道某个位置对应哪个输入，所以它不会自动放置任何东西；该功能只适用于照片，不适用于 JoyPro 的线稿，并且离线运行。

#表格和线条

在已知位置的图片上，表格（工具栏）会画出 JoyPro 1 风格的速查表：图片周围每组控件一个表格，连线指向各部件，每行显示绑定的关联，第二列显示修饰键绑定。预览框选择各行显示的内容：关联名称，或者某个游戏和飞机，并使用该游戏自己的菜单标题。在编辑模式下，你可以拖动表格（它会被固定）、表格的右边缘、连线的线段或某个位置；侧面板中有 修饰键列、行 + / 行 −、已固定、重新布线、删除线条、拆分为单个表格、重新合并、自动排列 和 重置。从 将关联拖到某一行上 拖出一个关联并放在某一行上，就会把它绑定到那里。

#一页多个视图

多视图 把同一设备的多张图片放在一页上（正面和侧面，让每个按钮都能显示）：添加视图、你的图像...、排列、编辑此视图、删除视图、删除页面、返回单张图片。页面格式可选打印用的 A4 或 Letter，屏幕用的 16:9 / 21:9 / 32:9。速查表会打印这一页。

#修正 JoyPro

如果某个输入缺失或位置不对，请在编辑模式下修正（拖动、添加控件、从图片中移除、在图例中重命名）。所有修改都作为你自己的一层保存在这台电脑上，叠加在 JoyPro 的数据之上。向 JoyPro 发送修正... 会把修改保存为一个小文件，并在 GitHub 上打开一个预先填好的问题表单；是否发送由你在那里决定。型号... > 重置为 JoyPro 默认设置... 会移除你对某个设备的所有修改（会先询问；撤销重置 可以恢复）。

#快捷键

V / E / B 切换模式，N 放置标记（布局文件），Del 删除，Ctrl+Z / Ctrl+Y 撤销和重做，Ctrl+S 保存，+ / - 缩放，0 或 F 适合窗口，编辑模式下方向键微调（Shift：10 px），按住 Alt 拖动时不吸附，拖入的图片文件会成为你为该设备拍的照片。

#页面的内部原理

  • 在这台电脑上（<data>\DeviceReference）：grips.json（型号选择的回答）、Layouts\（你在每张图片上的位置）、Callouts\（表格和线条）、MultiView\、ReferencePhotos\<model>\（用 SHA-256 校验）、Corrections\、ResetBackups\；你的设备定义在 <data>\Devices 中。全局速查表样式在 sheet-style.json 中。

#点亮我按下的控件

复选框已撰写
