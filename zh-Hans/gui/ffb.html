界面页面

力反馈

显示：

JoyPro 会读取你所驾驶游戏的实时遥测数据（空速、迎角、G 力、起落架、机炮、命中……），并把它变成力反馈摇杆（例如 VPforce Rhino）上的力：失速抖振、G 力下的摇杆重量感、起落架和襟翼的震动、机炮连射、跑道震动，以及随空速变硬并跟随配平的回中弹簧。摇杆的表现由一张节点图决定，你可以修改它。它适用于 DCS World、IL-2 Great Battles、IL-2 Korea 和 War Thunder。

新手入门

#四步获得力反馈

  1. 把页面的开关切换为 开。JoyPro 现在每 5 秒查找一次支持的游戏；在此之前不会运行任何东西。
  2. 在 设备和力 下按 刷新，然后选择你的力反馈摇杆。开始时 强度 和 最大力 保持默认即可（最大力是所有效果的上限，默认为 60 %）。
  3. 按 ↔ 方向测试。JoyPro 会轻轻推动摇杆，并问你它往哪个方向移动了：用按钮回答。它会替你设置 反转 X / Y，并检查回中弹簧和配平。
  4. 在 游戏 下选择你的游戏，然后按 遥测导出 下的 安装（请先关闭游戏）。这会让 DCS 或 IL-2 把遥测数据发送给 JoyPro（War Thunder 会自己发送）。然后就可以飞了。
关闭游戏自带的力反馈

JoyPro 会自己驱动摇杆。请为该摇杆关闭游戏的力反馈（DCS：飞机的 FFB 选项；IL-2：Settings > Input devices；War Thunder：关闭 force feedback），否则游戏会占用设备，JoyPro 就无法发送力。

在游戏中: 你会感受到什么

接近失速时摇杆会抖动；在 G 力下会变重；起落架和襟翼移动时会震动；在跑道上会随速度震动；机炮会一阵阵地后坐；被命中（IL-2）时会向侧面猛地一震。飞得越快，回中弹簧越硬，配平（游戏的配平，或 JoyPro 自己的配平按钮）会移动它的中心。在菜单中或游戏暂停时，JoyPro 会停止所有效果并松开摇杆（只有当回中弹簧由 JoyPro 提供时，它才会保留）。

高级

#设置选项卡

设备和力：设备、强度（所有效果）、最大力（每个轴的硬上限：任何效果或效果之和都不会超过它）、方向（反转 X / 反转 Y，按设备保存）、↔ 方向测试、回中（“由 JoyPro 提供回中弹簧”，配平需要）和 弹簧刚度（用于图中没有弹簧的轴上的普通弹簧）。

方向测试，逐步进行（每一步都等待 ▶ 就绪；■ 取消 可随时停止所有力）：

  1. 点 ▶ 开始。JoyPro 把摇杆向右推 2 秒（20 %）。回答：它往哪个方向动了？
  2. JoyPro 把它向前推 2 秒。回答：它往哪个方向动了？
  3. 回中弹簧。回答：它会弹回来吗？
  4. 配平：中心向前移动 35 %。回答：它是否移动并保持在那里？

第 4 步之后，会为此设备保存 反转 X / Y。↻ 重复此步骤 会重复当前步骤。

“它没有动”会保留该轴的设置，并告诉你要检查什么（在 VPforce 摇杆上：配平需要关闭 Configurator 自己的弹簧）。⏮ 重新开始 从头再来。测试需要独占摇杆：当 JoyPro 的力反馈正在为某个游戏运行时，测试会拒绝启动。

游戏：选择一个游戏、此游戏的力反馈、它的 强度、它的 图（内置 或你的某个图文件；在编辑器中打开）、内置图各效果的开关（buffet、gforce、gear、flaps、speedbrake、runway、shake、guns、hits、spring）、有自己的图或强度的飞机（添加飞机、删除）以及 遥测导出（安装、删除、试运行）。强度是相乘的：全局 x 游戏 x 飞机，然后再受最大力上限限制。

#图编辑器

图决定了遥测数据如何变成力。数值沿连线从左向右流动，归一化到 0..1（需要方向时为 -1..1）：

  • 遥测 节点读取游戏的一个键（ac.ias、ac.aoa、ac.g ...），并按最小/最大值归一化。
  • 分组、曲线（一条可拖动的贝塞尔曲线）、数学运算和有状态节点（低通、变化率限制、阈值）对数值进行加工。
  • 输出 就是效果：恒定力、周期力（正弦、方波、三角波、锯齿波；强度和频率由输入映射而来）、弹簧（刚度，中心 = 配平）、阻尼、摩擦。同一轴、同一槽位上同类型的输出相互竞争（最强的生效）；不同槽位的输出相加。
  • 来自你设备的 输入：设备按钮 / 苦力帽（任意设备；⏺ 现在请按下按钮... 会捕获它）、摇杆位置、配平（⇕ 分配配平按钮 会要求六个按钮：配平到摇杆位置、低头、抬头、向左、向右、复位）。

选择一种节点类型并点 添加到图中，从一个端口拖到另一个端口来连线，选中后点 删除所选。从内置图新建 从 JoyPro 飞行图的副本开始；保存 / 另存为 写入图文件，加载 / 重新扫描 读取它们。然后在设置选项卡上为某个游戏或飞机选择该图。

#遥测检查器

实时显示正在运行的游戏的每个遥测键，以及它的数值、标题和单位。可按键或标题筛选。用它来查看应该把哪个键放进遥测节点，以及它的数值范围。

技术细节

#页面的内部原理

视图模型：MainWindowViewModel.FfbTelemetry.cs（设置、游戏、飞机、安装、进程）、MainWindowViewModel.FfbDirectionTest.cs（测试向导）、FfbGraphEditorViewModel.cs（编辑器）；Views/Controls/FfbGraphCanvas.cs、FfbCurveEditor.cs。力反馈在独立进程 JoyPro.Ffb.exe 中运行（gui/JoyPro.Ffb，图引擎位于 gui/JoyPro.Ffb.Core）。

力反馈进程从游戏启动到释放摇杆的过程：

# 谁 会发生什么
1 JoyPro 页面为开启时每 5 秒检查一次：是否有支持的游戏正在运行？
2 JoyPro 启动力反馈进程：JoyPro.Ffb run --game DCS --game-pid N --parent-pid M --protocol。
3 游戏 发送遥测数据（DCS 使用 UDP 端口 41992）。
4 力反馈进程 在第一个力出现时（独占）接管摇杆。然后在遥测数据到达期间，每秒 50 次，只发送发生变化的效果值。
5 力反馈进程 遥测停止（菜单、暂停）：STOP ALL，摇杆被释放（开启“回中弹簧”时弹簧保留）。
  • 生命周期：进程通过进程句柄跟随游戏，并随游戏或 JoyPro 一起结束。每个恒定力和周期力的持续时间都是 0.3 秒并不断重新启动，因此卡死或被结束的进程不会在摇杆上留下力。遥测超时（0.5 秒）、游戏退出、JoyPro 退出以及出现任何错误时，都会执行 STOP ALL。
  • 设置：<data>\Ffb\Telemetry\telemetry-ffb.json（<data> = %LOCALAPPDATA%\JoyPro2）；图保存在 <data>\Ffb\Telemetry\Graphs\*.jpffb.json（格式 joypro-ffb-graph）；最后状态保存在 status.json。
  • 引擎：engine ffb telemetry status（页面的状态）、engine ffb telemetry config set / engine ffb telemetry config clear（--game、--plane：按游戏和飞机）、engine ffb telemetry effects、engine ffb telemetry setup dcs 以及其他游戏的安装（安装、删除、--dry-run；会先备份游戏文件）。
  • 游戏：DCS（Export.lua 中的一行，UDP）、IL-2 Great Battles 和 Korea（游戏的遥测设备输出，UDP）、War Thunder（游戏在端口 8111 上的本地 Web 服务器，无需安装）。在 设置 > 游戏 中隐藏的游戏不会显示，也不会被查找。
  • 方向：正的力在 X 轴上向右推，在 Y 轴上朝飞行员方向推；按设备（按实例 GUID）反转 X / Y 会翻转力和弹簧中心。

参考：ffb-telemetry，录制同样的遥测数据：telemetry-recording。
