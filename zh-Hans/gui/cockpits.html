界面页面

座舱

显示：

座舱页面是真实和虚构座舱的参考资料，编排方式就像飞行手册中的座舱章节：选择一架飞机、它的版本和座位，然后阅读概览、每个握把（摇杆、油门、周期变距杆、总距杆）一页并附 HOTAS 表格，以及每个面板一页。它不会改动你的配置文件或游戏；它帮助你决定哪个功能放在哪个按钮上，使用此布局 会用某架飞机的摇杆和油门布局打开设置向导。

新手入门

#三个部分

  • 左侧：选择器。 一个搜索框（“F-16”“Hornet”“TMS”）、类型、游戏、年代、角色 和 国家 的筛选器、飞机列表，以及列表下方的 版本 / 批次 / 阶段（例如 F-16C Block 50）。
  • 中间：手册。 座舱概览 和每个握把的选项卡、每个面板一页的 面板 列表、用于上一页和下一页的 ◀ / ▶，以及 在此座舱中搜索（“电瓶”“自动驾驶”）。
  • 右侧（窗口较窄时在上方）：座舱指南。 用浅显的话说明每个区域、面板和控件。它有什么作用？ 会打开某个控件的说明。

#握把页面上有什么

一张带编号标注的握把线稿，以及 HOTAS 表格：每个控件和方向（按下、长按、按住）一行，每种模式（NAV、A-A、A-G；或 TGP、HUD）一列。这就是真实飞机使用每个按钮的方式，是你自己做绑定的好榜样。

#图片

如果你安装的游戏中有这架飞机，根据我的游戏生成图片 会绘制游戏中的座舱，每个可点击的控件都编号，并按游戏中的名称命名。对于你没有的飞机，JoyPro 提供可下载的 图片包；对于没有任何游戏包含的座舱，则提供叠加了 JoyPro 标签的 经过核实的照片。

在游戏中: 不会写入任何内容

不会向游戏写入任何内容。与我的设置比较 会在 HOTAS 表格中标出你当前打开的配置文件已经为该游戏和飞机绑定了哪些功能，让你一眼看出还缺什么。

高级

#该型号的按钮

  • 与我的设置比较：打开配置文件后，如果你的某个关联在该游戏和飞机上占用了 HOTAS 表中的某个功能，该功能会得到一个标记，并显示关联名称和输入。隐藏 会去掉这些标记。
  • 使用此布局：打开设置向导，以该型号的摇杆和油门布局作为你绑定的样板（它的飞机排在优先级列表的最前面）。
  • 导出页面（PNG） / 所有页面（PDF）：把当前显示的页面或该型号的所有页面，按你的线稿样式（设置 > 线稿）导出到 Documents\JoyPro2\Cockpits；打开文件夹 打开它。
  • 座位：有两个座位（前座和后座）的版本，每个座位各有一套页面。

#图片从哪里来

打开一个型号时，JoyPro 按以下顺序显示第一个存在的图片：

  1. 来自你游戏的图片：总览、握把、每个面板一页。
  2. 来自 JoyPro 发布的图片包：JoyPro 会先询问（下载 / 暂不；设置 > 隐私：询问、总是或从不）。然后它会显示第 1 步中的游戏图片。
  3. 经过验证的照片：下载后，每张照片一页，带有 JoyPro 的编号标签。
  4. JoyPro 自己的线稿。
  • 根据我的游戏生成图片 读取游戏自己的文件（DCS、X-Plane 12、MSFS 2020、IL-2 Great Battles、Nuclear Option、Star Citizen、War Thunder），在这台电脑上渲染座舱。每张图片大约需要两秒；一个大型 DCS 模块有 50 到 80 张。图片与你的游戏数据保存在一起，绝不会放进游戏文件夹。
  • 旁边的框可以在 游戏中的图片 和 JoyPro 线稿（从渲染图描出的线稿，使用你的线稿样式）之间切换。当你的多个游戏都有这架飞机时，第二个框用于选择使用哪一套。
  • 来自 JoyPro 发布的图片包（可展开部分）：从游戏渲染的座舱图片，适用于你无法自己生成的飞机。下载我所有飞机的图片 或 下载此游戏的全部内容 会先显示总大小；下载时会显示进度，并且可以取消；校验和不匹配的图片包不会被安装。
  • 经过验证的照片：对于没有任何游戏能提供好图片的飞机（客机、航天器、部分直升机和喷气机），下载照片 会从原始地址（或网页存档的副本）获取每张照片，与 JoyPro 的记录逐一核对，并保存在这台电脑上。之后手册中每张照片一页，带有 JoyPro 的编号标签和照片的署名。
  • 照片（在页面下方）：指向真实照片的链接。JoyPro 在加载任何照片之前都会询问：是、否、座舱总是如此、从不。

#座舱指南

区域（左侧控制台、主面板、顶部面板）> 面板（“ENG & JET START control panel”）> 控件（每个开关、按钮和旋钮及其位置）。点击一个控件会打开显示它的页面，并圈出它的标注；点击一个标注会在指南中选中它。全部展开 / 全部关闭 展开或关闭所有区域。

技术细节

#页面的内部原理

  • 视图模型：CockpitsViewModel.cs（选择器、筛选、比较、使用布局）、CockpitsViewModel.Pages.cs（手册页面、导出）、CockpitsViewModel.Guide.cs、CockpitsViewModel.Pictures.cs、CockpitsViewModel.PicturePacks.cs、CockpitsViewModel.VerifiedPhotos.cs；页面视图 ManualPageView。
  • 数据：DB\Cockpits\*.json（飞机、型号、控件、面板）、DB\Cockpits\drawings、line-drawings、guide、photo-labels（每张经过验证的照片一个文件）。
  • 在这台电脑上：游戏图片位于 <data>\GameData\CockpitPictures\<game>\<aircraft>（pictures.json、index.json），经过验证的照片位于 <data>\CockpitPhotos\<aircraft>，链接的照片在下载缓存中；照片相关的回答与设备照片的回答保存在一起（cockpit:<aircraft>）。
  • 引擎：engine cockpits（list、search、get --json 用于 使用此布局、compare 用于 与我的设置比较、render 用于 PNG/PDF、pictures build|status|check、photos）。参考：cockpits、privacy。
