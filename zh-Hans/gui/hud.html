界面页面

HUD

显示：

HUD 会在你游戏时把你的设备显示在屏幕上，就像主播的手柄叠加层：摇杆图片会随你的摇杆倾斜，拉杆和轴以条形移动，按住的按钮会带着名称亮起，还有一行文字说明按下的按钮在运行中的游戏里的作用（“Gear Toggle”）。它可以显示在游戏上方、OBS 中，或者两者都显示，每处都有自己的小部件。这个页面就是它的设计器。

新手入门

#点三下启动 HUD

  1. 在底部栏中打开 HUD。移动摇杆时，预览已经会跟着动。
  2. 保持 在我的屏幕上（覆盖在游戏上方） 处于勾选状态。
  3. 按 启动 HUD（在 开始 页面上也有）。启动你的游戏：HUD 会显示在游戏上方，永远不会抢走游戏的鼠标或键盘。

停止 HUD（同一个按钮）会关闭它。你在这里做的所有设置都会保留，重启后依然存在。

#屏幕上有什么

  • 每个设备一个 小部件：摇杆、油门和脚舵一开始就会显示，面板和键盘则被隐藏（在 小部件 列表中勾选它们）。每个小部件可以显示设备的照片、摇杆位置、以条形显示的轴、按钮和苦力帽。
  • 飞机小部件：你所驾驶飞机的摇杆和油门，按游戏的画法绘制，随你的摇杆和油门一起动。
  • 游戏标题栏：游戏或 DCS 飞机及其图片。
  • 按钮的作用：最近按下的按钮及其在运行中游戏里的操作。

在预览中拖动小部件可以移动它；点击它可以在右侧修改它。自动排列 会把它们沿底部排列：油门和左手设备在左边，脚舵在中间，右手摇杆在右边。

在游戏中: 你在游戏中看到的内容

HUD 窗口是透明的，会保持在窗口化和无边框游戏的上方。点击会穿透它传到游戏中。它不会出现在任务栏或 Alt+Tab 中。独占全屏会把它遮住（这是 Windows 的限制）：请把游戏切换为无边框模式。按下按钮的那一行会写出该游戏和飞机中的操作名称，例如 F-16C 中的“Weapon Release”和 IL-2 中的“Fire guns”。

高级

#HUD 显示位置

三种输出彼此独立：

输出 面向 方式
在我的屏幕上（覆盖在游戏上方） 你自己 游戏上方的一个透明窗口
OBS 页面（浏览器源，透明） 你的直播（推荐） JoyPro 只在这台电脑上提供一个页面；复制 会把它的地址复制到剪贴板
直播窗口（窗口采集） 使用窗口采集直播 一个普通窗口（可以位于游戏后面），背景透明或使用色度键颜色

取消勾选 在我的屏幕上，就能在干净的屏幕上游戏，同时直播中仍显示 HUD；也可以在两边显示不同的小部件：每个小部件都有两个勾选框，一个是显示器（你的屏幕），一个是 OBS（直播）。预览：我的屏幕 / 直播 切换设计器中显示的内容。每秒最多更新次数（15、30 或 60；30 流畅且轻量）。

#设置 OBS（浏览器源）

  1. 勾选 OBS 页面（浏览器源，透明） 并点 启动 HUD。
  2. 点地址（http://127.0.0.1:8765/hud）旁边的 复制。
  3. 在 OBS 中：Sources > + > Browser。把地址粘贴到 URL，Width 设为 1920，Height 设为 1080。不需要其他任何设置：背景是透明的，无需自定义 CSS。
  4. 可选：勾选 Shutdown source when not visible，这样 OBS 会在没有它的场景中停止该页面。

该页面在一个按源缩放的 1920 x 1080 画面上，以与程序中相同的位置和样式绘制勾选用于直播的小部件。端口被其他程序占用了？在 端口 中选择另一个端口，然后重新复制地址。

改用窗口采集：勾选 直播窗口，选择背景（透明、绿色、品红、蓝色或你自己的颜色）。在 OBS 中添加 Window Capture，并设置 Capture Method: Windows 10 (1903 and up)；使用颜色背景时，添加该颜色的 Chroma Key 滤镜。如果透明背景在你的 OBS 中显示为黑色，请使用浏览器源或颜色背景。

OBS 浏览器源如何获取 HUD：先获取一个页面，之后只获取变化。

# 谁 会发生什么
1 OBS 浏览器源打开 http://127.0.0.1:8765/hud。
2 JoyPro 发送页面：布局、样式和图片。
3 OBS 打开 /hud/events。它会保持打开。
4 JoyPro 发送状态（轴、按钮、按钮的功能），每秒最多 30 次，并且只在有变化时发送。
5 JoyPro 当小部件、位置或样式改变时，再次发送布局。

#小部件

小部件 列出每个设备，以及标题栏、绑定滚动条和飞机小部件。重新加载设备 重新读取已连接的设备；全部显示 为你的屏幕勾选所有小部件；自动排列 和 重置位置 会把它们摆放到位。

每个小部件（在预览或列表中点击它）：

  • 在我的屏幕上显示、在直播中显示、大小、此小部件的样式（HUD 的样式或其他任意样式）。
  • 显示：名称、类型（摇杆、油门）、图片、图片随摇杆倾斜、按钮点亮、按住的按钮名称、轴和操纵杆、轴名称、轴数值、摇杆位置（万向节）、苦力帽。标题小部件：它的图片。
  • 图片：照片（厂商的图片，去掉背景）、布局（你在 布局 页面上的 JoyPro 布局图片，按下的按钮在其位置点亮）、自动（有照片时使用照片）。
  • 此底座上的握把：用于可以安装多种握把的底座（VPforce Rhino、Virpil WarBRD）；握把决定图片和按钮名称。
  • 摇杆轴：摇杆元素的 X、Y 和扭转来自哪里。自动 使用设备自己的轴；如果握把本身是一个没有轴的独立设备，就使用它所安装的底座的轴。

飞机小部件：摇杆、油门、油门行程条、摇杆位置、控件点亮、按住的控件名称；飞机（自动：你正在驾驶的飞机，或这台电脑上设置的任意图片）和 跟随（驱动它运动的摇杆和油门）。它的图片来自游戏自己的座舱图片（座舱 > 根据我的游戏生成图片，或图片包），否则使用 JoyPro 绘制的真实握把线稿。

#40 种样式

样式 有 40 种预设：玻璃、霓虹、极简，简洁类（磨砂浅色、主播简洁、主播醒目、紧凑、大字、粉彩、仅轮廓），座舱显示类（军用绿色 HUD、琥珀色 MFD、客机 PFD、玻璃座舱、夜视、红色座舱照明、矢量线框、复古终端、复古战机、全息），游戏和类型类（太空模拟橙、全息青、赛博朋克、合成波、霓虹粉、赛车、战术沙色、海军蓝与金、隐身、幽灵），颜色主题（极地、沙漠、海洋、日落、皇家、碳纤维）和易读性类（高对比度、高对比度浅色、单色、单色浅色）。› 切换到下一个。

下方：一键选择强调色，强调色、按下 和 不透明度，然后是各元素的设计选项：卡片（背景、边框、圆角、阴影）、文字（字体、大小、字间距、颜色、名称加粗）、摇杆元素（圆环、方形、十字准线、雷达、圆点；大小、发光）、条和拉杆（形状、高度、空白部分）以及 按钮和标签（形状）。更改任一选项后，样式会变为“自定义设计（已更改）”：保存样式 以你起的名称保存它，撤销更改 回到预设，导出样式... / 导入样式... 以文件形式分享它，删除 删除你自己的样式。

#按钮的作用和 DCS 飞机

按钮的作用：显示多少行、停留多久（秒）、字体大小、显示设备和按钮 和 仅在游戏运行时。鼠标穿透 让鼠标点击穿过 HUD 窗口（在 HUD 启动时生效）。

JoyPro 通过进程找到正在运行的游戏（DCS、IL-2、Star Citizen 以及它支持的所有其他游戏），只显示该游戏的绑定。DCS 还需要知道飞机：在 DCS 飞机 中选择，或者点 安装 DCS 挂钩，让 DCS 在每次任务开始时把飞机告诉 JoyPro（一个小的 Lua 文件，外加 Export.lua 中一行受保护的代码，修改前会先备份；删除 会把文件逐字节恢复原样；请先关闭 DCS）。检查 会告诉你挂钩是否已安装。

技术细节

#页面的内部原理

视图模型：MainWindowViewModel.Hud.cs（设备、小部件、布局）、MainWindowViewModel.HudStyles.cs（预设、自定义样式、导入/导出）、MainWindowViewModel.HudStream.cs（输出、直播页面、飞机小部件）、MainWindowViewModel.HudAxes.cs（摇杆轴）、MainWindowViewModel.Overlay.cs（启动/停止、正在运行的游戏、按钮行、DCS 挂钩）。视图：Views/HudWindow.axaml、Views/Controls/HudSurface.axaml、HudElements.cs、HudPanel.cs。预设：Models/HudStylePresets.cs。

  • 设备：engine hud devices 给出每个已连接设备的型号、类型、左右手、产品图片、轴及其作用、按钮及其名称和控件 id（Controls，供飞机小部件使用），以及带按钮位置的布局图片。
  • 正在运行的游戏的绑定：engine overlay map（--game、--plane、--unit）：带修饰键和标题的已绑定按钮。带修饰键的绑定在按住其修饰键时显示；匹配修饰键最多的绑定优先。
  • DCS 挂钩：engine overlay dcs-hook status / install / remove（--path、--dry-run）：Scripts\JoyProOverlay.lua，外加 Export.lua 中一行用 pcall 包裹的代码；DCS 把单位类型发送到 127.0.0.1:1992（UDP）。挂钩会调用它所替换的其他脚本（SRS、Tacview）的导出函数。
  • 直播服务器：Services/HudStreamServer.cs、HudStreamHub.cs、Resources/hud-stream.html；只绑定到 127.0.0.1，使用其他主机名的请求会被拒绝。GET /hud（页面）、/hud/events（Server-Sent Events：layout、state）、/hud/img/<id>（PNG 格式的图片）、/hud/state（JSON）。没有页面连接时，它只是监听。
  • 游戏时的开销：Services/HudInputPump.cs 只保留每个设备的最新报告，并按所选频率应用；元素只在变化时重绘；每次报告都不分配内存；图片只裁剪一次（飞机握把高 480 px）。由 HUD 长时间运行测试按 CPU、内存分配和内存占用预算进行测量。
  • 设置：%APPDATA%\JoyPro2\hud.json（位置、大小、每个小部件在屏幕和直播上的勾选、包含所有选项的样式、自定义样式、输出、端口、背景、更新频率）。样式文件：*.joypro-hudstyle.json（"format": "joypro-hud-style"）。
