界面页面

设置向导

显示：

设置向导会一次性为你的游戏设置好控制。它会查看你已连接的设备，给每个设备分配一个角色（主摇杆、油门、脚舵、面板……），为你游戏中飞机的重要功能创建关联，把它们绑定到你的设备上，并以速查表的形式向你展示结果。在你的配置文件被更改之前，你可以检查所有内容，按一次 撤销 就能全部撤回。它不使用 AI：相同的选择总是得到相同的计划。

从开始页面打开它。它的卡片“设置你的设备”有两个按钮：

  • 全部帮我设置好（蓝色按钮）：快速设置。它会自动运行这个向导，不显示各个步骤，最后停在一个简单的列表上，列出什么放在哪里。参见 快速入门。
  • 分步设置...：包含全部五个步骤的向导，由你自己选择每一步。

如果没有那张卡片（每款游戏都已经设置好了），请按开始页面上 你的游戏 下方的 自动设置我的设备...，或者在绑定页面上按它。

  1. 游戏
    要设置哪些游戏
  2. 设备
    每个设备的用途
  3. 优先级
    你的飞机、修饰键、功能放在哪里
  4. 计划
    JoyPro 放置了什么
  5. 检查
    检查，然后 应用到我的配置文件

快速设置（全部帮我设置好）会跳过这些步骤运行同一个规划器。它使用设备的常规角色，所有飞机一视同仁，不用修饰键，并沿用你上次在 功能放在哪里？ 中的选择。对于飞行模拟游戏，它只问一个问题：你使用头部追踪或 VR 吗？

新手入门

#五个步骤

步骤显示在顶部；底部的 返回 和 下一步 用来在步骤之间切换。你可以随时关闭窗口：在 应用 之前关闭的向导，再次打开时会保持你离开时的样子。

#1. 游戏

你在开始页面上监视的游戏会被勾选。勾选这次设置要涵盖的游戏。这不会改变 JoyPro 监视哪些游戏。

#2. 设备

JoyPro 会识别你的摇杆、油门、脚舵和面板，并为每个设备建议一个角色：“此设备的用途”。在列表中可以更改角色。每只手一个设备：同一只手的第二根摇杆会被设为“未使用”，除非你另作选择。可以装多个握把的底座会询问装的是哪个握把。右侧的框会用文字说明 JoyPro 将如何使用它们。重新检测 会重新读取设备（请先插入设备）。

#3. 优先级

  • 你的飞机：搜索一架飞机（“F-16”“直升机”“Star Citizen”），然后按 添加为下一优先级（新的一行）或 添加为同等优先级（加入选中的那一行）。飞机排得越靠前，它的功能就能得到越好的位置。同一行中的飞机权重相同；你没有列出的飞机权重最低。
  • 修饰键：修饰键是一个你按住的按钮（就像 Shift），让其他每个按钮都能做第二件事。选择要用多少个；尽量少 只在按钮不够用时才使用修饰键。
  • 模式开关（阶段层）：一个能保持位置的开关可以按作战阶段改变按钮的作用。
  • 功能放在哪里？：一个滑块。左端：每架飞机同一件事用同一按钮。右端：按真实飞机的位置。中间是初始位置。机炮和油门永远不会移动。参见 功能放在哪里？。
  • 你使用头部追踪或 VR 吗？ 仅适用于飞行模拟游戏。如果你靠转动头部环顾四周（TrackIR、带面部追踪的网络摄像头、Tobii 或 VR），或者打算这样做，选 是：设备上不放视角按钮，只放“视角回中”。否：环顾四周会放到摇杆或油门的苦力帽上，紧跟在最重要的按钮之后。参见 头部追踪和环顾四周。

#4. 计划

JoyPro 制定计划：它放置了多少个功能、哪些无法放置、它创建的修饰键、它遵循的规则，以及每架飞机的质量评分（100 % = 每个功能都在最佳位置上）。

#5. 检查

选择一个 设备 和一架 飞机，查看 JoyPro 绘制的设备线稿以及什么绑定在哪里。在列表中选择一个功能，可以把它移到空闲的输入上、与另一个功能交换，或者把它从计划中移除。未放置 列出放不下的功能，最重要的排在前面。

满意后：按 应用到我的配置文件，然后按 导出到我的游戏（会打开导出页面）。只有导出后你的游戏才会改变。

高级

#详情

  • 角色：主摇杆（每架飞机中的右手）、直升机摇杆（直升机中的右手，用于第二个摇杆，例如力反馈底座）、左手摇杆（太空游戏中的左手；没有油门时用在油门一侧）、油门、总距杆（直升机中的左手）、脚舵（方向舵和脚尖刹车）、面板（印刷标签相符的系统开关：“LDG GEAR UP”会分配到起落架）、键盘摇杆和虚拟设备（保留，不新增绑定）、未使用。
  • 你的配置文件优先：已经在你某个关联中的命令会留在那里，已经绑定到本次设置中某个设备上的关联会保留它的输入。你关闭的命令保持关闭。
  • 功能放在哪里？ 滑块从 每架飞机同一件事用同一按钮 到 按真实飞机的位置。中间以下，每个功能为所有飞机只建一个关联；从中间开始，真实 HOTAS 上把该功能放在别处的飞机会得到自己的关联，越往右，真实位置的影响越强。快速设置和开始页面会使用你上次的选择（初始为中间）。
  • 第 3 步的选择会被记住；下一次向导会以它们开始。
  • 应用 把所有内容作为一次更改写入：在配置文件的历史记录中生成一个名为“Setup wizard: N relations, M binds”的版本。撤销（Ctrl+Z）会把它全部撤回。
  • 打开表单 会在你的图片查看器中以原尺寸显示速查表，方便打印。
  • 当 设置 > 使用统计 > 让新飞机采用我最常用飞机的布局 开启时，新布局会参照你在同类飞机中最常用的那一架。
在游戏中: 应用并导出之后

导出之前不会有任何改变。按 应用 并导出后，每款游戏的控制文件中就会有向导做的绑定：当滑块靠近 每架飞机同一件事用同一按钮 时，DCS 中每架选中的飞机都会把同一个功能放在同一个按钮上；Star Citizen 会把飞船控制放在摇杆上，把平移轴放在左手摇杆上；面板会得到其标签所标示的系统。如果希望设备失去游戏之前的绑定，请用 在我的设备上替换 导出。

技术细节

#向导的内部原理

窗口 Views/SetupWizardWindow.axaml，视图模型 ViewModels/SetupWizardViewModel.cs（独立的视图模型，由 MainWindowViewModel.SetupWizard.cs 带着被监视的游戏创建），规划器 engine/SetupWizard/*.cs。每一步都是一个引擎命令，因此 CLI 会生成相同的方案：engine setup devices（识别和角色，--role、--grip）、engine setup aircraft（优先级列表）、engine setup plan（--games、--priorities "A>B|C"、--modifiers、--prefer-fewer 或 --use-all-modifiers、--placement（旧名 --realism）、--phase-layers，engine cockpits 的座舱条目作为 --cockpit-file；写入方案 JSON）、engine setup render（每个设备一张标注图）、engine setup apply（--plan，一个配置文件版本）。移动、交换、移除和放回在 GUI 中编辑方案（SetupPlanEdit），并在应用之前再次检查。参考：设置向导。

#应用

按钮已撰写

把这些按钮放入 JoyPro。游戏暂时不会改变。

第 5 步：一步把方案中的关联、绑定和修饰键写入你的配置文件：在配置文件的“历史记录”中是一个版本，一次“撤销”就能全部撤回。

会先检查方案；如果有问题，会停止并给出提示。
