界面页面

开始

显示：

开始页面是 JoyPro 启动时打开的页面。它显示已经设置了什么、下一步该做什么，以及你的游戏：导入 把你在游戏中做好的绑定导入 JoyPro；导出 把它们写回游戏。导入的分步说明：导入游戏。

新手入门

#从上到下

  • 通知：缺少的必要组件、需要生成或更新的命令列表、要发送的崩溃报告、可用的更新。
  • 设置你的设备：自动设置卡片。JoyPro 会（只读地）查看你的哪些游戏还没有分配任何内容，并列出它们的名称：“为 War Thunder 和 Star Citizen 设置设备”。全部帮我设置好（蓝色按钮）会自动完成一切；分步设置... 会打开设置向导，并勾选这些游戏。你自己做过绑定的游戏列在它下面：导入，然后填补空缺 会先导入你的绑定，然后设置只使用空闲的控件。已在配置文件中的游戏：填补空缺...。什么在哪里？ 显示你的设备以及每个控件的作用。
  • 配置文件概览：关联（以及其中有多少是轴）、已绑定的数量、修饰键、已连接的设备、已安装的游戏。
  • 下一步：JoyPro 现在给出的建议（“3 个关联还没有按钮：绑定它们”、“VPforce Rhino FFB Base 尚未使用：自动分配”、“把你的绑定写入游戏：导出”）。
  • 你的游戏：每款游戏一张卡片，带有 导入、导出、更新（它的命令列表）、撤销导出、监视更改 和一个隐藏按钮。自动设置我的设备... 会运行设置向导。
  • 你的设备：已连接的设备及其图片；点击会打开布局页面。设备上出现橙色的 哪个握把？ 或 哪个型号？ 表示 JoyPro 无法判断它是哪一款：点击它会打开布局页面并展开选择，你的回答会被保留。
  • 每款游戏的 最近活动 和游戏监视开关；HUD 卡片。
高级

#导入向导

  1. 选择一个游戏（点击其卡片上的 导入）。
  2. 选择导入方式：添加到我的配置文件（推荐） 或 从此游戏重新开始，以及键盘、未连接的设备、DCS 飞机。先查看 会在输出面板中显示游戏里有什么，不做任何改动。
  3. 立即导入：结果会显示在卡片上方（“Done: your profile now has 214 relations”），并带有 查看我的关联。

在卡片下方，专家导入 为每个游戏（DCS、IL-2、Star Citizen，以及 加载游戏 中的所有其他游戏）提供全部选项，带有扫描 / 导入 / 导出。

#页面的内部原理

MainWindowViewModel.GameHub.cs（卡片、向导）、MainWindowViewModel.Design.cs（仪表板）、MainWindowViewModel.DbUpdates.cs（命令列表）、MainWindowViewModel.DeviceCenter.cs（设备）、MainWindowViewModel.GameSync.cs（监视器）。引擎：engine games installs、engine db check-updates、engine hud devices、engine sync status、engine dcs import / engine dcs scan 以及其他游戏的导入和扫描。
