界面页面

配置文件栏

显示：

配置文件栏位于每个页面的上方。它显示打开的配置文件的名称，并包含在任何地方都能用的功能：打开或新建配置文件、保存状态、返回和前进、撤销和重做、配置文件的历史记录、更多 菜单、面向专家的 选项。它上方的横幅中，在颜色按钮旁边有 本页导览 和 帮助。每个页面下方的底部栏用来在页面之间切换。当设备被移到新的 ID 时，栏下方会出现一条通知告诉你。

新手入门

#什么是配置文件？

配置文件是一个文件（.pr0file），包含你在 JoyPro 中设置的一切：你的关联、哪个按钮做什么（绑定）、换挡按钮（修饰键）以及轴曲线。你可以有多个配置文件，但一次只能打开一个。它的名称显示在栏的左侧；把鼠标悬停在上面可以看到文件所在的位置。

#从左到右的按钮

  • 打开配置文件...：选择一个 .pr0file 文件。
  • 新建配置文件：一个空配置文件。它会在 Documents\JoyPro2\profiles 中获得一个带日期的名称；更多 > 重命名... 可以把它改成你的名称。更简单的办法：在开始页面导入一款游戏，它会为你创建配置文件。
  • 已保存 ✓：JoyPro 会自动保存每项更改。保存期间你会看到 正在保存…；保存失败时会显示 未保存 以及原因（它会再试一次）。
  • 返回 / 前进（箭头）：像浏览器一样回到你之前所在的位置（页面、打开的关联、搜索、滚动位置）。它们永远不会改动配置文件。
  • 撤销 / 重做：撤回配置文件的上一次更改，或者重新执行它（Ctrl+Z、Ctrl+Y）。工具提示会写明是哪项更改（“撤销 添加关联”）。
  • 历史记录：配置文件的每个已保存版本，可以查看、比较、回滚或保留。
  • 更多：打开上一个配置文件、保存副本、重命名、添加另一个配置文件、重新加载、关闭、检查更新、关于。
  • 选项：面向专家的设置（路径，以及配置文件加载时如何修复）。
  • 本页导览（右上角，横幅中）：当前打开页面的简短导览：它的用途、主要部分、下一步做什么。
  • 帮助（右上角，横幅中）：一个菜单，包含 帮助模式（F1）（点击任何东西即可查看它的作用）、本页导览、导览...（包含所有导览的欢迎向导）和 打开 Wiki。参见 帮助模式和导览。

#底部栏

每个页面一个按钮：开始、关联、绑定、修饰键、布局、导出、HUD、力反馈、虚拟摇杆、统计、座舱、设置、高级，另外还有 检查 和 输出 面板。设置 > 底部栏中的页面 可以隐藏你不用的页面并更改它们的顺序。

高级

#撤销、历史记录和后退是三回事

它浏览的内容 改变配置文件？
后退 / 前进 你去过的位置：页面、子视图、打开的关联或设备、搜索文本、筛选条件、滚动位置（最多 50 个） 否
撤销 / 重做 配置文件的版本，一次一步，重启后也可以 是
历史记录 每个版本及其改动；可以回滚到其中任意一个 是（回滚会生成一个新版本，所以可以用撤销退回）

后退和前进也可以用 Alt+Left / Alt+Right 以及鼠标的后退和前进键。

#历史记录面板

  • 左侧：版本列表，最新的在前（“Adding relation”、“Import from DCS”、“Before export to DCS”），配置文件当前所在的版本标有 现在，你保留的版本标有 已保留。
  • 详情 显示一个版本改了什么（“Relation 'Gear' renamed to 'Landing gear'”）；比较 显示该版本与当前配置文件之间的差异。
  • 保留 让一个版本不被清理；回滚到此处 让配置文件完全恢复到那个时间点的样子：之后的所有改动一步撤回，再撤销一次就能把它们找回来。
  • 清理 立即精简所有配置文件的旧版本：最近一天的全部保留，再往前按小时、天和周逐渐减少。JoyPro 也会在后台自动这样做。保留的版本始终不会被删除。

#设备提示

当你打开配置文件时，如果某个设备有了新 ID（Windows 时不时会给设备分配新 ID，或者换了一个同型号的新摇杆），JoyPro 会移动它的绑定，并在栏下方显示提示：哪个设备移到了哪里。撤销 把绑定放回旧设备，替换设备... 打开窗口让你逐个输入地自己移动绑定，OK 关闭提示。

#提示：JoyPro 自行添加的飞机

在 JoyPro 2.6.1 及之前，当命令列表发生变化（刷新 DB，或带新列表的更新）时，JoyPro 可能会在你的关联中启用你从未选择的飞机：所有与你的某个操作共用命令的其他飞机，例如直升机功率杆关联中的 F-15C、A-10C 和 MiG-29。这是 JoyPro 的错误。从 2.6.2 起，它只添加列表中新出现的飞机（你新添加的模块），并且在你打开配置文件时，会在配置文件的历史记录中查找这样的步骤。如果找到，栏下方会出现提示，说明它在多少个关联中、于何时启用了多少架飞机，并按关联和飞机列出：移除（移除勾选的飞机，一个撤销步骤；你自己的绑定保留）、保留这些飞机（JoyPro 不再询问）或 以后再说。在你做出选择之前，什么都不会改变。如果你确实想要其中某架飞机，取消勾选它即可。

“Default”以及 DCS 的其他输入层（摄像机、无线电菜单、地面单位）都不是飞机。导出会把它们写入该层自己的文件夹，绝不会写入某个模块。它们不计入数量，排在列表最后并标为“不是飞机”；如果配置文件里只有它们，就根本不会出现提示。导入以及自动分组等生成器添加的飞机永远不会出现在这里：那些飞机是你自己的。

#替换设备窗口

替换设备...（在提示中、布局页面的设备卡片上、设置 > 设备中）把旧设备的绑定移到另一个设备上：

  • 自动：同一产品使用相同的输入 ID；其他设备按其部件进行匹配。
  • 相同输入 ID（1:1）：按钮 5 仍是按钮 5，X 仍是 X。
  • 按布局（设备目录）：扳机对扳机，苦力帽 2 对苦力帽 2，油门对油门；没有对应部件的按钮按顺序匹配（标为猜测）。
  • 如果新设备的某些输入上已经有绑定：两者都保留、保留新设备的绑定 或 用旧设备的绑定替换。
  • 移动绑定 会先询问，在旁边保留一份配置文件副本，然后按显示的内容执行（撤销可以撤回）；取消 关闭窗口，不做任何改动。
在游戏中: 已移动的绑定

把绑定移到另一个设备上，在下次导出之前不会改变游戏中的任何内容；导出时，绑定会写给新设备。使用 在我的设备上替换 时，导出的飞机中旧设备的绑定会被清除。

技术细节

#顶部栏的内部原理

  • 配置文件命令：MainWindowViewModel.cs（OpenLastProfileAsync、LoadProfileAsync、MergeProfileAsync、SaveLastProfileAsync、ClearWorkspace、RefreshAllAsync），菜单的文件对话框在 Views/MainWindow.axaml.cs 中。
  • 自动保存和历史记录：Services/AutosaveScheduler.cs、MainWindowViewModel.ProfileHistory.cs，存储为 engine/ProfileHistory.cs，位于 %LOCALAPPDATA%\JoyPro2\ProfileHistory\<profile id>\（history.json，每种不同内容一个 gzip 数据块，drafts.json）。详情：profile-history。
  • 后退 / 前进：Services/NavigationHistory.cs、MainWindowViewModel.NavigationHistory.cs、Views/MainWindow.Navigation.cs（ui/navigation）。
  • 设备提示和替换设备：MainWindowViewModel.DeviceReplace.cs、Views/ReplaceDeviceWindow.axaml。
  • 更新：MainWindowViewModel.Updates.cs（updates）。
  • 帮助和导览：MainWindowViewModel.Help.cs、MainWindowViewModel.Tours.cs、Views/Controls/HelpLayer.axaml（ui/help-and-tours）。

每个 GUI 操作都会运行 engine.exe，并带上 --profile <file>、--status、--benchmark 以及 选项 中的加载修正选项（--load-corrections、--auto-add-db-items、--remap-missing-devices、--correction-mode、--correction-auto-threshold）。引擎：engine profile load、engine profile merge、engine profile save-last、engine profile summary、engine profile history、engine profile history show、engine profile history restore、engine profile history keep、engine profile history prune、engine devices replace、engine devices auto-remap。

#保留新设备的绑定

选项已撰写

工具提示 这些输入上旧设备的绑定保留在旧设备上

新设备在这些输入上保留它自己的绑定；旧设备对应的绑定留在旧设备上。

#用旧设备的绑定替换

选项已撰写

工具提示 这些输入上新设备的绑定会被移除（“撤销”可恢复）

新设备在这些输入上的绑定会被移除，由旧设备的绑定取而代之。

“撤销”可以把它们找回来。

#移动绑定

按钮已撰写

工具提示 按上面显示的方式移动绑定；“撤销”（顶部栏或通知）可恢复

“移动绑定”：先询问，在旁边保留配置文件的副本，然后按预览所示把旧设备的每个绑定和修饰键移到新设备，作为一项更改，并关闭窗口。

栏下方的通知会说明移动了多少个、哪些留在旧设备上；它的“撤销”可以撤回。
