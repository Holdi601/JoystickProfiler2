新手入门

#每款游戏一行

每一行都有游戏的封面、名称和状态：

  • 已勾选，带有文件夹：JoyPro 找到了该游戏（这一行会说明是怎么找到的：Steam、已知位置、Windows 应用列表）。
  • 未勾选：JoyPro 没有找到它。如果你没有这款游戏，这样没问题；它 不会 被隐藏，只要你一安装，JoyPro 就会找到它。

你可以做的事：

  1. 取消勾选已找到的游戏，如果你没有它或不关心它：它会在 JoyPro 的所有地方被隐藏（游戏卡片、导出卡片、监视器、游戏列表）。你为它做的绑定会保留在配置文件中。
  2. 安装在其他位置的游戏（便携版副本、另一个驱动器）：勾选它，然后按 安装 旁边的 浏览... 选择它的文件夹，或按 .exe... 选择游戏的程序或启动器。
  3. 控制设置保存在：有些游戏把控制设置保存在你的用户文件夹中。如果你的在别处，例如 Saved Games\DCS.openbeta 而不是 Saved Games\DCS，请按那里的 浏览...。
  4. 按 完成。以后再说 会关闭窗口，不做任何更改。
  5. 或者按 完成，并全部帮我设置好：JoyPro 会保存你的游戏并自动设置好你的摇杆。参见 快速入门。
提示

按 完成 后，JoyPro 会根据你自己的安装为你拥有的每款游戏生成命令列表。开始页面会显示进度，并为仍然缺少的列表显示通知。

高级

#详情

  • 链接的文件夹会根据游戏的标记文件（bin\DCS.exe、bin\game\Il-2.exe、X4.exe ...）进行检查：该行会显示“已找到标记”，或“未找到标记，但按你的选择保留该文件夹”。链接的文件夹在所有方面（导入、导出、命令列表）都被视为游戏安装位置，自动检测永远不会替换它。
  • 使用检测结果（安装位置或配置）会忘掉你的链接；JoyPro 会重新检测该游戏。
  • 我没有（在各处隐藏） 只为 JoyPro 没有找到的游戏提供：不选它时，游戏保持“未安装”，安装后会自动出现；选它时，游戏会像未勾选的已找到游戏一样被隐藏。
  • 把控制设置保存在安装目录中的游戏（IL-2、Falcon BMS、X-Plane ……）以只读方式显示其配置位置。
  • 隐藏的游戏列在 设置 > 游戏 的末尾，带有 再次显示。
技术细节

#窗口的内部原理

窗口 Views/GameSetupWindow.axaml（加上 .axaml.cs，用于文件夹选择器、完成和以后再说），视图模型 MainWindowViewModel.GameSetup.cs，行 Models/GameSetupItem.cs。当 ui-settings.json 中未设置 gameSetupDone 且启动时的检测（engine games installs）已返回结果时，该窗口会打开一次。完成 会对每个更改过的行运行 engine games install set（或 clear）、engine games config set（或 clear），然后为隐藏和显示的游戏运行一次 engine games install disable / enable，重新检测，把设置标记为完成，并启动 engine db check-updates 来生成缺少的命令列表。参考：游戏安装。
