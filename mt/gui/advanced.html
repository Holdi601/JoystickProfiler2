Paġni tal-GUI

Avvanzat

Uri:

Il-paġna Avvanzat hija l-console għall-esperti. Kull funzjoni li jeħtieġ utent normali għandha l-buttuna tagħha fil-paġni l-oħra; hawn tikteb il-kmandi tal-magna ta' JoyPro int stess, eżattament kif jiddeskrivihom il-command line tal-magna, u t-tweġiba tidher fil-pannell Output.

Għall-prinċipjanti

#Għandi bżonn din il-paġna?

Normalment le. Hija hemm għal tliet każi:

  • Xi ħadd (helper fuq Discord, il-wiki) jitolbok tħaddem kmand, pereżempju profile summary, biex tara x'qed jiġri.
  • Trid tibdel ħafna relazzjonijiet jew assenjazzjonijiet f'daqqa f'editur tat-test: Editja r-relazzjonijiet u Editja l-assenjazzjonijiet.
  • Trid ħarsa ġenerali malajr tal-profil miftuħ tiegħek: Qosor tal-profil.

#Ħaddem kmand

  1. Ikteb il-kmand f'Kmand mingħajr il-kelma engine, pereżempju profile summary jew relations list --game DCS.
  2. Ħalli Inkludi --profile immarkat: imbagħad il-kmand jaħdem fuq il-profil li għandek miftuħ.
  3. Agħfas Mexxi. It-tweġiba tidher fil-pannell Output isfel (agħfas Output fil-bar ta' isfel jekk ikun magħluq).
Attent

Il-kmandi miktuba hawn jistgħu jibdlu l-profil u l-logħob tiegħek eżattament bħalma jagħmlu l-buttuni. Kull bidla fil-profil hija verżjoni fl-Istorja (bar ta' fuq), għalhekk tista' tmur lura; il-fajls tal-logħob jiġu backed up qabel esportazzjoni.

Avvanzat

#Il-kaxxi

Kaxxa X'iżżid Għażla tal-magna
Kmand tal-editur Il-programm li jinfetaħ għal Editja r-relazzjonijiet / Editja l-assenjazzjonijiet (u għal relations edit / binds edit miktuba bl-idejn). {file} jieħu post il-fajl temporanju, eż. code --wait {file}. Vojt: Notepad. --editor (globali)
Fajl tal-output Jikteb it-tweġiba ta' kmand miktub bl-idejn f'dan il-fajl minflok fil-pannell Output. Biss għal kmandi miktuba hawn; il-buttuni tal-paġni l-oħra qatt ma jużawh. --out (globali)
Output tat-test Mixgħul (default): test li jinqara. Mitfi: JSON, kif jaqrawh l-iscripts. Biss għal kmandi miktuba hawn. --text (globali)
Args globali Kwalunkwe għażliet globali oħra mqiegħda qabel il-kmand, eż. --status true. l-għażliet globali
Kmand Il-kmand u l-għażliet tiegħu. Il-virgoletti jżommu path bi spazji flimkien. il-kmandi
Inkludi --profile Iżid --profile "<open profile>". Neħħilu l-marka għal kmandi li ma jeħtiġux profil (db summary, games installs). --profile
  • relations list u binds list miktuba hawn jaġġornaw ukoll il-listi tal-paġni Relazzjonijiet u Assenjazzjonijiet bit-tweġiba.
  • Il-linja tal-kmand tal-aħħar run hija l-ewwel linja tal-pannell Output ($ engine --profile ... profile summary): ikkopjaha biex tħaddem l-istess f'terminal.
  • Editja r-relazzjonijiet jikteb ir-relazzjonijiet kollha f'fajl JSON temporanju, jiftħu fl-editur tiegħek u jerġa' jaqrah meta l-editur jagħlaq; il-paġni Relazzjonijiet, Assenjazzjonijiet u Modifikaturi jerġgħu jitgħabbew. Pass wieħed ta' ħassar.
Dettalji tekniċi minn ġewwa

#Wara l-paġna

View model: MainWindowViewModel.cs (RunCustomCommandAsync, RelationsEditAsync, BindsEditAsync, RunEngineSummaryAsync, RunProfileSummaryAsync); l-argumenti jinbnew f'RunEngineAsync, l-istess metodu li tuża kull buttuna tal-GUI. Kmand miktub jinqasam minn TokenizeCli (il-virgoletti jiġu rispettati), l-args globali jmorru l-ewwel, imbagħad --profile, --status, --benchmark, --history-note (biss għall-bidliet tal-GUI stess), --out, --editor, l-għażliet tal-korrezzjoni tat-tagħbija tal-Issettjar u --text. Kmand li jibdel il-profil jaħdem bil-lock tal-profil u joħloq verżjoni fl-istorja bħal kull bidla oħra.

Magna: engine summary, engine profile summary, engine relations edit, engine binds edit, u kull kmand tal-linja tal-kmand tal-magna. Referenza: Parità bejn GUI u CLI (liema buttuna tħaddem liema kmand).

#Referenza

Id-dokumentazzjoni tal-funzjonijiet wara din il-paġna, iġġenerata mir-repository:

  • GUI / CLI parity EN
  • Game config backups EN

#Kull kontroll f'din il-paġna

7 kontrolli, moqrija mis-sors tal-programm: 7 miktuba, 0 bil-fatti mis-sors (tooltip, kumment fil-kodiċi, sejħa lill-magna), 0 għad iridu jiġu estiżi.

#Output tat-test

Kaxxa tal-markamiktub

Mixgħul: kmand miktub hawn iwieġeb b'test li jinqara faċilment.

Mitfi: iwieġeb b'JSON, kif jaqrawh il-GUI u l-iskripts.

Aktar dettalji (bl-Ingliż)

#Inkludi --profile

Kaxxa tal-markamiktub

Mixgħul: il-kmand miktub jieħu --profile "<open profile>", allura jaqra u jibdel il-profil li għandek miftuħ.

Neħħi s-sinjal għal kmandi li ma għandhomx bżonn profil.

Aktar dettalji (bl-Ingliż)

#Mexxi

Buttunamiktub

Iħaddem il-kmand miktub f'Kmand permezz tal-magna u juri t-tweġiba fil-pannell Output. relations list u binds list jaġġornaw ukoll il-paġni Relazzjonijiet u Assenjazzjonijiet.

Kmand li jibdel il-profil huwa pass wieħed ta' tħassir; kmand li jikteb f'logħba l-ewwel jagħmel backup tal-fajls tal-logħba, bħall-buttuni.

Aktar dettalji (bl-Ingliż)

#Editja r-relazzjonijiet

Buttunamiktub

Jiftaħ ir-relazzjonijiet kollha tal-profil bħala fajl JSON wieħed fl-editur tiegħek; meta tagħlaq l-editur, JoyPro jaqra l-fajl lura u l-paġni Relazzjonijiet, Assenjazzjonijiet u Modifikaturi jerġgħu jitgħabbew.

Pass wieħed ta' tħassir.

Aktar dettalji (bl-Ingliż)

#Editja l-assenjazzjonijiet

Buttunamiktub

Jiftaħ l-assenjazzjonijiet kollha tal-profil bħala fajl JSON wieħed fl-editur tiegħek; meta tagħlaq l-editur, JoyPro jaqrah lura u l-paġni jerġgħu jitgħabbew.

Pass wieħed ta' tħassir.

Aktar dettalji (bl-Ingliż)

#Qosor tal-magna

Buttunamiktub

Għadd f'linja waħda fil-pannell Output: relations=..., binds=..., modifiers=... tal-profil li l-magna għandha mgħobbi.

Ma jibdel xejn.

Aktar dettalji (bl-Ingliż)

#Qosor tal-profil

Buttunamiktub

Juri l-għadd u l-istat tal-profil miftuħ fil-pannell Output.

Ma jibdel xejn.
