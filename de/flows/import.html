Wichtigste Abläufe

Ein Spiel importieren

Zeigen:

Der Import liest die Steuerungseinstellungen, die ein Spiel gespeichert hat, und macht daraus ein JoyPro-Profil: eine Relation pro Funktion mit ihrer Taste oder Achse. Das ist der schnellste Start: Alles, was Sie in Ihren Spielen schon eingerichtet haben, kommt herein, und von da an hält JoyPro es an einem Ort.

Für Einsteiger

#Import mit drei Klicks

  1. Öffnen Sie Start (die erste Schaltfläche in der unteren Leiste). Unter Ihre Spiele hat jedes Spiel, das JoyPro auf Ihrem PC gefunden hat, eine Karte mit seinem Bild. Drücken Sie Importieren bei dem Spiel, das Sie am meisten spielen.
  2. JoyPro fragt, wie:
    • Zu meinem Profil hinzufügen (empfohlen) behält, was Sie haben, und fügt die Belegungen des Spiels hinzu.
    • Neu beginnen aus diesem Spiel ersetzt Ihre Relationen durch das, was das Spiel hat (JoyPro behält vorher eine Kopie Ihres Profils).
    • Auch die Tastaturbelegungen übernehmen holt auch Flugbefehle auf der Tastatur. Gerätebelegungen werden immer übernommen.
    • Für DCS: Alle meine DCS-Flugzeuge, oder nehmen Sie den Haken weg und wählen Sie Flugzeuge.
  3. Drücken Sie Jetzt importieren. Einen Moment später meldet die Karte „Fertig: Ihr Profil hat jetzt 214 Relationen (180 belegt)“, und Meine Relationen ansehen öffnet sie. Erst ansehen zeigt stattdessen, was das Spiel hat, ohne etwas zu ändern.

Kein Profil offen? JoyPro legt eines für Sie an und speichert es von da an automatisch (es gibt keine Schaltfläche Speichern: Jede Änderung wird gespeichert und lässt sich rückgängig machen, auch nach einem Neustart).

#Was ändert sich im Spiel?

Nichts. Der Import liest nur die Dateien des Spiels. Das Spiel behält seine Belegungen genau so, wie sie sind, ob Sie später exportieren oder nicht.

#Importieren und dann JoyPro die Lücken füllen lassen

Auf der Startseite listet die Karte „Ihre Geräte einrichten“ Spiele auf, in denen Sie selbst Belegungen gemacht haben. Importieren, dann Lücken füllen importiert ein solches Spiel zuerst. Danach legt Jetzt Lücken füllen... die wichtigen Funktionen auf die Tasten, die noch frei sind. Ihre eigenen Belegungen bleiben. Für Spiele, die schon in Ihrem Profil sind, bietet die Karte Lücken füllen... an.

#Vor Ihrem ersten Import: die Befehlsliste

JoyPro muss die Befehle jedes Spiels kennen (ihre Namen und IDs). Es baut diese Liste einmal aus Ihrer eigenen Installation. Fehlt eine Liste, zeigt die Startseite Liste erstellen (oder Alle fehlenden Listen erstellen); eine Spielkarte bietet nach einem Spiel-Update Aktualisieren an. Das dauert ein paar Sekunden bis ein paar Minuten (DCS liest jedes Modul).

Der Experten-Import (Seite Start, unter den Karten, und die Seite Erweitert) bietet jede Engine-Option pro Spiel mit Scannen (Vorschau), Importieren und Exportieren. Jede Wahl wird für den nächsten Import gemerkt.

#Namen, Gruppen und Modifikatoren kommen zurück

Eine Spieldatei enthält nur Gerät, Eingabe und vielleicht eine Kurve. Der Export von JoyPro legt seine eigenen Daten daneben, und ein Import liest sie zurück:

Spiel Daten von JoyPro Wiederhergestellt
DCS <aircraft>\joystick\<device>.jp, modifiers.lua Relationsname, Gruppen (in Reihenfolge), Modifikatoren mit Namen, Invertierung, Schieberegler, Totzone, Sättigung, Kurve
IL-2 Great Battles data\input\jp.actions Name, Gruppen, Alias, Modifikatoren, die genaue Abstimmung
Registry-Spiele (X-Plane, Elite, X4, Arma, MSFS, War Thunder, BMS ...) <config>.joypro-meta.json Name, Gruppen, Alias, Modifikatoren, Abstimmung
Star Citizen actionmaps.jp Namen

Der aktuelle Zustand des Spiels gewinnt: Eine Kurve, die Sie nach dem Export in DCS geändert haben, bleibt. Belegungen, die JoyPro nie exportiert hat, bekommen einen Namen aus der Aktion des Spiels und die Gruppen DCS, IL2 oder GENERATED + Spiel.

#Zwei Schutzfragen

  • Noch nicht exportierte Änderungen. Wenn Sie in JoyPro Belegungen geändert und noch nicht in dieses Spiel exportiert haben, würde ein Import die alten Belegungen zurückbringen. JoyPro fragt vorher.
  • Schon importiert? Wenn das Profil das Spiel schon hat, kommen Änderungen, die Sie später im Spiel machen, über die Spielüberwachung herein (sie fragt, nachdem das Spiel geschlossen wurde); ein erneuter Import bleibt ein Klick.
Im Spiel: Was der Import liest, je nach Art des Spiels

Der Import schreibt nie in einen Spielordner. Was er liest:

  • DCS: die Belegungen jedes Flugzeugs und Geräts, Ihre Modifikatoren und mit „Standards einbeziehen“ die Standardbelegungen, die DCS für jedes Gerät hat.
  • IL-2 Great Battles / Korea: das Key mapping und die Achsenkennlinien.
  • Star Citizen: die Keybindings des Zweigs (LIVE, PTU ...), mit den Joystick-Standards des Spiels auf js1.
  • Spiele mit Infanterie oder Fahrzeugen (War Thunder, Arma, Reforger, WARDOGS ...): nur die Flugaktionen; alles andere wird ignoriert, nicht gelöscht.
  • MSFS: die Eingabeprofile des Simulators (Steam oder die Version aus dem Microsoft Store) und auf Wunsch die Standard-Presets des Simulators.

Geräte, die das Spiel nicht unterscheiden kann (in manchen Spielen zwei Geräte desselben Modells), und Belegungen auf Achsenhälften (Elite) werden übersprungen und im Ergebnis genannt.

Technische Details

#Wie es im Inneren funktioniert

  1. GUI. StartImportWizard → RunImportWizardAsync (MainWindowViewModel.GameHub.cs). Es fragt AskAboutUnexportedChangesAsync (Engine sync pending), bestätigt Neu beginnen und behält eine Kopie des Profils (BackupProfileBeforeChange("before-import")), dann ruft es den Import des Spiels auf: ImportDcsAsync, ImportIl2Async, ImportStarCitizenAsync oder ImportRegistryGameAsync. Erst ansehen führt dasselbe mit scan aus (PreviewImportWizardAsync) und öffnet den Bereich Ausgabe.
  2. Engine. Für DCS: engine dcs import [--path <Saved Games\DCS>] --merge --include-defaults [--plane <a> --plane <b>] --include-keyboard true|false --ignore-easy-planes false --only-connected false --merge-same-name true. Der Importer liest jede Gerätedatei, ordnet das Gerät über seine DirectInput-Instanz-GUID und seinen Namen zu, ordnet jede Befehls-ID der Befehlsliste des Spiels zu (DB\<game> in %LOCALAPPDATA%\JoyPro2\GameData) und baut eine Relation pro Funktion und Eingabe. Korrekturen beim Laden (--load-corrections, --correction-mode) ordnen umbenannte Befehls-IDs mit einem Sicherheitswert neu zu.
  3. Profil. Die Relationen werden nach Name und nach gleicher Eingabe zusammengeführt; Modifikatoren werden aus modifiers.lua (DCS) oder den Shift-Einstellungen des Spiels angelegt. Das Profil wird atomar gespeichert, und jedes Speichern ist eine Version in <data>\ProfileHistory (Rückgängig funktioniert über Neustarts hinweg).
  4. Überwachung. Ein Import eines Spiels ohne Sync-Eintrag merkt sich die Dateien des Spiels, damit Änderungen, die Sie später im Spiel machen, bemerkt werden (<data>\Sync\<game>.json).

#Die Dateien, die er liest

Spiel Dateien
DCS Saved Games\DCS\Config\Input\<aircraft>\{joystick,keyboard}\*.diff.lua und modifiers.lua, dazu die sauberen Profile, die JoyPro aus Ihrer DCS-Installation gebaut hat
IL-2 Great Battles / Korea data\input\*.actions und die Achsen-Antworten
Star Citizen actionmaps.xml des Zweigs
MSFS der Steam-Remote-Ordner oder der Microsoft-Store-Speicherstand

Die Optionen der GUI als Engine-Optionen: Hinzufügen --merge, Tastatur --include-keyboard true, nicht angeschlossene Geräte --only-connected false, gleicher Name --merge-same-name true, Easy-Flugzeuge --ignore-easy-planes true. Die Schutzfrage für noch nicht exportierte Änderungen ist engine sync pending.

Engine-Befehle: engine dcs import, engine dcs scan, engine il2 import, engine starcitizen import und engine <game> import für jedes Registry-Spiel (zum Beispiel engine warthunder import, engine msfs2024 import). Regeln für den Re-Import: Re-Import. Tests: engine\tests\smoke\dcsincludedefaults.ps1, engine\tests\smoke\roundtrip.ps1, gui\JoyPro.Gui.Tests\ImportSettingsPersistTests.cs.
