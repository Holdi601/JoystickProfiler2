Wie mache ich

Ein reines Xbox-Spiel mit einem HOTAS spielen

Zeigen:

Manche Spiele kennen nur einen Xbox-Controller. ACE COMBAT 8 und Hell Let Loose: Vietnam sind solche Spiele. Sie sehen Ihren Stick überhaupt nicht. JoyPro macht aus Ihrem Stick, Schubhebel und Ihren Pedalen einen Ersatz-Controller (ein virtuelles Xbox-Pad). Das Spiel sieht einen Xbox-Controller und spielt damit.

Ihre Geräte
JoyPro
Das Spiel
Stick, Schubhebel, Pedale
Der Ersatz-Controller
(besteht, solange Start an ist)
ACE COMBAT 8 sieht einen Xbox-Controller
Für Einsteiger

#Einmal einrichten

  1. Alles für mich einrichten
    dann Diese Tasten verwenden
  2. Ersatz-Controller einrichten
    die zweite blaue Schaltfläche
  3. ViGEmBus installieren
    zuerst den Haken setzen
  4. Test
    Bewegen Sie Ihren Stick
  1. Drücken Sie auf der Seite Start Alles für mich einrichten. Die Antwort ACE COMBAT mit meinem Flugstick spielen in der Begrüßung führt Sie auch dorthin.
  2. Sehen Sie sich die Liste an. Drücken Sie Diese Tasten verwenden.
  3. Drücken Sie Ersatz-Controller einrichten. Das Einrichtungsfenster schließt sich. Die Seite Virtueller Joystick öffnet sich.
  4. Der Ersatz-Controller braucht ein kostenloses Hilfsprogramm: ViGEmBus. Setzen Sie den Haken unter der Lizenz. Drücken Sie dann ViGEmBus installieren. Windows fragt nach Erlaubnis: Klicken Sie auf Ja. Das machen Sie nur einmal.
  5. Drücken Sie Test. Bewegen Sie Ihren Stick. Das Controller-Bild bewegt sich mit. Drücken Sie eine Taste: Sie leuchtet auf.

Sie müssen nichts umstellen. JoyPro setzt diese Spiele von selbst auf den Ersatz-Controller. Die Seite sagt „Von selbst auf dem Xbox-Pad: Das Spiel liest nur Xbox-Controller“. Nichts wird ins Spiel geschrieben.

#Bei jedem Spielen

  1. Spiel starten
    auf den Titelbildschirm warten
  2. Alt+Tab
    zurück zu JoyPro
  3. Start
    der Ersatz-Controller ist an
  4. Alt+Tab
    zurück ins Spiel
  1. Starten Sie das Spiel. Warten Sie, bis es seinen Titelbildschirm zeigt.
  2. Halten Sie Alt gedrückt und drücken Sie Tab. Sie sind wieder in JoyPro.
  3. Drücken Sie Start.
  4. Drücken Sie wieder Alt+Tab. Sie sind wieder im Spiel. Guten Flug!
  5. Wenn Sie fertig sind, drücken Sie Stopp.
Start kommt nach dem Spiel

Drücken Sie Start erst, wenn das Spiel seinen Titelbildschirm zeigt. Zu früh? JoyPro meldet „Zu früh“. Drücken Sie Stopp, dann Start. Machen Sie das bei jedem Spielen.

#Was wohin kommt in ACE COMBAT 8

Auf Ihrem HOTAS Auf dem Ersatz-Controller Im Spiel
Stick nach vorn, hinten, links, rechts Linker Stick Nicken und Rollen
Schubhebel Vorn: RT. Hinten: LT. Beschleunigen und abbremsen
Stick-Drehung (oder die Pedale) LB und RB, ab etwa 30 % Gieren nach links und rechts
Ein freier Hat an Ihrem Stick Rechter Stick Umsehen
Ihre Flare-Taste L3 und R3 zusammen Flares (im Spiel noch nicht bestätigt)
Ihr Funkschalter oder KI-Menü-Hat Steuerkreuz Befehle an Flügelmänner
Eine Tasten-Relation namens „High-G“ Beide Trigger ganz durchgedrückt High-G-Kurve

Die Liste im Tab Live-Test sagt, was jede Taste macht, zum Beispiel „A: Fire machine gun“.

Flares sind noch nicht bestätigt

JoyPro drückt für Flares L3 und R3 zusammen. Bisher hat das niemand im Spiel bestätigt. Das sagt JoyPro auch.

#Etwas funktioniert nicht?

  • Das Spiel reagiert nicht. Wurde Start zu früh gedrückt? Drücken Sie Stopp, dann Start.
  • Die Nase geht in die falsche Richtung. Haben Sie im Spiel „Pitch Controls: Inverted“ eingestellt? Dann schalten Sie diese Webseite mit dem Schalter Zeigen: oben auf Erweitert.
  • Kein ViGEmBus. Ohne ViGEmBus kann das Spiel Ihren Stick nicht sehen. Installieren Sie es auf der Seite Virtueller Joystick.

Mehr zu den Spielen: ACE COMBAT, Hell Let Loose: Vietnam.

Erweitert

#Details

  • Kein HidHide für diese Spiele. Sie lesen nur Xbox-Controller und sehen Ihre echten Sticks daher nie. Nichts muss versteckt werden. HidHide ist nur für Spiele, die auf vJoy stehen.
  • Der Modus stellt sich selbst ein. Solange Sie keinen Modus gewählt haben, nutzen diese Spiele das Xbox-Pad. Wählen Sie auf der Seite Virtueller Joystick einen anderen Modus, und JoyPro behält Ihre Wahl.
  • Ihre Kurve kommt beim Pad an. Totzone, Sättigung, Kurve und Invertierung aus Achsenverhalten (Seite Belegungen) werden auf den Stick oder Trigger des Pads angewendet. Haken Sie unter Gilt für nur ACE COMBAT 8 an, wenn es eine eigene Kurve bekommen soll.
  • Nicken. Die Invertierung von DCS kommt nie beim Pad an. Standardmäßig senkt ein nach vorn gedrückter Stick die Nase. Mit „Pitch Controls: Inverted“ im Spiel entfernen Sie den Haken bei Invertieren nur für ACE COMBAT 8 (Achsenverhalten, Gilt für: ACE COMBAT 8).
  • Umsehen auf einem Hat. Liegt keine Achse auf den Umsehen-Aktionen, steuert ein freier Hat Ihres Sticks den rechten Stick. Eine Hat-Richtung hält den Stick ausgelenkt, solange Sie sie halten. Der Hat behält in anderen Spielen seine Aufgabe (Trimmung in DCS).
  • High-G-Kurve. Eine Tasten-Relation namens „High-G“ hält beide Trigger. Das tut auch die Relation mit DCS' ASC Direct Control (der „Cobra-Taste“ der Su-27, Su-33, J-11A). Der Schub auf den Triggern funktioniert weiter.
  • Mehrere Spiele auf dem Pad. ACE COMBAT 7 und 8 können es beide nutzen, jedes mit seiner eigenen Tabelle. Mit Autostart wird die Tabelle des laufenden Spiels aktiv. Sonst wählen Sie sie unter Xbox-Pad-Tabelle für „Start“ und „Test“.
  • Autostart erzeugt das Pad etwa 3 Sekunden nach dem Start des Spiels, noch vor seinem Titelbildschirm. Das kann für diese Spiele zu früh sein: Drücken Sie dann am Titelbildschirm Stopp und Start.
  • Fachleute. vJoy, HidHide, die Weiterleitungsrate und die Modi liegen unter Details für Fachleute zeigen (vJoy, HidHide, Modi).
  • ACE COMBAT 7 liest Sticks selbst. Es bekommt einen normalen Export seiner Input.ini (ACE COMBAT).
Technische Details

#Hinter dem Ersatz-Controller

  • Ein Spiel, das gar keinen Joystick liest, hat MaxJoysticks 0 und den vorgeschlagenen Modus xbox; ohne gespeicherte Wahl ist sein Modus xbox (VJoySettings.ModeOf). engine vjoy mode speichert eine Wahl.
  • Der Planer legt die Eingabe jeder Relation fest auf das Pad-Bedienelement, das das eigene Layout des Spiels verwendet (DB\<Game>\actions.tsv, 5. Spalte). Die eigenen Funktionen des Pads (geteilter Schub, Gier-Tasten, Flare-Tastenkombination, Steuerkreuz, High-G, Umsehen-Hat) kommen aus engine/VJoy/XboxPadAutoSetup.cs und werden bei jedem Plan neu erzeugt.
  • JoyPro.VJoy run --xbox-sink vigem erzeugt das Pad; Test nutzt --xbox-sink dry und ändert nichts.
  • engine vjoy pad-check meldet, was ein Profil auf dem Pad erreicht, mit einer Punktzahl. Referenz: Virtueller Joystick.
