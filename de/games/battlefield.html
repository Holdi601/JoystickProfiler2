Battlefield

Zeigen:

Battlefield 6 und Battlefield 2042 lesen einen Joystick, und ihre Belegungen nennen kein Gerät. Ein HOTAS aus mehreren Geräten funktioniert deshalb nur über den virtuellen Joystick von JoyPro: JoyPro legt jede Eingabe, die Ihre Battlefield-Relationen nutzen, auf ein vJoy-Gerät und versteckt die echten Geräte mit HidHide vor dem Spiel. Das Textprofil des Spiels enthält die Belegungen für Jets und Hubschrauber; JoyPro schreibt heute deren Tastaturtasten und liest die Joystick-Belegungen. Das Schreiben von Joystick-Belegungen wartet auf eine bestätigte Untersuchung der Joystick-Nummerierung des Spiels. Die älteren Battlefields sind nur dokumentiert.

Für Einsteiger

#In 3 Schritten zum Laufen bringen

  1. Alles für mich einrichten
    dann Diese Tasten verwenden
  2. Verwenden
    dann Start vor dem Spiel
  3. vJoy im Spiel belegen
    auf seiner Joystick-Seite
  1. Drücken Sie auf der Seite Start auf Alles für mich einrichten. Sehen Sie sich die Liste an. Drücken Sie Diese Tasten verwenden. JoyPro wählt die Tasten für Jets und Hubschrauber.
  2. Öffnen Sie die Seite Virtueller Joystick. Installieren Sie dort vJoy und HidHide, falls sie fehlen. Drücken Sie Verwenden neben Battlefield. Drücken Sie Start, bevor Sie das Spiel starten.
  3. Öffnen Sie im Spiel die Joystick-Seite. Klicken Sie in das Feld einer Zeile und drücken Sie dann Ihre Taste. Das Spiel sieht einen Joystick, „vJoy Device“.

JoyPro schreibt die Joystick-Belegungen von Battlefield noch nicht. Schritt 3 machen also Sie. Details unten.

#Was JoyPro für Battlefield tut

  • Ein Gerät für das Spiel: Im virtuellen Modus erscheinen Stick, Schubhebel und Pedale für Battlefield als ein vJoy-Joystick, dessen Eingaben sich nie verschieben. Jedes andere Programm sieht weiter Ihre echten Geräte.
  • Tastaturtasten: JoyPro liest und schreibt die Tastaturtasten der Tasten-Aktionen für Jets und Hubschrauber, wenn Sie die Tastatur wünschen.
  • Joystick-Belegungen: JoyPro liest sie (mit einer Warnung), schreibt sie aber noch nicht. Die Nummerierung der Joystick-Eingaben im Spiel ist nicht bestätigt; bis dahin belegen Sie das vJoy-Gerät selbst auf der Joystick-Seite des Spiels.

#Importieren

  1. Starten Sie das Spiel einmal, damit es sein Einstellungsprofil schreibt. Vorher listet JoyPro seine eigene Tabelle der Jet- und Hubschrauber-Aktionen; der erste Import ersetzt sie durch die Aktionen Ihres Profils.
  2. Öffnen Sie Start, drücken Sie Importieren auf der Karte von Battlefield 6 (oder 2042), setzen Sie den Haken bei Auch die Tastaturbelegungen übernehmen, wenn Sie sie möchten, und drücken Sie Jetzt importieren.

#Den virtuellen Joystick einrichten

  1. Öffnen Sie die Seite Virtueller Joystick. Installieren Sie unter Was diese Seite braucht vJoy und HidHide, falls sie fehlen.
  2. Stellen Sie unter Spiele Battlefield 6 auf vJoy um (JoyPro schlägt es dort mit Verwenden vor).
  3. Wenn die Seite vJoy für die Tabelle einrichten anbietet, drücken Sie darauf: JoyPro richtet das vJoy-Gerät ohne die Achsen Rx und Ry ein, weil Battlefield einen Joystick mit Rx / Ry für ein Xbox-Pad hält. Windows muss neu starten, bevor vJoy die Änderung übernimmt.
  4. Drücken Sie Start, bevor Sie das Spiel starten, und Stopp, wenn Sie fertig sind.

#Relationen bauen und prüfen

Belegen Sie auf der Seite Relationen Ihr HOTAS mit den Jet- und Hubschrauber-Aktionen von Battlefield (Ablauf Relationen): Nur Eingaben von Relationen mit einer Battlefield-Aktion bekommen einen Platz auf dem vJoy-Gerät. Jet und Hubschrauber sind verschiedene Fahrzeuge, also darf dieselbe Taste in jedem etwas anderes tun.

#Exportieren

  1. Schließen Sie das Spiel.
  2. Öffnen Sie Exportieren, lassen Sie Auf meinen Geräten ersetzen gewählt und drücken Sie Jetzt exportieren auf der Karte von Battlefield. Die Tastaturtasten werden geschrieben, wenn Sie beim Import die Tastatur angehakt haben (die Wahl wird pro Spiel gespeichert). Joystick-Belegungen werden als nicht geschrieben aufgeführt.
  3. Starten Sie das Spiel danach einmal und sehen Sie sich die Belegungen an: Steam Cloud und EA synchronisieren den Einstellungsordner, und eine Cloud-Kopie kann gewinnen.
Im Spiel: Was Sie in Battlefield sehen

Wenn der virtuelle Joystick läuft, ist der eine Joystick des Spiels „vJoy Device“. In Battlefield 6 stehen die Flugzeugzeilen unter dem Zahnrad-Symbol > CONTROLLER > EDIT SETTINGS > JOYSTICK > Aircraft EDIT („AIRCRAFT PILOT CONTROL MAPPING“): Jede Zeile zeigt UNBOUND oder die Belegung, zum Beispiel „AXIS 1 X -“. Tastaturtasten, die JoyPro geschrieben hat, erscheinen in den Tastaturbelegungen des Spiels.

#Was Sie in Battlefield selbst tun

  • Belegen Sie das vJoy-Gerät im Spiel auf der oben genannten Joystick-Seite: Klicken Sie in das Feld einer Zeile und bewegen Sie dann die Eingabe. Das Spiel belegt die erste Eingabe, die es sieht, deshalb sollte es nur vJoy sehen (virtueller Joystick läuft).
  • Schalten Sie Steam Input für das Spiel aus.
  • Wenn das Spiel Ihre echten Geräte trotzdem sieht (manche Spieler berichten, dass Battlefield 6 von HidHide versteckte Geräte sieht), stecken Sie sie beim Spielen ab; das vJoy-Gerät trägt alles.

#Häufige Stolperfallen

  • Die Joystick-Seite fehlt im Spiel: Der Joystick hat Rx- oder Ry-Achsen, und das Spiel hält ihn für ein Xbox-Pad. Richten Sie vJoy ohne sie ein (Schritt 3 oben) und starten Sie Windows neu.
  • Eine Zeile belegt eine zitternde Achse: Ein anderes Gerät ist für das Spiel noch sichtbar. Starten Sie den virtuellen Joystick vor dem Spiel, oder stecken Sie die echten Geräte ab.
  • Nur ein Gerät wurde exportiert: Das Spiel liest einen Joystick; JoyPro schreibt das Gerät mit den meisten Belegungen und listet die anderen auf („virtuellen Joystick verwenden“).

#Die Exportmodi in Battlefield

Nur Slots für Jet und Hubschrauber ändern sich. Slots für Soldaten und Bodenfahrzeuge, Slots für Maus und Pad, Tasten auf Achsen-Aktionen und Joystick-Codes, die JoyPros Tabelle nicht liest, ändern sich nie.

Modus Was passiert
Nur hinzufügen Eine Belegung, deren Eingabe eine andere Aktion desselben Fahrzeugs nutzt, wird übersprungen (markiert mit „Nicht ins Spiel geschrieben“); kein Slot wird freigegeben.
Aktualisieren, Belegungen des Spiels behalten Der Slot der anderen Aktion auf der Eingabe des Profils wird freigegeben; die belegten Slots der Aktion bleiben. Eine Belegung, die keinen freien Slot findet, bleibt draußen.
Aktualisieren, mein Profil gewinnt Wie oben, und die anderen Slots der Aktion (Tasten mit der Tastatur-Option) werden freigegeben; ein belegter Slot übernimmt die Eingabe des Profils.
Auf meinen Geräten ersetzen Die Flug-Slots dessen, was der Export schreibt, werden freigegeben: die Tastaturtasten, wenn Tasten exportiert werden (der Joystick, sobald Joystick-Belegungen geschrieben werden).
+ Auch meine anderen Geräte leeren Kein anderes Gerät zu leeren: Das Spiel liest einen Joystick.

#Was nie angefasst wird

  • Belegungen für Infanterie, Bodenfahrzeuge, Transport und Schützen; Slots für Maus und Pad.
  • Tastaturtasten auf Achsen-Aktionen (diese Paare verwaltet das Spiel) und Tastaturtasten ohne die Tastatur-Option.
  • Joystick-Slots, bis die Nummerierung bestätigt ist.
  • HidHide versteckt Ihre echten Geräte nur vor der Programmdatei des Spiels und nur, solange der virtuelle Joystick läuft; Stopp gibt HidHide genau seine vorherige Einstellung zurück.

#Achsen und andere Einstellungen

  • Pro Fahrzeugklasse: Jet und Hubschrauber sind getrennte Kategorien im Profil des Spiels; JoyPro schreibt beide.
  • Invertieren ist alles: Eine Achse wird als zwei Hälften geschrieben, und Invertieren tauscht sie. Keine Kurven oder Totzonen, keine Modifikatoren.
  • Hats: nur vier Richtungen, Diagonalen werden übersprungen. Spieler sehen etwa 18 Tasten; mehr ist nicht bestätigt.
  • Überwachung: Die Profildateien werden nach dem Beenden des Spiels überwacht (die Spielüberwachung).
  • HUD: Während das Spiel läuft, nennt das HUD die Aktion jeder gedrückten Taste.
  • Virtuelle Funktionen (Umschalter, Achsenbereiche, kurzer / langer Druck ...) funktionieren auf dem vJoy-Gerät für Battlefield.

Technische Details

#Im Inneren der Battlefield-Anbindung

Code: engine\Games\BattlefieldIntegration.cs (eine Klasse für Battlefield 6 und 2042); der vJoy-Planer, die Weiterleitung und die HidHide-Sitzung aus virtual-joystick.

  • Belegungszeilen: type 0 Maus, 1 Pad, 2 Tastatur (button = DIK-Scancode, 255 = keiner), 3 Joystick; „nichts belegt“ ist Achse 56 (Battlefield 6) oder 27 (2042) und Taste 60. negate 1 = der Slot steuert die Aktion in negativer Richtung. Das Standardprofil hat zwei leere Joystick-Slots pro Achsen-Aktion (negate 0 und 1); eine Tasten-Aktion bekommt Slot n+1 mit ihren vier Zeilen an ihrer sortierten Stelle.
  • Geräte: Die Belegungen nennen kein Gerät; JoyPro schreibt einen Joystick. Das Spiel meldet sich als Ein-Geräte-Spiel (1 Joystick, vorgeschlagener Modus virtual, vJoy-Achsen Rx und Ry vermieden). Deshalb gibt der Planer keiner Eingabe Rx / Ry, und engine vjoy configure-vjoy richtet das Gerät ohne sie ein.
  • Joystick-Nummerierung: eine vorläufige Tabelle aus dem entschlüsselten Schema von Battlefield 4 (X / Y als Axis1X / Axis1Y, Z / Rx / Ry / Rz als Halbachsen-Tastencodes 36-43, Taste n als Code n-1, Hat n als 44 + 4(n-1) + Richtung). Der eigene Standard des Spiels passt nicht dazu. Ohne bestätigte Tabelle liest JoyPro Joystick-Belegungen deshalb mit einer Warnung und schreibt keine. Die Live-Erhebung tools\e2e\games\BattlefieldJoystickSurvey.ps1 erzeugt die bestätigte Tabelle <engine>\TOOLS\Conversions\Battlefield6JoystickMap.tsv (Battlefield2042JoystickMap.tsv).
  • Befehle: engine bf6 paths, engine bf6 catalog, engine bf6 scan, engine bf6 import, engine bf6 export --include-keyboard --mode clean|add|merge|merge-overwrite --dry-run, engine bf6 refresh-db; dasselbe unter engine bf2042 export und seinen Geschwistern. Virtueller Modus: engine vjoy mode Battlefield6 virtual, engine vjoy map, engine vjoy apply-hidhide.

#Bekannte Grenzen

  • Joystick-Belegungen werden erst geschrieben, wenn die Erhebung die Nummerierung bestätigt.
  • Battlefield 2042 ist nach demselben Format umgesetzt, ohne installiertes Spiel.
  • Tasten über etwa 18 und ob eine halbe Achse als ganze Achse gespeichert wird, sind noch nicht bestätigt.
  • Tests: engine\tests\smoke\battlefield.ps1; die Erhebungsskripte tools\e2e\games\BattlefieldJoystickSurvey.ps1, BattlefieldSurveyAuto.ps1, BattlefieldAdminSession.ps1 (brauchen für die vJoy-Einrichtung ein Zeitfenster für einen Windows-Neustart).
