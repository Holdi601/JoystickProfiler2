IL-2 Sturmovik: Great Battles

Zeigen:

IL-2 Great Battles hat eine Tastenzuordnung für alle Flugzeuge, in Textdateien innerhalb der Spielinstallation (data\input). JoyPro liest diese Tastenzuordnung in Ihr Profil, lässt Sie ihre Aktionen in Relationen mit Ihren anderen Spielen verbinden („Fahrwerk“ in IL-2 und in DCS auf derselben Taste) und schreibt sie zurück. Das Spiel kompiliert die Dateien beim Start, deshalb läuft nichts von JoyPro, während Sie fliegen.

Für Einsteiger

#In 3 Schritten zum Laufen bringen

  1. Alles für mich einrichten
    auf der Seite Start
  2. Diese Tasten verwenden
    zuerst die Liste ansehen
  3. In mein Spiel schreiben
    IL-2 geschlossen lassen

Vorher: Lassen Sie IL-2 seine Tastenzuordnung einmal schreiben. Öffnen Sie Settings > Key mapping und drücken Sie ACCEPT. Schließen Sie IL-2.

Dann: Ihre Belegungen stehen unter Settings > Key mapping, in jedem IL-2-Flugzeug.

Haben Sie in IL-2 schon Tasten belegt? Dann bietet die Seite Start Importieren, dann Lücken füllen an. Ihre Belegungen bleiben, und nur freie Tasten bekommen neue Aufgaben. Siehe Schnellstart: meinen Stick zum Laufen bringen.

#Umsehen ohne Headtracking

Kein TrackIR, kein VR? Die Einrichtung legt die Sprung-Ansichten auf einen Hat Ihres Sticks: vorn, hinten, links und rechts. Die Blickachsen kommen auf den Mini-Stick Ihres Schubhebels, wenn er einen hat. Siehe Headtracking und Umsehen.

#Was JoyPro für IL-2 Great Battles tut

  • Importieren: Jede Aktion der Tastenzuordnung, die auf einem Stick, Schubhebel, Pedalen oder Panel liegt, kommt in Ihr Profil, mit Modifikatoren, dem Invertieren der Achse und den Zeilen der Achsenkennlinie. Tastaturtasten kommen mit, wenn Sie sie wünschen.
  • Relationen: Eine Relation ist eine Funktion in allen Ihren Spielen. IL-2 hat eine Tastenzuordnung für jedes Flugzeug, also wirkt die IL-2-Aktion einer Relation in jedem IL-2-Flugzeug.
  • Exportieren: JoyPro schreibt die Dateien der Tastenzuordnung in den Ordner data\input des Spiels. IL-2 zeigt Ihre Belegungen unter Settings > Key mapping.

#Ihre IL-2-Belegungen importieren

  1. Öffnen Sie Start. Die Karte von IL-2 Great Battles zeigt das Bild des Spiels. Wenn sie nach einer Befehlsliste fragt, drücken Sie Liste erstellen: JoyPro liest die Dateien der Tastenzuordnung, die Ihr IL-2 geschrieben hat.
  2. Drücken Sie Importieren auf der Karte. Wählen Sie Zu meinem Profil hinzufügen (oder Neu beginnen aus diesem Spiel) und setzen Sie den Haken bei Auch die Tastaturbelegungen übernehmen, wenn Sie Ihre Flugtasten auch haben möchten.
  3. Drücken Sie Jetzt importieren. Meine Relationen ansehen öffnet, was hereingekommen ist.

#Relationen bauen und prüfen

Auf der Seite Relationen steht jede IL-2-Aktion einer Relation neben derselben Funktion in Ihren anderen Spielen. Verbinden Sie sie mit dem Ablauf Relationen und drücken Sie dann Jetzt prüfen auf der Seite Export: Es findet eine Taste, die in IL-2 zwei Dinge tut, bevor das Spiel es tut (die Prüfung).

#Nach IL-2 exportieren

  1. Schließen Sie IL-2. JoyPro verweigert das Schreiben, solange Il-2.exe läuft.
  2. Öffnen Sie Exportieren. Die IL-2-Karte zeigt, wie viele ihrer Relationen belegt sind.
  3. Lassen Sie Auf meinen Geräten ersetzen mit Auch meine anderen Geräte leeren gewählt, wenn Sie Ihre Sticks in JoyPro einrichten. Drücken Sie Jetzt exportieren auf der IL-2-Karte.
Im Spiel: Was Sie in IL-2 sehen

Starten Sie IL-2 und öffnen Sie Settings > Key mapping. Ihre Belegungen stehen in den Aktionszeilen jedes Tabs (zum Beispiel Plane controls), auf Ihren Geräten. Die Achsenkennlinien, die JoyPro geschrieben hat, nutzt das Spiel ab diesem Start. Die Werte für Force Feedback und Rauschfilter, die JoyPro gesetzt hat, erscheinen unter Settings > Input devices.

#Was Sie in IL-2 selbst tun

  • Lassen Sie IL-2 seine Tastenzuordnung einmal schreiben. Wenn data\input noch keine global.actions hat, öffnen Sie Settings > Key mapping und drücken Sie ACCEPT. Ohne diese Datei gibt es nichts zu importieren, und die Befehlsliste enthält nur die Aktionen, die das Spiel geschrieben hat.
  • Für Force-Feedback- und Rauschfilter-Werte: Öffnen Sie einmal Settings > Input devices und drücken Sie ACCEPT, damit das Spiel seine Datei current.devices anlegt. JoyPro ändert diese Datei, legt sie aber nicht an.
  • Für das eigene Force Feedback von JoyPro aus der Telemetrie des Spiels trägt die Seite Force Feedback die Adresse von JoyPro in die startup.cfg des Spiels ein (schließen Sie vorher IL-2). Schalten Sie dann das eigene Force Feedback von IL-2 für diesen Stick aus.

#Häufige Stolperfallen

  • „IL-2 läuft“: Schließen Sie das Spiel vollständig und exportieren Sie erneut.
  • Belegungen auf dem falschen Gerät: IL-2 unterscheidet Geräte an der Nummer in devices.txt. Ein Gerät, das JoyPro schreibt, behält seine Nummer; ein neues Gerät bekommt die niedrigste freie. Nummerieren Sie Geräte zwischen Export und Import im Spiel nicht um.
  • Eine Belegung fehlt nach „Nur hinzufügen“: Die Taste war in IL-2 für eine andere Aktion belegt. Die Prüfung listet sie unter „Nicht ins Spiel geschrieben“; exportieren Sie mit Aktualisieren oder verschieben Sie die Belegung.
  • Die Force-Feedback-Werte haben sich nicht geändert: Das Spiel hat noch keine current.devices (siehe oben).
Erweitert

#Dateien, die JoyPro liest und schreibt

Datei Was es ist
<install>\data\input\global.actions das Key mapping: eine Zeile pro Aktion, `action, input, invert
<install>\data\input\devices.txt die Geräteliste: Nummer, DirectInput-GUID und Name jedes Joysticks
<install>\data\input\current.responses Kennlinien-Zeilen pro Aktion (mittig, einseitig), für alle Flugzeuge
<install>\data\input\global.pitch die Nick-Zeile mit einer Mittenverschiebung (nur angelegt, wenn Sie eine einstellen)
<install>\data\input\jp.actions JoyPros Kopie mit Relationsnamen, Gruppen, Modifikatoren und Tuning, beim nächsten Import zurückgelesen
<install>\data\input\current.devices Settings > Input devices: Force Feedback und der Rauschfilter für Joysticks (direkt in der Datei geändert)
<install>\data\startup.cfg Force-Feedback-Werte und JoyPros Telemetrie-Adresse

current.map kompiliert IL-2 bei jedem Start aus diesen Dateien; JoyPro schreibt sie nie.

#Die Exportmodi in IL-2

Modus Was in IL-2 passiert
Nur hinzufügen Nichts wird entfernt. Eine Belegung, deren Eingabe IL-2 schon für eine andere Aktion nutzt, wird nicht geschrieben und bekommt die Markierung „Nicht ins Spiel geschrieben“.
Aktualisieren, Belegungen des Spiels behalten Ihre Belegungen kommen hinein; die anderen Belegungen von IL-2 bleiben, außer einer Belegung einer anderen Aktion auf einer Eingabe, die Sie nutzen.
Aktualisieren, mein Profil gewinnt Wie oben, und jede Aktion, die Sie belegen, verliert ihre anderen Eingaben (Joysticks; die Tastatur nur mit der Tastatur-Option).
Auf meinen Geräten ersetzen Die Joysticks, die Sie schreiben, behalten nur Ihre Belegungen.
+ Auch meine anderen Geräte leeren Angeschlossene Joysticks ohne Belegung in Ihrem Profil verlieren ihre Belegungen.

global.actions behält die Reihenfolge des Spiels; neue Zeilen kommen ans Ende.

#Was nie angefasst wird

  • Zeilen eines nicht angeschlossenen Joysticks, die beim Import ignorierten Geräte und das vJoy-Gerät, in das JoyPro weiterleitet.
  • Mauszeilen (auch Mauseingaben mit Tastaturtasten), TrackIR und Zeilen mit einer Eingabe, die JoyPro nicht lesen kann.
  • Die Tastatur, außer Sie exportieren Tastaturbelegungen.
  • current.map und die anderen Dateien des Spiels.

#Flugzeuge, Kurven, Force Feedback

  • Granularität: global. Ein Key mapping und eine Kennlinien-Zeile pro Aktion gelten für jedes Flugzeug.
  • Achsenkurven (Achsenmodell il2): Totzone in der Mitte, Totzone am Rand und die Kurve („sensitivity balance“) für mittige Achsen; untere und obere Totzone für einseitige Achsen wie den Schubhebel; eine Mittenverschiebung für Nicken. Die Standardkurve wird an das Modell von IL-2 angenähert; Sie können auch eine nur für IL-2 einstellen oder für die IL-2-Familie (Great Battles und Korea lesen gegenseitig ihre Werte). Invertieren wird in die Zeile der Aktion geschrieben.
  • Spieleinstellungen (Einstellungen > Force-Feedback-Einstellungen der Spiele): Rauschfilter für Joysticks, Force Feedback an, Feedback-Stärke und Rütteln. Ein Export ohne Belegungen für IL-2 schreibt sie trotzdem.
  • Telemetrie-Force-Feedback: JoyPros eigene Effekte aus der Telemetrie-Ausgabe des Spiels (Force Feedback). Dieselbe Ausgabe speist die Telemetrie-Aufzeichnung (CSV; die Telemetrie hat keine Weltposition, also kein Tacview-Track).
  • HUD: zeigt die IL-2-Belegungen der gedrückten Tasten, während IL-2 läuft (HUD).
  • Überwachung: Eine Belegung, die Sie im Key mapping ändern, wird nach dem Beenden von IL-2 bemerkt; JoyPro fragt, ob sie übernommen werden soll (die Spielüberwachung).
Technische Details

#Im Inneren der IL-2-Anbindung

Code: engine\EngineIl2.cs (Import, Export, Dateien), engine\EngineIl2DbRefresh.cs (Befehlsliste), engine\AxisModels (Modell il2), engine\EngineFfbTelemetry.cs (Telemetrie-Einrichtung).

  • Eingaben: joy<N>_b<button, 0-based>, joy<N>_axis_<x|y|z|...>, joy<N>_pov<hat>_<angle>, Tastaturtasten über ihren DirectInput-Namen, Achsenpaare als <input>/<input>, Modifikatoren als <modifier>+<input>. IL-2 zählt Hats ab 0, JoyPro ab 1 (JOY_BTN_POV1_* ist pov0).
  • Geräte: devices.txt listet <number>,"<GUID>",<name>|; IL-2 schreibt die letzten 8 Bytes der DirectInput-Instanz-GUID umgekehrt als eine Gruppe. Jeder Modus behält die schon eingetragenen Nummern.
  • Befehlsliste: engine db refresh-il2 liest die *.actions-Dateien, die das Spiel schreibt (nicht jp.actions); die Tabs des Spiels (Service, Camera controls, Plane controls, Weapons controls ...) sind die Kategorien. Das Spiel schreibt nur Aktionen, die eine Eingabe haben, deshalb enthält die Liste einer frischen Installation etwa 376 Aktionen.
  • Import / Export: engine il2 import, engine il2 scan, engine il2 export (--mode clean|add|merge|merge-overwrite --nuke-untouched-devices true|false --ignore-device <d>). Sicherungen: jede Datei nach <file>.jpbak und in den Sicherungsspeicher vor dem ersten Schreiben.
  • Einstellungen und Kurven: engine ffb set --device * --game IL2Game, engine binds tuning set --scope game:IL2Game oder family:il2, engine binds tuning preview.
  • Telemetrie: engine ffb telemetry setup il2 fügt dem Abschnitt telemetrydevice von startup.cfg eine Adresszeile 127.0.0.1:41994 hinzu und ändert nie die Adressen anderer Programme; --remove stellt die Datei byte-genau wieder her.
  • Überwachung: engine sync status, engine sync diff (überwacht: global.actions, devices.txt, current.responses, current.devices, startup.cfg).

#Bekannte Grenzen

  • Aktionen ohne Eingabe in den Dateien des Spiels stehen nicht in einer frisch erstellten Befehlsliste.
  • Das eigene Force Feedback des Spiels muss für einen Stick aus sein, der JoyPros Telemetrie-Force-Feedback bekommt.
  • Tests: engine\tests\smoke\il2.ps1; im Spiel tools\e2e\games\IL2Game.ps1 (Belegungen, 38 von 38 Schritten) und IL2GameCurves.ps1 (vom Spiel kompilierte Kennlinien gegen JoyPros Vorschau).
