Settings

Show:

The Settings page holds every setting of JoyPro in 22 sections that open and close. A search box finds a setting by a word ("tray", "update", "photos"), the tabs at the top jump to a section, and you can put the sections in your own order. Every setting is kept at once and survives a restart; there is no Save button.

For beginners

#How the page works

  • Open a section: click its title. Open all / Close all at the top right open or close every section; the small arrow next to them puts JoyPro's order back with only Games open.
  • Find a setting: type a word into Search the settings. Only the sections with a matching setting stay, and they open. The x clears the search.
  • Your order: drag a section by its handle (or a tab at the top) to move it. JoyPro remembers which sections are open and their order.
  • Settings take effect at once. A few say "at the next start" next to them.

The first start opens Games only; everything else is a click away. Most people only ever need Games, Appearance, Language and About JoyPro and updates.

#The sections

#Games

One card per game JoyPro supports and you have, with its cover, "Installed" or "Not installed", where it is and where it keeps its controls.

  • Run setup again opens the first-start window again: tick the games you have, link folders, set config locations. Detect again looks for the games once more (after you installed or moved one).
  • Watch game configs: when you change controls JoyPro manages inside a game, JoyPro asks after the game closed whether to take the change into your profile (the game watcher).
  • vJoy device JoyPro tunnels into: None (default) treats every vJoy device as a normal device, for example one VoiceAttack drives. A number tells JoyPro that this vJoy device carries JoyPro's own output (Virtual Joystick): imports leave it out and exports never clear it.
  • War Thunder: read the full command list from the game's archives: on (default), JoyPro unpacks the game's gui.vromfs.bin and lang.vromfs.bin read-only for every aircraft and helicopter action. Off: only JoyPro's own list of the War Thunder actions it knows.
  • Hell Let Loose: Vietnam: use the Oodle library of another installed game: the game's files are compressed and it ships no library to read them. With your yes JoyPro uses the one another game on this PC has, where it is. Off: JoyPro's own list of the gamepad keys, which is all the Xbox pad mode needs. Ask again forgets your answer.
  • Per card: Choose folder... / Choose .exe... link the game's folder (a portable install, another drive); Use detected forgets the link; Hide hides a game you do not have everywhere in JoyPro (your binds for it stay). Hidden games are listed at the end with Show again.
In the game: Linked folders and hidden games

Nothing changes in a game here. A linked folder decides where import and export read and write; a hidden game gets no export tile and is not watched.

#Binds

  • Follow input on the Binds and Relations pages: press a button (or move an axis a long way) and the page jumps to its relation; press it again for the next relation on it. Not while recording or typing.
  • Show the note over the list when follow input jumps ("BTN 8 on WarBRD: Gear (1/3)"), off by default.
  • Record: also take a button that rests pressed when it is released: a 3-way switch's middle position or a mode switch is pressed all the time; ticked, letting it go during recording counts as that button.

#Startup

Open the last profile at start (on by default) opens the profile you had open last; the path is shown below. The note explains the profile history: every change is saved by itself and every save is a version in History (top bar). Old versions are thinned out: all of the last day, then one per hour for 7 days, one per day for 60 days, one per week after that; at most 200 MB per profile and 1 GB for all. Versions you keep stay.

#Pages in the bottom bar

One row per page of the bottom bar. Untick a page you do not use; drag a row by its handle (or use the arrows) to change the order. A hidden page still opens from other pages (for example Open the Modifiers page) and shows in the bar while it is open. Settings cannot be hidden. Reset to default brings JoyPro's order back with every page shown.

#Language

Language of JoyPro: English and 38 other languages, or Windows language (the display language of Windows, or English when JoyPro does not have it). The translations are made by a machine and may sound odd; game command names stay as the game names them. The tray helper's menu follows the language.

#Appearance

  • Colours: Light, Dark or System (follows Windows), and your own themes with Use and Edit.
  • Text size (Ctrl+Plus, Ctrl+Minus, Ctrl+0) and UI scale (the whole window: texts, buttons, pictures, spacing), both on top of Windows' display scaling; Reset next to each.
  • Theme editor: your own colours and fonts: New theme from Light / New theme from Dark start a theme; Import... loads a theme file someone shared. Then name it, pick fonts, line spacing, heading size and every colour, with a live preview of a small JoyPro page and a contrast check ("Some texts are hard to read" with Fix the contrast). Use this theme, Save, Duplicate, Export..., Reset colours and Delete are below the colours.

#Run in the background (system tray)

JoyPro can only notice that you changed controls in a game while it runs. A tiny helper keeps watching as an icon in the system tray after you closed JoyPro; it uses no noticeable CPU and a few MB of memory.

  • Start with Windows (in the tray): the helper starts when you sign in; JoyPro's window does not open. No administrator rights needed.
  • Close to tray: closing JoyPro (X) leaves the helper watching. Off: closing JoyPro ends the watching too.
  • Tray icon: click to open JoyPro (or to review a game's changes); right-click for "Watching game configs" on or off and "Exit".

#Confirmations

JoyPro asks before a change that is hard to take back. The questions you can switch off are listed here: removing an action from a relation, an import that drops changes you did not export yet, the first export to a game the profile never imported from, an export that removes binds, and the watcher hint in the import. A question you switched off with "Do not ask again" shows here unticked; Ask everything again turns them all back on.

#About JoyPro and updates

The version, the build and the licence line, Project page and Release page, the third-party notices, and the updates: Check for updates, Install update (downloads the new version, checks it, installs it and restarts JoyPro), Check for updates at start, and Offer it again for a version you skipped. "Where updates come from (for experts)" names the GitHub repository whose releases JoyPro installs.

#Privacy

JoyPro has no account and no telemetry. It goes online only for update checks, makers' product photos (after you said yes), game covers missing on this PC, the optional AI model download, optional drivers and a missing .NET Framework.

  • Makers' product photos: Ask for each device (default), Always download, Never (only JoyPro's drawings). Ask again for every device forgets your per-device answers.
  • Download reference photos automatically: a device's reference photos are fetched in the background when it appears (from the original address, or the web archive), checked and kept in your data folder. Off: JoyPro offers them and waits for your click.
  • Pictures from JoyPro's releases (cockpits, 3D device views): Ask, Always download or Never. Used by the Cockpits page and the 3D device views of the Layout page.
  • Game covers from the internet: covers Steam has no picture of on this PC are downloaded once. Takes effect at the next start.

#Usage statistics

JoyPro notes which games, aircraft and ships you use, from the games' own logs and Steam's playtime, and keeps a summary on this PC.

  • Show the Statistics page in the bottom bar (off by default): the Statistics page.
  • Lay out new aircraft like my most used one: Auto Assign, Auto Group, the Setup wizard and Lay out with AI give an aircraft you have not flown yet the layout of your most used aircraft of its class (jets, helicopters, spaceships).
  • Read the games' logs now reads what your games logged since the last time.
  • The ranking "Most used aircraft, ships and vehicles" and "Most used games": Pin makes an aircraft the model for its class; Exclude leaves it out of the ranking.

#Telemetry recording

Records every round, mission or flight with all the telemetry the game sends (position, attitude, speeds, controls, engines, weapons, events), like Tacview does for DCS, for every game JoyPro reads telemetry of.

  • Record the telemetry of my games (off by default), the Folder (Choose..., Default folder, Open folder), Values per second, Space for recordings (the oldest go first), Delete recordings after, and Also keep the raw data as the game sent it (about twice the size).
  • Games: tick the games to record.
  • Recorded sessions: date, game, aircraft, length and size, a small timeline of the selected one, Show in folder, Export for Tacview (ACMI), Export CSV and Delete.

#Drawings

How JoyPro draws your devices on the Layout page and the device cards (lines or cel-shaded, JoyPro's colours or your own), separately for the screen and for cheat sheets and exports. Reset all my layout changes... puts every device's picture back to JoyPro's default (your marker positions, tables and lines, renamed parts, photos, own device definitions and the layout files the profile uses; the files themselves stay); Undo reset right after brings them back. One device alone: the Layout page, its Model... menu. The drawing controls are explained on Layout.

#Report a problem

  1. Write what happened into What happened?
  2. Create Report: JoyPro shows what goes in, then saves one zip with your text and what is needed to find the problem (JoyPro's logs of at least the last 14 days, errors and crash reports, settings and versions, your devices, per game its folders and JoyPro's backups; with Include my open profile and its history also your profile, its history and the games' current bind files) and shows it in Explorer. Your user name, e-mail addresses and passwords are removed.
  3. Attach the zip to a GitHub issue (Open GitHub Issue Page) or send it to the developer. Nothing is sent by itself.

Keep background logs for n days (default 30; at most 200 MB together) and Open Log Folder are below.

#Local AI

Optional. JoyPro's offline rules always work; a free open-source language model can additionally read free sentences in Manage with AI, Edit with AI, the JoyPro assistant and Group by description, and JoyPro checks every answer. It runs on this PC only while you use it.

  • Use the local AI model, its status (loaded, ready, off, problem), Start now, Stop now, Stop after n idle minutes, Refresh.
  • Download a model: the model and runtime (auto, cpu, vulkan, cuda), its size and licences, I accept the size and the licenses above, Download and switch on, Cancel download, Remove model.
  • Already have llama.cpp and a GGUF model?: the paths to llama-server.exe and the .gguf file, Find on this PC, Use these files, Stop using them.

#Components

  • Needed by JoyPro: the .NET Framework and the engine's files, with Check Again and Install Missing.
  • Optional: one card per free program that is not part of JoyPro: vJoy (virtual joystick), HidHide (hides real devices from games), ViGEmBus (virtual Xbox pad), BYOJoystick for VTOL VR, and the local AI model. Each card says what it is for, its state, Project page, Windows apps (repair or uninstall), its licence, the tick "I have read..." and Install. JoyPro downloads the official installer only after your tick, checks it and runs it; Windows asks once for administrator rights. Force feedback needs no extra program.

#Devices

Look again shows a card per connected stick, throttle and pedals and per device your profile uses: its picture (click it to open the device on the Layout page), name, connected or not, and how many binds it has.

  • Device names: show the alias you gave on the Layout page, or the device's real name.
  • Use its axes for follow input and recording: for analog keyboards, whose keys also report as axes.
  • Replace... gives a device's binds to another device, input by input, with a preview (a new stick, a profile from an old PC); Move binds there asks first and keeps a copy of the profile. Remove takes a sold device's binds out of the profile; it asks first and keeps a copy of the profile too.
  • "Device lists and names (for experts)": List Devices, Input Catalog, Device Details, and the old Exchange Device / Remove Device Refs by typed names.

#Command lists (DB) and game paths: information for experts

Read-only answers in the Output panel about what JoyPro knows of each game: DB Summary, DB Check, DB List, DB Games, DB Planes, DB Fingerprint, Game Paths, Games List, Games Detect, with filters for a game and an aircraft. To read a game's new commands after an update, use Update on the game's card on the Start page.

#DCS: default binds

DCS puts its own default binds on every device. JoyPro's DCS export already removes them from every device it writes, in every aircraft. The two options here change the DCS installation itself, for all devices; both are off unless you switch them on.

  • Strip DCS default binds in the DCS install: every joystick input file of DCS gets its default binds switched off; each original is kept as <file>.nocombo.bak. Keep the UI layer's default binds (menus, VR) leaves the UI layer as it is.
  • Remove DCS's device-specific default files from the install: files such as "Joystick - HOTAS Warthog.lua" move into JoyPro's backup folder, so DCS uses its plain default for every device.
  • Preview files, Preview device files, Apply now (again after a DCS update), Restore DCS files, Check again; the folders and Find the folders; under "Folders and older JoyPro backups": Put back files an older JoyPro moved.
Careful

These options change DCS's own files. Some multiplayer servers do not let you in while they are on; Restore DCS files puts DCS's files back. A DCS update or repair brings the original files back; JoyPro switches the option on again at its next start.

#Command lists of DCS, Star Citizen and IL-2 (for experts)

Normally a game's list is built with Update on its card on the Start page. Here: only some DCS aircraft, a test run without writing, and the old click mode.

  • DCS: pick aircraft (All / None), Headless (recommended: DCS stays closed and JoyPro uses DCS's own Lua), Dry Run, Refresh ID DB, Refresh Clean DB; without Headless the legacy click mode with OCR, Launch, Keep Running and Preview Clicks.
  • Star Citizen DB: the game branch (LIVE, PTU, ...), Dry Run, Refresh Star Citizen DB.
  • IL-2 Great Battles DB: Dry Run, Refresh IL-2 DB.

#Force feedback settings of the games

Every force feedback setting a game offers (strength, effects, per device and, in DCS, per aircraft). JoyPro stores the values you set in the profile and writes them into the game on export; settings you do not store stay as the game has them. Pick the Game, the Device and the Aircraft (All aircraft, or one aircraft whose values win), change values, then Apply. Revert drops unapplied changes, Unset on a row stops storing one setting, Clear removes every stored setting shown. The telemetry force feedback of JoyPro itself is on the Force Feedback page.

#DCS force feedback: swap and invert per device

If your force feedback stick pushes the wrong way in DCS: tick Swap Axis, Invert X or Invert Y for it, then Apply. Clear gives the device DCS's defaults back. A table of devices with filters (Connected only, Profile only), selection buttons and Apply Selected / Clear Selected / Clear All; "Manual single-device (advanced)" sets one device by name.

In the game: Swap and invert

DCS reads the force feedback direction per device at start: a swapped or inverted device pushes the other way in every aircraft.

Advanced

#Tips and interactions

  • Games and the first-start window are two views of the same data: a link set in one shows in the other.
  • A game hidden in Games disappears from the Start page, the Export tiles, the watcher, the game backups and every game list; its relations stay in the profile and come back with Show again.
  • Watch game configs and the tray options work together: with Close to tray the helper keeps watching after JoyPro closed and opens JoyPro on the game's changes.
  • The vJoy tunnel device should match the device chosen on the Virtual Joystick page; then imports never pick up JoyPro's own output as binds and Also clear my other devices never empties it.
  • Report a problem replaces copying logs by hand: the zip has the session log of the Output panel, the engine's logs and, when you allow it, the profile and its history.
  • Confirmations that matter most for safety are the export ones; switching them off makes Replace and nuke exports run without a question (the game files are still backed up; Undo last export on the Export page restores them).
  • The Local AI status is the same line every AI action of JoyPro shows (the chip "Local AI: off - Turn on" next to Manage with AI, the assistant, Fix with AI on the Check).
  • Force feedback settings of the games and DCS force feedback both end up in DCS: invert and swap fall back to the per-device values of the DCS table when no game setting stores them.
