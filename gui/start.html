GUI pages

Start

Show:

The Start page is where JoyPro opens. It shows what is set up, what to do next, and your games: Import takes the binds you made in a game into JoyPro; Export writes them back. The import step by step: Import a game.

▶
Video: The Start page
Coming later: one YouTube video per topic, recorded with the English interface, with subtitles in every language JoyPro speaks.
For beginners

#From top to bottom

  • Notices: missing requirements, command lists to build or update, a crash report to send, an update.
  • Profile at a glance: relations (and how many are axes), how many are bound, modifiers, devices connected, games installed.
  • Next steps: what JoyPro suggests now ("3 relations have no button yet: Bind them", "VPforce Rhino FFB Base is not used yet: Auto Assign", "Write your binds into your games: Export").
  • Your games: one card per game with Import, Export, Update (its command list), Undo export, Watch for changes and a hide button. Set up my devices automatically... runs the setup wizard.
  • Your devices: the connected devices with their pictures; a click opens the Layout page. An orange Which grip? or Which model? on a device means JoyPro cannot tell which one it is: a click on it opens the Layout page with the choice open, and your answer stays.
  • Recent activity per game and the game watcher switch; the HUD card.
Advanced

#The import wizard

  1. Pick a game (Import on its card).
  2. Choose how: Add to my profile (recommended) or Start over from this game, the keyboard, devices that are not connected, the DCS aircraft. Look first shows what the game has in the Output panel without changing anything.
  3. Import now: the result stays on top of the cards ("Done: your profile now has 214 relations") with See my relations.

Below the cards, the expert import offers every option per game (DCS, IL-2, Star Citizen, and every other game from Load Games) with Scan / Import / Export.

Opens Settings > Report a problem with the description started as "Watcher: ...". Describe what the watcher did and create the report there.

MSFS import (wizard step 2 and the expert import): also takes the binds of devices that are not connected now. MSFS keeps the binds of every device it ever saw; off, only the connected devices are imported (--include-disconnected). Remembered with the import and export settings.

MSFS import: devices you never changed in the sim run on a preset MSFS ships. JoyPro takes it when the sim records that it uses it; on, also when that is not known, which can add binds the sim does not have (--include-sim-defaults). Remembered with the import and export settings.

DCS import (on by default): Windows gives a device a new ID now and then. On, the binds of its IDs are read as one device, on the connected ID (else the newest); two identical devices plugged in at once stay apart (--merge-same-name). Saved in the settings.

DCS import: on, devices that are not plugged in now are skipped and counted. Off (the default), they are imported too, useful for a stick you connect later (--only-connected). Saved in the settings.

Expert DCS import and scan (on by default): also takes the binds DCS gives by default to actions you have not bound: the keyboard keys and DCS's binds for your exact device model, only for aircraft and devices you already have binds for. Your own binds win; DCS's general joystick defaults are left out (--include-defaults). Remembered.

Expert import and export of the picked game: also reads or writes the keyboard binds of flight actions (--include-keyboard). Off: only device binds. Remembered per game.

MSFS 2024 export (on by default): writes the binds into the profile the sim uses for each device and category (Steam or Microsoft Store), backed up first. Off: JoyPro writes only import files (--user-profiles false). The same setting as on the Export page. In the game: your MSFS 2024 controls profiles hold the binds.

MSFS 2024 export: also writes an import file for every device and category (--import-files). Off: import files only where JoyPro could not write your profile. Import them in MSFS 2024 under Settings > Controls.

Yes on a device card: downloads the maker's photo of this device model from the maker's site and shows it on the card. The answer is kept for this model; Settings > Privacy changes it.

Always download: downloads the offered reference photos now and, from now on, the photos of every device that appears, in the background. It also allows the photos to be shown (Settings > Privacy switches it off).

No on the reference photo offer: no photos for these devices, JoyPro's drawings stay. The answer is kept per device model; Settings > Privacy forgets the answers.

The game watcher's main switch (on by default, kept across restarts): after a game closes, JoyPro asks whether to take the binds you changed in the game into your profile. Only games ticked Watch for changes are watched; off, none is. The same as Settings > Games > Watch game configs.
