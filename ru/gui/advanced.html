Страницы GUI

Расширенные

Показать:

Страница «Расширенные» — это консоль для экспертов. У каждой функции, нужной обычному пользователю, есть своя кнопка на других страницах; здесь вы сами вводите команды движка JoyPro, в точности как их описывает командная строка движка, а ответ появляется в панели Вывод.

Для начинающих

#Нужна ли мне эта страница?

Обычно нет. Она нужна в трёх случаях:

  • Кто-то (помощник в Discord, вики) просит вас выполнить команду, например profile summary, чтобы увидеть, что происходит.
  • Вы хотите изменить сразу много связок или привязок в текстовом редакторе: Правка связок и Правка привязок.
  • Вы хотите быстро посмотреть обзор открытого профиля: Сводка профиля.

#Выполнить команду

  1. Введите команду в поле Команда без слова engine, например profile summary или relations list --game DCS.
  2. Оставьте флажок Добавлять --profile: тогда команда работает с открытым профилем.
  3. Нажмите Выполнить. Ответ появится в панели Вывод внизу (нажмите Вывод на нижней панели, если она закрыта).
Осторожно

Команды, введённые здесь, могут менять ваш профиль и игры точно так же, как кнопки. Каждое изменение профиля — это версия в истории (верхняя панель), так что можно вернуться; файлы игр сохраняются в резервную копию перед экспортом.

#Поля

Глобальные аргументы Любые другие глобальные параметры, которые ставятся перед командой, например --status true. глобальные параметры
Команда Команда и её параметры. Кавычки удерживают путь с пробелами вместе. команды
Добавлять --profile Добавляет --profile "<open profile>". Снимите флажок для команд, которым профиль не нужен (db summary, games installs). --profile

  • Командная строка последнего запуска — первая строка панели вывода ($ engine --profile ... profile summary): скопируйте её, чтобы запустить то же самое в терминале.
  • Правка связок записывает все связки во временный JSON-файл, открывает его в вашем редакторе и читает обратно, когда редактор закрывается; страницы «Связки», «Привязки» и «Модификаторы» перезагружаются. Один шаг отмены.
Технические подробности

#Что стоит за страницей

Модель представления: MainWindowViewModel.cs (RunCustomCommandAsync, RelationsEditAsync, BindsEditAsync, RunEngineSummaryAsync, RunProfileSummaryAsync); аргументы собираются в RunEngineAsync, том же методе, который используют все кнопки интерфейса. Введённая команда разбивается TokenizeCli (с учётом кавычек), сначала идут глобальные аргументы, затем --profile, --status, --benchmark, --history-note (только для собственных изменений интерфейса), --out, --editor, параметры исправления при загрузке из «Настроек» и --text. Команда, которая меняет профиль, выполняется с блокировкой профиля и создаёт версию в истории, как любое другое изменение.

Движок: engine summary, engine profile summary, engine relations edit, engine binds edit и все команды командной строки движка. Справка: Соответствие интерфейса и командной строки (какая кнопка запускает какую команду).

#Текстовый вывод

Флажокописано

Вкл.: команда, введённая здесь, отвечает понятным текстом.

Выкл.: она отвечает в JSON — так, как его читают GUI и скрипты.

Подробнее (на английском)

#Добавлять --profile

Флажокописано

Вкл.: к введённой команде добавляется --profile "<open profile>", поэтому она читает и меняет профиль, который у вас открыт.

Снимите флажок для команд, которым профиль не нужен.

Подробнее (на английском)

#Выполнить

Кнопкаописано

Выполняет через движок команду, введённую в поле «Команда», и показывает ответ на панели «Вывод». relations list и binds list также обновляют страницы «Связки» и «Привязки».

Команда, которая меняет профиль, — это один шаг отмены; команда, которая пишет в игру, сначала делает резервную копию файлов игры, как и кнопки.

Подробнее (на английском)

#Правка связок

Кнопкаописано

Открывает все связки профиля одним JSON-файлом в вашем редакторе; когда вы закроете редактор, JoyPro прочитает файл обратно, и страницы «Связки», «Привязки» и «Модификаторы» перезагрузятся.

Один шаг отмены.

Подробнее (на английском)

#Правка привязок

Кнопкаописано

Открывает все привязки профиля одним JSON-файлом в вашем редакторе; когда вы закроете редактор, JoyPro прочитает файл обратно, и страницы перезагрузятся.

Один шаг отмены.

Подробнее (на английском)

#Сводка движка

Кнопкаописано

Одна строка с подсчётом на панели «Вывод»: relations=..., binds=..., modifiers=... для профиля, который загружен в движок.

Ничего не меняет.

Подробнее (на английском)

#Сводка профиля

Кнопкаописано

Показывает на панели «Вывод» количество элементов и состояние открытого профиля.

Ничего не меняет.
