Страницы GUI

Кабины

Показать:

Страница «Cockpits» — справочник по реальным и вымышленным кабинам, оформленный как глава о кабине в руководстве по лётной эксплуатации: выберите ЛА, его версию и место и читайте обзор, по странице на каждую рукоять (ручка, РУД, ручка циклического шага, рычаг шаг-газ) с таблицей HOTAS и по странице на каждую панель. Она ничего не меняет в вашем профиле или играх; она помогает решить, какую функцию поставить на какую кнопку, а Использовать эту раскладку открывает мастер настройки с раскладкой ручки и РУД этого ЛА.

Для начинающих

#Три части

  • Слева: выбор. Поле поиска («F-16», «Hornet», «TMS»), фильтры Тип, Игра, Эпоха, Роль и Страна, список ЛА и под ним Версия / блок / транш (например, F-16C Block 50).
  • Посередине: руководство. Вкладки Обзор кабины и для каждой рукояти, список Панели с одной страницей на панель, ◀ / ▶ для предыдущей и следующей страницы и Поиск по этой кабине («аккумулятор», «автопилот»).
  • Справа (или сверху в узком окне): путеводитель по кабине. Каждая зона, панель и орган управления простыми словами. Что это делает? открывает объяснение органа управления.

#Что вы видите на странице рукояти

Схема рукояти с пронумерованными выносками и таблица HOTAS: по строке на каждый орган управления и направление (нажатие, долгое нажатие, удержание), по столбцу на каждый режим (NAV, A-A, A-G; или TGP, HUD). Так каждая кнопка используется на настоящем ЛА — хороший образец для ваших собственных привязок.

#Изображения

Если ЛА есть в ваших установленных играх, Создать изображения из моих игр рисует кабину из игры, где каждый кликабельный орган управления пронумерован и назван так, как его называет игра. Для ЛА, которых у вас нет, JoyPro предлагает скачать пакеты изображений, а для кабин, которых нет ни в одной игре, — проверенные фото с подписями JoyPro поверх.

В игре: ничего не записывается

В игру ничего не записывается. Сравнить с моей настройкой отмечает в таблицах HOTAS, какие функции ваш открытый профиль уже привязывает для этой игры и ЛА, так что вы сразу видите, чего ещё не хватает.

Расширенные

#Кнопки варианта

  • Сравнить с моей настройкой: при открытом профиле каждая функция в таблицах HOTAS получает отметку, если одна из ваших связок отвечает за неё для этой игры и ЛА, с именем связки и входом. Скрыть убирает отметки.
  • Использовать эту раскладку: открывает мастер настройки, где раскладка ручки и РУД этого варианта служит образцом для ваших привязок (его ЛА первым в списке приоритетов).
  • Экспорт страницы (PNG) / Все страницы (PDF): показанная страница или все страницы варианта в вашем стиле схем (Настройки > Схемы) в Documents\JoyPro2\Cockpits; Открыть папку открывает её.
  • Место: у версий с двумя местами (переднее и заднее) свой набор страниц для каждого места.

#Откуда берутся изображения

Когда вы открываете вариант, JoyPro показывает первое из этого, что существует:

  1. Изображения из ваших игр: обзор, рукояти, одна страница на каждую панель.
  2. Набор изображений из релизов JoyPro: JoyPro сначала спрашивает (Загрузить / Не сейчас; Настройки > Конфиденциальность: спрашивать, всегда или никогда). Затем он показывает изображения из игр, как в шаге 1.
  3. Проверенные фото: скачиваются, по странице на фото с пронумерованными подписями JoyPro.
  4. Собственные схемы JoyPro.
  • Создать изображения из моих игр читает собственные файлы игр (DCS, X-Plane 12, MSFS 2020, IL-2 Great Battles, Nuclear Option, Star Citizen, War Thunder) и отрисовывает кабины на этом ПК. Это занимает около двух секунд на изображение; у большого модуля DCS их от 50 до 80. Изображения хранятся вместе с вашими данными игр, никогда в папке игры.
  • Поле рядом переключает между Изображение из игры и Рисунок JoyPro (контурный рисунок, обведённый по отрисовке, в вашем стиле схем). Если ЛА есть в нескольких ваших играх, второе поле выбирает набор.
  • Наборы изображений из релизов JoyPro (раскрывающийся раздел): изображения кабин, отрисованные из игр, для ЛА, которые вы не можете создать сами. Загрузить изображения для всех моих ЛА или Загрузить всё для этой игры сначала показывают общий размер; загрузка показывает ход выполнения, и её можно отменить; набор, контрольная сумма которого не совпадает, не устанавливается.
  • Проверенные фото: для ЛА, хороших изображений которых нет ни в одной игре (авиалайнеры, космические корабли, некоторые вертолёты и реактивные самолёты), Загрузить фото скачивает каждое фото с его исходного адреса (или копию из веб-архива), сверяет каждое с записью JoyPro и хранит его на этом ПК. Затем в руководстве появляется страница для каждого фото с пронумерованными подписями JoyPro и указанием автора фото.
  • Фото (под страницами): ссылки на реальные фото. JoyPro спрашивает, прежде чем загрузить какое-либо: Да, Нет, Всегда для кабин, Никогда.

#Путеводитель по кабине

Зона (левый пульт, приборная доска, верхний пульт) > панель («ENG & JET START control panel») > орган управления (каждый переключатель, кнопка и ручка с их положениями). Щелчок по органу управления открывает страницу, на которой он показан, и обводит его выноску; щелчок по выноске выбирает его в путеводителе. Открыть все / Закрыть все раскрывают или сворачивают все зоны.

Технические подробности

#Что стоит за страницей

  • Модель представления: CockpitsViewModel.cs (выбор, фильтры, сравнение, использование раскладки), CockpitsViewModel.Pages.cs (страницы руководства, экспорт), CockpitsViewModel.Guide.cs, CockpitsViewModel.Pictures.cs, CockpitsViewModel.PicturePacks.cs, CockpitsViewModel.VerifiedPhotos.cs; представление страницы ManualPageView.
  • Данные: DB\Cockpits\*.json (ЛА, варианты, органы управления, панели), DB\Cockpits\drawings, line-drawings, guide, photo-labels (по файлу на каждое проверенное фото).
  • На этом ПК: изображения из игр в <data>\GameData\CockpitPictures\<game>\<aircraft> (pictures.json, index.json), проверенные фото в <data>\CockpitPhotos\<aircraft>, фото по ссылкам в кэше загрузок; ответы о фото хранятся вместе с ответами о фото устройств (cockpit:<aircraft>).
  • Движок: engine cockpits (list, search, get --json для Использовать эту раскладку, compare для Сравнить с моей настройкой, render для PNG/PDF, pictures build|status|check, photos). Справка: cockpits, privacy.

#Сравнить с моей настройкой

Кнопкаописано

Подсказка Отмечает каждую функцию, для которой в открытом профиле есть связка (в играх и ЛА этого варианта)

Сравнивает ваш открытый профиль с этим вариантом: каждая функция в таблицах HOTAS, которую одна из ваших связок держит для своих игр и ЛА, получает ✓ со связкой и входом, а строка говорит, сколько функций покрыто.

Только читает; нужен открытый профиль.

Подробнее (на английском)

#Использовать эту раскладку

Кнопкаописано

Подсказка Передаёт раскладку ручки и РУД этого ЛА мастеру настройки (engine cockpits get ... --json)

Открывает мастер настройки с этим вариантом: его ЛА поднимается в начало списка приоритетов, а план размещает его функции как на ручке и РУД этого варианта, а не первого варианта ЛА.

Мастер, который вы оставили открытым до «Применить», тоже это принимает.

#Создать изображения из моих игр

Кнопкаописано

Подсказка Создаёт изображения кабин установленных игр ({0}), где каждый элемент управления пронумерован и назван так, как его называет игра. Создаются на этом ПК и хранятся вместе с данными игры.

Отрисовывает кабины ваших установленных игр на этом ПК, каждый кликабельный элемент управления пронумерован и назван так, как его называет игра.

Это занимает несколько минут на игру; изображения хранятся с вашими данными игр, никогда не в папке игры, и их используют страницы руководства.

Подробнее (на английском)

#Загрузить

Кнопкаописано

Подсказка Загружает изображения кабины, созданные JoyPro из игры (файл релиза на GitHub), проверяет их и хранит вместе с данными игры

Загружает предложенный набор изображений из релизов JoyPro с индикатором выполнения.

Каждый набор проверяется по контрольной сумме и распаковывается в ваши данные игр; затем страницы руководства этих ЛА показывают изображения из игры.

Подробнее (на английском)

#Не сейчас

Кнопкаописано

Закрывает предложение без загрузки; в этом сеансе JoyPro больше не предлагает эти наборы.

#Отмена

Кнопкаописано

Останавливает идущую загрузку набора изображений.

Неполный набор не устанавливается; уже завершённые наборы остаются.

Подробнее (на английском)

#Загрузить изображения для всех моих ЛА

Кнопкаописано

Подсказка Наборы всех известных JoyPro ЛА из ваших установленных игр; сначала вы увидите общий размер

Ищет наборы изображений для всех известных JoyPro ЛА из ваших установленных игр и предлагает те, которых ещё нет на этом ПК, с их общим размером; «Загрузить» запускает загрузку.

Подробнее (на английском)

#Загрузить всё для этой игры

Кнопкаописано

Загружает все наборы изображений этой игры из релизов JoyPro.

Каждый набор проверяется по контрольной сумме и распаковывается в ваши данные игр; затем страницы руководства этих ЛА показывают изображения из игры.

Подробнее (на английском)

#Загрузить фото

Кнопкаописано

Подсказка Загружает каждое фото этой кабины с исходного адреса (или из копии веб-архива), сверяет его с записью JoyPro и хранит на этом ПК

Загружает каждое проверенное фото этой кабины с его исходного адреса, сверяет каждое с записью JoyPro и хранит на этом ПК.

Щелчок также считается вашим «да» для фото этого ЛА; тогда в руководстве появляется страница на каждое фото с пронумерованными подписями JoyPro.

Подробнее (на английском)

Подробнее (на английском)

#Что это делает?

Кнопка-переключательописано

Открывает или закрывает пояснение к этому элементу управления в справочнике кабины: что он делает простыми словами, «В общем контексте», его положения, его название в игре и команды для привязки.

Подробнее (на английском)

#Да

Кнопкаописано5 ×

Отвечает на вопрос о фото этого ЛА: «Да» загружает ссылки на его фото сейчас, «Нет» — не загружает, «Всегда для кабин» загружает фото всех ЛА без вопросов, «Никогда» останавливает все фото кабин.

«Показать фото этого ЛА» после «Нет» — это и есть «Да».

Подробнее (на английском)
