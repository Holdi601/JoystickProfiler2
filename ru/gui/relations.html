Связки

Показать:

Страница «Связки» создаёт и упорядочивает связки: одна функция с её действием в каждой игре и на каждом ЛА. Пошаговое руководство со схемами и смыслом в игре — на странице Создание связок.

Для начинающих

#Три области

  • Слева: ваши связки. Поле поиска, фильтры (группы, игры, устройства, привязано или нет, ось или кнопка) и по одной карточке на связку с её кнопкой («Throttle - HOTAS Warthog · BTN 22 · Shift») или «не привязано».
  • Посередине: открытая связка. Её имя (щёлкните, чтобы переименовать), Ось или Кнопка, её вход и Её действия: по одной карточке на каждое действие игры.
  • Справа: инструменты. Добавить действия (поиск во всех играх), Предложено для этой связки, Каталог (просмотр действий игры по категориям) и Помощник JoyPro (введите предложение).

Новое начинает связку; Автоматически собрать связки из всех моих действий создаёт их для всего профиля.

Расширенные

#Советы

  • Ctrl/Shift+щелчок по нескольким карточкам открывает Массовые изменения (группы, дублировать, удалить) и Группы (добавить, убрать, переименовать).
  • Следовать за вводом: нажмите кнопку на ручке, и откроется её связка.
  • Карточка действия DCS открывает свои ЛА («82 из 84 ЛА»); снимите флажки у ЛА, где команда не должна применяться. Только тот же смысл оставляет только ЛА, где id означает одно и то же.
  • Если фильтр Игры стоит на одном ЛА («DCS World: F-100D»), открытая связка всё равно показывает все свои действия, чтобы ничего не изменить по ошибке: действия для F-100D идут первыми с синей рамкой и пометкой Фильтр: F-100D, остальные свёрнуты в Другие ЛА (n); щелчок разворачивает их.
  • Предложить недостающее (n) в открытой связке перечисляет, чего не хватает другим играм и ЛА; Ещё > Предложить недостающее для каждой связки... делает это сразу для всех связок.
  • Метка функции показывает, какой функцией JoyPro считает связку; если догадка неверна, измените её (от неё зависят предложения).

#Несколько действий сразу

В Её действия Ctrl+щелчок или Shift+щелчок выбирает несколько карточек действий (Ctrl+A — все). Панель показывает, сколько выбрано, и предлагает:

  • Копировать (Ctrl+C): запоминает их. Откройте другую связку того же вида и нажмите Вставить действия (n) (Ctrl+V) в её заголовке: они копируются туда вместе со своими ЛА, в том числе выключенными. В первой связке они остаются.
  • Перенести в...: окно спрашивает, куда их перенести: Новая связка (введите её имя; она получает вид этой связки, ось или кнопка, и пока без привязки) или Существующая связка (того же вида) (поиск по списку). Перенести убирает их из этой связки.
  • Удалить (Del): убирает их из этой связки после одного вопроса.

В контекстном меню действия также есть Копировать и Перенести в другую связку...: для этого действия или для выделения, если действие в него входит. В списке слева для нескольких выбранных связок есть Перенести действия в...: все их действия переходят в одну связку, а опустевшие связки удаляются вместе с привязками. Каждое из этих действий — один шаг для Ctrl+Z.

#То же значение

Кнопка-переключательописано2 ×

Подсказка Вкл.: фильтр находит также действия, которые делают то же самое (по синониму или описанию). Выкл.: только действия, в названии которых есть все введённые слова. Тот же переключатель, что и в «Добавить действия»; запоминается.

«Добавить действия»: «То же значение» под действиями, в названии которых есть каждое введённое вами слово, также показывает действия, которые делают то же самое, и менее точные.

Выкл.: только совпадения по названию; строка над списком сообщает, сколько скрыто.
