Страницы GUI

Экспорт

Показать:

Страница «Экспорт» записывает ваш профиль в игры. Это три пронумерованных шага, затем параметры для экспертов и резервные копии конфигураций игр. Полное описание режимов и того, что они делают в каждой игре, — на странице Экспорт в ваши игры.

Для начинающих

#Страница сверху вниз

  1. Проверьте профиль: Проверить запускает Проверку; её карточки появляются ниже.
  2. Как JoyPro записывает в игры: четыре варианта (заменить на моих устройствах, обновить с сохранением привязок игры, обновить с приоритетом моего профиля, только добавить) и флажок Очистить и другие мои устройства.
  3. Экспорт в игры: одна карточка на каждую игру с привязками в вашем профиле. Отметьте карточки и нажмите Экспорт отмеченных игр или Экспортировать на одной карточке. Отменить последний экспорт на карточке восстанавливает файлы этой игры.

Ниже: Параметры и пути (для экспертов), затем Проблемы, найденные проверкой, Одна кнопка использована дважды и Резервные копии конфигураций игр.

Расширенные

#Карточки и запомненный выбор

  • Карточка изначально отмечена, только если в игре есть привязанные связки и она хотя бы раз запускалась (её файлы управления существуют). Изменённый вами флажок сохраняется, для каждого профиля.
  • У карточки DCS есть ЛА...: все ЛА (и слои ввода) профиля с изображением и числом привязанных связок; записываются только отмеченные ЛА (Все / Ничего).
  • Каждая карточка показывает свой последний результат («Экспортировано: 14:02» или ошибку движка).
  • Неустановленные игры карточки не получают; страница называет их со ссылкой на Настройки > Игры.
  • Предпросмотр на карточке (где он есть) запускает экспорт как пробный прогон и показывает, что изменится.
Технические подробности

#Что стоит за страницей

Модель представления: MainWindowViewModel.ExportGames.cs (карточки, экспорт, отмена), MainWindowViewModel.ExportDefaults.cs (режимы по умолчанию, пометки), MainWindowViewModel.Backups.cs. Движок: engine profile games заполняет карточки; engine dcs export, engine il2 export, engine starcitizen export и engine <game> export записывают; engine backups list / engine backups restore для отмены и списка резервных копий; engine profile game-state для вопроса «Сначала импортировать?».

#Все элементы этой страницы

#Очистить и другие мои устройства (в экспортируемых самолётах устройства без привязок в моём профиле теряют все привязки)

Флажокописано2 ×

Подсказка Убирает все привязки устройств, которые не использует ваш профиль (сначала спрашивает; создаётся резервная копия)

Подключённые устройства, у которых нет привязок в вашем профиле, теряют все свои привязки в экспортированных ЛА.

Неподключённые устройства, игнорируемые при импорте устройства и устройство vJoy, в которое JoyPro передаёт входы, никогда не очищаются.

Подробнее (на английском)

#MSFS 2024: записывать в мои профили MSFS

Флажокописано

Подсказка Экспорт записывает привязки в профиль, который MSFS 2024 использует для каждого устройства и категории (Steam или Microsoft Store), предварительно создав резервную копию. Выкл.: только файлы импорта.

Только Microsoft Flight Simulator 2024, по умолчанию вкл.: экспорт после резервного копирования записывает ваши привязки прямо в профиль, который MSFS 2024 использует для каждого устройства и категории.

Поле под карточками затем показывает для каждого устройства, какой профиль их получил.

Подробнее (на английском)

#MSFS 2024: файлы импорта для каждого устройства

Флажокописано

Подсказка Выкл.: файлы импорта только там, где JoyPro не смог записать ваш профиль.

Только Microsoft Flight Simulator 2024, по умолчанию выкл.: экспорт также записывает файл импорта для каждого устройства и категории, а не только там, где JoyPro не смог записать ваш профиль.

«Открыть папку» в поле MSFS показывает эти файлы.

Подробнее (на английском)

#Открыть папку

Кнопкаописано2 ×

Только Microsoft Flight Simulator 2024. Там, где JoyPro не смог записать ваш собственный профиль MSFS 2024, экспорт записывает ваши привязки по одному файлу на устройство и категорию; эта кнопка открывает ту папку в Проводнике.

В симуляторе: Settings > Controls, выберите устройство и категорию, шестерёнку вашего профиля, Import и файл этого устройства и категории.

Подробнее (на английском)

#Настройки > Игры

Кнопкаописано

Показывается, когда некоторые игры вашего профиля не установлены: открывает «Настройки > Игры», где можно указать портативную установку или другую папку, чтобы игра считалась установленной.

Подробнее (на английском)

#Экспорт отмеченных игр

Кнопкаописано

Подсказка Экспортирует все отмеченные игры по очереди (DCS: только отмеченные ЛА)

Отправляет кнопки в отмеченные игры.

Записывает ваши привязки в каждую отмеченную игру по очереди, выбранным выше способом.

JoyPro сначала делает резервную копию, поэтому «Отменить последний экспорт» возвращает каждую игру в прежнее состояние.

Подробнее (на английском)

#Обновить

Кнопкаописано

Заново читает игры профиля и их привязанные связки и перестраивает карточки.

Подробнее (на английском)

#Входит в «Экспорт отмеченных игр»

Флажокописано2 ×

Флажок карточки игры: отмеченные карточки экспортирует «Экспорт отмеченных игр».

Карточка сначала отмечена, если у игры есть привязанные связки и она хотя бы раз запускалась; изменённая вами отметка запоминается для каждого профиля.

Подробнее (на английском)

#Показывает ЛА; экспортируются только отмеченные

Кнопкаописано

«ЛА...» / «Скрыть ЛА» на карточке с ЛА: открывает список ЛА профиля с их изображениями и тем, сколько их связок привязано.

Экспорт записывает только отмеченные ЛА; ваши отметки запоминаются для каждого профиля.

Подробнее (на английском)

#Предпросмотр

Кнопкаописано

Подсказка Показывает, что изменил бы экспорт, ничего не записывая (панель вывода)

Запускает экспорт этой игры без записи и перечисляет на панели «Вывод», что изменилось бы.

Ничего не записывается, и резервная копия не создаётся.

Подробнее (на английском)

#Отменить последний экспорт

Кнопкаописано

Подсказка Возвращает файлы управления игры в состояние до последнего экспорта JoyPro (сначала спросит; только после экспорта этой игры)

Возвращает игру в прежнее состояние.

Возвращает игру в состояние до последнего экспорта: JoyPro восстанавливает самую новую резервную копию этой игры: каждый файл, изменённый последним экспортом, возвращается байт в байт, а созданные им файлы удаляются.

Перед самим восстановлением тоже делается резервная копия, поэтому его тоже можно отменить.

Подробнее (на английском)

#Экспортировать

Кнопкаописано

Экспортирует только игру этой карточки, с теми же вопросами, что и «Экспорт отмеченных игр».

В игре: как выше, только для этой игры.

Подробнее (на английском)

#Все

Кнопкаописано

В списке «ЛА...» карточки: отмечает все ЛА, чтобы экспорт записал их все.

Подробнее (на английском)

#Ничего

Кнопкаописано

В списке «ЛА...» карточки DCS: снимает отметку со всех ЛА.

Экспорт записывает только отмеченные ЛА; остальные сохраняют свои файлы DCS как есть.

Подробнее (на английском)

#Свои пути и игнорируемые устройства для этого профиля

Флажокописано

Подсказка Выкл. (по умолчанию): пути игр и игнорируемые устройства принадлежат этому ПК, и их использует каждый профиль. Вкл.: этот профиль хранит свои; введённый путь всегда важнее того, что находит JoyPro.

Даёт открытому профилю собственные пути к играм и игнорируемые устройства вместо тех, что заданы для ПК.

При открытии другого профиля снова действуют пути ПК.

Подробнее (на английском)

#Экспорт IL2

Кнопкаописано

Параметр для опытных: экспортирует только IL-2 Great Battles, по пути, введённому в поле рядом, и с режимом, выбранным выше.

То же, что «Экспортировать» на карточке IL-2.

Подробнее (на английском)

#Экспорт Star Citizen

Кнопкаописано

Параметр для опытных: экспортирует только Star Citizen, с путём и необязательным источником из полей выше, режимом, выбранным выше, и двумя флажками Star Citizen.

В игре: привязки находятся в файле actionmaps.xml игры; игра читает его при запуске.

Подробнее (на английском)

#Пробный запуск

Флажокописано

Для игр, кроме DCS, IL-2 и Star Citizen: экспорт только показывает, что изменилось бы, ничего не записывается.

Подробнее (на английском)

#Экспорт игры

Кнопкаописано

Параметр для опытных: экспортирует игру, выбранную в «Другая игра», в файл или папку из поля, с режимом, выбранным выше; если отмечен «Пробный запуск», только показывает, что изменилось бы.

Подробнее (на английском)

#DCS: сохранить стандартные привязки клавиатуры

Флажокописано

Только DCS, по умолчанию вкл.: клавиатура сохраняет клавиши DCS по умолчанию.

Выкл.: записываются привязки клавиатуры из профиля, и удаляются только те клавиши DCS по умолчанию, которые они занимают.

Подробнее (на английском)

#DCS: очищать мои устройства и во всех других самолётах

Флажокописано

Подсказка Выкл. (по умолчанию): экспорт затрагивает только экспортируемые самолёты. Вкл.: с 'Заменить на моих устройствах' устройства, которые пишет JoyPro, теряют свои привязки и стандартные привязки DCS и во всех других установленных самолётах.

Только DCS, по умолчанию выкл.: с «Заменить на моих устройствах» записанные устройства также теряют свои привязки и привязки DCS по умолчанию во всех других установленных ЛА, а не только в экспортированных.

Подробнее (на английском)

#SC: сохранить стандартные привязки клавиатуры

Флажокописано

Только Star Citizen, по умолчанию вкл.: клавиатура сохраняет клавиши игры по умолчанию.

Выкл.: записываются привязки клавиатуры из профиля, а клавиши по умолчанию, которые они занимают, освобождаются.

#SC: предпочитать локальный порядок

Флажокописано

Только Star Citizen, по умолчанию вкл.: устройство сохраняет слот джойстика, который игра уже дала ему в своём файле; другие устройства занимают свободные слоты.

Выкл.: слоты идут в том порядке, в котором Windows сообщает об устройствах, а это может перенести все привязки устройства в другой слот.

#Экспорт DCS

Кнопкаописано

Параметр для опытных: экспортирует только DCS, все ЛА профиля, по пути DCS из поля, с режимом и флажками DCS, выбранными здесь.

«Экспортировать» на карточке DCS делает то же самое, но только для ЛА, отмеченных в «ЛА...».

Подробнее (на английском)

#Проверить профиль

Кнопкаописано

Ищет ошибки, например две задачи на одной кнопке.

Ищет ошибки и показывает каждую в виде карточки.

Запускает «Проверить», отчёты о дубликатах и конфликтах и отметки экспорта; карточки появляются в разделе «Проблемы, найденные проверкой».

Подробнее (на английском)

#Обновить

Кнопкаописано

Заново читает список резервных копий конфигурации для игры, выбранной слева.

Резервные копии игр, которые вы скрыли в «Настройки > Игры», не показываются.

Подробнее (на английском)

#Показать файлы

Кнопкаописано

Показывает файлы выбранного набора резервных копий под таблицей.

Подробнее (на английском)

#Предпросмотр восстановления

Кнопкаописано

Показывает, какие файлы вернёт «Восстановить», ничего не записывая.

Закройте игру перед настоящим восстановлением.

Подробнее (на английском)

#Восстановить

Кнопкаописано

Подсказка Возвращает файлы игры в состояние до выбранного экспорта (только для установленных игр)

Возвращает выбранный набор резервных копий. Сначала используйте «Предпросмотр восстановления», чтобы увидеть, какие файлы изменятся.

Перед восстановлением текущие файлы сохраняются в резервную копию.
