Начало работы

Скачать и установить

Показать:

JoyPro 2 бесплатен и имеет открытый исходный код (GPL-3.0). Нет учётной записи, нет регистрации и нет телеметрии.

Для начинающих

#Три шага

  1. Откройте страницу релизов на GitHub и скачайте JoyPro2-<version>-win-x64.zip (в разделе Assets).
  2. Щёлкните zip правой кнопкой мыши, выберите Извлечь все... и укажите папку, в которую можно записывать, например C:\JoyPro2 или папку в «Документах». (Не C:\Program Files: JoyPro обновляет себя в своей собственной папке.)
  3. Откройте папку и дважды щёлкните JoyPro.Gui (программа со значком джойстика; если расширения файлов показаны, она называется JoyPro.Gui.exe).

Windows пишет Система Windows защитила ваш компьютер? Нажмите Подробнее, затем Выполнить в любом случае. Windows спрашивает об этом один раз для программы из интернета, которую ещё не знает.

При первом запуске JoyPro ищет ваши игры и показывает их в окне: см. Первый запуск. Впервые в JoyPro? Нажмите там Готово, и настроить всё за меня и следуйте странице Быстрый старт: заставить мою ручку работать.

Затем приветствие спрашивает, что вы хотите сделать, и запускает подходящий вам тур. JoyPro 2 - Tour в той же папке в любой момент снова открывает это приветствие. Хотите крупный текст и короткие предложения? Отметьте Простые слова: крупный текст, короткие предложения в приветствии (Простые слова, туры и F1).

#Что вам нужно

  • Windows 10 или 11, 64 бит.
  • .NET Framework 4.8 для движка JoyPro. В Windows 10 и 11 он уже есть; если его нет, JoyPro предложит установщик от Microsoft.
  • Больше ничего: в zip есть всё (программе не нужно отдельно устанавливать .NET 9).

#Обновления

При запуске JoyPro проверяет на GitHub, нет ли более новой версии («Настройки»: Проверять обновления при запуске). Для новой версии открывается окно со списком изменений и кнопками Обновить сейчас / Позже / Пропустить эту версию. Ваши профили и настройки сохраняются.

Расширенные

#Где JoyPro хранит данные

Ваши профили находятся в папке «Документы», в JoyPro2. Туда же попадают отчёты о проблемах. Обновление заменяет только папку программы: ваши профили, настройки, списки команд, резервные копии и история остаются. Полный список папок — в разделе «Технические подробности».

#Дополнительные компоненты

Настройки > Компоненты устанавливает, каждый одним щелчком и с вашего согласия: vJoy (виртуальный джойстик), HidHide (скрывает физические устройства от игры) и ViGEmBus (виртуальный геймпад Xbox) — для режима Виртуальный джойстик. Настройки > Локальный ИИ может скачать необязательную модель ИИ для помощника; всё работает и без неё.

#Выход в интернет

JoyPro выходит в интернет только для: проверки обновлений (GitHub), фотографий ваших устройств от производителей (только после вашего согласия для каждого устройства), обложек игр, которых нет на вашем ПК (можно выключить), необязательной модели ИИ, дополнительных компонентов и установщика .NET Framework, если его нет. Эти сайты видят ваш IP-адрес. Подробности: Конфиденциальность.

Технические подробности

#Все папки JoyPro

Что Где
Программа папка, которую вы распаковали (с engine\engine.exe, vjoy\, tray\ и данными, которые JoyPro поставляет в DB\)
Ваши профили Documents\JoyPro2 (или там, где вы их сохраняете)
Настройки %APPDATA%\JoyPro2 (ui-settings.json, export-settings.json, hud.json ...)
Списки команд игр, построенные на вашем ПК %LOCALAPPDATA%\JoyPro2\GameData
Резервные копии файлов игр %LOCALAPPDATA%\JoyPro2\GameBackups (30 самых новых на игру)
История профиля (отмена после перезапуска) %LOCALAPPDATA%\JoyPro2\ProfileHistory
Журналы %LOCALAPPDATA%\JoyPro2\Logs (удаляются сами через несколько дней)
Отчёты о проблемах Documents\JoyPro2\Problem Reports

#Что внутри пакета

  • JoyPro.Gui.exe: приложение Avalonia (.NET 9, автономное).
  • JoyPro 2 - Tour.cmd: запускает JoyPro.Gui.exe --welcome — приветствие с его турами (передаёт его уже запущенному JoyPro).
  • engine\engine.exe: движок (.NET Framework 4.8). GUI запускает его для каждого действия; его можно запускать и в консоли (командная строка движка).
  • vjoy\JoyPro.VJoy.exe (ретранслятор виртуального джойстика), JoyPro.Ffb.exe (Force Feedback по телеметрии), tray\JoyPro.Tray.exe (отслеживание, пока GUI закрыт).
  • Обновление скачивает zip-архив релиза, проверяет его по опубликованному файлу .sha256 и устанавливает.
  • Сборка из исходников: dotnet build gui/JoyPro.Gui/JoyPro.Gui.csproj (собирает и движок; нужны средства сборки .NET Framework 4.8), см. README репозитория.
