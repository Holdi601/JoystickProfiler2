Начало работы

Быстрый старт: заставить мою ручку работать

Показать:

Вы хотите, чтобы ваша ручка работала в игре. Вы не хотите сначала изучать JoyPro. Эта страница для вас.

JoyPro смотрит на вашу ручку, РУД и педали. Он сам ставит на них важные команды управления игры. Вы смотрите на результат и нажимаете две синие кнопки. Вот и всё.

  1. Настроить всё за меня
    на странице «Старт»
  2. Использовать эти кнопки
    в новом окне
  3. Записать в мою игру
    следующая синяя кнопка
  4. Летайте
    запустите игру
Для начинающих

#Прежде чем начать

  • Скачайте JoyPro и распакуйте его: Скачать и установить.
  • Подключите ручку, РУД и педали.
  • Один раз запустите игру, затем закройте её. Некоторые игры создают свои файлы управления только тогда.
  • Держите игру закрытой, пока JoyPro в неё записывает.

#Быстрый путь, шаг за шагом

  1. Запустите JoyPro. При первом запуске окно покажет ваши игры. Нажмите Готово, и настроить всё за меня. Тогда шаг 2 можно пропустить.
  2. Нажмите «Настроить всё за меня». Эта кнопка находится на странице «Старт», в карточке «Настройте свои устройства». Ответ Просто чтобы моя ручка заработала в приветствии (первый вопрос JoyPro после первого запуска) делает то же самое.
  3. Посмотрите список. В нём сказано, что делает каждая кнопка, например «Button 4: Reload guns». Показать изображение крупно показывает вашу ручку со всеми кнопками.
  4. Нажмите «Использовать эти кнопки». Теперь ваши кнопки есть в JoyPro. Ваша игра пока не меняется.
  5. Нажмите «Записать в мою игру». Теперь ваши кнопки есть в игре. JoyPro хранит копию старых.
  6. Летайте. Страница «Старт» пишет «Получилось!». Запустите игру и летайте.

Синей бывает только одна кнопка за раз. Нажмите синюю, и синей станет следующая.

#Вопрос о трекинге головы

Для авиасимулятора список спрашивает: Вы используете трекинг головы или VR? Ответьте Да, если вы осматриваетесь, двигая головой (TrackIR, веб-камера с трекингом лица, Tobii или VR), или собираетесь так делать. Тогда на вашу ручку не ставятся кнопки обзора, только «центрировать вид». Ответьте Нет, если вы осматриваетесь ручкой: обзор получает хатка. См. Отслеживание головы и обзор.

Строка внизу

«Все важные кнопки назначены. Для некоторых редких дополнительных не хватило места (18). Это нормально.» Это хорошая новость. На вашей ручке меньше кнопок, чем в игре команд управления. Все важные — на вашей ручке.

#В игре уже есть кнопки

Вы раньше настраивали кнопки в игре? Тогда Записать в мою игру задаст один вопрос:

Ответ Что происходит
Использовать новые Кнопки JoyPro заменяют старые. JoyPro хранит копию старых.
Оставить и старые Ваши новые кнопки добавляются рядом со старыми. Ничего не удаляется.
Отмена Ничего не записывается. Когда будете готовы, снова нажмите Записать в мою игру.

#ACE COMBAT и другие игры только для Xbox

ACE COMBAT 8 и Hell Let Loose: Vietnam знают только контроллер Xbox. Вашу ручку они не видят. JoyPro превращает вашу ручку в ненастоящий контроллер (виртуальный геймпад Xbox). В эти игры ничего не записывается.

  1. Настроить всё за меня
    затем Использовать эти кнопки
  2. Настроить ненастоящий контроллер
    вторая синяя кнопка
  3. Тест
    подвигайте ручку
  4. Запустите игру
    дождитесь титульного экрана
  5. Alt+Tab, «Начать»
    затем Alt+Tab обратно
  1. Нажмите Настроить всё за меня, затем Использовать эти кнопки.
  2. Следующая синяя кнопка — Настроить ненастоящий контроллер. Откроется страница «Виртуальный джойстик».
  3. В первый раз нужен бесплатный помощник ViGEmBus. Отметьте флажок под лицензией. Затем нажмите Установите ViGEmBus. Windows спросит разрешение: нажмите Да.
  4. Нажмите Тест. Подвигайте ручку. Картинка контроллера тоже двигается.
  5. Запустите игру. Дождитесь её титульного экрана.
  6. Зажмите Alt и нажмите Tab. Вы снова в JoyPro. Нажмите Начать.
  7. Снова нажмите Alt+Tab. Вы снова в игре. Летайте!
«Начать» — после запуска игры

Нажимайте Начать, только когда игра показывает титульный экран. Слишком рано? JoyPro скажет «Слишком рано». Нажмите Стоп, затем Начать. Делайте это каждый раз, когда играете.

Подробнее об этих играх: Играть в игру только для Xbox с HOTAS и ACE COMBAT.

#Что-то пошло не так?

  • Не найдено ни игры, ни ручки. Подключите ручку или один раз запустите игру. Затем нажмите Попробовать снова.
  • Вы хотите выбирать больше сами. Нажмите Настроить пошагово. Откроется мастер настройки со всеми его шагами.
  • Вы хотите вернуть старые кнопки. См. Отменить быструю настройку.
  • Вы хотите другую кнопку для одной функции. См. Изменить одну кнопку позже.

#Простые слова

Хотите крупный текст и очень короткие предложения? Отметьте Простые слова: крупный текст, короткие предложения в приветствии или в первом окне. На каждой карточке тура тоже есть Слова попроще. См. Простые слова, туры и F1.

Расширенные

#Что делает быстрая настройка

  • Это мастер настройки, который работает сам. Он использует свои значения по умолчанию: ваши устройства и их обычные задачи, все ЛА равны, без модификаторов.
  • Он настраивает только те игры, где на ваших ручках ещё ничего нет. Карточка на странице «Старт» называет их: «Настроить устройства для War Thunder и Star Citizen».
  • Куда ставить функции? берётся из вашего последнего выбора в мастере (сначала — середина). См. Куда ставить функции?.
  • Устройство, которое JoyPro не знает, настраивается как обычное устройство своего вида. Движение ручки управляет, кнопка 1 стреляет, первая хатка триммирует, первый рычаг — это РУД. Об этом сообщает поле вверху.
  • Изменить что-то показывает инструменты: перенести, поменять местами или пропустить функцию и вернуть её обратно. Там же видно, что не поместилось.
  • Игры, в которых вы сами делали привязки, перечислены под карточкой. Импортировать, затем заполнить пробелы сначала забирает ваши привязки; затем настройка использует только свободные элементы управления. Для игр, которые уже есть в вашем профиле, есть Заполнить пробелы....
  • Использовать эти кнопки — это один шаг в истории профиля. Одно Отменить (Ctrl+Z) возвращает всё обратно.
  • Записать в мою игру — это экспорт этих игр. Сначала он делает резервную копию файлов игры, как страница «Экспорт».
  • После этого короткий тур показывает, где потом изменить кнопку. Он заканчивается словами «Готово! Запускайте игру».
Технические подробности

#Что стоит за быстрой настройкой

Быстрый путь выполняет шаги движка мастера, не показывая их: engine setup devices, engine setup aircraft и engine setup plan вплоть до проверки. Использовать эти кнопки запускает engine setup apply (одна версия профиля). Записать в мою игру запускает экспорт игры с настройками и резервной копией страницы «Экспорт». Для игр только с геймпадом вместо этого открывается страница «Виртуальный джойстик»; их таблица берётся из engine vjoy map. GUI: QuickSetupCommand на странице «Старт», StartQuickSetupAsync (MainWindowViewModel.AutoSetupStart.cs), окно Views/SetupWizardWindow.axaml.
