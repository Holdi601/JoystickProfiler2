Как сделать

Изменить одну кнопку позже

Показать:

Вашу ручку настроил JoyPro или вы сами. Теперь вы хотите другую кнопку для одной функции. Для этого нужны четыре шага ниже: три на странице «Привязки», затем один экспорт.

  1. Привязки
    в нижней панели
  2. Выбрать команду игры
    в списке
  3. Записать вход
    нажмите свою кнопку
  4. Экспорт
    отправить в игру
Для начинающих

#Шаг за шагом

  1. Откройте Привязки в нижней панели. Там всё, что вы настроили.
  2. Нажмите на команду игры в списке, например «Gear Up/Down». Поле поиска над списком быстро её найдёт.
  3. Нажмите Записать вход. Затем нажмите новую кнопку на ручке. Ось отклоните до упора.
  4. Снова отправьте это в игру. Сначала закройте игру. Откройте Экспорт в нижней панели. Нажмите Экспорт отмеченных игр.

Записать вход появляется только после того, как вы выбрали команду игры. Сначала выберите её.

#В игре только для Xbox

ACE COMBAT 8 и Hell Let Loose: Vietnam не получают экспорта. Нажмите Стоп, затем Начать на странице «Виртуальный джойстик». Тогда ненастоящий контроллер (виртуальный геймпад Xbox) будет использовать вашу новую кнопку.

#Отменить

Нажали не ту кнопку? Нажмите Ctrl+Z. Ваша старая кнопка вернётся.

Расширенные

#Другие способы

  • Нажмите кнопку, которую хотите изменить. Следовать за вводом на странице «Привязки» открывает связку нажатой кнопки.
  • На изображении. Страница «Раскладка» в режиме Привязка: щёлкните по входу, выберите связку, Привязать к этому входу.
  • Только одна игра. На карточке игры на странице «Старт» есть Экспорт для этой игры.
  • Вторая кнопка для того же самого. См. Несколько кнопок для одной функции.
  • Одна и та же кнопка в двух связках разрешена. Проверка подскажет, где это означает две задачи в одном ЛА.
Технические подробности

#Что за этим стоит

Записать вход ждёт следующего входа любого устройства и задаёт привязку (engine binds set); экспорт — это экспорт игры с режимом страницы «Экспорт» (Экспорт). Каждое изменение — одна версия профиля, поэтому Ctrl+Z работает и после перезапуска.
