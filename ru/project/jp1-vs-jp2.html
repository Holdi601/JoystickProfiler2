Проект

От JoyPro 1 к JoyPro 2

Показать:

JoyPro 1 (с 2021 по 2023 год) был инструментом для DCS: он создавал связки между входами разных ЛА и привязывал их к одному и тому же месту на ручке. JoyPro 2 сохраняет ровно эту идею и ту же модель связок / привязок / модификаторов (профиль JoyPro 1 открывается в JoyPro 2) и перестраивает всё вокруг неё: новый интерфейс, движок, который работает и сам по себе, десятки игр, тесты для каждой функции и много мер безопасности.

Для начинающих

#Что лучше для вас

  • Много игр, один профиль. JoyPro 1 был для DCS. JoyPro 2 импортирует и экспортирует 36 игр: DCS, IL-2 (Great Battles, Korea, 1946, Cliffs of Dover), Star Citizen, MSFS 2020 и 2024, X-Plane 11 и 12, Falcon BMS, War Thunder, Elite Dangerous, X4, Arma и другие. Одна связка хранит одну и ту же функцию во всех них.
  • Начните с того, что у вас уже есть. Импорт читает ваши существующие привязки из каждой игры; настройка при первом запуске сама находит ваши игры.
  • Ничего нельзя сломать навсегда. Каждый экспорт сначала делает резервную копию файлов игры, а Отменить последний экспорт возвращает их байт в байт. Каждое изменение в JoyPro сохраняется автоматически и может быть отменено, даже после перезапуска (история профиля).
  • Он говорит, что пойдёт не так. Проверка объясняет проблемы словами игры и исправляет их одним щелчком.
  • Он настраивается сам. Настроить всё за меня раскладывает важные функции на вашу ручку, РУД и педали. Вы просматриваете список и нажимаете Использовать эти кнопки и Записать в мою игру.
  • Меньше щелчков. Предложения, Автогруппировка, Автоназначение, мастер настройки и помощник JoyPro создают связки и привязки за вас; выученный «ваш стиль» повторяет то, как вы делали раньше.
  • Он замечает изменения. Когда вы меняете привязку внутри игры, JoyPro после закрытия игры спрашивает, перенести ли её в ваш профиль.
  • Ваш язык. Интерфейс говорит на 39 языках.
  • Больше, чем привязки. Изображения устройств и шпаргалки, HUD и оверлей для стрима, Force Feedback из телеметрии, виртуальный джойстик для игр, которые читают только одно устройство, имитация контроллера (виртуальный геймпад Xbox) для игр, которые знают только контроллер Xbox, база данных кабин, статистика того, на чём вы летаете.
  • Справка по каждой кнопке. F1 объясняет любую кнопку, туры указывают на настоящие кнопки, а «Простые слова» делают тексты короткими.
  • Не нужно искать дополнительные среды выполнения. Релиз — это один zip со всем внутри; без SlimDX, без сред выполнения C++.

Технические подробности

#Архитектура и качество

  • Разделение на движок и интерфейс. JoyPro 1 был одним WPF-приложением с логикой в коде окна. У JoyPro 2 есть движок (engine.exe, .NET Framework 4.8, чистый C#), который содержит всю логику профиля, импорта/экспорта и базы данных в виде 452 команд, и интерфейс на Avalonia (.NET 9), который запускает движок для каждого действия. Быстрые интерактивные команды идут в один постоянно работающий engine serve, поэтому интерфейс остаётся быстрым, не отказываясь от разделения. Всё, что делает интерфейс, можно выполнить скриптом (см. командную строку движка).
  • Отдельные процессы для постоянных задач: JoyPro.Ffb.exe (Force Feedback по телеметрии), JoyPro.VJoy.exe (передача на виртуальный джойстик), JoyPro.Tray.exe (отслеживание, пока интерфейс закрыт), каждый с бюджетом ресурсов и длительными тестами нагрузки, чтобы в фоне они оставались незаметными.
  • Тесты: 1,537 автоматических тестов (xUnit: логика движка, модели представлений, внеэкранная отрисовка страниц в светлой и тёмной теме), 88 частей дымового теста движка, которые запускают настоящий движок на тестовых папках, необязательный контроль качества с проверками инвариантов на реальных данных и сквозные прогоны в игре для игр, которые это поддерживают. Тесты работают в песочнице записи с проверкой отпечатка реальных папок, поэтому ни один тест не может затронуть настоящие папки игр.
  • Данные: списки команд игр строятся на ПК пользователя из установленной игры в %LOCALAPPDATA%\JoyPro2\GameData; JoyPro поставляет только свои собственные данные (каталог функций, каталог устройств, таблицы преобразования, база данных кабин).
  • Документация создаётся из исходного кода: таблица поддержки игр берётся из кода (engine games support), справка по командной строке — из engine --help, а этот сайт — из AXAML, моделей представлений и документации.
