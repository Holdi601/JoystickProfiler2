VTOL VR

Показать:

VTOL VR — боевой авиасимулятор только для VR: вы летаете, держа VR-контроллерами виртуальную ручку и РУД. Сама игра привязывает только три оси физического устройства — руль направления и два носочных тормоза — и хранит их в одном файле для всех ЛА. Полную поддержку HOTAS (ручка, РУД, каждый переключатель, для каждого ЛА и места) даёт бесплатный мод BYOJoystick. JoyPro обрабатывает обе части как две игры: VTOL VR (BYOJoystick mod) записывает файлы привязок мода, VTOL VR (native rudder and brakes) записывает собственный файл игры и её настройки управления.

Для начинающих

#Запуск за 3 шага

  1. Настроить всё за меня
    на странице «Старт»
  2. Использовать эти кнопки
    сначала посмотрите список
  3. Записать в мою игру
    держите VTOL VR закрытой

До: нажмите Установить BYOJoystick на карточке VTOL VR (один раз, см. ниже). Один раз запустите VTOL VR с подключёнными педалями и выйдите из Настройки кнопкой OK.

Потом: включите Hardware Control Rudder в настройках игры, иначе игра проигнорирует ваш руль направления.

Вы уже назначали кнопки в VTOL VR? Тогда страница «Старт» предложит Импортировать, затем заполнить пробелы. Ваши привязки останутся, а новые задачи получат только свободные кнопки. См. Быстрый старт: заставить мою ручку работать.

#Что JoyPro делает для VTOL VR

  • С BYOJoystick: каждая цель, которую предлагает мод (оси ручки и РУД, шасси, закрылки, оружие, средства противодействия, радар, огни, кнопки MFD и другое), для каждой машины и места — с ваших ручек, РУД и клавиатуры.
  • Без мода: собственные Руль направления, Wheel Brake L и Wheel Brake R игры, а также настройки её меню Controls (Hardware Control Rudder, мёртвые зоны VR, тактильная отдача).
  • Связки: одна связка — это одна функция; экспорт BYOJoystick записывает её в каждый файл места, у машины которого есть эта цель.

#Установка BYOJoystick (один раз)

  1. Откройте Старт и нажмите Установить BYOJoystick на карточке VTOL VR. Панель покажет, что это за мод, его официальный источник (Steam Workshop, исходный код на GitHub), его размер и есть ли на этом ПК VTOL VR Mod Loader и сам мод.
  2. Отметьте флажок, что вы прочитали, что такое BYOJoystick, и хотите установить его из Steam Workshop, затем нажмите Установить BYOJoystick. JoyPro сохранит резервную копию ваших файлов BYOJ и откроет Steam: установите Mod Loader, если Steam попросит, затем нажмите Subscribe на странице BYO Joystick. Steam скачает мод; JoyPro ничего из него не копирует.
  3. Нажмите Проверить снова: JoyPro найдёт мод и создаст по нему список команд VTOL VR.

#Импорт ваших привязок

Нажмите Импорт на карточке VTOL VR (BYOJoystick) или на карточке нативной части, затем Импортировать. Для BYOJoystick вариант Брать также клавиши клавиатуры переносит и ваши привязки клавиатуры.

#Создание и проверка связок

Создавайте связки так же, как для любой игры (порядок работы со связками); мастер настройки и автоназначение знают цели BYOJoystick. Затем запустите проверку на странице «Экспорт».

#Экспорт в VTOL VR

  1. Закройте VTOL VR. JoyPro отказывается записывать, пока игра работает (процесс VTOLVR).
  2. Откройте Экспорт и оставьте Заменить на моих устройствах вместе с Очистить и другие мои устройства, если вы настраиваете свои устройства в JoyPro.
  3. Нажмите Экспортировать на карточке VTOL VR (BYOJoystick) и, для педалей, на нативной карточке.
В игре: Что вы увидите в VTOL VR

В игре раздел Настройки показывает Hardware Control Rudder включённым, если это задано в вашем профиле, а Bindings перечисляет Руль направления, Wheel Brake L и Wheel Brake R с вашим устройством и его осью. Привязки BYOJoystick находятся в собственном окне мода, для каждого места в машине; его кнопка Загрузить заново читает файлы.

#Что вы делаете сами в VTOL VR

  • Один раз запустите VTOL VR с подключёнными педалями и выйдите из Настройки кнопкой OK. Тогда игра перечислит ваши устройства и создаст gameSettings.cfg; нативный экспорт записывает только устройства, которые игра перечислила, и никогда не создаёт файл настроек.
  • Hardware Control Rudder должен быть включён, иначе игра проигнорирует оси руля направления и тормозов. Включите его в игре или сохраните в JoyPro (Расширенные), чтобы его записал нативный экспорт.
  • BYOJoystick нужен VTOL VR Mod Loader из Steam; JoyPro только открывает страницы Steam.

#Частые ошибки

  • Руль направления не работает: Hardware Control Rudder выключен. Игра читает его при появлении машины.
  • Работает только один носочный тормоз или оба следуют за курком РУД: игра берёт тормоза с педалей, только когда привязан Wheel Brake L. Привяжите оба.
  • Носочный тормоз тормозит только на второй половине хода: игра читает тормоз в диапазоне от 0 до 1. Задайте диапазон оси этой связки как Positive (Расширенные); JoyPro предупреждает об этом случае.
  • Две одинаковые педали: игра хранит одну карту на модель устройства, поэтому обе управляют одним и тем же действием.
  • Привязка BYOJoystick пропала: при загрузке файла мод отбрасывает цели, которых нет у машины.
Расширенные

#Файлы, которые JoyPro читает и записывает

Файл Что это
<install>\SaveData\BYOJ_<seat>.xml привязки BYOJoystick одного места в технике: AV42C, FA26B, F45A, AH94Front, AH94Rear, T55Front, T55Rear, EF24GFront, EF24GRear
%APPDATA%\Boundless Dynamics, LLC\VTOLVR\SaveData\inputbindings.cfg собственные привязки игры: карты джойстика Rewired в текстовом файле; его синхронизирует Steam Cloud
%APPDATA%\Boundless Dynamics, LLC\VTOLVR\SaveData\gameSettings.cfg значения Settings > Controls (HARDWARE_RUDDER, ...); его синхронизирует Steam Cloud
<library>\steamapps\workshop\content\3018410\3276352374\BYOJoystick.dll установленный мод: только чтение, для его списка целей
<install>\VTOLVR_Data\level0 список действий Rewired игры: только чтение, для собственного списка команд игры

Устаревший файл <install>\SaveData\inputbindings.cfg никогда не записывается. Перед каждой записью делается резервная копия, а сама запись атомарна (временный файл, затем замена): игра заменяет повреждённый inputbindings.cfg пустым.

#Режимы экспорта в VTOL VR

Режим BYOJoystick (файл для каждого места) Собственный (inputbindings.cfg)

#Что никогда не затрагивается

  • Неподключённые устройства, игнорируемые при импорте устройства и устройство vJoy, в которое передаёт JoyPro.
  • BYOJoystick: входы, которые JoyPro не может прочитать, и кнопка-модификатор места, если ваш профиль не задаёт свою.
  • Собственная часть: карты кнопок, карты клавиатуры и мыши, поведение входов, карты калибровки, назначения контроллеров и игрок System. Экспорт BYOJoystick не записывает gameSettings.cfg.
  • Клавиатура, если вы не экспортируете привязки клавиатуры (только BYOJoystick).

#Места, оси, настройки

  • Детализация: BYOJoystick — для каждого места в технике (цель попадает в каждое место, где она есть); собственная часть игры глобальная.
  • Оси BYOJoystick: инверсия и одно число мода Мёртвая зона на привязку. На Joystick Pitch, Roll, Yaw и на Throttle, Power, Collective это не мёртвая зона, а отклонение, которое нужно HOTAS, чтобы забрать управление у другого члена экипажа в мультиплеере; на SOI Slew X/Y и Articulate Tilt оно отсекает малые значения без масштабирования; в остальных местах мод его не использует. Кривых нет. См. axis-curves.
  • Собственные оси игры: инверсия, а для носковых тормозов — диапазон оси (Full или Positive). Мёртвые зоны и кривые записать нельзя.
  • Модификаторы: BYOJoystick знает одну кнопку-модификатор на файл места (привязки, которым она нужна, действуют только пока она удерживается); у привязки клавиатуры может быть одна клавиша-модификатор. В собственной части игры их нет.
  • Настройки управления: Настройки > Настройки FFB игр, игра VTOL VR (control settings, VR haptics): Hardware Control Rudder, Thumb Control Rudder, Twist Rudder Deadzone, Thumbstick Deadzone, Thumbstick Mode, Toggle Grip, Flight Control Haptics, Overall Haptics. Собственный экспорт игры записывает их в gameSettings.cfg, даже если в профиле нет собственных привязок игры.
  • Force Feedback: в VTOL VR нет Force Feedback для джойстика; тактильная отдача — у VR-контроллеров.
  • Отслеживание: файлы BYOJ, а с собственной частью игры — gameSettings.cfg (отслеживание).
Технические подробности

#Внутри интеграции VTOL VR

Код: engine\Games\VtolVrIntegration.cs (BYOJoystick), VtolVrMod.cs (состояние установки, список целей), ClrMetadata.cs, VtolVrNativeIntegration.cs, engine\AxisModels\VtolVr.cs (byoj, vtolnative), engine\FfbModels\VtolVr.cs (настройки управления).

  • Формат BYOJoystick: XML-сериализация .NET, корень <Bindings> с <KeyboardBindings> (Target, Key, ModifierKey в виде имён Unity KeyCode) и <JoystickBindings> (Target, JoystickId, Input, RequiresModifier, Invert, Deadzone, POVDirection). Input: X Y Z RX RY RZ, S1 S2, PoV1..PoV4, B1..B128. Устройства — по GUID экземпляра DirectInput (JoystickId).
  • Собственный формат игры: текстовый файл с корнем RewiredSaveData и строками {key} = {value}; карта джойстика — это Rewired XML (объявлен как UTF-16 внутри файла UTF-8). Действия: 0 Rudder, 5 Wheel Brake L, 6 Wheel Brake R. Ключ карты — модель устройства: hardwareIdentifier = WindowsRawInput + строка продукта HID без пробелов + десятичный PID + GUID продукта, hardwareGuid нулевой для устройств, которых Rewired не знает. Элемент — это n-я ось устройства.
  • Списки команд: engine vtolvr refresh-db читает цели из установленного BYOJoystick.dll, не загружая и не запуская его (его метаданные и строковые литералы), затем ваши собственные BYOJ_*.xml; без мода списка нет. engine vtolvr-native refresh-db читает список действий Rewired из level0.
  • Команды: engine vtolvr mod (status, prepare --accept-license), engine vtolvr scan, engine vtolvr import, engine vtolvr export, engine vtolvr-native scan, engine vtolvr-native import, engine vtolvr-native export, настройки через engine ffb set --device * --game VTOLVR.

#Известные ограничения

  • Прогона в игре пока не было; BYOJoystick проверен с DLL-заменителем. Загружается ли мод в текущей версии игры, пока не подтверждено.
  • Собственная часть: порядок осей устройств, которых Rewired не знает, и точный идентификатор устройства взяты из кода игры, а не из файла, записанного игрой.
  • BYOJoystick: диагонали хаток, кнопка на цели-оси и ось на цели-кнопке пропускаются с предупреждением.
  • JoyPro не поставляет никакой части BYOJoystick; его список команд существует, только если мод установлен.
  • Тесты: engine\tests\smoke\vtolvr.ps1 (импорт туда и обратно, собственные значения, общие настройки игры, экспорт только настроек).
