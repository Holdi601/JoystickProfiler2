Microsoft Flight Simulator 2024

Показать:

MSFS 2024 хранит ваше управление в профилях, по одному на устройство и категорию (Airplanes и General), и запоминает для каждого устройства и ЛА, какой профиль используется. JoyPro читает эти профили в один собственный профиль и записывает ваши привязки обратно именно в те профили, которые использует симулятор, в версиях Steam и Microsoft Store. Для ЛА, которые симулятор ещё не настроил для устройства, JoyPro добавляет свои пресеты в виде небольшого пакета в папке симулятора Community2024, а там, где он не может записать профиль, оставляет вам файл для импорта в меню Controls симулятора.

Для начинающих

#Запуск за 3 шага

  1. Настроить всё за меня
    на странице «Старт»
  2. Использовать эти кнопки
    сначала посмотрите список
  3. Записать в мою игру
    симулятор должен быть закрыт

До: один раз подключите каждое устройство.

Затем: прочитайте поле Ваши профили MSFS 2024. Там указан файл импорта? Тогда импортируйте этот файл в симуляторе (см. Что вы делаете сами ниже).

Вы уже назначали кнопки в MSFS 2024? Тогда страница «Старт» предложит Импортировать, затем заполнить пробелы. Ваши привязки останутся, а новые задачи получат только свободные кнопки. См. Быстрый старт: заставить ручку работать.

#Что JoyPro делает для MSFS 2024

  • Импорт: профили, которые вы создали в меню Controls симулятора (Steam или Microsoft Store), попадают в ваш профиль — лётные привязки и привязки General (камеры, виды, активная пауза и так далее) вместе с настройками осей со страницы Sensitivity. Устройство, которое вы никогда не меняли в симуляторе, приносит пресет, который симулятор для него поставляет, если собственные записи симулятора показывают, что этот пресет используется.
  • Связки: одна связка — это одна функция. В MSFS 2024 связка может действовать для всех ЛА (по умолчанию) или только для отмеченных вами ЛА, как в DCS.
  • Экспорт: JoyPro записывает ваши привязки в профиль, который симулятор использует для каждого устройства и категории, записывает свой пакет пресетов для ЛА, которые симулятор ещё не настроил, и записывает файл импорта там, где не смог обновить ваш профиль.

#Импорт привязок MSFS 2024

  1. Откройте Старт и нажмите Импорт на карточке Microsoft Flight Simulator 2024.
  2. Для MSFS важны два параметра, оба выключены, пока вы их не отметите:
    • Импортировать и неподключённые устройства: MSFS хранит привязки всех устройств, которые когда-либо видел. Выкл.: только устройства, подключённые сейчас.
    • Импортировать и пресеты по умолчанию, которые симулятор может не использовать: для устройств, у которых записи симулятора не показывают использование поставляемого пресета. Это может добавить привязки, которых в симуляторе нет.
  3. Нажмите Импортировать (или Сначала посмотреть, чтобы увидеть, что есть в симуляторе, не меняя свой профиль).

Импортированные связки действуют для всех ЛА. Если привязка есть только в профилях некоторых ЛА, после импорта страница Связки показывает заметку с вариантами Ограничить этими ЛА для каждой связки, Ограничить все и Оставить для всех ЛА.

#Создание и проверка связок

На странице Связки действие MSFS 2024 показывает ЛА симулятора с галочками: если отмечены все ЛА, значит, для всех ЛА. Действие, которое есть только в некоторых дополнительных ЛА, пишет «только для:» с этими ЛА, и при его добавлении отмечаются только они. См. работу со связками, затем запустите Проверку на странице «Экспорт»: она раньше симулятора находит кнопку с двумя функциями.

#Экспорт в MSFS 2024

  1. Закройте MSFS 2024. JoyPro отказывается записывать, пока симулятор работает (в версии Microsoft Store — также пока работает его помощник запуска).
  2. Откройте Экспорт. В разделе Экспорт в игры два флажка относятся к MSFS 2024:
    • MSFS 2024: записывать в мои профили MSFS (вкл.): экспорт обновляет профиль, который симулятор использует для каждого устройства и категории, предварительно сделав резервную копию.
    • MSFS 2024: файлы импорта для каждого устройства (выкл.): файл импорта для каждого устройства и категории, а не только там, где JoyPro не смог записать ваш профиль.
  3. Оставьте Заменить на моих устройствах вместе с Очистить и другие мои устройства, если вы настраиваете устройства в JoyPro, и нажмите Экспортировать на карточке MSFS 2024.

После экспорта поле Ваши профили MSFS 2024 перечисляет каждый записанный JoyPro профиль с его ЛА и числом привязок. Если были записаны файлы импорта, второе поле называет их и предлагает Открыть папку.

В игре: Что вы видите в MSFS 2024

Запустите симулятор, откройте Settings > Controls, затем выберите устройство и категорию (Airplanes или General). Ваши привязки находятся в вашем собственном профиле под названиями действий симулятора; страница устройства (Hardware Settings под шестерёнкой устройства) показывает кривые осей, записанные JoyPro. В ЛА, который симулятор ещё не настроил для этого устройства, устройство начинает с пресета JoyPro.

#Что вы делаете сами в MSFS 2024

  • Ничего — для каждого профиля, отмеченного как обновлённый в Ваши профили MSFS 2024.
  • Файлы импорта: если экспорт указывает такой файл, откройте Settings > Controls, выберите устройство и категорию (Airplanes или General), щёлкните шестерёнку профиля (не пресета), выберите Импорт и укажите файл, который JoyPro записал для этого устройства и категории. Симулятор принимает файл только для того же устройства и категории. Если файл носит имя вашего профиля, симулятор спросит, перезаписать ли его: подтвердите, и в вашем профиле будут привязки JoyPro. Импортируйте файл снова, только когда экспорт сообщает, что он новый или изменился.
  • Перед первым экспортом один раз подключите каждое устройство: JoyPro нужен ID продукта устройства для его пресета.
  • Одному ЛА нужны другие привязки, чем остальным: дайте ему собственный профиль в симуляторе (Controls, когда загружен этот ЛА: сделайте копию профиля), затем снова выполните экспорт. Экспорт называет каждую связку, которую не смог разместить.
  • Вопрос облака Xbox: если симулятор или приложение Xbox спрашивает, какое сохранение оставить, оставьте сохранение этого ПК; другое удаляет привязки JoyPro (тогда выполните экспорт снова).

#Частые ошибки

  • «MSFS 2024 работает»: закройте симулятор; в версии Microsoft Store помощник запуска симулятора (gamelaunchhelper.exe) тоже должен завершиться.
  • В одном ЛА не хватает привязок: этот ЛА использует другой ваш профиль. Проверьте список Ваши профили MSFS 2024; строка с «import file» означает, что этот файл нужно импортировать в симуляторе.
  • Связка не записалась: она ограничена некоторыми ЛА, но профиль, который симулятор там использует, общий с другими ЛА. Предупреждение называет профиль и ЛА.
  • У устройства несколько профилей: импорт берёт тот, который указан в записях симулятора, иначе самый новый, и называет остальные. Выберите другой в Профиль игры в форме Другие игры на странице «Старт».
  • «WRONG DEVICE» при привязке в симуляторе: устройство, которое постоянно отправляет значения (некоторые ручки с Force Feedback), перехватывает сканирование симулятора. Это происходит при привязке в самом симуляторе, а не в JoyPro.
  • Reset to Defaults в симуляторе сбрасывает пресеты всех устройств и ЛА; JoyPro никогда не делает этого за вас.

#Файлы, которые JoyPro читает и записывает

Файл Что это
<Steam>\userdata\<id>\2537590\remote\inputprofile_<n> ваш собственный профиль (Steam), обычный XML без расширения; записывается на месте, Steam Cloud загружает его при следующей синхронизации
%LOCALAPPDATA%\Packages\Microsoft.Limitless_8wekyb3d8bbwe\SystemAppData\wgs\<user>\ сохранение Microsoft Store (containers.index, container.<n>, по одному blob на профиль); JoyPro записывает новый blob, новый файл контейнера и индекс
remote\profile_00 (Store: контейнер profile_00) записи устройств симулятора: какой профиль или пресет каждое устройство использует для каждого ЛА. Только чтение, никогда не записываются
<packages>\Community2024\joypro-input-profiles\InputProfiles\Categories\Airplane\JoyPro_<device>_<guid8>_2024_Planes.xml пресет JoyPro для устройства (лётные действия), с layout.json и manifest.json
...\Categories\Transversal\JoyPro_<device>_<guid8>_2024_Transversal.xml пресет JoyPro для привязок General устройства
%USERPROFILE%\Documents\JoyPro2\MSFS 2024 import files\<device>_<guid8>_Airplanes.xml / _General.xml файлы импорта в собственном формате профилей симулятора
<install>\Packages\fs-input-profiles, asobo-input-profiles-pc, fs-base\en-US.locPak пресеты, поставляемые Asobo, и названия меню: только чтение, для списка команд и пресетов по умолчанию
%LOCALAPPDATA%\JoyPro2\Ownership\MSFS, ...\Backups\MSFS данные JoyPro о принадлежности и резервные копии, никогда не в синхронизируемой папке

<packages> — это InstalledPackagesPath из %APPDATA%\Microsoft Flight Simulator 2024\UserCfg.opt (Store: %LOCALAPPDATA%\Packages\Microsoft.Limitless_8wekyb3d8bbwe\LocalCache\UserCfg.opt). Перед каждой записью вся папка сохранения Store или файл Steam попадает в набор резервных копий, поэтому Отменить последний экспорт возвращает сохранение.

#Режимы экспорта в MSFS 2024

Режимы работают для каждого профиля (то есть для каждой группы ЛА) и только в обрабатываемых контекстах.

Режим Что происходит в ваших профилях MSFS 2024
Только добавить Привязка записывается, только если никакое другое действие этого профиля не использует эту комбинацию входов; иначе она указывается как незаписанная. Ничего не удаляется.
Обновить, привязки игры сохранить Другое действие на вашей комбинации входов теряет её; всё остальное остаётся, в том числе старая комбинация действия (у действия их две: Primary и Secondary).
Обновить, мой профиль важнее Как выше, и каждое привязанное вами действие теряет свои другие комбинации, в том числе в профилях других подключённых устройств (эти профили тоже записываются).
Заменить на моих устройствах Профили подключённых устройств, которые записывает JoyPro, сохраняют только ваши привязки.
+ Очистить и другие мои устройства Никогда не очищает ни один из ваших собственных профилей MSFS 2024.

Связка для всех ЛА попадает в каждый профиль, названный в записях симулятора; связка, ограниченная отдельными ЛА, попадает только в профили, все ЛА которых отмечены. Ограниченные связки никогда не попадают в пакет пресетов или файлы импорта, потому что те действуют для всех ЛА.

#Что никогда не затрагивается

  • Контексты меню, карты мира и разработчика (MENU, MENU_*, WORLDMAP_*, DEBUG, DEVMODE*, EDITOR_*, MISSION_FLOW_TOOLS) — в любом режиме.
  • Профили клавиатуры, мыши и геймпада (GUID="{0}"): привязки клавиатуры в MSFS не записываются.
  • profile_00, пресеты, поставляемые Asobo, слоты пресетов для конкретных ЛА и все остальные контейнеры сохранения Store (лётные журналы, другие игры).
  • Неподключённые устройства, игнорируемые при импорте устройства и устройство vJoy, в которое передаёт JoyPro.

#ЛА, кривые, прочее

  • Детализация: для каждого устройства и категории (Airplanes, General) и для каждого профиля; симулятор выбирает профиль для каждого устройства и ЛА, JoyPro следует этому выбору.
  • Кривые осей: страница Sensitivity устройства, один набор на физическую ось: Sensitivity + и -, Neutral, Dead zone, Extremity dead zone, Reactivity, флаг «без кривой» и инверсия. Связка может дать одному действию свои значения (переопределение для отдельного действия в MSFS 2024). Связки на одной оси устройства делят её страницу: экспорт записывает значения первой связки и предупреждает. См. axis-curves.
  • Force Feedback: собственного у MSFS нет.
  • Запись телеметрии: через SimConnect, только чтение, с вашим собственным SimConnect.dll (JoyPro его не поставляет): в Steam-версии MSFS 2024 его нет, поэтому установите MSFS 2024 SDK или держите установленным MSFS 2020 (его копия тоже подходит).
  • HUD: HUD находит симулятор по его процессу и показывает его привязки.
  • Отслеживание: JoyPro отслеживает свой пакет, профили Steam и containers.index сохранения Store; после закрытия симулятора (сохранение Store ждёт 10 с после последней записи) он спрашивает, перенести ли ваши изменения из игры (отслеживание).
  • Повторный импорт: имена связок, группы и настройка осей возвращаются через метаданные JoyPro рядом с файлами (повторный импорт).
  • Параметры для экспертов (Другие игры на странице «Старт»): Профиль игры (выбрать один профиль, если у устройства их несколько), ЛА для экспорта (экспортировать также связки, ограниченные одним ЛА, для всех ЛА), Записывать в мои профили MSFS, Также записывать файлы импорта MSFS для каждого устройства, пробный прогон.
Технические подробности

#Внутри интеграции MSFS 2024

Код: engine\Games\MsfsIntegration.cs (один класс для обоих симуляторов), MsfsIntegration.UserProfiles.cs (прямая запись), MsfsIntegration.ImportFiles.cs, MsfsCommunityPackage.cs, MsfsUserProfiles.cs (чтение Steam и Store), WgsContainers.cs (сохранение Store), MsfsSimProfile.cs (записи в profile_00), MsfsSimDefaults.cs, MsfsProfileFile.cs (построчный редактор), MsfsGameData.cs, MsfsAircraft.cs, engine\AxisModels\Msfs.cs.

  • Формат: фрагмент XML (несколько элементов верхнего уровня): <Version>, <FriendlyName>, <Device DeviceName GUID ProductID CompositeID HWVer> с <Axes> и <Context ContextName> / <Action ActionName Flag> / <Primary> / <Secondary> / <KEY Information>code</KEY>. Профиль 2024 перечисляет все действия своих контекстов, непривязанные — как пустые <Action/>. Коды: кнопка N = N-1, хатка 256-259, L-ось X/Y/Z 1026/1042/1058, R-ось 770/786/802, ползунки 514/530. Флаги: 2 — цифровой, 4 — ось, 128 — инверсия, 1024 — без кривой чувствительности, 4096 — переопределение оси для отдельного действия. Заново выводятся только изменённые элементы <Action>.
  • Устройства: профиль называет своё устройство по GUID экземпляра DirectInput (GUID), поэтому для его чтения подключённое устройство не нужно. Симулятор сопоставляет пресет по USB product ID (hex): JoyPro использует тот, что симулятор записал в profile_00, иначе USB PID (vJoy отображается с product ID 0).
  • Какой профиль активен: для каждого устройства и ЛА записи в profile_00 содержат слот General и слот категории; собственный профиль там — это inputprofile_<n>, то есть имя файла в Steam и имя контейнера в Store.
  • Сохранение Store: записывается, только если индекс имеет известную структуру (версия 14, без флага конфликта, контейнер указан один раз в известном состоянии); тогда создаётся новый блоб container.<n+1>, индекс записывается последним (временный файл и замена), затем читается обратно, а старое поколение удаляется. При любой ошибке всё возвращается как было; при чём-либо неизвестном ничего не записывается, и привязки переносит файл импорта.
  • Список команд: engine msfs2024 refresh-db читает пресеты Asobo, все события полёта, названные в en-US.locPak, ваши профили General и распакованные пакеты дополнений (Community, Marketplace) с их ЛА; список ЛА берётся из списка контента симулятора. При новой установке список строится при первом импорте.
  • Команды: engine msfs2024 paths, engine msfs2024 catalog, engine msfs2024 scan, engine msfs2024 import (--game-profile, --include-disconnected, --include-sim-defaults, --limit-to-profile-aircraft, --replace), engine msfs2024 export (--mode, --nuke-untouched-devices, --dry-run, --aircraft <key>; --user-profiles false и --import-files как два флажка страницы «Экспорт»); связки для отдельных ЛА через engine relations aircraft set; отмена через engine backups restore; отслеживание через engine sync status и engine sync diff. Старое имя CLI engine msfs ... по-прежнему означает MSFS 2024.

#Известные ограничения

  • Слоты пресетов для конкретных ЛА не записываются (они приходят только с собственным пакетом ЛА); JoyPro никогда не записывает profile_00 (файл заканчивается контрольной суммой).
  • Пресет JoyPro доходит только до тех ЛА, для которых симулятор ещё не настроил устройство; в остальных привязки переносит ваш собственный профиль или файл импорта.
  • Не более двух комбинаций входов на действие; о третьей сообщается. Половины осей, диагонали хаток и вторая хатка не читаются и не записываются. Модификаторы: только кнопки того же устройства.
  • Упакованные пакеты дополнений (.fsarchive) пропускаются; пути сохранений Store длиннее 260 символов не читаются.
  • Облачная копия (Steam Cloud, облако Xbox) может перекрыть запись JoyPro, если другой ПК сохранил позже.
  • Тесты: engine\tests\smoke\msfs.ps1, smoke\msfsuserprofiles.ps1, gui\JoyPro.Gui.Tests\MsfsProfileImportTests.cs (сохранения Steam и Store, профили для отдельных ЛА, откат), MsfsStoreWatcherEndToEndTests; в симуляторе tools\e2e\games\Msfs2024Settings.ps1 (пресеты, оси, кнопки и кривая для каждого действия в Controls).
