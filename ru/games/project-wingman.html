Project Wingman

Показать:

Project Wingman — аркадная игра о воздушных боях на Unreal Engine 4. Она читает несколько устройств DirectInput одновременно и хранит привязки в простом Input.ini, каждая названа по устройству и его месту в списке устройств игры; кривые и мёртвые зоны хранятся в сохранении. JoyPro читает и то и другое в ваш профиль и записывает обратно. Клавиатура, мышь, геймпад и хатки остаются такими, как в игре.

Для начинающих

#Запуск за 3 шага

  1. Настроить всё за меня
    на странице «Старт»
  2. Использовать эти кнопки
    сначала посмотрите список
  3. Записать в мою игру
    Project Wingman должна быть закрыта

До: запустите игру один раз, затем закройте её. Отключите для игры Steam Input.

Затем: ваши привязки находятся в Элементы управления игры. Добавили или убрали контроллер? Выполните экспорт снова.

Вы уже назначали кнопки в Project Wingman? Тогда страница «Старт» предложит Импортировать, затем заполнить пробелы. Ваши привязки останутся, а новые задачи получат только свободные кнопки. См. Быстрый старт: заставить ручку работать.

#Что JoyPro делает для Project Wingman

  • Импорт: каждая привязка джойстика лётных действий (тангаж, крен, рыскание, тяга, две оси обзора и кнопки) попадает в ваш профиль на ваших настоящих устройствах вместе с инверсией, кривой и мёртвой зоной.
  • Связки: «Fire missile» в Project Wingman может быть той же связкой, что и сброс оружия в ваших других играх.
  • Экспорт: JoyPro записывает ваши привязки в Input.ini, а кривые и мёртвые зоны — в сохранение.

#Импорт привязок Project Wingman

  1. Если вы ещё ни разу не запускали игру, запустите её один раз, чтобы появилась её папка.
  2. Откройте Старт. Если карточка Project Wingman просит список команд, нажмите Создать список: JoyPro читает лётные действия из собственных файлов игры.
  3. Нажмите Импорт на карточке, оставьте Добавить в мой профиль (рекомендуется) и нажмите Импортировать.

#Создание и проверка связок

Объедините действия Project Wingman с вашими другими играми на странице Связки (работа со связками), затем запустите Проверить на странице «Экспорт»: проверка находит кнопку, которая делает в игре две вещи.

#Экспорт в Project Wingman

  1. Закройте Project Wingman. JoyPro отказывается записывать, пока она работает.
  2. Откройте Экспорт и отметьте карточку Project Wingman.
  3. Оставьте Заменить на моих устройствах вместе с Очистить и другие мои устройства или выберите Обновить, привязки игры сохранить, если вы привязываете и в игре. Нажмите Экспортировать на карточке.
В игре: Что вы видите в Project Wingman

Откройте в игре Элементы управления. KEY BINDINGS и AXIS BINDINGS показывают ваши привязки в следующем свободном слоте каждой строки, названные по устройству без пробелов и его номеру, например «VJOYDEVICE 8 BUTTON 24» или «VJOYDEVICE 8 AXIS 1», с отмеченным флажком Инверсия там, где вы инвертировали. CURVES + DEADZONES показывает CURVE и DEADZONE, которые JoyPro записал для каждой оси.

#Что вы делаете сами в Project Wingman

  • Выполняйте экспорт снова после добавления или удаления контроллера. Игра нумерует устройство по его месту в своём списке устройств, а это место меняется, когда контроллер появляется или пропадает. JoyPro вычисляет его по устройствам, подключённым во время экспорта.
  • Хатки: игра не умеет привязывать хатку. Задайте Hat Function 1 / 2 (WEAPON или VIEW) в Controls > Miscellaneous.
  • Отключите для игры Steam Input; геймпад Steam Input появляется как дополнительное устройство.

#Частые ошибки

  • Привязки указывают на не то устройство: после экспорта был добавлен или убран контроллер. Выполните экспорт снова с обычными подключёнными устройствами. Импорт предупреждает, если номер устройства сдвинулся.
  • Привязка хатки отклонена: так задумано, см. Hat Function выше.
  • РУД тормозит в нижней половине: «Thrust Axis» в Project Wingman — центрированная ось: выше центра она ускоряет, ниже — тормозит.
Расширенные

#Файлы, которые JoyPro читает и записывает

Файл Что это
%LOCALAPPDATA%\ProjectWingman\Saved\Config\WindowsNoEditor\Input.ini привязки, раздел [/Script/Engine.InputSettings]: строки ActionMappings=(...) и AxisMappings=(...)
%LOCALAPPDATA%\ProjectWingman\Saved\SaveGames\savegame.sav кривые и мёртвые зоны для каждого действия оси (<Axis>Curve, <Axis>Deadzone) и функции хаток
<install>\ProjectWingman\Content\Paks\pakchunk0-WindowsNoEditor.pak только чтение: DefaultInput.ini, привязки игры по умолчанию и список действий
...\Input.ini.joypro-meta.json данные JoyPro об экспортированных привязках (имена, группы, настройка осей) для следующего импорта

Игра записывает Input.ini в тот момент, когда в её меню меняется привязка, и только изменённые вами списки; остальные берутся из значений по умолчанию pak-файла. Поскольку записанный список заменяет значения по умолчанию, JoyPro сначала записывает значения по умолчанию для отсутствующего списка. Steam Cloud синхронизирует папку сохранений.

#Режимы экспорта в Project Wingman

Удаляются только назначения джойстика для действий полёта из каталога; клавиатура, геймпад, мышь, строки меню и неподключённые устройства остаются.

Режим Что происходит
Только добавить Привязка на входе, который игра использует для другого действия полёта, не записывается (помечается «Не записано в игру»); собственная форма привязки в игре (Invert) остаётся.
Обновить, привязки игры сохранить Также удаляет назначение игры на входе, который профиль отдаёт другому действию; остальные назначения действия остаются.
Обновить, мой профиль важнее Также удаляет остальные назначения джойстика у каждого действия, которое привязывает профиль, так что перенос переносит полностью.
Заменить на моих устройствах Экспортированные устройства теряют свои остальные назначения джойстика (игра только о полётах).
+ Очистить и другие мои устройства То же самое на остальных подключённых устройствах.

#Что никогда не затрагивается

  • Назначения клавиатуры, мыши и геймпада, строки меню, хатки.
  • Неподключённые устройства, игнорируемые при импорте устройства и устройство vJoy, в которое передаёт JoyPro.
  • Все остальные строки Input.ini (порядок и концы строк сохраняются) и все остальные байты savegame.sav.

#Кривые, мёртвые зоны, другие настройки

  • Для каждого действия оси, для всех устройств вместе: CURVE (в меню от 0.00 до 2.00, 1.00 = прямая) и DEADZONE (от 0 до 100 %) для тангажа, крена, тяги, рыскания и двух осей обзора. Значения игры по умолчанию: тангаж и крен 25 %, обзор 10 %, тяга и рыскание 0 %.
  • Инверсия для каждой привязки (флажок Invert в слоте).
  • Формула игры неизвестна. Предпросмотр JoyPro предполагает масштабированную мёртвую зону и кривую как показатель степени (пока не подтверждено).
  • Глобально: профилей ЛА нет. Модификаторов нет (в игре их нет), Force Feedback нет.
  • Отслеживание: Input.ini и savegame.sav проверяются после закрытия игры (отслеживание).
  • HUD: пока игра работает, HUD называет действие каждой нажатой кнопки.
Технические подробности

#Внутри интеграции Project Wingman

Код: engine\Games\ProjectWingmanIntegration.cs, engine\Games\ProjectWingmanSaveGame.cs, engine\AxisModels\ProjectWingman.cs (модель осей projectwingman).

  • Ключи: Joystick_<name>_<place>_Axis<n>, ..._Button<n>. <name> — это имя продукта DirectInput без пробелов (VPforce Rhino FFB Joystick превращается в VPforceRhinoFFBJoystick), а не строка HID. <place> — место устройства в списке игры (Controls > Miscellaneous), то есть порядок DirectInput в обратном направлении; геймпадов XInput в этом списке нет. Axis<n> считает имеющиеся оси устройства с 0 в порядке X Y Z Rx Ry Rz Slider Slider; Button<n> считает с 0. Ключ с запятой в имени заключается в кавычки.
  • Инверсия = Scale=-1.000000.
  • Значения по умолчанию: ключи Android_* из значений по умолчанию pak-файла сохраняются, потому что меню показывает один слот на назначение, а эти ключи — пустые слоты.
  • savegame.sav: Unreal GVAS; FloatProperty <Axis>Curve (половина значения в меню) и <Axis>Deadzone (0..1), правятся на месте или добавляются перед завершающим None. Контрольной суммы нет.
  • Список команд: engine pw refresh-db читает DefaultInput.ini из pak-файла и ваш Input.ini: 6 осей и 14 кнопок.
  • Команды: engine pw paths, engine pw catalog, engine pw scan, engine pw import, engine pw export --mode clean|add|merge|merge-overwrite --nuke-untouched-devices --dry-run.

#Известные ограничения

  • Номер устройства меняется вместе с вашими контроллерами: после смены оборудования выполните экспорт снова.
  • Хатки и модификаторы отклоняются.
  • Формула кривой — рабочее предположение.
  • Один полный прогон теста в игре ещё не выполнен; экспорт и импорт в игре проверены.
  • Тесты: engine\tests\smoke\projectwingman.ps1 (тестовые данные реальной формы); в игре tools\e2e\games\ProjectWingmanSettings.ps1 (случайные оси, кнопки, инверсия, кривая и мёртвая зона; страницы управления читаются обратно; папки конфигурации и сохранений восстанавливаются).
