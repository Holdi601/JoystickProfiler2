Microsoft Flight Simulator 2020

Показать:

MSFS 2020 хранит один профиль управления на устройство, который используется для всех ЛА. В версии Steam каждый профиль — небольшой XML-файл в папке Steam remote симулятора; JoyPro читает эти файлы в ваш профиль и записывает ваши привязки обратно в них, на месте. Профили версии Microsoft Store импортируются, но не записываются. В отличие от MSFS 2024 здесь нет пакета пресетов, нет файла импорта и нет профиля для каждого ЛА.

Для начинающих

#Запуск за 3 шага

  1. Настроить всё за меня
    на странице «Старт»
  2. Использовать эти кнопки
    сначала посмотрите список
  3. Записать в мою игру
    симулятор должен быть закрыт

До: один раз создайте в симуляторе профиль для каждого устройства (Settings > Controls). JoyPro записывает только версию Steam; версию Microsoft Store можно только импортировать.

Затем: запустите симулятор. Ваши привязки находятся в Settings > Controls, в каждом ЛА.

Вы уже назначали кнопки в MSFS 2020? Тогда страница «Старт» предложит Импортировать, затем заполнить пробелы. Ваши привязки останутся, а новые задачи получат только свободные кнопки. См. Быстрый старт: заставить ручку работать.

#Что JoyPro делает для MSFS 2020

  • Импорт: профиль каждого подключённого устройства (Steam или Microsoft Store) попадает в ваш профиль: лётные привязки, привязки General (камеры, виды, пауза) и настройки осей со страницы Sensitivity.
  • Связки: одна связка — это одна функция. Связка действует для всех ЛА, потому что в MSFS 2020 один профиль на устройство.
  • Экспорт: JoyPro редактирует профили устройств в папке remote версии Steam. Симулятор читает их при следующем запуске.

#Импорт привязок MSFS 2020

  1. Откройте Старт и нажмите Импорт на карточке Microsoft Flight Simulator 2020.
  2. Импортировать и неподключённые устройства (выкл.): MSFS хранит профили всех устройств, которые когда-либо видел; выкл. — только устройства, подключённые сейчас. Импортировать и пресеты по умолчанию, которые симулятор может не использовать (выкл.) добавляет пресет, который симулятор поставляет для устройства без собственного профиля, даже если неизвестно, использует ли его симулятор.
  3. Нажмите Импортировать или Сначала посмотреть, чтобы увидеть, что есть в симуляторе, не меняя свой профиль.

#Создание и проверка связок

Создавайте связки на странице Связки, как для любой игры (см. работу со связками), затем запустите Проверку на странице «Экспорт». Здесь проверка не считает ошибкой РУД самолёта и шаг-газ вертолёта на одной оси: в MSFS 2020 нет отдельных списков ЛА.

#Экспорт в MSFS 2020

  1. Закройте MSFS 2020. JoyPro отказывается записывать, пока симулятор работает.
  2. Откройте Экспорт, оставьте Заменить на моих устройствах вместе с Очистить и другие мои устройства, если вы настраиваете устройства в JoyPro, и нажмите Экспортировать на карточке MSFS 2020.
  3. Запустите симулятор. Папка remote — это папка Steam Cloud, поэтому Steam синхронизирует изменённые файлы.
В игре: Что вы видите в MSFS 2020

Откройте Settings > Controls и выберите своё устройство: ваши привязки находятся в профиле устройства под названиями действий симулятора, а страница Sensitivity устройства показывает кривые осей, записанные JoyPro. Один и тот же профиль используется во всех ЛА.

#Что вы делаете сами в MSFS 2020

  • Один раз создайте в симуляторе профиль для каждого устройства (Settings > Controls). JoyPro редактирует только существующие профили; для устройства без профиля экспорт пишет «сначала создайте его в симуляторе».
  • Версия Microsoft Store: JoyPro импортирует ваши профили, но не может их записать. Для экспорта используйте версию Steam или задайте привязки в симуляторе.
  • Связки, ограниченные отдельными ЛА: MSFS 2020 не может их разделить. В форме Другие игры на странице «Старт» пункт ЛА для экспорта экспортирует и связки, ограниченные одним ЛА, — для всех ЛА.

#Частые ошибки

  • «MSFS 2020 работает»: закройте симулятор и снова выполните экспорт.
  • Симулятор показывает старые привязки: Steam Cloud вернул более старую копию. Закройте симулятор и снова выполните экспорт.
  • У устройства несколько профилей: JoyPro использует тот, что выбран в Профиль игры в форме Другие игры, или единственный; иначе устройство пропускается с предупреждением, в котором перечислены имена.
  • Не хватает привязки: у действия не больше двух комбинаций входов (Primary и Secondary); о третьей сообщается, и она пропускается.
Расширенные

#Файлы, которые JoyPro читает и записывает

Файл Что это
<Steam>\userdata\<id>\1250410\remote\inputprofile_<n> один профиль устройства, XML без расширения; записывается на месте (сначала резервная копия .jpbak)
<Steam>\userdata\<id>\1250410\remote\profile_00 двоичный индекс профилей устройств симулятора: только чтение, никогда не записывается
%LOCALAPPDATA%\Packages\Microsoft.FlightSimulator_8wekyb3d8bbwe\SystemAppData\wgs\<user>\ сохранение Microsoft Store: только чтение (импорт и сканирование)
<install>\Input\*.xml, fs-base\en-US.locPak пресеты, поставляемые с симулятором, и названия его меню: только чтение
%LOCALAPPDATA%\JoyPro2\Ownership\MSFS, ...\Backups\MSFS данные JoyPro о принадлежности и резервные копии, никогда не в папке Steam

Папка Steam remote — это папка Steam Cloud. Правятся только существующие файлы inputprofile_*: profile_00 симулятора называет конкретные файлы, поэтому новый файл не был бы подхвачен.

#Режимы экспорта в MSFS 2020

Режим Что происходит в профилях устройств
Только добавить Привязка записывается, только если в профиле нет другого действия на этой комбинации входов; иначе она указывается в «Binds Not Written, Button Taken In The Game». Ничего не удаляется.
Обновить, привязки игры сохранить Другое действие на вашей комбинации теряет её; всё остальное остаётся, в том числе старая комбинация действия.
Обновить, мой профиль важнее Как выше, и каждое привязанное вами действие теряет свои другие комбинации в профилях подключённых устройств.
Заменить на моих устройствах Профили подключённых устройств, которые привязывает JoyPro, сохраняют только ваши привязки.
+ Очистить и другие мои устройства Профили подключённых устройств без привязки в вашем профиле очищаются.

#Что никогда не затрагивается

  • Контексты меню, карты мира и разработчика (MENU, MENU_*, WORLDMAP_*, DEBUG, DEVMODE*, EDITOR_*, MISSION_FLOW_TOOLS) — в любом режиме.
  • Профили клавиатуры, мыши и геймпада (GUID="{0}"): привязки клавиатуры в MSFS не записываются.
  • Профили неподключённых устройств, profile_00, сохранение Store, игнорируемые при импорте устройства и устройство vJoy, в которое передаёт JoyPro.

#Кривые и прочее

  • Детализация: один профиль на устройство, для всех ЛА.
  • Кривые осей: страница Sensitivity устройства, один набор на физическую ось: Sensitivity + и -, Neutral, Dead zone, Extremity dead zone, Reactivity, флаг «без кривой» и инверсия. В MSFS 2020 нет переопределения для отдельного действия: связка, которая его запрашивает, получает страницу устройства и предупреждение. Предпросмотр кривой совпадает с симулятором (измерено в MSFS 2020). Область настройки family:msfs охватывает оба симулятора; см. axis-curves.
  • Force Feedback: собственного у MSFS нет.
  • Запись телеметрии: через SimConnect, только чтение, с SimConnect.dll из папки установки симулятора (или из MSFS SDK; JoyPro его не поставляет).
  • HUD: HUD находит симулятор по его процессу (FlightSimulator) и показывает его привязки.
  • Отслеживание: JoyPro отслеживает файлы inputprofile_* и containers.index сохранения Store и спрашивает после закрытия симулятора (отслеживание).

#Чем отличается от MSFS 2024

MSFS 2020 MSFS 2024
Цель экспорта профили Steam на месте ваши собственные профили (Steam и Store), пакет пресетов JoyPro, файлы импорта
Версия Microsoft Store только импорт импорт и запись
Профили один на устройство на устройство и категорию, выбираются для каждого ЛА
Связки, ограниченные отдельными ЛА только с ЛА для экспорта (тогда для всех ЛА) записываются в профили этих ЛА
Список действий в профиле только привязанные действия все действия его контекстов
Переопределение оси для отдельного действия нет да
Технические подробности

#Внутри интеграции MSFS 2020

Код: engine\Games\MsfsIntegration.cs (один класс для обоих симуляторов, sim == 2020), MsfsProfileFile.cs (построчный редактор), MsfsUserProfiles.cs (чтение Steam и Store), MsfsSimDefaults.cs, MsfsGameData.cs, MsfsAircraft.cs, engine\AxisModels\Msfs.cs.

  • Формат: фрагмент XML (читается в режиме фрагмента): <Version>, <FriendlyName>, <Device DeviceName GUID ProductID>, <Axes> с <Axis AxisName AxisSensitivy AxisDeadZone ...> (имена атрибутов с опечатками — это имена симулятора), <Context ContextName> / <Action ActionName Flag> / <Primary> / <Secondary> / <KEY Information>code</KEY>. Освобождённое действие удаляется; новое действие попадает в тот контекст, который у него есть в других профилях папки, иначе в контекст из каталога, иначе в PLANE (с предупреждением).
  • Устройства: GUID — это GUID экземпляра DirectInput, поэтому для чтения подключённое устройство не нужно; ProductID — десятичный USB product ID. Коды: кнопка N = N-1, хатка 256-259, оси 1026/1042/1058, 770/786/802, ползунки 514/530; последний KEY комбинации — основной вход, другие кнопки того же устройства — модификаторы.
  • Список команд: engine msfs2020 refresh-db читает пресеты симулятора (<install>\Input, его официальные пакеты) и все лётные события, названные в en-US.locPak; начало у него общее со списком MSFS 2024.
  • Команды: engine msfs2020 paths, engine msfs2020 catalog, engine msfs2020 scan, engine msfs2020 import (--game-profile, --include-disconnected, --include-sim-defaults), engine msfs2020 export (--mode, --nuke-untouched-devices, --dry-run, --aircraft <key>); отмена с помощью engine backups restore.
  • Старые профили: профили, сохранённые, когда в JoyPro была одна игра MSFS (MSFS:<action>), при загрузке получают узел для каждого симулятора.

#Известные ограничения

  • Версия Microsoft Store доступна только для чтения; экспорт с её папкой сохранения в качестве пути отклоняется.
  • Новые файлы inputprofile_* не создаются; устройству нужен профиль, созданный в симуляторе.
  • Steam Cloud может вернуть более старый профиль.
  • Половины осей, диагонали хаток и вторая хатка не читаются и не записываются; не более двух комбинаций на действие.
  • Поставляемые пресеты MSFS 2020 не проверялись на настоящей установке, поэтому пресет 2020 должен также содержать имя устройства, чтобы считаться значением по умолчанию.
  • Тесты: engine\tests\smoke\msfs.ps1 (страница Sensitivity, переопределения, флаги, конфликты, слияние); в симуляторе tools\e2e\games\MsfsCurves.ps1 (привязки, страница Sensitivity, кнопки и кривые осей в полёте, считанные обратно через SimConnect).
