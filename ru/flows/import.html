Основные сценарии

Импорт игры

Показать:

Импорт читает настройки управления, сохранённые игрой, и превращает их в профиль JoyPro: одна связка на функцию с её кнопкой или осью. Это самый быстрый старт: всё, что вы уже настроили в своих играх, попадает в профиль, и с этого момента JoyPro хранит это в одном месте.

Для начинающих

#Импорт в три клика

  1. Откройте Старт (первая кнопка в нижней панели). В разделе Ваши игры у каждой игры, которую JoyPro нашёл на вашем ПК, есть карточка с изображением. Нажмите Импорт у игры, в которую вы играете чаще всего.
  2. JoyPro спрашивает, как:
    • Добавить в мой профиль (рекомендуется) сохраняет то, что у вас есть, и добавляет привязки игры.
    • Начать заново с этой игры заменяет ваши связки тем, что есть в игре (JoyPro сначала сохраняет копию вашего профиля).
    • Брать также клавиши клавиатуры переносит и лётные команды на клавиатуре. Привязки устройств берутся всегда.
    • Для DCS: Все мои ЛА DCS или снимите флажок и выберите ЛА.
  3. Нажмите Импортировать. Через мгновение карточка сообщит «Готово: в вашем профиле теперь 214 связок (180 привязано)», а Мои связки откроет их. Сначала посмотреть вместо этого показывает, что есть в игре, ничего не меняя.

Профиль не открыт? JoyPro создаст его для вас и с этого момента будет сохранять автоматически (кнопки «Сохранить» нет: каждое изменение сохраняется и может быть отменено, в том числе после перезапуска).

#Что меняется в игре?

Ничего. Импорт только читает файлы игры. Игра сохраняет свои привязки ровно такими, какие они есть, будете вы потом экспортировать или нет.

#Импортировать, а потом дать JoyPro заполнить пробелы

На странице «Старт» карточка «Настройте свои устройства» перечисляет игры, в которых вы сами делали привязки. Импортировать, затем заполнить пробелы сначала импортирует такую игру. Затем Заполнить пробелы сейчас... ставит важные функции на кнопки, которые ещё свободны. Ваши собственные привязки остаются. Для игр, которые уже есть в вашем профиле, карточка предлагает Заполнить пробелы....

#Перед первым импортом: список команд

JoyPro нужно знать команды каждой игры (их названия и id). Он один раз создаёт этот список из вашей собственной установки. Если списка нет, страница «Старт» показывает Создать список (или Создать все недостающие списки); после обновления игры её карточка предлагает Обновление. Это занимает от нескольких секунд до нескольких минут (DCS читает каждый модуль).

Расширенные

#Параметры и что они делают

Параметр По умолчанию Эффект
Добавить в мой профиль / Начать заново Добавить «Добавить» объединяет с открытым профилем; «Начать заново» заменяет его связки после подтверждения и создания копии профиля.
Брать также клавиши клавиатуры ваш последний выбор Команды полёта, привязанные к клавишам, тоже импортируются.
Импортировать и неподключённые устройства вкл. Устройства, которые сейчас не подключены, тоже импортируются (полезно для ручки, которую вы подключите позже). Выкл.: они пропускаются и подсчитываются.
Считать устройства с одинаковым именем одним устройством вкл. Windows время от времени даёт устройству новый ID; его старые и новые файлы читаются как одно устройство с подключённым ID. Два одинаковых устройства, подключённые одновременно, остаются раздельными.
Включая стандартные (DCS, экспертная форма) вкл. Импортируется каждая привязка по умолчанию, активная в DCS для импортируемого устройства, чтобы импорт, а затем экспорт с «Заменить» + «Очистить и другие» оставлял DCS таким, каким он был. Ваши собственные привязки побеждают привязку по умолчанию на том же входе.
Импорт инверсии / ползунка / изгиба / мёртвой зоны / насыщения (экспертная форма) выкл. Берёт значения, заданные в игре, для привязок, которые JoyPro не экспортировал сам. Привязка, экспортированная JoyPro, получает свою настройку осей обратно и без этого.
DCS: пропускать ЛА *_easy выкл. Упрощённые копии ЛА (easy mode) пропускаются.

Расширенный импорт (страница «Старт», под карточками, и страница «Расширенные») предлагает все параметры движка для каждой игры с кнопками Сканировать (предпросмотр), Импорт и Экспорт. Каждый выбор запоминается для следующего импорта.

#Имена, группы и модификаторы возвращаются

Файл игры хранит только устройство, вход и, может быть, кривую. Экспорт JoyPro сохраняет рядом свои данные, а импорт читает их обратно:

Игра Данные JoyPro Восстанавливается
DCS <aircraft>\joystick\<device>.jp, modifiers.lua имя связки, группы (по порядку), модификаторы с именами, инверсия, ползунок, мёртвая зона, насыщение, кривая
IL-2 Great Battles data\input\jp.actions имя, группы, псевдоним, модификаторы, точная настройка осей
Игры из реестра (X-Plane, Elite, X4, Arma, MSFS, War Thunder, BMS ...) <config>.joypro-meta.json имя, группы, псевдоним, модификаторы, настройка осей
Star Citizen actionmaps.jp имена

Побеждает текущее состояние игры: кривая, которую вы изменили в DCS после экспорта, сохраняется. Привязки, которые JoyPro никогда не экспортировал, получают имя, составленное из действия игры, и группы DCS, IL2 или GENERATED + игра.

#Две защиты

  • Изменения, ещё не экспортированные. Если вы изменили привязки в JoyPro и не экспортировали их в эту игру, импорт вернул бы старые привязки. JoyPro сначала спрашивает.
  • Уже импортировано? Если игра уже есть в профиле, изменения, которые вы потом сделаете в игре, приходят через отслеживание игр (оно спрашивает после закрытия игры); повторный импорт по-прежнему делается одним щелчком.
В игре: Что импорт читает в каждом виде игр

Импорт никогда не записывает в папку игры. Что он читает:

  • DCS: привязки каждого ЛА и устройства, ваши модификаторы, а с «Включая стандартные» — привязки по умолчанию, которые есть у DCS для каждого устройства.
  • IL-2 Great Battles / Korea: раскладку клавиш и отклик осей.
  • Star Citizen: привязки клавиш ветки (LIVE, PTU ...) вместе с привязками джойстика по умолчанию на js1.
  • Игры с пехотой или техникой (War Thunder, Arma, Reforger, WARDOGS ...): только лётные действия; всё остальное игнорируется, а не удаляется.
  • MSFS: профили ввода симулятора (Steam или версия из Microsoft Store) и, по запросу, пресеты симулятора по умолчанию.

Устройства, которые игра не может различить (в некоторых играх — два устройства одной модели), и привязки к половине оси (Elite) пропускаются и называются в результате.

Технические подробности

#Как это устроено внутри

  1. GUI. StartImportWizard → RunImportWizardAsync (MainWindowViewModel.GameHub.cs). Он вызывает AskAboutUnexportedChangesAsync (движок sync pending), подтверждает «Начать заново» и сохраняет копию профиля (BackupProfileBeforeChange("before-import")), затем вызывает импорт игры: ImportDcsAsync, ImportIl2Async, ImportStarCitizenAsync или ImportRegistryGameAsync. Сначала посмотреть запускает то же самое с scan (PreviewImportWizardAsync) и открывает панель «Вывод».
  2. Движок. Для DCS: engine dcs import [--path <Saved Games\DCS>] --merge --include-defaults [--plane <a> --plane <b>] --include-keyboard true|false --ignore-easy-planes false --only-connected false --merge-same-name true. Импортёр читает каждый файл устройства, сопоставляет устройство по GUID экземпляра DirectInput и имени, сопоставляет каждый id команды со списком команд игры (DB\<game> в %LOCALAPPDATA%\JoyPro2\GameData) и строит одну связку на функцию и вход. Исправления при загрузке (--load-corrections, --correction-mode) переназначают переименованные id команд с оценкой уверенности.
  3. Профиль. Связки объединяются по имени и по одинаковому входу; модификаторы создаются из modifiers.lua (DCS) или из настроек shift в игре. Профиль сохраняется атомарно, и каждое сохранение — это версия в <data>\ProfileHistory (отмена работает и после перезапуска).
  4. Отслеживание. Импорт игры без записи синхронизации запоминает файлы игры, чтобы изменения, которые вы потом сделаете в игре, были замечены (<data>\Sync\<game>.json).

#Какие файлы читаются

Игра Файлы
DCS Saved Games\DCS\Config\Input\<aircraft>\{joystick,keyboard}\*.diff.lua и modifiers.lua, плюс чистые профили, которые JoyPro построил из вашей установки DCS
IL-2 Great Battles / Korea data\input\*.actions и отклики осей
Star Citizen actionmaps.xml ветки
MSFS удалённая папка Steam или сохранение Microsoft Store

Параметры GUI в виде параметров движка: «Добавить» --merge, клавиатура --include-keyboard true, неподключённые устройства --only-connected false, одинаковое имя --merge-same-name true, упрощённые ЛА --ignore-easy-planes true. Защита от ещё не экспортированных изменений — engine sync pending.

Команды движка: engine dcs import, engine dcs scan, engine il2 import, engine starcitizen import и engine <game> import для каждой игры из реестра (например, engine warthunder import, engine msfs2024 import). Правила повторного импорта: повторный импорт. Тесты: engine\tests\smoke\dcsincludedefaults.ps1, engine\tests\smoke\roundtrip.ps1, gui\JoyPro.Gui.Tests\ImportSettingsPersistTests.cs.
