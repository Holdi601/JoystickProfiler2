Release notes

JoyPro 2.6.4

From docs/releases/v2.6.4.md in the repository (generated, always the current text).

#New

  • See what a device still lacks in a game. Tick a game or an aircraft under Games and a new chip appears next to Bound and Not bound, e.g. No action in Falcon BMS (4). Click it: the list shows the relations that have no action there yet. Tick a device under Devices too and you see what that device still lacks, without comparing lists by eye. Add an action and the count drops at once; the relation leaves the list when you open the next one. It works with Sort and the search, stays on after a restart, and the Binds page has it too.
  • The axis response speaks DCS's numbers. For DCS, dead zone, saturation X/Y and the user curve points now read 0 .. 100, as in DCS's own dialog (curvature -100 .. 100, as there): just type 8 instead of 0.08. Up / Down moves by 1, Shift by 10. Your profile and what JoyPro exports stay as they were (8 here is 0.08 in the file), and a value with more decimals stays exact until you change it. The curve's numbers and the live position follow. Other games keep their own units, and a line above the boxes says which they are.

#Fixed

  • A number outside the range no longer changes without a word. Typing 150 still goes back to 100 when you press Enter or leave the box, but the line under the box now says so. And if you type 0.08 out of habit, it asks: "Did you mean 8?"
  • "Not bound" says what it means. Its tooltip now reads: no input at all, in any game. A relation with no action in one game is what the new chip above is for.
  • Detent mode explained. The section now says in plain words what it does, that the calibration belongs to the device axis (every throttle relation on it shares it, a left and a right lever are separate axes), and why full power at the detent is on by default: an aircraft without afterburner has nothing behind the detent, so it reaches full power there. The line below says plainly whether this axis is calibrated, with its values, and what happens if it is not. Nothing about how detent mode works has changed.
  • Add actions said it found nothing, right above the actions it found. Searching "Bomb Release Button" in a relation that already holds it said "No action's name has every word". JoyPro had found them; they are already in your relation. When the only results are those, there is no box any more; the line above the list says: "No new actions: the 2 found are already in this relation (see below)", with Same meaning on or off. With Same meaning off and other actions hidden, a short box says: "No new actions with every word of "Bomb Release Button": the 2 found are already in this relation (see below). 11 more found by what they do are hidden because Same meaning is off.", with Show same meaning. Suggested for this relation says the same kind of thing when the game you ticked is already in the relation.
  • Actions already in the relation name their aircraft again. Since 2.6.3 their aircraft line was empty, so the F-4E pilot's and WSO's "Bomb Release Button" looked like the same row twice. Now one says "F-4E-45MC" and the other "F-4E-45MC_WSO". An action the relation has for only some of its aircraft still names only the ones you can add.
  • "0 of 0 free aircraft" is gone. The button under such an action now says what the relation has: "1 of 1 aircraft in this relation", or "1 of 3 aircraft in this relation" when the other two aircraft use the command for something else. The list it opens only shows the aircraft: nothing can be added from an action that is greyed, so it no longer has ticks that do nothing. To add one of those aircraft, use the action's own aircraft list in the relation.
  • The line above the list counts what is listed. With Same meaning off it said "11 actions in 1 game + 7 already in this relation" with nothing to add and two rows below. It now reads "No new actions + 2 already in this relation · understood as Weapon release (pickle) · 11 with the same meaning hidden (Same meaning is off) · 5 more in this relation hidden". With Same meaning on it counts as before.
  • The Catalog's filter shows what you asked for. In Falcon BMS, "RMFD OSB 20" listed all four displays' OSB-20 and the MFD power switch, equal and by category, with the switch marked Recommended and RMFD neither first nor marked. Now it lists RMFD: OSB-20 Button - Push, marked Recommended, as Add actions does. "thrust" still finds the throttles. Actions that are only related are listed only when nothing else fits, and the line above the list says so.
  • Recommended in the Catalog follows your words. While a filter is on, the chip marks the best action for what you typed, and the best rows come first. With an empty filter it shows the best action of each function, as before.
  • "OSB20" finds "OSB-20" in the Catalog, as it does in Add actions. And "OSB 3" no longer lists OSB 1 because of a digit in the game's id.
  • Same meaning now works in the Catalog too. It is the same remembered switch as in Add actions, next to Only free. When it is off, the line above the list says how many actions it hides.
  • Reset to default takes a marker you moved a moment ago with it. The positions are saved 2 seconds after the last move. If you pressed Reset to default before that, the move stayed after the reset, or came back a moment later. Now it is saved first, goes with your other changes, and Undo reset brings it back.
  • "right now" is not a side. Since 2.6.3 a sentence like "stop my ship right now" or "a wider area left and right" lost its best matches, because "right" was read as the right side. Those rows are found by what they do again.
