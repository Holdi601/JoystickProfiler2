Release notes

JoyPro 2.7.0

Show:

From docs/releases/v2.7.0.md in the repository (generated, always the current text).

More than one input per relation, several actions at once, a quick way to get binds, a welcome with tours and F1 help, games on the Xbox pad by themselves, and your binds on the DCS kneeboard.

#New

  • Several inputs per relation is now a normal feature. No setting to switch on any more (Settings > Experimental is gone): any relation can be on more than one button or axis, each with its own device, modifiers and axis curve. A relation with one input works and saves exactly as before.
    • Every page knows a relation's other inputs. Press a button on the second stick and Follow input finds its relation. The Layout page's picture and tables name the relation on that input too. The Devices filter and the search (with "Everything") of the Relations and Binds pages find a relation by any of its inputs, and the device lists offer those devices.
    • One curve per input. For an axis on two devices, Axis response on the Binds page has an Input list at the top: pick input 1 (the main one) or input 2 and set its own curve, dead zone and saturation.
  • Select several actions of a relation. In the relation editor, Ctrl+click or Shift+click action cards (Ctrl+A for all). A bar offers Copy, Move to... and Remove:
    • Copy (Ctrl+C), then open another relation of the same kind and press Paste (Ctrl+V). The actions come with their aircraft, also the switched-off ones.
    • Move to... asks: New relation (type the name; it is an axis or button relation like the old one) or Existing relation, picked from a list you can search. Only relations of the same kind are listed.
    • Remove (Del) takes them out after one question.
    • The right-click menu of an action has Copy and Move to another relation... too.
    • Move the actions of several relations: select several relations in the list (Ctrl/Shift+click) and press Move actions to...: all their actions go to one relation, new or existing, and the emptied relations are deleted.
    • Each of these is one step: one Ctrl+Z takes it back.
  • Set it all up for me. At the first start, Done, and set everything up for me saves your games and then sets up your stick, throttle and pedals by itself for the games where nothing is assigned yet. You see the result as a plain list ("Trim rudder left", never an id, and in your language: "Seitenrudertrimmung links", "Kanone feuern", the PlayStation buttons as "Quadrat", "Kreuz" ...), press Use these buttons, then Write to my game, and fly. The Start page has the same as its blue Set it all up for me (the full wizard is the grey Set up step by step...), and so does the welcome's "Just make my stick work". The line at the bottom stays calm: "All important buttons are set. Some rare extras had no room (18). That is OK."
    • One blue button at a time. After Use these buttons that button greys out, so the next one is the only blue one. The tools to move, swap or leave out a function wait behind Change something; the picture of your stick opens big with Show the picture big.
    • ACE COMBAT and the other Xbox-controller games end with the pad, not with an export. Their second button is Set up the pretend controller: the setup window closes and the Virtual Joystick page shows the last steps (the free helper ViGEmBus when it is missing, Test, and when to press Start). The tour card waits while the setup window is open ("Finish the setup window first"); it never runs ahead of it.
    • The helper's install says what to do first: tick the box below the license (it glows), then Install ViGEmBus (it glows next). Going on without it, the card first says that the game will not see your stick; ticking the box after that brings back "Now click Install ViGEmBus". Coming from the first start, a card first says why ("Your game only knows an Xbox controller. JoyPro turns your stick into a pretend one."). While the card waits for the setup window there is no Skip.
    • One name: the pretend controller. For players whose games all use it, the bar button, the page, its status, the ViGEmBus card (now in your language) and F1 say "pretend controller". vJoy, HidHide, the forwarding rate and the modes wait under Show details for experts, which stays after a restart.
    • Test stays on screen after the click: "Now move your stick. Does the picture move? Then click Next."
    • Back from a full-screen game: the card and a small picture show Alt+Tab: start the game, at its title screen hold Alt and press Tab, click Start, Alt+Tab back. Start pressed before ACE COMBAT 8 or Hell Let Loose: Vietnam runs says "Too early" and how to do it; Auto start's tooltip says it is too early for these games.
    • Write to my game asks nothing when the game has nothing on its sticks yet. When the game already has stick buttons, it asks one plain question: "IL-2 Sturmovik: Great Battles already has buttons set. Use the new ones instead? JoyPro keeps a copy of the old ones, and you can undo." Use the new ones writes them (with the backup as always); Keep the old ones too writes your new buttons next to the old ones and removes nothing (where a button is already taken, the old one stays and Check shows it); Cancel writes nothing, and the setup window says to press Write to my game again when you are ready. The Export page keeps its own questions.
    • The calm line is right for IL-2 too. Gear up and down on two buttons, the trim axes as trim buttons and the wheel brakes on one button count as placed, so a flyable plane no longer reads "A few important ones had no room".
    • The quick window speaks plainly: "Look: what goes where" (no step number), no aircraft list for a game with one setup, and the inputs as you hold them ("Twist", "L1", "Hat 1 left", not "Z rotation" or "Trim hat left"). With Easy words its sentences are the easy ones (German "du").
    • IL-2's function names in your language in the quick review and on the Binds page ("Fahrwerk einfahren", "Bombenschacht auf/zu", "Waffen nachladen" ...), in all 38 languages. A name you gave a relation stays as it is.
    • Afterwards it says "It worked!" on the Start page ("IL-2 Sturmovik: Great Battles now has your buttons. JoyPro kept a backup of the old ones."), then a short tour shows where to change a button later (first pick a game control in the list, then Record input) and how to send it to the game again, and ends with "Done! Start ".
    • When the setup stops before the result (no game or no stick found), it offers Try again and Set it up step by step instead of only a message.
  • Set up your devices, right on the Start page. JoyPro looks which of your games have nothing assigned yet and says so: "Set up your devices for War Thunder, Star Citizen and MSFS 2024". Set it all up for me does it by itself; Set up step by step... opens the setup with exactly these games ticked. It only reads your games' control files; nothing changes before you apply.
    • Your own binds stay. A game where you already made binds yourself is listed below with Import, then fill the gaps: your binds come into JoyPro first, then the setup only uses the controls that are still free. Games already in your profile get Fill the gaps....
  • A welcome that asks what you want to do. Everyone who opens this version for the first time, also when coming from an older JoyPro 2, is asked once: Play ACE COMBAT with my flight stick, DCS World or Falcon BMS, Just make my stick work, Show me around, I used JoyPro 1 or No tour, and how long a tour should be (Short or Long, with every extra). JoyPro picks the answer from the games it found (DCS or Falcon BMS: the DCS way; only Xbox-controller games: the pad way; otherwise the quick way) and says why above the answers. It shows after the first-start game setup and never comes back by itself; when you pick Done, and set everything up for me there, the setup starts instead and the welcome does not open next to it.
  • Easy words. One switch (on the welcome, in the first-start window, as Easier words on every tour card, and in Settings > Tours) for anyone who wants it simple, children included: big cards, the shortest texts (at most 12 words a sentence; German says "du"), and F1's help starts with one plain sentence and keeps the details behind More details. It stays after a restart.
  • Small pictures that explain. Four drawn cards: what a joystick axis is, what the pretend Xbox controller is, what Export does (and that Undo brings the old buttons back), and Alt+Tab.
  • Tours that show the real buttons. A tour dims the window, makes the real control glow and waits for your click ("Waiting for you to click the glowing button"), with Back and a big Next; Skip and End tour are small links. Your window size, UI scale, theme and page order do not matter, and it goes on at the same step after a restart. Every page has Tour of this page (in the bar at the top and the Help menu); Settings > Tours lists every tour, shows the welcome again and can ask again at the next start. Double-click JoyPro 2 - Tour in JoyPro's folder to open the welcome and its tours any time; when JoyPro is already running, it opens there.
  • F1 explains any button. Press F1 (or Help > Help mode (F1) in the bar at the top) and click any button, field, list row or tab: it does not run, and a small window next to it says what it does in one plain sentence, then (behind More details with easy words) the details, why it matters, what happens next and what JoyPro's words mean, with a link to its wiki entry. A button with a menu lists its entries. F1 or Esc ends help mode; Enter or Space shows the help of the focused control.
  • ACE COMBAT 8 and Hell Let Loose: Vietnam use the Xbox pad by themselves. These games read no joystick at all, only Xbox controllers. While you have not picked a mode for them, the Virtual Joystick page sets them to Xbox pad and says why: "On the Xbox pad by itself: the game reads only Xbox controllers". Status, the mapping, Start/Test, the auto start and the export all follow it. Pick another mode and JoyPro keeps your choice. If the ViGEmBus driver is missing, the Games card says so and offers the one-click install.
    • Your axis curve now reaches the Xbox pad. The dead zone, saturation, curvature or user curve and invert you set under Axis response are applied to the pad stick or trigger, with the same curve the panel shows. Tick only ACE COMBAT 8 under Applies to to give it a curve of its own. vJoy games still get the raw values, because the game applies the exported curve.
    • Several games on the Xbox pad. ACE COMBAT 7 and 8 can both be on the pad, each with its own pad table. With auto start the running game's table goes live. Start and Test use the running game's table, else the one you pick under Xbox pad table for Start and Test.
    • The live test says what each pad control does, such as "A: Fire machine gun (VKB Gunfighter BTN1)" and "LX: Roll (Rhino X)". A pressed button lights up.
    • Sorted game lists. The Virtual Joystick page and the game picker for virtual functions list the games alphabetically by name in your language.
  • Better ACE COMBAT 8 defaults on the Xbox pad, from a live test:
    • The throttle drives both triggers: forward is RT (accelerate), back is LT (decelerate). This also works when Decelerate sits in a toe brake relation, and the brake axis no longer takes LT.
    • Yaw on LB/RB comes from your stick twist, or from the rudder pedals if there is no twist. It presses at about 30 % deflection.
    • Flares are L3 + R3 pressed together for 120 ms, fed from your flare / CMS forward button. This is not confirmed in the game yet, and JoyPro says so.
    • The D-pad (wingman orders) comes from your comm switch or AI-menu hat.
    • High-G turn: your "Cobra button" (the DCS relation with ASC Direct Control of the Su-27, Su-33, J-11A), or a button relation you name "High-G", holds both triggers fully. The throttle on the triggers keeps working.
    • Macros have a new option, Steps: pressed together, for chords like L3 + R3.
    • engine vjoy pad-check shows what a profile reaches on the pad (throttle split, yaw, flares, High-G, D-pad) with a score.
  • Your binds on the kneeboard. Layout page, Kneeboard: Put on the kneeboard puts the cheat sheet of each aircraft on its kneeboard in DCS (also DCS.openbeta), so you see what every button does right in the cockpit: a clear list in large text of only the controls you use, grouped by control, with the device picture on top and the aircraft's name as the game shows it. A device with many binds continues on a second page. You can also put all devices on the same pages, or use the cheat sheet picture instead. OpenKneeboard shows them too, or pick a folder of your own for other tools and games. JoyPro only adds or replaces its own pages (named JoyPro_...); your other kneeboard pages stay as they are. The name ending and page height are kept for next time.
  • Where is what? A new window shows every device with the function on each control, for the game and aircraft you pick. Press a button or move an axis or hat: its row lights up and its function is named in big letters at the top. Follow the game switches to the game you play and, in DCS, to the aircraft you fly. Put it on a second monitor: it comes back there, with the same size, game, aircraft and options, also after a restart. Open it from the Start page, the Layout page, the setup's review step or the tray menu. It reads your devices only while it is open and not minimized.
  • Devices JoyPro does not know still work. A stick or throttle that is not in JoyPro's device list is set up like a usual one (moving the stick steers, button 1 fires, the first hat trims, the first lever is the throttle), and the setup says so in plain words.
  • WinWing URSA MINOR. The Fighter, Space and Airline sticks and both throttles are recognised by their USB id and by their name.
  • The setup is better on many more setups. JoyPro now tests its setup on 40 device setups (Warthog, T.16000M, VKB, Virpil, WinWing, X56, X52 Pro, TCA Airbus, Honeycomb, a gamepad alone, two sticks for space, MFDs, button boxes ...) in every game it can set up and the main DCS aircraft. What changed:
    • Twin-engine aircraft and DCS's Default layer no longer fight over the throttle lever, so zoom, brakes and other axes get the free sliders.
    • A function the aircraft already has another way (gear toggle next to gear up and down on a switch) gives its button back.
    • No more yaw on a quadrant lever or the flaps lever: pitch, roll and rudder only go on axes that spring back.
    • Countermeasures go on the throttle's hat when your stick has no CMS hat of its own.
    • When your hats are too few for TMS, CMS and the other hat functions, JoyPro adds a shift button and says so.
    • Yokes and throttle quadrants get the same care as sticks and throttles (CMS, TMS and comms on the yoke's hats, a shift button on the yoke).
    • Without a panel, gear and flaps may use the stick's buttons instead of staying unbound.
    • An Xbox controller alone now works: left stick pitch and roll, triggers rudder, the right stick looks around.
    • Two identical sticks (two T.16000M): the second one becomes your left stick for space games.
    • Devices whose button numbers are not published, and devices you add from the catalog, get the usual numbering (button 1 = trigger, first hat) instead of no buttons at all. The setup says so; check them in the review.
    • IL-2: look around without head tracking. The setup puts the snap views (forward, back, left, right) on a hat and the look axes on the throttle's mini stick when there is one.
  • Head tracking or VR? The setup asks. For DCS, IL-2, Falcon BMS, MSFS, X-Plane, War Thunder, Arma, Star Citizen, Elite and the other flight sims the setup (and the quick setup) asks Do you use head tracking or VR? With Yes (also when you only plan to get one) no button on your HOTAS is spent on looking around, only a button to centre the view. With No looking around gets a hat of your stick or throttle right after the gun, weapons, countermeasures, brakes, trim and target; a small device (a gamepad, a stick with one hat, a yoke) gets it behind the shift button instead of not at all. Change the answer in Settings > Looking around; it offers to set the sims up again.
  • A gamepad looks around with its right stick. The throttle moves to the D-pad (up / down = more / less) in the DCS aircraft that have throttle buttons, so it no longer springs back to half power; other games keep the throttle on the right stick.
  • Safer switches. No engine master, starter or magneto toggle on a switch that stays where it is put (the Honeycomb Bravo's and TCA's switches in MSFS and X-Plane): a missed flip no longer leaves switch and engine out of step, and a starter is never held on by a switch. The gear is no longer one slip of the thumb away on the stick's grip, the Warthog's boat switch or a gamepad's face buttons; a printed gear lever only works the gear, a lever printed "Flaps" only the flaps, and a guarded or labelled switch (MOZA MTP "RUD TRIM") is never the mode switch.
  • "Where should functions go?" is a real slider now. It used to act as a switch at the middle; now the real aircraft's positions take over step by step (the HOTAS hats first, then the buttons, the axes and the rest), and on a Warthog the real DMS stays the DMS from the middle on.
  • Suggestions and Auto Group follow a reworked profile. The flight sims, IL-2, Battlefield, ACE COMBAT and the other games now get their look, view, autopilot, anti-ice, lights, magneto, G1000 and other buttons into the same relations a careful hand setup uses. Auto Group on a new profile makes these relations by itself.
    • One click brings the sister sim. Add an MSFS action to a relation and FSX, Prepar3D and the other MSFS version are suggested with the same command; the same goes for X-Plane 11 and 12, IL-2 Great Battles and Korea, Cliffs of Dover and Blitz, Arma 2 and 3, Battlefield 2042 and 6.
    • Your style carries to other games. When two games of a relation use a function that is not the relation's own (the throttle-up button in "RPM Increase"), a game without that relation's function is offered the same. A game with only a toggle (Cliffs of Dover's canopy) is offered its toggle for "Canopy close". Both come as medium, with the reason.
  • Pick the throttle relations to merge. Merge my throttle relations... (Binds page, Detent mode) took every throttle relation of a device axis, a helicopter collective as well. Now each relation of a plan has a checkbox, all ticked at first. Untick the ones to keep apart: they stay as they are, with their own curve and their own detent settings, and the plan is made again for the ticked ones. Merge joins only the ticked ones; with fewer than two ticked it says so and waits.

#Faster

  • A profile opens sooner. It no longer waits for the picture list when there is nothing new to show, and the aircraft check runs after the profile is open instead of holding up the relation list.
  • Typing in the Check's search stays smooth. It shows the first page of cards at once and builds them a few at a time, so the window never freezes while you type.
  • The Start page no longer slows the app down. Its look at your games runs in the background when JoyPro is idle, at low priority, and stops when you leave the Start page. Before, the games list could take many seconds; now it shows at once.
  • Clicks after an export stay quick. JoyPro no longer saves the profile again on every click after an export, and after a short pause it no longer has to load itself back into memory. Memory is given back after two quiet minutes.
  • War Thunder's controls load about five times faster (the look at your games, the export's preview).
  • Looking at your games is quicker: a game your profile already handles is not read again, and your devices are read once per look instead of once per game.
  • Very long folder paths work. DCS files deep in a long Saved Games path were skipped before; now they are read like any other.

#Fixed

  • Lists in a sentence use the language's own word ("A, B und C"): the export's removal question no longer has an English "and" in German (and is in "Sie" throughout), and the relation delete question names its relations the same way.
  • F1 in plain words for the license box ("Tick this to say yes: JoyPro may download and install this free helper."), Record input ("Press one button; for a stick axis, move it all the way.") and Check ("It only looks; it changes nothing.").
  • The pad tour opens the quick setup, not the full five-step setup, and names the buttons that are really there. Its Live test step opens the tab and asks you to press Test first.
  • One rule for when to press Start with the Xbox controller, said the same way in the pad tour, F1's help, the page help and the Virtual Joystick page: start the game, wait for its title screen, then press Start (too early? Stop, then Start). The page no longer tells an Xbox-controller game to switch to Virtual and export again.
  • Picking the quick way again while a setup is open shows that setup instead of starting a second, hidden one.
  • The device picture of the setup no longer shows "The sheet could not be shown." on an empty panel: JoyPro reads a picture that is still busy a few times more, and else says the list shows what goes where.
  • German: buttons on the screen are "Schaltfläche", buttons on your stick "Taste"; a bind is a "Belegung"; no English left in the tours ("Gear up", "Study-Sims", "Axis Tune", "clean oder nuke"), and the sort menu follows a language change.   • "Like the real aircraft?" is now "Where should functions go?" The setup wizard's slider runs from Same button for the same job in every aircraft to Where the real aircraft has it, in every language. The quick setup and the Start page use your last choice. Moving the slider never takes the gun off the trigger or the throttle off its lever. "Where the real aircraft has it" now knows which hat of a T.16000M, TWCS, X56, X52 Pro, MongoosT CM3, STECS, T.Flight and the WinWing grips stands in for the real trim hat, TMS, DMS, CMS, speed brake, boat switch or coolie (from the game's own default profiles of these devices). On devices JoyPro does not know that well it changes little, and the wizard says so under the slider.
  • The Warthog's SPEED BRAKE switch is the speed brake again, never the landing gear. A printed name on a grip belongs to its function, as on a base.
  • JoyPro's shift button is always a plain push button. It no longer lands on the TCA stick's reverser zone (which pressed it whenever the slider was low), on a lever detent or on a latched switch.
  • Nothing goes on a mode wheel. The X56 MODE wheel, the X52 MODE selector, the STECS mode switch and the TCA's ENG MODE knob always hold one position, so they no longer stop the engine or open the canopy when you turn them.
  • A switch with a function's name is never the mode switch (the Warthog's ENG OPER L, the URSA MINOR's ENG 1 MASTER).
  • TCA Airbus: the ENG 1 / 2 MASTER switches and the ENG MODE knob are known now, and button 2 of the sidestick is a head button, not a second trigger stage.
  • Small HOTAS and gamepads: gear, flaps, trim, looking around and the comm switch are placed in a fixed order of what must fit first: trim takes a stick's only hat before the TMS, gear up and down stay together, and buttons a thumb stick already does (TDC slew) are left free for these.
  • Cursor slew, sideways thrust and looking around only go on axes that spring back to the centre, never on a throttle lever or slider.
  • Lever detents only get functions of the lever they belong to (no afterburner on the Bravo's mixture lever).
  • Countermeasures stay on one hat in plans with many aircraft.
  • Plain names: relations the setup makes for one game (not DCS) are named after the game's own actions ("Map") instead of internal names ("Kneeboard TOGGLE").
  • Switches with a printed name get their own function. The Warthog's FLAPS switch takes flaps up / down again, the Honeycomb Alpha's MASTER BAT, MASTER ALT, AVIONICS BUS 1 / 2, BCN, LAND, TAXI, NAV, STROBE and the IGNITION selector get battery, alternator, avionics, the lights and the magnetos (up is on), and the Bravo's HDG, NAV, APR, REV, ALT, VS, IAS and AUTOPILOT buttons get those autopilot modes. Landing lights no longer go on the TAXI switch.
  • Gear and flaps find a place on the Warthog again (on the grips or the pinky / boat switch when every base switch has its own label), and the wheel brake button is left out when your pedals have toe brakes.
  • Logitech / Saitek throttle quadrant: its rocker switches spring back and are used as buttons now. A yoke without a trigger gets the gun on its first handle button.
  • Hats go the right way: radar elevation down is no longer on the coolie's UP, and on / off pairs keep their direction.
  • Nuclear Option: the gun is on the trigger.
  • Auto Group and Fill all follow the setup's rules for a bound button: nothing on a lever detent but the lever's own functions, an engine stop only on its own lever's OFF, no second function for an aircraft on the same button, never on and off on one button, nothing on a switch labelled for something else.
  • Elite Dangerous: forward thrust is never on a sideways axis, the roll buttons give way to the roll axis, and the throttle up / down keys are named as such (they were "RPM +/-"). MSFS: the autopilot's yaw is the yaw damper.
  • Nothing that cannot be undone sits under your fingers. The automatic setup no longer puts engine stop, eject, jettison, canopy or mixture cut-off on a stick or throttle trigger, button, mini-stick or scroll wheel, also not behind a shift button. They go only on a switch whose printed label names them, or as the two positions of a switch (start / stop), or they stay free for you to set.
  • Moving a lever no longer changes something else. The TCA's reverser zone of the slider gets nothing (it raised the gear before), lever detents take only the lever's own functions, and an engine is stopped from a detent only by a one-way cut-off on that lever's own OFF position, never by a start / stop toggle at IDLE.
  • Switches keep their meaning. A latched switch only gets something with an ON and an OFF position, and a switch with a printed name (FUEL FLOW, EAC ARM, ENG 1 MASTER) keeps it: rudder trim held all flight on FUEL FLOW and gear on ENG MASTER are gone. AP on / off no longer sits on the Bravo's AP value knob, and trim is never behind a shift button.
  • The gun stays on the trigger with many DCS modules. With 10 to 30 modules, a one-stage trigger fires every module's gun; the camera / laser first detent of the F-16 or A-10C no longer takes it. The VKB Gladiator Mk.II gets the gun on its trigger again.
  • Twin-engine helicopters keep the collective on the throttle lever (the engine levers of the Mi-8, Ka-50 and AH-64 go to a free knob), and no throttle lands on a spring-loaded thumb stick or twist.
  • VKB STECS Space throttle: the throttle lever and the grip's gimbal are known now. VKB Gladiator Mk.II: the pedal-port axes are no longer taken for pedals that are not there.
  • ACE COMBAT 8: the automatic setup puts the flight controls on the pad. It set up only the gun, change weapon, radar map, camera and two yaw buttons; pitch, roll, the throttle, missiles and target stayed unbound. Now pitch and roll go on the stick, the throttle on both triggers, yaw on LB / RB from the twist or the pedals, and missile, target, flares, High-G and the wingman D-pad on your HOTAS. The functions carry the game's names (Radar map, Change weapon). ACE COMBAT 7 got its flight axes, missile and flares too.

  • Suggest missing and Fill all suggest only games installed on your PC. Untick "Only games installed on this PC" to see every game.

  • The Virtual Joystick mapping no longer lists Hell Let Loose: Vietnam (with a warning) when you do not have it.
  • Fill all no longer adds commands that do something else. "Your style" suggestions took a command from one game family as proof (MSFS 2020 and 2024 counted as two games) and also across kinds of function, so the NS430 got Falcon BMS's brake channel switch and the AI menu got IL-2's Esc menu. Your style now needs two different simulators and the relation's own kind of function; anything else is only offered as a low suggestion, which Fill all does not take. Fill all also never puts the opposite of a relation's command into it (lights on into Lights Off, engine stop into Engine Start).
  • Looking around needs the whole set. The setup puts all four view directions on one hat, one set per game, instead of half a set that cannot look sideways.

  • The automatic setup puts the gun on the trigger. On sticks with a one-stage trigger (T.16000M, X56, Extreme 3D, T.Flight, gamepads ...) the F-16, A-10C and similar jets got the camera / laser detent on the trigger and the gun on a base button.   • Moving the throttle no longer does something else. Lever detents (Airbus quadrant, Bravo, URSA MINOR Airline) only get throttle functions such as idle / cut-off, reverse or TOGA. A printed label (PTT, TRIM, ENG OPER ...) keeps its button for its own function, and engine start / stop, jettison or eject never land on a stick hat.

  • One game command, one bind. In Elite Dangerous, Star Citizen, X4, Arma and a few DCS layers the setup could bind the same game command twice (Elite's yaw axis on the twist and the slider). Now each command gets one place.

#Known limitations

  • Very small controllers (one stick, few buttons) may put flares/chaff behind a modifier button. The plan says which button to hold.
  • A stick without a throttle: the throttle goes on a slider or knob if there is one. Without such an input you add one yourself in that game.
  • "All games in one plan" can leave out the throttle or flares on unusual or tiny setups. For those, set up one game at a time.
  • Big HOTAS setups with many games in one plan can miss a wheel brake button in some aircraft.
  • Two identical sticks are planned correctly, but the plan text does not say which one is left or right.
  • Helicopters and airliners get sensible but not perfect layouts. Have a look at the plan before you export.
  • Rarely used functions (flaps, airbrake, master arm) can stay unbound on small devices.
