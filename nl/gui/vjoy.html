GUI-pagina's

Virtuele joystick

Tonen:

Sommige games nemen maar een paar joysticks, pakken de verkeerde of halen hun volgorde door elkaar als je een ander apparaat aansluit. In de virtuele modus zet JoyPro elke as, knop en hat die de toewijzingen van een game gebruiken op één virtuele joystick (vJoy), of op een virtuele Xbox 360-pad voor games die alleen gamepads lezen. De game ziet één apparaat waarvan de inputs nooit verschuiven; je profiel houdt je echte apparaten. Daarbovenop doen virtuele functies wat Joystick Gremlin doet: asbereiken als knoppen, aan/uit-schakelaars, kort/lang drukken, shift-lagen, macro's, modi.

Voor beginners

#Gebruiken in vier stappen

  1. Zet de game onder Games op vJoy (of op Xbox-pad voor games die alleen een gamepad nemen). Games waarvan bekend is dat ze maar één apparaat lezen, tonen een voorstel met Gebruiken. Games die alleen Xbox-controllers lezen (ACE COMBAT 8, Hell Let Loose: Vietnam) staan vanzelf op de Xbox-pad tot je een andere modus kiest; de pagina zegt waarom. De lijst is op naam gesorteerd.
  2. Exporteer de game opnieuw op de pagina Exporteren. JoyPro schrijft de toewijzingen naar de virtuele joystick; je profiel houdt je echte apparaten.
  3. Druk op Start. Eén regel per soort game, op dezelfde manier gezegd in de padrondleiding, de help en de pagina:
    • Xbox-pad (ACE COMBAT, Hell Let Loose: Vietnam): start eerst de game en wacht op het titelscherm, druk dan op Start. Te vroeg? Druk op Stoppen en dan op Start. Deze games krijgen geen export en hoeven niet omgezet te worden, dus stap 1 en 2 vallen voor ze weg.
    • vJoy: druk op Start voordat je de game start. JoyPro verbergt je echte apparaten voor die game met HidHide (Windows vraagt één keer om beheerdersrechten) en kopieert elke input live naar de virtuele joystick.
  4. Druk op Stoppen als je klaar bent. HidHide krijgt precies de instelling terug die het eerder had; niets blijft verborgen.

Wat deze pagina nodig heeft toont de gratis drivers: vJoy (voor games die op vJoy staan), ViGEmBus (Xbox-pad) en HidHide (voor vJoy-games). Ze horen niet bij JoyPro; installeer daar met één klik wat je nodig hebt. Een game die alleen Xbox-controllers leest (ACE COMBAT 8, Hell Let Loose: Vietnam) heeft alleen ViGEmBus nodig: hij ziet je echte apparaten nooit, dus HidHide is niet nodig en Windows vraagt niet om beheerdersrechten.

Alleen games die alleen Xbox kennen?

Dan heet de pagina Nagebootste controller en toont hij alleen wat deze games nodig hebben: de ViGEmBus-kaart, Testen en Start. vJoy, HidHide en de moduslijsten zitten achter Details voor experts tonen (vJoy, HidHide, modi). Zie Een game die alleen Xbox kent spelen met een HOTAS.

Eerst testen

Testen leest je apparaten en toont op het tabblad Livetest wat de game zou krijgen, zonder vJoy of HidHide aan te raken. Beweeg je stick en kijk naar de balken.

In de game: Wat er in de game verandert

Het besturingsmenu van de game toont één apparaat, "vJoy Device", met je toewijzingen op zijn knoppen en assen. Je echte apparaten zijn alleen voor die game onzichtbaar zolang de virtuele joystick draait; elk ander programma blijft ze zien. Curves, dode zones en omkeringen komen nog steeds uit de eigen instellingen van de game die JoyPro exporteert. Op de Xbox-pad is het anders: die games krijgen geen export, dus JoyPro past elke ascurve zelf toe (pagina Toewijzingen, Asrespons).

Geavanceerd

#De vier tabbladen

Overzicht: wat het is en hoe je het gebruikt; Status van vJoy (versie, apparaten), HidHide en de sessie van JoyPro (Vernieuwen, vJoy instellen voor de tabel als een vJoy-apparaat assen, knoppen of hats mist, HidHide herstellen na een crash, vJoy instellen op maximum: 8 assen, 128 knoppen, 4 hats, vraagt een herstart van Windows); Wat deze pagina nodig heeft; Games (Native / vJoy / Xbox-pad per game, wat de game van één joystick leest, met waarschuwingen erboven); Opties: de echte apparaten verbergen (HidHide, aanbevolen), vanzelf starten en stoppen als een virtuele game start en eindigt (JoyPro kijkt er elke 3 seconden naar; vóór de game op Start drukken is voor vJoy nog steeds het veiligst; de Xbox-pad-games hierboven willen het na hun titelscherm).

Toewijzingstabel: de tabel. Elke fysieke input die de virtuele games gebruiken, heeft een vaste plek op de virtuele joystick: een as houdt zijn eigen as waar die vrij is (X blijft X), knoppen en hats nemen het volgende vrije nummer. Bestaande plekken verschuiven nooit, dus de toewijzingen van de game blijven van sessie tot sessie hetzelfde. Toewijzingstabel bijwerken geeft nieuwe inputs een plek en slaat de tabel op in het profiel.

Functies: virtuele functies, hun modi, de Gremlin-import en de grafiek (hieronder).

Livetest: balken voor de assen, de ingedrukte knoppen en hats van elk vJoy-apparaat zoals de doorstuurder ze schrijft, met het logboek van de doorstuurder. De virtuele joystick live tonen (voor spelers van wie alle games op de nagebootste controller staan: De nagebootste controller live tonen) zet de balken aan of uit. Voor de Xbox-pad zegt elk gekoppeld bedieningselement wat het doet en waar het vandaan komt ("A: Fire machine gun (VKB Gunfighter BTN1)", "LX: Roll (Rhino X)"), en een ingedrukte knop licht op.

#De Xbox-pad

  • Vanzelf: een game die geen joystick leest, alleen Xbox-controllers, gebruikt de Xbox-pad zolang je er geen modus voor hebt gekozen ("Vanzelf op de Xbox-pad"). Jouw keuze wint en blijft bewaard. Zonder de ViGEmBus-driver zegt de kaart Games dat en biedt ze de installatie met één klik aan.
  • As-curves: deze games krijgen geen export, dus JoyPro past de ascurve van de relatie (dode zone, saturatie, kromming of eigen curve, omkering; de eigen curve van de game, anders de Standaardcurve) zelf toe op de stick of trigger van de pad. Asrespons op de pagina Toewijzingen zegt dat voor deze games. vJoy-games houden de ruwe waarden, omdat hun curve in de export zit.
  • Meerdere games op de pad: elke game houdt een eigen padtabel; er is er één tegelijk actief. Met automatisch starten de tabel van de game die draait; Start en Testen nemen de tabel van de draaiende game, anders die gekozen onder Xbox-pad-tabel voor Start en Testen (bewaard in het profiel).
  • Automatische installatie (uit de livetest van ACE COMBAT 8, voor elk profiel): de throttle stuurt beide triggers (naar voren RT, naar achteren LT) en een remas neemt LT niet; yaw op LB/RB komt van de twist van je stick, anders van de roerpedalen, bij ongeveer 30 % uitslag; de flares van ACE COMBAT 8 (L3 + R3 samen, nog niet bevestigd in de game) komen van je flare- / CMS-vooruitknop; de wingman-D-pad van je comm switch of AI-menu-hat; een hatrichting op Change target stuurt Y; je Cobra-knop (DCS ASC Direct Control) of een knoprelatie met de naam "High-G" houdt beide triggers vast voor de High-G-bocht. Eén input stuurt nooit twee padbedieningen, en een padslot dat geen relatie meer voedt, verdwijnt vanzelf.
  • Omkeren op de pad: de omkering van DCS komt nooit bij de pad aan. De pitch van ACE COMBAT 8 is standaard omgekeerd (met de standaard Pitch Controls van de game geeft naar voren de neus omlaag). Draai de as van één game om in Asrespons met alleen die game aangevinkt onder Geldt voor; DCS houdt zijn eigen instelling. engine vjoy pad-check toont wat een profiel op de pad bereikt.

#Virtuele functies

Functies draaien in de virtuele joystick, tussen je apparaten en wat de game krijgt. Kies de game, het type, Functie toevoegen, en stel dan in de editor de inputs en uitgangen in.

Functie Wat het doet
Asbanden een as verdeeld in maximaal 16 banden, elke band een knop (kliksstanden van de throttle)
Knopcyclus elke druk gaat naar de volgende uitgang
Schakelaar (vergrendelen) een drukknop die aan blijft tot je er weer op drukt
Schakelaar naar aan/uit-pulsen een vaste schakelaar stuurt één puls per stand
Kort / lang / dubbel drukken drie taken op één knop
Shiftlaag zolang de shift-knop wordt vastgehouden, gaan inputs naar andere uitgangen
Assen samenvoegen / splitsen twee pedalen tot één roer; één as tot twee
Ascurve dode zone, saturatie, kromming, omkering, slider
Asuiteinden naar knoppen, assen naar hat, knoppen naar as, as naar encoderpulsen omzettingen
Turbo, macro herhalen zolang vastgehouden; een reeks drukken en toetsen
Hat naar knoppen, knoppen naar hat, omleiden hats en omleidingen
Modusschakelaar verandert de modus (wisselen naar, vasthouden, aan/uit, cyclus, terug)

De editor: naam, Aan, Toetsenborduitvoer (laat uitgangen en macrostappen toetsen indrukken; alleen als het echt draait), een knooppuntweergave (inputs → functie → uitgangen, verlicht zodra een uitgang afgaat), de balk met asbanden met versleepbare randen, de curve, Werkt in de modi, Modus om naar te wisselen, inputs (apparaat en input, Wissen), uitgangen (vJoy-knop of -as, Xbox-bediening of toets; Relatie toewijzen wijst een relatie toe aan die uitgang), instellingen en macrostappen. Uitproberen voert de functie uit in de editor met schuifregelaars en drukknoppen; er gaat niets naar vJoy of de game. Opslaan slaat haar op; een draaiende virtuele joystick neemt haar over na Stoppen en Start.

Koppelen: een input kan de uitgang van een andere functie lezen in plaats van een apparaat: kies ⚙ f1 ... in de apparatenlijst van de input, of sleep in de Grafiek van alle functies van een uitgangspunt (rechterrand) naar een inputpunt (linkerrand). Lussen worden geweigerd. Klik op een draad en dan op de × ervan om los te koppelen.

Modi (lagen): geef je inputs per situatie een andere taak (Combat, Landing ...). Een modus kan erven van een andere; een functie werkt in de aangevinkte modi (geen = elke modus). Modus toevoegen, Hernoemen, × (verwijderen), Bij start (de modus waarin de doorstuurder start). De actieve modus wordt live gemarkeerd.

#Kom je van Joystick Gremlin

Kies de game, vink eventueel Functies en modi van de game vervangen aan, druk op Een Gremlin-profiel importeren... en kies de .xml (R13 of R14). JoyPro toont eerst een rapport: wat het ervan maakt, wat het niet kan (activeringsvoorwaarden, muisacties, Python-plug-ins, geluiden ...) en wat geïmporteerd, maar anders is. Er wordt niets opgeslagen tot Importeren. Modi, omleidingen, curves, macro's, samengevoegde assen, tempo-, keten- en toggle-containers worden functies en modi. Zet de game daarna op vJoy, houd de relaties op de vJoy-uitgangen of wijs ze toe, exporteer en druk op Start: HidHide en de doorstuurder vervangen het verbergen van apparaten en het achtergrondprogramma van Gremlin.

Technische details

#Achter de pagina

Viewmodels: MainWindowViewModel.VirtualJoystick.cs (status, tabel, Start/Testen/Stoppen, automatisch starten, liveweergave), MainWindowViewModel.VirtualFunctions.cs, MainWindowViewModel.VirtualModes.cs (modi, Gremlin-import), VirtualFunctionEditorViewModel.cs; weergaven VirtualJoystickView.axaml, VirtualFunctionEditorView.axaml, Views/Controls/VirtualFunctionGraphView.cs, VirtualFunctionFlowView.cs, AxisBandEditor.cs.

Start van de virtuele joystick:

# Wie Wat er gebeurt
1 Jij Druk op Start.
2 Engine vjoy map: nieuwe inputs krijgen een slot; de tabel wordt in het profiel opgeslagen.
3 Engine vjoy forwarder-config: de tabel en de functies, uitgewerkt.
4 Engine vjoy apply-hidhide schrijft eerst zijn journaal en verbergt dan de fysieke apparaten voor de vJoy-games (HidHide vraagt één keer om beheerdersrechten). Games die alleen Xbox-controllers lezen: "HidHide is niet nodig", geen vraag.
5 JoyPro.VJoy run --sink vjoy --parent-pid N: bij elke ronde (bijvoorbeeld 144 keer per seconde) leest het de apparaten, voert het de functies uit en schrijft het naar vJoy of de Xbox-pad.

Stoppen:

# Wie Wat er gebeurt
1 Jij Druk op Stoppen.
2 JoyPro.VJoy Stopt: uitgangen neutraal, toetsen losgelaten.
3 Engine vjoy restore-hidhide zet precies de instelling van daarvoor terug.
  • Toewijzingstabel: in het profiel (Pr0file.VirtualJoystick); engine vjoy map (--prune, --reset), engine vjoy mode (native | virtual | xbox per game), engine vjoy status, engine vjoy settings (welke vJoy-apparaten JoyPro gebruikt), engine vjoy configure-vjoy (vJoyConfig, haalt nooit iets weg behalve vermeden assen), engine vjoy limits.
  • Export, import, synchronisatie: zolang een virtuele game wordt geëxporteerd, geïmporteerd of gesynchroniseerd, wijzen zijn toewijzingen naar de vJoy-slots; daarna heeft het profiel zijn fysieke apparaten terug. Een ontbrekend vJoy-apparaat stopt de export met een melding.
  • HidHide-sessie: engine vjoy apply-hidhide, engine vjoy restore-hidhide, engine vjoy recover: vóór elke wijziging wordt een logboek geschreven, zodat na een crash alles kan worden hersteld (HidHide herstellen).
  • Functies en modi: engine vjoy functions types, engine vjoy functions list, engine vjoy functions add --game, engine vjoy functions set --game, engine vjoy functions remove --game, engine vjoy functions test (simuleren, er gaat niets naar vJoy), engine vjoy modes list. Opgeslagen per game in het profiel (VJoySettings.Functions[game], VJoySettings.Modes[game]); hun uitgangen zijn gereserveerd in de tabel. Dezelfde evaluatiecode draait in de test van de engine, het voorbeeld van de editor en de doorstuurder; functies worden bij elke doorloop in volgorde van afhankelijkheid geëvalueerd, en per doorloop wordt niets in het geheugen toegewezen (ongeveer 10 µs per doorloop voor 50 functies).
  • Gremlin: engine vjoy import-gremlin (--dry-run voor het rapport, --replace, --vjoy-device).
  • Doorstuurder: gui/JoyPro.VJoy (JoyPro.VJoy.exe run --config ... --sink vjoy|dry), niet-exclusieve DirectInput erin, vJoyInterface.dll / ViGEmBus eruit. Testen gebruikt de dry sink en geen HidHide.

Naslag: virtual-joystick, drivers: components.

#Band toevoegen

Knopbeschreven

Tooltip Splitst de breedste band in tweeën (tot 16 banden).
