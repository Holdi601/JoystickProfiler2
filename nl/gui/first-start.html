GUI-pagina's

Instelling bij de eerste start

Tonen:

Het venster "Welkom bij JoyPro2: je games" opent één keer bij de eerste start, nadat JoyPro naar je games heeft gezocht. Het toont elke game die JoyPro ondersteunt, gevonden games eerst. Hier zeg je welke games je hebt, koppel je een game die is geïnstalleerd op een plek waar JoyPro niet keek, en wijs je JoyPro een andere map aan voor de besturing van een game. Hetzelfde venster opent opnieuw via Instellingen > Games > Instelling opnieuw uitvoeren. De uitleg voor een nieuwe gebruiker staat op Eerste start.

In elke rij Wat er gebeurt
Vink Ik heb deze game uit JoyPro verbergt de game overal. Je toewijzingen ervoor blijven.
Bladeren... of .exe... naast Installatie Die map is de game. Handig voor een kopie op een andere schijf.
Bladeren... naast Besturing opgeslagen in JoyPro leest en schrijft de besturing van de game daar.

Druk dan op een van de drie knoppen onderaan:

Je drukt op
Wat er hierna komt
Gereed
JoyPro slaat je games op. Bij de eerste start vraagt het welkomstscherm wat je wilt doen.
Gereed, en alles voor me instellen
JoyPro slaat je games op. Daarna zet de snelle instelling de belangrijke functies op je stick.
Later
Er verandert niets. Bij de eerste start komt daarna het welkomstscherm.
Voor beginners

#Eén rij per game

Elke rij heeft de cover van de game, de naam en een status:

  • Aangevinkt, met een map: JoyPro heeft de game gevonden (de rij zegt hoe: Steam, een bekende plek, de lijst met Windows-apps).
  • Niet aangevinkt: JoyPro heeft hem niet gevonden. Dat is prima als je hem niet hebt; hij is niet verborgen en JoyPro vindt hem zodra je hem installeert.

Wat je kunt doen:

  1. Vink een gevonden game uit die je niet hebt of die je niet interesseert: hij wordt overal in JoyPro verborgen (gamekaarten, exportkaarten, de gamebewaking, gamelijsten). Je toewijzingen ervoor blijven in het profiel.
  2. Een game die ergens anders is geïnstalleerd (een draagbare kopie, een andere schijf): vink hem aan en druk op Bladeren... naast Installatie om de map te kiezen, of op .exe... om het programma of de launcher van de game te kiezen.
  3. Besturing opgeslagen in: sommige games bewaren hun besturing in je gebruikersmappen. Staat die van jou ergens anders, bijvoorbeeld Saved Games\DCS.openbeta in plaats van Saved Games\DCS, druk daar dan op Bladeren....
  4. Druk op Gereed. Later sluit het venster en verandert niets.
  5. Of druk op Gereed, en alles voor me instellen: JoyPro slaat je games op en stelt je stick vanzelf in. Zie Snelstart.
Tip

Na Gereed maakt JoyPro de commandolijst van elke game die je hebt uit je eigen installatie. De Startpagina toont de voortgang en een melding voor elke lijst die nog ontbreekt.

Geavanceerd

#Details

  • Een gekoppelde map wordt gecontroleerd op de markeringsbestanden van de game (bin\DCS.exe, bin\game\Il-2.exe, X4.exe ...): de rij zegt "Markering gevonden", of "Markering niet gevonden, maar de map blijft zoals je hem hebt gekozen". Een gekoppelde map telt voor alles als de installatie (import, export, commandolijst) en de detectie vervangt hem nooit.
  • Gedetecteerde gebruiken (installatie of configuratie) vergeet je koppeling; JoyPro detecteert de game opnieuw.
  • Ik heb hem niet (overal verbergen) wordt aangeboden voor een game die JoyPro niet heeft gevonden: zonder deze keuze blijft de game "niet geïnstalleerd" en verschijnt hij vanzelf zodra hij is geïnstalleerd; met deze keuze wordt de game verborgen zoals een uitgevinkte gevonden game.
  • Games die hun besturing in de installatie bewaren (IL-2, Falcon BMS, X-Plane ...), tonen hun configuratielocatie als alleen-lezen.
  • Verborgen games staan onderaan in Instellingen > Games met Weer tonen.
Technische details

#Achter het venster

Venster Views/GameSetupWindow.axaml (+ .axaml.cs voor de mapkiezers, Gereed en Later), viewmodel MainWindowViewModel.GameSetup.cs, rijen Models/GameSetupItem.cs. Het venster opent één keer als gameSetupDone niet is ingesteld in ui-settings.json en de detectie bij het opstarten (engine games installs) heeft geantwoord. Gereed voert per gewijzigde rij engine games install set (of clear) en engine games config set (of clear) uit, daarna één engine games install disable / enable voor de verborgen en getoonde games, detecteert opnieuw, markeert de installatie als klaar en start engine db check-updates om de ontbrekende commandolijsten te bouwen. #Ik heb deze game

Selectievakjebeschreven

"Ik heb deze game": aan het begin aangevinkt voor elke game die JoyPro heeft gevonden of die jij hebt gekoppeld.

Vink een gevonden game uit die je niet hebt, en Gereed verbergt hem overal in JoyPro; vink een game aan die je eerder had verborgen, en Gereed toont hem weer.

#Ik heb hem niet (overal verbergen)

Selectievakjebeschreven

Tooltip Anders vindt JoyPro de game zodra hij is geïnstalleerd

Wordt getoond voor een game die JoyPro niet heeft gevonden: aangevinkt verbergt Gereed hem overal, net als een gevonden game die niet is aangevinkt.

Zonder dit blijft de game "niet geïnstalleerd" en vindt JoyPro hem zelf zodra je hem installeert.

JoyPro haalt de map van de game uit wat je kiest, vinkt de game aan en controleert of het markeringsbestand van de game erin staat.

#Gereed

Knopbeschreven

Slaat de games op en sluit dit venster.

Slaat je keuzes op en sluit het venster: gekoppelde mappen en configuratielocaties worden geschreven, gevonden games die niet zijn aangevinkt worden verborgen en aangevinkte getoond, daarna zoekt JoyPro de games opnieuw en maakt het de commandolijsten van de games die je hebt.

Als een stap mislukt, blijft het venster open en zegt het welke game.

#Gereed, en alles voor me instellen

Knopbeschreven

Tooltip Slaat je games op, daarna zet JoyPro zelf de belangrijke functies op je stick en gashendel en laat je het resultaat zien

Slaat de games op. Daarna stelt JoyPro de stick automatisch in.

Alleen bij de eerste start: Gereed, en alles voor me instellen slaat je games op zoals Gereed, daarna stelt JoyPro zelf je apparaten in voor de games waar nog niets is toegewezen.

Het vindt je stick, throttle en pedalen, geeft elk zijn gewone taak en zet de belangrijke functies waar piloten ze verwachten.
