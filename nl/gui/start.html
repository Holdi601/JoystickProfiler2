GUI-pagina's

Start

Tonen:

De Startpagina is waar JoyPro opent. Hij toont wat is ingesteld, wat je nu kunt doen, en je games: Importeren neemt de toewijzingen die je in een game hebt gemaakt over in JoyPro; Exporteren schrijft ze terug. Het importeren stap voor stap: Een game importeren.

Voor beginners

#Van boven naar beneden

  • Meldingen: ontbrekende vereisten, commandolijsten om te maken of bij te werken, een crashrapport om te versturen, een update.
  • Je apparaten instellen: de kaart voor de automatische instelling. JoyPro kijkt (alleen lezend) welke van je games nog niets toegewezen hebben en noemt ze: "Je apparaten instellen voor War Thunder en Star Citizen". Alles voor me instellen (de blauwe knop) doet alles vanzelf; Stap voor stap instellen... opent de installatiewizard met deze games aangevinkt. Games waarin je zelf toewijzingen hebt gemaakt staan eronder: Importeren, dan gaten vullen neemt eerst je toewijzingen over, daarna gebruikt de instelling alleen de vrije bedieningselementen. Games die al in je profiel staan: Gaten vullen.... Wat zit waar? toont je apparaten met wat elk bedieningselement doet.
  • Profiel in één oogopslag: relaties (en hoeveel daarvan assen zijn), hoeveel er zijn toegewezen, modifiers, aangesloten apparaten, geïnstalleerde games.
  • Volgende stappen: wat JoyPro nu voorstelt ("3 relaties hebben nog geen knop: Toewijzen", "VPforce Rhino FFB Base wordt nog niet gebruikt: Automatisch toewijzen", "Schrijf je toewijzingen naar je games: Exporteren").
  • Je games: één kaart per game met Importeren, Exporteren, Bijwerken (de commandolijst), Export ongedaan maken, Wijzigingen bewaken en een knop om te verbergen. Mijn apparaten automatisch instellen... start de installatiewizard.
  • Je apparaten: de aangesloten apparaten met hun afbeeldingen; een klik opent de pagina Lay-out. Een oranje Welke grip? of Welk model? op een apparaat betekent dat JoyPro niet kan zien welke het is: een klik erop opent de pagina Lay-out met de keuze open, en je antwoord blijft bewaard.
  • Recente activiteit per game en de schakelaar van de gamebewaking; de kaart HUD.
Geavanceerd

#De importwizard

  1. Kies een game (Importeren op de kaart ervan).
  2. Kies hoe: Aan mijn profiel toevoegen (aanbevolen) of Opnieuw beginnen vanuit deze game, het toetsenbord, apparaten die niet zijn aangesloten, de DCS-toestellen. Eerst bekijken toont in het paneel Uitvoer wat de game heeft, zonder iets te veranderen.
  3. Nu importeren: het resultaat blijft boven de kaarten staan ("Klaar: je profiel heeft nu 214 relaties") met Mijn relaties bekijken.

Onder de kaarten biedt de expertimport elke optie per game (DCS, IL-2, Star Citizen en elke andere game uit Games laden) met Scan / Import / Export.

Technische details

#Achter de pagina

MainWindowViewModel.GameHub.cs (kaarten, wizard), MainWindowViewModel.Design.cs (dashboard), MainWindowViewModel.DbUpdates.cs (commandolijsten), MainWindowViewModel.DeviceCenter.cs (apparaten), MainWindowViewModel.GameSync.cs (gamebewaking). Engine: engine games installs, engine db check-updates, engine hud devices, engine sync status, engine dcs import / engine dcs scan en de import en scan van de andere games.
