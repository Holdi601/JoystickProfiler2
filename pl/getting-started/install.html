Pierwsze kroki

Pobieranie i instalacja

Pokaż:

JoyPro 2 jest darmowy i ma otwarte źródło (GPL-3.0). Nie ma konta, rejestracji ani telemetrii.

Dla początkujących

#Trzy kroki

  1. Otwórz stronę wydań na GitHubie i pobierz JoyPro2-<version>-win-x64.zip (w Assets).
  2. Kliknij plik zip prawym przyciskiem, Wyodrębnij wszystkie... i wybierz folder, w którym możesz zapisywać, na przykład C:\JoyPro2 albo folder w Dokumentach. (Nie C:\Program Files: JoyPro aktualizuje się we własnym folderze.)
  3. Otwórz folder i kliknij dwukrotnie JoyPro.Gui (program z ikoną joysticka; gdy rozszerzenia plików są widoczne, nazywa się JoyPro.Gui.exe).

Windows pokazuje System Windows ochronił ten komputer? Kliknij Więcej informacji, potem Uruchom mimo to. Windows pyta o to raz przy programie pobranym z internetu, którego jeszcze nie zna.

Przy pierwszym uruchomieniu JoyPro szuka Twoich gier i pokazuje je w oknie: zobacz Pierwsze uruchomienie. Nowy w JoyPro? Naciśnij tam Gotowe, ustaw wszystko za mnie i idź według Szybki start: niech mój drążek działa.

Potem powitanie pyta, co chcesz zrobić, i uruchamia pasujący do Ciebie przewodnik. JoyPro 2 - Tour w tym samym folderze w każdej chwili otwiera to powitanie ponownie. Chcesz duży tekst i krótkie zdania? Zaznacz w powitaniu Proste słowa: duży tekst, krótkie zdania (Proste słowa, przewodniki i F1).

#Czego potrzebujesz

  • Windows 10 lub 11, 64 bity.
  • .NET Framework 4.8 dla silnika JoyPro. Windows 10 i 11 już go mają; jeśli go brakuje, JoyPro proponuje instalator od Microsoftu.
  • Nic więcej: zip zawiera wszystko (program nie wymaga osobno zainstalowanego .NET 9).

#Aktualizacje

JoyPro przy uruchomieniu sprawdza na GitHubie, czy jest nowsza wersja (Ustawienia: Sprawdzaj aktualizacje przy uruchomieniu). Nowsza wersja otwiera okno z listą zmian i Zaktualizuj teraz / Później / Pomiń tę wersję. Twoje profile i ustawienia zostają.

Zaawansowane

#Gdzie JoyPro trzyma dane

Twoje profile są w folderze Dokumenty, w JoyPro2. Tam trafiają też raporty problemów. Aktualizacja zastępuje tylko folder programu: Twoje profile, ustawienia, listy poleceń, kopie zapasowe i historia zostają. Pełna lista folderów jest w Szczegółach technicznych.

#Komponenty opcjonalne

Ustawienia > Komponenty instaluje, każdy jednym kliknięciem i za Twoją zgodą: vJoy (wirtualny joystick), HidHide (ukrywa fizyczne urządzenia przed grą) i ViGEmBus (wirtualny pad Xbox), dla trybu Wirtualny joystick. Ustawienia > Lokalna AI może pobrać opcjonalny model AI dla asystenta; wszystko działa bez niego.

#Łączenie z internetem

JoyPro łączy się z internetem tylko w tych celach: sprawdzanie aktualizacji (GitHub), zdjęcia produktów Twoich urządzeń od producentów (dopiero po Twojej zgodzie dla każdego urządzenia), okładki gier, których brakuje na Twoim komputerze (można to wyłączyć), opcjonalny model AI, opcjonalne komponenty i brakujący instalator .NET Framework. Te strony widzą Twój adres IP. Szczegóły: Prywatność.

Szczegóły techniczne

#Wszystkie foldery JoyPro

Co Gdzie
Program folder, który rozpakowałeś (z engine\engine.exe, vjoy\, tray\ i danymi dostarczanymi przez JoyPro w DB\)
Twoje profile Documents\JoyPro2 (albo gdziekolwiek je zapiszesz)
Ustawienia %APPDATA%\JoyPro2 (ui-settings.json, export-settings.json, hud.json ...)
Listy poleceń gier zbudowane na Twoim komputerze %LOCALAPPDATA%\JoyPro2\GameData
Kopie zapasowe plików gier %LOCALAPPDATA%\JoyPro2\GameBackups (30 najnowszych na grę)
Historia profilu (cofanie także po ponownym uruchomieniu) %LOCALAPPDATA%\JoyPro2\ProfileHistory
Dzienniki %LOCALAPPDATA%\JoyPro2\Logs (usuwają się same po kilku dniach)
Raporty problemów Documents\JoyPro2\Problem Reports

#Wewnątrz pakietu

  • JoyPro.Gui.exe: aplikacja Avalonia (.NET 9, samodzielna).
  • JoyPro 2 - Tour.cmd: uruchamia JoyPro.Gui.exe --welcome, powitanie z przewodnikami (przekazuje je do działającego JoyPro).
  • engine\engine.exe: silnik (.NET Framework 4.8). GUI uruchamia go przy każdej akcji; możesz też uruchomić go w konsoli (wiersz poleceń silnika).
  • vjoy\JoyPro.VJoy.exe (przekazywanie do wirtualnego joysticka), JoyPro.Ffb.exe (force feedback z telemetrii), tray\JoyPro.Tray.exe (obserwator, gdy GUI jest zamknięte).
  • Aktualizacja pobiera plik zip wydania, sprawdza go względem opublikowanego pliku .sha256 i go instaluje.
  • Budowanie ze źródeł: dotnet build gui/JoyPro.Gui/JoyPro.Gui.csproj (buduje też silnik; wymaga narzędzi do budowania .NET Framework 4.8), zobacz README repozytorium.
